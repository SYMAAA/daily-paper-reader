## 摘要
高昂的计算与环境成本阻碍了大型语言模型（LLM）的可扩展部署。传统压缩技术（稀疏性、量化、低秩近似）通常被孤立地使用，各自都遇到了精度与效率的瓶颈。本论文提出“压缩三位一体”（Compression Trinity），一个统一框架，将三大支柱联合应用：稀疏性以减少计算，量化以最小化内存带宽，低秩近似以恢复精度。为加速预训练，我们将三位一体应用于优化器和模型架构。MKOR通过块对角稀疏性和低秩求逆近似曲率，保持量化状态的数值稳定性；它将曲率更新复杂度从$O(d^3)$降至$O(d^2)$，并比KFAC加速收敛最多1.85倍。SLoPe通过针对N:M稀疏性的双重剪枝反向传播将训练加速最多1.25倍，在训练最后1%阶段使用低秩“惰性”适配器以恢复精度。对于训练后压缩，OPTIMA通过将权重重建公式化为全局最优的列式二次规划，在零训练模式下稳定静态掩码，零样本精度提升最多3.97%。在给定微调预算的情况下，PATCH通过学习0%至50%之间的动态混合稀疏比例，打破了静态掩码的上限，带来最多1.38倍的加速。最后，SLiM一次性实现了完整的压缩三位一体，使用数学推导的低秩适配器来恢复因量化和稀疏性而丢失的信息，相比最先进方法精度提升最多5.66%，并在相同参数预算下以0.6%的优势超越未压缩的稠密模型。综合这些结果，表明联合应用压缩三位一体对于实现高效、可扩展、高性能的LLM至关重要。

## Abstract
Prohibitive computational and environmental costs impede the scalable deployment of Large Language Models (LLMs). Traditional compression techniques (sparsity, quantization, low-rank approximations) are typically applied in isolation, and each hits an accuracy-efficiency wall. This thesis proposes the "Compression Trinity," a unified framework that applies the three pillars jointly: sparsity to reduce computation, quantization to minimize memory bandwidth, and low-rank approximations to recover accuracy. To accelerate pretraining, we apply the Trinity to the optimizer and model architecture. MKOR approximates curvature via block-diagonal sparsity and low-rank inversion, maintaining numerical stability for quantized states; it reduces curvature update complexity from $O(d^3)$ to $O(d^2)$ and accelerates convergence by up to 1.85x over KFAC. SLoPe accelerates training by up to 1.25x via a double-pruned backward pass for N:M sparsity, using low-rank "lazy" adapters in the final 1% of training to recover accuracy. For post-training compression, OPTIMA stabilizes static masks in a zero-training regime by formulating weight reconstruction as globally optimal column-wise quadratic programs, improving zero-shot accuracy by up to 3.97%. Given a fine-tuning budget, PATCH breaks the ceiling of static masks by learning a dynamic hybrid sparsity ratio between 0% and 50%, yielding up to 1.38x speedups. Finally, SLiM realizes the full Compression Trinity in one shot, using mathematically derived low-rank adapters to recover information lost to quantization and sparsity, improving accuracy by up to 5.66% over state-of-the-art methods and outperforming uncompressed dense models at equal parameter budgets by 0.6%. Together, these results show that jointly applying the Compression Trinity is essential for efficient, scalable, high-performance LLMs.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：大型语言模型（LLM）的训练与部署面临高昂的计算、内存和环境成本，传统压缩技术（稀疏性、量化、低秩近似）各自独立应用时，都会遭遇"精度-效率墙"（accuracy-efficiency wall），即单一压缩方法在达到一定压缩比后，模型精度急剧下降。
- **关键观察——"稀疏性悖论"**：作者发现，仅有2倍压缩比的2:4稀疏性导致的精度损失，反而大于4倍压缩比的4-bit量化。这说明稀疏性是三大支柱中"最具破坏性"的技术，因为它直接删除了网络连接（拓扑信息）。
- **核心主张**：压缩不应被视为单一优化问题，而应是一个**多维度平衡行为**。作者提出"压缩三位一体"（Compression Trinity）框架，主张联合应用三大互补的压缩支柱：
  - **稀疏性** → 减少计算量（FLOPs），加速计算密集阶段（训练、预填充）；
  - **量化** → 降低内存带宽需求，加速内存密集阶段（推理解码）；
  - **低秩近似** → 作为算法"配重"，在低维空间中恢复精度，不重新引入已被消除的硬件开销。
- **整体意义**：该框架贯穿LLM全生命周期（预训练与推理），证明"效率墙"不是根本性的，而是方法论的失败。

## 2. 论文提出的方法论

论文以"压缩三位一体"为统一框架，按LLM生命周期分两阶段、共五个方法展开。

### 2.1 预训练阶段

**MKOR（Momentum-Enabled Kronecker-Factor-Based Optimizer Using Rank-1 Updates）**
- 将三位一体应用于二阶优化器内部计算：
  - **稀疏性**：块对角化近似Fisher信息矩阵；
  - **低秩近似**：用rank-1更新（Sherman-Morrison恒等式）代替昂贵的矩阵求逆，将曲率更新复杂度从 $O(d^3)$ 降至 $O(d^2)$；
  - **量化**：利用rank-1更新的数值稳定性，将因子存储和通信降到半精度（16-bit），而其他二阶方法需要32-bit。
- 提出Norm-Based Stabilizer（基于范数的稳定器）抑制梯度爆炸；提出损失下降率驱动的混合切换机制（MKOR-H），在训练后期自动切换回一阶方法。

**SLoPE（Double-Pruned Sparse Plus Lazy Low-Rank Adapter Pretraining）**
- 提出**双重剪枝反向传播**（Double-Pruned Backward Pass）：前向传播使用标准N:M掩码；反向传播先转置再施加新的N:M掩码，从而同时加速前向和反向传播，避免昂贵的可转置掩码搜索。
- 提出**惰性低秩适配器**（Lazy Low-Rank Adapters）：仅在训练最后1%的迭代引入低秩适配器，以并行路径而非矩阵相加的方式与稀疏权重共存，避免破坏稀疏模式，快速恢复精度。

### 2.2 后训练压缩阶段

**OPTIMA（Optimal One-Shot Pruning via Quadratic Programming）**
- 将剪枝后的权重重建问题分解为逐列的**带约束凸二次规划（QP）**：
  - 关键洞察：同一层所有列共享相同的Hessian矩阵 $H = X^T X$，但约束不同（由掩码决定）；
  - 采用一阶primal-dual QP求解器（rAPDHG），利用共享Hessian实现批量并行求解；
  - 作为"即插即用"的权重更新步骤，可替换Wanda、SparseGPT、Thanos等方法的更新环节，获得全局最优重建。

**PATCH（Learnable Tile-Level Hybrid Sparsity）**
- 将权重矩阵划分为硬件友好的块（tile），通过可学习的Gumbel-Softmax采样，将每个tile分配为**稠密（0%稀疏）**或**2:4稀疏（50%稀疏）**，从而实现0%~50%之间的**连续可调混合稀疏比**。
- 支持两种变体：
  - **PATCH Joint**：联合优化稠密tile位置与稀疏tile内部的2:4掩码；
  - **PATCH Tile**：仅优化稠密tile位置，冻结2:4掩码（内存高效版，适用于7B/8B大模型）。
- 使用全局稀疏目标正则化，动态将剪枝集中在冗余层（如MLP）而保护关键层（如注意力中的Key/Value矩阵）。

**SLiM（One-shot Quantized Sparse Plus Low-rank Approximation）**
- 三步流水线完整实现三位一体：
  1. **SLiM-Quant**：将量化尺度α的寻找形式化为概率重建误差最小化，通过对权重直方图数值积分求最优α；
  2. **稀疏化**：对量化权重施加硬件友好的2:4或非结构化剪枝（与Wanda等掩码选择器兼容）；
  3. **SLiM-LoRA**：设计满足可逆性与可加性的**显著性函数** $F(W) = \text{diag}(x)W$，使低秩适配器通过SVD解析求解（one-shot），无需训练：
$$L, R = \arg\min_{L,R} \|\text{diag}(x)(W - W^C) - \text{diag}(x)LR\|^2$$
- 适配器本身可进一步4-bit量化（SLiM-LoRA Q），并支持可选的轻量PEFT微调。

## 6. 论文的主要结论与发现

1. **联合应用三大支柱是必要的**：在8倍压缩比下，2-bit量化（31.81%）或87.5%稀疏（31.24%）单独应用均使LLaMA-2-7B精度接近随机，而4-bit量化+50%稀疏联合应用可达52.38%。
2. **三位一体适用于全生命周期**：不仅后训练压缩，连优化器本身和训练过程都可以通过三位一体加速。
3. **稀疏性需要专门强化**：由于稀疏性最具破坏性，必须先将其强化为稳定支柱（OPTIMA、PATCH），才能承受联合压缩的压力。
4. **低秩近似是误差校正的关键**：SLiM证明数学推导的显著性加权低秩适配器可以一次性补偿量化和稀疏性带来的复合误差，无需重训练。
5. **性能成果量化**：
   - MKOR：BERT-Large训练提速达2.57倍（vs LAMB），1.75倍（vs KAISA）；
   - SLoPE：训练提速1.25倍，推理加速1.34-1.54倍，训练/推理内存降低约0.63/0.61倍；
   - OPTIMA：零样本精度提升最高3.97%（绝对百分点）；
   - PATCH：LLaMA-2 7B端到端加速1.18x-1.38x，精度超过MaskLLM达2.96%；
   - SLiM：在2:4稀疏+4-bit量化下超越SOTA达5.66%，同等参数量下比稠密模型高0.6%，单层推理加速达3.78倍（RTX-3060）。
6. **模型选择洞察**：在同等参数量下，经SLiM压缩的大型模型优于未压缩的小型稠密模型，为硬件受限场景提供配置指南。

## 8. 不足与局限

- **硬件耦合性强**：2:4稀疏模式紧密绑定NVIDIA Sparse Tensor Core，未验证在TPU、AMD MI系列、CPU上的可移植性；自定义CUDA/Triton kernel构成软件移植障碍。
- **训练稳定性风险**：二阶优化器（MKOR）对超参数仍比AdamW更敏感，额外超参数带来调参负担。
- **流水线复杂度高**：联合压缩（如SLiM）的实现、调试与维护成本远高于简单的后训练量化方案，构成实际采用门槛。
- **评估规模受限**：实验主要在125M至70B参数范围，未涵盖万亿级前沿模型；超长上下文下KV缓存与注意力压缩未深入探索。
- **公平性/偏差风险**：压缩质量仅用聚合精度衡量——虽然模型整体精度可能匹配，但**可能掩盖对少数群体、低资源语言的性能退化**。校准与评估数据以主流人群为主，压缩方法可能放大已有偏差。论文坦承这种风险。
- **研究者自身指出（第8章）**：
  - 未来应扩展至上下文窗口压缩（KV缓存量化、稀疏注意力）；
  - 需要硬件-算法协同设计，消除稀疏格式的元数据存储开销；
  - 激活张量的动态稀疏仍有待探索。
