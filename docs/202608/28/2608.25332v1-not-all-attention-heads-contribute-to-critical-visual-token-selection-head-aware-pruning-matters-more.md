## 摘要
视觉语言模型（VLMs）在各种视觉场景中展现出了令人瞩目的性能。然而，这一成功是以视觉标记的爆炸式增长为代价的，这在推理过程中带来了大量的内存和计算开销，最终增加了延迟。为了提高VLM推理效率，一类典型的视觉标记剪枝方法通过聚合大型语言模型（LLM）骨干网络中剪枝层的所有注意力头的注意力分数来估计标记重要性，并基于聚合分数对标记进行剪枝。然而，在本文中，我们揭示了一个引人注目的现象：定位关键视觉标记的能力集中在一小部分注意力头上。仅在这些头上进行聚合可以提高任务性能。受此观察启发，我们提出了ProViP，一种无需训练的渐进式视觉标记剪枝框架。ProViP首先在LLM骨干网络推理之前，基于输入标记的嵌入相似性去除冗余的视觉标记，然后在推理过程中通过头部感知剪枝进一步剪枝标记。实验表明，ProViP在任务性能和推理效率方面表现出色。例如，当应用于LLaVA-1.5-7B时，ProViP在88.9%的剪枝比例下保留了95.9%的原始性能，并实现了1.62倍的推理加速。

## Abstract
Vision-Language Models (VLMs) have exhibited impressive performance across diverse visual scenarios. However, this success comes at the cost of explosive growth in visual tokens, which imposes substantial memory and computational overhead during inference, ultimately increasing latency. To improve VLM inference efficiency, a typical class of visual token pruning methods estimates token importance by aggregating attention scores across all heads in the pruning layer of the Large Language Model (LLM) backbone and prunes tokens based on aggregated scores. However, in this paper, we reveal a compelling phenomenon: the capability to pinpoint critical visual tokens is concentrated within a small fraction of heads. Aggregation exclusively on these heads can improve task performance. Inspired by this observation, we propose ProViP, a training-free progressive visual token pruning framework. ProViP first removes redundant visual tokens based on the embedding similarity of input tokens before reasoning of the LLM backbone, and then further prunes tokens during reasoning via head-aware pruning. Experiments demonstrate that ProViP delivers outstanding task performance and inference efficiency. For instance, when applied to LLaVA-1.5-7B, ProViP retains 95.9% of the original performance and achieves 1.62x inference speedup under an 88.9% pruning ratio.

## 二、论文提出的方法论

### 核心思想

ProViP 是一个**训练无关（training-free）的渐进式视觉token剪枝框架**，包含三个阶段：

1. **LLM推理前的相似性剪枝**：利用文本与视觉token的嵌入相似度，在视觉token进入LLM骨干之前预先去除冗余token。
2. **浅层推理中的头部感知剪枝**：仅利用识别出的“视觉头”的注意力分数来估计视觉token重要性，进行精准剪枝。
3. **中层推理中的全头剪枝**：在中间层使用所有注意力头的分数进行剪枝，因为此时视觉信息已在各头间充分融合。

### 关键技术细节

**(1) 关键文本token选择（Critical Textual Token Selection）**

- 为避免非内容词（如介词）对后续剪枝造成干扰，需要从指令中抽出语义关键token。
- 方法：利用文本嵌入的自相似度计算每个token的排名分数：

\[
r = \frac{1}{N_t} \sum_{i=1}^{N_t} \text{Softmax}(E_t \cdot E_t^T)_i
\]

选择分数高于均值 \(\text{Mean}(r)\) 的token作为关键文本token集合 \(\mathcal{T}\)。

**(2) LLM推理前的相似性剪枝（Pruning before the LLM Backbone）**

- 构建关键文本token与视觉token之间的跨模态余弦相似度矩阵 \(M \in \mathbb{R}^{|\mathcal{T}| \times N_v}\)：

\[
M_{i,j} = \frac{E_{t,t_i} \cdot E_{v,j}^T}{\|E_{t,t_i}\| \|E_{v,j}\|}
\]

- 为抑制非区分性文本token（对所有视觉token具有均匀高相似度）的影响，对每个文本token的相似度分数做均值减法（recalibration）：

\[
\hat{M}_{i,j} = M_{i,j} - \frac{1}{N_v} \sum_{k=1}^{N_v} M_{i,k}
\]

- 对每个视觉token取跨文本维度的最大分数作为其重要性得分：

\[
p_j = \max\{\hat{M}_{1,j}, \hat{M}_{2,j}, \dots, \hat{M}_{|\mathcal{T}|,j}\}
\]

- 保留得分最高的 \(N_1\) 个token，未选中的token会按ApET方法**合并到最近的中心token中**，以减少信息损失。

**(3) 推理过程中的头部感知剪枝（Pruning during the LLM Backbone）**

- **视觉头识别**：对于剪枝层 \(l\) 的第 \(h\) 个注意力头，计算其跨模态注意力图在所有关键文本token上的方差之和作为置信度：

\[
C_h^l = \sum_{i=1}^{|\mathcal{T}|} \text{Variance}(A^l_{cross, h, t_i})
\]

- 取置信度最高的 \(N_{vis}\) 个头作为视觉头集合 \(\mathcal{V}^l\)。
- **浅层剪枝**：仅对视觉头的注意力分数求平均：

\[
S_{vis} = \frac{1}{|\mathcal{V}^l|} \sum_{j \in \mathcal{V}^l} A^l_{cross, j}
\]

再对每个视觉token在所有文本token上取平均，得到重要性分数 \(v_i\)，保留得分最高的 \(N_2\) 个token。

- **中层剪枝**：简单地将视觉头集合替换为全部注意力头，其余流程相同。

## 六、论文的主要结论与发现

1. **核心发现**：VLM中识别关键视觉token的能力并非均匀分布于所有注意力头，而是集中在一小部分“视觉头”上。仅聚合这些头的注意力分数进行剪枝，比聚合全部头的效果更好，尤其在浅层剪枝时增益明显。
2. **层间差异**：视觉头带来的性能优势在LLM浅层显著，在中深层逐渐消失，原因在于深层视觉token经过充分全局交互后变得更加同质，对选token的精度不再敏感。
3. **ProViP的有效性**：
   - 在LLaVA-1.5-7B上，剪枝88.9%的视觉token后，仍保留原始性能的95.9%，推理延迟降低38.2%，预填充时间减少62.2%。
   - 在LLaVA-NEXT-7B高分辨率场景下，保留320个token即可达到95.9%的平均性能保留率，优于所有基线。
   - 在Qwen2.5-VL-7B上亦稳定优于SparseVLM和PDrop，表明方法具备良好的跨架构泛化能力。
4. **正确定位**：实验表明，头部感知剪枝（head-aware pruning）是提升VLM推理效率的更优策略，为高效VLM设计提供了新的视角。

## 七、优点

- **现象发现具有原创性**：系统性地揭示了“注意力头对关键视觉token识别能力存在异质性”这一现象，并提出了可操作的“视觉头”启发式识别方法。
- **方法训练无关、即插即用**：ProViP不需任何微调，可直接部署于现有的开源VLM中，实用性较强。
- **渐进式设计合理**：将LLM前预剪枝（基于相似度）+浅层头感知剪枝（基于视觉头）+中层全头剪枝有机结合，兼顾了效率与精度。
- **信息损失控制**：对剪枝掉的token采用合并到最近中心token的策略（借鉴ApET），有效降低了硬剪枝带来的信息损失。
- **实验体系比较完整**：覆盖多数据集、多模型、多剪枝比例，且包含效率测量与多类消融分析；在每项主流基线横向对比中均取得最优或接近最优的性能。
- **写作清晰，理论分析到位**：对计算量（FLOPs）提供了推导，从数学上说明了剪枝带来的加速收益。

## 八、不足与局限

- **仅适用于开源白盒模型**：ProViP在剪枝过程中需要访问LLM的中间层注意力输出，因此无法直接应用于闭源或黑盒API模型（如Gemini、GPT-5）。
- **无法完全绕过注意力计算**：因为依赖注意力分数做引导，剪枝层仍然需要显式计算注意力，可能部分抵消FlashAttention等高效注意力实现带来的加速。
- **视觉头数量的设定较为武断**：实验中固定为每个剪枝层取6个视觉头，虽然做了少量敏感性分析（2/4/8/10），但未给出自适应的选取策略，可能在更复杂任务或模型上不够灵活。
- **评估基准范围有限**：主要集中在视觉问答、幻觉检测等场景，未涵盖视频理解、具身智能、视觉定位等高阶任务。
- **效率评测不够全面**：延迟和FLOPs等指标仅在一个数据集（POPE）上报告，缺少更多样化的统计结果。
- **未报告多次运行的标准差**：若实验存在随机性，缺乏方差信息可能影响结论的稳健性判断。
