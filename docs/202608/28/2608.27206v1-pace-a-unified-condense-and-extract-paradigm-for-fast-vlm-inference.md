## 摘要
视觉语言模型（VLM）展现出卓越的视觉推理能力，然而随着视觉令牌数量的增加，其推理成本迅速上升。现有的视觉令牌剪枝方法存在两个根本性局限。首先，大多数方法仅在视觉编码器之后运行，未能优化视觉编码阶段的显著延迟。其次，在严格的令牌预算下，这些方法往往无法同时保留整体视觉上下文和细粒度细节，导致性能下降。为解决这些瓶颈，我们提出了PACE（像素自适应压缩与提取），一种无需训练的推理框架，通过统一的压缩-提取范式同时加速视觉编码器和大语言模型（LLM）。在压缩阶段，自适应像素压缩器（APC）在编码前评估视觉信息密度，自适应地下采样冗余输入，减少编码器计算量，同时保留全局上下文和关键视觉线索。在提取阶段，动态双注意力提取器（DDAE）通过融合来自编码器的内部视觉信号和来自LLM的语义信号，选择性保留视觉令牌，确保任务关键细节不被丢失。通过将PACE集成到Qwen2.5-VL-7B中，模型在仅使用10%视觉令牌的情况下保持了93.8%的原始性能，并使首令牌时间（TTFT）加速3.1倍。我们的代码可在https://github.com/jjL357/PACE获取。

## Abstract
Vision-Language Models (VLMs) demonstrate exceptional visual reasoning capabilities, yet their inference costs escalate rapidly with the proliferation of visual tokens. Existing visual token pruning methods exhibit two fundamental limitations. First, most approaches operate exclusively post-vision encoder, leaving the substantial latency of the visual encoding phase unoptimized. Second, under strict token budgets, these methods often fail to jointly preserve holistic visual contexts and fine-grained details, leading to performance degradation. To address these bottlenecks, we propose PACE (Pixel-Adaptive Condense and Extract), a training-free inference framework that accelerates both the vision encoder and the Large Language Model (LLM) via a unified Condense-and-Extract paradigm. During the Condense stage, an Adaptive Pixel Compressor (APC) evaluates visual information density prior to encoding, adaptively downsampling redundant inputs, curtailing encoder computation while preserving global context and essential visual cues. In the Extract stage, a Dynamic Dual-Attention Extractor (DDAE) selectively retains visual tokens via a fusion of internal visual signals from the encoder and semantic signals from the LLM, safeguarding task-critical details. By integrating PACE into Qwen2.5-VL-7B, the model retains 93.8% of its original performance while utilizing only 10% of the visual tokens, yielding a 3.1x speedup in time to first token (TTFT). Our code is available at https://github.com/jjL357/PACE.

# 论文总结：PACE——一种用于快速VLM推理的统一压缩-提取范式

## 1. 核心问题与整体含义（研究动机和背景）

- 视觉语言模型（VLM）推理成本随视觉 token 数量急剧增长，尤其是高分辨率图像和视频会产生大量视觉 token，导致视觉编码器和 LLM 预填充阶段的计算成为严重瓶颈。
- 现有视觉 token 剪枝方法存在两大根本局限：
  - **仅在视觉编码器之后操作**：只减少 LLM 端序列，无法优化视觉编码阶段的高额计算开销；
  - **低预算下难以兼顾全局与细节**：在严格 token 预算（如 10%、5%）下，简单剪枝会破坏整体布局和丢失细粒度证据（如文字笔画、图表网格线），导致在细节敏感任务（ChartQA、DocVQA、OCRBench 等）上性能急剧下降。
- 论文提出 **PACE（Pixel-Adaptive Condense and Extract）**，一种**训练无关、即插即用**的推理加速框架，通过统一的“压缩-提取”范式同时加速视觉编码器和 LLM，在极低视觉 token 预算下保留全局上下文与关键细节。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

PACE 由两个阶段组成：

### (1) Condense 阶段：自适应像素压缩器（APC）

- **目标**：在视觉编码器前压缩冗余像素，降低编码器计算量，同时保留全局布局和局部细节。
- **流程**：
  1. **浅层特征预览**：使用 ViT 的第一个 block（K=1）提取初始 token 嵌入，进行 ℓ2 归一化，得到特征序列。
  2. **全局信息密度**：计算所有 token 对的平均余弦相似度 φ，定义全局信息密度 ρg = 1 − φ。φ 高表示冗余多（如大块均匀背景）。
  3. **局部细节对比**：计算全局平均 token c 作为基线，对每个 token 计算到基线的欧氏距离 d_i；取距离最大的前 10% 的 token 的均值 d̄_top，映射为局部保留分数 ρd = min(d̄_top / γ, 1.0)，γ 为缩放因子。
  4. **自适应缩放**：融合全局和局部分数得到统一保留比例 ρ = α·ρg + (1−α)·ρd，并将原图像等比缩放（边长乘以 √ρ）。若存在硬性内存预算，则取更小值。
- **关键点**：APC 不使用启发式 patch 丢弃，而是动态调整整图分辨率，避免破坏连续性 2D 布局。

### (2) Extract 阶段：动态双注意力提取器（DDAE）

- **目标**：在编码后剔除剩余冗余，保留既语义相关又信息丰富的视觉 token。
- **流程**：
  1. 从 LLM 的指定层（L_ext）抽取交叉注意力图，归一化得到语义相关性图 S_llm；
  2. 从 ViT 末端层抽取自注意力图，归一化得到视觉密度图 S_vis；
  3. 使用两种注意力分布的**标准差**作为置信度代理，经 softmax 动态分配融合权重：
     - α_weight, β_weight = Softmax([σ_llm, σ_vis] / τ)
  4. 计算最终显著性得分 S_final = α_weight·S_llm + β_weight·S_vis，保留 top-K 视觉 token 作为 LLM 上下文。
- **动机**：LLM 注意力可能过度聚焦显式文本提及的区域，忽略未提及的关键视觉锚点；ViT 自注意力无查询条件，可能保留任务无关背景。动态融合可权衡语义相关性与细节完整性。

### 整体加速效应

- APC 减少 ViT 计算，DDAE 减少 LLM 预填充长度；理论上编码器复杂度由 O(N²) 降低至 O(p₁²N²)，LLM 预填充计算量近似由 O(S_pre²) 降低至 O(L_ext·S_pre² + (L_l−L_ext)·S_post²)。

## 7. 优点

- **统一解决双瓶颈**：同时优化视觉编码器和 LLM 预填充，而非仅处理 LLM 侧；
- **训练无关、即插即用**：无需任何训练或架构修改，可直接应用于现有 VLM；
- **保留全局与细节**：APC 通过信息密度评估自适应调整输入分辨率，避免硬性 patch 丢弃破坏布局；DDAE 融合视觉自注意力与 LLM 语义注意力，兼顾任务相关性与细节完整性；
- **正交兼容性**：APC 作为独立前置模块可与任意后编码剪枝方法组合，即插即用价值高；
- **实验全面且细致**：多模型、多数据集、多预算、多消融，并给出了详细的效率剖析（TTFT、prefill/encoder 分阶段延迟），有助于社区复现和推广。

## 8. 不足与局限

- **编码器加速依赖分辨率压缩有效性**：APC 仅当降低像素/ tile 数量能实际减少编码器 token 数时才有效；在固定网格 VLM 中，DDAE 只能加速 LLM 预填充，APC 无编码器增益。
- **预览开销因架构而异**：浅层特征预览引入额外延迟，虽然平均被摊销，但在不同架构/分辨率下加速效果可能不一致，论文给出的 Qwen2.5-VL 速度提升不一定能迁移到其他骨干。
- **APC 是查询无关的一次性压缩**：可能漏掉极其微小、低对比度的视觉目标（如细小字符、图表标签、细线），一旦压缩后变得模糊，DDAE 无法恢复。论文建议在高风险场景使用更高保留率或更低 α。
- **实验覆盖有限**：仅验证了 Qwen2.5-VL（3B/7B）和 InternVL3.5-4B，未覆盖 LLaVA、Phi-4-mini 等其他主流 VLM；也未评估视频输入场景。
- **未评测解码阶段加速**：PACE 仅加速预填充（TTFT），不加速自回归生成过程，长时间生成时总加速比会被稀释。
- **未与最新的 token 合并/动态分辨率方法（如 AdaPatch、VisionThink 等）进行直接对比**，对比基线集中在经典剪枝方法，最新 SOTA 对比略显不足。
- **潜在偏差风险**：部分任务（如 POPE、MMBench）本身存在高重复图像（表 5 中重复率高达 94%），可能对剪枝方法的鲁棒性评估带来一定偏差；但论文已报告详细数据，对比较公平。
