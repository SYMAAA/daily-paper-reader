## 摘要
由于视频输入会产生大量视觉Token，适配视频视觉语言模型（VLM）的计算成本很高，使得微调和推理都代价高昂。虽然视觉Token压缩可以减少这种开销，但在压缩输入上直接适配常常导致语义漂移和明显的性能下降。我们提出了Token预算蒸馏（TBD），一种在固定Token预算下适配视频VLM的参数高效微调框架。TBD冻结预训练骨干网络，仅更新LoRA适配器，并将基于FlashVID的视觉Token压缩集成到视频通路中。为了在压缩下保留全Token语义，TBD采用双路径教师-学生设计，其中全Token教师提供稳定监督，压缩学生则通过任务损失、答案区域KL蒸馏、GT锚定边际蒸馏和可靠性感知KD控制进行优化。这种设计使学生能够恢复全Token模型的语义行为，同时在激进Token缩减下保持高效。我们在三个视频VLM骨干网络（包括LLaVA-Video、LLaVA-OneVision和Qwen3-VL-8B-Instruct）及四个视频理解基准上评估了TBD。在中等和激进压缩下，TBD均持续优于仅压缩的基线。在LLaVA-Video上，当保留比率R=10%时，TBD保留了Vanilla模型平均准确率的97.0%；在LLaVA-OneVision上，当R=10%时，TBD取得了58.4的平均分数，并达到了100.0%的相对准确率。

## Abstract
Adapting video vision-language models (VLMs) is computationally expensive because video inputs produce a large number of visual tokens, making both fine-tuning and inference costly. Although visual token compression can reduce this overhead, direct adaptation on compressed inputs often causes semantic drift and noticeable performance degradation. We present Token-Budget Distillation (TBD), a parameter-efficient fine-tuning framework for adapting video VLMs under a fixed token budget. TBD freezes the pretrained backbone, updates only LoRA adapters, and integrates FlashVID-based visual token compression into the video pathway. To preserve full-token semantics under compression, TBD employs a dual-path teacher-student design, where a full-token teacher provides stable supervision and a compressed student is optimized with task loss, answer-region KL distillation, GT-anchored margin distillation, and reliability-aware KD control. This design enables the student to recover the semantic behavior of the full-token model while remaining efficient under aggressive token reduction. We evaluate TBD on three video VLM backbones, including LLaVA-Video, LLaVA-OneVision, and Qwen3-VL-8B-Instruct, across four video understanding benchmarks. TBD consistently outperforms compression-only baselines under both moderate and aggressive compression. On LLaVA-Video at retention ratio R = 10 percent, TBD preserves 97.0 percent of the Vanilla model's average accuracy; on LLaVA-OneVision at R = 10 percent, it achieves an average score of 58.4 and matches 100.0 percent relative accuracy.

## 一、核心问题与研究动机

- **背景**：视频视觉语言模型（Video VLM）在视频问答、指令跟随、长视频理解等任务上表现出色，但视频输入会产生大量视觉 Token（即“Token 爆炸”），导致微调和推理的注意力计算呈二次复杂度增长，计算开销极大。
- **已有方案的不足**：
  - 视觉 Token 压缩（如 FastV、VisionZip、FastVID、FlashVID 等）能降低开销，但多数被当作“即插即用”的推理加速器；
  - 若在固定 Token 预算下对压缩后的输入直接进行任务微调，会产生显著的**语义漂移（Semantic Drift）**：模型对细粒度动作的判别（如“骑自行车”）退化为笼统概念（如“运动物体”），视觉注意力从关键前景分散到背景噪声。
- **核心论点**：作者将问题重新定义为“语义保持”问题，而非单纯的“效率优化”问题——在激进压缩下，需要把全 Token 模型的语义能力迁移到压缩学生模型上。

## 二、方法论：Token-Budget Distillation (TBD)

### 核心思想
- 采用**双路教师-学生架构**：全 Token 教师分支提供稳定监督，压缩学生分支在固定 Token 预算下训练，训练后丢弃教师分支，仅保留高效的学生模型。
- **参数高效**：冻结预训练骨干 Θ，仅更新 LoRA 适配器 Φ；压缩模块（FlashVID）本身完全无训练，梯度只流经压缩后的表示。

### 关键技术细节
1. **Token 压缩与 LoRA 结合**
   - 压缩算子：z_c = C(z_f; B)，将全 Token 序列压缩至预算 B；
   - LoRA 权重更新：W = W₀ + ΔW，ΔW = B_W·A_W（低秩矩阵，r ≪ min(d, d′)）；
   - 压缩负责削减序列长度，LoRA 负责通过残差更新抵消语义漂移。

2. **答案区域 KL 蒸馏（Answer-Region KL Distillation）**
   - 在有效答案区域内计算 KL 散度：L_KL = (1/|Ω|) Σ_{i∈Ω} KL(σ(l_t^i/τ) ∥ σ(l_s^i/τ))·τ²；
   - 关键创新是**可靠性掩码 Ω**：只保留教师预测正确且置信度超过阈值的 Token 位置，过滤噪声蒸馏信号。

3. **GT 锚定边际蒸馏（GT-Anchored Margin Distillation）**
   - 显式定义正确 Token 与最难负样本之间的边际：m_t = l_{t,y} − l_{t,n}，m_s = l_{s,y} − l_{s,n}；
   - 用 Huber 损失惩罚学生与教师边际的偏差，防止“边际崩塌”，强化决策边界。

4. **可靠性感知 KD 控制**
   - KD 权重 λ̂_kd(t) 采用线性预热（warmup），并相对 CE 损失大小进行严格上限截断，避免训练早期过度正则化。

5. **总体损失**
   - L = λ_ce·L_CE + λ̂_kd(t)·L_KD，其中 L_KD = L_KL + λ_m·L_margin。
   - 完整流程见 Algorithm 1：教师前向（无梯度）→ 学生前向（含梯度）→ 可靠性掩码构建 → 多目标损失计算 → 动态加权与参数更新。

## 六、主要结论与发现

1. **TBD 在各类设置下一致优于仅压缩基线**：
   - LLaVA-Video：R=20% 平均分 59.7（98.4% 相对精度）；R=10% 平均分 58.9，保留 Vanilla 的 97.0% 精度；
   - LLaVA-OneVision：R=20% 平均分 59.0（101.0% 相对精度）；R=10% 平均分 58.4，达到 100.0% 相对精度，完全匹配未压缩模型；
   - Qwen3-VL-8B-Instruct：R=20% 从 FlashVID 的 60.9 提升至 61.6；R=10% 从 58.8 提升至 59.4，相对精度从 91.3% 升至 92.2%。
2. **TBD 在多层面修复语义漂移**：
   - 输出分布对齐：学生与教师的 KL 散度从 0.2310 降至 0.1172（100 样本均值）；
   - 决策边界重建：平均边际从 2.2325 增至 2.7832，负边际比例从 31.5% 降至 24.0%；
   - 注意力漂移被遏制：学生注意力聚焦区域与教师高度一致。
3. **压缩模块的影响**：TBD 可与不同压缩前端搭配，但最终性能上界受前端压缩质量约束（FlashVID 最优）。
4. **总体判断**：在 Token 压缩下进行高效适配，本质上是语义保持问题；TBD 提供了将“压缩效率”与“语义保真”统一起来的有效范式。

## 七、优点

- **方法层面**：
  - 参数高效：仅训练 LoRA，显存与存储开销低；

  - 边际蒸馏弥补了纯 KL 对齐对局部决策边界保持不足的缺陷，两者互补。

## 八、不足与局限

- **训练期开销高**：推理时虽高效，但训练阶段必须运行全 Token 教师前向，训练期显存和计算需求大，未真正实现端到端的内存高效训练。

- **实验覆盖不足**：
  - 评测基准以选择题为主，缺少开放生成任务评测；
  - 消融实验仅在一个骨干（LLaVA-Video）和一个压缩率（R=10%）下进行；
  - 未与其他蒸馏式/可学习压缩方法对比。
- **潜在偏差风险**：
  - 教师模型本身并非“真实 Oracle”，其错误预测若被掩码选中或被置信度阈值漏过，会影响蒸馏质量；

- **应用限制**：当前框架适用于固定 Token 预算下的视频 VLM 适配，对动态自适应预算、流式视频、超长视频等场景的适用性尚未验证。
