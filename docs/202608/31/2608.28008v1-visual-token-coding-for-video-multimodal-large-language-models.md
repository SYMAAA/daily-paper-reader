## 摘要
在本文中，我们提出了一种用于视频多模态大语言模型（MLLMs）的新令牌压缩范式，称为视觉令牌编码（VTC）。受经典视频编码原理（如HEVC）的启发，VTC通过预测视频的I/P帧并测量其逐帧残差来估计令牌冗余，从而进行结构化压缩。基于这一基线框架，我们还通过一系列新颖的动态设计增强了VTC，例如动态分辨率输入（DyRSO）、动态令牌分配（DyTA）和空间覆盖Top-K（SC-TopK），并将这种新方法命名为$VTC_{Dy}$。为验证VTC，我们将其应用于三种MLLMs，并在多个视频理解基准上进行了实验。实验结果表明，对于Qwen3-VL，在50%令牌预算下，VTC$_{\mathrm{Dy}}$实现了100.1%的平均性能保持，而当令牌预算降至25%时，仍保持了97.8%的平均性能。此外，作为一种即插即用的设计，VTC在令牌编码过程中无需额外调整MLLMs。我们的代码可在https://github.com/Msr233/VTC获取。

## Abstract
In this paper, we propose a new token compression paradigm for video Multimodal Large Language Models (MLLMs), termed Visual Token Coding (VTC). Inspired by classical video coding principles, e.g., HEVC, VTC performs structured compression by predicting the I/P frames of a video and measuring their frame-wise residuals to estimate token redundancy. Based on this baseline framework, we also enhance VTC with a set of novel dynamic designs, such as Dynamic Resolution Input (DyRSO), Dynamic Token Allocation (DyTA), and Spatial Coverage Top-K (SC-TopK), and term this new approach $VTC_{Dy}$. To validate VTC, we apply it to three MLLMs and conduct experiments on multiple video understanding benchmarks. The experimental results show that VTC$_{\mathrm{Dy}}$ achieves an average performance retention of 100.1% with a 50% token budget for Qwen3-VL, while still retaining 97.8% of the average performance when the token budget is reduced to 25%. Moreover, as a plug-and-play design, VTC requires no additional tuning of MLLMs for token coding. Our code is available at https://github.com/Msr233/VTC.

## 1. 核心问题与整体含义

- **背景**：视频多模态大语言模型（Video MLLMs）在长视频理解上表现优异，但输入视频的视觉 token 数量极大。例如 Qwen3-VL 处理 1 小时、1 FPS 视频时需约 46 万个视觉 token，导致推理和内存成本过高。
- **问题**：如何在不损失精度的前提下压缩视觉 token？现有方法多依赖 token 重要性打分（如视觉显著性、多样性、查询相关性），或者进行帧间相似性合并，但缺乏对“参考-残差”这类结构化冗余的建模。
- **整体思路**：受传统视频编码（如 HEVC）中 I/P 帧预测、残差编码和码率分配的启发，作者将视频编码原理迁移到视觉 token 空间，提出 **视觉令牌编码（Visual Token Coding, VTC）**，将 token 压缩视为一种“编码”过程，实现结构化压缩。

## 2. 方法论

### 2.1 核心思想
- 将视频特征序列组织为 **语义 I 帧**（保留完整参考信息）和 **语义 P 帧**（相对于参考的残差信息）。
- 通过“预测 + 残差”衡量每个 token 的新增信息量，从而决定保留哪些 token。
- 整个方法 **无需训练**，即插即用，可直接适配现有 MLLM。

### 2.2 基线 VTC 框架
- **预测与残差**：对第 t 帧特征 \(F_t\)，用前一帧特征 \(F_{t-1}\) 作为参考，残差 \(R_t = F_t - \hat{F}_t\)，其中 \(\hat{F}_t = F_{t-1}\)（恒等预测）。token 级残差能量 \(E_{t,i} = \|R_t(i)\|_2\)。
- **语义 I/P 帧判定**：首帧为 I 帧；后续帧若当前帧平均残差能量 \(E_t\) 大于历史均值 \(E_{\text{hist}}\) 的 \(\tau\) 倍，则记为 I 帧（场景切换），否则为 P 帧。每个 chunk 内 I 帧数量有上限 \(M_{\max}^I\)。
- **预算分配**：设定全局保留率 \(r\)，总 token 预算 \(B_{\text{total}} = \lfloor r \sum_t N_t \rfloor\)。按 chunk 分为 \(B_l\)，I 帧消耗部分预算，剩余 P 帧预算均分，每帧保留残差能量最高的 \(K_{P_t}\) 个 token。

### 2.3 动态增强版本 \(VTC_{Dy}\)
- **动态分辨率输入（DyRSO）**：构建多分辨率 GOP（Group of Pictures），每个 GOP 由 1 个全分辨率 I 帧和 4 个半分辨率 P 帧组成（拼接为 2×2 画布）。在保持相同视觉编码成本（像素数）的前提下，覆盖 5 个时间戳，提升时间覆盖范围。
- **动态令牌分配（DyTA）**：利用 HEVC 编码的 bitcost 作为视频帧复杂度先验。对每个时间间隔计算 bitcost 的均值 \(\mu_t\) 和 90 分位数 \(p_t\)，加权得到复杂度 \(q_t = \alpha \tilde{\mu}_t + (1-\alpha)\tilde{p}_t\)。将 P 帧总预算按复杂度比例分配，同时为每帧保留最小 token 数 \(K_P^{\min}\)。
- **空间覆盖 Top-K（SC-TopK）**：为避免全局 Top-K 将所有 token 集中在高残差区域，将 token 网格划分为 \(M = G_h \times G_w\) 个区域，先按区域选择局部高残差 token（保证区域覆盖），再在剩余槽位中进行全局选择。

### 2.4 完整流程
- 输入视频 → 按 GOP 结构采样（全分辨率 I 帧 + 半分辨率 P 帧画布）→ 经 ViT 编码为 token 特征序列 → 计算残差能量 → 判定语义 I/P 帧 → 根据 bitcost 分配各帧预算 → 用 SC-TopK 在每个帧内选择 token → 将保留 token 送入 LLM。

## 6. 主要结论与发现

- 基线 VTC 在 50% 预算下平均保留约 98% 性能，25% 预算约 96%，验证了视频编码结构思想用于 token 压缩的可行性。

- \(VTC_{Dy}\) 在大部分基准上优于 FastV、VisionZip、HoliTom、FlashVID，尤其在 25% 预算下优势明显（如 MLVU 上领先第二好方法 2.4 个百分点）。
- 推理延迟降低 2.5 倍，且剪枝开销较小，整体效率优于对比方法。
- 消融实验表明：DyRSO 提升细节理解，DyTA 受益于长尾/全局复杂度建模，SC-TopK 保证空间覆盖；三者作用互补。

## 7. 优点

- **新颖视角**：首次将经典视频编码的“预测-残差-参考”结构引入 MLLM token 压缩，与传统重要性打分方法形成互补。
- **即插即用、零训练**：无需修改模型结构或进行任何微调，可直接应用于现有视频 MLLM。
- **动态设计合理**：分辨率、时间预算、空间覆盖三个维度均采用自适应机制，具有较强的泛化能力。
- **效率与精度兼顾**：在保证甚至提升精度的同时显著降低推理延迟。
- **实验严谨**：匹配了预剪枝编码成本，消除了输入像素数差异带来的不公平；消融和参数鲁棒性分析较完善。
