## 摘要
在移动设备上部署视觉语言模型（VLM）因其巨大的内存和计算需求而具有挑战性。我们提出了一种量化VLM的框架，用于在资源受限的硬件上进行高效推理。我们的方法结合了一种量化流程，该流程利用模型自身生成训练数据，且无需访问训练设置，并采用一种新颖的每参数2.7位格式，支持在Arm CPU上的高效执行。我们通过将Llama 3.2 11B Vision Instruct模型压缩至3.7 GB（8位激活），并在一系列标准视觉问答任务上保持强劲性能，验证了我们的方法。

## Abstract
Deploying vision-language models (VLMs) on mobile devices is challenging due to their significant memory and compute requirements. We present a framework for quantizing VLMs for efficient inference on resource-constrained hardware. Our approach combines a quantization pipeline that uses the model itself to generate training data and does not require access to the training setup, with a novel 2.7-bit-per-parameter format supporting efficient execution on Arm CPUs. We validate our approach by compressing the Llama 3.2 11B Vision Instruct model to 3.7 GB with 8-bit activations, preserving strong performance on a set of standard visual question answering tasks.

## 1. 核心问题与整体含义

- **研究动机**：视觉语言模型（VLM）在移动设备上的部署面临着严峻的内存与算力瓶颈。Llama 3.2 11B Vision Instruct 等模型以 bfloat16 存储时约需 21.3 GB，远超手机等资源受限设备的承载能力。量化是压缩模型的有效手段，但在多模态场景下，激进的低比特量化（< 3-bit）仍非常困难，且现有方法往往依赖原始训练数据或缺乏对特定硬件（Arm CPU）的效率考量。
- **整体含义**：本文提出了 Llama-Mobile 框架，将 VLM 压缩到每参数 2.7 bit（总大小 3.7 GB），同时以 8-bit 激活保持可接受的推理精度，使得 VLM 在 Arm CPU（包括 Android 手机）上的本地部署成为可能。这项工作突破了"极端量化必然导致严重性能下降"的传统认知，为资源受限设备上的多模态推理提供了实用路径。

## 2. 论文提出的方法论

### 2.1 整体框架
框架包含三个相互衔接的环节：
1. **合成数据生成**：利用被量化的原始模型自身生成训练数据（无需访问原始训练集）。
2. **量化感知训练（QAT）**：以原始全精度模型为教师，低比特模型为学生，在合成多模态数据上进行知识蒸馏。
3. **移动端部署**：在 Arm CPU 上运行量化模型，使用为高效解码设计的 S3D8 格式。

### 2.2 量化感知训练（QAT）
- **蒸馏目标**：设教师模型输出分布为 \(p_T^{(t)}\)，学生模型输出分布为 \(p_S^{(t)}\)，训练目标为最小化教师与学生逐 token 的 KL 散度：
  \[
  \mathcal{L}_{KD} = \frac{1}{|y|} \sum_{t=1}^{|y|} D_{KL}(p_T^{(t)} \| p_S^{(t)})
  \]
- **直通估计器（STE）**：前向传播使用量化参数 \(\hat{\theta}_S = Q(\theta_S)\)，反向传播通过 STE 近似梯度。
- **其他设置**：主权重保持 float32，学习率按比特数缩放 \(\eta = 2^{-(b+14)}\)，使用 AdamW（\(\beta_1=0.9, \beta_2=0.95\)）和余弦学习率调度。

### 2.3 合成数据生成管线（核心创新之一）
- **图像来源**：ImageNet 训练集（128 万张自然图像），与下游评估任务无关，避免过拟合。
- **提示词采样策略**：
  - 以 75% 概率使用指令微调模板，其余使用无模板原始格式；
  - 从 495 个通用图像理解问题组成的池中随机采样；
  - 以 70% 概率附加随机采样的指令块（含长度约束、格式要求、遵循性提示等）；
  - 长度约束偏向短/中等回复，少量长回复。
- **响应生成**：使用教师模型（bfloat16）在 temperature=0.6、top_p=0.9 下采样生成答案，最大 512 token。
- **关键洞察**：固定提示词（如 "Describe the image:"）产生的数据多样性不足，会显著损害下游性能；随机采样提示词可大幅改善 QAT 效果。

### 2.4 S3D8 数值格式（核心创新之二）
- **格式概述**：S3D8（signed 3D 8-bit）将 3 个权重打包在 8 bit 中——共享 1 个 5-bit 质心索引（32 个码字）+ 3 个符号位（每权重 1 bit），平均 2.67 bit/参数（加上通道缩放后约 2.68 bpp）。
- **编码流程**：原权重经通道缩放（absmax）后取绝对值，将 3 元素向量就近映射到 Lloyd-Max 训练的质心（32×3 整数表）。
- **解码公式**：
  \[
  \tilde{W}_{ij} = \alpha_i \cdot s_{ij} \cdot C_{q_{\lfloor i/3 \rfloor, j}, \, i \bmod 3}
  \]
  其中 \(\alpha\) 为逐通道缩放系数，\(s\) 为逐元素符号，\(C\) 为码本，\(q\) 为量化索引。
- **Arm CPU 效率设计**：
  - 每个字节打包 3 个不同输出通道的权重，避免归约轴上的 padding/对齐逻辑；
  - 利用 Arm 的 64 项表查找指令（TBL），将符号位融合进查找索引，直接取出带符号值；
  - 经过精心设计的位布局，仅需 5 条逻辑指令 + 3 次表查找即可解码 48 个元素（见 Listing 1/2）。
- **质心构造**：在 QAT 前用 Lloyd-Max 算法（k-means++ 初始化）对归一化权重一次性拟合；QAT 期间质心冻结，只更新缩放、符号和索引。

## 6. 主要结论与发现

1. **S3D8 格式在相同尺寸下显著优于标量格式**：2.68 bpp 下平均任务成绩 0.661（相对 bfloat16 退化 0.083）；同尺寸的 INT 仅 0.347、student-t 为 0.565、lloyd-max 为 0.436。
2. **QAT 在极低比特下优于 PTQ**：约 2.7 bpp 时，S3D8+GPTQ 仅得 0.340，S3D8+QAT 达 0.661；直接投射在 <3.5 bpp 时严重退化。
3. **格式本身是低比特性能差距的最大来源**：使用相同 GPTQ 流程，S3D8 比 INT 高出约 0.32 的平均分（0.340 vs. 0.018）。
4. **提示词多样性至关重要**：采样提示的 QAT 在各训练步数下均显著优于固定提示。
5. **运行时优势集中在自回归生成阶段**：S3D8 相比于 INT8 在小批量（\(m=1\)）矩阵乘上明显加速（如 Graviton4 上 1031 vs. 461 GMAC/s），但在大批量 prefill 时略慢于 INT8（因反量化开销无法被计算掩盖）。
6. **端到端可行**：Pixel 8a 上实现 3.8 token/s（12.5 GB/s 参数读取带宽），Graviton4 上达 36.8 token/s。

## 7. 优点

- **硬件-算法协同设计**：S3D8 的位布局、表查找融合、输出通道打包等设计均围绕 Arm SIMD 指令集优化，从第一天起就面向实际部署，而非仅追求理论压缩率。
- **不依赖训练数据**：合成数据管线仅需模型自身 + 通用图像集（ImageNet），适用面广；这与现实中大多数开源模型无法获得原始训练数据的场景高度契合。
- **严谨的对比框架**：所有格式在同一 QAT 流程下比较，隔离了格式与训练方法的效应；GPTQ 基线也在全模型（含视觉部分）上运行，对比公平。
- **充足的工程细节**：提供了完整的数据生成超参数、内核实现示例（Listing 1/2）、反汇编验证和基准测试配置，可复现性强。
- **发现了有意思的科学现象**：训练 KL 损失与下游任务性能呈强相关（\(\rho=-0.91\)），为后续 QAT 研究提供了有价值的度量指标。

## 8. 不足与局限

- **单模型验证**：仅对 Llama 3.2 11B Vision Instruct 一个模型评测，框架的通用性缺乏跨模型证据（如 Gemma 3、Qwen3-VL 等）。
- **硬件针对性过强**：S3D8 依赖 Arm 的 64 项 TBL 指令和 i8mm/dotprod 扩展；在 x86、GPU 等主流硬件上需重新设计解码内核。
- **评估面窄**：仅 4 个 VQA 基准，且使用固定 1024 样本子集，缺少对更复杂能力（多图推理、视频理解、开放生成质量、指令遵循稳健性）的评测。
- **未见训练数据规模与耗时**：未报告 QAT 的总训练时长、合成数据生成成本，以及 GPTQ 校准的计算资源，降低了工程复现的可预期性。
- **数据管线仍有改进空间**：ImageNet 自然图像与文档/图表/科学图示差异较大，DocVQA 等任务退化更明显（0.844→0.740），提示图像域多样性可进一步优化。
- **部分层保留高精度未见收益**：输出投影层和视觉编码器保持 INT8 仅提升 0.006 平均分（代价是模型增大 26%），说明当前粒度下的混合精度策略需要更精细的探索。
- **文中未披露某些统计细节**：如各任务 1024 样本子集的采样方式与方差，以及 GPTQ 对 128k 词表输出投影层的具体处理等潜在影响因素。
