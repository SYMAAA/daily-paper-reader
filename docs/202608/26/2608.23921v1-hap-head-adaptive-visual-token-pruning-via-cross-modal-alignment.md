## 摘要
最近的语言-视觉模型将高分辨率图像编码为长序列的视觉标记，导致高昂的预填充成本。为了压缩这些标记，现有方法通过对所有头部均匀平均文本到视觉的注意力来对每个视觉标记进行评分，这假设每个头部都匹配查询。然而，我们的实证分析表明，未对齐的头部主导了平均值，放大了背景标记并淹没了细粒度线索。为了解决这个问题，我们提出了PAQ（提示引导的注意力质量），一个衡量每个头部如何将提示与图像区域对齐的指标。基于PAQ，我们的剪枝分三个阶段进行。给定一个目标FLOPs预算，我们首先将Transformer层划分为组，并为每组分配一个视觉标记预算。在每组内，我们通过PAQ加权的softmax将每头的注意力图聚合成一个组级矩阵。最后，我们根据该矩阵的幅度对视觉标记进行评分，并保留每组的分配预算。通过用PAQ加权头部，我们的方法根据更忠实反映提示相关性的注意力信号对标记进行评分，而不是通过均匀平均来稀释它们。在18个基准测试中，我们的方法实现了最先进的权衡。具体来说，在LLaVA-1.5-7B（9个任务）上，仅保留**5.6%**的标记即可维持**99.1%**的原始性能，超越了最强的基线AutoPrune 4.2个百分点。代码可在https://github.com/baokou-fw2/HAP获取。

## Abstract
Recent Vision-Language Models encode high-resolution images into long visual token sequences, incurring prohibitive prefill costs. To compress them, existing methods score each visual token by averaging text-to-visual attention uniformly across all heads, which assumes every head matches the query. However, our empirical analysis shows that misaligned heads dominate the average, amplifying background tokens and drowning out fine-grained cues.   To address this, we propose PAQ (Prompt-Grounded Attention Quality), a metric quantifying how well each head aligns the prompt with image regions. Built on PAQ, our pruning proceeds in three stages. Given a target FLOPs budget, we first partition the transformer layers into groups and allocate a visual token budget to each. Within each group, we then aggregate per-head attention maps via PAQ-weighted softmax into a group-level matrix. Finally, we score visual tokens by this matrix's magnitude and retain the allocated budget per group. By weighting heads with PAQ, our method scores tokens by attention signals that more faithfully reflect prompt relevance, rather than diluting them through uniform averaging.   Across 18 benchmarks, our method delivers state-of-the-art trade-offs. Specifically, on LLaVA-1.5-7B (9 tasks), retaining only \textbf{5.6\%} tokens preserves \textbf{99.1\%} of the original performance, surpassing the strongest baseline AutoPrune by 4.2 points. Code is available in https://github.com/baokou-fw2/HAP.

## 2. 方法论

### 2.1 核心思想

核心洞察是：不同注意力头对提示的"接地"（grounding）质量存在显著差异，因此不应均匀对待。HAP通过PAQ指标对头部进行加权，让高质量头部主导剪枝信号，低质量头部被自然抑制。

### 2.2 关键技术：PAQ指标

PAQ（Prompt-Grounded Attention Quality）基于**不确定性系数**（Theil's uncertainty coefficient）定义：

\[
PAQ = \frac{I(V; T)}{H(V)}
\]

- \(I(V; T)\)：视觉分布被文本查询驱动的程度（互信息）；
- \(H(V)\)：视觉分布总不确定性（熵）。

PAQ完全从内部注意力统计计算，无需额外参数。其数值范围为[0,1]。

**三种失败模式映射**：
- Sink头：所有文本token关注同一视觉token集 → 条件概率与文本token无关 → \(I(V;T)=0\) → PAQ≈0；
- Dispersed头：所有文本token均匀分布于所有视觉token → 同样导致 \(I(V;T)=0\) → PAQ≈0；
- Optimal头：注意力随文本token变化而集中 → \(I(V;T)>0\) → 高PAQ。

### 2.3 HAP框架流程

HAP分为三个阶段：

1. **预算分配**：将\(L\)层Transformer划分为\(M\)个连续组，每组\(L/M\)层。目标预算采用几何金字塔结构：第\(g\)组的预算为 \(N_v^{(g)} = V / (1+g)^2\)。组数\(M\)由目标FLOPs预算通过闭式函数直接推导，无需逐任务调参。

2. **PAQ引导的两级聚合**：
   - **层内头聚合**：对每层\(l\)的\(H\)个注意力头，以PAQ分数经中心化（减去均值）后做softmax，得到权重\(w_c\)，加权融合产生层注意力图 \(A^{(l)}_{agg}\)；
   - **组内层聚合**：将同一组内的各层注意力图作为新候选集，再次施用PAQ-softmax，融合得到组级注意力矩阵 \(A^{(g)}_{group}\)。

3. **标记评分与剪枝**：对每个视觉token，在组级注意力矩阵上对文本位置取平均，得到重要性分数 \(s^{(g)}_i\)，按分数排序并保留预算数量的token。

### 2.4 效率与兼容性

- 剪枝后FLOPs有闭式表达式：\(F_{pruned}(m) \approx \frac{L}{m}\left[A(1-\frac{1}{1+m}) + \frac{B}{3}(1-\frac{1}{(1+m)^3})\right]\)；
- PAQ计算开销为\(O(HN_t V L/m)\)，远小于完整前向传播成本；
- 兼容FlashAttention：通过"双闪存"策略扩展，在SRAM中累积块级统计，避免物化完整\(N^2\)注意力矩阵，额外内存开销仅需每层\(L \times C\)个标量；
- 实测PAQ计算开销不足2%的墙钟时间。

## 7. 优点

1. **问题发现敏锐**：通过直观的可视化（图1）和量化实验（图2）清晰揭示了"头部异质性"这一被忽视的关键问题；

## 8. 不足与局限

1. **预填充阶段剪枝的边界**：HAP在预填充阶段操作，解码阶段的视觉KV缓存保持不变。虽然附录I表明FLOPs节省在约10⁵ token解码长度内仍为正值，但对于超长输出场景，加速收益会逐渐趋平；
2. **PAQ是注意力代理指标**：PAQ基于跨模态注意力统计，依赖成对文本查询的存在。虽然提供了相关性证据，但缺乏完全因果性的验证（如反事实token干预）；
3. **未处理纯视觉压缩场景**：当前框架假设存在文本提示，对无文本/单模态场景的头部自适应剪枝不适用；
4. **评估范围局限**：仅覆盖静态图像和短视频基准，未涉及流式输入或超长多模态上下文中的头部对齐模式；
5. **硬件环境单一**：所有实验仅在RTX 3090上运行（虽对比了不同批次大小），未在更广泛硬件平台（如A100/H100）验证可扩展性；
6. **训练时间未报告**：虽然方法本身训练免费，但评估500+小时的推理时间未明确报告，对于复现可能不够透明；
