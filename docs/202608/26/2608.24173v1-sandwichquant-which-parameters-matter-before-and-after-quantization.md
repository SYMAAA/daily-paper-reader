## 摘要
量化校正方法通常优化权重、量化参数或重建目标，而负责有效校正的底层参数子空间仍不明确。在本工作中，我们从参数子空间的角度研究量化校正，并揭示校正能力在不同参数组之间高度不均匀。通过将可训练参数分解为主干权重、归一化仿射参数和量化参数，我们表明在匹配的预算下，低维归一化仿射子空间提供了高效校正方向。基于这一发现，我们提出了SandwichQuant，一种两阶段归一化仿射校正框架，在量化前后分别进行适配。前期阶段提高量化鲁棒性，而后期阶段在量化图固定后补偿残余误差。在视觉模型和大语言模型上的大量实验表明，在各种低比特量化设置下均能实现一致的改进，验证了子空间对齐校正的有效性。

## Abstract
Quantization correction methods usually optimize weights, quantization parameters, or reconstruction objectives, while the underlying parameter subspaces responsible for effective correction remain unclear. In this work, we study quantization correction from a parameter subspace perspective and reveal that correction capability is highly non-uniform across parameter groups. By decomposing trainable parameters into backbone weights, normalization-affine parameters, and quantization parameters, we show that the low-dimensional normalization-affine subspace provides a highly efficient correction direction under matched budgets. Based on this finding, we propose SandwichQuant, a two-stage normalization-affine correction framework that performs adaptation before and after quantization. The pre-stage improves quantization robustness, while the post-stage compensates residual errors after the quantized graph is fixed. Extensive experiments on vision models and large language models demonstrate consistent improvements under various low-bit quantization settings, validating the effectiveness of subspace-aligned correction.

## 1. 论文的核心问题与整体含义（研究动机和背景）

量化感知训练（QAT）在大模型上训练成本过高，因此后训练量化（PTQ）成为主流部署范式。然而，在极低比特（如 W2A4KV4 联合量化）下精度下降依然严重。现有 PTQ 方法通常致力于设计更好的舍入策略、量化网格、变换矩阵或权重补偿规则，但论文指出，一个被忽视的问题是：**量化校正的有效性本质上取决于底层参数子空间的结构**。

论文将可训练状态分解为 `Θ = (W, Φ, Ω)`，其中 W 为主干权重，Φ 为归一化仿射参数，Ω 为量化器参数。作者从参数子空间角度提出核心问题：**哪些参数子空间对量化校正真正起决定性作用？它们应在 PTQ 之前、之后，还是两侧同时起作用？** 通过匹配预算的受控实验，论文发现校正能力在不同参数组之间高度非均匀——极低维的归一化仿射子空间（Φ）具有异常高的校正杠杆，由此引出 SandwichQuant 两阶段仿射校正框架。

## 2. 论文提出的方法论

- **核心思想**：利用归一化仿射参数（BN 的 γ/β 或 RMSNorm 的 γ）作为高效校正方向。这类参数虽然数量极少，但每个参数通过通道广播机制影响所有 token/空间位置，从而重塑大量下游层的响应轨迹。仿射适配可以修复结构化响应失配与错误传播，但无法重建被严重裁剪或舍入所破坏的信息。
- **两阶段框架**：
  - **Pre-stage（Φpre）**：在 PTQ 之前适配仿射参数，改变输入给量化器的响应分布，提高量化鲁棒性；随后将仿射状态转移到原始稠密 checkpoint 并从头重跑 PTQ 后端。
  - **Post-stage（Φpost）**：在 PTQ 图固定后，冻结所有权重与量化器变量，仅更新仿射参数，补偿残余响应误差。
  - 完整流程为：`Φpre → PTQ_B → Φpost`，两个阶段共享同一组归一化仿射坐标，但作用时间不同、优化器独立。
- **优化目标**：
  `L_SQ = L_task(z_q, y) + λ_KD · T² · KL(p_T(z_0) ∥ p_T(z_q))`
  即任务损失（交叉熵）+ 预测级知识蒸馏，教师为原始稠密模型，学生为伪量化模型，两者在相同目标图上优化。
- **关键公式**：仿射更新对响应的影响为 `Δa_{l,c} = h_{l,c}·Δγ_{l,c} + Δβ_{l,c}`（RMSNorm 无 β），说明一两个标量即可改变整个通道在所有 token 上的输出；局部误差分解 `e_z = e_∥ + e_⊥` 将可校正残差与不可恢复残差分离。
- **算法流程**（Algorithm 1）：保存稠密快照 → 构建一次性 PTQ 探针图 G1 → 仅对 Φ 求梯度优化得到 Φpre → 丢弃 G1、恢复稠密状态 → 仅转移仿射张量 → 从头重建 PTQ 图 G2 → 冻结 G2 后优化 Φpost → 部署。整个流程不增加任何推理分支或新算子——BN 的仿射因子可折入相邻卷积，RMSNorm 缩放因子本就是原生模型参数。

## 6. 论文的主要结论与发现

- **校正能力高度非均匀**：在相同参数预算下，归一化仿射子空间 Φ 的校正效果显著优于等规模随机权重、注意力权重、MLP 权重甚至梯度选择的权重子空间（Φ 在 Qwen3-8B W2A4KV4 上联合困惑度-准确率 Pareto 最优）。
- **Φ 的杠杆来自广播结构与响应控制**：一个仿射标量改变整个通道在所有 token 上的输出，可通过传播修正下游大量层级的结构化响应失配；但无法恢复被裁剪/舍入不可逆破坏的信息。
- **量化前后两阶段具有互补性**：Post 校正更稳定，Pre 预条件化通过改变量化器输入间接改变最终解；完整两阶段组成在 W2A4KV4 联合量化下收益最大（如 Qwen3-8B 上 Wiki2 PPL 从 18.71 降至 12.03，Avg6 从 49.62% 提升至 58.05%）。
- **跨领域可迁移性**：从视觉 CNN 到 LLM，从 W4A4 到 W3A16 到 W2A4KV4，从 RTN 到经补偿的 GPTAQ/ResComp，SandwichQuant 均带来一致提升，且不增加部署期推理算子。

## 8. 不足与局限

- **模型规模覆盖有限**：实验仅涉及 7B–8B 稠密 Transformer LLM，**未覆盖更大规模（如 70B+）、MoE 架构或开源小模型以外的部署场景**，结论的外推性有待验证。
- **种子与确定性**：所有实验使用固定单一随机种子（seed 0），未报告多种子方差，统计可靠性未知。
- **数据效率问题**：表 8 表明在 ImageNet 上当前实现的仿射适配高度依赖调优数据覆盖（使用 5K/10K 图像几乎无法恢复坍缩模型，需全量训练数据 66.11% vs 2.98%/3.88%），因此**并非校准级 few-shot 方法**，与常规小样本 PTQ 的定位不同。
- **后端/比特/校准特定性**：仿射状态无法跨后端、跨位宽或跨校准集迁移（匹配失配图时掉 17.39 个点），离线需要两次 PTQ + 两次仿射优化，额外训练成本不可忽视。
- **恢复能力根本受限**：严重裁剪或舍入造成的不可逆信息损失无法通过仿射子空间恢复，这是方法的内在天花板。
- **计算资源信息不足**：未报告 GPU 型号/总训练时数/算力规模，仅以 MetaX C500/C600-A 单卡运行时长示例，外部复现的成本估计不便。
