## 摘要
尽管视觉大语言模型（VLLMs）在多模态推理方面取得了显著成功，但其长上下文推理由于视觉键值（KV）缓存带来的巨大计算和内存开销而仍然代价高昂。现有的KV压缩方法通常对视觉token和层进行均匀剪枝，导致大量信息丢失和性能下降。为应对这一挑战，我们提出了**VisCache**，一个即插即用的框架，用于无训练的从粗到细的**Vis**ual KV **Cache**剪枝，包含两个协同阶段。首先，一个轻量级VLM通过选择性转发语义上有信息量的关键帧来过滤时间冗余。其次，我们引入了{PruneKV}，一种针对VLLM注意力动态量身定制的外科手术式KV压缩算法。与刚性剪枝策略不同，PruneKV采用抛物线式的逐层预算分配，结合非对称更新机制，选择性剪枝键的同时融合值，从而保留关键上下文信息。大量实验表明，VisCache显著提高了推理效率，实现了高达{2.35×加速}和显著的内存减少，同时仅靠{19–28%}的KV缓存保留率即可保持有竞争力的性能。VisCache始终优于现有基线，为长上下文VLLM推理建立了效率与性能之间的新帕累托前沿。代码可在 https://github.com/Wlklk/VisCache 获取。

## Abstract
While Vision Large Language Models (VLLMs) have achieved remarkable success in multimodal reasoning, their long-context inference remains prohibitively expensive due to the massive computation and memory overhead of visual Key-Value (KV) caches. Existing KV compression methods often apply uniform pruning across visual tokens and layers, leading to substantial information loss and degraded performance.To address this challenge, we propose \textbf{VisCache}, a plug-and-play framework for coarse-to-fine \textbf{Vis}ual KV \textbf{Cache} pruning without training, which consists of two synergistic stages. First, a lightweight VLM filters temporal redundancy by selectively forwarding semantically informative keyframes. Second, we introduce {PruneKV}, a surgical KV compression algorithm tailored to the attention dynamics of VLLMs. Unlike rigid pruning strategies, PruneKV adopts a parabolic layer-wise budget allocation together with an asymmetric update mechanism that selectively prunes keys while fusing values, thereby preserving critical contextual information. Extensive experiments demonstrate that VisCache substantially improves inference efficiency, achieving up to {2.35$\times$ speedup} and significant memory reduction while maintaining competitive performance with only {19--28\%} KV cache retention. VisCache consistently outperforms existing baselines, establishing a new Pareto frontier between efficiency and performance for long-context VLLM inference. Code is available at https://github.com/Wlklk/VisCache

### 1. 核心问题与整体含义

- **研究背景**：视觉大语言模型（VLLMs）在多模态推理（如长视频理解、视觉问答）中取得了显著成功，但其长上下文推理面临两大瓶颈：
  - **内存瓶颈**：长视频产生大量视觉 token，导致 KV 缓存急剧膨胀，占据 GPU 内存并加剧内存带宽竞争。
  - **计算瓶颈**：注意力计算随序列长度呈二次增长，显著放大推理延迟。
- **现有方法的缺陷**：当前 KV 压缩方法（如量化、低秩分解、均匀 token 剪枝）大多在视觉 token 和层上采取**均匀或粗粒度剪枝**策略，忽略了视觉信息的三重结构化冗余：
  - 时间层面：只有部分视频帧与当前查询相关；
  - 层间层面：不同 transformer 层对视觉 token 的重要性不均；
  - 键值层面：key 和 value 在注意力计算中扮演的功能角色不对称。
- **核心问题**：如何在极端压缩率下（仅保留 19–28% KV 缓存），既大幅提升推理效率，又保持甚至超越原有推理性能？

### 2. 方法论

VisCache 是一个**无训练、即插即用**的"从粗到细"（coarse-to-fine）双阶段视觉 KV 缓存剪枝框架。

#### 阶段一：提示感知关键帧过滤（Prompt-Aware Scout）

- 使用轻量级视觉-语言模型（如 CLIP）作为 "scout"。
- 将视频帧和文本提示映射到共享嵌入空间，计算 MMR（最大边际相关）分数：

$$MMR(f) = \lambda \cdot \text{sim}(h_f, h_t) - (1-\lambda) \cdot \max_{f' \in \Omega} \text{sim}(h_f, h_{f'})$$

- MMR 同时兼顾**与提示的相关性**和**帧间多样性**，迭代选出紧凑且语义覆盖完整的关键帧集合 Ω。

#### 阶段二：PruneKV——层感知视觉 KV 压缩算法

**（1）Token 重要性评分**

- 利用预填充阶段各层的注意力权重，聚合每个视觉 token 接收到的注意力作为重要性分数：

$$s_v = \frac{1}{L}\sum_{l=1}^{L}\sum_{i=1}^{N} A^l_{i,v}$$

**（2）抛物线式分层预算分配（Parabolic Budget Allocation）**

- 设定截断层阈值 h（默认 h = 3L/4），对 h 层以上的视觉 KV 条目**完全丢弃**；
- 对剩余层按抛物线衰减公式分配保留预算：

$$b_l = 1 - \frac{(l-1)^2}{2(h-1)^2}$$

- 预算从浅层到深层**逐渐递减**（b₁=1, b_h=0.5），浅层保留更多细粒度空间细节，深层因语义抽象而可容忍更强压缩。

**（3）非对称键值更新（Asymmetric Key-Value Update）**

- 核心洞察：key 决定注意力分布（相关性选择器），value 承载实际语义内容（信息载体）。
- **键剪枝**：对低重要性 token 的 key 向量直接丢弃。
- **值融合**：低重要性 token 的 value 不丢弃，而是通过相似度加权聚合到保留 token 上：

$$\Phi = \text{Softmax}\left(\frac{V_k V_d^\top}{\tau}\right)$$

$$V_k^{new} = \mu V_k + (1-\mu)(\Phi V_d)$$

- μ=0.7 为默认融合强度，τ 为温度参数。

### 6. 主要结论与发现

- **效率显著提升**：VisCache 仅保留 19–28% 的 KV 缓存，即可实现最高 **2.35× 推理加速**，FLOPs 降至全缓存的 6–15%。
- **性能保持甚至超越**：在 3B 模型上，28% 保留率下的平均准确率（45.64%）**超过全缓存**（44.16%）和所有基线；32B 模型上同样以 56.86% 的平均准确率超越全缓存（57.46% 之外的所有方法）。
- **模块协同有效**：Scout 过滤时间冗余 + PruneKV 压缩 KV 结构冗余，两者互补，且优势在更极端压缩下更显著。
- **抛物线预算优于其他分配策略**：相比算术、几何、固定分配，抛物线分配在保持一致保留率时性能最佳。
- **非对称键值更新有效**：剪键融合值比简单的键值同剪更能保留上下文信息。
- **任务依赖的最优保留率**：不同任务对保留率的敏感度不同（DREAM1K 在更高保留率下持续增益，EgoSchema 约 70% 达到最优），选择合适压缩率甚至可以超越全缓存性能。

### 7. 优点

- **无需训练、即插即用**：可直接应用于现有 VLLM，无需微调或重训练。
- **两阶段协同设计**：在输入层（帧级）和模型内部（KV 级）同时消除冗余，粗粒度过滤 + 细粒度剪枝形成互补。
- **深度洞察注意力动态**：关注层间异构性、key-value 功能不对称性，超越了以往均匀剪枝或简单金字塔衰减的粗放做法。
- **抛物线预算分配直观有效**：数学形式简洁，符合视觉信息随深度由具体到抽象的认知规律，且优于算术/几何方案。
- **实验规模大、维度广**：涵盖了多模型规模、多基准、多压缩率、多消融维度，验证充分。
- **跨架构兼容性好**：在 Qwen2.5-VL、Qwen3-VL、LLaVA-OneVision 以及量化组合下均能保持竞争力。
- **实际推理加速验证**：不仅报告 FLOPs 的理论降低，还测量了真实系统的 E2E 延迟、TTFT、TPOT 和显存占用。

### 8. 不足与局限

- **Scout 与主模型的对齐问题**：轻量级 scout（如 CLIP）的视觉表征可能与主 VLLM 骨干的偏好不一致，导致所选关键帧并非下游模型最优；论文本身也承认这一局限。
- **注意力分数存储开销**：PruneKV 需要在预填充阶段保存所有层的注意力分数用于 token 排序，引入了额外的内存开销（尽管论文认为后续可优化）。
- **scout 模型引入额外延迟**：关键帧选择阶段本身需要运行一次轻量 VLM，虽然已包含在 E2E 延迟测量中，但极端低延迟场景下仍构成额外开销。
- **几何分配在特定任务上表现不佳**：在部分 MVBench 子任务上，PDrop（几何分配）仍能在某些任务（如 UA）上取得领先，表明没有任何一种分配策略在所有任务上最优，VisCache 的抛物线策略也存在任务偏置。
- **实验基准的局限性**：主要集中在视频理解任务上，未涵盖图像-文本多图交互、多模态 Agent 等更广泛的 VLLM 应用场景。
- **未分析偏差传播风险**：论文在影响声明中提到压缩过程可能传播基础模型中的偏差，但未提供相关测试或缓解措施。
