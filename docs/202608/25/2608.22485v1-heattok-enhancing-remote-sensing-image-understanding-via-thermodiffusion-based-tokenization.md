## 摘要
当前多模态大语言模型（MLLMs）中的视觉分词器主要依赖基于图像块的分割方法，这导致遥感图像中由于地理对象的不规则轮廓而产生严重的语义混合和对象碎片化。此外，现有的自适应方法难以提取精确的对象级分词，并且缺乏针对不规则区域的专用几何位置编码。在本文中，我们提出了HeatTok，一种由热扩散聚合驱动的语义感知分词器。受热传导物理原理的启发，HeatTok自适应地合并相邻的均匀区域，以生成语义独立、对象对齐的不规则分词。为了使MLLMs能够感知这些不规则形状，我们设计了高斯多模态旋转位置编码（G-MRoPE），通过二维高斯分布对分词空间分布进行建模，并显式注入中心、尺度和方向线索。在VRSBench和EarthVQA数据集上的大量评估表明，HeatTok有效保留了对象级语义完整性，并在合理的分词预算下实现了最先进的性能。代码可在 https://github.com/YingyingYan1/HeatTok 获取。

## Abstract
Current visual tokenizers in Multimodal Large Language Models (MLLMs) predominantly rely on patch-based partitioning, which causes severe semantic mixture and object fragmentation in remote sensing imagery due to the irregular contours of geo-objects. Moreover, existing adaptive methods struggle to extract precise object-level tokens and lack dedicated geometric positional encodings for irregular regions. In this paper, we propose HeatTok, a semantic-aware tokenizer driven by thermodiffusion aggregation. Inspired by the physical principles of heat conduction, HeatTok adaptively merges adjacent homogeneous regions to generate semantically independent, object-aligned irregular tokens. To enable MLLMs to perceive these irregular shapes, we design the Gaussian Multimodal Rotary Positional Embedding (G-MRoPE), which models token spatial distributions via 2D Gaussians and explicitly injects center, scale, and orientation cues. Extensive evaluations on the VRSBench and EarthVQA datasets demonstrate that HeatTok effectively preserves object-level semantic integrity and achieves state-of-the-art performance under a reasonable token budget. The code is available: https://github.com/YingyingYan1/HeatTok.

## 一、核心问题与整体含义（研究动机与背景）

- **核心痛点**：当前多模态大语言模型（MLLMs）的视觉分词器大量依赖基于图像块（patch）的均匀切分方式。对于遥感图像，地理目标（建筑物、水体、农田等）往往具有不规则轮廓，均匀切分会导致：
  - **语义混合**：一个 patch 内混杂多种地物类别；
  - **对象碎片化**：一个完整地理对象被拆散到多个 patch 中。
- **既有方法不足**：已有自适应分词方法虽然试图缓解 patch 切分的问题，但仍存在两个关键缺陷——难以提取精确的对象级分词，以及缺乏针对不规则区域的专项几何位置编码。

## 二、方法论

### 2.1 核心思想：热扩散聚合（Thermodiffusion Aggregation）

- **物理启发**：借鉴热传导（heat conduction）的物理原理，将图像像素/特征视为热场，温度梯度驱动相邻同质区域自动融合，直到边界达到稳定。
- **聚合策略**：HeatTok 自适应地合并相邻的均匀（homogeneous）区域，生成**语义独立、对象对齐的不规则分词**（irregular tokens），而非固定网格 patch。
- **关键优势**：每个 token 对应一个语义完整的对象或对象片段，从根本上避免语义混合与对象碎片化。

### 2.2 G-MRoPE：高斯多模态旋转位置编码

- **动机**：不规则 token 无法像矩形 patch 那样用行列坐标直接编码位置，MLLM 需要知晓每个 token 在图像中的空间分布。
- **技术方案**：
  - 用**二维高斯分布**建模每个不规则 token 的空间分布特性；
  - 从高斯模型中显式提取三类几何线索——**中心位置（center）、尺度（scale）、方向（orientation）**；
  - 将这些线索注入到多模态旋转位置编码（RoPE）框架中，使 LLM 能感知不规则 token 的几何形态。
- **意义**：G-MRoPE 让 LLM 不仅知道“哪里有什么”，还理解“这个对象多大、以什么角度分布”，增强空间推理能力。

### 2.3 整体流程（文字描述）

1. 输入遥感图像，提取视觉特征；
2. 通过热扩散聚合迭代合并相邻同质区域，生成对象级不规则分词；
3. 对每个不规则分词计算其二维高斯分布参数（中心、尺度、方向）；
4. 使用 G-MRoPE 将几何信息注入位置编码；
5. 将语义 token 与几何增强后的位置编码一同送入 LLM，完成视觉-语言对齐与推理。
