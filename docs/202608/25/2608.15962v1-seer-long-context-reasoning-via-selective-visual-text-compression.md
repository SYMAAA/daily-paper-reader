## 摘要
长上下文推理对于大型语言模型来说计算成本仍然很高，因为注意力机制在文本标记上的复杂度是二次方的。视觉-文本压缩提供了一种有前景的替代方案，通过将文本渲染为图像并使用视觉-语言模型进行处理，通常可以减少标记的使用。然而，现有方法无论查询相关性如何都采用统一压缩，可能在需要详细提取的地方牺牲精度。我们提出了SEER，一个通过视觉扫描学习选择与查询相关的图像，并仅在需要时检索文本内容的框架，将视觉压缩的效率与基于文本的推理的精度相结合。通过在工具交互轨迹上进行监督微调，SEER学会了自适应调用工具进行选择和检索。在长上下文基准测试上的实验表明，SEER通过选择性文本检索提高了提取精度，同时相对于全文基线保持了平均提示标记节省。在LongBench上，SEER实现了51.11%的平均准确率，比视觉-文本基线Glyph-9B高出2.33个百分点，比Qwen3-8B高出3.49个百分点。代码可在https://github.com/jiaweixu98/SEER获取。

## Abstract
Long-context reasoning remains computationally expensive for large language models due to the quadratic complexity of attention over text tokens. Visual-text compression offers a promising alternative by rendering text into images and processing them with vision-language models, often reducing token usage. However, existing approaches apply uniform compression regardless of query relevance, potentially sacrificing precision where detailed extraction is required. We present SEER, a framework that learns to select query-relevant images through visual scanning and retrieve textual content only where needed, combining the efficiency of visual compression with the precision of text-based reasoning. Through supervised fine-tuning on tool-interaction trajectories, SEER learns adaptive tool invocation for selection and retrieval. Experiments on long-context benchmarks show that SEER improves extraction precision through selective text retrieval while retaining average prompt-token savings relative to full-text baselines. On LongBench, SEER achieves 51.11% average accuracy, outperforming the visual-text baseline Glyph-9B by 2.33 points and Qwen3-8B by 3.49 points. Code can be accessed at https://github.com/jiaweixu98/SEER

## SEER：通过选择性视觉-文本压缩实现长上下文推理 — 论文总结

### 1. 论文的核心问题与整体含义（研究动机与背景）

- **问题背景**：长上下文推理对于大语言模型（LLM）计算成本高昂，其核心瓶颈在于自注意力机制对文本 token 具有二次方的计算复杂度。
- **已有探索**：业界提出了多种缓解方案，如扩展位置编码（YaRN）、稀疏/线性注意力等；近期出现的**视觉-文本压缩（Visual-Text Compression）**范式（如 Glyph、Vist、DeepSeek-OCR）通过将文本渲染成图像，并交由视觉-语言模型（VLM）处理，利用视觉编码器对密集文本信息的紧凑表达能力来压缩 token 数量（通常可压缩 3–4 倍），并显著加速 prefill。
- **现有方法的局限**：已有视觉文本压缩方法对全部上下文采用**统一压缩策略**，不考虑查询相关性。这种“一刀切”的做法带来难以调和的权衡：**压缩率过高则丢失精确推理所需的细节，压缩率过低则丧失效率优势**。
- **核心研究问题**：能否将视觉压缩的高效率与文本推理的高精度结合起来，使模型能够根据具体查询**按需**决定哪些区域需要精确的文本信息？
- **整体含义**：SEER 提出一种“选择-检索-推理”的框架，将视觉全局扫描与局部文本精确检索相结合，在保持 token 节省的同时显著提升提取密集型任务的精度，为长上下文推理提供了一种“效率与精度平衡”的新思路。

### 2. 论文提出的方法论

#### 2.1 核心思想

- **互补性洞察**：视觉表示支持快速全局信息访问（类比人类浏览文档时快速定位相关章节），而文本表示支持局部精确推理；SEER 通过工具调用机制将二者结合。
- **总体框架**：遵循 **Select-Retrieve-Reason（选择-检索-推理）** 三阶段流程，并将整个流程建模为 ReAct 风格的 Thought-Action-Observation 工具交互轨迹。

#### 2.2 三阶段推理流程

1. **Stage 1：视觉选择（Visual Selection）**
   - 将文本上下文 C 渲染为图像序列 I = Render(C)，模型 f 根据查询 q 输出相关图像索引集合 S ⊆ {1, ..., m}，即 S = f(I, q)。
   - 实施时对模型输出的索引进行规范化处理（去重、丢弃越界索引）。
2. **Stage 2：文本检索（Text Retrieval）**
   - 对选中的图像，从渲染过程中保留的源文本进行确定性查找：yR = Retrieve(yS)。
   - 作者明确选择确定性检索而非训练 OCR 组件，理由是：任务聚焦于学习“何时需要精确文本”，且数字文档场景下源文本通常可用，同时模块化设计允许未来兼容 OCR 系统。
3. **Stage 3：推理（Reasoning）**
   - 模型在保留全部视觉上下文（全局信息）的基础上，结合检索到的文本（局部精确信息）生成推理链和最终答案：y = f(I, q, yS, yR, yCoT)。

#### 2.3 训练策略

- **数据构造**：使用 Qwen3.5-9B 对每个渲染页面进行相关性标注（利用查询、参考答案和页面文本判断页面是否为回答查询所必需）；使用 Qwen3-32B 生成推理链和答案，仅保留预测答案与参考答案匹配的样本；最终从 7 个数据集构建了 10,041 个训练轨迹样本。
- **监督微调（SFT）**：从 Glyph-9B 初始化，在完整 Select-Retrieve-Reason 轨迹上训练；使用**加权 token 级 SFT 损失**（公式见论文 Eq.7），对模型生成的 token（工具调用、推理、答案）赋予正权重，对系统提供的观察 token 掩码为 0，并对工具调用和格式标记 token 额外上加权。

### 6. 论文的主要结论与发现

- **精度显著提升**：SEER 在 LongBench 上达到 **51.11%** 平均准确率，比 Glyph-9B 高 **2.33** 个百分点，比 Qwen3-8B 高 **3.49** 个百分点；提升集中在提取密集型任务上（Qasper +8.75，MultiFieldQA-Zh +19.17，HotpotQA +3.80）。
- **选择性检索是增益的主要来源**：消融显示 w/o Retrieve 为 43.00（Δ=−8.11），w/o mechanism 为 45.20（Δ=−5.91）；iso-training control 排除了“单纯微调数据”的解释。
- **选择行为稀疏且饱和**：平均每查询选择 1.59 页（中位数 1），选择数量不随上下文长度线性增长，而是稳定在 3 页以内——这既是效率优势的来源，也构成分布式证据场景下的召回上限。
- **少量检索即可恢复大部分增益**：在中间检索预算 k=1 时即可恢复 k=0→all 端点差距的 61.5%。
- **Token 节省是平均意义上的**：SEER 平均 prompt 压缩率为 1.28×（介于全文与纯视觉压缩之间），但 21 个任务中有 7 个任务的 prompt 反而大于全文基线。
- **效率声明需要限定范围**：token 节省体现在 prompt 和 KV-cache 占用上，而非单请求延迟；批大小为 1 时 SEER 中位端到端延迟为 5.47s（因显式推理轨迹），高于全文推理的 1.07s。

### 7. 优点

- **方法新颖且优雅**：将“视觉全局扫描 + 文本局部精读”的互补思想形式化为可训练的工具调用轨迹，是视觉文本压缩方向上的一个有意义创新。
- **实验严谨性突出**：通过 iso-training control 分离了“机制效果”与“数据效果”；通过内在页面选择评估与端到端选择器对比两个层面验证了选择器的有效性；坚持同家族、同基线的受控对比原则。
- **分析深入全面**：对选择行为分布、检索预算敏感性、任务异质性、token 压缩与真实延迟的差异、prefill 扩展性等均有详细分析，不回避负面结果（如延迟劣势、BM25 在某些子集更强）。
- **工程细节完整**：附录提供了完整的特殊 token 定义、轨迹示例、逐任务 token 明细、训练超参数、数据流水线各阶段保留量等，可复现性强。
- **局限性叙述坦诚**：对选择器健壮性、效率声明的适用范围、分布式证据的弱点、数据偏差风险均有明确说明。

### 8. 不足与局限

- **选择器健壮性不足**：模型偶尔输出越界页面索引（被直接丢弃而非修正），在实际系统中可能直接导致检索失败。
- **效率声明有范围限制**：平均 token 节省不保证每任务都节省（7/21 任务 prompt 更大）；在 LongBench 规模的批大小为 1 场景下没有延迟优势（甚至明显更慢），效率收益主要体现在 prompt/KV-cache 占用和更长上下文的可处理性上。
- **适用场景有限**：精度提升局限于“证据集中在少数页面”的问题；证据分布在 3 页以上时，单轮选择的召回率受限（选择器决策饱和）。论文没有评估自然图像、图表或 OCR 基准，仅适用于渲染后的长文档问答。
- **训练数据存在偏差风险**：教师模型（Qwen3-32B）质量过滤倾向于保留对教师来说更容易的样本，可能使训练分布偏向简单区域；分布式证据场景在训练数据中代表性不足。
- **跨家族对比不完全公平**：SEER 在自建轨迹上做了任务特定微

调训练，而 LLaMA-3.1-8B、Qwen3-8B 等文本基线并未在相同任务数据上微调，因此部分精度差距可能部分来自监督微调本身而非 SEER 机制本身。虽然 iso-training control 在一定程度上排除了“数据 / 微调”的混杂解释，但跨模型家族的对比仍不易完全对齐训练数据、模板与解码设置，结论需谨慎解读。

### 9. 总体评价与展望

- **总体定位**：SEER 是一项“效率—精度”权衡视角下的务实创新。它并不试图在单一模态内同时获得两种优势，而是通过显式的工具调用将视觉的全局扫描能力与文本的局部精确检索能力组合起来，本质上是让模型自主决定“何时看概要、何时读原文”，在方法论上具有较高的可迁移性。
- **贡献层次**：论文的贡献不仅在于提出新框架，更在于提供了一整套严谨的评估范式——包括 iso-training control、内在/端到端双重选择器评估、逐任务 token 明细与延迟测量，为后续视觉文本压缩研究树立了可参照的实验标准。
- **待解决问题**：当前框架仍然受限于渲染后纯文本长文档场景，尚未覆盖图像表格、扫描 PDF 或自然图像理解；选择器的单轮决策机制在分布式证据场景下存在召回瓶颈；token 节省与延迟之间的张力也需要在更大 batch、更长上下文（如 100K+）的部署场景中进一步验证。
- **未来方向**：论文末尾提及将 SEER 扩展至多轮选择、端到端强化学习训练，以及将确定性检索替换为可训练的 OCR 组件，这些方向若能实现，有望进一步统一视觉压缩与文本推理的边界，推动长上下文多模态推理走向更实用的形态。
