## 摘要
结构化剪枝通过移除权重列来减小大型语言模型（LLM）的规模和推理成本，但由此产生的输出误差会降低准确率。现有的免训练补偿方法使用加性偏置或在保留权重的输出侧进行单一正交旋转。这些修正保持其输入奇异框架不变，因此限制了保留权重在列移除后的适应能力。我们提出COEC（校准正交等价补偿），一种免训练补偿框架，对保留权重交替应用左右正交旋转。右旋转在约化的Stiefel流形上进行优化，同时使用广义交叉验证重新缩放奇异值，以选择每层的正则化强度。COEC进一步缓和校准Gram矩阵以降低高能量激活方向的主导性，并引入对齐惩罚以保持相邻注意力投影之间的几何关系。所有组件使用来自小型校准集的二阶统计量，既不需要通过LLM进行反向传播，也不需要重新训练模型参数。COEC独立于列剪枝准则，可应用于多种结构化剪枝方法。在Llama-3、Llama-3.1和Qwen2.5模型家族上、跨多个结构化稀疏度水平的实验表明，与现有补偿方法相比，COEC在每个模型上都改善了困惑度，并在大多数设置下提高了零样本准确率，在更高稀疏度下收益更大。这些结果表明，剪枝后补偿可以恢复因列移除而损失的部分性能。

## Abstract
Structured pruning reduces the size and inference cost of large language models (LLMs) by removing weight columns, but the resulting output error can degrade accuracy. Existing training-free compensation methods use an additive bias or a single orthogonal rotation on the output side of the retained weight. These corrections leave its input singular frame unchanged and therefore limit how the retained weight can adapt after column removal. We propose COEC (Calibrated Orthogonal-Equivalence Compensation), a training-free compensation framework that applies alternating left and right orthogonal rotations to the retained weight. The right rotation is optimized on a reduced Stiefel manifold, while singular values are rescaled using generalized cross-validation to select the regularization strength for each layer. COEC further tempers the calibration Gram matrix to reduce the dominance of high-energy activation directions and introduces an alignment penalty that preserves the geometric relation between adjacent attention projections.All components use second-order statistics from a small calibration set and require neither backpropagation through the LLM nor retraining of the model parameters. COEC is independent of the column pruning criterion and can be applied to multiple structured pruning methods. Experiments on the Llama-3, Llama-3.1, and Qwen2.5 model families across multiple structured sparsity levels show that COEC improves perplexity on every model and zero-shot accuracy in most settings over existing compensation methods, with larger gains at higher sparsity. These results show that post-pruning compensation can recover part of the performance lost to column removal.

- **研究背景**：大语言模型（LLM）推理成本高昂，结构化剪枝通过移除整列权重（MLP神经元、注意力KV组）直接获得更小的稠密模型，节省参数、内存与计算开销。但因LLM规模庞大，重训练成本过高，因此免训练的剪枝后补偿机制极具吸引力。
- **核心问题**：结构化剪枝移除权重列后会产生输出误差，损害模型精度。已有的免训练补偿方法存在明显局限：
  - **Wanda-sp**：仅做列选择，完全不补偿，输出偏差未修正；
  - **FLAP**：用加性偏置补偿均值误差，但常数偏置无法修正与输入相关的方向性误差；
  - **RCPU**：仅对保留权重施加左侧（输出侧）正交旋转加全局缩放，输入奇异框架（`V_K`）保持不变，限制了权重在列移除后的适应能力。

- **整体含义**：论文论证了"剪枝后补偿"本身是一个值得独立优化的环节，并提出了一个**与列选择准则无关、即插即用**的补偿框架COEC，可挂接在任何结构化剪枝方法之后。

## 2. 方法论

### 2.1 核心思想

将补偿权重参数化为保持谱结构的双侧正交等价变换：
$$\tilde{W} = Q_\ell \, W^{(S)}_K \, Q_r, \quad Q_\ell \in O(d_{out}),\, Q_r \in O(k)$$

即左旋转调整输出奇异框架，右旋转调整输入奇异框架，逐模式奇异值重缩放控制谱的变化。相比无约束最小二乘重构，这种参数化避免了过度拟合小校准集、扭曲预训练权重的风险。

### 2.2 关键技术细节

- **交替优化的目标函数**：相对重构误差 + 对齐惩罚项（仅作用于注意力输出投影）：
$$L = \frac{\|Y - \tilde{W}X_K\|^2_F}{\|Y\|^2_F} + \lambda_a A(Q_r)$$
- **左旋转（闭式解）**：正交 Procrustes 解，`Q_ℓ = polar(G_yx \tilde{W}^⊤)`，即对交叉统计量做极分解取正交因子。
- **全局缩放（交替更新）**：标量最优解为 `s* = ⟨G_yx, \tilde{W}⟩ / ⟨\tilde{W}, \tilde{W}G_xx⟩`，在每轮右旋转更新后重新计算，实现联合收敛。
- **右旋转（约化Stiefel流形求解）**：由于权重按输出分片处理（b < k），目标只依赖 `R = V_g^⊤ Q_r ∈ St(b,k)`，在约化Stiefel流形上做投影梯度下降（Newton–Schulz极分解回缩或Cayley回缩），计算和内存开销减少约 b/k 倍。初始化 `Q_r = I` 对轻度稀疏至关重要。
- **GCV逐模式奇异值重缩放**：每层独立选择正则化强度 λ，用广义交叉验证（GCV）平衡对校准集的拟合度与过拟合风险。正则化后的奇异值为 `s_g,i(λ) = (ρ_i + λs*σ_i)/(e_i + λ)`，当 λ→0 退化为逐模式最小二乘解，λ→∞ 退化为全局缩放。
- **Gram矩阵谱缓和**：对校准激活Gram矩阵做谱压缩 `G_α = E diag(μ_i^α) E^⊤`，降低高能量激活方向的主导地位，默认 α=0.9。
- **锚定层间对齐惩罚**：用于注意力输出投影，约束其右旋转后的前 r_p=16 维子空间投影器与原始未剪枝投影的前导子空间（限制到保留坐标后正交化）对齐，惩罚项为：
$$A(R) = \|U_v^⊤(\Pi_{r_p}(R) - \Pi_{anchor})U_v\|^2_F / r_p^2$$
- **完整流程（每层权重矩阵）**：谱缓和 → 左旋转 → GCV重缩放 → 交替迭代（右旋转 → 重缩放 → 左旋转 → 重缩放）直到收敛（最多50轮），整个流程免训练、无反向传播。

## 6. 主要结论与发现

- **COEC在困惑度上全面领先**：三种选择准则下，COEC在每个模型的PPL均优于对应原生补偿；30%稀疏度下最大提升为 Qwen2.5-32B（13.90 → 9.64，Wanda-sp选择）。
- **零样本准确率多数提升**：大部分设置下COEC优于基线，个别例外（如Qwen2.5-14B的RCPU对比）但PPL仍保持领先。
- **增益随稀疏度增大**：相对RCPU的平均PPL差距从10%的0.06 → 20%的0.20 → 30%的0.25，说明高稀疏度下补偿收益更大。
- **各组件贡献明确**：双侧旋转与GCV重缩放贡献主要PPL下降；约化Stiefel求解贡献大部分零样本增益；Gram谱缓和恢复PPL成本；对齐惩罚提供最终零样本提升。
- **补偿不改变部署成本**：旋转和重缩放不改变模型形状，30%稀疏度的参数/内存/FLOPs下降（23–29%）在剪枝后即固定。
- **几何分析结论**：剪枝使输入方向旋转约22°，重构误差最小化不会恢复原始输入框架；COEC的对齐惩罚将投影器不匹配度降低中位数7.2倍，且不破坏层内输入-输出的配对关系。

## 7. 优点

- **方法设计新颖**：首次将双侧正交旋转引入剪枝后补偿，解决了单侧旋转无法调整输入奇异框架的根本局限；在约化Stiefel流形上求解，显著降低计算开销。
- **自适应正则化**：用GCV为每层独立选择奇异值重缩放的强度，避免全局手动调参，且附录验证了层级GCV与全局最优调参效果相当。
- **即插即用**：补偿与列选择准则完全解耦，可直接挂接Wanda-sp、FLAP、RCPU等任何结构化剪枝方法，无需改架构。
- **免训练、资源友好**：仅需128条校准序列的二阶统计量、无反向传播；7–8B模型补偿不到1.5 GPU小时，实用性强。
- **实验严谨**：统一协议、超参固定后跨模型家族迁移验证、无选择性报告、附上多条数值保护措施（奇异值限幅、步长限制、降级回退链）。
- **问题定位清晰**：用几何测量提供了剪枝导致输入子空间旋转的直接证据，帮助理解补偿机制为何有效。

## 8. 不足与局限

- **补偿仍非完全恢复**：几何分析表明，对齐惩罚虽降低了投影器不匹配度（中位数7.2倍），但主角度（22–24°）并未减小，旋转仅是被"投影器盲区"掩盖，真正恢复原始输入框架仍需角度感知的目标函数。
- **特定场景下收益有限**：10–20%轻度稀疏度下，FLAP的简单偏置补偿在多数模型上PPL仍具竞争力；Qwen2.5-14B在30%稀疏度下零样本准确率略低于RCPU，说明COEC并非在所有情况下都严格占优。
- **校准集依赖**：方法依赖128条特定风格（WikiText-2）校准序列的二阶统计量；跨领域/多语言场景下校准分布偏移的影响未在文中测试。
- **评估范围限制**：零样本评估仅覆盖7个英文任务；未包含对话、代码、数学等生成式任务的端到端质量评估；任务多样性对结论普适性有潜在影响。
- **超参仍有人工选择**：尽管GCV自动选择λ，但α（谱缓和强度）、λa（对齐惩罚权重）、r_p（子空间维度）、δ（容差）等仍有默认值依赖开发模型的启发式选择，附录B虽报告了搜索范围但未做更细的敏感性分析。
- **数值稳定性依赖工程防护**：文中披露了多种数值反常现象（负分母产生10³⁷尺度因子、cuSOLVER挂起等），说明在部分Qwen层上方法依赖额外的数值保护链，工程实现复杂度较高。
- **计算开销未与端到端剪枝流程总成本比较**：论文报告了补偿的绝对成本，但未说明其占整个剪枝管线（含激活统计采集和选择评分）的比重。
