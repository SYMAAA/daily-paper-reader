## 摘要
在移动设备上部署视觉语言模型（VLM）因其巨大的内存和计算需求而具有挑战性。我们提出了一种用于在资源受限硬件上高效推理的VLM量化框架。我们的方法将一种量化流程与一种新颖的每参数2.7位格式相结合，该流程利用模型自身生成训练数据，且无需访问训练设置，并支持在Arm CPU上高效执行。我们通过将Llama 3.2 11B视觉指令模型压缩至3.7 GB（采用8位激活）来验证我们的方法，在一组标准视觉问答任务上保持了强劲的性能。

## Abstract
Deploying vision-language models (VLMs) on mobile devices is challenging due to their significant memory and compute requirements. We present a framework for quantizing VLMs for efficient inference on resource-constrained hardware. Our approach combines a quantization pipeline that uses the model itself to generate training data and does not require access to the training setup, with a novel 2.7-bit-per-parameter format supporting efficient execution on Arm CPUs. We validate our approach by compressing the Llama 3.2 11B Vision Instruct model to 3.7 GB with 8-bit activations, preserving strong performance on a set of standard visual question answering tasks.

## 2. 方法论

### 2.1 整体流程
- 框架包含三个步骤：
  1. **合成数据生成**：使用原模型自身在通用图像上生成问答训练数据，避免依赖原始训练集或下游任务数据。
  2. **量化感知训练（QAT）**：以原 bfloat16 模型为教师，量化模型为学生，在合成数据上进行知识蒸馏。
  3. **移动端部署**：将训练好的量化权重以专用格式打包，并在 Arm CPU 上高效执行。

### 2.2 QAT 目标与损失
- 教师模型 \(f_T\) 保持 bfloat16 高精度，学生模型 \(f_S\) 的权重在前向传播时经过量化算子 \(Q(\cdot)\)，梯度通过直通估计器（STE）传播。
- 对每个训练样本 \((\mathbf{I}, x, y)\)，在教师生成的回答 token 上计算逐 token 的 KL 散度并取平均：
  \[
  \mathcal{L}_{\text{KD}}(\mathbf{I}, x, y) = \frac{1}{|y|}\sum_{t=1}^{|y|} D_{\text{KL}}(p_T^{(t)} \| p_S^{(t)})
  \]
- 目标是最小化量化学生与原始教师在生成分布上的差异。

### 2.3 合成数据生成管线
- **图像来源**：使用 ImageNet 训练集（约 128 万张自然图像），与下游评测任务无关。
- **提示词采样**：
  - 以 75% 概率套用 Llama 3.2 Vision 的指令模板，其余使用无模板输入。
  - 从手写通用问题池和模板化生成的问题池中随机采样问题。

  - 长度约束偏向短/中等回答，少量长回答。
- **教师生成**：使用温度 0.6、top-p 0.9，最大生成 512 token，生成响应作为蒸馏目标。
- 关键点：不使用任何下游 benchmark 图像或提示，避免过拟合评测任务。

### 2.4 S3D8 量化格式
- **名称**：Signed 3D 8-bit，即“有符号三维 8 位”格式。
- **核心设计**：每个字节存储 3 个权重，包含 1 个 5 位共享质心索引 + 3 个符号位，平均约 2.7 bit/参数。
- **量化公式**：
  \[
  \tilde{W}_{ij} = \alpha_i \cdot s_{ij} \cdot C_{q_{\lfloor i/3\rfloor},\, j \bmod 3}
  \]
  其中 \(\alpha_i\) 为每输出通道尺度，\(s_{ij}\) 为符号，\(C\) 为 32×3 的质心表。
- **质心训练**：先按输出通道绝对最大值归一化权重，取绝对值，利用 Lloyd-Max / k-means 算法拟合 32 个质心；QAT 过程中质心冻结，只更新尺度、索引和符号。
- **硬件加速**：
  - 使用 Arm Advanced SIMD 的 64 项 TBL 查找指令，将符号位合并进查找索引，无需额外符号修正。
  - 位打包经过优化，只需 5 条逻辑指令即可生成 3 个查找索引。
  - 每个字节中的 3 个权重来自不同输出通道，简化了融合反量化-点积内核的 padding 和对齐。

## 6. 主要结论与发现（续）

- **额外保留 INT8 层收益很小**：将输出投影和视觉编码器保留为 INT8 时，平均任务分仅小幅提升（约 0.01–0.02），但视觉编码器的内存占用显著增加。考虑到视觉编码器仅需在前处理阶段运行一次，保留其 INT8 精度对内存的边际成本较低，可作为可选优化；而输出投影层保留 INT8 的收益不足以弥补额外的内存开销，因此默认配置不采用。

## 7. 局限性与不足

- **模型泛化性有限**：所有实验均基于单一模型（Llama 3.2 11B Vision Instruct），未验证 S3D8 格式与其他 VLM 架构（如 LLaVA、Qwen-VL）或文本模型（如 LLaMA 3.1 8B）的兼容性。S3D8 的“3 权重共享一个字节”设计对权重矩阵的输出通道数有对齐要求，不同架构的 paddding 策略可能影响压缩率。
- **评测带宽有限**：仅使用 4 个 VQA 类 benchmark，且每个仅 1024 个样本。未覆盖图像生成、视频理解、多轮对话等更丰富的多模态任务；1024 个样本的置信区间较宽，任务分差异在 ±0.02 以内时可能不具统计显著性。
- **合成数据与真实数据分布差异**：合成数据仅基于 ImageNet 自然图像，对文档、图表、科学图示等域内图像的覆盖不足。论文通过随机化提示词部分缓解了 prompt 侧过拟合，但图像侧多样性仍有局限。
- **GPTQ 对比设置不完全对等**：GPTQ 基线仅量化权重（激活保持 bfloat16），而 QAT 和直接投射同时量化了权重和激活（8 bit）。这使 GPTQ 在内存和延迟上处于劣势，但其更高的激活精度可能已使其性能受益，对比的公平性存在争议。
- **硬件验证范围窄**：实测仅覆盖 Arm 平台（Pixel 8a、Graviton4），未在 x86 CPU 或移动 GPU（如 Adreno、Mali）上验证 S3D8 的通用性。TBL 查表指令在 x86 上无直接等价实现，部署到其他平台需要额外的指令映射或软件模拟，可能损失性能优势。

## 8. 总结

本文提出了一套面向移动端 VLM 的完整低比特量化部署方案，其核心贡献可归纳为三点：其一，提出 S3D8 数值格式，利用每字节 3 个共享质心权重的设计在极低比特率（2.7 bit/参数）下保留高精度，并通过 Arm TBL 指令实现高效解量化；其二，给出了一套无需原始训练数据的 QAT 流程，通过教师生成合成数据 + 多样性提示词采样 + KL 散度蒸馏，使得量化模型在 VQA 任务上的性能损失可控；其三，在真实移动端 CPU 上验证了端到端可行性，将 11B VLM 压缩至约 3.7 GB，在 Pixel 8a 上实现了约 7–9 token/s 的生成速度。该工作对资源受限设备上的多模态 AI 部署具有工程参考价值，其合成数据蒸馏和自定义量化格式的设计思路可推广到更广泛的模型压缩场景。

## 9. 个人评价与启示

- **值得借鉴的思路**：将“数值格式设计”与“量化训练方法”解耦研究，分别做消融，这种实验策略在量化论文中属于较清晰的范式；合成数据蒸馏的 pipeline 可复用性强，为无监督量化提供了可行路径。
- **值得注意的风险**：S3D8 需要为每个模型重新训练质心，且质心表是每输出通道共享的，若权重分布出现离群通道，32 个质心可能不够；论文未分析量化权重在训练后的分布漂移情况。
- **可扩展方向**：
  1. 将 S3D8 推广到 4 权重/字节或混合精度格式，以适应不同层对比特数的敏感度差异；
  2. 引入激活量化感知的端到端蒸馏，进一步压缩首 token 延迟；
  3. 在更多指令微调 VLM 和真实移动应用场景（如离线 OCR、视觉助手）中验证方法的鲁棒性。
