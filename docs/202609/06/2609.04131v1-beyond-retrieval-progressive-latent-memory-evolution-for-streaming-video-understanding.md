## 摘要
流式视频理解要求多模态大语言模型（MLLMs）在严格因果性和有限记忆条件下处理连续视觉输入并响应用户查询。现有方法通常将历史观察压缩到外部记忆库中，并检索与查询相关的证据作为额外视觉上下文。尽管有效，这种存储-检索范式将历史证据保留为外部视觉上下文，使其无法被内化为一种紧凑、演化的潜在记忆，以持续指导流式推理。为弥合这一差距，我们引入了LatentStream，一种渐进式潜在工作记忆框架，将流式记忆从存储-检索转变为检索-内化。具体而言，LatentStream包含三个协同组件。首先，查询无关的分层流式记忆通过Jenks引导的自适应整合，在固定记忆预算下将视觉历史组织为短期、中期和长期层级。一旦查询到达，分层潜在记忆演化赋予各组潜在记忆令牌逐渐扩大的记忆感受野，使其能够迭代地从相应范围检索历史证据并将其内化为紧凑的定长潜在记忆。最后，渐进式置信度引导的潜在记忆优化从分组预测熵构建分层进度奖励，并联合细化潜在记忆令牌与检索证据，鼓励日益自信的流式推理。大量实验表明，LatentStream在现有在线和离线视频基准上取得了新的最先进成果。

## Abstract
Streaming video understanding requires multimodal large language models (MLLMs) to process continuous visual inputs and respond to user queries under strict causality and bounded memory. Existing approaches typically compress historical observations into an external memory bank and retrieve query-relevant evidence as additional visual context. Though effective, this store-and-retrieve paradigm keeps historical evidence as external visual context, preventing it from being internalized into a compact, evolving latent memory that can continuously guide streaming reasoning. To bridge this gap, we introduce LatentStream, a progressive latent working memory framework that shifts streaming memory from store-and-retrieve to retrieve-and-internalize. Specifically, LatentStream comprises three coordinated components. First, Query-agnostic Hierarchical Streaming Memory organizes visual history into short-, mid-, and long-term levels under a fixed memory budget through Jenks-guided adaptive consolidation. Once a query arrives, Hierarchical Latent Memory Evolution equips groups of latent memory tokens with progressively expanding memory receptive fields, enabling them to iteratively retrieve historical evidence from their corresponding scopes and internalize it into a compact, fixed-length latent memory. Finally, Progressive Confidence-guided Latent Memory Optimization constructs a hierarchical progression reward from group-wise predictive entropy and jointly refines the latent memory tokens and retrieved evidence, encouraging increasingly confident streaming reasoning. Extensive experiments demonstrate that LatentStream achieves new state-of-the-art results on existing online and offline video benchmarks.

## 2. 方法论：LatentStream 框架

作者提出了 **LatentStream**，一种“渐进式潜在工作记忆”框架，由三个协同的组件构成，且在整个过程中保持底层的 Video-LLM 参数完全冻结：

### (1) 查询无关的分层流式记忆（Query-agnostic Hierarchical Streaming Memory，HSM）

- 在查询到达前，持续在线地维护一个三层记忆库：短期记忆 M_s（保存细粒度、近期的感知细节）、中期记忆 M_m、长期记忆 M_l。
- 记忆的跨层迁移通过 **Jenks Natural Breaks（Jenks 自然间断点）** 这一数据驱动方法实现自适应压缩：
  - **短期→中期迁移**：对时间重要性分数 S_temp 做三类 Jenks 划分，得到两个阈值 τ1、τ2，将历史表征路由为 Drop/Compress/Preserve 三类（式 1）。得分特别低的丢弃，中等程度的做时间压缩，高分者完整保留。
  - **中期→长期迁移**：对空间距离分布 S_spat = {d_ij}（其中 d_ij = 1 - cos(v_i, v_j)）使用两类 Jenks 划分；低距离组视为空间冗余并合并，高距离组逐项保留。
- 整体记忆消耗被限制在固定的 token 预算内。该记忆构建过程与查询无关，但在后续潜在记忆推理中为查询相关的证据访问提供了层次化基础。

### (2) 分层潜在记忆演化（Hierarchical Latent Memory Evolution，HME）

- 引入 **Latent Memory Tokens（LMTs，潜在记忆令牌）**，在演化迭代 r 时将 LMTs 分成三组——Ẑ_s、Ẑ_m、Ẑ_l，每组对应一个检索感受野：
  - C_s = M_s；
  - C_m = M_s ∪ M_m；
  - C_l = M_s ∪ M_m ∪ M_l。
- 三组感受野形成嵌套累进结构：范围更大的一组既能访问长期记忆也不会丢失近期细碎信息。
- **初始化**：通过一次“引导前向传播”，将初始 LMT 嵌入与查询、外部记忆共同送入模型，同时使用组别特定的注意力掩码，得到查询条件化的初始潜在状态 Ẑ(0)。
- **潜在引导的证据检索**：在每一轮演化迭代 r 中，每个 LMT 组 Ẑ_g 在自身对应的感受野 C_g 内检索历史证据。对每个候选视觉 token，使用的是它和该组内 K 个 LMT 的最大余弦相似度作为亲和度分数（见式 4），取 TopK_B 个证据作为本轮临时证据 E_g^(r)。
- **证据注入与潜在记忆更新**：将上一轮已累积的证据池、本轮新检索的可优化证据副本插入到对应 LMT 组之后，连同 LMT 一起构建候选输入状态；通过奖励门控决定是否将本轮新证据合并进证据池——仅当候选状态产生比上一轮更好的奖励时才接受新证据，否则丢弃（式 5）。
- 检索证据的梯度通过奖励信号回传，从而优化可训练的 LMT 嵌入，使得“查询相关历史被逐步内化到固定轮数的潜在状态中”，并反过来引导下一轮检索。最终解码前全部注入的视觉证据副本被移除，只保留外部记忆、查询与经过优化演化的潜在记忆 tokens。

### (3) 渐进式置信度引导的潜在记忆优化（Progressive Confidence-guided Latent Memory Optimization，PMO）

- 利用冻结 MLLM 自身输出的预测不确定度作为内在反馈，为 LMT 演化提供无外部标注的自监督信号：
  - 在演化迭代 r 中，对每个组 g 取 TopK_δ 概率位置，计算 **归一化 top-δ 熵** E_g(U)（式 6）。熵越低表示预测置信度越高。
  - 期望的熵顺序为 E_s ＞ E_m ＞ E_l：即可访问历史范围越大，推理应越自信。
- 定义**分层进展奖励**（式 7）为两部分：
  1. *绝对置信项*：对所有组 1 - E_g 求和；
  2. *分层进展项*：对 [E_s - E_m]+ 与 [E_m - E_l]+ 求和，鼓励熵严格递减的次序。
- **优化算法**：在状态上采用高斯扰动 ξ ~ N(0, σ²I) 形成 REINFORCE 型策略梯度更新（式 8、式 9），梯度形式为 E[R(U')ξ/σ²]。对候选状态中的 LMT 嵌入和新检索的证据表示做联合逐轮更新，优化后仅保留 LMT 参与最终解码。

- LatentStream 在 **OVO-Bench** 上以 Qwen2.5-VL-7B 为骨干取得 **64.2%** 总体分数，比基线提升 **+10.2%**，超越所有同规模开源模型（含训练式方法）；3B 版本也从 52.2% 提升到 **59.0%**。
- 在 **StreamingBench** 上达到 **76.9%**，超过所有无训练式对照方法（+3.0%）。
- 在**离线基准**上同样有增益：VideoMME 达 **66.6%**（较基线 63.3% 提升 3.3%，其中短/中/长视频子集分别达到 77.2%/67.4%/55.1%）、MLVU 达 **74.0%**（较基线 67.9% 提升 6.1%）、LongVideoBench 达 **62.1%**（较基线 60.7% 提升 1.4%）。
- 消融表明：HSM 模块贡献显著；PMO 能把 58.1% 提至 62.4%；完整加入 HME 后达到 64.2%。“演化后的 LMTs”远优于“直接把检索证据拼接到上下文”或“引入未演化的 LMTs”，证明历史证据确实被内化进了潜在记忆而非仅作为外部上下文。分层进展奖励比“仅绝对置信优化”更高（64.2% vs 62.5%/66.6% vs 65.5%）。
- 效率对比显示 LatentStream 在 7B 骨干下显著降低峰值显存（30.80GB→21.97GB）和 TPOT（6.45ms→3.16ms，降幅 51.0%），说明固定预算分层潜在记忆在推理效率上同样受益；TTFT 则因额外演化步骤从 7.63s 增至 8.41s。
- 以上结果共同支持论文的中心论点：将流式视频记忆范式从“存储-检索”推进到“检索-内化”，可以实现更有效且更有推广能力的持续视频推理——该方法在在线与离线场景、不同骨干规模下均保持了可靠增益。

## 8. 局限与潜在不足

- **测试时优化的额外延迟**：表 6 显示 7B 模型的 TTFT 从 7.63s 增至 8.41s，说明多次潜在记忆演化并非零成本。虽然 TPOT 大幅下降，但在对“首响应时间”极敏感的实时交互场景（如语音助手、自动驾驶告警）中，多轮演化引入的启动延迟仍可能成为瓶颈。
- **内在奖励信号的适用边界**：基于输出 top-δ 熵的分层进展奖励是一个无任务先验的启发式信号，隐含“证据越多、置信度越高”的假设。这一假设在分布外场景或长尾问题上未必成立——模型完全可能在错误答案上表现出高置信度，或在正确答案附近保持高熵。论文未讨论这类失败模式，也未将熵信号与任务级验证信号结合。
- **在线聚类机制的脆弱性**：HSM 的记忆迁移依赖 Jenks Natural Breaks 对时间重要性分数与空间距离分布做无监督划分。该阈值完全由当前批次的数据分布决定，当视频主题发生剧烈突变（如镜头切换、事件断裂）时，可能把本应保留的关键帧当作冗余丢弃；论文没有对分布漂移的鲁棒性做专门分析。
- **评测规模与骨干覆盖有限**：实验均基于 Qwen2.5-VL-3B/7B 两个规模，且算力集中描述为 8 张 H20 GPU。验证范围尚未覆盖更大尺度（如 72B 量级）或更多样的 MLLM 架构，因此框架对“模型规模扩大后潜在记忆容量与输出空间仍能对齐”这一假设尚未给出强经验证据。
- **多轮交互与查询依赖的评测缺失**：现有基准大多假设用户查询在某一时刻点到达、回答一次后结束；对“连续多轮查询、中间插入新视频帧、上一轮答案影响下一轮推理”的对话式流式场景，论文未提供专门评估。
- **效率指标粒度不足**：TTFT/TPOT/显存给出了聚合结果，但没有分解 HSM 压缩、引导前向、R 轮演化各自的耗时占比；也未对比不同演化轮数下的显存曲线与能耗，给复现和部署时的预算规划带来不便。

## 9. 创新点凝练与学术价值

- **范式层面的迁移**：将流式视频记忆的核心设计问题从“去哪里检索更多相关证据”转移到“如何把检索到的证据变成模型自身潜在状态”，对 streaming MLLM 的研究路径是一次有价值的重新定向。
- **记忆容量与推理演化的统一**：论文用定长 LMTs 作为内在记忆载体，将无限增长的外部记忆“折叠”为可与查询共同迭代演化的潜在状态，在数学形式与工程实现上都回避了随视频长度线增长的上下文开销，同时借助嵌套感受野保留了多粒度时间信息。
- **自监督测试时优化的巧妙落地**：在不训练 LLM、不需要人工标注的前提下，利用模型自带概率分布构建分层置信度奖励并配合高斯扰动 REINFORCE 更新，既保持了骨干的通用性，又让潜在记忆能针对特定视频与查询做即时适配，具备较强的应用可迁移性。
- **对部署的价值**：在与充分上下文基线同等甚至更低的显存与逐 token 生成延迟条件下取得更强精度，意味着“结构化的潜在记忆”不只是精度上的补充，也是一种面向边缘设备与长时任务的可行记忆压缩方案。

## 10. 总体评价

总体而言，这是一篇问题定义清晰、方法设计完整、实验支撑较充分的流式视频理解工作。它的最大亮点不在于某一个模块的性能提升，而在于提出了“retrieve-and-internalize”这一更高层次的研究命题，并用一套可复现的、训练-free 的框架完成了概念验证。论文写作在动机叙述与模块对应关系上都较为工整，对比实验兼顾了训练式/无训练式、开源/闭源、在线/离线的多维边界，消融也直接服务于核心机制断言。

若要进一步打磨，可考虑补充：更细粒度的耗时与显存分解；对熵奖励信号失效场景的分析；在更多骨干（含更大规模或不同视觉编码器）上的泛化实验；以及面向多轮对话式流式视频问答的评测设定。即便如此，本文在“外存-查询-潜在记忆”三者关系上的建模，已为其后续在 long-horizon embodiment、实时监控、可穿戴设备等场景的延伸提供了扎实的理论与实验起点，也具有较强的学术参考价值。
