## 摘要
量化通过使用更少的比特来表示权重，使视觉语言模型（VLM）的存储和运行成本更低。尽管压缩后视觉问答（VQA）的答案保持不变是一种预期行为，但它们仍可能掩盖底层分数（对数概率）的变化。例如，模型在压缩后可能仍然回答“是”，即使“是”和“否”之间的分数差距已经缩小。我们提出 BEFORE THE FLIP 来测量这些隐藏变化。我们的方法将压缩引起的分数变化与将图像的内部表示（即图像 token）替换为一个固定平均 token 所引起的变化进行比较。然后，我们每次提高一个权重组的精度，以识别额外比特在何处有帮助，并测试为每个问题选择不同权重组是否能带来超出打乱对照组的收益。在 8,277 个图像 token 替换可测量地影响分数的 LLaVA 问题中，4 比特压缩使“是”或“否”的分数差距比 8 比特压缩更远地偏向替换输出。Qwen 表现出相同模式，但差异更小。然而，在 4 比特下，9,000 个 LLaVA 答案中只有 265 个发生变化。在一项针对 1,024 个校准问题的独立研究中，为每个问题单独选择权重组在任何测试的存储预算下都没有同时优于两个打乱对照组。这些发现表明，压缩可以改变未变答案背后的分数，但并未证明为每个问题调整精度能带来可靠收益。

## Abstract
Quantization makes vision language models (VLMs) cheaper to store and run by using fewer bits to represent their weights. While unchanged answers on visual question answering (VQA) after compression are an expected behavior, they can still hide changes in the underlying scores (log probabilities). For example, a model may still answer yes after compression, even as the score gap between yes and no shrinks. We introduce BEFORE THE FLIP to measure these hidden changes. Our method compares the score change caused by compression with the change caused by replacing the image's internal representations, or image tokens, with one fixed average token. We then increase the precision of one weight group at a time to identify where extra bits help, and test whether choosing different groups for each question offers benefits beyond shuffled controls. Among 8,277 LLaVA questions where image token replacement measurably affects the scores, 4-bit compression shifts the yes or no score gap farther toward the replacement output than 8-bit compression. Qwen shows the same pattern, but with a smaller difference. Yet only 265 of 9,000 LLaVA answers change at 4 bits. In a separate study of 1,024 calibration questions, choosing weight groups separately for each question does not outperform both shuffled controls at any tested storage budget. These findings show that compression can alter the scores behind unchanged answers, but do not establish a reliable benefit from adjusting precision for each question.

## 1. 核心问题与研究动机

- **背景**：量化（如 4-bit、8-bit）通过用更少比特存储权重来降低视觉语言模型（VLM）的存储与推理成本。现有 VLM 量化研究主要报告基准分数（accuracy/F1），而视觉 grounding 类研究多针对全精度模型，二者之间存在空白。
- **核心问题**：VQA 的最终答案不变**并不等于**模型内部没有变化。例如模型压缩后仍回答 "yes"，但 YES/NO 两个 logit 之间的**分数差距（log probability gap）可能已经缩小甚至反向移动**。只看 accuracy 会系统性掩盖这种"翻转前"的隐藏漂移。
- **整体含义**：在部署场景（尤其高风险 AI 应用）中，被压缩的模型可能存在未被基准测出的内部偏好改变，而当前缺乏针对"压缩后部署模型"的原则性评测手段。
- **作者立场**：论文既报告了这种隐藏偏移确实存在，也明确指出它**不构成对逐题自适应精度的可靠收益证明**——是一个带有强烈否定性结论的诊断型工作。

## 2. 方法论：BEFORE THE FLIP 三阶段评测

### 核心思想
将"压缩造成的分数变化"与"用固定平均图像 token 替换图像 token 造成的分数变化"做方向性对比，从而把不可见的内部漂移转成一个可测量的标量。

### Stage 1：Prior Reversion Score（PRS）——测量隐藏分数偏移
- **三次运行同一问题**（POPE 为二分类 YES/NO）：
  - 16-bit 权重 + 真实图像 → 分数 $z^{16}_{I,i}$
  - 16-bit 权重 + 替换图像 token → 分数 $z^{16}_{\emptyset,i}$
  - 压缩权重 + 真实图像 → 分数 $z^{\pi}_{I,i}$
- **去中心化**：对每个两维分数减去其均值 $c(z) = z - \frac{1}{2}\mathbf{1}\mathbf{1}^\top z$，只保留决定答案的分数差。
- **两个变化量**：$d_i = c(z^{16}_{\emptyset,i}) - c(z^{16}_{I,i})$（图像替换效应）；$q^{\pi}_i = c(z^{\pi}_{I,i}) - c(z^{16}_{I,i})$（压缩效应）。
- **PRS 定义**：$\mathrm{PRS}_i(\pi) = \dfrac{\langle q^{\pi}_i,\, d_i\rangle}{\lVert d_i \rVert_2^2 + \epsilon}$。正值表示压缩把两个答案分数**推向**图像替换后的输出；0 表示无该方向移动；1 表示完全到达替换输出。
- **稳定性过滤**：仅保留 $\lVert d_i \rVert_2 > \tau_d$（$\tau_d = 0.302$，即 10 百分位），过滤后保留 91.97% 的问题，避免小分母导致 PRS 爆炸。
- **辅助指标**：$\mathrm{PRS}^+ = \max(\mathrm{PRS}, 0)$；response ratio（压缩模型对图像替换的响应强度 / 16-bit 响应强度）；flip match rate（翻转答案中与替换答案一致的比例）。
- **五种图像替换方式**：数据集平均 token、单图平均 token、全零 token、另一张图的 token、灰度图（经完整视觉编码器）。
- **重要澄清**：作者强调 "prior reversion" 只是描述**被测量的方向**，不主张模型内部存在隐藏的语言先验。

### Stage 2：逐组提升精度——定位额外比特的作用
- 把模型划分为 **G = 57 个权重组**：24 个图像编码器 block + 1 个 connector + 32 个解码器 block。
- 起点全部为 4-bit，**每次只把一组提升到 8-bit**，重新跑问题。
- **Faithfulness 损失**：$L^{\text{faith}}_i(\pi) = \frac{[\mathrm{CE}_i(\pi) - \mathrm{CE}_i(16)]^+}{s_{\mathrm{CE}}} + \frac{[\mathrm{PRS}_i(\pi)]^+}{s_{\mathrm{PRS}}}$（正确答案交叉熵增量 + PRS 正部，各自缩放，越低越好）。
- **改进量**：$\Delta F_{i,g} = L^{\text{faith}}_i(W4) - L^{\text{faith}}_i(W4[g \to W8])$，正值表示该组升精度降低损失。
- 进一步把 13 个解码器 block 拆成 attention 与 FFN 两个子部件，检验子部件效应是否可加。

### Stage 3：逐题选择精度组——用打乱对照证伪
- **固定方案（fixed plan）**：用所有问题的平均损失下降选一组。
- **事后方案（hindsight plan）**：看过所有结果后为每题单独选组，**不可部署**，且可能只是选中了噪声。
- **两个打乱对照**：
  - Shuffle A：在每个组内打乱问题（保留该组的取值分布，破坏问题身份）。
  - Shuffle B：在每个问题内打乱组（保留该问题的难度，破坏组身份）。
- **判定标准**：真实事后增益必须**同时超过两个**打乱增益，才支持逐题选择。
- 最后把所有被选中的组组合**真实过一遍模型**，因为多组变更之间可能相互作用（不能简单相加）。

## 3. 实验设计

- **模型**：主模型 LLaVA-1.5-7B；验证模型 Qwen2.5-VL-7B-Instruct。所有实验使用 4-bit 与 8-bit 量化，16-bit 为参照。
- **数据集 / 场景**：
  - **POPE-COCO 9,000 题**（random / popular / adversarial 各 3,000），是二分类 YES/NO 的核心评测。
  - **1,024 题平衡校准集**（来自 COCO train2014），用于组图分析、损失阈值校准、选择器评估，图像子集互不重叠。
  - **CHAIR 500 张 COCO 图**：开放式 caption 幻觉（句子级错误率 CHAIR_s、物体召回、平均长度）。
  - **MME perception、MMBench、ARC (Easy)、HellaSwag**：文本任务统一喂同一张中性图像。
  - **VCD（Visual Contrastive Decoding）**：对比真实图与噪声破坏图的输出，扫描强度 $\alpha$ 与扩散步数（500/999），$\beta=0.1$。
- **图像 token 设置**：LLaVA 保留全部 576 个图像 token；Qwen 固定分辨率 448×448、256 个 token（非原生可变分辨率）。
- **对比对象**：
  - 精度：W4 vs W8 vs 16-bit；五种图像替换方式。
  - 精度方案：image encoder W8、connector W8、前 8 个解码器 block W8、固定 5%/10%/15% 平均 token 方案、K3_P1/P2/P3（k-medoids 得到的混合方案）、capstep01。
  - 选择器：岭回归、两层小神经网络、Jensen–Shannon 距离固定规则（非学习）。
  - 统计方法：10,000 次图像级 bootstrap 置信区间、McNemar 配对检验、Spearman 秩相关、方差分解、Kendall $\tau$。
- **预注册性质**：阈值与候选方案在独立校准集上先行固定，再在测试集评估。
