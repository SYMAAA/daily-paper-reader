## 摘要
低位键值（KV）缓存减少了自回归解码所需的内存，但由此产生的质量损失取决于模型和量化器。我们保持量化器固定，在学生执行物理打包增量缓存的同时，将浮点缓存模型的行为蒸馏到低秩Q/K/V投影更新中。在三个种子上，4位仿射缓存适配器在TinyLlama-1.1B上恢复了留出困惑度差距的54.24%±2.47%，在Gemma-4-12B上恢复了75.96%±4.04%。在相同的冻结NF4 Llama-3.1-8B基座上，每个量化器一次验证集选定的运行在KIVI K2V2下恢复了60.42%，在KVarN K4V2下恢复了37.61%，同时保留了180例关联检索。Gemma在官方4K/8K RULER子集上的得分从未适配的4位缓存的42.80上升到适配后的48.33（浮点为46.15），存在显著的任务异质性。最后，一次2位秩-标记扫描将TinyLlama的2位PPL从576.10降至三个种子上的11.4000±0.0059（浮点为10.3988），但仅恢复了180例检索中的11至12例。这些结果表明，低秩投影适配可以在固定缓存格式下恢复留出质量，而困惑度恢复并不一定恢复长上下文检索。

## Abstract
Low-bit key--value (KV) caches reduce the memory required for autoregressive decoding, but the resulting quality loss depends on the model and quantizer. We keep the quantizer fixed and distill the floating-cache model's behavior into low-rank Q/K/V projection updates while the student executes a physically packed incremental cache. Across three seeds, 4-bit affine-cache adapters recover $54.24\%\pm2.47\%$ of the held-out perplexity gap on TinyLlama-1.1B and $75.96\%\pm4.04\%$ on Gemma-4-12B. On the same frozen NF4 Llama-3.1-8B base, one validation-selected run per quantizer recovers $60.42\%$ under KIVI K2V2 and $37.61\%$ under KVarN K4V2, while preserving 180-case associative retrieval. Gemma's score on an official 4K/8K RULER subset rises from 42.80 with the unadapted 4-bit cache to 48.33 after adaptation (46.15 floating), with substantial task heterogeneity. Finally, a 2-bit rank--token sweep reduces TinyLlama's 2-bit PPL from 576.10 to $11.4000\pm0.0059$ across three seeds, versus 10.3988 floating, but restores only 11--12 of 180 retrieval cases. These results show that low-rank projection adaptation can recover held-out quality across fixed cache formats, while perplexity recovery need not restore long-context retrieval.

### 1. 论文的核心问题与整体含义（研究动机与背景）

- **背景**：自回归推理会持续存储键（Key）和值（Value）用于后续注意力计算，形成 KV 缓存。随着序列长度和批量大小增加，KV 缓存的内存与带宽开销随之增长。低位（low-bit）量化是降低这些开销的有效手段。
- **问题**：低位 KV 缓存量化会带来模型输出质量下降（语言建模困惑度升高、长上下文检索能力受损），且**质量损失的大小高度依赖模型架构和量化器**。现有大量工作专注于设计更好的量化器/缓存格式（如 KIVI、KVQuant、KVarN 等），但往往针对特定格式优化，通用性有限。
- **研究切入点**：一个关键工程事实是，实际部署时缓存格式往往已被硬件/系统约束固化（如位宽、分组方式、是否对称、是否有残差窗口等）。作者提出一个**不修改缓存格式和量化器**的通用后训练恢复方案：在格式被固定后，通过低秩适配器更新注意力投影矩阵来弥补量化导致的精度损失。
- **核心问题表述**：能否通过一个小规模的训后更新，在工程约束已固定缓存格式的情况下，恢复量化 KV 缓存带来的质量差距？作者进一步追问：恢复语言建模困惑度（PPL）是否等同于恢复长上下文检索等行为能力？

### 2. 论文提出的方法论

论文将问题建模为一种"教师-学生"自我蒸馏框架：教师是使用未量化（浮点）KV 缓存的原始模型，学生是执行打包/增量缓存路径的同一模型，学生附加低秩注意力适配器进行学习。

**核心公式化描述：**
- 对于某一注意力层，投影的定义：Q = HW_Q^T，K = HW_K^T，V = HW_V^T。
- 选定的投影 W（Q、K 或 V），更新方式为标准 LoRA 形式：W‘ = W + α(r)·B·A，其中 A、B 的内维为 r（秩），预训练 W 冻结。
- 可配置适配器放置位置：Q-only、K-only、QK、QKV 四种组合。

**物理增量缓存（训练时前向路径）：**
- 标量仿射分组量化：按 head 维度分组（每组 64），计算分组 scale 和 offset（zero-point），量化后将无符号码、FP16 的 scale 和 offset 打包存储。输入新 token 后，新状态先打包再追加到缓存——训练和推理均不保留原始浮点 KV 副本。
- 对称量化是仿射的一种对照：只有幅度 scale，无 offset。
- 推理时将缓存按 128 token 分块读取，重构后送入标准框架注意力（而非定制低比特内核）。

**量化器兼容性接口：**
- 设 Rφ 为完整的固定缓存通路（编码、元数据、残差/变换状态、重构）。校准中，将 (K,V) 替换为 Rφ(K,V) 后执行学生前向，即可把任意格式的缓存放进训练回路。
- 对硬量化通过直通估计器（STE）传梯度，但实际解码时缓存不保留源激活。
- 对于增强型缓存方法，论文指出三类兼容性：
  - **确定性后处理型**（如 KVQuant 的 outliers 或 GEAR 的 dense–sparse 分解）：若重构可导/可近似，则直接适用；
  - **带状态方法**（如 KVLinC 的循环校正状态）：须视为完整注意力算子整体替换，不能直接用适配器方案。

**注意力直通与校正逻辑：**
- 新追加的重构状态用于 STE：x̂ = x + (x − stopgrad(x)) 形式（即前向为量化重建值，反向等效对原始浮点值求导），使 K/V 适配器有有效梯度路径。Q-only 适配器不需要该特殊通道。
- 损失函数采用前向 KL 散度：L(x) = KL(p_float(·|x) ∥ p_packed(·|x; A, B))。
- 论文用 QK 适配器的分解（三维增量项）说明：Q-only 和 K-only 适配器只能覆盖部分线性增量，QKV 全适配器额外含 V 路径 → 解释为什么联合适配比单投影适配更充分。

**部署开销与会合：**
- 显式适配器推理：增加 r(d_in + d_out) 参数和每 token 的额外两条低秩乘加运算。
- 密集基座模型时 LoRA 可合并（W ← W + BA），理论上无推理额外代价；但论文报告 4-bit NF4 路径（如 Gemma、Llama-3.1）保留显式适配器分支。融合/延迟的墙钟测量不在本文范围内。

### 6. 主要结论与发现

1. **低秩适配器可跨多种量化格式恢复质量**：主结果中 TinyLlama-1.1B（4-bit 仿射）恢复 54.24% ± 2.47% 的 PPL 差；Gemma-4-12B（4-bit 仿射）恢复 75.96% ± 4.04%。两个模型采用不同校准预算与种子，结果是多尺度一致的。
2. **QKV 联合适配是最高效的放置**：无论是 TinyLlama（56.95% 恢复）还是 Llama-3.1-8B（63.21%）都是一致的排序；按参数匹配约束下 QKV > QK ≈ Q > K，绝大多数差异显著。说明 V 路径被此前的 Q-only/QK 范式忽视了。
3. **向真实既定量化器（KIVI/KVarN）转移成功**：在 Llama-3.1-8B 上，KIVI K2V2 恢复 60.42% 的 PPL 差值；KVarN K4V2 恢复 37.61%，两种适配后均保持 NIAH 180 例的高检索保留量。值得注意的是 KVarN 的未适配差距小（0.0439 PPL），因而绝对 PPL 降幅只有 0.0165，但仍有实际改进。
4. **PPL 恢复≠行为恢复**：2-bit 下 rank-48 20M-token 适配器将 PPL 从 576 压到 11.4（接近浮点 10.40，恢复率 99.82%），却只恢复 11–12/180 NIAH 案例（浮点 170/180）。这是最明确的证据：PPL 指标对缓存量化的行为退化不敏感。
5. **恢复效果受操作点强烈影响**：4-bit 适配后 Gemma 的 RULER 宏观均值 48.33 超过浮点 46.15，但单针检索反而下降、变量追踪几乎不能被恢复——恢复是**任务异质**的。
6. **容量-校准存在持续改进趋势**：在 2-bit 下(1.31M–20M token 每个 rank)，提高秩与校准量单调地改善验证 PPL，未出现饱和——说明 2-bit 容量需求仍需更大规模调优（或存在该格式瓶颈）。

### 7. 优点

- **方法定位清晰**：与设计/调优量化器、加残差/细粒度混合等"改缓存结构"路线不同，本方法完全不改变推理时的缓存格式、打包布局和注意力算子，实际部署兼容性好，属"穷则变，变则通"的通用后处理手段。
- **实验设计具有明确的信息分离**：论文明确区分"缓存存储格式"和"适配器质量恢复"两个层面，按 PPL（质量）、恢复率（相对改善）和行为度量（检索能力）分别评估，避免被单一指标的假象欺骗。
- **对照与消融严谨且成本可控**：多阶对照（浮动 vs 打包 vs 适配）、matched-budget 消融（参数总量近似相等），排除了"参数量多所以效果好"的简单解释；3 个种子的主结果提升稳定，2-bit 有 Holm 校正 + 独立集复现，错误发现控制良好。
- **诚实展示评估原理**：明确指出 RULER 仅 200 例不足以支持强统计结论、恢复率的不稳定性（8-bit 121% 的比值是分母趋零所致）、优化器数值非有限跳过等实现细节，支持读者独立判断。
- **叙述了实用的计算复杂度**：显式适配器参数/乘加量列为静态计算代价，且区分可达 LoRA merge（零代价推理）与 NF4 显式分支；避免标准 LoRA 总是零开销的误解。
- **发现本身的科研价值**：2-bit PPL 几乎恢复完全，但检索未恢复的“负向解耦”结果，是对KV量化研究的一个重要边界条件的直接证据。

### 8. 不足与局限

- **模型规模/家族覆盖不够广**：主要结论落在 TinyLlama-1.1B、Gemma-4-12B、Llama-3.1-8B 三个模型上；三个模型都是 decoder-only 通用结构，缺少编码器-解码器、MoE、长上下文专用模型等多元验证。
- **部分关键结果仅单种子**：位置消融（Q vs K vs QK）和 KIVI/KVarN 各只有一个训练运行，不足以估计该条件的方差，也不可直接用于跨量化器比较——论文对此充分声明但毕竟是结论的最弱关节。
- **校准域差异大**：几个模型的校准 token 预算相差一个数量级（TinyLlama 用 1.31M ~ 20M，而 Gemma 是 19.97M）；不同恢复率不能归因于模型/位宽，可能仍受拟合不足的干扰。作者虽声明不打算做跨模型可扩展性结论，但也没有将预算归一化。
- **行为测评范围过窄**：只使用 NIAH 和 RULER 中的 4/13 任务（RULER 有 13 个任务，仅用 200 例），无法覆盖长上下文在真实下游（如多文档摘要、复杂推理、代码理解）上的恢复。
- **缺乏墙钟/内存/能效实测**：论文对计算 MACs/参数有静态分析但无 kernel 融合、批处理 vs 延迟、功耗、吞吐性能测评，所以在硬件部署中的端到端实用性仍是空白。
- **对已固定缓存格式以外的场景**（如新增融合 kernel 的情况）的适用性尚不确定；框架注意力可能有意或无意地掩盖了定制低比特通道特有的误差形态。
- **RULER 宏观报告的误导风险**：宝石 QK 适配使宏观平均值高于浮点，但单针检索下降而变量追踪为 0，说明宏观聚合不足以评估任务的普适恢复。
