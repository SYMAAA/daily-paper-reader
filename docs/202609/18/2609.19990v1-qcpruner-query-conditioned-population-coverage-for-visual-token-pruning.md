## 摘要
多模态大语言模型（MLLMs）中高昂的视觉令牌负载促使人们采用免训练剪枝来减少后续层计算，但在固定预算下，剪枝必须保留与查询相关的证据，同时避免冗余。现有方法对令牌进行排序、使所选子集多样化或优化覆盖，但未使用共享的、针对每个视觉项的查询效用来同时加权视觉目标与候选代表。我们提出 QCPruner，它通过双边效用加权使这两类角色均以查询为条件。利用关键词匹配的查询锚点，QCPruner 将两种跨模态线索融合为效用，并将其应用于基于视觉亲和度的覆盖中的视觉目标与候选代表。由此得到的非负设施选址目标具有单调性和子模性，保留了标准的 (1-1/e) 贪心保证，且无需模型训练或参数更新。在 LLaVA-1.5、LLaVA-NeXT、LLaVA-Video 和 Qwen2.5-VL 上，QCPruner 在每一个报告的令牌预算下，均在所评估的完整系统剪枝方法中取得最高的平均相对性能。在 LLaVA-1.5-7B 上，当使用 576 个令牌中的 32 个时，它保留了未剪枝性能的 96.1%，而评估中最强基线为 93.9%。在 Qwen2.5-VL-7B 上，当使用 1296 个令牌中的 256 个时，对应数值分别为 96.7% 和 92.5%。

## Abstract
The high visual-token load in multimodal large language models (MLLMs) motivates training-free pruning to reduce later-layer computation, but under a fixed budget, pruning must preserve query-relevant evidence while avoiding redundancy. Existing methods rank tokens, diversify selected subsets, or optimize coverage without using a shared per-visual query utility to weight both visual targets and candidate representatives. We introduce QCPruner, which makes both roles query-conditioned through bilateral utility weighting. Using keyword-matched query anchors, QCPruner fuses two cross-modal cues into utility and applies it to both visual targets and candidate representatives within visual-affinity-based coverage. The resulting nonnegative facility-location objective is monotone and submodular, retains the standard (1-1/e) greedy guarantee, and requires no model training or parameter updates. Across LLaVA-1.5, LLaVA-NeXT, LLaVA-Video, and Qwen2.5-VL, QCPruner achieves the highest average relative performance among evaluated complete-system pruning methods at every reported token budget. At 32 of 576 tokens on LLaVA-1.5-7B, it retains 96.1% of unpruned performance, versus 93.9% for the strongest evaluated baseline. At 256 of 1296 tokens on Qwen2.5-VL-7B, the corresponding values are 96.7% and 92.5%.

# QCPruner 论文详细中文总结

## 一、核心问题与研究动机

- **背景**：多模态大语言模型（MLLMs）将图像/视频编码为视觉令牌前缀，与用户指令一起送入 Transformer 处理。标准 LLaVA-1.5 一张图产生 576 个视觉令牌，高分辨率与视频输入则可达数千个，显著增加预填充（pre-fill）计算与激活内存开销。
- **核心矛盾**：在固定最终令牌预算下进行免训练剪枝时，必须在**保留查询相关证据**与**避免冗余**之间取得平衡；仅仅"删得多"并不等于任务性能好。
- **现有方法不足**：
  - 独立注意力/相关性排序：可能保留冗余的相邻 patch；
  - 冗余/多样性导向方法：保留视觉广度，但视觉冗余本身未必能识别当前指令所需证据；
  - 条件 DPP（CDPruner）：耦合指令相关性与子集多样性，但只关注被保留子集及其内部交互，缺乏对更广视觉总体的显式表示；
  - 覆盖式方法（MMTok）：查询感知且群体相对，但将查询作为独立的文本侧目标，而非直接条件化视觉—视觉覆盖。
- **关键研究问题**：上下文查询证据应如何决定"什么值得被覆盖"以及"什么能作为视觉群体内的代表"？
- **论文整体含义**：提出 QCPruner，通过**双边效用加权**让目标与代表两个角色均以查询为条件，在固定预算下提升剪枝后性能保留率。

## 二、方法论

### 1. 核心思想
- 每个视觉令牌具有双重角色：作为**目标（target）**，其效用衡量保留其证据的重要性；作为**代表（representative）**，其效用与亲和度决定它能否可信地代表其他目标。
- 用同一份**查询条件化的逐视觉效用**同时加权目标侧与代表侧，并通过视觉亲和度连接两者，形成查询条件化的群体覆盖目标。

### 2. 关键词匹配的查询锚点（Query Anchors）
- 从用户可见提示中用 **KeyBERT** 提取至多 6 个排名内容 unigram 关键词。
- 用 MLLM 分词器将每个关键词重新分词，并在原始提示中作为连续子序列匹配，保留所有匹配位置（含重复出现），得到锚点位置集合 $I_{anc}$（基于位置而非 token ID，以处理被切分为多个子词的关键词）。
- 若无关键词匹配，则确定性回退到排除特殊令牌、视觉占位符与已知模板片段后的用户内容位置。

### 3. 双线索查询条件化效用估计（在第 ℓ 层后钩子处）
- **相似度语义线索**：对锚点 $t_j$ 与视觉令牌 $v_i$ 的隐藏状态做余弦相似度，取对锚点的最大值聚合：$r^{sim}_i = \max_{j \in I_{anc}} (\bar{h}^{t}_j)^\top \bar{h}^{v}_i$。最大聚合避免强锚点特定相关性被平均稀释。
- **查询—键对齐线索**：使用 softmax 前的头平均缩放点积 $A_{j,i} = \frac{1}{H}\sum_h \frac{(q^{(h)}_j)^\top k^{(h)}_i}{\sqrt{d_h}}$，同样取最大值：$r^{attn}_i = \max_{j \in I_{anc}} A_{j,i}$。注意这是 pre-softmax 对齐分数，而非注意力概率。
- **线索融合**：对每个视觉令牌的分数向量做 min–max 归一化（$\epsilon = 10^{-6}$），等权平均后再归一化：
  $u = \mathrm{Norm}\left( \frac{\mathrm{Norm}(r^{sim}) + \mathrm{Norm}(r^{attn})}{2} \right)$。等权设计避免引入数据集特定融合系数。

### 4. 查询条件化群体覆盖
- **效用校准（utility floor）**：$\hat{u}_i = \rho + (1-\rho) u_i$，$\rho \in [0,1]$。$0 \le \rho < 1$ 时保持排序、压缩效用差距；$\rho = 0$ 禁用下限，$\rho = 1$ 退化为纯视觉覆盖（诊断端点）。每个骨干族在独立校准数据上选一次并冻结。
- **非负视觉亲和度**：$c_{i,j} = [\cos(h^v_i, h^v_j)]_+$，负相似度视为无覆盖而非负证据。
- **查询加权边**：$w_{i,j} = c_{i,j} \hat{u}_i \hat{u}_j$，其中 $\hat{u}_i$ 加权目标价值，$\hat{u}_j$ 加权代表适配性。
- **覆盖目标（双边加权设施选址）**：
  $F(K) = \sum_{i=1}^{N_v} \hat{u}_i \max_{j \in K} c_{i,j} \hat{u}_j$，其中 $cover_i(K) = \max_{j \in K} w_{i,j}$，$cover_i(\varnothing)=0$。外层目标权重决定每个目标对目标的贡献，内层决定代表 j 代表目标 i 的能力；max 防止多个代表对同一目标重复加分。
- **贪心边际增益选择**：$\Delta(k|K) = \sum_{i=1}^{N_v} [w_{i,k} - cover_i(K)]_+$。目标级边际增益随集合增长不增，总和具有递减回报；加上空集零覆盖与非负边权，$F$ 归一化、单调、子模，**保留标准 $(1-1/e)$ 贪心保证**（针对代理目标而非下游精度）。从空集开始迭代加入最大边际增益候选，更新覆盖为逐元素 max，直到 $|K|=K$。

### 5. 实现要点
- 剪枝位置：在第 7 层后、第 8 层前（基于 MMStar 校准数据选定，跨骨干、预算、测试集迁移）。
- 视频：在每帧内以相同逐帧预算独立求解，不做跨帧自适应分配；保留帧网格换行符。
- 稠密亲和矩阵下直接实现为 $O(N_v^2)$ 内存、$O(KN_v^2)$ 最坏选择时间。
- 全程免训练、无参数更新。
