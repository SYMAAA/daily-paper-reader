## 摘要
多模态大语言模型（MLLMs）由于依赖数百个视觉token来表示图像，因而会产生大量的计算开销。尽管token剪枝已成为降低MLLMs推理成本的一种有前景的方法，但现有方法通常使用稀疏或连续位置嵌入为保留的token重新分配位置嵌入，二者分别引入了不同的局限。稀疏位置嵌入往往会降低分配给视觉token的注意力值，从而削弱MLLMs的感知能力；而连续位置嵌入会破坏视觉token原有的空间对应关系，导致其定位能力减弱。为缓解这一问题，我们对语言解码器进行逐层分析，并观察到中间层在token剪枝下对维持MLLMs的定位能力起着关键作用。基于这一观察，我们提出一种层感知位置嵌入策略，该策略在定位敏感层切换为稀疏位置嵌入，而在其他层保持连续位置嵌入。在代表性剪枝方法和多样化基准上的大量实验表明，与标准稀疏和连续位置嵌入相比，我们的方法提升了剪枝后MLLMs的综合多模态性能。

## Abstract
Multimodal large language models (MLLMs) incur substantial computational overhead due to the reliance on hundreds of visual tokens to represent images. While token pruning has emerged as a promising approach to reduce the inference cost of MLLMs, existing methods typically reassign position embeddings to the retained tokens using either sparse or continuous position embeddings, each introducing distinct limitations. Sparse position embeddings tend to decrease the attention value allocated to visual tokens, thereby degrading the perception capability of MLLMs, whereas continuous position embeddings disrupt the original spatial correspondence of visual tokens, leading to weakened grounding capability. To mitigate this issue, we perform layer-wise analysis of the language decoder and observe that intermediate layers play a critical role for maintaining the grounding capability of MLLMs under token pruning. Based on this observation, we propose a layer-aware position embedding strategy, which switches to sparse position embeddings at grounding-sensitive layers while maintaining continuous position embeddings elsewhere. Extensive experiments across representative pruning methods and diverse benchmarks demonstrate that our approach improves the comprehensive multimodal performance of pruned MLLMs compared with standard sparse and continuous position embeddings.

# 论文总结：Layer-Aware Position Embeddings for Visual Token Pruning in MLLMs

## 1. 核心问题与研究动机

- **背景**：多模态大语言模型（MLLMs）依赖大量视觉 token 表示图像（如 LLaVA-1.5 用 576 个，InternVL3.5 高分辨率下可达数千个），视觉 token 主导输入序列长度，成为推理效率的主要瓶颈。视觉 token 剪枝（training-free）因此成为主流加速手段，分为 **pre-LLM 剪枝**（进入 LLM 前删冗余 token）与 **intra-LLM 剪枝**（在 LLM 层内动态删 token）。
- **被忽视的关键点**：现有剪枝方法几乎只关注"删哪些 token"，却忽视了**保留 token 的位置嵌入如何重新分配**。由于 MLLM 普遍采用 RoPE，注意力对 token 间相对距离敏感，这一设计直接决定剪枝后性能。
- **两种策略的两难**：
  - **稀疏位置嵌入**（保留剪枝前的原始索引）：维持空间对应关系，但引入大索引间隙 → RoPE 相对距离增大、注意力衰减 → **文本对视觉 token 的注意力下降，感知能力受损**（MME 从 1370 降至 1325）。
  - **连续位置嵌入**（把保留 token 重索引为连续序列）：位置连续、注意力保持，但破坏原始空间对应 → **定位能力崩塌**（RefCOCO testA 从 30.4 降至 3.9）。
- **核心问题**：能否在保留感知所需的位置连续性的同时，恢复定位所需的空间对应关系？论文的回答是：**按解码器层分工**——只在"定位敏感层"使用稀疏嵌入，其余层保持连续嵌入。

## 2. 方法论

### 2.1 理论铺垫（RoPE）
- 位置信息通过旋转算子注入 query/key：`q_m = R(m)W_q x_m`，`k_n = R(n)W_k x_n`。
- 注意力 logit 仅依赖相对距离：`z_{m,n} = (W_q x_m)ᵀ R(n−m) W_k x_n / √d_h`。
- 依据 RoPE 的衰减性质，归一化项随相对距离 |m−n| 增大而衰减 → 稀疏嵌入造成的大间隙会系统性压低视觉 token 的注意力上界（论文给出对应上界公式 (4)）。

### 2.2 现象验证（实证分析）
- 在 LLaVA-1.5-7B 上用 FastV（intra-LLM）与 CDPruner（pre-LLM）做对比，保留 64 / 128 token（11.1% / 22.2%）。
- 结论：**任务依赖的权衡**——TextVQA 上连续嵌入稳定更优，RefCOCO 上稀疏嵌入稳定更优；pre-LLM 剪枝（CDPruner）比 intra-LLM 更敏感；剪枝越激进差距越大。
- 注意力可视化（1000 条 TextVQA 样本）：连续嵌入在多数层给出更高的"文本→视觉"注意力总和，解释了感知优势的来源。

### 2.3 定位敏感层标定（Grounding Layer Calibration）
- 做法：以"全部层用连续嵌入"为基线，**逐层单独**把第 l 层换成稀疏嵌入，测定位精度相对变化：
  `Δ_l = (Acc^sparse_l − Acc^cont) / Acc^cont × 100%`。
- 发现：从第 7 层起定位精度急剧提升（相对提升 > 400%），在后续层间波动，约到第 21 层后增益趋于消失；该趋势在不同剪枝方法与不同保留比例下一致，说明是 MLLM 的**内在属性**而非剪枝配置的偶然产物。
- 定义 `L_gs`（首次显著提升层）到 `L_ge`（增益趋于零前最后一层）的区间为**定位敏感层集合 G**。

### 2.4 层感知位置嵌入策略
- 分配规则：
  - `p(l) = p_sparse`，当 `l ∈ G`（定位敏感层，恢复空间对应）；
  - `p(l) = p_cont`，当 `l ∉ G`（其余层，保持位置连续性、维持视觉注意力）。
- 实现细节：敏感层之前的层把 system token、保留视觉 token、文本 token 统一重索引为连续序列；敏感层内改用剪枝前原始索引；之后切回连续。
- 特点：**training-free**，不修改模型参数、不改变剪枝流程本身，可直接套用于 pre-LLM 与 intra-LLM 两类剪枝方法。
- 附录给出的标定结果：LLaVA-1.5-7B（32 层）取 7–21；LLaVA-1.5-13B（40 层）取 8–13；InternVL3.5-8B（36 层）取 4–26。

## 6. 主要结论与发现

- **核心发现**：MLLM 的**中间解码层**在剪枝条件下对维持视觉定位能力至关重要，且该层间敏感模式在不同剪枝方法、不同保留比例下高度一致。
- **策略有效性**：层感知位置嵌入在所有评测的剪枝方法下都取得最高的平均精度与相对性能，且提升覆盖感知、知识推理、关系理解与定位四类能力，而非仅利于某一类任务。
- **代表数字**：
  - LLaVA-1.5-7B + CDPruner（保留 128 token）：平均精度 54.6%，保留原模型 **98.2%** 的性能，比稀疏嵌入高 4.4%（精度）/7.9%（相对性能），比连续嵌入高 13.3%（相对性能）。
  - LLaVA-1.5-13B + DivPrune：平均 57.1%，比连续高 1.9%、比稀疏高 8.3%；CDPruner 下 MMstar coarse-perception 达 60.4%（连续 56.0%、稀疏 52.4%）。
  - InternVL3.5-8B + DivPrune（保留 25% token）：平均 61.8%，保留原模型 88.7%，比连续高 12.5%（精度）/19.4%（相对性能）；VSR 上甚至超过原模型 1.6%。
- 总体结论：稀疏与连续位置嵌入**都不是全局最优**，按层分工能在不牺牲推理

效率的前提下同时保住感知与定位能力，为"位置嵌入重分配"这一被长期忽视的维度提供了一个即插即用的解决方案。

- **机制层面的解释**：敏感层区间（如 LLaVA-1.5-7B 的 7–21 层）恰好落在视觉特征与文本特征开始深度交互的中层，此时稀疏索引带来的原始空间坐标对 grounding 类任务具有不可替代的语义价值；而更浅层（特征尚未充分混合）与更深层（已进入语言生成阶段）则更依赖位置连续性带来的注意力强度。这一"中层负责空间、两端负责流畅"的分工，构成了论文对现象的核心解释。
- **对"位置嵌入是否重要"的回答**：在 25% 甚至 11.1% 的极端保留率下，位置嵌入方案带来的差异可达 10 个百分点以上，量级与换一个剪枝算法相当，说明其并非可忽略的实现细节，而是与"选哪些 token"同等重要的设计变量。

## 7. 局限性与批判性审视

- **理论层面偏薄**：论文用 RoPE 的衰减性质解释了"稀疏 → 注意力下降"，但对"为什么恰好是中间层对定位敏感"仅给出定性推测，缺少注意力头级别、表征相似度（如 CKA）或探针实验的机制性证据；`L_gs`/`L_ge` 的判定依赖人工设定的"显著提升"阈值，边界存在主观性。
- **标定成本未摊销**：方法虽 training-free，但每个新模型、每种剪枝强度都需要一次逐层扫描（32 层即 32 次完整 RefCOCO 评测）来定位 G。论文未讨论该区间能否跨剪枝方法、跨保留比例甚至跨模型规模迁移复用——若不能，则实际部署前的前置开销不可忽略。
- **敏感层区间缺乏敏感性分析**：G 的宽度（15 层 vs 更窄/更宽）、边界偏移 ±k 层、只用单层或全部层用稀疏嵌入等设置均未做消融，无法判断该区间是"宽松有效"还是"精确必需"。
- **任务覆盖偏向定位**：标定信号完全来自 RefCOCO，而 RefCOCO 是短文本指代任务，与长链推理、多轮对话中的空间指代存在分布差异；对视频、多图、文档等场景的泛化性未知。
- **对比基线不完整**：Related Work 中提到的 Restore、IVC-Prune、Grounding-Aware Token Pruning 等同样关注剪枝后位置/空间信息保持的工作未纳入实验对比，削弱了"本文是更优解"的说服力。
- **评测粒度较粗**：MMstar 仅取 coarse-perception 子集，VSR 仅用 zero-shot split，且缺少对生成质量（如幻觉率、POPE）与效率指标（TTFT、吞吐、显存）的实测，而后者恰恰是剪枝研究的立身之本。

## 8. 启示与可迁移性

- **"位置嵌入"应成为剪枝方法的标准报告项**：论文表明，同一剪枝算法在连续/稀疏/层感知三种嵌入下的成绩差异足以改变方法间的排名结论，因此后续剪枝工作若不声明位置处理方式，其对比结果的可比性存疑。
- **分层异质设计思路可外推**：既然不同层对"空间保真"与"注意力强度"的偏好不同，类似的层感知策略也可能适用于其他模态压缩场景（如长视频 token 的时序索引、长文本 KV 压缩中的位置重映射）。
- **工程价值明确**：实现上仅需在指定层区间切换索引方式，不触碰权重、不改变剪枝流程，可直接封装进现有推理框架（如 LLaVA 的 token merge 管线），落地门槛低。

## 9. 总体评价

论文抓住了视觉 token 剪枝中被普遍忽略的一环——保留 token 的位置嵌入如何重新分配，并给出一个干净、低成本的解法。其最大贡献不在于算法复杂度，而在于**把一个隐式的实现细节显式化为可优化变量**，并通过跨模型、跨剪枝范式、跨任务类型的系统实验证明其重要性。核心结论（连续嵌入利于感知、稀疏嵌入利于定位、按层分工可兼得）清晰且与直觉一致，实验设计在广度上令人信服。

主要短板集中在深度：机制解释偏定性、敏感层区间的消融缺失、标定开销与迁移性未讨论、效率收益未量化。这些不足并不动摇结论方向，但限制了该工作从"有效技巧"上升为"可解释原理"的高度。
