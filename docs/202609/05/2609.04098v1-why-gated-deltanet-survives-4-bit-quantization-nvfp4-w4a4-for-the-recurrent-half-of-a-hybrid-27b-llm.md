## 摘要
混合大语言模型将softmax注意力与线性注意力层（如门控DeltaNet，GDN）配对，后者的循环状态以固定大小总结上下文。早期社区对Qwen3.8-27B（48层GDN，16层注意力）的4比特量化将GDN块保留为8位或16位精度——尤其是其衰减和写入强度门——直觉是递归中的误差会在长上下文上累积。我们通过构建Minima来检验这一直觉：对所有496个线性层采用NVFP4 W4A4，包括GDN。在4K/32K的困惑度、MMLU-Pro、GSM8K、AIME'25、GPQA-Diamond、LiveCodeBench以及RULER检索达64K的实验中，Minima在种子噪声内与BF16匹配（5任务平均-0.52），同时是我们比较的选项中最小（17.5 GiB）且预填充最快（+14-19%）的方案，其32K困惑度差距随位置而缩小。一项四部分机制研究解释了原因：（i）NVFP4的16元素块缩放将残差流的极端异常值局部化，使激活误差在各层角色间均衡；（ii）据称脆弱的门投影最不敏感——softplus/指数和sigmoid参数化将约11%的GEMM误差压缩到约2%的输出误差；（iii）delta规则递归在32K token上将注入噪声保持在平坦平台，并在数百步内遗忘状态脉冲，因为每次写入沿当前键方向覆盖状态；（iv）每token量化成本随上下文增加而消散，而非复合。我们还修复了当按模块校准的NVFP4检查点由将这些模块融合为单个GEMM的内核服务时出现的全局尺度不匹配，并显示校准的FP8 KV缓存尺度无性能损失。结果：一个实用的方案——量化一切，携带KV尺度——以及一个机制解释，说明为什么混合大语言模型的循环半部分是易于量化的那一半。检查点：https://huggingface.co/minima-ai/mnma_qwen3.8_27b_nvfp4

## Abstract
Hybrid LLMs pair softmax attention with linear-attention layers such as Gated DeltaNet (GDN), whose recurrent state summarizes the context in fixed size. Early community 4-bit quantizations of Qwen3.8-27B (48 GDN layers, 16 attention layers) left the GDN block in 8- or 16-bit precision -- especially its decay and write-strength gates -- on the intuition that errors in a recurrence accumulate over long contexts. We test that intuition by building Minima: NVFP4 W4A4 on all 496 linear layers, GDN included. Across perplexity at 4K/32K, MMLU-Pro, GSM8K, AIME'25, GPQA-Diamond, LiveCodeBench, and RULER retrieval to 64K, Minima matches BF16 within seed noise (5-task average -0.52) while being the smallest (17.5 GiB) and fastest-prefill (+14-19%) recipe we compare, and its 32K perplexity gap shrinks with position. A four-part mechanism study explains why: (i) NVFP4's 16-element block scaling localizes the residual stream's extreme outliers, equalizing activation error across layer roles; (ii) the supposedly fragile gate projections are the least sensitive -- softplus/exponential and sigmoid parameterizations compress ~11% GEMM error to ~2% output error; (iii) the delta-rule recurrence holds injected noise at a flat plateau over 32K tokens and forgets a state impulse within hundreds of steps, because each write overwrites the state along the current key direction; (iv) the per-token quantization cost washes out with context instead of compounding. We also repair a global-scale mismatch that arises when per-module-calibrated NVFP4 checkpoints are served by kernels that fuse those modules into one GEMM, and show calibrated FP8 KV-cache scales are performance-free. The result: a practical recipe -- quantize everything, ship KV scales -- and a mechanistic account of why the recurrent half of a hybrid LLM is the easy half to quantize. Checkpoint: https://huggingface.co/minima-ai/mnma_qwen3.8_27b_nvfp4

## 一、论文的核心问题与研究动机

- **背景冲突**：当前前沿开源模型正走向"混合架构"（hybrid LLM）——如 Qwen3.8-27B 的 64 层中，48 层为 Gated DeltaNet（GDN）线性注意力，只有 16 层为全 softmax 注意力。在模型服务成本压力下，4-bit weights-and-activations（W4A4）推理（NVFP4 格式）已成为实际目标。
- **社区保守直觉**：GDN 通过固定大小的循环状态（delta-rule 递归 $S_t = \alpha_t S_{t-1} + \beta_t k_t (v_t - S_{t-1}^\top k_t)^\top$）跨数万 token 携带上下文。因此社区在量化 Qwen3.8-27B 时，普遍将 GDN 块（尤其是控制衰减的 $a$ 门和控制写入强度的 $b$ 门）保留在 FP8/BF16 甚至更高精度，理由是"递归中每步量化误差会随长上下文累积，门控误差累积最快"。
- **论文核心问题**：这一直觉是否正确？论文通过构建 **Minima**——真实全量 NVFP4 W4A4 量化（496 个线性层全部含 GDN）——并配合系统性机理分析，论证该直觉对这类架构是**反的**：混合 LLM 中"循环半边反而是容易量化的半边"。

## 二、方法论

### 1. 量化方案（Minima）
- 格式：NVFP4 = E2M1 4-bit 数值 + 每 16 元素一块的 E4M3 scale（设为 blockmax/6）+ 每张量一个 FP32 global scale。
- 范围：**全部 496 个线性层**（240 个 GDN 投影、64 个 attention、192 个 MLP）做 W4A4；仅 lm_head、embedding、卷积、norm 保持在 BF16。
- 校准：冻结的 128 样本 × 32K token 校准集，llm-compressor 后训练量化（PTQ）。
- 关键修复 ①：**全局尺度失配**——llm-compressor 按单模块校准 FP32 global scale，而 vLLM 将 GDN 投影融合（qkv+z 一组、b+a 一组）为一个 GEMM 并按最大值取 scale，导致在 48 层中产生 1.82×/2.75× 的权重误标定。修复方法：将融合组改写为共享 global scale、把比率折入 E4M3 block scale。
- 关键修复 ②：**KV cache 校准 scale**——对 16 个 attention 层的 FP8 KV cache 增加静态逐张量校准 scale（Minima+scales，即发布的检查点）。

### 2. 机理研究的四步链（均基于捕获的真实 BF16 激活 + NVFP4 fake quantization）
1. **输入统计**：捕获 4×32K token（48 个 GDN 层），分析 max/RMS、峰度、1-hot block 占比、A4/W4 相对误差。
2. **逐投影敏感性重放**：每次只量化一个投影（96 次重放，8K token），测量对层输出 $y$ 的影响，并与全量化对照。
3. **递归误差传播**：lockstep FP32 双轨运行——一条干净轨迹 + 11 条受扰轨迹，32K token、5 个层深；另做单次 1% 状态脉冲注入实验与合成噪声（对 $\alpha$/$\beta$ 直接加噪）对照。
4. **端到端位置分解**：将 32K 样本的逐 token NLL 按 2K 窗口切分，分离权重量化代价（Minima−BF16，KV 精度一致）与 KV 压缩代价（FP8−BF16 KV）。

### 3. 关键发现机制
- 门控参数化 $g_t = -\exp(A^{\log})\,\mathrm{softplus}(a_t+dt\_bias)$、$\alpha_t=e^{g_t}$、$\beta_t=\sigma(b_t)$ 中的 softplus/exponential/sigmoid **压缩**了约 11% 的 GEMM 误差到约 2% 的输出误差。
- delta rule 的**写入覆盖**机制：每次写入沿当前 key 方向重写状态，主动擦除旧误差；1% 状态脉冲在 80–1382 步内衰减到 $1/e$，远快于衰减门隐含的 44K–62K 步视界（对比实验说明直接对 $\alpha$ 加 0.1% 噪声会产生 22% 状态误差，量化 $a$ 预激活却只有 3.6%）。
