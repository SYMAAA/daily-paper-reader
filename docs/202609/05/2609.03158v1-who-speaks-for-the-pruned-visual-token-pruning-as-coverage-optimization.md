## 摘要
视觉令牌剪枝降低了视觉语言模型（VLM）的推理成本，但大多数方法只关注保留哪些令牌。这种保留令牌的视角可能会保留冗余的高分令牌，同时使被丢弃的证据没有紧密的代表。我们提出了CoverPruner，一种无需训练的剪枝器，它从互补的需求侧角度提问：当某个令牌被移除后，哪个幸存的原始令牌能够为目标VLM代表它？CoverPruner将剪枝形式化为表示覆盖最大化（RCM），通过查询加权需求覆盖完整的投影视觉令牌集。它利用投影器空间覆盖和轻量级第一层注意力探针实现了RCM。在多种VLM架构和压缩率下，CoverPruner在所有对比方法中取得了最佳平均准确率，且最大的提升通常出现在激进压缩情况下。

## Abstract
Visual token pruning reduces the inference cost of vision-language models (VLMs), but most methods only ask which tokens to keep. This retained-token view can keep redundant high-scoring tokens while leaving discarded evidence without a close representative. We propose CoverPruner, a training-free pruner that asks the complementary demand-side question: after a token is removed, which surviving original token represents it for the target VLM? CoverPruner formulates pruning as Representational Coverage Maximization (RCM), covering the full projected visual-token set with query-weighted demand. It instantiates RCM with projector-space coverage and a lightweight first-layer attention probe. Across multiple VLM architectures and compression rates, CoverPruner achieves the best average accuracy among all compared methods, with the largest gains usually appearing under aggressive compression.

## 1. 核心问题与整体含义（研究动机与背景）

视觉语言模型（VLM）将图像编码为大量视觉 token，注意力机制随序列长度呈平方级增长，因此视觉 token 数量成为推理成本的主导因素。视觉 token 剪枝通过在推理时仅保留少量 token 来降低开销，但现有方法大多站在"幸存者视角"，只问"应该保留哪些 token"：

- 这类方法容易保留冗余的高分 token，同时让被剪掉的、可能承载关键证据的区域（如小号文字、图表标签、上下文区域）没有一个紧密的代表。
- Token 合并方法虽然降低冗余，但融合后的表示会稀释细粒度证据；既有集合级方法提出了多样性/覆盖/查询引导，但未在目标 VLM 自身的投影空间中定义覆盖。

论文的整体含义是：剪枝不仅是"哪些 token 活下来"，更要回答需求侧问题——"当一个 token 被删除后，应该由哪个幸存的原始 token 为它在目标 VLM 中代言？"

为此作者提出 CoverPruner，一个**免训练**的剪枝器，将剪枝形式化为**表示覆盖最大化（RCM）**：用查询加权的需求覆盖完整的投影视觉 token 集合。该方法在多种 VLM 架构和压缩率下取得了最佳平均精度，且在激进压缩时优势最大。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想

- 将剪枝视为**集合覆盖问题**，而不是独立 token 排序问题。
- 一个保留 token 的价值不在于自身得分有多高，而在于它能覆盖当前集合尚未覆盖的视觉需求。
- 相似度在投影器输出空间（即视觉 token 进入语言模型前的输入空间）计算，查询需求通过 LLM 第一层注意力估计，无需外部定位模型或训练参数。

### 2.2 关键技术细节

**（1）表示覆盖最大化（RCM）**
- 对每个 token i，在保留集 S 下的覆盖定义为：
  cov(i, S) = max_{j∈S} sim(v_i, v_j)，其中 sim 为余弦相似度。
- 总体目标是最大化加权总覆盖：
  f(S) = Σ_{i=1}^{n} w_i · max_{j∈S} sim(v_i, v_j)，其中 w_i ≥ 0 是 token i 的需求权重，|S| = m。
- 由于该目标是非负、单调子模的，贪心算法可达到 (1 − 1/e) 的近似保证。

**（2）锚定在消费该 token 的 LLM 中**
- **相似度的 LLM 空间选择**：在投影器输出空间 V = g(f_v(X)) 中计算相似度，因为投影后的空间才是解码器实际消费的表示；两个补丁在视觉编码器空间中未必近邻，但在投影后可能成为"可替代"证据。
- **相似度矩阵校准**：原始投影 token 间的余弦相似度动态范围有限，容易导致覆盖增益被均匀膨胀。作者对相似度矩阵做行方向的均值中心化：
  M̃_ij = M_ij − (1/n) Σ_k M_ik
  然后取非负值 A_ij = max(0, M̃_ij)，即低于图像内平均相似度的匹配不提供覆盖。这样可让贪心算法更好地区分冗余 token 和新颖 token。
- **查询相关性的第一层注意力探针**：使用解码器第一层的输入 LayerNorm 和 W_Q/W_K，以用户指令文本位置作为查询、视觉 token 位置作为键，计算缩放点积注意力，并对指令位置和注意力头取平均得到每个视觉 token 的相关性 r_i：
  r_i = (1/|T_q|H) Σ_{t∈T_q} Σ_{h=1}^{H} α^{(0,h)}_{t,i}
  随后经 min-max 归一化到 [0,1]，再经指数温度变换：
  w_i = e^{τ·r̃_i}，默认 τ=0.3；τ=0 时退化为均匀覆盖。

**（3）需求加权覆盖选择**
- 定义当前被覆盖量 c_i = max_{j∈S} A_ij。
- 每一步贪心选择使边际覆盖增益最大的 token：
  k* = argmax_{k∉S} Σ_i w_i · max(0, A_ik − c_i)
- 选择后更新 c_i ← max(c_i, A_ik*)，直至 |S| = m。
- 保留原始 token 顺序，将保留序列喂入**未修改**的解码器，不进行合并或表示改动。

**（4）算法流程（见论文 Algorithm 1）**
1. 预处理：得到文本指令 token、视觉 token 位置和指令位置；计算 V。
2. 计算覆盖矩阵 M，行中心化并裁剪得到 A。
3. 用第一层注意力探针获得 r_i，转换为需求权重 w_i。
4. 初始化 S=∅, c_i=0；循环按边际增益选择 k*，直到满足预算 m。
5. 按原始顺序返回保留 token，与指令 token 拼接后送入解码器。

## 6. 主要结论与发现

1. **覆盖视角优于排名视角**：将同一相关性信号从排序器改为覆盖需求权重，可显著恢复性能；单独排名会集中在少数查询相关区域，导致大面积图像未表示。
2. **CoverPruner 在不同骨干和压缩率上均取得最高平均精度**：在 LLaVA-1.5-7B 上保留 32 token 时相对精度 93.7%，领先最强基线约 3.1 个点；在 LLaVA-NeXT-7B 和 Qwen2.5-VL 上也保持一致优势。
3. **压缩越激进，覆盖方法优势越大**：在中等预算下各方法差距缩小，激进预算下分布集中型排序方法和合并方法容易失效，集合式覆盖优势凸显。
4. **应将剪枝理解为集合构造问题**：查询相关性以"分配需求"的形式发挥作用，而不是作为单个 token 得分。
5. **效率优势明显**：在 LLaVA-NeXT-7B 上，CoverPruner 将 prefill 时延降低 7.5 倍、解码时延降低 2.6 倍、FLOPs 降低 10.7 倍，同时 F1 还提升了（86.8→87.3）。

## 7. 优点

- **问题定义创新**：将剪枝从"幸存者重要性"重构为"被剪 token 的需求覆盖"，更符合实际推理中的信息损失问题。
- **训练免、即插即用**：无需任何训练或额外模型，不需要外部定位或 CLIP 监督，可直接用于多个 VLM 架构。
- **信号取样于消费侧 LLM**：相似度取自投影空间，需求用第一层注意力探针估计，避免了代理不对齐的问题；单个配置跨模型/数据集泛化。
- **理论与算法清晰**：与子模最大化结合，有 (1−1/e) 近似保证，贪心步骤具有明确边际收益解释。
- 实验覆盖度广，压缩率跨度大，并且提供可视化分析与被剪错误案例，形成较完整论证。

## 8. 不足与局限

- **无法用于闭源/API 模型**：需要访问投影器视觉 token 与早期解码器信号，不适用于仅提供 API 的商业多模态模型。
- **细粒度敏感任务存在风险**：当答案依赖小目标、OCR 细节、精确计数、空间关系等局部证据时，覆盖面并不必然能代表真语义替代，作者亦承认该局限。
- **相似度矩阵复杂度**：两两相似度随 token 数平方增长，虽在当前分辨率下可行，更高分辨率或视频输入需更细致的工程优化。
- **视频场景未覆盖图片级剪枝**：视频冗余既含空间也含时间，直接应用到全部视频 token 可能过度表示持久背景而忽略短暂事件；论文仅讨论局限，没有相应实验。
- **单次剪枝、不随时间更新**：CoverPruner 在解码前一次性选择 token，不能适应多步推理、对话或长生成中视觉需求动态变化。
- **评测公平性与偏差风险**：基线方法参数采用其默认/公开配置，未逐方法进行同一强度校准；结果通常是平均值，最高增益集中在 POPE 等覆盖敏感任务，对 OCR/文本任务提升较小。
- 附录负面案例也显示在 POPE 上存在由于小目标/模糊目标导致错误判断的情况，说明覆盖并不能保证所有粒度证据的替代关系。
