## 摘要
免训练的视觉 Token 剪枝通常将 Token 重要性、冗余度或相关选择准则作为安全移除的代理指标。我们表明，仅凭这些信号并不能完全刻画可移除性；可移除性同时取决于表示深度与周围的删除集合。受控干预实验表明，在不同深度移除相同 Token 会对下游造成显著不同的扰动；而在固定深度下仅改变删除上下文，也会改变候选边际与剪枝边界决策。这些发现表明，仅靠 Token 重要性无法确定一个 Token 何时可被安全移除，也无法确定其在联合删除下可移除性如何变化。受此观点启发，我们提出 CoRePrune，一个免训练的两阶段框架。渐进式扰动感知视觉剪枝（Progressive Perturbation-Aware Visual Pruning）随着视觉表示的演化刷新删除效应；而集合条件精炼（Set-Conditioned Refinement）在视觉-文本交互后，在当前删除集合下重新评估候选挽救收益。在涵盖标准图像、高分辨率输入和视频的五种多模态大语言模型骨干上，CoRePrune 在激进的 Token 预算下仍能保持性能。在 Qwen3.5 上，最终预算为 128 个视觉 Token 时，它保留了稠密模型 90.3% 的性能，同时将总预填充时间减少 51.0%。

## Abstract
Training-free visual-token pruning often uses token importance, redundancy, or related selection criteria as proxies for safe removal. We show that these signals alone do not fully characterize removability, which is conditioned on both representation depth and the surrounding deletion set. Controlled interventions demonstrate that removing the same tokens at different depths produces substantially different downstream perturbations, while changing only the deletion context at a fixed depth alters candidate marginals and pruning-boundary decisions. These findings show that token importance alone cannot determine when a token is safely removable or how its removability changes under joint deletion. Motivated by this perspective, we propose CoRePrune, a training-free two-stage framework. Progressive Perturbation-Aware Visual Pruning refreshes deletion effects as visual representations evolve, while Set-Conditioned Refinement reevaluates candidate rescue benefits under the current deletion set after visual--text interaction. Across five multimodal large language model backbones covering standard images, high-resolution inputs, and video, CoRePrune preserves performance under aggressive token budgets. On Qwen3.5, with a final budget of 128 visual tokens, it retains 90.3% of dense-model performance while reducing aggregate prefill time by 51.0%.

## 1. 核心问题与研究动机

- **背景**：MLLM 将图像/视频编码为视觉 Token 序列与文本联合处理。提高分辨率、切图（tiling）、增加视频帧数可提升视觉覆盖，但单次 prompt 的视觉 Token 可达数百至数千，显著加重 prefill 阶段的注意力与前馈计算。
- **现有范式**：免训练（training-free）压缩因其可作用于冻结模型、无需校准数据或参数更新而受青睐。已有方法依据注意力、显著性、相似度、冗余度或视觉-文本相关性在语言模型之前或解码器内部剪枝。
- **核心质疑**：论文指出 **Token 重要性 ≠ 可移除性（removability）**。重要性只描述当前表示下的属性，而可移除性关注"删除该 Token 所引发的扰动"，后者还取决于：
  - **表示深度（representation depth）**：同一 Token 在不同层被删除，扰动差异显著；
  - **删除集合（deletion set）**：固定深度下，某候选的边际效应依赖于"哪些 Token 已被同时删除"。
- **整体含义**：剪枝问题应从"哪些 Token 看起来不重要"转为"在什么条件下它们可被安全移除"，固定的 Token-wise Top-K 排序无法刻画联合删除决策。

## 2. 方法论（CoRePrune）

### 2.1 形式化基础（沿用 CAOTE 的注意力输出扰动视角）
- 单头注意力输出 $Y^{\ell}_{hq}=\sum_j a^{\ell}_{hqj}V^{\ell}_{hj}$；删除集合 $S$ 后注意力被 $1-M^{\ell}_{hq}(S)$ 重归一化。
- 删除引发的扰动为 $-\frac{\sum_{i\in S}a^{\ell}_{hqi}(V^{\ell}_{hi}-Y^{\ell}_{hq})}{1-M^{\ell}_{hq}(S)}$，据此定义 **集合失真** $D^{\ell}(S;Q)$。
- 单 Token 分数 $d^{\ell}(i;Q)$ 同时包含注意力质量与 value 偏差，而非仅注意力。
- **条件挽救边际** $\Delta^{\ell}_i(S;Q)=D^{\ell}(S;Q)-D^{\ell}(S\setminus\{i\};Q)$，显式依赖当前删除集合 $S$——这是全文的理论支点。

### 2.2 Stage 1：渐进式扰动感知视觉剪枝（Progressive Perturbation-Aware Visual Pruning）
- **目标**：将 $N_0$ 个架构对齐的候选（patch、2×2 合并单元或帧内 Token）压到中间预算 $K_V$。
- **调度**：在视觉编码器多个深度 $\ell_1<\dots<\ell_T$ 上采用均匀线性调度 $N_t=N_0-\text{round}(t(N_0-K_V)/T)$。
- **关键操作**：每一步**用当前层的表示重新计算**单 Token 删除分数 $d^{\ell_t}(i;I_{t-1}\setminus\{i\})$，移除最低分的 $N_{t-1}-N_t$ 个，保留原始空间/时序顺序。
- **设计意图**：直接回应"深度条件可移除性"——删除效应随表示演化而刷新，避免早期估计过期。

### 2.3 Stage 2：集合条件精炼（Set-Conditioned Refinement）
- **位置**：LLM prefill 中，视觉-文本交互发生后（零基第 7 层之后、第 8 层之前），复用同一 prefill 的注意力张量，无额外前向。
- **流程**：以问题 Token 位置 $Q$ 为接收者，初始化 $S_0=C$（全部视为虚拟删除），按当前删除集合计算 $\Delta_i(S_t)$，每轮**挽救边际最大**的 $B=4$ 个候选，直到保留 $K_L$ 个。
- **增量更新**：删除集统计量 $M_{hq}$、$R_{hq}$ 逐轮做减法更新，避免重算。
- **复杂度**：$O\!\left(H|Q|d_h K_V\lceil K_L/B\rceil\right)$；批量化把条件重评分轮数从 $K_L$ 降到 $\lceil K_L/B\rceil$。$B=1$ 即顺序反向贪心。
- **特点**：两阶段均**免训练、免校准、无参数更新**，且物理缩短序列（非掩码），真正节省后续计算。

- **漂移传播**：删除扰动沿层放大（L+1 → L+8 的下游漂移单调增加），这从机制上解释了"越晚删除越安全"，也说明在浅层做不可逆决策的代价最高。

## 7. 与现有方法的主要对比结果

- **精度**：在匹配最终保留预算 $K_L$ 的条件下，CoRePrune 在 5 个骨干的绝大多数操作点上取得最高 Avg. Rel.，并在多个"激进预算"档位（如 LLaVA-1.5 的 64/32 Token、LLaVA-Video 的 1024 Token）上相对次优方法拉开较明显差距——低预算区间正是固定单 Token 排序失效最严重、集合条件收益最大的区域。
- **与 QCPruner† 的关系**：QCPruner† 作为精度导向参照在部分设置下接近或略高，但 CoRePrune 在同等精度下保留的 Token 更少/运行更快；两者定位不同（前者偏精度上限、后者偏精度–效率前沿）。
- **效率**：由于物理缩短序列而非掩码，prefill 时间与峰值显存随 $K_L$ 近似单调下降；在 1500 样本 × 16 解码步的计时协议下，CoRePrune 相比稠密基线取得显著的 prefill 加速，且 Stage 2 复用同一 prefill 的注意力张量、无额外前向，因此其开销主要体现为少量评分计算而非一次完整前向。
- **视频场景**：在 10816 → 4096/2048/1024 的大幅压缩下，CoRePrune 相对帧级固定预算方法与 FastVID 的全局分配策略仍保持优势，说明深度–集合双条件化在长序列、跨帧冗余强的场景中收益更明显。
- **稳定性**：跨 20+ 个 matched-budget 操作点上，CoRePrune 相对各基线的成对比较在多数配置中全胜，且不同骨干上的结论方向一致，降低了"单一模型/单一基准调参"的偶然性风险。

## 8. 论文的主要贡献归纳

1. **概念层面**：明确提出并论证"Token 重要性 ≠ 可移除性"，把剪枝从"逐 Token 打分排序"重构为**双条件（深度条件 + 删除集合条件）的可移除性判定**问题。
2. **理论层面**：基于注意力输出扰动与条件挽救边际 $\Delta_i(S)$，给出可计算、可增量维护的集合条件化目标函数，并沿用/扩展了 CAOTE 的扰动视角。
3. **方法层面**：提出免训练、免校准的两阶段框架 CoRePrune——Stage 1 渐进式扰动感知剪枝（刷新深度条件）+ Stage 2 集合条件精炼（批量集合贪心挽救），并给出 $O(H|Q|d_hK_V\lceil K_L/B\rceil)$ 的复杂度控制。
4. **实证层面**：在 5 个骨干、图像与视频共 10+ 基准、20+ 操作点上验证有效性；并通过固定身份只变深度、固定深度只变集合的干净对照，以及 24 组端点控制与 16 组 persistent-low 控制，把增益归因到设计动机本身，而非显著性漂移或超参调优。

## 9. 局限与批判性评价

- **诊断基准覆盖面有限**：深度/集合条件的机制性诊断集中在 MME、TextVQA，样本规模（如 2,374 个 MME 样本）与任务多样性不足以完全排除基准特异性；建议扩展到 OCR、图表、多图、长视频等更异质的任务。
- **跨实现一致性风险**：部分基线（尤其 QCPruner†）结果引自先前研究，代码实现、prompt 模板、tokenizer 与评测脚本差异可能引入不可忽略的偏差；理想做法是统一重实现或至少在附录给出可复现配置。
- **超参与调度依赖**：Stage 1 的深度端点 $\ell_1..\ell_T$、中间预算 $K_V$、Stage 2 的插入层（第 7/8 层之间）与 $B$ 均需按骨干调整，论文虽给出扫描但未提供自动选择准则，迁移到新模型仍需少量试调。
- **理论假设**：扰动度量建立在单头注意力输出重归一化之上，隐含"注意力输出偏差可代表信息损失"的假设；对依赖跨层残差流、MLP 记忆或位置编码的语义损失刻画不完整。
- **效率评估边界**：仅单张 48 GB Ada 单卡、1500 样本 × 16 步的计时协议，缺少长上下文、高并发、批处理动态 shape、KV-Cache 复用等真实服务场景的吞吐评估；也未涉及 70B 级或 MoE 骨干的资源表现。
- **与 token merging / 结构重参数化类方法的对比缺失**：论文主要对标剪枝类方法，未与合并（merging）、蒸馏式压缩或量化联合方案比较，因此"物理缩短序列"的效率优势在更激进的压缩栈中是否仍成立尚不清楚。

## 10. 一句话结论

论文把视觉 Token 压缩从"看起来不重要就删"推进到"在什么深度、与谁一起删才安全"，用条件挽救边际统一了深度条件与集合条件，并以免训练的 CoRePrune 在多个骨干与预算档位上兑现了这一视角的精度–效率收益。
