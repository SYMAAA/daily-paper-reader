## 摘要
大型视觉-语言模型（LVLMs）由于其长且高度冗余的视觉令牌序列而承担了大量的推理成本。基于多样性的剪枝通过基于成对余弦相似度选择令牌子集来缓解这一成本。然而，我们发现原始视觉令牌之间的相似度强烈集中在正范围内，限制了它们区分非冗余令牌的能力。改进这种分辨率的一种自然方法是在计算余弦相似度之前对令牌特征进行居中。居中确实揭示了更丰富的成对结构，但单独使用时却意外地降低了剪枝性能。我们表明，这种明显的矛盾之所以出现，是因为原始几何结构不仅仅代表成对多样性：它还隐式地偏好全局独特的令牌，这些令牌往往包含语义信息丰富的内容。居中更好地解析了子集多样性，但失去了这种有用的令牌级偏好，揭示了多样性和独特性在原始几何结构中是纠缠在一起的。基于这一分析，我们提出了居中几何剪枝器（Cen-Prune），它使用居中的余弦相似度来衡量子集多样性，同时保留原始空间中的独特性作为互补的令牌级偏好。这种轻量级、即插即用的校正不改变底层选择机制，且计算开销可忽略不计。在多个图像和视频理解基准以及LVLM架构上的大量实验表明，Cen-Prune在现有的基于多样性的剪枝器中提供了稳健的整体性能改进。

## Abstract
Large vision-language models (LVLMs) incur substantial inference costs due to their long and highly redundant visual-token sequences. Diversity-based pruning mitigates this cost by selecting token subsets based on pairwise cosine similarity. We find, however, that similarities between raw visual tokens are strongly concentrated in the positive range, limiting their ability to distinguish non-redundant tokens. A natural way to improve this resolution is to center token features before computing cosine similarity. Centering indeed reveals a substantially richer pairwise structure, yet unexpectedly degrades pruning performance when used alone. We show that this apparent contradiction arises because the raw geometry does more than represent pairwise diversity: it also implicitly favors globally distinctive tokens, which tend to contain semantically informative content. Centering better resolves subset diversity but loses this useful token-wise preference, revealing that diversity and distinctiveness are entangled in the raw geometry. Based on this analysis, we propose the \textbf{Cen}tered Geometry \textbf{Prune}r (Cen-Prune), which measures subset diversity using centered cosine similarity while retaining raw-space distinctiveness as a complementary token-wise preference. This lightweight, plug-and-play correction leaves the underlying selection mechanism unchanged and incurs negligible computational overhead. Extensive experiments across multiple image- and video-understanding benchmarks and LVLM architectures demonstrate that Cen-Prune provides robust improvements in overall performance across existing diversity-based pruners.

## 2. 论文提出的方法论

### 2.1 核心思想

Cen-Prune 的核心在于**将多样性与独特性分置到互补的几何空间中**：

| 信号 | 几何空间 | 作用 |
|------|----------|------|
| 子集多样性 | 中心化特征空间 | 提供角度对比，避免令牌间冗余 |
| 令牌独特性 | 原始特征空间 | 区分全局非冗余、语义重要的令牌 |

### 2.2 关键技术细节

**（1）中心化几何（用于子集多样性）**

- 对图像内所有视觉令牌计算均值向量： μ = (1/N) Σⱼ xⱼ
- 中心化： x̄ᵢ = xᵢ − μ
- 构建中心化余弦相似度矩阵： S̄ᵢⱼ = ⟨x̂̄ᵢ, x̂̄ⱼ⟩，其中 x̂̄ᵢ 为归一化残差方向
- 中心化将共同方向移除，使相似度分布从集中正区间扩展到包含大量负值的宽范围，使选择器能够直接优化残差方向上的角度分离，从而实现“纯多样化”。

**（2）原始空间独特性分数（用于令牌级偏好）**

- 定义： gᵢ = −(1/(N−1)) Σⱼ≠ᵢ Sᵢⱼ（即该令牌与其余令牌的负平均余弦相似度）
- 几何解释：该分数与 ‖x̂ᵢ − m‖² 单调相关（m 为归一化特征的均值），高 gᵢ 表示该令牌远离图像共享的普遍特征模式，即全局独特
- 分数按图像进行 min–max 归一化（LLaVA架构）或 z-score + sigmoid 归一化（Qwen2.5-VL架构），得到 g̃ᵢ ∈ [0,1]

**（3）集成到现有选择器的公式**

- **Max–min 选择（DivPrune/ZOO-Prune）**：在贪心选择的每一步中，将独特性作为乘性权重：

  i\* = arg maxᵢ∉T  g̃ᵢ · minₛ∈T  Dᵢₛ

  其中 Dᵢₛ = 1 − S̄ᵢₛ（基于中心化距离）

- **Determinantal 选择（CDPruner）**：将独特性乘入原有 relevance 分数并替换核矩阵：

  L_Cen = diag(r̃ ⊙ g̃) · S̄ · diag(r̃ ⊙ g̃)

  其中 r̃ 为原有指令相关性分数，⊙ 为逐元素乘法

**（4）Qwen 特化的标准化中心化**

- 针对 Qwen2.5-VL 中少数维度主导方差的问题（单个维度占 98.9% 中心化方差），先对特征按维度方差归一化（Y = V·diag(σ)⁻¹），再进行中心化，消除端点集中现象，将 |cos|>0.9 的令牌对比例从 74.6% 降至 0.008%。

## 6. 论文的主要结论与发现

1. **原始视觉令牌几何高度集中**：成对角度中位数 72°，平均余弦相似度 0.3663，仅 2.3% 负相似对，现有选择器本质上只做“去重”而非“多样化”。
2. **中心化能揭示残差多样性但单独使用有损性能**：中心化后相似度分布大幅拓宽，但纯多样化选择的子集缺乏对独特令牌的偏好，导致下游任务性能下降。
3. **多样性与独特性在原始几何中纠缠**：原始几何在有限的多样性分辨率之外，还隐式地偏好全局独特的令牌（表现为更高的 [CLS] 注意力权重）。
4. **Cen-Prune 解缠两种信号可获得一致改进**：将中心化余弦相似度用于多样性、原始空间独特性分数用于令牌偏好，两者互补。
5. **即插即用且开销可忽略**：在 64 令牌保留设置下，Cen-Prune 与 DivPrune 的延迟差异仅约 0.3ms，FLOPs 完全一致；同时保持 1.99 倍 prefill 加速、1.67 倍端到端加速和 76.3% FLOPs 削减。
6. **跨架构稳健泛化**：在 LLaVA 系列（1.5/NeXT/Video）、Qwen2.5-VL 上均取得一致性能提升，例如 LLaVA-NeXT-7B 在 88.9% 剪枝率下保留 96.1% 性能，Qwen2.5-VL 在 90% 剪枝率下将 DivPrune 的保留性能从 85.1% 提升至 88.9%。

- **性能下降的基准未深入分析**：在某些基准上（如 LLaVA-1.5 的 MME、POPE 等个别分数），Cen-Prune 强化后反而有细微下降（如 POPE 从 81.7 降至 82.8 后个别设置下降），论文未对这类退化做深入归因。
- **评估资源报告不完整**：虽说明使用了 4 块 A6000，但未报告总

但未报告总 GPU 小时数、各基准条目的详细推理耗时与峰值内存绝对值，效率分析仅给出缩减比例，且未提供代码仓库链接，制约了复现成本评估与横向参考价值。此外，Cen-Prune 在选择器中的乘性融合方式缺乏理论上的最优性论证；对中心化与独特性分数的归一化策略（min–max vs. z-score+sigmoid）依赖经验选择，未说明在何种特征分布下应使用何种归一化；极端剪枝率（如保留 32 令牌）下的性能急剧下降现象也未做归因分析，可能导致边界场景应用受限。

## 9. 总体评价

本文通过严谨的几何诊断揭示了一个长期被忽视的问题——原始视觉令牌特征的余弦相似度分布过度集中，从根本上限制了多样性剪枝器的分辨能力，并进一步发现原始几何中多样性与独特性相互纠缠这一深层矛盾。对应的 Cen-Prune 方法以轻量、无训练、即插即用的方式同时解决两个信号的分置与融合，在图像、视频、多分辨率、动态分辨率等多种设定下均取得一致改进，兼具学术洞察与工程实用性。尽管在统计严谨性、理论深度与资源报告完整性上仍有提升空间，但其分析方法和解决思路为视觉令牌剪枝乃至更广泛的 token 稀疏化研究提供了全新的视角。若未来能补充更多模型规模、更细粒度误差分析，并探索可学习的融合策略，该方法的价值将进一步放大。
