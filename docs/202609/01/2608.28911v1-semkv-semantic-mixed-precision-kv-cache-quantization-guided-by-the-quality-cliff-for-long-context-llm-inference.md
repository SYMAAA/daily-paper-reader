## 摘要
键值（KV）缓存是长上下文大语言模型（LLM）推理的主要内存瓶颈，随上下文长度线性增长。我们表明，在分数位网格上的均匀KV量化不会优雅地降级：在预设的多种子统计协议下，采用仿射量化器的Llama-3.1-8B-Instruct在低至2.322码位/值时与FP16 KV在统计上不可区分，并在2.0位时崩溃——这一出现在(2.0, 2.322]区间内的质量悬崖在生成时量化和多轮对话中重现，并迁移到Mistral-7B。该悬崖重新定义了重要性感知混合精度：在悬崖之上，八个模型内部重要性指标在统计上是可互换的，因此混合的益处在于网格插值，能够达到均匀量化无法实现的平均精度。SemKV保留每个token，根据模型内部评分对token排序，并分配两个相邻的悬崖以上精度，实现了实测6.0倍的存储缩减，且与完整KV（n=900，三个种子）相比无统计可检测的质量差异，同时优于拥有1.5倍更大内存预算的FP16 token剪枝。将仿射基础替换为失真优化量化器（TurboQuant-MSE）在所有测试协议中都降低了悬崖，将无可检测损失的工作点提高到7.9倍。方法：针对目标部署环境测量悬崖，然后在其上方进行插值。

## Abstract
The key-value (KV) cache is the dominant memory bottleneck of long-context large language model (LLM) inference, growing linearly with context length. We show that uniform KV quantization on a fractional-bit grid does not degrade gracefully: under a prespecified multi-seed statistical protocol, Llama-3.1-8B-Instruct with an affine quantizer is statistically indistinguishable from FP16 KV down to 2.322 code bits/value and collapses at 2.0 bits - a quality cliff in (2.0, 2.322] that reappears in generation-time quantization and multi-turn dialogue and transfers to Mistral-7B. The cliff reframes importance-aware mixed precision: above it, eight model-internal importance indicators are statistically interchangeable, so the benefit of mixing is grid interpolation, reaching average precisions uniform quantization cannot realize. SemKV preserves every token, ranks tokens by a model-internal score, and assigns two adjacent above-cliff precisions, achieving a measured 6.0x storage reduction with no statistically detectable quality difference from full KV (n=900, three seeds), and outperforming FP16 token pruning granted a 1.5x larger memory budget. Replacing the affine base with a distortion-optimized quantizer (TurboQuant-MSE) lowers the cliff in every protocol tested, raising the no-detectable-loss operating point to 7.9x. The recipe: measure the cliff for the target deployment setting, then interpolate above it.

### 研究动机与背景
- **KV缓存内存瓶颈**：在长上下文LLM推理中，KV缓存随上下文长度线性增长，成为GPU内存的主要瓶颈，直接制约了可服务的批处理规模和上下文预算。
- **现有方法的局限性**：
  - **均匀量化**：对所有token采用相同比特宽度，忽略了token间的语义差异；且在分数比特网格上，质量并非平滑下降，而是在某一点突然崩塌。
  - **删除/剪枝方法**：移除被认为不重要的token，存在丢失长上下文推理所依赖的关键证据token的风险。
  - **重要性感知混合精度**：已有方法（如MiKV、QAQ等）虽考虑token重要性，但未系统回答"如何选择精度水平而不跨越质量边界"这一核心问题。
- **核心观察**：论文从一个实证发现出发——均匀KV量化在分数比特网格上存在**质量悬崖**：在(2.0, 2.322]比特区间内，模型输出质量从统计上无损突然崩塌，并伴随失控生成（runaway generation）现象。这一发现重新定义了混合精度量化的意义：混合精度的价值不在于在悬崖之上"保护重要token"（此时所有指标都无差别），而在于**在悬崖之上的网格点之间进行插值**，达到均匀量化无法实现的平均精度。

## 2. 论文提出的方法论

### 核心思想
SemKV是一个**全token保留的混合精度KV缓存量化框架**，其核心操作规则是：**先测量目标部署环境下的质量悬崖，再在悬崖之上进行精度插值**。

### 关键技术细节

**（1）质量悬崖的离线映射（Cliff Mapping）**
- 在分数比特网格（如 log₂5≈2.322、log₂6≈2.585 bits）上对均匀量化进行系统扫描
- 采用预指定的多种子统计协议，将每个网格点与全精度FP16 KV进行配对统计检验
- 通过检查相邻网格点之间的差异，定位质量悬崖——即两个相邻网格点之间退化急剧增加、且方向在多个种子中一致的区间
- 悬崖位置是（模型、基础量化器、评估协议、上下文预算构成）的属性，与单个输入无关

**（2）语义重要性评分**
- 默认指标为**隐藏状态delta范数**（公式3）：
  \[s_i = \frac{1}{m}\sum_{l=L-m+1}^{L} \|h_i^{(l)} - h_i^{(l-1)}\|_2\]
- 采用最后m层（实验中m=4）的表示变化量作为token语义重要性的代理指标
- 指标是**可插拔模块**，论文系统评估了四个家族的8种模型内部指标：
  - 隐藏状态家族：delta范数、最终层范数、坐标方差、余弦delta
  - KV范数家族：key范数、value范数
  - 逻辑家族：自信息（−log pθ(xi|x<i)）
  - 注意力家族：累积注意力接收量
  - 随机选择作为无信息基线
- 得分仅通过prompt内的排序进入方法，无需归一化

**（3）token级混合精度分配**
- 计算重要性分数后，选取前r比例的token作为高精度token（公式4-5）：
  - H = TopK({si}, K)，其中K = ⌊rT⌋
  - bi = bhigh（若i∈H），否则bi = blow
- 精度对(bhigh, blow)由离线悬崖映射确定，选择悬崖之上的两个相邻网格点（实验中为2.585/2.322 bits，r=25%，平均2.39 bits）
- 分配完全由top-r排序实现，无需估计分数阈值

**（4）量化方案**
- 使用整数级标量量化 + Hadamard旋转
- 分数比特宽度对应非2的幂的级别数（如2.322 = log₂5个级别）
- token级精度分配在所有层和KV头上广播，不在头维度分配比特

**（5）生成token的块精确延迟量化**
- 生成token的分数逐个到达，无法预先知道完整分布，因此采用块精确延迟方案（块大小B=64）：
  - 新生成的token先以全精度追加到缓存，仅收集其重要性分数
  - 每积累B个token，在块内选择分数最高的round(rB)个token量化为bhigh，其余为blow
  - 每个生成回合结束时，对残余部分块应用相同规则
  - 保证规定的高精度比例构造成立，消除阈值估计
- 最近少于B个token的块在解码期间临时保持FP16

**（6）全token保留性质**
- 与剪枝方法（P⊂I, |P|<|I|）不同，SemKV满足ISemKV = I，即保留所有token，仅调整每个token的精度

## 6. 论文的主要结论与发现

### 核心结论
1. **质量悬崖的存在与位置**：在仿射量化器下，Llama-3.1-8B在(2.0, 2.322]比特区间存在质量悬崖；该悬崖在生成侧和多轮对话中重现，并迁移到Mistral-7B（但其深度依赖种子和任务）

2. **悬崖内部不可安全导航**：混合2.322/2.0 bits即使在75%保护比例下仍显著退化；且悬崖内部，重要性集中的保护不如随机分散的保护——退化是广泛分布而非局限于少量证据token

3. **悬崖上插值的有效性**：SemKV在2.39平均比特下（25% token在2.585 bits，75%在2.322 bits）达到6.0×存储缩减，质量与全精度KV在统计上不可区分；8种指标全部等价（结构效应）

4. **删除vs低精度保留**：FP16剪枝（4.0-bit等效内存预算）崩塌至0.065-0.149，而SemKV（2.39 bits，更小1.5倍的内存）与全KV无差异；随机剪枝与指标剪枝无差异，表明**删除本身**是失败主因

5. **生成token的可操作点**：2.322 bits生成与FP16在统计上不可区分，且降低最大长度终止率；任何包含2.0 bits分量的配置都显著退化

6. **指标质量在悬崖下才重要**：在标准工作点上指标无关紧要；当低比特侧位于悬崖之下时（3.0/2.0 bits），指标出现清晰排序，且某些指标（hidden-norm、key-norm）差于随机

7. **基础量化器决定悬崖位置**：TurboQuant-MSE将悬崖从(2.0, 2.322]下移至(1.585, 2.0]（预填充和多轮）和(1.0, 1.585]（生成侧），SemKV的混合机制不变地组合，在1.9码位（有效2.025 bits）实现7.9×压缩且统计不可区分

8. **多轮对话存在残余地板**：全缓存多轮量化在两种量化器下都存在小的悬崖上残余赤字（TurboQuant下小2.5倍），且对更高比特不敏感，选择达到天花板但无法超越

## 7. 优点

- **方法论亮点**：
  - **质量悬崖概念**：从一个简洁的实证观察出发，重新定义了混合精度量化的目的——从"保护重要token"转为"在悬崖之上的网格间插值"，具有理论指导意义
  - **操作规则清晰**：先测量悬崖，再在悬崖上插值——这一配方可迁移到不同模型、不同量化器
  - **全token保留**：从根本上避免删除带来的证据丢失风险，保持注意力图完整
  - **块精确延迟量化**：为生成token提供了构造性、无阈值估计的混合精度方案

- **实验设计亮点**：
  - **统计严谨性**：预指定多种子协议、配对检验、Bonferroni校正、item级稳健性验证——在KV量化文献中较为少见
  - **系统性消融**：8种指标×4个家族×3种子的全面消融，证明了平坦区间的指标无关性
  - **公平对比**：给剪枝方法更大内存预算、同次运行包含锚点、分享全KV基线、记录实现细节
  - **多层次验证**：从悬崖映射到插值、生成侧、多轮、跨模型、跨量化器、压力测试，形成完整的证据链
  - **明确区分**：n.s.与"无损"的区分、统计分辨率限制的诚实报告

## 8. 不足与局限

- **硬件资源未透明**：未报告GPU型号、数量、训练/推理耗时等具体信息，可复现性受限
- **压力测试样本量小**：悬崖下指标排序实验仅10个对话×3种子，被作者标注为方向性证据而非确定性结论
- **剪枝对比的局限性**：是受控的结构性基线（单一指标、无recency window），并非对工程化驱逐系统（H2O、SnapKV等）的基准对比
- **多轮对话残余地板未解决**：两种量化器下均存在无法消除的小型悬崖上赤字，其通过对话文本复合的解释是推断而非直接消融验证
- **TurboQuant迁移覆盖面有限**：仅测试了Llama，未在其他骨干上验证TurboQuant基础下的结论
- **TurboQuant实现为复现**：原始论文未明确之处（异常通道选择、旋转共享）由本文自行决策，可能引入偏差
- **存储测量为微基准**：假设混合基数打包布局，而非经过优化的融合内核；实际系统级性能可能不同
- **悬崖位置的可变性**：上下文预算构成会影响悬崖位置（4k预算下2.322 bits也退化），增加了部署时的测量要求
- **统计分辨率限制**：n=900下95% CI约±0.011，更小的真实赤字无法被检测到，只能报告为n.s.
- **悬崖深度依赖种子和任务**：位置稳定但深度不稳定，使得跨设置的量化比较需要仔细的统计控制
