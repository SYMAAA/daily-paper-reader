## 摘要
流式视频理解要求在持续增长的视觉流上、于任意时刻回答问题。核心挑战在于紧凑地记忆长期历史，同时有效地检索与问题相关的证据。我们提出了动态轴辐式记忆（D-HSM），一种无需训练的框架，将较远的历史表示为结构化文本记忆，同时保留最近帧作为视觉标记，用于细粒度感知。具体而言，D-HSM 将选定的历史视频片段转换为类型化文本观察，并将其存储在以实体为中心的轴辐式记忆中，其中实体作为枢纽，相关证据作为辐条。在回答问题时，D-HSM 动态检索一个紧凑的、感知问题的记忆子集，通过轴辐式链接扩展该子集，并将其与最近的视觉窗口结合，用于冻结 VLM 的答案预测。在流式视频和长视频基准上的大量实验表明，D-HSM 持续且显著地提升了 VLM 骨干网络，并优于其他最先进的在线和离线视频理解基线。

## Abstract
Streaming video understanding requires answering questions at arbitrary times over a continuously growing visual stream. The central challenge is to compactly remember long-range history while effectively retrieving question-relevant evidence. We propose Dynamic Hub-and-Spoke Memory (D-HSM), a training-free framework that represents distant history as structured textual memory while preserving the recent frames as visual tokens for fine-grained perception. Specifically, D-HSM turns selected historical video chunks into typed textual observations and stores them in an entity-centered hub-and-spoke memory, with entities as hubs and related evidence as spokes. When answering a question, D-HSM dynamically retrieves a compact question-aware memory subset, expands it through hub-and-spoke links, and combines it with the recent visual window for frozen-VLM answer prediction. Extensive experiments on both streaming and long video benchmarks show that D-HSM consistently and substantially improves VLM backbones and outperforms other state-of-the-art online and offline video understanding baselines.

- **现有方法的不足**：现有在线/流式方法多从 token 预算角度出发，通过稀疏采样、视觉 token 压缩、缓存或检索视觉表征来压缩历史。但这些方法主要回答“应该保留哪些视觉单元”，而没有明确解决“保留后的历史应该如何表示和组织”的问题。
- **本文的核心观点**：作者通过诊断实验发现，将历史片段转换为文本描述比直接拼接历史视觉 token 更有效，这表明文本语义痕迹是紧凑记忆历史的有力形式。同时，不同问题对历史证据的需求不同——实时类问题往往只需近期帧，回溯类问题则必须依赖历史。因此，一个理想的记忆系统不仅要结构良好，还要能根据问题动态调整检索量。
- **论文提出方案**：提出 **D-HSM（Dynamic Hub-and-Spoke Memory）**，一种无需训练的框架，将长期历史组织为以实体为中心的轴辐式文本记忆，同时保留近期帧作为视觉 token，并在回答问题时动态检索和扩展问题相关的记忆子集，与近期视觉窗口结合后输入冻结的 VLM 进行答案预测。

## 二、方法论

### 1. 总体框架
- 维护一个文本记忆 \(M_t\) 累积历史信息。
- 在时间步 \(t\)，历史块 \(h_t\) 被转换为类型化文本观察 \(z_t\)，并增量融入记忆：\(z_t = \phi_{obs}(h_t),\ M_t = U(M_{t-1}, z_t)\)。
- 当问题 \(q_t\) 到达时，动态检索证据子集 \(C_t = R(M_t, q_t)\)，并与近期视觉窗口 \(r_t\) 一起送入冻结 VLM：\(a_t = f_{VLM}(C_t, r_t, q_t)\)。

### 2. 记忆构建与更新
- **动态历史观察预算**：
  - 候选历史块为 \(H_t=\{h_1,\dots,h_t\}\)。
  - 当 \(t \le B\) 时使用全部；当 \(t > B\) 时通过近似均匀采样选择 \(B\) 个块，即 \(S_t = H_t\) 或 \(S_t = \Pi_B(H_t)\)。
  - 增量增补集 \(\Delta_t^+\) 和移除集 \(\Delta_t^-\) 用于更新观察；被移除块支持的证据会从记忆中删除。
- **结构化文本观察**：
  - 对每个选中块，使用固定 schema 的 prompt 让冻结 VLM 生成六个字段：`OBJECTS`、`PEOPLE`、`ACTIONS`、`OCR-TEXT`、`SPATIAL`、`EVENT`。
  - 实体使用局部标识符（如 O1、P1），跨块依据视觉描述相似度合并为持久身份。
- **实体中心轴辐式记忆更新**：
  - 实体作为 hub，来自 ACTION/OCR/SPATIAL/EVENT 等证据作为 spoke，附属于相应实体。
  - 更新规则包括：实体链接（余弦相似度阈值 \(\tau_{link}\)）、spoke 插入与合并、同块实体共现边、同一实体动作的时间顺序边（next-action chain）、基于支持块集合的记忆移除。
  - 每个 hub/spoke 记录时间戳和出现次数，便于时间定位。

### 3. 动态检索
- **问题自适应选择**：
  - 使用关键词门控，对明确针对当前状态的问题（如含有 now、currently 等）跳过记忆检索。
  - 对历史相关问题，计算问题与记忆条目的余弦相似度，经过阈值 \(\theta\) 和最大预算 \(K\) 得到候选排序列表。
  - 通过检测最大相似度间隙实现动态截断：计算相邻分数差 \(\Delta_i = s_i - s_{i+1}\)，若最大间隙同时满足置信度自适应阈值 \(\gamma_t = \max(\lambda_0, \lambda_1 [s_1-\theta]_+)\) 和 \(2 \times\) 中位数间隙，则以该点为截断点；否则回退到全量候选。
- **轴辐式扩展**：
  - 对选中的实体 hub，扩展其附带 spoke、同块共现实体，以及同一实体相邻的动作链。
  - 时间感知问题额外检索时间戳事件。
  - 最终将证据线性化为实体档案、屏幕文本、事件时间线、计数聚合等文本块，与近期帧和问题一起输入冻结 VLM。

## 六、主要结论与发现

- D-HSM 在流式基准上显著超越现有 SOTA：StreamingBench 上 Qwen2.5-VL 从 73.7 提升到 84.7，Qwen3-VL 达到 85.4，超过 Gemini 1.5 Pro 和 Streamforest 分别约 9.7 与 8.1 分。
- 在 OVO-Bench 上，D-HSM 在 Real-Time、Backward 和 Forward 三类任务上均取得有竞争力的结果，证明其能根据问题类型动态决定是否依赖历史。
- 在离线长视频基准上（LongVideoBench 60.7、MLVU 67.3、VideoMME 63.9），D-HSM 也优于多个开源长视频模型，说明其作为紧凑长时表示具有通用性。
- 消融显示：
  - 近期帧和结构化历史记忆互补，两者结合最佳。
  - 类型化观察和实体中心组织优于扁平字幕。
  - 动态检索优于固定 top-k，能减少无关历史干扰。
  - 中等历史预算（20 chunks）和检索预算（K=12）效果最好，过多反而引入噪声。
- 记忆质量人工评估表明 hub-spoke 记忆在实体链接和 spoke 附着上具有较高的可靠性。

## 七、优点

- **无需训练、即插即用**：完全冻结 VLM，可灵活适配不同骨干，易于部署。
- **结构化记忆设计**：以实体为中心的 hub-spoke 组织形式使长历史紧凑且可解释，便于跨时间聚合与定位证据。
- **动态检索机制**：通过关键词门控和统计显著间隙检测实现问题自适应检索，避免固定预算带来的信息冗余或缺失。
- **实验系统全面**：覆盖流式与离线、专有与开源、在线与离线多种对比，并辅以消融、人工质量评估和效率分析。
- **效率可控**：记忆更新和检索开销很低，瓶颈主要在冻结 VLM 的观测与答案生成，符合流式场景需求。

## 八、不足与局限

- **依赖 VLM 生成质量**：结构化观察由冻结 VLM 生成，实体识别、OCR、动作描述的错误会传播到记忆中。
- **文本化丢失细节**：长期历史以文本存储，距离较远的细粒度视觉信息可能被压缩丢失。
- **实体链接误差**：实体链接准确率约 77%，存在合并不同实体或拆分同一实体的情况，影响记忆质量。
- **动态截断的风险**：动态截断依赖相似度分布中的明显间隙，若问题证据分散或相似度平滑则可能退化为全量检索。
- **评估范围有限**：主要基于 7B/8B 开源 VLM，未在更大规模模型（如 72B）上验证；人工质量评估样本量较小（30 视频、100 对等），可能存在偏差。
- **超参数敏感性**：历史预算、检索预算、最近帧数等对性能有明显影响，需要根据场景调参，但在文中提供了较系统的分析。
- **失败案例分析**：最大错误来源是答案合成（31%），其次是观测生成（23%）和检索（19%），说明在证据选择与生成阶段仍有改进空间。
