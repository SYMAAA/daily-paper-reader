## 摘要
视觉前缀在多模态大语言模型（MLLMs）的逐层计算中占据主要部分，因此视觉 token 剪枝是加速推理的一种直接方法。现有的 top-K 方法通常独立评估 token，并对所有输入采用统一预算，忽视了选择相关的交互以及样本间视觉复杂度的变化。与之相反，我们提出 StepPrune，将视觉 token 剪枝形式化为一个自适应序贯决策过程。以先前选中的 token 和文本上下文为条件，StepPrune 逐步构建保留子集，并通过学习到的 STOP 动作自动确定其大小。在训练期间，一个保持方差的噪声门为离散选择过程提供了可微代理，而在推理期间，未选中的 token 会在语言模型预填充之前被物理移除。分组选择机制进一步将 StepPrune 扩展到高分辨率输入。在 LLaVA-1.5、LLaVA-NeXT、Qwen2.5-VL 和 InternVL3 上的实验表明，StepPrune 在 LLaVA-1.5、Qwen2.5-VL 和 InternVL3 上的所有评估剪枝率下均实现了最佳的平均归一化性能保留率，同时在 LLaVA-NeXT 显著更长的 AnyRes 前缀上仍具有竞争力。在 LLaVA-1.5 上，StepPrune 在剪枝 88.9% 的视觉 token 的同时，保留了全前缀归一化性能的 94.6%。当平均保留数量为 64 时，StepPrune 将预填充延迟从 59.95 ms 降至 40.05 ms，相当于 1.50 倍的预填充加速。

## Abstract
Visual prefixes account for a major portion of the per-layer computation in multimodal large language models (MLLMs), making visual-token pruning a direct approach to accelerating inference. Existing top-K methods typically evaluate tokens independently and apply a uniform budget to all inputs, overlooking both selection-dependent interactions and variations in visual complexity across samples. In contrast, we propose StepPrune, which formulates visual-token pruning as an adaptive sequential decision process. Conditioned on previously selected tokens and textual context, StepPrune progressively constructs the retained subset and automatically determines its size through a learned STOP action. During training, a variance-preserving noise gate provides a differentiable surrogate for the discrete selection process, whereas during inference, unselected tokens are physically removed before language-model prefill. A grouped selection mechanism further extends StepPrune to high-resolution inputs. Experiments across LLaVA-1.5, LLaVA-NeXT, Qwen2.5-VL, and InternVL3 show that StepPrune achieves the best average normalized performance retention across all evaluated pruning rates on LLaVA-1.5, Qwen2.5-VL, and InternVL3, while remaining competitive on the substantially longer AnyRes prefixes of LLaVA-NeXT. On LLaVA-1.5, StepPrune retains 94.6% of the full-prefix normalized performance while pruning 88.9% of the visual tokens. At a mean retained count of 64, StepPrune reduces prefill latency from 59.95 ms to 40.05 ms, corresponding to a 1.50x prefill speed-up.

# StepPrune 论文总结

## 1. 核心问题与整体含义

- **研究背景**：在多模态大语言模型（MLLM）中，图像以"视觉前缀"形式注入——冻结的视觉塔将图像编码为数百个 patch token，拼接到文本 prompt 前由自回归语言模型处理。由于 Transformer 逐层计算量随序列长度超线性增长，视觉前缀长度成为推理延迟与显存的主导因素，因此视觉 token 剪枝是加速 MLLM 推理最直接的途径。
- **核心问题**：现有 top-K 剪枝方法存在两个隐含假设：
  - **独立性假设**：每个 token 独立打分，一旦某 token 被保留，剩余候选（尤其是重复或邻近 token）的边际价值不会被重新估计。
  - **固定压缩比假设**：K 由外部指定并统一施加，无视输入从"近乎空白的文档缩略图"到"密集自然场景"之间的视觉复杂度差异。
- **整体含义**：作者主张放弃这两个假设，将 token 选择重新定义为**逐步序贯决策过程**——每一步只承诺一个（或一组）token，每步条件于此前已选 token，并由模型自行决定何时停止，从而使保留数量 K 成为随输入变化的自适应量，而非固定超参数。

## 2. 方法论

### 核心思想
将剪枝建模为历史条件化的自回归策略，用指针式解码器实现：
- **序贯选择**：策略概率分解为 \( P_\theta(A|X,Q)=\prod_{t=1}^{T}\pi_\theta(a_t|a_{<t},X,Q) \)。
- **学习 STOP 动作 \(\emptyset\)**：候选集在 N 个视觉 token 之外追加一个学习到的 STOP 嵌入，与视觉候选处于同一指针空间；首次选中 \(\emptyset\) 即终止，保留序列为 \(S(A)=(a_1,...,a_{T^\star-1})\)，长度 \(K=T^\star-1\) 完全由同一策略决定。

### 关键技术细节

**（1）跨模态输入编码器**
- 两个 pre-norm ViT 块，文本嵌入先经投影进入视觉特征空间，系数 \(g_{text}\) 在早期训练中逐渐增大。
- 联合编码后仅保留视觉位置作为可选候选，文本通过跨模态自注意力影响 \(H\) 但不被选择。

**（2）指针解码器**
- 每层含：对选择历史的因果自注意力、对候选记忆 \(M=[H;s_{stop}]\) 的交叉注意力、FFN。
- 交叉注意力 logits 复用为指针 logits；已选位置被 mask（每 token 至多选一次）。
- 采用 straight-through 方式：前向用硬动作 \(a_t=\arg\max\)，反向通过指针分布 \(p_t\) 传播梯度。

**（3）轨迹感知的可微优化**
- **轨迹聚合**：定义"存活概率" \(A_t=\prod_{u=1}^{t-1}(1-p_u(\emptyset))\)，并对每个 token 累积 \(s_i=\sum_{t=1}^{T_{max}}A_t\,p_t(i)\,\beta^t\)（\(\beta\) 为几何折扣因子），既降低后期步骤贡献，又更重视早期偏好。
- **可微保留数**：\(\hat{K}=\sum_t A_t(1-p_t(\emptyset))\)，仅用于优化；推理时由首次硬 STOP 决定实际长度。
- **分数极化**：用可微 SoftTopK 将连续分数 \(s_i\) 映射为 \([0,1]\) 的 \(\alpha_i\)，其中 \(k\) 取 batch 内期望保留数的 stop-gradient 值。
- **保持方差的噪声门**：\(\tilde{x}_i=\sqrt{\alpha_i}\,x_i+\sqrt{1-\alpha_i}\,\epsilon_i\)，作为硬剪枝的可微代理——\(\alpha_i\to1\) 时保留原 token，\(\alpha_i\to0\) 时被高斯噪声替代。
- **局部掩码去噪器**：噪声门后接一个自注意力被限制为对角阵的 ViT 块，防止 token 间信息泄漏（强噪声 token 无法从邻居恢复内容）。
- **训练-推理对齐**：训练送入全长度门控序列；推理移除噪声门与去噪器，物理 gather 硬选中的原始 token 并恢复原生视觉顺序。

**（4）训练目标**
- \( L=L_{LM}(\tilde{X})+\lambda\frac{\hat{K}}{N} \)，\(\lambda=0.03\)；视觉塔、多模态投影器、语言模型全部冻结，仅优化跨模态编码器、指针解码器、局部去噪器、文本投影及 START/STOP 嵌入。

**（5）分组序贯执行（高分辨率）**
- 标准策略每步保留 1 个 token，循环轮数随保留长度线性增长。
- 对长前缀改为每轮保留 5 个最高分未选 token（\(U_r=\text{TopG}(\cdot,5)\)），STOP 判断不变；对最终保留 K，循环轮数从约 \(K+1\) 降到 \(\lceil K/5\rceil+1\)，以选择粒度换取更低选择器延迟。

## 6. 主要结论与发现

- **性能保留**：在 LLaVA-1.5、Qwen2.5-VL、InternVL3 上，StepPrune 在所有评估剪枝率下取得最佳平均归一化性能保留；在 LLaVA-NeXT 的超长 AnyRes 前缀上保持竞争力。
- **具体数字**：LLaVA-1.5 上剪枝 88.9% 视觉 token 仍保留 94.6% 全前缀归一化性能；平均保留 64 token 时预填充延迟从 59.95 ms 降至 40.05 ms（1.50× 加速），端到端延迟从 138.37 ms 降至 98.97 ms。
- **剪枝越激进优势越明显**：对 VisionZip 的平均优势从 66.7% 剪枝时的 0.1 个百分点扩大到 88.9% 时的 2.6 个百分点；POPE 上增益从 0.4 点增至 6.1 点。
- **自适应预算有效**：STOP 动作使保留数随输入变化，TextVQA 平均保留 109.6 个 token、ScienceQA-IMG 为 100.9，而 MME/GQA/POPE 约 90；在匹配均值 K 下，自适应选择在 TextVQA（+0.90 点）和 MME（+0.81 点）上优于固定预算。
- **扩展性**：选择器延迟随序列增长而增加，但全前缀预填充增长更快，LLaVA-1.5 上加速比从 320 token 的 0.98× 升至 2240 token 的 4.10×；LLaVA-NeXT 从 1.24× 升至 3.88×。
- **超参稳健性**：\(\lambda\) 主要控制停止时机（均值 K 从 45 到 175 变化），对匹配预算下的排序影响较小（92.8–93.5%）；\(\beta\in[0.8,0.98]\) 时性能稳定在 93.1–93.7%，但过强衰减（0.60）导致性能骤降至 82.4%。
- **失败模式**：极端压缩下细粒度局部文本证据仍难保留（TextVQA 在 LLaVA-NeXT 最紧预算下降至 43.3），过早 STOP 是主要失败原因。

## 7. 优点

- **问题建模有新意**：明确指出并突破 top-K 方法的"独立性"与"固定压缩比"两大假设，把剪枝重构为历史条件化序贯决策，视角清晰且有说服力。
- **自适应停止机制优雅**：STOP 动作与视觉候选共享指针空间，使"选哪些 token"与"选多少 token"由同一策略产出，避免了外部分配预算的两阶段设计。
- **可微化方案完整**：轨迹聚合（存活概率 + 几何折扣）+ 分数极化 + 保方差噪声门 + 局部掩码去噪器构成闭环，去噪器的对角注意力设计有效防止了跨 token 信息泄漏绕过门控信号。
- **训练-推理一致性有专门验证**：不回避训练用软门控、推理用硬剪枝的表示差异，用对照实验量化了 0.3–1.2 个百分点的差距。
- **工程适配性强**：分组执行机制使方法可迁移到 AnyRes、动态分辨率、多 tile 等不同视觉组织，且给出粒度-延迟的可控权衡。
- **实验透明度较高**：明确区分自适应 K 与固定 K，并补充匹配预算对比；坦承并非所有 benchmark 全面占优。

## 8. 不足与局限

- **细粒度局部证据保留不足**：文本密集输入（如 TextVQA）在激进压缩下性能明显下降，过早触发 STOP 会导致相关局部证据永不进入保留子集，这是当前最突出的失败模式。
- **训练-推理表示不一致**：训练保持全长度噪声门控序列，推理物理移除 token，两者存在 0.3–1.2 个百分点的差距，且随预算收紧而扩大；更直接地优化硬选择仍是开放问题。
- **多操作点依赖多检查点**：不同全局效率-精度区间需要分别训练选择器，单一 checkpoint 支持多预算推理尚未实现。
- **评估覆盖有限**：仅测试图像 benchmark 与 7B–8B 规模开源 MLLM，未涉及视频输入（空间+时间双重冗余，可能需层次化选择）和更大规模语言模型。
- **跨 backbone 迁移性未验证**：选择器能否跨 backbone 迁移未做实验。
