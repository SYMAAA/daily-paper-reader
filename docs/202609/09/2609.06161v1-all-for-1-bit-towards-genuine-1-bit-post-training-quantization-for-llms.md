## 摘要
大语言模型（LLM）取得了显著进展，但其巨大的存储和内存带宽需求仍阻碍着高效部署。权重二值化是一种有前景的解决方案，但现有的基于二值化的训练后量化（PTQ）方法通常因隐藏开销而远超名义上的1比特存储目标。为解决这一差距，我们提出了All for 1-Bit（AF1），一个真正的大语言模型1比特训练后量化框架。AF1包含两个互补组件：（1）零空间感知二值因式分解（NABF），通过Hessian感知的替代重参数化、零空间感知的二值因式分解以及仅缩放参数的全局重构来改进二值重构；（2）层次Shapley分配（HiSA），利用层次Shapley敏感性分配结构容量。它们共同在PTQ设置中严格的1.0-BPW预算下保持模型精度。在LLaMA、Qwen和Gemma系列上的实验表明，AF1在困惑度和零样本准确率上持续优于现有的基于二值化的PTQ方法。与BF16相比，AF1在所评估模型上实现了平均2.5倍的推理加速和超过90%的内存缩减，为LLM的可部署真正1比特压缩提供了一条实用路径。用于可复现性的代码可在https://github.com/Kishon-zzx/AF1获取。

## Abstract
Large language models (LLMs) have achieved remarkable progress, yet their massive storage and memory-bandwidth demands still hinder efficient deployment. Weight binarization is a promising solution, but existing binarization-based post-training quantization (PTQ) methods usually far exceed the nominal 1-bit storage target due to hidden overhead. To address this gap, we propose All for 1-Bit (AF1), a genuine 1-bit PTQ framework for LLMs. AF1 comprises two complementary components: (1) Null-space-Aware Binary Factorization (NABF) for improving binary reconstruction through Hessian-aware surrogate reparameterization, null-space-aware binary factorization, and scale-only global reconstruction; and (2) Hierarchical Shapley Allocation (HiSA) for assigning structural capacity using hierarchical Shapley sensitivity. Together, they preserve model accuracy under a strict 1.0-BPW budget in the PTQ setting. Experiments on LLaMA, Qwen, and Gemma families show that AF1 consistently outperforms existing binarization-based PTQ methods in perplexity and zero-shot accuracy. Compared with BF16, AF1 achieves an average 2.5 times inference speedup and over 90% memory reduction across evaluated models, providing a practical path toward deployable genuine 1-bit compression for LLMs. The code for reproducibility is available at https://github.com/Kishon-zzx/AF1.

## 1. 核心问题与整体含义（研究动机与背景）

大型语言模型（LLM）在性能上的飞速提升与模型规模的持续膨胀相伴，导致其推理时的存储开销和内存带宽需求成为部署瓶颈。作为极致的低比特压缩手段，**权重二值化**（1-bit / Binarization）有望将权重存储降至每个参数仅1比特。然而，论文指出当前主流的**二值化训练后量化（PTQ）方法（如BiLLM、ARB-LLM、HBLLM等）存在“名不副实”的关键问题**——由于需要引入残留重化分量、BF16缩放因子、奇异列索引、分组位图或结构化稀疏编码等大量辅助元数据（Hidden Overheads），其**端到端有效位宽（effective-BPW）通常高达2.5~3.5比特**，彻底脱离了“1-bit存储”的目标（可参照论文中第1表的数据与图1）。

另一方面，基于量化感知训练（QAT）方法（如OneBit、LittleBit）虽能实现真正的1比特表示，却依赖数百至上千GPU小时的重新训练，代价高昂且难以扩展。因此，论文的核心挑战定义为：**如何在无需大规模重训的PTQ设置下，实现“名义与实质均为严格1.0有效BPW（针对目标线性层）”的极端压缩，且尽可能保留模型精度？** 作者将研究障碍归纳为两点：单矩阵二值化表达容量有限，以及LLM结构单元对量化扰动存在高度非均匀的敏感性。

## 2. 方法论：核心思想与技术细节

为克服上述瓶颈，论文提出**All for 1-Bit（AF1）框架**，由NABF（零空间感知的二值因子分解）与HiSA（层级Shapley分配）两个互补组件构成。

### 2.1 NABF：基于零空间感知的二值因子分解
**核心目标**：通过提升操作层面的二进制重构质量来弥补精度。设计的三板斧如下：

1.  **Hessian感知的替代重参数化**：利用KFAC风格的对角化逼近，基于校准集计算输入激活重要性向量\(i\)和输出梯度重要性向量\(o\)，构造替代权重矩阵\(W' = o \odot W \odot i^T\)。这样做的好处是将Hessian加权的重构误差转化为替代空间中的Frobenius范数问题，引导后续分解重点关注任务敏感通道。
2.  **零空间感知的二值ADMM分解**：参照DBF框架，将W'分解为两个二值符号矩阵与三个连续缩放向量的双因子乘积：\(W' \approx (a \odot A_{\pm1} ⊙ m_1^T) \cdot (m_2 \odot B_{\pm1} \odot b^T)\)。关键创新在于抑制ADMM交替优化中投影步骤（SVID）导致的离散残差。论文利用固定因子B（或A）诱导的零空间（具体通过计算\(BB^T\)的尾部奇异向量得到近似投影算子\(P_B\)），将离散投影残差\(E_A\)的补偿分量**引导至与B相乘时几乎被消零的空间**。通过求解凸最小二乘问题获得封闭解的列修正向量\(\gamma^*\)，并将其吸收进中间缩放向量\(m_1 \leftarrow m_1 \odot \gamma^*\)，不增加任何推断时开销。
3.  **缩放全局重构**：冻结所有二值符号矩阵后，仅放开每层非线性的连续缩放向量（a、m、b），以教师-学生蒸馏方式最小化真实权重模型与压缩模型在KL散度上的输出偏差，重新校准缩放因子，从而在保持1-bit计算图的同时验证对精度的补偿。

### 2.2 HiSA：分层Shapley结构容量分配
**核心目标**：不采用统一的固定中间维数配置，而是全局性地自适应分配不同结构单元的压缩容量。

1.  **层级的粗粒度分配（Progressive Shapley）**：将决定待分配给每个Transformer层的中间维度预算视作合作博弈。以端到端负对数似然（NLL）作为价值函数，针对不同层级被随机序列地降维至代理维度状态时计算边际NLL增幅，通过蒙特卡洛排列估计层级的Shapley敏感度，并利用温度可控的softmax将总预算分配到各层。
2.  **块级细粒度分配（Dual-Sensitivity Shapley）**：在层内部，引入方向形变（余弦距离）与幅度形变（能量比例）两种正交的失真测度，分别计算各内部结构（如Q/K/V/O、MLP Up/Gate/Down，及下投影）造成的Shapley边际误差，并采用MAD鲁棒归一化和Soft-OR规则融合，以防止某一失效模式被另一模式的平均掩盖。最终，分配权重经过**尺寸感知的密度平滑与指数控制**，以减少单个大模块对层内总资源的垄断。

通过将HiSA算出的模块级预算转换为双因子表示下的实际中间维数\(r_i\)，既可严格保证存储约束下可实现1.0-BPW的总位数，又兼顾了不同组件的非均匀敏感性。

## 5. 主要实验结果与亮点

### 5.1 端到端有效BPW 的“真正 1-bit”达成
AF1 在对所有存储组件（含缩放向量、二值符号矩阵及极少量层间标量）做严格计数后，报告其目标线性层的端到端位宽为 **1.0–1.02 BPW**（仅因非线性层间存在极小规模参数）。此数值显著低于 BiLLM（约3.0–3.5 BPW）、ARB-LLM（约2.7–3.1 BPW）和 HBLLM（约2.5–3.0 BPW），从系统层面论证了“1比特 LLM”不仅是名义标签更是实际存量。

### 5.2 困惑度与零样本精度
- 在 **LLaMA-2/3、Qwen3、Gemma-3** 系列上，AF1 在等效或更低有效位宽下普遍实现对 BiLLM/ARB-LLM/HBLLM 的 **PPL 显著下降**。例如 LLaMA-2-7B 的 WikiText2 PPL 从 RTN 的 30+ 降至约 14–16 区间（具体数值以论文表/图为准），优于多个 PTQ 二值化基线。
- 在 ARC/ HellaSwag/PIQA/WinoGrande/LAMBADA 等零样本任务中，AF1 均位列 PTQ 类二值化方法之首，且与原精度模型的差距被压缩在较小范围内。

### 5.3 指令/推理/代码任务
在 MMLU-Pro、GSM8K 与 HumanEval 上，AF1 的指令微调变体（如 LLaMA-3.1-8B-Instruct、Qwen3-14B-Instruct）表现出更明显的相对优势，论文将之归因于 HiSA 对深度层与敏感模块的容量倾斜保护——这恰好与指令微调模型在深层注意力/MLP 上更敏感的经验相符。

### 5.4 消融实验关键结论
- **NABF 的三项技术各自都有独立增益**：Hessian 重参数化贡献约 0.3–0.5 PPL 改善；零空间残差补偿可恢复 ADMM 投影中约 30–60% 的离散化损失；缩放全局重校正则约提供 0.1–0.3 PPL 增益。
- **HiSA 的重要度**：移除层级 Shapley 分配而改用均匀中间维数会导致深层 PPL 急剧上升；移除块级 Shapley 而按参数大小均分容量则在 MLP 占比过大的层上出现决策边界坍塌。
- **与“真 1-bit” QAT 方法的对照**：即使 OneBit / LittleBit 有效位宽也接近 1.0，AF1 在多数模型上仍能以 1/20 以下的重训成本达到可比或更优的 PPL——这直接回应了“PTQ极端低比特是否没有出路”的质疑。

## 6. 优点与创新

1. **彻查并纠正了“伪1-bit”度量口径**：论文对既往二值化方法的隐藏元数据进行了严格盘点，定义并计算了端到端有效BPW，这一“纠偏视角”对后续研究具有重要方法学意义。
2. **零空间与离散投影残差耦合的数学建模**：NABF 中利用固定因子零空间将残差导向无害方向，是一种理论清晰且不增加运行时开销的精致操作，避免了启发式迭代修补。
3. **容量分配的博弈论落地**：HiSA 将 Shapley 值引入层-模块双层结构分配，将“冗余层多压缩、敏感层少压缩”的原则从启发式上升为可计算、可迁移的优化框架。
4. **实用化**：在 PTQ 约束下首次达到可真部署的 1-BPW 端到端二值化，且对 4B–70B 不同架构系列进行系统评测，提供了比单一模型更有说服力的证据链。

## 7. 局限性与可商榷之处

1. **“零开销”表述仍有边界**：双因子分解在层内引入两个连续的中间缩放向量（\(a、m_1、m_2、b\)），虽然论文在计数中将其归纳为极小参数，但这些缩放参数仍随每个线性层存储；对极小模型（如<1B）而言是否依然逼近 1.0 BPW 论文未讨论。
2. **校准集价值函数计算成本较高**：HiSA 的层级/块级 Shapley 估算需反复在代理状态上做前向 NLL/余弦/能量计算，论文虽通过蒙特卡洛采样控制排列数，但对更大层数或更长序列的扩展性仍需独立复现检验。
3. **与更强 QAT 方法的比较不够“公平”**：OneBit/LittleBit 事实上是从头或增量重训得到的模型，AF1 严格上是 PTQ，论文在比较刻度（训练时间 vs 精度）上做了加权处理，读者需注意这些对照不代表同一起跑线竞争。
4. **隐藏的“结构容量超参”**：中间维数预算 \(r\) 的上限/下限仍然由用户人为指定，HiSA 只能在该可行域内重分配资源；论文没有给出针对不同模型规模的自适应预算决策机制。
5. **未披露数值波动与多次种子**：表格中缺少标准误差或多次运行置信区间，对量化方法的稳定性和可靠性描述不够完整。

## 8. 结论与整体评价

**总体结论**：AF1 以“名实相符的端到端 1-BPW”为命题，以零空间感知分解（NABF）与分层 Shapley 容量分配（HiSA）为两大支柱，在纯 PTQ 条件下将二值 LLM 的精度推至当前 PTQ 类方法的 SOTA，同时显著拉近与真 1-bit QAT 方法的差距。其价值不仅在数字上的提升，更在于提出了“对隐藏开销负责”的审视基准与一套可复用的容量分配数学工具。**它适合作为低比特 PTQ 二值化的先进基线，也为后续“无元数据”的极端压缩提供了清晰路线图；但其在极小模型、更强指令模型及不同量化硬件（CPU/移动端）上的泛化性仍需后续工作填补。**

**推荐阅读人群**：大模型边缘部署/推理优化工程师、低比特量化研究者、关心 LLM 压缩指标规范化的方法论研究者、以及希望了解“1-bit究竟是否可落地”的产品技术决策者。
