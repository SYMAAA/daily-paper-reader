## 摘要
大型视觉-语言模型（LVLMs）实现了强大的多模态理解，但它们处理数百到数千个视觉令牌，带来了巨大的计算开销，这促使了免训练的视觉令牌剪枝。在这项工作中，我们对视觉令牌剪枝进行了两个互补的分析。首先，我们测量了跨模态融合前保留令牌的特征空间覆盖范围，发现激进剪枝会丢弃大量视觉信息。其次，我们跟踪了解码器层中文本到视觉的注意力，发现被认为重要的视觉令牌随深度显著变化，使得一次性剪枝决策不可靠。这些发现共同表明，有效的剪枝应在融合前保持广阔的视觉覆盖，并在融合过程中随着跨模态证据的演变逐步细化保留的令牌。因此，我们提出了STAR-Pro（阶段式自适应令牌缩减与渐进精化），一个免训练的两阶段框架。其自适应阶段应用枢轴QR分解来构建一个超出预算的特征覆盖候选池，而其渐进阶段在选定的解码器层使用演变的文本到视觉注意力，在目标层平均令牌预算下剪枝出一个嵌套的幸存者集。在跨越多种架构的七个LVLM和18个图像和视频基准上的大量实验证明了STAR-Pro在激进剪枝下的有效性。在LLaVA-Video-7B上，STAR-Pro减少了90.5%的视觉令牌，保留了92.7%的基线性能，并实现了2.24倍的实测推理加速。代码可在https://github.com/EasonAI-5589/starpro获得。

## Abstract
Large vision-language models (LVLMs) achieve strong multimodal understanding, but the hundreds to thousands of visual tokens they process impose substantial computational overhead, motivating training-free visual token pruning. In this work, we conduct two complementary analyses of visual token pruning. First, we measure the feature-space coverage of tokens retained before cross-modal fusion and find that aggressive pruning discards substantial visual information. Second, we track text-to-visual attention across decoder layers and find that the visual tokens considered important change substantially with depth, making one-shot pruning decisions unreliable. Together, these findings show that effective pruning should preserve broad visual coverage before fusion and progressively refine the retained tokens as cross-modal evidence evolves during fusion. We therefore propose STAR-Pro (STage-Wise Adaptive Token Reduction with Progressive Refinement), a training-free two-stage framework. Its Adaptive Stage applies pivoted QR to construct an over-budget feature-coverage candidate pool, while its Progressive Stage uses evolving text-to-visual attention at selected decoder layers to prune a nested survivor set under a target layer-average token budget. Extensive experiments across seven LVLMs spanning multiple architectures and 18 image and video benchmarks demonstrate the effectiveness of STAR-Pro under aggressive pruning. On LLaVA-Video-7B, STAR-Pro reduces visual tokens by 90.5%, retains 92.7% of baseline performance, and achieves a $2.24\times$ measured inference speedup. Code is available at https://github.com/EasonAI-5589/starpro.

## 一、论文的核心问题与整体含义（研究动机与背景）

- **背景与痛点**：大型视觉-语言模型（LVLMs）虽具备强大的多模态理解能力，但其视觉侧输入往往产生数百至数千、甚至数万（视频场景）的视觉 token，导致显著的计算与推理开销。现有免训练（training-free）视觉 token 剪枝方法主要分两类：
  - **LLM 前（Pre-LLM）方法**：在进入解码器前一次性选取视觉 token（如 VisionZip、DivPrune、CDPruner 等）。
  - **LLM 内（In-LLM）方法**：在解码器内依赖跨模态注意力进行剪枝（如 FastV、PyramidDrop、SparseVLM 等）。
- **核心问题**：作者通过两项互补的实证发现指出现有方法的两个关键缺陷：
  1. **融合前特征覆盖坍塌**：大幅压缩时，预解码器的一次性选择（即使基于多样性或注意力）会丢失大量互补的视觉特征信息，导致视觉覆盖不足；
  2. **视觉 token 重要性随层数演化**：同一视觉 token 在不同解码器深度的重要性不断变化（作者称之为 Visual Token Importance Evolution），因此“一次剪定”的一步式决策不可靠，可能过早丢弃后续推理所需的关键证据。
- **整体含义**：有效的剪枝策略应遵循"**融合前保覆盖、融合中渐进精化**"（coverage-to-refinement）的原则，即在跨模态融合前保留充分的特征空间覆盖；在跨模态证据生成过程中，利用演化中的注意力逐步细化保留集合。这即是 STAR-Pro 的核心出发点。

## 二、提出的方法论：核心思想、技术与流程

- **总体框架**：STAR-Pro（**St**age-Wise **A**daptive Token **R**eduction with **P**rogressive **R**efinement）是一个全**免训练**的两阶段剪枝框架，设目标为"层平均视觉 token 数" T（layer-average token budget）。
- **阶段一：自适应阶段 Adaptive Stage（融合前覆盖）**
  - 作用点：vision encoder + projector 之后、进入 LLM 解码器之前。设视觉特征矩阵为 Fv ∈ R^{n×d_s}。
  - 目标：在给定候选池大小 m=αT（α 为超参数，默认 2）的条件下，选出特征空间中**互补性强、覆盖范围广**的 token，构建超预算候选池 C。
  - 方法：采用**pivoted QR 分解**来贪心近似最大化所选集 Gram 矩阵行列式（行列式的平方根即为所选特征向量张成的体积），每步将"剩余特征中在已选空间上投影残差范数最大"的 token 选入集合，其选择的量化目标是：
    - 贪心更新：π<sub>t+1</sub> = arg max<sub>i∉C_t</sub> ‖(I − Q_t Q_t^T) z_i‖，即最大程度增加已覆盖特征空间体积。
  - 动机：相比现有的空间或集合覆盖策略，这一方法以**特征子空间覆盖**（feature-subspace coverage）为准则，保证在激进压缩下保留足够的互补视觉结构。对视频（帧）或多裁剪图（crop）等分组建模，可分别按组调用同一选择算子。
- **阶段二：渐进阶段 Progressive Stage（解码器内精化）**
  - 作用点：选定的 P 个 decoder 剪枝层 L = {ℓ₁, …, ℓ_P}。
  - 做法：记进入解码器的候选池 S₀ = C；在每次剪枝层 ℓ_k 处，用**当前层**真实 text-to-visual 注意力，在所有 head 与文本 token 上平均得到每个 token 的重要性得分：
    - r<sup>(ℓ_k)</sup><sub>v</sub> = (1/(n_q H)) Σ<sub>j=1..n_q</sub> Σ<sub>h=1..H</sub> A<sup>(ℓ_k),h</sup><sub>j,v</sub>
  - 随后按该得分从现有幸存集 S<sub>k−1</sub> 中取 Top-m_k，得到嵌套幸存集：C=S₀⊇S₁⊇⋯⊇S_P。已移除 token 不可重新加入（不可逆、单调精化）。
  - 预算约束：所有剪枝层后的数量 m_k 需满足层平均 token 数为 T，即 (ℓ₁·αT + Σ(m_k·span))/L = T。
  - 设计动机：由于视觉 token 重要性跨层演化，在多个深度重估并渐进剪枝比固定在某层一次性决策更可靠。
- **架构差异处理**：
  - LLaVA-1.5/NeXT、LLaVA-Video、Qwen3-VL 等按其图像裁剪或视频帧分组分别执行自适应选择；
  - InternVL3 则针对缩略图（thumbnail）与局部裁剪（local crop）设置 4:1 的候选配额权重。

## 六、主要结论与发现

- STAR-Pro 在 12 个 LLaVA 模型–压缩设置中 11 个取得并列或最优相对性能；在最高压 94.4% 压缩下，四个 LLaVA 模型均保留 ≥94.9% 的性能。
- 视频任务中，在 LLaVA-Video-7B 上：
  - 压缩 81.1%（32 tokens/帧）：保留 96.7% 基线性能，领先第二名 1.5 pp；
  - 压缩 90.5%（16 tokens/帧）：保留 92.7%，领先幅度扩大至 2.8 pp，综合三个视频基准均为第一。
- Qwen3-VL 与 InternVL3 上，预算越小、边际优势越明显（如 InternVL3 在 T=128 时高出第二名 4.5 pp），证明其对新兴架构的泛化能力。
- 效率方面：LLaVA-NeXT-7B 在 160 tokens（94.4% 剪枝）下保留 97.0% 性能并提速 2.27×；LLaVA-Video-7B 在 16 tokens/帧（90.5% 压缩）下实现 2.24× 实测端到端加速。自适应阶段总开销仅占净节省约 4%，主要收益来自更短的 decoder prefill。
- 消融证实两个阶段互补：缺少任一阶段都会明显降低性能，尤其是 aggressive budget 下（如缺 Progressive 阶段时 Mean-4 score 差距由 0.62 扩大至 1.64 点）。
- 剪枝层位置搜索显示 (12,20) 位于一片稳健的高分区域，而非孤立的最优点，增强了该方法架构级部署的可迁移性。

## 七、优点

- **洞察驱动设计**：通过两个针对性的实证观察（特征覆盖损失、注意力跨层演化），精准指明了现有方法的机制缺陷，提出的两阶段框架具有较强的可解释性。
- **免训练、即插即用**：无需任何权重更新或架构改动，可直接用于多种现有 LVLM 架构，部署成本低。
- **候选池加渐进裁剪的结合**：既不盲目追求早剪枝的长 prefill 收益，也不放任未筛选的全量 token 加大计算；在延迟与精度的 Pareto 前沿上有明显推进。
- **丰富的实验支撑**：覆盖 7 个模型、18 个图像与视频 benchmark、9 个 baseline，并提供了多组有对照变量的消融（stage、α、剪枝层位置、token 分配方式、控制选择算子等），结果有较高可信度。
- **对计算成本透明**：逐一拆解自适应阶段耗时（仅占净节省 4%），并测量同步端到端延迟、显存开销与 TFLOPs，对比方式相对严谨。

## 八、不足与局限

- **缺乏大规模训练的验证条件说明**：作为"免训练"方法，实验者不必训练模型，但大规模评测工作量与评估成本未量化，无法复核资源投入或能耗。
- **高级架构的视频与更多模态场景未验证**：视频实验仅在 LLaVA-Video-7B 上完成；Qwen3-VL、InternVL3 虽验证了图像理解，但尚未验证其视频（动态时间建模）或多图交错场景。此外未涉足语音/文档等多模态输入场景。
- **基线可比性部分受限**：多个对比方法的数值来自原论文或近似复现，评测 harness 不完全统一可能导致微量偏差（虽然作者尽力统一了 VLMEvalKit/lmms-eval/LLaVA 官方脚本）。
- **α 与剪枝层仍需人工标定**：虽然 (12,20) 与 α=2 在 LLaVA-1.5-7B 上表现稳健，不同架构仍需各自重选剪枝层与层内 token 分配，未达到全自动自适应。
- **客观性偏差**：所有消融与调度搜索均在 LLaVA-1.5-7B 上执行，架构间差异、数据集间可能存在的选择偏差未能完全排除；
- **聚合指标可能掩盖弱点**：Acc./Rel. 为多任务平均结果，个别 benchmark（如 MMMU、部分 POPE 配置）上方法并不总能领先，存在"靠均衡取胜"而非"全维压制"的现象。
