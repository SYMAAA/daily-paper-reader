## 摘要
训练后权重-激活量化降低了大语言模型的显存与推理成本，但激进的 W4A4 量化仍然困难，因为激活离群值会降低有效量化分辨率。尽管权重优化、通道级缩放和正交旋转可以缓解这一问题，但它们所处理的误差分量及其相互关系仍不清楚。通过将局部权重-激活量化误差精确分解为激活引导的权重补偿项和正交残差，我们利用持续存在的通道级离群量与常规激活量来界定该残差。该分解阐明了哪些误差分量可以通过权重补偿处理，哪些需要变换设计。随后，我们利用这些残差界推导出应用随机 Hadamard 旋转、符号选择和通道缩放的实用准则。特别地，该分析解释了随机符号如何抑制持续离群通道之间的相长干涉，采样多种符号模式如何改进变换选择，以及二阶矩平衡如何导出 $L_2$ 缩放规则，而进一步松弛则可恢复 SmoothQuant 风格的 $L_\infty$ 缩放。我们在八个 Llama 和 Mistral 模型上通过免反向传播配置评估了这些准则，获得了与梯度训练的 SpinQuant 相当的性能。

## Abstract
Post-training weight-activation quantization reduces the memory and inference costs of large language models, but aggressive W4A4 quantization remains difficult because activation outliers degrade effective quantization resolution. Although weight optimization, channel-wise scaling, and orthogonal rotation mitigate this problem, the error components they address and their relationship remain unclear. Using an exact decomposition of local weight-activation quantization error into an activation-guided weight compensation term and an orthogonal residual, we bound the residual using persistent channel-wise outlier and regular activation quantities. This decomposition clarifies which error components can be addressed by weight compensation and which require transformation design. We then use the residual bounds to derive practical guidelines for applying randomized Hadamard rotation, sign selection, and channel scaling. In particular, the analysis explains how random signs suppress constructive interference among persistent outlier channels, how sampling multiple sign patterns can improve transformation selection, and how second-moment balancing leads to an $L_2$ scaling rule while a further relaxation recovers SmoothQuant-style $L_\infty$ scaling. We evaluate these guidelines through backpropagation-free configurations across eight Llama and Mistral models, obtaining performance competitive with gradient-trained SpinQuant.

## 2. 方法论

- **局部量化设定**：
  - 线性层 \(Y = XW^\top\)，引入可逆变换 \(P\)，令 \(Z = XP\)，\(V = WP^{-\top}\)，保持全精度输出不变。
  - 激活采用无裁剪动态 per-token 对称均匀量化；权重量化器 \(Q_W\) 不限定具体规则，可为 GPTQ/GPTAQ 等。
  - 局部重建目标：\(J(P,\tilde V)=\frac1T\|\tilde Z\tilde V^\top-ZV^\top\|_F^2\)。

- **核心分解：定理 1**
  - 精确分解为：
    - \(J_{\text{AGWC}}\)：激活引导的权重补偿项；
    - 正交残差：\(\frac1T\|(I-\Pi_{\tilde Z})AV^\top\|_F^2\)。
  - 关键结论：固定变换下，权重优化可降低 AGWC，但不能改变正交残差；正交残差需通过变换设计改善。
  - 用持续通道离群量 \(J_{\text{co}}\) 和常规激活量 \(J_{\text{reg}}\) 给出正交残差上界。

- **持续通道离群分解**：
  - 将激活写成 \(X=X_{\text{co}}+X_{\text{reg}}\)；
  - \(X_{\text{co}}\) 表示跨 token 持续存在的大通道分量；
  - \(X_{\text{reg}}\) 表示剩余 token 相关变化。
  - 变换形式为 \(P=\Lambda^{-1}DH^\top\)：\(\Lambda\) 为正对角缩放，\(D\) 为随机符号矩阵，\(H\) 为归一化 Hadamard 矩阵。

- **旋转分析：定理 2**
  - 固定旋转：\(J_{\text{co}}\) 最坏依赖约为 \(N_{\text{co}}^2/d\)，多个离群通道可相长干涉。
  - 随机符号旋转：Rademacher 符号使交叉项期望为零，依赖降为约 \(N_{\text{co}}\log d/d\)。
  - 采样多个符号矩阵：候选集中更可能包含有利符号模式，支持基于校准的符号选择。
  - 直觉：随机符号抑制持续离群通道之间的相长干涉。

- **缩放分析：命题 1**
  - 随机符号 Hadamard 旋转后，常规项 \(J_{\text{reg}}\) 可由二阶矩能量控制。
  - 使用 Frobenius 代理 \(R_2(\Lambda)=\|W\Lambda\|_F^2\|X_{\text{reg}}\Lambda^{-1}\|_F^2\)，最小化得到 **L2 缩放规则**：
    \[
    \lambda_k^{(2)}=\sqrt{\frac{\|(X_{\text{reg}})_{:,k}\|_2}{\|W_{:,k}\|_2}}
    \]
  - 进一步用 \(L_\infty\) 统计松弛，可恢复 SmoothQuant 风格缩放：
    \[
    \lambda_k^{(\infty)}=\sqrt{\frac{\|(X_{\text{reg}})_{:,k}\|_\infty}{\|W_{:,k}\|_\infty}}
    \]
  - 实践上用全激活经验统计近似 \(X_{\text{reg}}\)。

- **实践方法 L2-SmoothRot**：
  - 在 QuaRot 框架内实现，免反向传播；
  - **SOR**：在在线 Hadamard 旋转前加入符号翻转，覆盖 attention 输出、FFN down 投影、RoPE 后的 Q/K 旋转；
  - **SS**：基于校准数据搜索多个符号模式，联合选择 offline、attention-output、FFN-down、QK 旋转符号；
  - **L2S**：对 FFN down-projection 输入应用 L2 通道缩放，缩放因子可融合进权重，不增加推理开销；
  - 权重量化采用 GPTAQ。

## 6. 主要结论与发现

- 局部量化误差可精确分解为 **AGWC 项**和**正交残差**；权重优化只能处理 AGWC，不能消除正交残差。
- 正交残差可由持续通道离群量和常规激活量界定，从而说明旋转和缩放是互补的变换设计手段。
- 固定 Hadamard 旋转下，多个持续离群通道可能相长干涉，导致 \(O(N_{\text{co}}^2/d)\) 依赖；随机符号可抑制交叉项，将依赖降至约 \(O(N_{\text{co}}\log d/d)\)。
- 采样多个符号模式可提高找到有利干涉模式的机会，支持校准式符号选择。
- 最小化常规项二阶矩代理得到 L2 缩放；进一步松弛可恢复 SmoothQuant 风格 L∞ 缩放，说明两者是同一残差界的不同松弛层次。
- 实践配置 L2-SmoothRot 在 8 个模型上取得最低 WikiText-2 困惑度，并在 C4 上全部最低；在 5 个模型上平均零样本准确率最高。
- 在 Llama3-8B 上，全组件将 PPL 从 QuaRot 的 7.45 降至 7.20；SOR、SS、L2S 各自均有增益。
- 种子选择中，top-3 重评通常优于 top-1，候选集增大有益；RTN 筛选是低成本选择策略。
- 总体结论：无需反向传播的配置可达到与梯度训练 SpinQuant 竞争的性能，验证了误差分解框架的实用指导价值。
