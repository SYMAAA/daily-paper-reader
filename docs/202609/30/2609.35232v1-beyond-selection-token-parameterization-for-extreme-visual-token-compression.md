## 摘要
视觉 token 压缩能有效提升视觉-语言模型的效率，但在极端压缩预算下，token 剪枝可能破坏视觉 grounding，而可学习重采样器会增加参数量、注意力开销和训练复杂度。我们从 token 参数化的视角重新审视压缩，将 (i) 基变换与结构化截断（保留子空间/可压缩性）与 (ii) 坐标组织（优化与跨模态对齐）区分开来。这一视角引出两个耦合目标，即可压缩性与可学习性，我们将其形式化为统一的泛函。在这些目标的指导下，我们设计了 Braco，一种轻量级四步编码器，结合了变换基截断、输入无关的基坐标嵌入、预算相关的正交重参数化，以及来自轻量池化的可学习空间残差 token。实验表明，Braco 在 $23\times$--$64\times$ 压缩下形成有利的经验准确率-效率前沿，并在 $144\times$ 下保持竞争力，达到 95.2% 准确率，同时相对于未压缩上限将 prefill FLOPs 降低 84.2%--86.7%。与先前方法相比，Braco 在匹配或提升准确率的同时，实现最高约 36% 的端到端加速，并将压缩器延迟/FLOPs 分别降低至原来的 1/16.6、1/78.8。

## Abstract
Visual-token compression is effective for improving the efficiency of vision-language models, but under extreme compression budgets, token pruning can break visual grounding while learned resamplers increase parameter count, attention cost, and training complexity. We revisit compression through a token parameterization lens, separating (i) basis transformation and structured truncation (retained subspace/compressibility) from (ii) coordinate organization (optimization and cross-modal alignment). This view yields two coupled objectives, compressibility and learnability, which we formalize as unified functionals. Guided by these objectives, we design Braco, a lightweight four-step coder that combines transform-basis truncation, input-independent basis-coordinate embeddings, budget-dependent orthogonal re-parameterization, and learned spatial residual tokens from lightweight pooling. Experiments show that Braco forms the favorable empirical accuracy-efficiency frontier under $23\times$--$64\times$ compression and remains competitive at $144\times$, reaching 95.2% accuracy while reducing prefill FLOPs by 84.2%--86.7% relative to the uncompressed upper bound. Against prior methods, Braco matches or improves accuracy while achieving up to approximately 36% end-to-end speedup and using $16.6\times$/$78.8\times$ lower compressor latency/FLOPs.

## 1. 核心问题与研究动机

- **背景**：视觉-语言模型（VLM）将图像编码为视觉 token 序列，计算成本随 token 数线性增长。移动端推理、低延迟交互智能体、长上下文多模态推理等部署场景可能只允许几十个视觉 token。
- **现有方法的困境**：
  - **Token 选择/剪枝/合并**（如 PruMerge、DivPrune、Token Merging）：中等压缩下性价比高，但极端压缩下会丢弃稀有但关键的区域；原始注意力等重要性代理不稳定。
  - **可学习重采样**（Perceiver 式 cross-attention、query 驱动接口，如 MQT-LLaVA、QueCC、TokenPacker）：可缓解脆弱性，但引入额外注意力计算、参数量和分阶段训练/多模态对齐复杂度。
- **核心追问**：极端 token 预算下，性能主要取决于"更精细地选择 token"，还是"为视觉 token 场选择更好的参数化"？
- **核心思想**：将极端视觉 token 压缩视为 **token 参数化问题**，分离两个正交维度：
  - (i) **基变换 + 结构化截断** → 决定保留子空间（**可压缩性 compressibility**）；
  - (ii) **坐标组织** → 影响优化与跨模态对齐（**可学习性 learnability**）。
- **整体含义**：性能瓶颈源于两个约束——保留子空间必须集中任务相关信息，且保留坐标必须诱导可处理的对其问题；据此设计轻量编码器 **Braco**。

## 2. 方法论

### 2.1 Token 参数化形式化

- 视觉编码器输出 patch token 网格：$X = f_{vis}(I) \in \mathbb{R}^{L \times D_v}$，$L = N^2$。
- 正交基 $B \in \mathbb{R}^{N\times N}$（$B^\top B = I_N$）诱导 $U_B = B \otimes B$，重表达为 $Y = U_B X$。
- 固定结构化索引集 $S \subseteq [L]$（$|S|=K$），行选择矩阵 $P_S$ 截断：$\bar{Z} = P_S Y$。
- 正交矩阵 $A \in \mathbb{R}^{K\times K}$ 可重组保留坐标：$Z = A P_S U_B X$。
- 关键分工：$(B,S)$ 决定**保留哪个子空间**；$A$ 只改变**子空间内坐标**。

### 2.2 两个统一目标泛函

**可压缩性**（basis + truncation）：

- Token 轴二阶矩 $M = \mathbb{E}[X X^\top]$。
- 能量保留：$E(B;S) = \frac{\mathrm{tr}(P_S U_B M U_B^\top P_S^\top)}{\mathrm{tr}(M)}$（正交 $A$ 不影响该值）。
- 可读性 $R(B;S)$：任务方向 $W^\star$ 被保留子空间（M-正交投影 $\Pi_{B,S}$）保留的比例，$R \in [0,1]$。
- 综合诊断：$C(B;S) = \lambda E(B;S) + (1-\lambda)R(B;S)$，$\lambda$ 权衡能量与任务方向保留。

**可学习性**（坐标组织）：

- 令 $\bar{G} = \mathbb{E}[\bar{Z}\bar{Z}^\top]$，$G(A) = A\bar{G}A^\top$。
- 统计条件惩罚：$L_{st}(A) = \|\mathrm{OffDiag}(G(A))\|_F^2 + \gamma\|\mathrm{diag}(G(A)) - \frac{\mathrm{tr}(\bar{G})}{K}\mathbf{1}\|_2^2$。
- 几何兼容惩罚：$L_{geo}(A) = 1 - \frac{1}{K}\langle A, A_0\rangle_F = \frac{1}{2K}\|A - A_0\|_F^2$。
- 预算感知目标：$L_{learn}(A;K) = \frac{1}{K^2}L_{st}(A) + \beta L_{geo}(A)$（$1/K^2$ 使统计项跨预算可比）。
- **预算相关阈值**：比较系数坐标 $I$ 与逆 DCT 粗网格 $U_C$，得 $\Delta_{learn} = \frac{\Delta_{st}}{K_b^2} - \beta\rho_C$；当 $K_b$ 极小（$K_b^2 < \Delta_{st}/(\beta\rho_C)$）选 vanilla 系数坐标，$K_b$ 较大时选 idct 粗网格。
