## 摘要
视频大语言模型（Video LLMs）在视频理解方面已取得显著进展，但其推理效率受到长视频所产生的大量视觉 token 的限制。近期的视频 token 压缩方法越来越多地引入复杂的 token 选择、剪枝与合并策略。这引出了一个根本性问题：仅仅通过保留视觉表示中编码的结构，能够获得多少压缩性能？我们通过 SimpleCluster 研究这一问题。SimpleCluster 是一种简单且无需训练的基线方法，它在视觉特征空间中执行位置感知的跨帧聚类，并用每个簇的原始视觉特征的均值来表示该簇。在四个视频理解基准和三个代表性 Video LLM 上的大量实验表明，在广泛的 token 保留率范围内，SimpleCluster 相较于近期压缩方法取得了有竞争力或更优的性能，并且在极低保留率（例如 1%）下表现出特别强的鲁棒性。为了理解这一行为，我们从局部近似保真度和全局覆盖度两个方面分析了不同压缩方法所保留的特征空间。结果表明，更强的下游性能始终与更好地保留原始视觉特征分布（尤其是其全局覆盖度）相关联。这些发现凸显了在高度受限的 token 预算下，特征空间保留是视频 token 压缩的一个重要考虑因素。我们的代码可在 https://github.com/xiaozhang79/SimpleCluster 获取。

## Abstract
Video Large Language Models (Video LLMs) have achieved remarkable progress in video understanding, but their inference efficiency is constrained by the large number of visual tokens produced by long videos. Recent video token compression methods increasingly introduce sophisticated strategies for token selection, pruning, and merging. This raises a fundamental question: how much of compression performance can be obtained by simply preserving the structure encoded in the visual representations? We investigate this question with SimpleCluster, a simple and training-free baseline that performs position-aware cross-frame clustering in the visual feature space and represents each cluster using the mean of its original visual features. Extensive experiments across four video understanding benchmarks and three representative Video LLMs show that SimpleCluster achieves competitive or superior performance over recent compression methods across a wide range of token retention ratios, with particularly strong robustness under extremely low retention rates (e.g., 1%). To understand this behavior, we analyze the feature space preserved by different compression methods in terms of local approximation fidelity and global coverage. The results show that stronger downstream performance is consistently associated with better preservation of the original visual feature distribution, especially its global coverage. These findings highlight feature-space preservation as an important consideration for video token compression under highly constrained token budgets. Our code is available at https://github.com/xiaozhang79/SimpleCluster.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：Video LLM 通过结合视觉编码器与 LLM 在视频理解上取得显著进展，但长视频产生的大量视觉 token 严重制约推理效率。视觉 token 压缩（token selection、pruning、merging）成为高效 Video LLM 的重要方向。
- **核心问题**：近期视频 token 压缩方法不断引入越来越复杂的机制（重要性选择、密度感知剪枝、token 合并、注意力锚点、最优传输等），这引出一个根本性追问——**在高度受限的 token 预算下，仅靠保留视觉表示本身所编码的结构，能获得多少压缩性能？** 复杂设计是否真的必要？
- **整体含义**：作者提出 SimpleCluster——一个刻意简单、无需训练、无需架构修改的基线，在视觉特征空间中做位置感知的跨帧聚类。若如此简单的策略即可媲美甚至超越复杂方法，则说明**特征空间保持（尤其是全局覆盖）** 才是压缩性能的关键，而非精巧的选择机制。这为视频 token 压缩研究提供了一个新的分析视角与强基线参照。

## 2. 方法论

### 核心思想
- 在视觉 token 经 projector 之后、输入 LLM 之前，对全部视频帧的视觉 token 进行**跨帧聚类**，每个簇用其**原始视觉特征的均值**表示，得到压缩后的紧凑序列。
- 关键分离：**位置信息只用于确定聚类分配**，特征聚合仍在原始投影特征空间中进行，从而不破坏已与 LLM 对齐的视觉语义。

### 关键技术细节
- **位置感知特征构建**：
  - 每个 token $x_i$ 关联时空坐标 $p_i = (f_i, h_i, w_i)$（帧、行、列）。
  - 对 $x_i$ 施加 3D RoPE 变换并按 L2 归一化，得到聚类空间特征 $z_i = \frac{R(p_i)x_i}{\|R(p_i)x_i\|_2}$。
  - $z_i$ 仅用于定义聚类度量空间；原始 $x_i$ 保持不变用于最终聚合。
- **跨帧聚类**：将全部 $N$ 个 token 划分为 $B$ 个簇（$B$ 为目标 token 预算），通过最小化簇内余弦距离：
  - $\{C_k\} = \arg\min \sum_{k=1}^{B}\sum_{i\in C_k}\left(1 - \frac{z_i^\top \mu_k}{\|z_i\|_2\|\mu_k\|_2}\right)$，其中 $\mu_k$ 为簇原型。
  - 由于在 3D RoPE 增强空间中用余弦相似度聚类，分组同时考虑视觉相似性与时空关系，可区分外观相似但位置不同的 token，并自适应分配有限预算。
- **簇级特征聚合**：每个簇用原始视觉特征均值表示 $y_k = \frac{1}{|C_k|}\sum_{i\in C_k}x_i$，直接送入 LLM。
- **理论分析（附录 C）**：
  - 该目标与经典聚类/矢量量化（Lloyd、k-means）一致，最优原型为簇内均值；畸变可写为 $\frac{1}{2|C_k|}\sum_{i,j\in C_k}\|z_i-z_j\|_2^2$。
  - **跨帧预算共享**优于逐帧固定分配：联合聚类的全局最优畸变 $J^*_{joint}(B) \le \min \sum_t J^*_t(B_t)$，因为不同帧的冗余 token 可共享代表。
  - 均值聚合在固定簇下最小化平方重构误差；聚类畸变随预算单调递减。

### 算法流程（文字版）
1. 用原始视觉编码器 + projector 提取视频 token $X$，排除模型特定结构 token（如换行符）。
2. 为每个 token 构造位置感知归一化特征 $z_i$。
3. 设定目标预算 $B = \min(N, \max(1, \text{round}(rN)))$，在 $\{z_i\}$ 上做跨帧余弦聚类（迭代分配 + 归一化均值更新）。
4. 对每个簇在原始空间做均值聚合，得到 $B$ 个压缩 token。
5. 压缩 token 与文本 token 拼接后输入 LLM。

## 6. 主要结论与发现

- **性能结论**：
  - 5% 保留率下，SimpleCluster 在 LLaVA-OV-7B / LLaVA-Video-7B / InternVL3-2B 上平均分分别为 **55.7 / 55.6 / 53.7**，一致优于所有对比方法。
  - **1% 极低保留率下优势更明显**：分别保留未压缩模型 **88.3% / 84.8% / 85.8%** 的性能（如 LLaVA-OV 51.6 vs. EarlyTom 45.7、VisionZip 43.5）。
  - 25% 保留率下 LLaVA-OV 平均分 58.6，甚至略高于未压缩模型（100.3%），说明压缩可去除冗余。
- **简单策略对照**：10% 保留率下 SimpleCluster 平均 57.3，优于时空网格采样（55.4）、空间网格采样（55.6）等固定坐标方案，说明按特征结构组织 token 更有效。
- **消融结论**：
  - 3D RoPE 带来 +0.7（57.3 vs 56.6）；跨帧聚类比逐帧 +1.2（57.3 vs 56.1）；均值与最近邻聚合几乎持平（57.3 vs 57.2），说明**聚类分配质量比聚合方式更重要**。
- **特征空间分析**：
  - 10% 时 SimpleCluster L2-NQE 0.281、Cosine Coverage@0.90 59.7%，显著优于最强竞品（EarlyTom 0.407；FastVID 35.0%）。
  - 5% 时 L2-NQE 0.336、覆盖率 45.9%，甚至优于其他方法在 10% 时的表现。
  - 从 10% 降到 5%，SimpleCluster 的 L2-NQE 仅增 0.055、覆盖率保留 76.9%，下游分数仅降 1.6 分；竞品降幅为 2.4–5.6 分。
- **效率结论**：10% 保留率下，SimpleCluster prefill FLOPs 27.5T、TTFT 514.1ms，较未压缩模型降低 73.2% 与 45.5%，保留 98.1% 性能；相比 AOT 进一步降低 TTFT 26.2% 且平均分更高。
- **核心发现**：**更强的下游性能始终与更好地保持原始视觉特征分布（局部保真度 + 全局覆盖度）相关**，尤其是全局覆盖度是低预算下的关键因素。

## 7. 优点

- **方法极简且实用**：无需训练、无需架构改动、即插即用，可直接用于不同 Video LLM 骨干，工程落地成本低。
- **强鲁棒性**：在 1% 极端压缩下仍保留 85%+ 性能，相比复杂方法退化更小，适合高约束场景。
- **效率优势明显**：不仅压缩后推理更快，压缩过程本身也轻量（无注意力锚点、无最优传输迭代），TTFT 优于 AOT。
- **分析视角有价值**：不止于刷点，而是从**局部近似保真度（L2-NQE）与全局覆盖度（Cosine Coverage）** 两个维度解释压缩效果，把下游性能与特征空间保持建立经验联系。
- **理论支撑**：附录给出与矢量量化目标的联系、跨帧预算共享优于逐帧分配的不等式证明、均值聚合的最优重构性质，增强了方法论说服力。
- **实验公平性较好**：统一 checkpoint、帧采样、prompt、评分器；对不可行配置不强行截断/填充，如实报告。
- **可视化清晰**：跨帧聚类分配图与稠密特征覆盖热力图直观展示了“跨帧冗余聚合”和“覆盖更均匀”的机制。

## 8. 不足与局限

- **定位限制**：作者明确将工作定位为“强基线研究”而非新压缩算法；未充分刻画在哪些场景下更复杂的压缩机制仍有额外优势。
