## 摘要
视觉令牌剪枝作为一种降低大型视觉语言模型计算成本的实用方法，已被广泛研究。然而，它难以保留关键视觉信息，这可能导致性能大幅下降。具体而言，基于图像的令牌选择可能忽略与任务相关的细节，而文本引导的令牌选择可能无法捕捉复杂推理所需的文本-视觉关系。我们发现，过早引入文本引导会限制其识别与答案相关的视觉区域的能力，而文本到视觉的注意力在解码器中间层深度时变得更具信息量。这一发现启发了我们的免训练方法，该方法将早期的视觉引导剪枝与延后的文本引导重选分开。我们首先使用视觉编码器注意力剪枝视觉令牌，保留额外候选令牌直到解码器中点，然后使用文本到视觉注意力确定最终的视觉令牌集合。在八个基准和三个模型上，我们的方法在 80% 和 90% 剪枝率下，性能恢复分别平均超过表现最佳的基线 11.10 和 16.84 个百分点，同时 LLM 预填充延迟与大多数基线相当或更低。源代码公开于 https://github.com/kmc3661/DeFT

## Abstract
Visual token pruning has been widely studied as a practical approach to reducing the computational cost of large vision-language models. However, it struggles to preserve essential visual information, which can lead to substantial performance degradation. In particular, image-based token selection can overlook task-relevant details, while text-guided token selection may fail to capture the text--visual relationships needed for complex reasoning. We find that applying textual guidance too early can limit its ability to identify answer-relevant visual regions, whereas text-to-visual attention becomes more informative at intermediate decoder depths. This finding motivates our training-free method, which separates early vision-guided pruning from deferred text-guided reselection. We first prune visual tokens using vision-encoder attention, retain additional candidates until the decoder midpoint, and then use text-to-visual attention to determine the final visual-token set. Across eight benchmarks and three models, our method outperforms the best-performing baselines by an average of 11.10 and 16.84 percentage points in performance recovery at 80% and 90% pruning, respectively, with comparable or lower LLM-prefill latency than most baselines. The source code is publicly available at https://github.com/kmc3661/DeFT

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：大型视觉语言模型（VLM）在视觉问答、图像描述、多模态推理等任务上表现出色，但高分辨率图像被编码为大量视觉 token，显著拉长了语言模型处理的序列长度，带来沉重的计算开销。
- **解决思路**：视觉 token 剪枝（visual token pruning）通过缩短视觉序列来降低开销，其中**免训练（training-free）**方法因无需更新参数或训练额外选择器而尤为实用。
- **核心困境**：现有方法难以保留关键视觉信息，导致性能大幅退化，具体表现为两条技术路线的失败：
  - **基于图像的剪枝**（如 ZOO-Prune）依赖视觉显著性/冗余度，会忽略任务相关的细节（例如丢弃问题所询问的品牌名区域）。
  - **文本引导的剪枝**（如 SparseVLM）依赖图文交互，但难以捕捉复杂推理所需的文本–视觉关系（例如保留了"我是受害者"的支撑区域，却丢失了对应的数值）。
- **关键发现**：作者系统分析发现，**过早引入文本引导会削弱其识别答案相关视觉区域的能力**；文本到视觉注意力（text-to-visual attention）在解码器**中间层深度**才变得显著更具信息量。因此，文本引导的**时机**是有效 token 选择的关键。
- **整体含义**：论文将上述发现提炼为一条设计原则——**早期视觉引导剪枝与延后文本引导重选应当分离**，并据此提出免训练方法（代码库名 DeFT），在多种模型与基准上显著提升剪枝后的性能保持率。

## 2. 方法论

### 2.1 核心思想
采用**两阶段**设计：
1. **早期纯视觉剪枝 + 候选保留**：在 LLM 之前用视觉编码器注意力剪枝，但保留多于最终预算的候选 token；
2. **解码器中点的延后文本引导重选**：在解码器深度中点，用文本到视觉注意力从候选集中重选出最终视觉 token 集合。

这一设计刻意推迟文本引导，直到其信息量足够充分，同时早期仅依赖图像信息完成初步压缩。

### 2.2 关键技术与公式流程

- **阶段一：早期视觉剪枝与候选保留（LLM 之前）**
  - 设 N 为可剪枝视觉 token 数，D 为解码器深度，最终预算 K ≈ (1−p)N（p 为剪枝率）。
  - 计算头平均的视觉编码器注意力，并聚合为每个视觉 token 的图像重要性分数 `s_img`：
    - 对带 class token 的编码器，使用 CLS 到视觉 token 的注意力；
    - 对无 class token 的编码器，使用各视觉 token 从其他视觉 query 处接收到的自注意力。
  - 保留候选集合：`M = min{N, K + ⌈α(N−K)⌉}`，`C = TopK_M(s_img)`，其中 **α ∈ [0.1, 0.3] 为保留比例超参数，默认 α = 0.2**。
  - 集合 C 包含图像排名前 K 的 token 及其后的 M−K 个额外候选，这些候选在解码器中点之前一直被保留。

- **阶段二：延后文本引导重选（解码器中点 L = D/2）**
  - 利用解码器原生 query/key 计算头平均注意力 `A_text`，`s_text_i` 为候选 i 从输入文本 token 处接收到的注意力（遵循解码器原生注意力掩码）。
  - 最终选择：`S = TopK_K(s_text|C)`，即在候选集 C 内按文本到视觉注意力重选 K 个 token。
  - **角色分工**：图像分数只用于构建候选集 C，最终选择完全由中点的文本到视觉注意力决定；这允许初始视觉 top-K 之外的候选在变得与输入更相关时进入最终集合。
  - 注意：正确答案与生成答案 token 不用于 token 选择。

- **重选深度选择依据**：
  - 通过掩码区域重要性分析（对每张图 8 个空间区域逐一掩码，度量对正确答案 NLL 的影响），定义区域重要性 h_r；
  - 用 Spearman 秩相关比较匹配问题注意力与交换问题注意力，`Δρ_ℓ = ρ^match_ℓ − ρ^swap_ℓ`，发现早期层信号弱、中间层显著增强；
  - 在匹配 token–block 计算预算下消融深度，发现 **D/2 处恢复效果最好**（表 1：D/4、D/2、观测峰值、3D/4 中 D/2 均值最高 92.806）。

## 6. 主要结论与发现

- **文本引导的时机至关重要**：文本到视觉注意力在解码器早期层识别答案相关区域的能力弱，在中间层显著增强；过早应用文本引导反而有害。
- **分离式设计有效**：早期用视觉编码器注意力剪枝、中点用文本到视觉注意力重选，在全部 9 个模型–剪枝设置上取得最高的平均相对性能。
- **量化收益**：
  - 80% 剪枝时平均超越最强基线 **11.10 个百分点**；90% 剪枝时超越 **16.84 个百分点**；
  - 在 Qwen3-VL-8B、90% 剪枝下仍保留 **90.65%** 的 Dense 性能，而所有对比方法均低于 70%；
  - 增益在 TextVQA、ChartQA、InfoVQA 等依赖局部化、提示相关证据的任务上尤为显著；剪枝越激进，优势越大。
- **机制验证**：约 **39–45% 的最终视觉 token 来自初始视觉 top-K 之外**的保留候选，说明中点文本注意力对初始视觉排序进行了实质性修正，且增益并非仅来自早期保留更多 token。
- **效率**：在保留额外候选的情况下，LLM prefill 与端到端延迟仍与多数基线相当或更低（如 80% 剪枝下 prefill 121.20 ms vs. Dense 226.66 ms）。
- **可调性**：保留比例 α 在 [0.1, 0.3] 内近似线性地控制性能与推理成本权衡；即使 α = 0.1 也超过最强基线。

## 7. 优点

- **洞察驱动、动机清晰**：通过掩码式区域重要性分析与匹配/交换问题的秩相关对比，量化证明了"文本引导何时有效"，为方法设计提供了可验证的实证依据，而非纯经验调参。
- **方法极简且免训练**：仅复用模型已有的视觉编码器注意力与解码器原生注意力信号，无需训练选择器、无需参数更新，也无额外的 token 合并或学习模块，易于即插即用。
- **设计原则具有一般性**：将"早期视觉剪枝"与"延后文本重选"分离的思路不依赖特定骨干架构，在 Qwen3-VL 与 LLaVA-OneVision 两类不同模型上均成立。
- **实验严谨性较高**：采用匹配 token–block 计算预算的对比、统一的输入/预处理/生成/评分配置、禁用 KV 缓存保持一致配置；消融设计（图 5、图 6）能干净地分离各因素贡献。
- **性能–效率权衡可控**：α 提供显式旋钮，并同时用解析 FLOPs 与实测延迟两种方式验证趋势，避免结论仅依赖于单一测量口径。
- **定性证据丰富**：8 个基准 × 3 个骨干的定性案例直观展示了"视觉上不显著但任务相关"的证据如何被本文方法保留。

## 8. 不足与局限

- **计算资源报告不完整**：仅说明延迟测量使用单张 RTX A6000，未报告评估所用 GPU 总量、总耗时或能耗；作为免训练方法虽无训练算力需求，但推理侧的大规模评估成本未量化。
- **任务覆盖仍有边界**：8 个基准以问答与描述为主，未涵盖视频、多图、长文档、多轮对话等更复杂的多模态场景；深度诊断实验仅基于 4 个 QA 基准的 300 图 × 2 问题采样。
- **模型覆盖有限**：仅 3 个骨干（Qwen3-VL-4B/8B、LLaVA-OneVision-1.5-8B），未验证更小或更大规模模型、以及非 Transformer 视觉编码器架构下的泛化性。
- **超参数依赖**：α 与重选深度 L = D/2 为固定/经验设定；论文虽消融了 α 与深度，但"中点"是否对所有模型、分辨率与任务类型都是最优边界尚缺乏更强理论解释。
- **部分对比范围受限**：PyramidDrop 与 FlowCut 的对比仅在 Qwen3-VL-8B 上进行；渐进式基线在匹配预算下最终 token 数可能与本文不同，跨方法比较存在口径差异风险。
- **收益分布不均**：在 NoCaps 等非问题条件化的开放式描述任务上提升相对较小，说明方法优势主要集中于需要定位局部、提示相关证据的任务。
- **偏差风险**：评估依赖特定实现细节（如 FlashAttention-2 vs. SDPA、KV 缓存禁用

），可能影响跨方法比较的严格可比性；文本注意力权重本身可能受注意力汇聚（attention sink）与位置偏置影响，论文未深入讨论如何剥离这类伪影。

## 9. 可复现性与开放性问题

- **可复现性较好**：方法免训练、无随机初始化依赖，核心信号（视觉编码器注意力、解码器中点文本到视觉注意力）均可由标准前向传播直接获得；关键超参数（α = 0.2、L = D/2、剪枝率 70/80/90%）均已明确给出，具备较高的复现可行性。
- **尚存模糊之处**：
  - 论文未给出候选集构建在多头注意力下的具体归一化与聚合细节（如是否按层平均、是否对注意力做长度归一化），这类实现差异在实际复现中可能带来数个百分点的波动；
  - 渐进式基线的"匹配预算"折算规则（如何将平均解码器视觉 token 使用量等价为本文的固定 K）描述相对简略；
  - 延迟测量的 100 个 InfoVQA 输入虽按尺寸分层，但未说明是否覆盖极端宽高比与超长文本提示场景，端到端延迟结论的泛化性有待观察。

## 10. 对领域的启示与未来方向

- **方法层面**：本文提出的"时机分离"原则提示，视觉 token 压缩的研究不应只关注"用什么信号打分"，还应关注"在何处打分"。这一视角可迁移到其他多模态压缩与加速场景，例如视频 token 压缩、长文档多图理解、多轮对话中的视觉上下文管理。
- **架构层面**：结论暗示解码器的中间层是多模态融合的"信息拐点"，这一现象本身值得进一步研究——它与已有的"多模态融合发生在中层""视觉信息在深层被稀释"等观察相互呼应，可能成为理解 VLM 内部信息流的一个有用抓手。
- **可能的扩展方向**：
  - 将固定中点 L = D/2 替换为**自适应深度选择**（如基于注意力熵或层间注意力变化率动态触发重选）；
  - 把一次性重选扩展为**多次渐进重选**，在多个深度上逐步收敛最终 token 集合；
  - 探索在**训练阶段**引入该时机先验（如对齐损失引导中层文本–视觉注意力），以进一步压缩候选集规模；
  - 将该原则与 KV 缓存压缩、token 合并等方法结合，考察叠加收益与相互干扰。

## 11. 总体评价

本文是一篇"以小见大"的工作：方法本身极为轻量（无训练、无额外参数、仅复用现成注意力），但其立论建立在可验证的实证诊断之上——通过掩码区域重要性与匹配/交换问题的秩相关对比，明确刻画了文本引导信息量随解码深度的变化曲线，并据此推导出"早期视觉剪枝 + 延后文本重选"的设计原则。这一"先诊断、后设计"的路径使其区别于大量依赖经验调参的剪枝方法。

在实验上，论文覆盖 3 个骨干、3 个剪枝率、8 个基准，并采用匹配 token–block 计算预算的公平对比口径，主要结论（80% 剪枝领先 11.10 个百分点、90% 剪枝领先 16.84 个百分点、90% 剪枝下仍保留 90.65% Dense 性能）具有较强说服力；机制层面"39–45% 最终 token 来自初始 top-K 之外"的量化证据，有效支撑了"中点文本注意力对视觉排序进行实质性修正"这一解释，而非归因于单纯多留 token。

主要短板集中在外部效度与报告完整性：骨干数量与任务类型仍偏窄（缺少视频、多图、长文档、多轮场景），计算资源报告不完整，部分基线对比仅限单一骨干，且"中点"最优性缺乏理论刻画。尽管如此，其提出的设计原则简洁、可迁移、即插即用，对视觉 token 剪枝乃至更广义的多模态效率研究具有明确的参考价值。
