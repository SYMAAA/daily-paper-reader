## 摘要
多模态大语言模型面临显著的效率挑战，这些挑战源于两个不同但又相互耦合的来源：数据冗余和计算冗余。尽管大多数方法通过从视觉编码器输出中剪枝视觉 Token，或利用块级重要性度量 LLM 解码器中的冗余，来关注数据冗余，但更细粒度的层间表示变化以及层内本身的分布差异尚未得到充分探索。在这项工作中，我们全面研究了这种双层低效问题。我们认为，为了实现有效的视觉 Token 剪枝，应考虑来自视觉编码器中间层的 Token，因为语义焦点会随层变化，中间层 Token 能捕获更详细的以对象为中心的信息，而更深层可能会将这些信息抽象掉。此外，我们揭示了注意力机制和前馈网络（FFN）在不同 LLM 解码器层中的差异化贡献。基于这些发现，我们提出了 SPIDER，一个无需训练的框架，它集成了多层语义视觉 Token 剪枝（multi-layer Semantic visual token PrunIng）与自适应子层跳过（aDaptive sub-layER skipping）机制。实验评估表明，SPIDER 在各种 MLLM 架构和压缩比率下始终能保持强劲性能。例如，在 LLaVA-NeXT-7B 上，SPIDER 将 FLOPs 减少 79%，同时保持基线性能的 96%。

## Abstract
Multimodal Large Language Models face significant efficiency challenges that stem from two distinct yet coupled sources: data redundancy and computational redundancy. While most methods focus on data redundancy by pruning visual tokens from the output of the visual encoder or computing redundancy in LLM decoders using blockwise importance, the finer-grained inter-layer representation shifts and the distribution differences within the layers themselves have not been fully explored. In this work, we comprehensively investigate this dual-level inefficiency. We posit that intermediate layer tokens from vision encoders should be considered for effective visual token pruning, as semantic focus shifts across layers, with middle-layer tokens capturing more detailed object-centric information that deeper layers may abstract away. Furthermore, we reveal the differential contributions of Attention and FFNs across distinct LLM decoder layers. Building upon these discoveries, we propose \textbf{SPIDER}, a training-free framework that integrates multi-layer \underline{\textbf{S}}emantic visual token \underline{\textbf{P}}run\underline{\textbf{I}}ng with an a\underline{\textbf{D}}aptive sub-lay\underline{\textbf{ER}} skipping mechanism. Experimental evaluations demonstrate that SPIDER consistently maintains strong performance across various MLLM architectures and reduction ratios. For instance, on LLaVA-NeXT-7B, SPIDER reduces FLOPs by $79\%$ while maintaining 96$\%$ of the baseline performance.

# SPIDER 论文中文总结

## 1. 核心问题与整体含义

- **研究背景**：多模态大语言模型（MLLM）在图像理解、视频理解、视觉推理等任务上表现强劲，但推理开销巨大。
- **双重效率瓶颈**：
  - **数据冗余**：高分辨率图像经视觉编码器后产生大量视觉 Token（如 LLaVA-NeXT 可达 2880 个），显著拉长序列长度。
  - **计算冗余**：LLM 解码器在处理剩余 Token 时仍存在大量冗余计算。
- **现有方法不足**：
  - 多数 Token 剪枝方法仅依赖视觉编码器**最后一层**特征计算重要性，忽视层间语义焦点迁移；中层 Token 往往保留更细粒度的目标中心信息，而深层更偏抽象全局语义。
  - 现有层跳过方法多为**块级粗粒度**，直接跳过整个 LLM 解码器块，忽视 Attention 与 FFN 子层的贡献差异。
- **核心主张**：视觉 Token 的效用随深度变化，应在编码器侧做多层语义剪枝，在解码器侧做自适应子层跳过，将二者统一为“深度依赖的效用分配”问题。

## 2. 方法论

### 核心思想
SPIDER 是一个**免训练**框架，包含两个耦合模块：
- **MSV-Prune**：多层语义视觉 Token 剪枝，决定哪些 Token 进入解码器。
- **ASL-Skip**：自适应子层跳过，决定保留 Token 在解码过程中还需要多少计算。

### 关键技术细节

#### （1）MSV-Prune：多层语义视觉 Token 剪枝
- **Anchor Token 选择**：
  - 对视觉编码器自注意力矩阵按头平均，得到每个 patch 的注意力分数 \(a_v\)。
  - 用动态阈值 \(\tau\) 选出预算为 \(n \times R \times r\) 的 anchor Token，其中 \(R\) 为总体保留率，\(r\) 为 anchor 占比。
- **互补 Token 选择（粗到细）**：
  - **粗粒度语义聚类**：对非 anchor Token 的高层特征做 K-means 聚类，按簇大小比例分配配额 \(N_k\)，保证各语义组均有代表。
  - **细粒度多视角剪枝**：计算 Token 对 \((i,j)\) 的多层相似度 \(S_{ij}\)，包含：
    - 中层特征与深层特征的簇内相似度；
    - 与已选 anchor Token 的相似度。
  - 每个簇保留相似度最低的 \(N_k\) 个 Token，聚合成互补 Token 集 \(T_v^{cmp}\)。
- **最终输入**：anchor Token 与互补 Token 按空间索引拼接，再与文本 Token 融合送入 LLM。

#### （2）ASL-Skip：自适应子层跳过
- **在线可跳过性分数 \(S_{sa}\)**：
  - **内在信息熵 \(E_{ii}\)**：将隐藏状态投影到词表空间后计算 Shannon 熵，熵低表示语义已收敛，可跳过。
  - **图文相关性 \(F_{itc}\)**：视觉 Token 与文本上下文向量的余弦相似度，相关性弱则更可跳过。
  - 保留分数 \(R(i,\ell)=E_{ii}+F_{itc}\)，可跳过性分数为 \(S_{sa}=\text{ReLU}(1-R)\)。
- **离线子层贡献分数 SLC**：
  - 通过 KL 散度衡量跳过某层 Attention 或 FFN 对最终输出的影响。
  - 低 SLC 表示该子层更冗余，更适合跳过。
  - 归一化后得到 \(SLC_{Norm}\)，每层选择分数更高的子层作为该层跳过目标 \(m(\ell)\)。
  - 关键发现：视觉 Token 的 Attention 子层通常比 FFN 更冗余。
- **分数融合与累积**：
  - 融合分数：\(S_{fuse}(i,\ell)=w_1 S_{sa}(i,\ell)+w_2 SLC_{Norm}(\ell)\)。
  - 在前半层 \(L/2\) 内累积 \(S_{skip}\)，超过阈值 \(T_{skip}\) 后 Token 进入“跳过模式”。
  - 跳过目标在进入时冻结，后续所有层均跳过该指定子层；不同层进入的 Token 可跳过不同子层。

## 6. 主要结论与发现

- **视觉编码器中层 Token 对细粒度任务至关重要**：中层关键目标覆盖率高，深层更偏全局抽象，仅用最后一层会丢失对象中心细节。
- **Attention 与 FFN 贡献不均**：视觉 Token 的 Attention 子层通常比 FFN 更冗余，跳过 Attention 的代价显著低于跳过 FFN。
- **SPIDER 性能强劲**：
  - LLaVA-NeXT-7B 上减少 **79% FLOPs**，仍保留 **96%** 基线性能。
  - LLaVA-1.5-7B 约 26% TFLOPs 时聚合准确率 96.73%。
  - Qwen3-VL-8B-Instruct 约 55% 和 45% TFLOPs 时分别保留 99.06% 和 98.33% 性能。
- **免训练 SPIDER 可媲美训练感知方法**：在约 30% TFLOPs 下与 PruMerge+ 聚合准确率均为 99.0%，微调后提升至 99.5%。
- **效率提升**：LLaVA-1.5-7B 上 Prefill 延迟从 67.4 ms 降至 48.2 ms，Decode 延迟从 23.1 ms 降至 20.6 ms，吞吐从 43.3 提升至 45.2 tokens/s。
- **知识边界漂移可控**：POPE 上准确率从 85.9% 提升至 86.6%，纠正的错误多于翻转的正确预测。

## 7. 优点

- **免训练、即插即用**：无需重新训练，适用于多种 MLLM 架构。
- **多层语义剪枝**：显式利用视觉编码器中层与深层特征的语义差异，提升细粒度任务表现。
- **子层粒度跳过**：区分 Attention 与 FFN，并做到 Token 级、层内自适应的跳过决策。
- **实验覆盖广**：跨 LLaVA、Qwen 系列，多 benchmark、多压缩率，含丰富消融。
- **分析深入**：包含 SLC 稳定性、中层敏感性、失败案例、知识边界漂移等分析。
- **效率与精度平衡好**：在高压缩率下仍保持较高聚合准确率。

## 8. 不足与局限

- **解码阶段实际加速受限**：ASL-Skip 产生不规则、输入依赖的 Token 级动态稀疏，标准密集 GPU 内核难以充分利用，需硬件感知稀疏实现。
- **失败案例暴露鲁棒性问题**：
  - 低质量、运动模糊图像中，注意力选择可能保留噪声区域，导致 OCR 类任务幻觉。
