## 摘要
后训练量化（PTQ）能够实现大型视觉-语言模型（LVLM）的高效部署，但其通常仅在小规模校准集上进行校准，却需要泛化到多样的下游任务。尽管近期面向 LVLM 的 PTQ 方法引入了敏感性信号，它们仍以最小化相对于全精度模型的重建损失为目标，这可能过度保留全精度行为以及校准集特有的偏差。我们观察到，量化不应仅被视为需要最小化的误差，它还可能为某些层和模态提供有益的正则化。受此观察启发，我们提出了平衡拟合（Balanced Fitting），一种基于量化效应的框架，在基于重建的优化之外平衡精度与正则化。通过测量权重、视觉激活和文本激活在层级与组件级的量化效应，平衡拟合对敏感组件采用细粒度拟合，同时采用更粗粒度的拟合以利用潜在的正则化收益。在多个 LVLM 上的实验表明，我们的方法在仅权重量化和权重-激活量化下均持续优于先前的 PTQ 方法，而更低的重建损失并不一定能可靠地转化为更好的下游性能。源代码公开于 https://github.com/kmc3661/BFQ

## Abstract
Post-training quantization (PTQ) enables efficient deployment of large vision-language models (LVLMs), but is typically calibrated on a small set while expected to generalize across diverse downstream tasks. Although recent PTQ methods for LVLMs incorporate sensitivity signals, they still minimize reconstruction loss with respect to the full-precision model, potentially over-preserving FP behavior and calibration-specific bias. Rather than treating quantization solely as an error to be minimized, we observe that it can also provide beneficial regularization for certain layers and modalities. Motivated by this observation, we propose Balanced Fitting, a quantization effect-based framework that balances precision and regularization beyond reconstruction-based optimization. By measuring layer- and component-wise quantization effects for weights, vision activations, and text activations, Balanced Fitting combines fine-grained fitting for sensitive components with coarser fitting to exploit potential regularization benefits. Experiments on multiple LVLMs show that our method consistently outperforms prior PTQ approaches under both weight-only and weight-activation quantization, while lower reconstruction loss does not reliably translate into better downstream performance. The source code is publicly available at https://github.com/kmc3661/BFQ

## 一、核心问题与整体含义（研究动机与背景）

- **背景**：大型视觉-语言模型（LVLMs）在多模态推理任务上表现优异，但计算与内存开销巨大。后训练量化（PTQ）因仅需少量校准集即可压缩模型，成为高效部署的重要途径。
- **核心问题**：现有 LVLM PTQ 方法（如 Q-VLM、MBQ、QIG）虽引入敏感性信号，但仍以最小化相对于全精度（FP）模型的重建损失为统一目标。作者认为该范式存在两个根本局限：
  - **过度保留 FP 行为**：FP 模型本身可能包含过拟合或次优组件，压缩有时反而能提升性能（已有文献在剪枝/量化中报道类似现象）。
  - **校准集偏差**：校准集规模小且未必反映下游分布，最小化重建误差会保留校准集特有偏差，损害泛化。
- **关键观察**：量化并非总是有害扰动；在不同层和不同组件（权重、视觉激活、文本激活）上，量化效应异质——某些组件对量化敏感，某些则能从量化中获得正则化收益（见图 2(a)）。
- **整体含义**：论文提出应将量化视为“精度与正则化之间的平衡”，而非单纯误差最小化，为 LVLM 的 PTQ 提供了新视角。

## 二、方法论

### 2.1 核心思想
- 提出 **Balanced Fitting** 框架：通过逐层、逐组件的量化效应度量，自适应地控制拟合强度——对敏感组件进行**细粒度拟合**（更精细的 CWE 搜索），对可受益于量化的组件进行**粗粒度拟合**（更粗搜索以利用正则化）。
- 保留原始 CWE（通道级均衡）目标函数，仅改变每层 CWE 搜索候选数量，不修改底层优化目标。

### 2.2 关键技术细节与算法流程

**步骤①：量化效应估计**
- 对每层 ℓ 与组件 c ∈ {w（权重）, v（视觉激活）, t（文本激活）}，仅量化该组件、保持其余不变，定义量化效应：
  - `s(ℓ)_c = L(FP)_calib − L(ℓ, c-quantized)_calib`
  - 其中 `L_calib` 为校准子集上 token 级负对数似然（NLL）。
- 正值表示量化降低校准损失（潜在正则化收益）；负值表示量化损害重要信息（敏感）。

**步骤②：重要性分数转换与冲突处理**
- 将 `s(ℓ)_c` 转换为重要性分数：
  - 当 `s ≥ 0`（有益）：`ŝ = −α·s`，用 α ∈ [0,1] 降低其重要性（鼓励粗拟合）。
  - 当 `s < 0`（敏感）：`ŝ = −s`，保留其重要性（鼓励细拟合）。
- 激活分支聚合：`ŝ_a = ŝ_v + ŝ_t`。
- 引入**层内冲突分数** `κ(ℓ) = Std(s_w, s_v, s_t)`，衡量同层不同组件响应的分歧程度，并将其以系数 β 加入权重与激活的最终重要性分数（分歧越大，分配越多预算）。
- 实验中统一取 α = 0.5，β = 0.5。

**步骤③：层间预算分配**
- 每层分配离散预算 `g(ℓ)`，即用于优化 CWE 的网格点数。
- 定义三个量：最小预算 `gmin`、目标平均预算 `gavg`、集中因子 `γ`，由量化效应分布自动确定（附录 B 提供统计驱动规则）。
- 分配流程：
  - 所有层先获得 `gmin`，剩余预算 `R = Gtarget − Gmin` 按重要性分数分配。
  - 以第 50 百分位 `qlow` 为阈值，仅上尾层获得额外预算：`p(ℓ) = (t(ℓ))^γ / Σ(t(j))^γ`，`g(ℓ) = gmin + round(R·p(ℓ))`。
  - γ 越大，预算越集中于高重要性层。

**步骤④：分支融合与 CWE 搜索**
- W3A16 仅使用权重分支：`g(ℓ)search = g(ℓ)_w`。
- W4A8 同时使用权重与激活分支，按分支正重要性质量归一化加权：
  - `ρw = Sw/(Sw+Sa)`，`ρa = 1 − ρw`
  - `g(ℓ)search = round(ρw·g(ℓ)_w + ρa·g(ℓ)_a)`
- 最终在分配的预算下执行标准 CWE 搜索：
  - `E* = arg min_E Σ_i || Q_W(W⊙E)·Q_X(E⁻¹⊙Xi) − W·Xi ||²₂`
  - 预算大 → 细粒度搜索（敏感层）；预算小 → 粗粒度搜索（潜在正则化层）。

**自动分配规则（附录 B）**：基于增益比 r、损失严重度 M、激活侧损失份额 A、支持比 S、集中度 C₀.₁ 等统计量归一化后，通过固定公式计算 `gmin`、`gavg`、`γ`，同一量化模式下跨模型共享系数。
