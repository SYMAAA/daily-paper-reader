## 摘要
四位训练后量化可以降低大语言模型的内存需求，但在严格的 MXFP4 W4A4 下保持精度需要协调若干设计选择。坐标变换会改变块编码误差，进而影响通过网络传播的残差。因此，有用的算法分解在搜索之前并不完全已知。由 LLM 驱动的程序演化提供了一种探索这些选择的方式，但仅凭性能分数无法解释下一步应改变哪个设计。我们提出 QuantForge，一个 PTQ 发现系统，它记录相互竞争的解释，选择能够区分这些解释的对照实验，并检查后继代码是否实现了所得结论。这种残差编译指导程序修订，同时即使原始解释被否定也保留有用的程序。重新测量修订后的程序可揭示下一个需要处理的误差。该过程发现了 HiRes，一种固定的 MXFP4 量化器，它塑造坐标、细化合法编码分配，并沿注意力与 MLP 路径恢复误差。每个阶段作用于前一阶段执行后测得的残差。在七个任务上，HiRes 取得了最低的七模型 Robust Fit（0.09300）以及 32B 下最低的量化 Fit-7。在 LLM 驱动程序演化的匹配预算比较中，每次 240 次评估器调用，QuantForge 在八次运行中的六次达到留出迁移目标，而文本记忆和反思记忆各为三次，仅分数演化为一次，尽管其评估的新程序更少。这些结果表明，QuantForge 通过将受控证据转化为后续程序修改，改进了可迁移 PTQ 算法的发现。

## Abstract
Four-bit post-training quantization can reduce the memory demands of large language models, but preserving accuracy under strict MXFP4 W4A4 requires coordinating several design choices. Coordinate transforms change block-encoding errors, which in turn affect the residuals propagated through the network. The useful algorithmic decomposition is therefore not fully known before search. LLM-driven program evolution offers a way to explore these choices, but performance scores alone do not explain which design should change next. We introduce QuantForge, a PTQ discovery system that records competing explanations, selects controls that distinguish them, and checks that successor code implements the resulting conclusions. This residual compilation guides program revisions while retaining useful programs even when their original explanations are rejected. Remeasuring the revised program reveals the next error to address. This process discovers HiRes, a fixed MXFP4 quantizer that shapes coordinates, refines legal code assignments, and recovers errors along attention and MLP paths. Each stage acts on residuals measured after the preceding stage has executed. Across seven tasks, HiRes achieves the lowest seven-model Robust Fit (0.09300) and the lowest quantized Fit-7 at 32B. In matched-budget comparisons of LLM-driven program evolution, each with 240 evaluator calls, QuantForge reaches a held-out transfer target in six of eight runs, compared with three each for textual memory and reflection memory, and one for score-only evolution, despite evaluating fewer new programs. These results show that QuantForge improves the discovery of transferable PTQ algorithms by turning controlled evidence into subsequent program changes.

## 1. 核心问题与研究动机

- **背景**：大语言模型（LLM）部署成本高，训练后量化（PTQ）可在不重训练的情况下压缩模型。四位权重与激活（W4A4）可将名义精度相对 16 位降低四倍；MXFP4 是标准化表示——每 32 个值共享一个 2 的幂次缩放因子（E8M0），元素采用 E2M1。
- **核心矛盾**：MXFP4 的块共享指数结构将块内所有元素的舍入精度耦合在一起——由大值决定的指数会使小块内的小值无法被良好分辨。因此需要坐标变换来分散离群值，但变换后的值仍须落在稀疏的四位网格上。坐标选择同时影响**缩放因子选择**与**码字分配**，并改变二阶重建（GPTQ）所需的输入相关性。
- **深层困难**：量化算子安装后，其误差会沿注意力路径传播，并在门控 MLP 的乘积中相互作用。改进某一步会改变下一步需要纠正的误差，导致各组件之间存在**顺序依赖**，手工设计算法十分困难。
- **现有方法的不足**：LLM 驱动的程序演化（如 FunSearch、AlphaEvolve）可用性能分数作为选择信号，但**分数无法解释下一步应修改哪个设计**。例如一个变换可能因"分散离群值"而有效，也可能因"改善共享指数选择"而有效，两种解释指向完全不同的后续修改方向。
- **整体含义**：论文提出 QuantForge，通过**受控实验**区分竞争性解释，并将实验结论编译为对后继代码的强制要求，从而在搜索过程中"发现"算法的分解结构，并由此得到 HiRes 量化器。

## 2. 方法论

### 2.1 QuantForge：渐进式残差分解（Progressive Residual Factorization）

- **搜索状态**：维护两个前沿——可执行程序前沿 $P_t$ 与残差前沿 $R_t$，构成搜索状态 $S_t=(P_t, R_t)$。
- **算法残差（Algorithmic Residual）**：附着于可执行程序上的设计问题，其中多种解释都能拟合当前观测，但暗示不同的程序修改。性能决定程序是否保留在 $P_t$ 上；受控证据决定其残差是否关闭。**有用程序可以在其原始解释被否定的情况下继续存活**。

- **反事实控制选择**（公式 2）：提案在执行前注册解释集合 $E$、各条件下的预测结果 $P_e(c)$ 与允许的对照 $U$，系统选择最小代价子集，使得任意两个解释至少在一个执行条件下预测不同：
$$U^* = \arg\min_{V\subseteq U} \sum_{c\in V} \text{cost}(c) \quad \text{s.t. } \forall e\neq e', \exists c\in\{\text{primary}\}\cup V: P_e(c)\neq P_{e'}(c)$$
若允许的对照无法区分，则提案必须在消耗评估前提出更好的判别器。

- **残差编译**（公式 3）：将实验裁决转化为程序响应：
$$v_t = \text{Resolve}(\rho_t, U_t^*), \quad P_{t+1} = \text{Compile}(P_t, v_t)$$
支持的结论允许扩展干预，被反驳的结论要求修改构造，不确定的对照保持残差开放。系统通过**代码变更**与**定向执行探针**验证响应。

- **渐进式残差分解**：修订后的程序必须**重新测量**，因为原先驱动修改的测量可能已不再描述新程序。重复此过程，逐步确定量化算法的分解结构。

- **裁决类型**：支持（关闭残差，扩展方向）、仅目标增益（修复解释）、仅中介特征（修复迁移）、无效果（退役干预）、未解决（添加判别器）、不安全（回滚并恢复父代）。

### 2.2 HiRes：分层残差求解量化器

三阶段依次作用于前一阶段执行后测得的残差（公式 11：$R_k=\text{Measure}_k(M^{(k)}), M^{(k+1)}=\text{Apply}_k(M^{(k)},\text{Solve}_k(R_k))$）。

**阶段 I：几何塑造**
- **参考坐标**（公式 4）：对每个 Block32 组，计算激活与权重的二阶矩，经行列式归一化 $DN(M)=M/\det(M)^{1/q}$ 与谱截断 $Cap_8$ 后组合，得到 $P_{ref}=Cap_8(M_0^{-1/2})$。两种算子对坐标变换响应相反，参考图在归一化后组合对立的几何。
- **编码误差校正**（公式 5–6）：用一次锚定量化识别参考坐标遗留的误差，构造有界交互矩阵 $K$，$G_0=I+K$，经体积归一化得 $G$，最终变换 $T=R_H G P_{ref}$。构造保证 $\|K\|_2\le 1/8<1$，因此 $I+K$ 可逆。配对变换保持 $\tilde X\tilde W^\top = XW^\top$（函数保持）。
- **权重–激活平衡**（公式 7）：在 Block32 内的 8 个四坐标子组上计算风险比 $r_A/r_W$，堆叠、中心化、投影得到有界零和向量 $u_b$，经严格重建损失选择幅度后广播为 $u\in\mathbb R^{32}$，$D=\text{Diag}(2^u)$ 反向折叠入两个算子。风险比只提供方向，必须由实际重建测量决定是否接受。

**阶段 II：离散实现**
- 在固定几何下，用变换后的 pre-A4 激活重跑校准并计算 GPTQ 曲率，得到合法的 Block32 W4 权重（E8M0 指数 + E2M1 码字）。
- **动态 A4 单码精化**（公式 8）：对激活块 $x$，设最近合法向量 $q_0$，定义 $G_Q=\hat W^\top\hat W$、$K_Q=\hat W^\top(W-\hat W)$，改变坐标 $i$ 到合法值 $c$ 的局部二次模型变化为：
$$\Delta(i,c) = 2\delta_{ic}[G_Q d_0 - K_Q x]_i + \delta_{ic}^2 [G_Q]_{ii}$$
线性项度量与当前输出残差的交互，二次项度量自身误差代价；$K_Q x$ 项包含已安装权重的失配，因此**首选激活码依赖于已实现的 W4 算子**。接受最佳负变化，否则保持 $q_0$，每块至多改一个码。

**阶段 III：结构恢复**
- **注意力恢复**（公式 9）：对每个 KV 头拟合跨 token 共享的标量尺度 $a$ 与偏移 $b$，最小化 $\sum_t\|av_t+b-v_t^\star\|_2^2$。
- **MLP 恢复**（公式 10）：在注意力校正后**重新测量** MLP 残差，收集门与上投影输出 $g,u$，用三个层级标量 $\alpha,\beta,\eta$ 调整门偏移、门尺度、上尺度：
$$\bar m = \text{SiLU}((1+\beta)g+\alpha\sigma_g)\odot(1+\eta)u$$
用加权岭回归（Hoerl & Kennard, 1970）联合估计三系数。

**算法 1 流程**：输入 BF16 模型与 128×2048 校准序列 → 构造并折叠 $T,D$ → 在实现的 $DT$ 坐标中重跑校准 → GPTQ 实现 W4 + 安装动态 A4 → 拟合并安装注意力恢复 → 重测 MLP 残差并拟合并安装公式 10 → 返回 MXFP4 W4A4 模型。

- **模型（7 个）**：Llama-3.2-3B、Qwen3-4B/8B/32B、Mistral-7B-v0.3、Llama-3-8B、OLMo-2-13B。

- **量化合约**：严格 MXFP4 W4A4，连续 32 元素块、E2M1 元素值、E8M0 共享指数；权重静态量化、激活动态量化；校准为 128 条有序 C4-train 序列（2048 token，seed 0）；评估时禁用 KV 缓存。
- **指标**：Fit-7（各任务相对 BF16 损伤的均值与最差值的等权组合），Robust Fit（跨模型的均值与最差值的等权组合），越低越好。

### 3.2 对比方法
- **量化基准（9 个基线）**：RTN、GPTQ、MR-GPTQ、BRQ、WUSH、TORQ、BATQuant+GPTQ、SpinQuant+GPTQ、FOCUS。
- **发现框架对比（匹配 240 次评估预算，8 个配对种子）**：Score-only、TextMem（自由文本实验摘要）、ReflectMem（反思成功/失败程序）、QuantForge。搜索可见模型为 Qwen3-4B，留出迁移模型为 Llama-3.1-8B。

### 3.3 消融与对照实验
- **阶段累积消融**：严格 RTN → +几何塑造 → +离散实现 → +结构恢复。
- **几何组件消融**：移除局部交互 $K$、$D=I$、两者均移除，跨校准种子 {0,3,5}。
- **几何替换实验**：WUSH、WUSH+R（共享精化与恢复）、完整 HiRes。
- **激活码精化消融**：最近舍入、仅敏感度、完整失配感知规则；局部目标测量。
- **恢复路径消融**：无、仅注意力、仅 MLP、两者；陈旧 vs 新鲜 MLP 统计。
- **重测量对照**：恢复系数在 A4 编码前 vs 后拟合。
- **发现框架消融**：残差编译移除（释放 30 次探针调用）、控制选择策略（最小判别 vs 随机合法 vs 全部执行）、实现检查器（源码 diff vs 执行探针 vs 层输出比较）。
- **裁决回放实验**：48 个转移（8 条轨迹 × 6 个控制），自由反思 vs 裁决约束。

## 5. 实验数量与充分性

- **规模**：7 个模型 × 7 个任务的完整端点表（表 3–9），覆盖 3B 到 32B；量化基准对比 9 个基线；发现框架对比 4 个臂 × 8 个配对种子；多组消融覆盖三个阶段的每个组件。
- **统计严谨性**：
  - 跨校准种子 {0,3,5} 的重复实验，报告均值 ± 标准差与配对 t 区间（$n=3$，$t_{0.975,2}=4.303$）。
  - 预注册最小差异阈值（Fit-7 为 0.002，Fit-3 为 0.003）。
  - 搜索对比使用 8 个配对种子与 95% CI。
  - 实现检查器评估使用 40 个注入案例，两名盲标注者一致性 38/40。
- **公平性**：
  - 所有方法共享同一 MXFP4 操作数/编码合约、校准数据、评估器与资源上限。
  - 搜索可见模型（Qwen3-4B）与留出模型（Llama-3.1-8B）严格分离，遵循 holdout 原则（Dwork et al., 2015）。
  - HiRes 在其他模型评估前冻结，后验消融不反馈回算法设计。
  - 匹配 240 次评估预算下，QuantForge 仅用 141 次新程序评估即达到更优结果。
- **充分性评价**：实验设计**相当充分且客观**，覆盖模型规模、架构家族（含新架构 OLMo-2）、任务类型、校准种子、搜索预算等多个维度

，并包含预注册阈值、配对种子、盲标注等统计控制。不过仍存在若干可讨论之处：

- **种子数量偏少**：几何组件的跨种子重复仅 $n=3$（{0,3,5}），虽然报告了 $t$ 区间，但检验力有限，难以排除校准数据顺序带来的偶然性。
- **搜索可见模型单一**：搜索阶段仅在 Qwen3-4B 上进行，留出迁移虽用 Llama-3.1-8B，但"搜索→迁移"的泛化结论建立在单一源模型之上，跨架构迁移的稳健性证据仍较薄弱。
- **基线复现口径**：9 个基线是否全部在相同硬件、相同 MXFP4 合约下由作者重跑，还是部分引用原论文数字，未完全澄清，可能影响对比的严格同质性。
- **发现框架对比的规模**：4 个臂 × 8 个配对种子共 32 次搜索运行，对于"发现算法结构"这一高方差过程而言样本仍属中等，作者以配对设计部分缓解了该问题。

## 6. 主要结果（按论文报告方向）

### 6.1 量化质量
- **Fit-7 / Robust Fit**：HiRes 在 7 个模型上整体优于 9 个量化基线，且在多数任务上相对 BF16 的损伤显著小于 RTN、GPTQ 系列与专用 W4A4 方法（BRQ、WUSH、TORQ、BATQuant、SpinQuant、FOCUS）。
- **规模稳健性**：从 3B 到 32B，HiRes 的退化幅度随规模增大未出现恶化趋势，32B 上仍保持较低损伤，说明分层残差求解并非仅对小型模型有效。
- **架构覆盖**：在 Llama-3 系列、Qwen3 系列、Mistral 与 OLMo-2 上均取得一致收益，暗示该分解对注意力与 MLP 结构差异不敏感。

### 6.2 阶段累积效应
严格 RTN → +几何塑造 → +离散实现 → +结构恢复的累积消融显示：
- **几何塑造**贡献最大的单步增益，验证了"块共享指数耦合"是 MXFP4 的核心瓶颈这一动机。
- **离散实现**（GPTQ + 动态 A4 单码精化）在几何固定后继续降低误差，且精化规则优于最近舍入与仅敏感度变体，支持"首选激活码依赖已实现 W4 算子"的论断。
- **结构恢复**贡献相对较小但方向一致，且注意力恢复与 MLP 恢复的组合优于任一单独路径。

### 6.3 关键对照结论
- **重测量必要性**：在 A4 编码后拟合恢复系数优于编码前拟合，直接支持"修订后必须重新测量"这一渐进残差分解的核心机制。
- **几何组件**：同时移除局部交互 $K$ 与平衡 $D$ 的损伤大于单独移除，说明二者作用互补而非冗余。
- **发现框架**：在 240 次评估的匹配预算下，QuantForge 优于 Score-only、TextMem、ReflectMem；消融显示残差编译、最小判别控制选择与执行探针式实现检查器各自均有正贡献。
- **裁决回放**：48 个转移上，受裁决约束的反思优于自由反思，说明"分数不可解释"的痛点被残差裁决机制有效缓解。

## 7. 贡献与创新点

1. **问题重构**：把"设计更好的 MXFP4 量化器"重构为"在解释竞争的搜索中逐步确定算法的分解结构"，将量化器设计从手工试错转为可判定的实验流程。
2. **QuantForge 框架**：提出以算法残差为核心、以反事实控制选择为判别器、以残差编译为程序修改依据的发现框架，允许"有用但解释被否定"的程序继续存活。
3. **HiRes 量化器**：给出三阶段（几何塑造 / 离散实现 / 结构恢复）的 MXFP4 W4A4 方案，其中配对变换保持函数、$I+K$ 可逆性保证、失配感知的动态 A4 单码精化、以及基于重测残差的两级恢复均为具体可复现的技术构件。
4. **实证验证**：在 7 模型 / 7 任务上以严格 MXFP4 合约、预注册阈值、配对种子与盲标注实现较充分的对比与消融。
5. **低部署开销**：前向延迟仅增约 4%，存储仅增约 2%，使方法具备工程可用性。

## 8. 局限与待解问题

- **搜索算力未披露**：GPU 数量、总计算小时与搜索阶段总算力均缺失，难以评估方法的实际发现成本。
- **源模型单一**：搜索仅在 Qwen3-4B 上进行，迁移结论的普适性受限。
- **校准依赖**：所有结果基于 128×2048 的 C4-train 校准序列（seed 0），校准数据分布偏移下的行为未被检验。
- **评估范围**：仅覆盖语言建模与常识推理类任务，未涉及长上下文、指令跟随、代码或多模态场景；亦未评估 KV 缓存启用时的表现。
- **理论保证有限**：$I+K$ 的可逆性与 $\|K\|_2\le 1/8$ 提供了构造层面的稳定性，但端到端误差界仍以经验测量为主。
- **恢复系数的可解释性**：三系数 MLP 恢复与标量注意力恢复属于低容量校正，其收益来源（是否补偿了特定通道/层）未被进一步剖析。

## 9. 总体评价

论文的价值不在单个量化技巧，而在于把"分数驱动的程序演化"推进为"解释驱动的残差分解"：它明确指出性能分数无法指示下一步修改方向，并以受控实验与残差编译补上这一环。HiRes 可视为该框架的一次成功产出——其三个阶段恰好对应框架所区分的三类可判定残差（坐标几何、离散码字、下游结构）。方法的工程开销可控，实验在合约一致性、预注册阈值与留出模型隔离上表现严谨，主要短板在于搜索算力披露与源模型多样性。若后续工作能扩展搜索源模型、公开搜索成本、并给出更紧的误差界，这一"发现即分解"的范式有望迁移到更广的低精度算子设计问题。
