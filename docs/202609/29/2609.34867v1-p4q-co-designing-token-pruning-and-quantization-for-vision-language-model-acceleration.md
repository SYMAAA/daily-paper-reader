## 摘要
视觉语言模型已在广泛的多模态应用中取得强劲性能，但其高昂的计算与内存开销阻碍了高效部署。视觉令牌剪枝与训练后量化从两个互补的维度降低推理开销，即序列长度和数值精度。现有工作流通常独立优化这些技术，或按顺序依次应用它们。二者不同的优化目标使关键交互问题未被解决，并制约了可实现的压缩性能。我们重新审视这些设计，并提出 P4Q，一个实用的协同设计框架，联合优化视觉令牌剪枝与低位量化，以实现高效的 VLM 推理。首先，P4Q 在 LLM 之前引入一种量化感知的视觉令牌选择策略。它对投影器所生成特征的副本施加伪量化，并利用这些伪量化特征计算得到的统计量来选择视觉令牌，从而使选择器基于特征的决策依赖于模拟的低位扰动。其次，P4Q 引入一种剪枝感知的量化校准策略。它采用与剪枝相同的选择策略，在保留令牌分布上校准量化模型，从而使校准过程与部署时使用的剪枝执行路径保持一致。通过耦合这两个组件，P4Q 在保持相当任务性能的同时实现了显著的推理加速，相比独立优化的流程取得了更好的效率-精度权衡。例如，在 LLaVA-NeXT 上，P4Q 在八个不同测试集上实现了平均 2.8 倍的端到端推理加速，同时保持比先前压缩与量化方法更高的精度。

## Abstract
Vision language models have achieved strong performance across a wide range of multimodal applications, yet their substantial computational and memory costs hinder efficient deployment. Visual token pruning and post-training quantization reduce inference overhead along two complementary dimensions, namely sequence length and numerical precision. Existing workflows typically optimize these techniques independently or apply them sequentially. Their distinct optimization objectives leave critical interactions unaddressed and constrain the achievable compression performance. We revisit these designs and present P4Q, a practical co-design framework that jointly optimizes visual token pruning and low-bit quantization for efficient VLM inference. First, P4Q introduces a quantization-aware visual token selection strategy before the LLM. It applies fake quantization to copies of the features produced by the projector and selects visual tokens using statistics computed from these fake-quantized features, thereby conditioning the selector's feature-based decisions on simulated low-bit perturbations. Second, P4Q introduces a pruning-aware quantization calibration strategy. It uses the same selection strategy as pruning to calibrate the quantized model on the retained-token distribution, thereby aligning the calibration process with the pruned execution path used during deployment. By coupling these two components, P4Q achieves substantial inference speedups while maintaining comparable task performance, resulting in a better efficiency-accuracy trade-off than independently optimized pipelines. For instance, on LLaVA-NeXT, P4Q achieves an average end-to-end inference speedup of 2.8x across eight distinct test sets, while retaining higher accuracy than prior compression and quantization methods.

## 二、方法论

### 2.1 核心思想

P4Q 通过**两个互补组件**耦合剪枝与量化：在 LLM 前进行**量化感知的令牌选择**，在量化校准阶段采用**剪枝感知的校准策略**，使校准分布与部署时的剪枝执行路径一致。

### 2.2 关键技术细节

**（1）量化感知的 LLM 前令牌选择（Quantization-Aware Pre-LLM Selection）**

- **位置**：在语言模型之前进行，避免依赖量化解码器内部逐渐扰动后的注意力值或隐状态。
- **伪量化机制**：对投影器（projector）输出的特征副本施加**selector-only 伪量化**，选择器基于伪量化特征统计量做决策；而实际送入 LLM 的仍是原始 FP16 表示。
- **三阶段互补选择**，按预算比例 α、β、γ 分配：
  - **查询相关性（Query Relevance，α=0.3）**：从问题中提取名词/专有名词，计算其平均子词嵌入与视觉令牌伪量化特征的余弦相似度，逐概念做 Top-K 选择，保留与多个实体/属性相关的局部视觉证据。
  - **视觉显著性（Visual Saliency，β=0.2）**：从视觉塔最后一层多头自注意力的 [CLS]→patch 注意力权重（跨头平均）中提取显著性分数，补充查询未明确提及的显著物体与场景信息。
  - **视觉多样性（Visual Diversity，γ=0.5）**：对剩余候选池执行 max-min 多样性采样，每次选取与当前保留集最大余弦相似度最低的候选，逐步扩展视觉覆盖。
- 整体选择公式：`S_keep = α·TopK(查询相关性) + β·TopK(视觉显著性) + γ·Div(视觉多样性)`。

**（2）剪枝感知的量化校准（Pruning-Aware Quantization Calibration）**

- **校准集构建**：使用 128 个固定随机种子的图像-问题对（来自 ScienceQA 训练集）。
- **关键操作**：对每个校准样本，使用与推理时**完全相同的 P4Q 选择器和令牌预算**生成剪枝后的多模态序列，再进行分块量化校准。
- **校准目标**：对语言模型第 ℓ 块，最小化剪枝序列上 W4A4 伪量化块输出与 FP16 块输出之间的均方重构误差（式 5）。校准逐块进行，第 ℓ 块的 FP16 输出作为第 ℓ+1 块的输入，避免上游量化误差累积。
- **可学习参数**：因子化通道变换、逐通道对角缩放、权重与激活裁剪因子；原模型参数冻结。对角缩放初始化插值指数 0.3，每块校准 15 个 epoch，AdamW 优化器，变换矩阵学习率 5×10⁻³、裁剪参数 5×10⁻²，余弦退火至 5×10⁻⁶。

### 2.3 算法流程（文字说明）

1. 对每个输入图像-问题对，提取投影器特征并施加伪量化；
2. 依次执行查询相关性、视觉显著性、视觉多样性三阶段选择，得到保留令牌索引；
3. 将原始 FP16 特征按保留索引送入 LLM 进行剪枝推理；
4. 离线校准阶段：用同一选择器和预算构造剪枝校准集，逐块最小化重构误差拟合量化参数；
5. 部署时使用 W4A4 权重与激活执行剪枝后推理。

## 六、主要结论与发现

- **效率-精度权衡显著优于独立优化流程**：
  - LLaVA-NeXT-7B：平均 **2.8× 端到端加速**，峰值显存降至 Vanilla 的 **51.3%**，平均精度保留 **95.5%**（8 基准平均）。
  - LLaVA-1.5-7B：平均 **2.49× 加速**，峰值显存降至 **42.0%**，平均精度保留 **96.1%**。
- **消融实验验证协同设计的必要性**：
  - 仅顺序执行（先量化后剪枝，Row 2）精度保留 92.1%，比完整 P4Q（95.5%）低 3.4 个百分点，说明简单叠加不能获得协同增益。
  - 伪量化选择（FQP）与剪枝感知校准（PC）各自贡献正向增益，二者结合达到最佳。
- **泛化性**：在 Qwen2.5-VL-7B 上，P4Q 在 66.7% 和 88.9% 两种剪枝率下均达到与 SpecFlow 相当甚至略优的平均性能。
- **与 QUOTA 对比**：在仅保留 11% 令牌时，P4Q 精度超过 QUOTA 在 20% 保留率下的结果 1.1 个百分点，在 10% 保留率下领先 3 个百分点。
- **秩位移实证**：W4A4 在 LLaVA-NeXT-7B 各解码层引起显著视觉令牌重要性排序变化（Layer 2/4/8/16 的 PRAS 分别为 7.7%/9.4%/12.4%/21.6%），验证了量化感知选择的必要性。
- **Prefill 加速**：LLaVA-NeXT-7B 上平均 prefill 加速 **3.33×**，最大达 4.58×（VizWiz）。

## 七、优点

- **问题识别精准**：清晰刻画了剪枝与量化串行组合带来的两类失配（排序漂移与校准分布偏移），并给出了理论形式化与实证验证（秩位移可视化、PRAS 指标）。
- **协同设计思路简洁有效**：两个组件各自针对一类失配，且实现成本低（伪量化仅用于选择器，不改变前向精度；校准仅改变校准数据构造方式），易于集成到现有 PTQ 流程。
- **选择器设计合理**：三阶段互补信号（查询相关性 + 视觉显著性 + 多样性）覆盖语义、显著性与覆盖度，且放在 LLM 前避免了量化解码器内部的不稳定注意力信号。
- **对超参鲁棒**：令牌预算分配比例在较宽范围内变化时，平均精度保留率波动仅 1.2 个百分点，说明方法不敏感于精确比例。
- **实验覆盖面较广**：跨 3 个 VLM 架构、8 个基准、多种压缩基线，并提供了详细的效率与显存测量。
- **与同期工作的对比透明**：论文明确说明 QUOTA 为 arXiv 同期工作，并注明其原始论文报告的保留率来源，学术表达较为诚实。

- **校准成本与可迁移性讨论不足**：剪枝感知校准需要针对每个「模型 × 剪枝率 × 量化配置」组合重新构造剪枝校准集并逐块优化，论文未报告校准的总耗时、显存开销与收敛稳定性，也未讨论该校准参数能否跨模型或跨剪枝预算复用，这直接影响方法的实际部署成本评估。

- **压缩维度未完全打通**：P4Q 保持 KV cache 为 FP16、视觉塔与投影器为全精度。这意味着论文所声称的"协同压缩"主要发生在**视觉令牌序列维度 + LLM 权重/激活数值维度**，而 KV cache 量化与视觉塔量化这两个同样与令牌剪枝强耦合的环节被排除在外，剪枝—量化交互的全貌尚未被完整刻画。

- **配置空间探索有限**：主实验固定在 88.9% 剪枝率 + W4A4，未系统扫描剪枝率与位宽（如 W3A4、W4A8、W2A4）的二维组合，缺少效率—精度帕累托前沿的完整呈现，因而难以判断 P4Q 的增益在何种压缩强度区间最为显著、在何种强度下会失效。

- **缺少与训练式压缩方法的对比**：基线集中在 PTQ 与免训练剪枝方法，未与量化感知训练（QAT）、知识蒸馏或联合微调类方法对比，因此"免训练协同"相对于"训练式协同"的成本—收益优势未被量化。

- **效率测量的外推性受限**：端到端加速与显存数据均在单卡 RTX 4090、batch size = 1 下测得，未验证在 batch > 1、多卡张量并行或不同 GPU 架构（如 A100/H100）下的表现；此外 prefill 与 decode 两阶段的加速贡献未分别拆解，而令牌剪枝理论上主要收益于 prefill，其解码阶段收益应相对有限，这一点缺少显式说明。

- **理论刻画偏经验性**：对"排序漂移"的论证主要依赖 PRAS 这一经验指标与可视化，未给出失配误差如何传播至最终输出的形式化上界或近似保证，方法的必要性论证在实证层面较强、在理论层面较弱。

- **选择器对外部组件的依赖**：查询相关性依赖问题文本中的名词/专有名词抽取，视觉显著性依赖视觉塔最后一层的 [CLS]→patch 注意力，这使方法对不采用 CLS token 设计的视觉编码器（如部分 SigLIP/InternVL 变体）的适配性需要额外验证。

- **评测场景相对单一**：8 个基准均为单图、单轮视觉问答类任务，未覆盖视频理解、多图交错、长上下文或 OCR 密集等更贴近真实部署压力的多模态场景，剪枝选择器在这些场景下的鲁棒性未知。

## 九、总体评价

P4Q 的核心价值在于**把一个被普遍忽视的工程事实提升为明确的研究问题**：视觉令牌剪枝与训练后量化并非正交，串行组合会同时引入"量化改变剪枝排序"和"剪枝改变量化校准分布"两类失配。论文围绕这两类失配各设计了一个低成本的对应组件——LLM 前的伪量化选择器与剪枝感知的逐块校准——从而在不引入训练、不改变推理前向精度的前提下取得协同增益。方法动机清晰、组件与问题一一对应、实现侵入性小，具备较好的可复现性与工程落地潜力。

从证据强度看，主实验在 2 个 7B 模型、8 个基准上验证了约 2.5–2.8× 端到端加速、显存降至 42%–51%、平均精度保留 95%–96% 的权衡，消融实验进一步表明"简单串行"比"协同设计"低约 3.4 个百分点，直接支撑了论文的核心主张；与同期工作 QUOTA 的对比也在更严苛的保留率下取得领先。这些都构成了较为扎实的经验证据。

从局限看，论文的短板主要集中在**覆盖度**而非**方法论**：模型规模仅限 7B、压缩配置单一、KV cache 与视觉塔未纳入协同范围、校准成本未披露、缺少训练式方法对照与多卡/多 batch 的效率外推、理论刻画偏经验。这些局限并不否定论文结论，但限制了其"通用协同框架"这一更宏大定位的说服力。

**适用判断**：对于希望在资源受限（单卡 24GB 级）环境下部署 7B 级 LLaVA 式 VLM、且能接受一次性离线校准成本的工程场景，P4Q 是一个实用且易于集成的方案；对于需要跨架构、跨规模、跨压缩强度泛化的研究场景，则仍需补充更多维度的验证。
