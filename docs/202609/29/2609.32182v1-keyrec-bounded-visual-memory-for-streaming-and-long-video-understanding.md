## 摘要
视觉-语言模型正越来越多地用于理解长视频和连续流。然而，密集视觉 token 会随视频时长而累积，使长上下文推理的成本高得难以承受。现有的免训练视觉 token 选择方法通过保留信息量大的 token 来降低这一成本，但可能丢失连贯的事件证据，也无法区分细节丰富的近期观测与长程历史。我们提出 KeyRec，一个用于构建有界视觉记忆的免训练框架。在与查询无关的写入过程中，KeyRec 将细粒度的近期观测保存在视觉缓存中，并将历史证据组织为结构化事件库。候选事件根据其相对于已存储事件的新颖性被提出，并通过在线添加—合并—淘汰更新进行维护。当问题到来时，一个纯文本路由器会在近期记忆与事件记忆之间自适应地分配固定的读取预算，而无需重新处理历史帧。KeyRec 作用于面向模型的视觉嵌入，并同时支持模块化编码器—投影器 VLM 以及无编码器和投影器的 NEO-ov 架构。在四个流式与长视频基准和三个 VLM 主干上，KeyRec 仅使用密集解码器端视觉 token 预算的 10%，就在 15 个设置中的 13 个取得了最佳压缩性能。它在实时问题上以 2.21—18.37 个点超过最强的压缩基线，在六个长视频设置中的五个取得最佳压缩结果，并在每个 NEO-ov 2B 设置中表现最佳。

## Abstract
Vision-language models are increasingly used to understand long videos and continuous streams. However, dense visual tokens accumulate with video duration, making long-context inference prohibitively expensive. Existing training-free visual-token selection methods reduce this cost by retaining informative tokens, but may lose coherent event evidence and fail to distinguish detailed recent observations from long-range history. We propose \textbf{KeyRec}, a training-free framework for constructing bounded visual memory. During query-agnostic writing, KeyRec preserves fine-grained recent observations in a visual cache and organizes historical evidence into a structured event bank. Candidate events are proposed according to their novelty relative to previously stored events and maintained through an online add--merge--evict update. When a question arrives, a text-only router adaptively allocates a fixed readout budget between recent and event memory, without reprocessing historical frames. KeyRec operates on model-facing visual embeddings and supports both modular encoder--projector VLMs and the encoder- and projector-free NEO-ov architecture. Across four streaming and long-video benchmarks and three VLM backbones, KeyRec achieves the best compressed performance in 13 of 15 settings using only 10\% of the dense decoder-facing visual-token budget. It outperforms the strongest compressed baseline by 2.21--18.37 points on real-time questions, achieves the best compressed result in five of six long-video settings, and performs best in every NEO-ov 2B setting.

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言模型（VLM）正被用于长视频与连续流理解。但每帧通常被编码为几十到几百个视觉 token，视觉序列随帧数线性增长，预填充阶段密集自注意力计算随序列长度二次增长，导致长上下文推理成本过高。
- **流式与长视频的特殊困难**：
  - 流式视频时长未知、查询随时到达，要求因果处理与低延迟；
  - 长视频可能超出显存或上下文预算，且多个问题会反复处理同一段视频。
- **现有免训练视觉 token 选择方法的局限**：
  - 新颖性通常只对近期帧、粗粒度锚点或全局语义表示衡量，未把历史组织成时序局部事件，导致演化事件被碎片化，或视觉相似但时间不同的事件被混淆；
  - 独立选择重要 token 会丢弃连接“人物—动作—物体—场景”的连贯事件证据；
  - 对近期细节与长程历史采用统一保留策略，均匀稀疏记忆可能保留宏观语义，却丢失“当前正在发生什么”所需的细粒度证据。
- **整体含义**：论文主张把压缩从“token 选择”提升为“有界视觉记忆组织”，将**查询无关的记忆写入**与**查询自适应的固定预算读取**解耦。这样既能保持持久存储有界，又能在每个查询到来时只读取固定预算的证据，而不重新处理历史帧。

## 2. 方法论

### 2.1 总体框架

- 形式化目标：
  - 记忆更新：\(M_t = \text{Update}_M(M_{t-1}, H_t)\)，且 \(|M_t| \le S\)；
  - 查询读取：\(Z_q = \text{Read}(M_\tau, q)\)，且 \(|Z_q| \le B\)；
  - 答案生成：\(\hat{y} = \text{VLM}(Z_q, q)\)，不重新访问视频。
- KeyRec 将记忆分为两部分：\(M_t = (C_t, E_t)\)。
  - \(C_t\)：近期视觉缓存，保留最近帧的细粒度证据，最多 \(N_C\) 个 token；
  - \(E_t\)：关键事件库，保留有界的历史事件，最多 \(K\) 个事件，每个事件最多 \(m\) 个 token；
  - 总持久存储满足 \(N_C + Km \le S\)。
- 记忆构建不依赖查询；查询时由纯文本路由器分配固定读取预算 \(B\)。

### 2.2 查询无关记忆构建

- **近期视觉缓存**：
  - 对每个新帧 \(H_t\)，执行 \(C_t = \text{Tail}_{N_C}(C_{t-1} \parallel H_t)\)；
  - 即只保留最新 \(N_C\) 个视觉 token，旧 token 逐渐被挤出。
- **关键事件记忆**：
  - 每个事件表示为 \(e_k = (r_k, P_k, \tau_k, u_k)\)：
    - \(r_k\)：紧凑的路由嵌入；
    - \(P_k\)：存储的视觉 token；
    - \(\tau_k\)：对应时间戳；
    - \(u_k\)：事件效用。
- **候选事件构建**：
  - 对每个 token 计算新颖度 \(\nu_{t,i} = 1 - \max_{e_k \in E_{t-1}} \cos(h_{t,i}, r_k)\)；
  - 当事件库为空时 \(\nu_{t,i}=1\)；
  - 选取帧内最新颖的 \(m\) 个 token，按归一化新颖度加权求和得到候选路由 \(r_t\)；
  - 同一批 token 构成候选事件 token \(P_t\)，保留时间戳，候选效用为平均新颖度。
- **有界事件库更新（在线增—并—删）**：
  - 先找最相似存储路由：\(k^\star = \arg\max_k \cos(r_t, r_k)\)；
  - 合并需同时满足语义相似度与时间局部性：\(s_{t,k^\star} \ge \gamma\) 且时间间隔 \(g_{t,k^\star} \le \delta\)；
  - 若不满足，则作为新事件插入；若超过容量 \(K\)，执行淘汰；
  - 若满足，则合并：
    - 路由按移动平均更新：\(r_{k^\star} \leftarrow \text{Norm}((1-\beta)r_{k^\star} + \beta r_t)\)；
    - token 与时间戳按时间排序后，用 \(\text{Uniform}_m\) 均匀保留最多 \(m\) 个条目，以保持事件时间跨度；
    - 效用取最大值：\(u_{k^\star} \leftarrow \max(u_{k^\star}, u_t)\)，避免短暂显著变化被相邻冗余观测稀释。
  - **淘汰规则**：当事件数超过 \(K\)，计算保留分数
    \[
    S_{\text{ret}}(e_k) = u_k + \lambda d^{\text{temp}}_k
    \]
    其中 \(d^{\text{temp}}_k\) 是事件中心时间到最近事件中心时间的距离；淘汰分数最低者。效用项偏好有独特视觉变化的事件，时间项偏好覆盖不足时间区域的事件。

### 2.3 查询自适应固定预算读取

- 定义五个读取状态，从偏近期到偏事件：
  - AllRecent、HeavyRecent、Balanced、HeavyEvent、AllEvent。
- 纯文本路由器只观察问题与两类记忆的文本描述，不访问也不重处理视频：
  \[
  z_q = \text{Router}_{\text{VLM}}(q), \quad z_q \in Z
  \]
- 令 \(\pi_q \in [0,1]\) 为分配给事件记忆的读取比例：
  - \(\pi_q=0\) 对应 AllRecent，\(\pi_q=1\) 对应 AllEvent；
  - 事件数 \(k_q = \min(K, \text{round}(\pi_q B / m))\)；
  - 近期 token 数 \(r_q = B - k_q m\)。
- 历史事件选择策略：
  - HeavyRecent 与 Balanced：按问题平均池化嵌入与事件路由的余弦相似度做相关性检索；
  - HeavyEvent 与 AllEvent：按事件中心时间排序并均匀选取，偏向时间覆盖；
  - AllRecent：不检索历史事件。
- 选中的事件恢复时间顺序，近期贡献为 \(C_q = \text{Tail}_{r_q}(C_\tau)\)，最终 \(Z_q\) 总 token 数不超过 \(B\)。
- **记忆序列化**：
  - 默认将读取内容序列化为带中性编号标签的独立记忆段，保留边界但不赋予语义事件类型；
  - 对比模板包括 Naive（直接拼接、无边界）与 Detailed（暴露“关键事件”“近期上下文”等语义标签和时间范围）。

### 2.4 在原生 One-Vision 模型上的适配

- 现有压缩方法多针对模块化 VLM（视觉编码器 + 投影器）；NEO-ov 等原生 one-vision 模型使用轻量 patch embedding，并在统一骨干中联合处理视觉与文本 token。
- KeyRec 直接作用于面向模型的视觉嵌入，因此记忆构建与读取机制不变。
- 对 NEO-ov 的唯一适配是保留每个保留 token 的位置元数据 \(\xi_i = (h_i, \tau_i, p^h_i, p^w_i)\)，即源帧与原始空间位置；选择与下采样时元数据跟随同一索引，读取时按源时间排序并恢复到原生时空位置，再插入对应 `<IMG_CONTEXT>` 位置。
- 适配只需结构保持的位置簿记，不修改底层记忆算法，也不重建密集视觉网格。
