## 摘要
视觉标记剪枝通过仅保留一部分视觉标记来降低多模态大语言模型（MLLMs）的推理开销。现有方法通常基于重要性或冗余度来选择标记。然而，我们观察到这些标准在不同输入间产生稳定的空间偏差，并且并不总是优于简单的均匀网格采样，这突显了广泛空间覆盖的价值。受此启发，我们提出了S$^2$Prune，一种无需训练、在保持空间覆盖的同时使标记密度适应局部图像结构的剪枝方法。我们首先将图像划分为若干区域，并为每个区域分配至少一个标记以保持覆盖。然后根据拉普拉斯变化量分配剩余标记预算，为结构更丰富的区域分配更多标记。我们使用从第一个解码器块计算得到的早期表示变化（ERC）来选择每个区域内的代表性标记。我们在多种设置和两种MLLM架构上评估了S$^2$Prune。在Qwen2.5-VL-7B-Instruct上，它在所评估的免训练剪枝方法中达到了最高的平均准确率。仅使用原始576个视觉标记中的32个，它仍保留了完整模型性能的79.3%。代码可在https://github.com/yuanyuanjia71-spec/S2Prune获取。

## Abstract
Visual token pruning reduces the inference overhead of multimodal large language models (MLLMs) by retaining only a subset of visual tokens. Existing methods usually select tokens based on importance or redundancy. However, we observe that these criteria produce stable spatial biases across inputs and do not always outperform simple Uniform Grid sampling, highlighting the value of broad spatial coverage. Motivated by this, we propose S$^2$Prune, a training-free pruning method that preserves spatial coverage while adapting token density to local image structure. We first divide the image into regions and assign at least one token to each region to preserve coverage. The remaining token budget is then distributed according to Laplacian variation, giving more tokens to regions with richer structure. We then use Early Representation Change (ERC), computed from the first decoder block, to select representative tokens within each region. We evaluate S$^2$Prune across diverse settings and two MLLM architectures. On Qwen2.5-VL-7B-Instruct, it achieves the highest average accuracy among the evaluated training-free pruning methods. With only 32 of the original 576 visual tokens, it still retains 79.3% of the full-model performance. Code is available at https://github.com/yuanyuanjia71-spec/S2Prune.

## 论文总结：S²Prune：用于多模态大语言模型的空间结构化视觉标记剪枝

### 1. 核心问题与研究动机
- **核心问题**：多模态大语言模型（MLLMs）将视觉输入编码为大量视觉标记，导致注意力计算与预填充推理开销显著增加。视觉标记剪枝旨在仅保留一部分关键标记，以降低推理成本，同时尽量保持下游任务性能。
- **已有方法的局限**：现有剪枝方法通常基于单个标记的得分——如注意力重要性（FastV）、视觉冗余度（DART、GPrune）、相似度/多样性（VisionZip）等——进行全局 Top-B 选择。但这些方法普遍忽视了一个关键问题：不同得分准则会带来**稳定的空间偏差**，即不管输入内容如何，被选中的标记常常聚集在图像特定位置（如边缘区域），导致空间覆盖不均。
- **关键观察**：
  1. 简单的 **Uniform Grid**（均匀网格采样）在激进剪枝下能取得与复杂评分准则相当甚至更好的结果，说明**空间覆盖本身**比精巧的逐标记得分更重要。
  2. 全局评分决定的不只是“选哪些标记”，更决定了有限的预算在图像空间中**花在哪里**。因此，标记剪枝应将空间分配（where）与代表选取（which）分开审视。
  3. 均匀网格的问题并非在于“覆盖”本身，而在于所有区域使用相同的恒定密度——对于图像内结构分布极不均匀的场景（如文字、精细纹理、物体边界集中的区域），均匀密度或过度代表平滑区域，或欠代表细节丰富区域，造成预算浪费。
- **整体含义**：有效的剪枝应在保留宽泛空间覆盖的同时，使标记密度自适应图像局部结构复杂度——这与图像压缩中的码率分配问题高度相似：平滑区域需要较少码率，细节区域需要较大码率。

### 2. 方法论：S²Prune
S²Prune 是一个**免训练（training-free）**框架，将剪枝过程分为两个解耦的阶段：**空间预算分配**（决定每个图像区域应保留多少标记）和**局部代表选取**（决定区域内具体保留哪一个标记）。

#### (1) 自适应空间脚手架（Adaptive Spatial Scaffold）
- 将视觉标记网格等分为多个粗粒度区域（如 $5\times5$ 网格），每个区域至少保留一个标记以保证空间覆盖。
- 以 **拉普拉斯方差**（Variance of Laplacian responses）度量每个区域的局部结构复杂度：
  - 先将完整输入图像转为灰度图，用复制填充（replicate padding）计算整个图像的四邻域拉普拉斯响应图 L；
  - 将各区域映射到图像域，计算区域内响应方差作为结构得分：$c^{raw}_g = Var(L|_{\Omega_g})$；
  - 对原始得分在单张图像内做 min-max 归一化得到 $c_g$。
- 将剩余 $B-G$ 个标记按结构得分比例分配给各区域，并受容量约束：
$$1 \leq B_g \leq |R_g|,\quad \sum\nolimits_{g} B_g = B$$
- 使用迭代最大余数法（iterative largest-remainder procedure）完成整数分配；当区域饱和时，超额预算重新分配给未饱和区域。
- 每个区域被递归划分为 $B_g$ 个近似等面积、互不重叠的矩形单元（cell）。
- **归一化结构分数的意义**：其衡量的是图像局部变化量（结构的表示需求），而非与当前问题有关的语义相关性，使分配策略与下游问题无关。

#### (2) 基于早期表示变化（ERC）的局部选择
- 在解码器 Layer 0（第一个 decoder block）后，计算每个视觉标记的**早期表示变化**得分：
$$r_i = \| h^1_i - h^0_i \|_2$$
其中 $h_i^0$ 与 $h_i^1$ 分别为解码器 Layer 0 前后的隐藏表示。
- 在每个局部单元内，仅保留 ERC 得分最高的标记：
$$i^*_{g,k} = \arg\max_{i \in C_{g,k}}\; r_i$$
- 打分仅在单元内部进行，不同区域之间不做跨区比较——预算（which region 有多少 token）已由结构复杂度决定，ERC 只承担“该单元内哪个 token 最具代表性”的职责。
- 保留标记按原始序列索引排序，保留原 M-RoPE 位置 ID，物理删除其他视觉标记，之后所有后续解码层仅处理保留的 B 个标记。

### 6. 主要结论与发现
- **空间角色未被充分认识**：不同 token 选择准则会在空间上留下稳定且差异明显的选择模式（如 FastV 偏好边缘、VisionZip 较均衡），这种空间偏差难以通过换用更深层剪枝等方式消除。
- **简单空间采样不简单**：Uniform Grid 优于随机，且在多个 benchmark 上可匹敌甚至超过复杂的逐 token 重要度方法，说明空间覆盖本身是剪枝鲁棒性的重要来源。
- **结构自适应有增益且与结构异质性正相关**：当图像内局部结构分布不均匀时（高异质性），结构自适应的密度分配相对均匀密度有明显优势（B=32 时最高增益 2.79 pp），且该增益随预算收紧而增大。
- **分离“预算花在哪里”与“选择哪个”更有效**：Laplacian 变化量确定**各区域容量**，ERC 负责局部代表选取，二者解耦后整体效果优于端到端的全局评分方法。
- **最终成绩**：在 Qwen2.5-VL-7B 上分别以 0.1、0.3、0.9 pp 的优势超过最强基线，B=32 时达到 55.9 Acc / 79.3% Rel；跨架构到 LLaVA-OneVision-7B 上亦一致领先。

### 7. 优点与亮点
- **方法视角新颖且简洁可解释**：将视觉 token 剪枝类比为图像压缩中的码率分配问题，将空间分配与代表选择解耦，思想清楚，工程实现容易（仅需计算图像拉普拉斯方差与一层解码器的表示变化）。
- **充分的动机支持**：通过多个受控实验（Global Top-B 下的空间偏差统计、Random 与 Uniform Grid 对照、异质性分组分析等）循序渐进的支撑核心论点；
- **真正免训练、零参数**：无需任何训练或微调、无需问题文本参与（不依赖 query attention），剪枝逻辑完全与任务无关，泛化性好、易移植；
- **实验严谨**：控制变量的消融、跨预算和跨网格大小的稳定性分析、跨架构验证以及多预算连续对比，保证了实验结论的可信度；
- **保留原顺序与位置编码**：剪枝后按原始索引排序、保留原 M-RoPE 位置 ID，避免引入额外位置错配偏差。

### 8. 不足与局限
- **性能优势幅度有限**：即使平均精度最高，B=128/64/32 下相对最强基线的 Acc 优势仅 0.1 / 0.3 / 0.9 pp，单个数据集上并非全面领先，优势主要靠多个 benchmark 的累计体现；
- **结构先验与任务语义之间缺少桥接**：完全使用图像内禀特征（拉普拉斯方差）做区域预算分配，忽略问题语义相关区域；在需要推理与知识整合的任务（如 MMMU）上表现仍存在波动；
- **评估场景有限**：仅验证 7B 两个架构，未扩展到更大规模（如 72B 级）或使用不同视觉编码器/分辨率设置的模型；动态分辨率场景（图像被切分为多个 crop）如何处理尚待研究；
- **无训练属性**也是其局限——在任务自适应、与训练型剪枝方法相结合、进一步提升鲁棒性方面存在天花板；
- **未充分报告方差与统计显著性**：未说明多次运行的标准差，文中差别较小的涨跌可能未做显著性检验；
- **效率分析范围较窄**：仅报告了 POPE 上的 FLOPS/prefill/KV cache，没有报告端到端吞吐、解码延迟（token 生成阶段）或在不同 batch size/硬件条件下的鲁棒性。
