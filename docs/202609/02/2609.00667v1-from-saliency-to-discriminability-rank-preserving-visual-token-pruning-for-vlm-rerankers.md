## 摘要
大型视觉语言模型用作列表式重排序器时，必须联合处理每个查询的数十个候选对象的视觉令牌，因此令牌剪枝对于实际部署至关重要。现有剪枝方法通过注意力显著性保留令牌，但我们表明，显著性与排序贡献系统性错位：视觉上显著的令牌常常捕获跨候选共享的序中立模式。这种不匹配是层依赖的：显著性仅在注意力集中处才具有信息性，而归一化注意力熵可诊断这种可靠性转移（Pearson r=0.87）。我们提出RaDiCal（排序判别校准），一种无需训练的框架，利用归一化注意力熵来决定显著性何时可被信任，将其与无注意力的排序判别先验融合，并从同一信任景观中选择剪枝层。在三个检索基准和多种VLM架构上，RaDiCal以20%令牌预算在Flickr30K上与Dense MRR@10持平，在MSCOCO上超过它，在FashionIQ上位列所有剪枝方法之首，并在10%保留率下于Flickr30K和MSCOCO上保持在1.2个百分点以内。它将FLOPs减少39--45%，并在两种VLM架构上实现1.28--1.45倍的实测加速，无需针对数据集重新调整。

## Abstract
Large vision-language models used as listwise rerankers must jointly process visual tokens from tens of candidates per query, making token pruning essential for practical deployment. Existing pruning methods retain tokens by attention saliency, yet we show that saliency is systematically misaligned with ranking contribution: visually prominent tokens often capture order-neutral patterns shared across candidates. This mismatch is layer-dependent: saliency becomes informative only where attention is concentrated, and normalized attention entropy diagnoses the reliability shift (Pearson r=0.87). We propose RaDiCal (Rank-Discriminative Calibration), a training-free framework that uses normalized attention entropy to decide when saliency can be trusted, fusing it with an attention-free rank-discriminative prior and selecting pruning layers from the same trust landscape. Across three retrieval benchmarks and multiple VLM architectures, RaDiCal matches Dense MRR@10 on Flickr30K and surpasses it on MSCOCO at a 20% token budget, ranks first among all pruning methods on FashionIQ, and holds within 1.2 pp on Flickr30K and MSCOCO at 10% retention. It cuts FLOPs by 39--45% and delivers 1.28--1.45$\times$ measured speedups across two VLM architectures without dataset-specific retuning.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究场景**：大型视觉语言模型（VLM）越来越多地被用作**列表式重排序器（listwise reranker）**，即同时对一个查询对应的数十个候选图像进行联合打分排序。每个高分辨率图像贡献成百上千个视觉 token，列表式重排使视觉 token 成为推理开销的绝对瓶颈，token 剪枝对实际部署至关重要。
- **核心发现的问题**：现有剪枝方法普遍基于**注意力显著性（attention saliency）** 保留重要 token。然而，作者通过诊断实验发现，**显著性与排名贡献存在系统性错位**：视觉上显著的 token（如大块狗身体）往往是所有候选图像共有、不携带排序信息的模式；真正影响排序的是"查询相关且跨候选可区分"的证据（如红色飞盘、接住的动作）。
- **问题更深层的结构**：这种错位**因层而异**——显著性在某些层（注意力集中处）具有信息性，在另一些层（注意力弥散处）则不可靠。固定剪枝层（此前工作的默认做法）要么在显著性不可靠处剪枝、要么错失其信息窗口，因此需要校准而非全盘弃用。
- **整体意义**：压缩 VLM 重排序器需要从"保持单图理解保真度"转变为"保持查询条件下的候选顺序"，即排名保留标准。论文提出了一套无需训练的、以归一化注意力熵为统一坐标的校准框架，弥合显著性剪枝与排名判别之间的鸿沟，实现高压缩率下的重排序质量保持。

## 2. 方法论（核心思想、关键技术细节、流程）

### 2.1 总体框架：RaDiCal（Rank-Discriminative Calibration）

- **核心思想**：用归一化注意力熵 \(H_{norm}\) 同时解决三个耦合问题——**剪什么（what）**、**何时信任显著性（when）**、**在哪几层剪（where）**——它既是显著性可信度的诊断信号，也是 token 分数融合的权重来源，还是剪枝层调度的坐标。

### 2.2 两个互补的 token 级信号

- **判别性 token 重要性（DTI, Discriminative Token Importance）**：一个**无注意力（层不变）**先验，直接从 ViT 编码器输出计算一次，跨所有剪枝层复用。由两个分量几何相乘：
  - \(CCU(t_i^k, C) = 1 - \cos(t_i^k, \bar{v})\)（跨候选独特性）：tokens 与全局图像原型偏离越大越独特；
  - \(QRel(t_i^k, q) = \max(\cos(t_i^k, q_{emb}), 0)\)（查询相关性）：tokens 与查询文本嵌入在语义上越近越相关；
  - \(\mathrm{DTI}(t_i^k) \propto CCU \cdot QRel\)——只有同时"查询相关"和"跨候选可区分"的 token 才可能影响排序。

- **AttentionInfo 显著性（层相关）**：从层级的 KL 散度分解到个体 token：
  - \(\mathrm{AttInfo}_i^{(l,T)} = \max\big(p_i^{(l,T)} \cdot \log(V_T \cdot p_i^{(l,T)}),\, 0\big)\)
  - 当且仅当 token 的注意力权重超过当前活跃 token 集上的均匀基线 \(1/V_T\) 时取得正分；归一化后作为 Saliency 通道。

### 2.3 可信度校准的几何融合

- **信任系数**：\(\alpha^{(l)} = \frac{H_{norm}^{(l)} - H_{min}}{1 - H_{min}} \in [0, 1]\)，其中 \(H_{min}\) 是模型全部层中注意力最集中层的熵值（模型固有，离线一次读取）。\(\alpha=0\) 表示完全信任显著性（AttentionInfo），\(\alpha=1\) 表示显著性不可用、完全由 DTI 主导。
- **融合公式**（几何/log-线性融合）：
  - \(f_i^{(l)} \propto \max(\hat{d}_i, \epsilon)^{\alpha^{(l)}} \cdot \max(\hat{s}_i^{(l)}, \epsilon)^{1-\alpha^{(l)}}\)
  - 优势：尺度不变（DTI 与 Sal 不必同量纲）；在 \(\alpha \in (0,1)\) 时具有软否决行为：任一通道趋零都会压制综合分数；端点处自然退化为纯单信号。

### 2.4 α-Maximin 层调度

- 对给定的剪枝层数 \(K\) 和层间隔守卫 \(g\)，在 α 空间执行**贪心最远点选择**：锚定在最可靠（\(\alpha\) 最小，即 Hnorm 最低）的层，反复挑选离已选集合 α 距离最大的可行层，使 K 个剪枝层覆盖从高熵（DTI 主导）到低熵（显著性主导）的**多样化信任区间**。
- 全局保留率 R 按每层等比例保留实现：每层保留率 \(= R^{1/K}\)，逐层应用后实际保留率恰为 R。

### 2.5 统一流程

- **离线阶段（每模型、每预算一次）**：计算各层的 \(H_{norm}\)，生成剪枝层序和每层保留率。
- **在线阶段（每次推理）**：用 ViT 输出计算一次 DTI → 前向传播至第一个剪枝层 → 计算 AttentionInfo → 按融合分数保留 Top-K token → 继续前向至下一剪枝层，如此往复直至所有 K 层完成。

## 6. 主要结论与发现

- **核心诊断**：注意力显著性和排名贡献在 VLM 列表式重排中系统性错位；\(H_{norm}\) 是显著性可信度的有效诊断信号（与排列校正 z-score 的 Pearson 相关为 0.87），且 \(H_{norm}\) 曲线为模型固有性质（Flickr30K 与 MSCOCO 间 r=0.9993）。
- **性能表现**：R=20% 预算下，RaDiCal 在 MSCOCO 上超过 Dense MRR@10（59.09 vs. 58.94），在 Flickr30K 上匹配 Dense（83.98 vs. 84.04）；R=10% 压力测试下仍与 Dense 差距在 1.2 pp 以内，且**在所有 12 个指标列中全部排名第一**。
- **效率**：FLOPs 降 39–45%，实测端到端加速 1.28–1.45 倍；PyramidDrop 虽然削减 FLOPs 更多却在 Qwen3-VL-4B 上慢于 Dense（0.76×），证明"分析性压缩 ≠ 墙钟加速"，排名感知的 token 选择比激进删除更有效。
- **关于"在何处剪"与"如何打分"同样重要**：消融中 CCU-only、w/o Token Scoring、w/o α-Maximin 三者的退化幅度接近，支持层调度与打分机制重要性相当。
- **定性案例证实**：显著性倾向保留视觉显著但顺序无关区域，DTI 聚焦查询相关且候选独特的区域（如蓝色牛仔裤），RaDiCal 融合两者产生空间更连贯的保留模式。

## 7. 优点与亮点

- **问题定位精准**：将"显著性 ≠ 排序贡献"从笼统的现象观察到分层结构性诊断（非单调可靠性曲线），并找到 \(H_{norm}\) 这一轻量、模型固有、无需逐数据集的校准信号。
- **统一的设计哲学**：一个熵坐标同时驱动 token 融合和层选择，避免了传统方法中"打分"与"在哪剪"两阶段独立调参的割裂；α-Maximin 在 α 空间做最远点采样，与简单启发式相比有清晰的原理驱动，消除了逐数据集层选择的必要。
- **方法设计优雅且训练无关**：DTI 是注意力自由先验（O(Vd) 成本，全局原型近似避免了 O(V²d) 精确对比较）；几何融合具有尺度不变性和软否决的自然语义；无需微调或任何训练信号即可与 Dense 质量持平。
- **实验规范度高**：多个随机种子、条件/无条件指标同时报告、全基线同框架复现、跨数据集/模型/检索器/任务域的迁移验证；诚实报告了 Random 对照（表 10）、单图像迁移的表现边界与 OCR 型任务的退化，说明作者对方法适用范围有清晰认识。
- **跨架构自适应性**：Qwen3-VL-4B/8B 与 InternVL2.5-8B 各自自动选出不同的剪枝层集合，无需人工重调即可保留超过 99% 的 Dense 质量。

## 8. 不足与局限

### 论文自述局限

- **适用范围**：RaDiCal 专为列表式重排设计，依赖多候选提供的跨候选对比信号；对其他多图像任务（视觉比较、多图像 VQA）未验证。
- **无学习组件**：α 或 DTI 权重未做任务特定的学习；作者亦未探索训练融合的潜力。
- **架构假设**：依赖 softmax 注意力，无法直接推广到线性注意力或状态空间模型等替代注意力机制。
- **领域覆盖有限**：尽管涵盖三种重排基准、三种检索器和两种 VLM 家族，未在更广的检索域或多模态场景验证；同时对能源消耗、碳排放、偏见、隐私、幻觉等风险未做测量或缓解。

### 潜在不足（基于分析视角）

- **时间标注存疑**：arXiv 编号为 2609.00667v1（2026 年 9 月），文中大量引用 2026 年的文献，预印本阶段的同行评议验证尚未完成。
- **主实验规模偏小**：Flickr30K/MSCOCO 各自仅有 1,000 条测试查询（top-20 池），FashionIQ 上条件指标只覆盖 1,599/6,016 个查询；真实检索场景中查询分布更多样、候选池更大，泛化证据仍需更大规模验证。
- **近似性假设**：DTI 用全局原型近似跨候选独特性（\(\bar{v}\) 为所有候选 tokens 的均值），当候选分布高度多峰时该近似可能失真（论文仅提供了一种透明上界的替代方案）。
- **剪枝层数的非自适应设定**：K 和层间隙 \(g\) 被描述为固定部署选择而非逐数据集调参，但 K 的选择本身经敏感性分析证明存在明显最优值（K=4），最佳 K 是否随模型而变化仍需进一步确认。
- **可控的墙钟效率比较局限**：对 InternVL2.5-8B 的 FastV 速度 2.00× 来自远更激进的 FLOPs 削减（71.1%），而质量掉至 86.1%，需要在相同质量约束下评估延迟优势才更具说服力。
- **单图像任务迁移受限**：附录显示在 DocVQA/TextVQA 等 OCR 密集任务上退化达 8.9–12.7 pp，显著差于 PyramidDrop，尽管这超出了论文的目标场景，仍提示该方法对细粒度文本 token 的保留不足。
