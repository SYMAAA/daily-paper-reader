## 摘要
块量化（BQ）是一种很有前景的大语言模型（LLM）高效部署方法，能够在实现低精度计算的同时，将精度下降控制在可控范围内。与标量仅权重量化（WoQ）相比，块量化同时对权重和激活值进行量化，因而具有更高的硬件效率，并能在统一数据通路上进行端到端推理，但其设计空间（涉及位宽、块大小、缩放和数值格式等）仍未得到充分探索。我们通过设计空间探索（DSE）提供了硬件与基准测试结果。我们发现，增大块大小可以通过分摊反量化和累加成本来提高硬件效率，但会降低精度。这一权衡限制了传统块量化方法。基于这一洞察，我们提出了分层块量化（HBQ）。与使用小块和传统2的幂（PoT）或整数缩放的先前方法[1]、[2]不同，HBQ使用大块以提高硬件效率，同时引入低开销的有效数（SIG）缩放用于二级量化。通过有效分配量化级别并考虑激活值与权重分布的不同，SIG缩放能够比现有PoT和INT方案更有效地补偿大块误差。HBQ-A（高精度）仅使用W4A5即可达到W4A16的精度水平，同时所需硅片面积小于NVFP4。HBQ-E（高效）进一步将硬件成本降低17%，同时保持比所有现有BQ方法更高的精度。我们实现了一款28nm ASIC加速器，将HBQ应用于权重、激活值和KV缓存，并集成了一种新颖的部分和块量化方案，以进一步降低EMA能耗。与最先进的WoQ相比，HBQ在相同精度水平下实现了2.3倍/4.6倍的面积/能量效率提升；与现有BQ方法相比，系统能耗降低1.6–3.3倍，速度提升1.5–3.0倍，同时提供了最优精度。

## Abstract
Block Quantization (BQ) is a promising approach for efficient deployment of large language models (LLMs), enabling low-precision computation with controlled accuracy degradation. Compared to scalar weight-only quantization (WoQ), BQ quantizes both weight and activation, offering higher hardware efficiency and end-to-end inference on a unified datapath, but its design space, spanning bit-width, block size, scaling, and numeric formats, remains underexplored.   We provide hardware/benchmark results through design space exploration (DSE). We find that increasing block size improves hardware efficiency by amortizing dequantization and accumulation costs, but degrades accuracy. This trade-off limits conventional BQ methods.   Motivated by this insight, we propose Hierarchical Block Quantization (HBQ). Unlike prior methods [1], [2], which use small blocks and conventional Power-of-Two (PoT) or integer-based scaling, HBQ uses large blocks to maximize efficiency and introduces low-overhead significand (SIG) scaling for second-level quantization. By allocating quantization levels effectively and accounting for distinct activation and weight distributions, SIG scaling compensates for large-block errors more effectively than prior PoT and INT schemes. HBQ-A (accurate) achieves W4A16-level accuracy using only W4A5 while requiring less silicon area than NVFP4. HBQ-E (efficient) further reduces hardware cost by 17% while maintaining higher accuracy than all existing BQ methods.   We implemented a 28nm ASIC accelerator applying HBQ to weights, activations, and KV cache, and integrated a novel partial-sum BQ scheme to further reduce EMA energy.   Compared to state-of-the-art WoQ, HBQ delivers $2.3\times$/$4.6\times$ higher area/energy efficiency at the same accuracy level; $1.6$--$3.3\times$ system energy reduction and $1.5$--$3.0\times$ speedup over prior BQ methods while providing best accuracy.

## 2. 方法论：核心思想、技术与流程

### 2.1 总体思路：分层块量化（HBQ）

- HBQ 采用**两级量化**结构：
  - **第一级（L1）**：仍用块大小为 **B=128** 的大块，对整个块计算一个高精度缩放因子 \(s_b\)（FP8 格式），以摊薄反量化与累加硬件开销。
  - **第二级（L2）**：将大块再划分为 **μB** 大小的微块，每个微块引入一个低开销的缩放因子 \(\alpha_{b,u}\)（2-bit），对第一级量化后的误差进行细粒度修正。
- 最终的有效缩放因子为：
  \[
  \tilde{s}_{b,u} = s_b \cdot \alpha_{b,u}
  \]
- 量化和反量化过程：
  \[
  q_{(b,u)}=Q_F\left(\frac{x}{\tilde{s}_{b,u}}\right),\quad
  \hat{x}=q_{(b,u)}\cdot \alpha_{b,u}\cdot s_b
  \]

### 2.2 关键创新：Significand Scaling（SIG）

- 论文提出一种新的二级缩放形式——**有效数缩放**，记为 **SIG_x**：
  \[
  \alpha_{\text{SIG}_x}(c) = 1 + \frac{c}{2^x},\quad c\in\{0,1,\ldots,2^n-1\}
  \]
  其中 \(n=2\)（2-bit 量化），\(x\) 控制缩放粒度。
- **为什么有效**：
  - PoT 和 INT 二级缩放会在不同 \(c\) 值之间产生级别重叠，还需覆盖过宽动态范围；而 SIG 只调整尾数（significand）的精细步长，动态范围窄，级别排列更紧密。
  - 针对权重和激活/ KV 分布的不同特点，采用不同 x：
    - 激活与 KV：选择 **SIG1** 的粒度（误差可回落至 B16 水平）；
    - 权重：选择 **SIG3** 的粒度（误差低于 B16）。
- **离线混合选择**：由于权重离线量化，HBQ 对每个 L1 块在 SIG2/SIG3 中选择使量化 MSE 更小的方案；每块用 1-bit 选择信号 \(k\) 记录，反量化时再用于解码。无校准数据需求。

### 2.3 配置

- **L1 块大小**：B=128（与注意力头维度对齐）。
- **微块大小**：HBQ-E（高效版）μB=32；HBQ-A（精确版）μB=8。
- **位宽设置**：均采用 W4A5（权重 4-bit、激活 5-bit），其中有效位宽包含缩放因子开销：HBQ-E ≈ W4.13/A5.13，HBQ-A ≈ W4.31/A5.31。
- **元素格式**：FP，带 2-bit 指数的尾数格式（如 E2M1–E2M5），比 INT 或 FP8/E4M3 更适配块内窄分布。

### 2.4 硬件/PE 设计

- 基线 PE（BQ）：乘法→块内定点加法树→L1 反量化→跨块 FP 累加。
- HBQ PE：先对微块 μB 做定点加法树归约，再进行 2-bit L2 反量化（因为 α 取值范围很小，可在定点域内完成），然后跨微块归约，最后做 L1 反量化 → FP 累加。
- 该结构仅比普通 BQ 增加一个廉价 L2 阶段，却能使大块（B128）的精度恢复到小块（B16）水平。

### 2.5 部分和 MXINT8 量化（Psum Quantization）

- 存储 psum 的 buffer 大，是限制 tile 大小和造成反复 EMA 的瓶颈。
- 论文对每 32 个 FP16 部分和（与 PE 数量匹配）做 MXINT8 块量化，使 psum 缓存容量实际翻倍。
- 累加精度保持 FP16；MXINT8 只发生在跨块累加时，误差传播次数很少（每 M/B 步一次），量化带来的 PPL 损失仅为 +0.01 左右（表 VII），几乎无损。

### 2.6 与已有分层方法的关键区别

| 维度 | VSQ/MicroExponent | HBQ |
|---|---|---|
| L1 块大小 | 16 或 channel 级 | **128** |
| 缩放类型 | PoT / INT | **SIG** |
| L2 位宽 | 或含较大开销 | **2-bit 低开销** |
| 动机 | 纯精度优化 | 硬件-精度协同，为了“使用大块” |

  1. FP8 缩放优于 PoT（MX）缩放，且在大块下开销可被摊薄；
  2. “2-bit 指数 + 更高尾数位”的 FP 格式是最佳元素格式；
  3. 5-bit 激活是效率——精度最佳平衡点；
  4. 大块（B≥32）对硬件效率很重要，但传统方法为保精度不得不用小块；
  5. 块大小才是决定 BQ 硬件效率的主轴，而不是调整格式/位宽可替代的。
- **HBQ 结论**：
  - HBQ-A 用 W4A5 达到 WoQ（AWQ W4A16）同水平 PPL，面积比 NVFP4 更小；
  - HBQ-E 比 NVFP4 还低 17% 面积，但精度高于所有现有 BQ；
  - 在 KV cache 量化后，端到端推理仍然保持较好的精度与速度（表 X、XI）。
- **系统性能结论**：
  - 相比 WoQ（AxCore）：PE 面积效率提升 ≥2.3×，能效提升 ≥4.6×；
  - 相对前代 BQ：系统能耗降低 1.6–3.3×，推理速度提升 1.5–3.0×，且精度最优。
- **Long-generation** 场景：HBQ-A 与 NVFP/MXFP 接近的精度，但 KV cache 减半不影响精度，DRAM 能效显著更好。
- **消融意义**：大块带来的 0.31 PPL 退化被 SIG 补回 0.27，部分和 MXINT8 只付出几乎为 0 的精度代价却省 16.4% 能耗。

## 7. 优点（亮点）

- **角度新颖**：首次将“块大小”作为硬件效率的主设计变量，从 DSE 提出“BQ 目前性能瓶颈源于没敢用大块”的洞见，并据此建立解决思路，而非简单调整数据格式。
- **算法-硬件协同充分**：不只是发量化方法，还做了完整 ASIC 加速器（28nm、布局布线、SRAM/功耗实测），让 PPL 与面积/能量/速度指标形成闭环；这种“算法+电路”联合工作非常少见。
- **SIG 数学设计简单且有效**：仅用 2-bit 的尾数缩放就能恢复精度，几乎不增加反量化复杂度；这一“廉价第二级量化”设计避免了大块精度的牺牲。
- **处理分布差异巧妙**：离线区分激活/SIG1、权重/SIG2&3 的选择，针对 LLM 中激活与权重分布差异的本质对症下药；无需校准数据即可运行。
- **部分和量化的工程想法实用**：将 MXINT8 用于 psum buffer 压缩，在不损害精度的前提下将 tile 加倍，直接减少 DRAM 访问，系统级收益显著。
- **全面、公平的基准**：模型家谱、任务类型、bit-width、序列长度、频率、面积、能量、长生成……实验矩阵相当丰富；RTL 开源，可复现性强。

## 8. 不足与局限

- **缺少公开资源信息**：“实验资源算力”一项论文没有明确记录；对成本和可复现的时间没有指导。
- **领域局限**：所有实验均聚焦 Post-Training Quantization（PTQ），没有考虑训练感知量化（QAT）、梯度传播或 fine-tuning 场景。
- **KV cache 量化只测了静态精度 loss**：没有对超长序列（>16k/100k）验证 KV 量化的稳定性；KV block size 到 128 时 PPL 已上升至 7.79（表 IV），说明 HBQ-A 在更大 KV 长度下仍可能面临挑战。
- **公平性小瑕疵**：
  - “HBQ-A 用 W4A5 达到 WoQ W4A16”，比 WoQ 多用 5 位激活，本质上缩小了比较优势的解释范围；
  - 与 NVFP4 等相比时，激活位宽不同（5 vs 4），而论文的表 IX 仅给 PPL 未给出同 PPL 的全套对照；
  - 用已发布结果（MANT、MicroScopiQ）而没完全重实现，可能引入结构差异（论文有注明）。
- **模型规模上限只到 70B**，未对 100B+ 的大模型验证；而 70B 以内所反映的分布偏差可能不足以代表所有 SOTA 模型。
- **辅助单元非完整系统**：论文假设 SIMD 可执行 LayerNorm、Softmax、RoPE 等，但没有给这些模块的具体面积/功率，对“端到端统一硬件”的表述打了折扣。
- **权重为离线静态量化时只考虑 MSE，未深究激活离群点对两个微块之间的边际效应**——论文对 B=128 时误差上升的分析停留在“激活小元素”被压碎，没有从信息论上给出上限。
- **没有限制序列长度/token 规模下的“系统能耗”模型**：如 4pJ/bit 的 DRAM 假设立即对结果高度敏感。

## 结束语

HBQ 是一篇方法论与硬件实现都很扎实的研究：用硬件感知 DSE 发现了“块大小”是 BQ 的关键折衷轴，通过廉价 2-bit SIG 第二级缩放恢复因大块造成的精度损失，并完成了真实的 28nm ASIC 验证，给出了大量 LLM 精度/硬件 benchmark。方法论上有借鉴意义，工程实现上有参考价值，但仍受限于模型规模、序列长度、与 WoQ/训练系统对比时的口径以及未公开 GPU 资源记录等细节，在推广时应仔细核对实验配置。
