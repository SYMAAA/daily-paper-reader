## 摘要
低比特权重—激活量化可降低大语言模型部署所需的内存和计算，但校准后激活舍入仍可能降低精度。基于舍入输入的重建无法区分同一量化区间内的激活。我们提出 ResCom，一种低秩校正，利用激活舍入残差来补偿由此产生的层输出误差。一种输出感知的校准过程根据残差方向对输出重建的贡献进行选择，并以闭式解计算校正，无需梯度训练，也无需更新已校准权重。在 4 比特权重和激活的 Llama-3-8B 上，秩为 32 的注意力校正将 WikiText-2 困惑度从 7.708 降至 7.147，使 MMLU 提升 2.89 个百分点，并将五样本 GSM8K 准确率从 23.96% 提高到 36.16%。在 1B 至 70B 参数模型以及留出 C4 上的评估检验了该方法在此设置之外的表现。所评估的 FP32 实现使 4K 预填充时间增加 2.25%；一个单独的紧凑存储实现相对于 FP16 仍保持 27.7% 的峰值内存降低。

## Abstract
Low-bit weight--activation quantization reduces the memory and computation needed to deploy large language models, but activation rounding can still degrade accuracy after calibration. Reconstruction from rounded inputs cannot distinguish activations within the same quantization bin. We propose ResCom, a low-rank correction that uses the activation rounding residual to compensate for the resulting layer-output error. An output-aware calibration procedure selects residual directions by their contribution to output reconstruction and computes the correction in closed form, without gradient training or updates to the calibrated weights. On Llama-3-8B with 4-bit weights and activations, rank-32 attention corrections reduce WikiText-2 perplexity from 7.708 to 7.147, improve MMLU by 2.89 percentage points, and raise five-shot GSM8K accuracy from 23.96 to 36.16 percent. Evaluations on models from 1B to 70B parameters and on held-out C4 test the method beyond this setting. The evaluated FP32 implementation adds 2.25 percent to 4K prefill time; a separate compact-storage implementation retains a 27.7 percent peak-memory reduction relative to FP16.

# ResCom 论文结构化总结

## 一、核心问题与研究动机

- **背景**：低比特权重—激活量化（如 W4A4）能显著降低大语言模型部署的内存与计算开销，但激活舍入会在校准后持续损害精度。
- **关键痛点**：均匀量化器下，激活值范围被离群值放大，导致大量激活共享同一量化桶；仅依赖舍入后输入 $Q(x)$ 的重建/补偿方法（如 SERQ）无法区分同一桶内不同激活，因而对它们施加相同校正，无法恢复各自不同的输出贡献。
- **现有方法的局限**：
  - LRC 联合优化量化权重与低秩校正，需重做权重近似；
  - ARHQ 用残差统计选择高精度权重分量并重新量化剩余权重，改变了主路径；
  - 二者都在“构建量化模型”阶段介入，无法在已校准模型上独立附加校正。
- **核心问题**：如何在不改动已校准权重、量化设置与既有重建路径的前提下，利用被舍入丢弃的信息恢复层输出误差？

## 二、方法论

### 2.1 核心思想
- 在已校准量化模型（host model）上附加一个**以激活舍入残差为条件**的低秩校正分支，冻结主路径与既有重建项，仅拟合该分支。
- 残差定义为 $d = x - Q(x)$，记录舍入丢弃的输入信息；不同激活即使 $Q(x)$ 相同，其 $d$ 也不同，从而可被区分。

### 2.2 关键技术细节
- **校正目标**：用同一冻结线性映射 $W_s$（含反量化主路径权重与既有重建项）分别作用于 $x$ 与 $Q(x)$，得到输出误差 $e = W_s d$。
- **分支形式**：$\hat{y}_{RC} = \hat{y} + U(Vd) + b$，其中 $U\in\mathbb{R}^{m\times r}$、$V\in\mathbb{R}^{r\times n}$ 为秩 $r$ 因子，$b$ 为截距。
- **输出感知校准**：求解正则化降秩回归
  $$\min_{\text{rank}(B)\le r,\,b}\ \sum_t \|e_t - Bd_t - b\|_2^2 + \lambda\|B\|_F^2,\quad B=UV$$
  以输出重构误差而非残差幅度来分配秩预算。
- **闭式求解流程**（Algorithm 1）：
  1. 在冻结模型上流式收集校准统计量 $\bar d,\bar e,G=\sum \tilde d_t\tilde d_t^\top,C=\sum \tilde e_t\tilde d_t^\top$；
  2. 对 $G+\lambda I=LL^\top$ 做 Cholesky；
  3. 对 $CL^{-\top}$ 做秩 $r$ SVD：$CL^{-\top}=\Phi\Sigma\Psi^\top$；
  4. 取 $U=\Phi_r\Sigma_r$、$V=\Psi_r^\top L^{-1}$、$b=\bar e-UV\bar d$；
  5. 所有层统计量收集完毕后再统一附加分支，避免早期校正改变后续层输入分布。
- **理论保证（命题 1）**：在相同秩预算下，残差输入的最小无正则化重建误差等于目标矩阵截断误差，且不大于未舍入输入或量化输入；并给出岭正则化下的误差上界。

### 2.3 集成与成本
- 分支可附加于注意力或前馈投影的输入量化器处，无需撤销 host 的缩放/旋转/置换。
- 校准存储 $O(n^2+mn)$ 统计量，与校准 token 数无关；推理时每 token 增加 $r(n+m)$ 次乘加与一次 $n$ 维减法。

- **精度恢复**：Llama-3-8B W4A4 下 WikiText-2 PPL 7.708→7.147，MMLU +2.89 点，五样本 GSM8K 23.96%→36.16%；九个 W4A4 SERQ 检查点 PPL 全部下降。

## 七、优点

- **方法层面**：
  - 首次将“激活舍入残差”作为独立校正信号，明确区分于量化输入与未舍入输入；
  - 闭式解、无梯度、不改动已校准权重，可与多种 PTQ 流水线即插即用；
  - 输出感知的降秩回归按输出贡献分配秩预算，并有命题 1 的理论对齐保证；
  - 分支参数化紧凑，推理开销可控。
- **实验层面**：
  - 配对比较设计严格，固定检查点/评测协议；
  - 匹配秩输入消融与通道控制有效隔离变量；
  - 覆盖 1B–70B、多家族、跨语料、跨流水线，外部效度较好；
  - 同时报告精度、延迟、显存与原生 MXFP4 执行，工程可信度较高。

## 八、不足与局限

- **收益条件性强**：W4A8 下几乎无增益；部分模型/任务出现负增益，方法并非普适。
- **层内最优 ≠ 端到端最优**：分支基于冻结未修复模型收集统计量，附加后上游校正会改变下游输入分布，作者明确不保证端到端损失下降。

- **实验公平性风险**：部分基线引用已发表值，评测协议可能与本文不完全一致；LongBench 的 prompt/截断细节与 SERQ 原表不完全可比。
- **覆盖缺口**：未评估更大规模（>70B）、MoE 架构、多模态场景；W4A4 之外的极低比特（如 W2A4）未涉及。
