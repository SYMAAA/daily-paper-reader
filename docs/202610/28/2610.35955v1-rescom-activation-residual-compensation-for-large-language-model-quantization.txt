## ABSTRACT 

Low-bit weight–activation quantization reduces the memory and computation needed to deploy large language models, but activation rounding can still degrade accuracy after calibration. Reconstruction from rounded inputs cannot distinguish activations within the same quantization bin. We propose ResCom, a low-rank correction that uses the activation rounding residual to compensate for the re-sulting layer-output error. An output-aware calibration procedure selects residual directions by their contribution to output reconstruction and computes the correc-tion in closed form, without gradient training or updates to the calibrated weights. On Llama-3-8B with 4-bit weights and activations, rank-32 attention corrections reduce WikiText-2 perplexity from 7.708 to 7.147, improve MMLU by 2.89 per-centage points, and raise five-shot GSM8K accuracy from 23.96 to 36.16 percent. Evaluations on models from 1B to 70B parameters and on held-out C4 test the method beyond this setting. The evaluated FP32 implementation adds 2.25 per-cent to 4K prefill time; a separate compact-storage implementation retains a 27.7 percent peak-memory reduction relative to FP16. 

## 1 INTRODUCTION 

Large language models (LLMs) continue to improve in capability, but their memory and compu-tational requirements make inference costly (Pope et al., 2023). Quantization reduces these costs by representing model values with fewer bits. Post-training quantization (PTQ) applies this conver-sion to pretrained models using limited calibration data, avoiding a full quantization-aware training procedure (Nagel et al., 2021). Since linear layers multiply learned weights by input-dependent ac-tivations, quantizing both operands enables low-bit matrix multiplication on compatible hardware. With four-bit weights and activations (W4A4), however, few numerical levels represent activation ranges that can be enlarged by outliers (Dettmers et al., 2022). For a uniform quantizer, a wider range spreads these levels farther apart, so wider intervals of activation values share each rounded value. The layer consequently loses input distinctions that may affect its output. To reduce this distortion, activation-shaping methods adjust distributions before quantization through scaling or transformations (Xiao et al., 2023; Ashkboos et al., 2024). The resulting low-bit computation can still incur output error, which error-reconstruction methods compensate with compact branches (Zhang et al., 2024; 2025). For W4A4, SERQ implements reconstruction with a single compensation matrix operating on quantized activations (Park et al., 2026). LRC jointly optimizes quantized weights and a correction, whereas ARHQ uses residual statistics to determine a weight split before quantizing the remaining weights (Scetbon & Hensman, 2024; Wang et al., 2026). Their correction procedures therefore participate in constructing the quantized model. Once a model has been calibrated, preserving its weights and input transformations allows those calibra-tion choices to be reused while fitting an additional correction.

Different activations can produce different layer outputs even when they round to the same vector. A correction conditioned only on that vector, as in SERQ, gives these inputs the same adjustment, leaving their distinct output contributions unresolved. This motivates a correction that accesses the discarded information while retaining the already calibrated computation. How can such a correction recover layer outputs under a limited computation budget? To address this question, we propose R ES COM , which adds a residual-conditioned low-rank correc-tion to an already calibrated quantized model, referred to as the host model (Figure 1). R ES COM fits the correction to layer-output error while retaining the existing weights, quantization settings, and reconstruction path. We evaluate this post-calibration attachment beyond SERQ using Llama-3-8B checkpoints from PrefixQuant and FlatQuant (Chen et al., 2026; Sun et al., 2025). The branch receives the activation rounding residual, the difference between an activation before quantization and the value reconstructed from its quantized representation. This residual records what rounding discards and is formed at the existing input quantizer. In our SERQ instantiation, the frozen linear map includes both the dequantized main-path weights and the existing reconstruction term. Because both inputs are evaluated under the same frozen map, its response to the residual exactly equals the output difference caused by activation rounding. This activation-induced output difference defines our SERQ calibration target. Using the residual isolates the input component absent from the main path and directly matches this target’s linear dependence on the discarded information. Evaluating the frozen map on the residual would recover this difference directly, but requires a dense high-precision multiplication. To bound the additional cost, R ES COM uses a low-rank approximation implemented by two smaller matrix multiplications, trading recovery capacity for computation and storage. Under this budget, residual magnitude alone overlooks output amplifi-cation, while weights alone ignore which residual variations occur; a small residual can still have a large output effect. R ES COM therefore fits a regularized reduced-rank regression to output error, us-ing a ridge term to stabilize fitting from limited calibration data and obtaining a closed-form solution without gradient training. ## 2 RELATED WORK 

Low-bit quantization and activation shaping. Activation shaping improves low-bit accuracy by limiting how outliers enlarge the range represented by a quantizer. Xiao et al. (2023) shift quanti-zation difficulty from activations to weights through channel scaling in SmoothQuant. Suppressing activation outliers can enlarge weight ranges, making the balance between the two errors important. Shao et al. (2024) optimize this balance by jointly learning equivalent transformations and weight-clipping parameters in OmniQuant. Scaling changes each channel’s magnitude while keeping its values within that channel. To spread outlier values across channels, Ashkboos et al. (2024) use output-preserving Hadamard rotations in QuaRot. Rotations mix channels without independently rescaling them; Sun et al. (2025) combine mixing and rescaling through learned affine transforma-tions in FlatQuant. Beyond these feature transformations, Chen et al. (2026) isolate token-associated outliers in prefixed tokens in PrefixQuant, enabling static activation scales. These methods improve how activations fit the available numerical levels, while subsequent rounding still discards input-dependent information. R ES COM targets the resulting output error after calibration, preserving the host’s transformations and quantization settings. 

Quantization error reconstruction. Reconstruction methods compensate quantization error with compact branches. Zhang et al. (2024) use activation-scaled weight-error decomposition in LQER, but its heuristic scaling does not directly solve expected output-error minimization. Zhang et al. (2025) address this limitation through an analytical output-error formulation in QERA. Its weight-reconstruction target, however, does not explicitly include the output discrepancy introduced by activation rounding, so minimizing that target alone does not ensure activation-error recovery. Be-yond the fitting objective, two-factor execution requires sequential products; when both factors run at low precision, intermediate quantization adds error and computation. To avoid this step, Park et al. (2026) use a single compensation matrix on selected quantized activation channels. Yet its correction still receives only rounded inputs: activations sharing the same quantized vector receive the same adjustment, leaving their distinct output contributions unresolved. R ES COM addresses this input limitation by fitting a residual-driven branch to the activation-rounding output difference under the frozen SERQ map. 

Unrounded activations and residual correction. Accessing unrounded activations can recover distinctions unavailable from rounded inputs. Scetbon & Hensman (2024) use them in LRC while jointly optimizing quantized weights and a low-rank correction. This coupling means that adding its correction to an existing checkpoint requires revisiting the weight approximation. An analytical alternative is ARHQ: Wang et al. (2026) use activation-residual statistics to select a high-precision weight component, avoiding joint fitting of the weights and correction. However, the selected com-ponent is removed from the main-path weights before the remainder is quantized. Its construction therefore changes the quantization problem and does not preserve an already calibrated main path. Both methods access unrounded information through constructing the weight approximation, leav-ing a need for correction fitted independently after calibration. R ES COM meets this requirement by using each input’s rounding residual to drive an added low-rank branch. Its output-aware fit retains the host weights, quantizer, and existing reconstruction path, allowing the calibrated computation to be reused.

ResCom addresses this limit after the original quantization pipeline has been calibrated. It passes the information removed by activation rounding to a small correction branch, then fits that branch to the missing layer output. At inference, the branch evaluates that correction for the current token and adds it to the frozen quantized output. The shared layer bias is omitted. 3.1 RESIDUAL -CONDITIONED CORRECTION 

Recovering the missing input distinction. For a layer with input width n, let the unrounded ac-tivation x ∈ Rn denote the input to its calibrated quantizer, expressed in the quantizer’s coordinate system. The quantize–dequantize operator Q returns the dequantized activation Q(x) ∈ Rn. Dif-ferent activations can share the same Q(x) while having different deviations from that value. Acorrection conditioned only on Q(x) gives these inputs the same adjustment. ResCom therefore conditions its branch on the activation rounding residual d ∈ Rn, defined as 

d = x − Q(x).

The residual d records the input information removed from the current token. It is formed by ele-mentwise subtraction at the quantizer, where both x and Q(x) are available in the current forward pass. 

Defining the correction target. The residual d identifies the removed input component; the cor-rection branch is fitted to the resulting change in the layer output. We obtain this target by evaluat-ing x and Q(x) with the same frozen linear map Ws ∈ Rm×n, where m is the output width. The map Ws combines the dequantized main-path weights with any existing linear reconstruction term and is evaluated through the host’s existing components. With the shared layer bias c ∈ Rm, the unrounded-input output yu, the quantized-input output ˆy, and the target output error e are 

yu = Wsx + c, ˆy = WsQ(x) + c, e = yu − ˆy = Wsd. (1) Because both outputs use the same frozen map and bias, e isolates the output contribution removed by activation rounding. 

Adding a limited-rank branch. Computing Wsd directly at inference would require a dense multiplication. ResCom approximates this contribution with a rank-r branch using the factors 

V ∈ Rr×n and U ∈ Rm×r . By concentrating this budget on residual directions that most af-fect the layer output, the branch can recover the dominant missing output contributions and thereby reduce reconstruction error. The matched-input controls in Table 5 and the held-out evaluations in Section 4 examine how this alignment translates into model-level improvements. 3.4 INTEGRATION AND COST 

ResCom attaches at the input quantizer of a chosen linear projection. It forms the residual before the unrounded activation is discarded and adds the branch output after the existing linear computation. Scaling, rotation, or permutation introduced by the host pipeline is reflected in the coordinate system of x; ResCom does not need to undo those transformations. The branches can be attached to selected attention or feed-forward projections after calibration. The default configuration repairs attention projections, and Section 4.3 evaluates other placements. For an n-input, m-output layer, calibration stores O(n2 + mn ) statistics, independent of the number of calibration tokens; layers can be processed in groups to limit memory. This work is performed once, without gradients or updates to the quantized weights. At inference, forming the residual requires an n-element subtraction, and the branch uses r(n + m) multiply-accumulates per token. Its factors and intercept store r(n+m)+ m scalars. The chosen rank therefore sets both the capacity of the output correction and its added inference cost. 

## 4 EXPERIMENTS 

4.1 EXPERIMENTAL SETUP 

Models and comparisons. We evaluate Llama-3/3.2 1B–8B (Grattafiori et al., 2024), LLaMA-2 7B/13B/70B (Touvron et al., 2023), Mistral-7B-v0.3 (Jiang et al., 2023), and Gemma-3-1B/4B (Gemma Team, Google DeepMind, 2025). SERQ provides the main quantized checkpoints; every ResCom result is paired with our evaluation before repair. PrefixQuant and FlatQuant test transfer to other pipelines. W4A4 is the main setting; W4A8 appears in Appendix D.2. Within each pair, the checkpoint, tokenizer, evaluation harness, and test examples are fixed, so the comparison isolates the fitted branch rather than a change in quantization or evaluation protocol. 

Calibration and metrics. The rank-32 attention branch uses 128 WikiText-2 windows of 2048 tokens and λ = 0 .01 tr( G)/n . We evaluate language modeling with WikiText-2 (Merity et al., 2017) and held-out C4 (Raffel et al., 2020) perplexity; general task performance with an eight-task zero-shot mean and 57-subject MMLU (Hendrycks et al., 2021); and reasoning and long-context generation with five-shot GSM8K (Cobbe et al., 2021) and three LongBench tasks (Bai et al., 2024). ## 5 CONCLUSION 

Low-bit activation quantization creates token-specific output errors that are no longer identifiable from rounded activations alone. We introduced ResCom, a low-rank branch conditioned on the rounding residual and fitted to layer-output error by closed-form reduced-rank regression, while leaving the calibrated weights and main quantized path unchanged. Across the evaluated 1B to 70B backbones, the correction consistently lowers paired perplexity; on Llama-3-8B it reduces WikiText-2 PPL from 7.708 to 7.147, raises MMLU by 2.89 points, and improves five-shot GSM8K from 23.96% to 36.16%. Matched-input, cross-corpus, and cross-pipeline studies connect these gains to the residual conditioning signal, while deployment measurements quantify the additional latency and memory. The evidence supports activation residuals as a useful complementary signal for repairing an already calibrated low-bit model, with the attainable gain depending on the backbone, task, and quantization path. 10 ResCom: Activation Residual Compensation for Large Language Model Quantization

## B POST -CALIBRATION REPAIR VERSUS RESIDUAL -AWARE WEIGHT SPLITTING 

ARHQ (Wang et al., 2026) and ResCom both preserve information unavailable from the rounded activation alone, but they solve different integration problems. ARHQ starts from a full-precision weight W ∈ Rm×n, chooses a rank-r component Wsplit = BaA⊤ 

> a

with Aa ∈ Rn×r and Ba ∈

Rm×r , and then quantizes the modified remainder. With weight quantizer Qw and the shared bias omitted, its deployed layer is 

ˆyARHQ = Qw(W − Wsplit )Q(x) + Wsplit x. (20) The high-precision branch is therefore coupled to a newly quantized main path. ResCom instead starts from an already calibrated effective map Ws and keeps that map fixed. Its deployed layer is 

ˆyRC = WsQ(x) + Bd + b, d = x − Q(x), (21) where B = U V is fitted to the activation-only target e = Wsd in the default SERQ setting. The de-ployed residual-conditioned branch keeps the calibrated main operator fixed. The same reduced-rank regression procedure also supports other fixed output-error targets. Our PrefixQuant and FlatQuant extensions use references that include weight-side error, as detailed in Appendix C, without repeat-ing their weight calibration. An algebraic expansion makes the distinction explicit. Adding and subtracting Qw(W )Q(x) in Eq. (20) gives 

ˆyARHQ = Qw(W )Q(x) + Wsplit d + ∆ wQ(x), ∆w = Qw(W − Wsplit ) + Wsplit − Qw(W ).

(22) The term Wsplit d exposes a residual-dependent component, while ∆wQ(x) records the accompa-nying change to the quantized main path. Because quantization is nonlinear, optimizing the split and requantizing the remainder generally changes both terms together. ResCom has no correspond-ing main-path change: it learns B from the frozen host layer’s observed residual-to-output relation. Thus the two methods differ in optimization stage, branch input, fitted target, and whether deploy-ment replaces the calibrated main operator; their shared access to unrounded information does not make their deployed corrections equivalent. 

## C REPRODUCTION AND IMPLEMENTATION DETAILS 

For completeness, the signal limitation used in the introduction can be stated directly. For two inputs 

x1, x 2 ∈ Rn with Q(x1) = Q(x2) but Ws(x1 − x2)̸ = 0 , any deterministic correction conditioned only on Q(x) must be identical for both inputs, although their required corrections differ. Residual input distinguishes them. This is a statement about the information available to the branch; an unrounded-input branch also has that information and is tested as a matched-rank control. The representation ˆy = WsQ(x) + c in Eq. (1) assumes that the frozen main path and any existing linear compensator act on the same quantize–dequantize input Q(x). All weights and activations are expressed in the coordinate system of the calibrated input quantizer, including any host scaling, rotation, or permutation. For the SERQ instantiation, Ws = cW + RS , with Wc = RS , where 

S ∈ Rk×n selects k salient channels. Here cW ∈ Rm×n and R ∈ Rm×k denote the fixed numerical weight values used by the deployed paths, including dequantization where applicable. The combined matrix Ws is never materialized for inference. This single-map representation does not automatically apply to hosts with separate activation quan-tizers for different paths or an additional output quantizer. In such cases, the target must be defined from the actual frozen reference and host operators, rather than assuming e = Wsd. All calibration statistics are collected from the frozen, unrepaired host model before any ResCom branch is attached. This choice defines a common calibration reference across layers. After the branches are attached, upstream corrections can change the activations and rounding residuals en-countered by downstream layers. The closed-form solution is therefore optimal for the specified layerwise objective on the collected calibration inputs; it does not guarantee optimality under the input distribution induced by the augmented model, or a reduction in end-to-end language-model loss. Uncentered moments and means are accumulated and then centered at solve time. In the SERQ runs, products are computed in FP32, accumulated into FP64 statistics, and solved in FP64 before factors are cast to the loaded model dtype. The artifact-bound timing run confirms FP32 loading for the existing accuracy implementation.
