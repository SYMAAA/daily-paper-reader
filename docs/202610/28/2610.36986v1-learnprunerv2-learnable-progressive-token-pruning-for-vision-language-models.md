## 摘要
视觉-语言模型（VLMs）已展现出卓越的多模态能力，但由于视觉Token数量庞大，面临难以承受的计算开销。尽管Token剪枝是一种有前景的解决方案，现有方法仍存在两个主要缺陷：1）剪枝准则不可靠：由于固有的注意力偏差或与查询无关的设计，无法准确定位任务相关区域；2）剪枝策略次优：采用刚性、非自适应的调度方案，忽略了Token冗余在不同模型深度上的动态演变。为解决这些挑战，我们提出LearnPrunerV2，将先前的两阶段启发式框架（LearnPruner）扩展为完全可学习的架构。具体而言，我们在VLM主干的每一层中集成轻量级可学习模块，通过融合内在视觉显著性与经由影子Token捕获的外在查询相关性来估计Token重要性。通过揭示VLM各层中一致的阶梯式冗余模式，我们进一步引入预算确定性剪枝（Budget-Deterministic Pruning, BDP），以建立具有固定逐层预算的硬件友好调度方案。在多种基准和VLM上的大量实验结果表明，LearnPrunerV2始终优于先前的最先进方法。值得注意的是，在LLaVA-v1.5上剪枝77.8%的视觉Token时，LearnPrunerV2仍保持原始性能的99.8%，实现了更优的精度-效率权衡。

## Abstract
Vision-Language Models (VLMs) have demonstrated remarkable multimodal capabilities but suffer from prohibitive computational overhead due to the massive number of visual tokens. While token pruning is a promising solution, existing methods still suffer from two major drawbacks: 1) unreliable pruning criteria that fail to accurately localize task-specific regions due to inherent attention biases or query-agnostic designs, and 2) suboptimal pruning strategies that employ rigid, non-adaptive schedules, overlooking the dynamic evolution of token redundancy across different model depths. To address these challenges, we propose LearnPrunerV2, which extends the previous two-stage heuristic framework (LearnPruner) into a fully learnable architecture. Specifically, we integrate lightweight learnable modules into every layer of the VLM backbone, which estimate token importance by fusing intrinsic visual saliency with extrinsic query relevance captured via a shadow token. By uncovering a consistent staircase redundancy pattern across VLM layers, we further introduce Budget-Deterministic Pruning (BDP) to establish a hardware-friendly schedule with fixed per-layer budgets. Extensive experimental results across various benchmarks and VLMs demonstrate that LearnPrunerV2 consistently outperform previous state-of-the-art methods. Notably, LearnPrunerV2 preserves 99.8% of the original performance when pruning 77.8% of visual tokens on LLaVA-v1.5, achieving a superior accuracy-efficiency trade-off.

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言模型（VLM）通常将图像/视频编码为大量视觉 token，再与文本 token 拼接送入 LLM。视觉 token 往往占输入序列主导地位，而自注意力复杂度随序列长度二次增长，导致推理延迟、显存和计算开销显著增加，限制实时与资源受限部署。
- **核心问题**：视觉 token 存在大量冗余，剪枝是有效方向，但现有方法在两个维度上仍不理想：
  - **剪枝准则不可靠**：基于视觉编码器注意力、LLM 注意力或 token 相似度的方法，可能受注意力 sink、位置偏置、查询无关设计或词级语义粒度限制，难以准确定位任务相关视觉区域。
  - **剪枝调度僵化**：多数方法采用静态、一次性或手工设计的多阶段调度，忽略 token 冗余随模型深度动态演变的事实。
- **整体含义**：论文主张将剪枝从“启发式规则”推进为“全可学习、逐层渐进、预算可控”的架构，使 VLM 在显著减少视觉 token 的同时尽量保持原性能，并兼顾硬件部署所需的确定性延迟。

## 2. 方法论

### 2.1 核心思想

- 将前作 LearnPruner 的两阶段启发式框架扩展为 **完全可学习的逐层渐进剪枝框架**。
- 在 VLM 主干 LLM 的每一层插入轻量级 **可学习剪枝模块（LPM）**，联合估计每个视觉 token 的重要性。
- 重要性由两部分融合：
  - **内在视觉显著性**：来自视觉 token 的隐藏状态；
  - **外在查询相关性**：通过新增的可学习 **shadow token** 聚合指令上下文，并与视觉 token 交互得到。
- 训练后利用发现的 **阶梯式冗余模式**，提出 **Budget-Deterministic Pruning（BDP）**，为每层分配固定 token 预算，实现硬件友好的确定性推理。

### 2.2 关键技术细节

- **输入序列扩展**：训练时序列为 `[X_sys, X_vis, X_ins, X_shd, X_ans]`，shadow token 初始化为换行符，可关注所有前序 token，但通过自定义因果掩码对其他 token 不可见，避免扰动原模型预测。
- **查询相关性向量**：对第 i 个视觉 token，用 shadow query 与视觉 key 计算多头 pre-softmax logits：
  - `a_i = [q_shd^h (k_i^h)^T / sqrt(d)]`；
  - 不直接读取内部注意力矩阵，因而兼容 FlashAttention，并保留数值对比度。
- **相关性特征映射**：每层使用层特定 MLP φ 将 `a_i` 映射为 `r_i`。
- **跨层门控稳定**：将当前层相关性特征 `r_i^(l)` 与上一层平滑特征 `r_i^(l-1)` 拼接，经线性层和 sigmoid 得到门控权重 `w_i^(l)`，再更新：
  - `r̃_i^(l) = w_i^(l) · r_i^(l) + (1 - w_i^(l)) · r̃_i^(l-1)`；
  - 初始 `r̃_i^(0)=0`，用于抑制跨层注意力噪声。
- **重要性评分**：将视觉 token 隐藏状态 `X_i^(l)` 与平滑相关性特征 `r̃_i^(l)` 拼接，送入共享评分网络 MLP ψ，经 sigmoid 得到重要性分数 `s_i^(l)`。
- **参数共享策略**：MLP φ 层特定，MLP ψ 全层共享，以兼顾层间语义差异与优化稳定性。
- **离散剪枝与梯度传播**：以阈值 0.5 得到二值 mask，使用 Straight-Through Estimator（STE）桥接不可微的 keep/drop 决策。
- **累积掩码**：`M̂^(l) = M̂^(l-1) ⊙ M^(l)`，token 一旦被剪枝，后续层永久排除。
- **训练目标**：
  - 剪枝正则项 `L_prune` 约束各层保留 token 比例接近 ρ（实验中 ρ=0，鼓励最大稀疏）；
  - 总损失 `L = L_ntp + λ L_prune`，λ=1；
  - shadow token 不参与下一 token 预测损失，以专注跨模态相关性建模。
- **BDP 调度**：
  - 离线校准得到每层平均保留比例 `η_l`；
  - 给定用户预算 `n̄`（每层平均保留 token 数），计算全局缩放因子 `α = n̄·L / (N_vis·Ση_l)`；
  - 每层预算 `n_l = round(η_l · N_vis · α)`，保持学习到的层间分布并固定每层 token 数。
- **多样性感知选择**：若候选重要 token 数超过预算，先选 top-`n_p` 作为 pivot，再按与 pivot 的最大余弦相似度最低原则填充剩余名额，以平衡重要性与多样性，低预算下尤其有效。

## 6. 主要结论与发现

- LearnPrunerV2 在多个保留比例下 consistently 优于 FastV、SparseVLM、VisPruner、DART、CDPruner 和 LearnPruner。
- **LLaVA-v1.5**：保留 128 token（剪除 77.8%）时保持 **99.8%** 原性能；保留 32 token 时仍达 **95.7%**，比此前 SOTA 高约 2.1%。
- **LLaVA-NeXT**：保留 640 token 时达 **99.7%**；剪除 94.4% 视觉 token 时仍保留 **96.2%** 性能，并实现 **9.7× TFLOPs 降低**、prefill 加速 6.2×、KV cache 降低 8.7×、总推理时间加速 3.7×。
- **Qwen2.5-VL**：在 66.7% 和 77.8% 剪枝率下平均相对性能超过 100%，显示跨架构泛化性。
- **Video-LLaVA**：在视频基准上优于 FastV，低保留率下优势更明显。
- **机制发现**：学习到的逐层保留比例呈现稳定的“阶梯式”模式——浅层快速丢弃背景等无信息 token，中层进行密集跨模态交互并进一步剪枝，深层视觉 token 几乎完全冗余。
- **消融结论**：hidden state + shadow token 相关性 + 门控机制最有效；shadow token 优于 last-token attention/logit；层特定 φ + 共享 ψ 的混合共享最优；多样性选择在 32 token 低预算下优于 Top-K。

## 7. 优点

- **方法统一且端到端可学习**：将剪枝准则与调度统一到每层轻量模块中，减少手工启发式设计。
- **shadow token 设计巧妙**：既提供查询相关聚合信号，又通过自定义掩码避免干扰原预测；使用 pre-softmax query-key logits，兼容 FlashAttention 且保留数值对比度。
- **跨层门控增强稳定性**：缓解 VLM 注意力跨层波动，提升重要性估计一致性。
- **BDP 兼顾性能与部署**：利用离线校准的阶梯式先验，固定逐层预算，提升批处理吞吐与推理确定性，硬件友好。
- **低预算下多样性选择有效**：在固定预算内缓解 Top-K 的空间聚集和语义冗余问题。
- **模型无关性较好**：在 LLaVA、LLaVA-NeXT、Qwen2.5-VL、Video-LLaVA 上验证，具备一定通用性。
- **效率收益显著**：在高剪枝率下仍保持高精度，TFLOPs、prefill、KV cache 和总时延均有明显改善。

## 8. 不足与局限

- **训练成本未披露**：未报告 GPU 数量、训练时长、显存占用和模块参数量，难以评估实际训练代价与可复现性。
