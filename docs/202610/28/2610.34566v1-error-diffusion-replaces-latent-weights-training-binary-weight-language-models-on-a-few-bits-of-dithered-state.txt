# Error Diffusion Replaces Latent Weights: Training Binary-Weight Language Models on a Few Bits of Dithered State

Independent Researcher 

pierre-olivier.bonin@hotmail.com 

## Abstract 

Binary-weight language models store one bit per weight, but training them keeps a full-precision latent copy of each weight plus Adam state, about 96 extra bits per weight, so a deployed binary model cannot be adapted on the device that runs it. We replace the latent weight with a 2–8-bit residual buffer quantized by stochastic rounding, which cuts the training state per weight from 97 bits to 3–9, up to 19 ×

less. The resulting error-diffusion (ED) optimizer moves the residual-carrying loop of image halftoning onto the weight-update path. Each buffer accumulates the unrealized part of every update and flips the weight when the accumulated value crosses a threshold, and it works only when its quantization grid has a level exactly at that threshold. Under this threshold-alignment rule, 4-bit buffers match 8-bit buffers on a binary multilayer perceptron benchmark, and the same rule lifts a different latent-free optimizer, Bop, from a 10-point deficit at 4 bits to full-precision accuracy. On character-level transformers with 97% of parameters binary, ED trains within 5–11% of the latent-weight reference at a 2,000-step budget and within 1.7% at convergence. On scaling ladders over enwik8 and wikitext-103, up to 19M parameters on enwik8 (70M with the wikitext-103 embeddings), the latent-free loss stays within −2.3% to +2 .9% of the reference at all six sizes once a per-step cap on the buffer update removes a launch instability (§5.4); without the cap it trails by 10% at the largest tokenized size. A deployed binary model continues training under ED at one tenth of the latent training state, matching latent-weight continuation, and a fused CPU kernel completes the adaptation within a 275 MB training-memory budget, which latent-weight training cannot. A 250-step probe sets the flip learning rate at any new scale. 

## 1 Introduction 

Small language models suit agentic systems because they run where the agent acts, on a phone, a laptop, or an embedded controller. Binary-weight networks push this furthest, with 32 × memory compression and multiplication-free inference [Rastegari et al., 2016, Wang et al., 2023]. The standard training recipe since BinaryConnect [Courbariaux et al., 2015] keeps a full-precision (FP) 

latent weight per binary weight, updates it with Adam [Kingma and Ba, 2015], and binarizes it on the fly, as do XNOR-Net [Rastegari et al., 2016], DoReFa [Zhou et al., 2016], BitNet [Wang et al., 2023, Ma et al., 2024], and binary normalized networks [Cabral et al., 2025]. The training state per weight is then 97 bits (a 32-bit latent weight, two 32-bit Adam moments, and the sign), so a 100M-weight binary model occupies 12.5 MB at rest but needs about 1.2 GB of training state to be adapted. Latent-free alternatives exist but keep at least 32 bits per weight. The binary optimizer Bop [Helwegen et al., 2019] replaces the latent weight with a 32-bit exponential moving average (EMA) of gradients, and BOLD [Nguyen et al., 2024] keeps an accumulator of unspecified precision.

We transfer a mechanism from image processing. A grayscale image survives 1-bit quantization because Floyd–Steinberg error diffusion [Floyd and Steinberg, 1976] carries each pixel’s rounding residual forward until it accumulates into a pixel flip. Signal processing knows this loop as sigma-delta ( ∆Σ ) modulation [Anastassiou, 1989], error feedback (EF) in gradient compression [Seide et al., 2014, Karimireddy et al., 2019] applies it in time, and stochastic rounding (SR) [Höhfeld and Fahlman, 1992] applies it in value. We apply it to the weight-update path, so the residual buffer replaces the latent weight, and we quantize the buffer to 2–8 bits with SR, which cuts the training state per weight from 97 bits to 3–9 (Appendix A). 

Contributions. 

1. We propose ED, whose entire per-weight training state is one sign bit plus a 2–8-bit SR-quantized error-feedback buffer, 19 × less than latent-weight training at 4 bits (§3). 2. We show that the buffer is a stochastic accumulate-and-fire unit whose grid must contain a level at the flip threshold, a rule that removes an apparent 4-bit floor and restores full-precision accuracy to dithered Bop at 4 bits (§5.1). 3. We show that 97%-binary transformers train within 5–11% of the latent reference at 2,000 steps and 1.7% at convergence, that the loss tracks the reference at all six ladder sizes once a per-step update cap removes a launch instability, and that a deployed model continues training on a CPU within a 275 MB training-memory budget (§5.2–§5.5). 4. We give a 250-step probe that sets the flip learning rate at a new scale, validated by a pre-registered prediction (§5.6). 

## 2 Related work 

Latent-free binary training. Bop [Helwegen et al., 2019] flips a weight when a 32-bit gradient EMA crosses a threshold and is the closest prior method; Yayla and Chen [2022] compress its state by about 2×. BOLD [Nguyen et al., 2024] and the binary-error-signal line [Colombo et al., 2024, 2025] train without backpropagated gradients. None combines backpropagated updates with a low-bit SR-quantized residual as the sole per-weight state. 

Error feedback. 1-bit SGD, EF-SignSGD, and EF21 [Seide et al., 2014, Karimireddy et al., 2019, Richtárik et al., 2021] correct communication compression while FP weights persist underneath. ECO [Nikdan et al., 2026] removes master weights at FP8/INT4 by feeding the quantization error into Adam momentum, so 64 b/wt of optimizer state remains, and MicroAdam [Modoranu et al., 2024] quantizes an error-feedback buffer beside FP weights. Sigma-delta modulation appears as activation coding [O’Connor and Welling, 2016, O’Connor et al., 2018] and as post-training weight quantization [Xia et al., 2025, Czaja and Na, 2024, Lybrand and Saab, 2020]. In all of these the modulator’s output is a message or a post-hoc quantization, whereas in ED it is the stored model. 

Precision and scale. Scaling-law studies of quantized training [Kumar et al., 2025, Frantar et al., 2025, Chen et al., 2025] cover latent-weight training only, so §5.3 tests whether parallel loss curves survive removing the latent weight. μP [Yang et al., 2021] and u-μP [Blake et al., 2024] derive learning-rate transfer from continuous latent weights, which ED lacks, and we are not aware of a cross-scale rule for Bop’s threshold (§5.6). 

## 3 Method 

Notation. Each binary weight w ∈ {− 1, +1 } is scaled by a fixed per-layer scalar s = E|Winit |. All quantities are in flip units , where the distance between the two weight states is 2 and the flip threshold is 1. 1+ b for b ∈ { 2, . . . , 8} (3 b/wt–9 b/wt). The clamp adds an off-grid rail state ( 2b+1 reachable values, 4.09 bits at b=4 ), which we round down to b bits in favor of ED. Per-layer weight scales, per-batch activation scales, and the FP embeddings, LayerNorms, and head of the transformers are excluded from the per-weight count (§4). 

## 4 Experimental setup 

Tasks and data. (i) A teacher–student MLP benchmark isolates feature learning. Inputs are 

x ∼ N (0 , I 64 ) and labels come from a fixed random 4-layer tanh teacher with 10 classes (20k train, 4k test). The student is a frozen random FP projection, two binary hidden layers of width 

W with binary activations (the only feature learners), and a trainable FP readout, and the metric is test accuracy (higher is better). (ii) Character-level Shakespeare [Karpathy, 2015] (1.1 MB) trains nanoGPT-style [Karpathy, 2022] 4-layer transformers with dmodel ∈ { 128 , 256 , 512 } for 2,000 steps, and dmodel =256 for 50,000 steps. (iii) A byte-level enwik8 ladder [Hutter, 2006] trains 0.5M, 3.3M, and 19M parameters (2, 4, and 6 layers) for 15k steps of 64 × 256 bytes, and (iv) a tokenized ladder trains the same binary cores on wikitext-103 [Merity et al., 2017] with GPT-2 byte-pair encoding [Radford et al., 2019] (118M tokens, block 128). (v) Deploy-then-adapt pretrains a latent-weight binary transformer (4 layers, d=256 ) on enwik8, discards the latent weights, and adapts the deployed artifact to byte-level Shakespeare for 5,000 steps. For (ii)–(v) the metric is the best validation loss in nats (lower is better). In every transformer the attention and MLP projections are binary (97% of parameters at d=256 on characters), and the embeddings, LayerNorms, and head are FP and trained by AdamW [Loshchilov and Hutter, 2019]. 

Baselines. FP32+Adam (96 b/wt) is the accuracy upper bound, BitNet-style latent-weight training (97 b/wt, the “latent reference”) is the standard recipe and shares the STE with ED, and dithered Bop (9 b/wt at 8 bits) is the closest latent-free method and runs on the MLP benchmark. A frozen-random-binary control (binary layers never updated) is the floor above which accuracy is attributable to the update rule (Appendix E adds three further controls). 

Protocol. The flip-lr is the one hyperparameter of ED. MLP cells use flip-lr 1.0 at every width. The 2,000-step Shakespeare cells use the best of a five-point sweep on seed 0, reused for the other seeds. Every longer transformer cell and every adaptation cell sets its flip-lr by a 250-step drive probe. We train 250 steps at two or three candidate flip-lrs, record the mean absolute buffer occupancy 

¯|e| at step 250, compute the drive ρ = ¯|e|/250 in flip units per step, and keep the candidate with 

ρ ∈ [1 .0, 1.3] × 10 −3 (Appendix B). Section 5.6 shows that sweep-selected and probe-selected flip-lrs lie in or near this band. FP and latent arms use AdamW at 3 × 10 −4 with no schedule unless stated. Runs of 15k steps and longer decay the flip-lr linearly to 0.1×. 5.1 The buffer is a stochastic accumulate-and-fire unit Does a quantized buffer match a latent weight? At width 192 (5 seeds), the frozen control scores

Where must the grid sit? With the naive clamp C=1 .5, accuracy falls below 8 bits and collapses at 2 bits (Table 1, left), which looks like a 4-bit floor. With the grid strictly inside the threshold (C ∈ { 0.5, 0.75 , 0.9, 0.95 }), training is inert at every bit width (zero flips in 25 epochs for C ≤ 0.9), because per-step drives of about 10 −3 flip units never reach the threshold from the top grid level, and with levels beyond it ( C=1 .5) 2-bit buffers fire 1.3M times per epoch and score below the frozen control. At C=1 .0 every flip is an SR jump onto a grid level with |ℓ| ≥ 1. The buffer accumulates sub-threshold evidence and SR converts the excess into a firing probability, so the top grid level must sit exactly at the threshold. Under this rule 4-bit buffers equal 8-bit buffers and 2-bit buffers recover from collapse (Table 1). Does the rule transfer to Bop? Dithered Bop at 9 b/wt matches ED at every width (Figure 1), but at 4 bits on an absmax-scaled grid it loses 10 points (Table 1, right). We predicted before the run that regridding the EMA so that a level sits exactly at its threshold τ would restore full-precision accuracy (Appendix D), and it does, with 57 .0 ± 1.0 at 5 b/wt against 56 .6 ± 1.5 for the FP EMA at 33 b/wt, 

+8 .5 points at 3 bits (45.3 vs. 53.8, not shown) and +12 .4 at 2. At 8 bits the two grids tie, as expected once some level falls within one per-step drive of the threshold anyway. Threshold alignment is therefore a property of thresholded quantized accumulators in general, and it holds on the transformer: on the 3.3M enwik8 cell, Bop’s 4-bit EMA collapses on the absmax grid ( 2.46 ± 0.24 ) and reaches 

1.669 ± 0.004 on the aligned grid, below ED-int4 at the same 5 b/wt (1.707), while its FP EMA ties ED-int8 (1.524 vs. 1.516; Appendix F). 

Is the buffer just a small integer latent weight? A (k+1) -bit saturating integer latent weight with SR updates ties the buffer at every matched budget, and a symmetric integer grid satisfies C=1 by construction, so the buffer coordinates are the frame in which the design variable is visible rather than a separate method. Appendix E (Table 7) adds a sign counter, which wins at 8 bits but collapses at 2, and two budget-split ablations that do not beat it. 

5.2 Transformers at a fixed budget and at convergence Does the latent-free transformer meet the criterion? Table 2 shows the 2,000-step cells. ED with an 8-bit buffer trails the latent reference by 4.8%, 8.1%, and 11.4% at dmodel 128, 256, and 512, inside the +20% criterion at every width, and the 4-bit buffer is within 0.06 of the 8-bit one. Does the gap close with training? In the 50,000-step regime (Table 2, last column) ED reaches 1.583 with a linear flip-lr decay, within 1.7% of the latent reference (1.556), and 1.586 without it. These single-run cells 5land within 0.035 of each other and FP32+Adam overfits this 1.1 MB corpus well before 50k steps, so we do not rank them. 

5.3 Scaling ladders Does the gap grow with scale? Table 3 gives both ladders. On byte-level enwik8, ED with an 8-bit buffer beats the latent reference by 2.5% at 0.5M parameters and trails it by 3.3% at 3.3M and 3.9% at 19M, so the gap stops widening between the two larger sizes. On tokenized wikitext-103 the two arms land within 0.15% of each other at the two smaller sizes, but at 19M ED trails by 10.2% at equal budget and 16.5% at a doubled budget. On this vocabulary the full-precision (FP) remnant, the parameters outside the binary layers (embeddings and head, 51.5M parameters) trained by Adam, outweighs the binary core 2.7:1, a regime the byte-level ladder never enters. Is training stable? At 19M on enwik8, two of five ED launches stall in the first 2,000 steps and finish 0.14–0.20 worse, so the 19M cell averages the three runs that did not stall (9.5% with the stalled runs included). Section 5.4 traces both the stalls and the tokenized gap to one event and removes it. Does a 4-bit buffer scale? At 2,000 steps it matches the 8-bit buffer (Table 2), but the gap opens with horizon and scale. On the enwik8 ladder, at probe-set flip-lrs two to four times below the 8-bit ones, the 4-bit buffer completes every size without stalls but trails the 8-bit buffer by 5.7%, 12.6%, and 17.2%, and the 50k convergence cell lands at 1.681 against 1.583. 

5.4 Launch stalls are flip avalanches, and a per-step update cap removes them 

Three questions remain from §5.3: what causes the 19M stalls, and whether a buffer initialization or a flip-lr warm-up prevents them; whether the tokenized gap comes from a learning-rate mismatch between the AdamW-trained FP remnant and the ED core; and whether the 4-bit buffer saturates over long horizons. Appendix F holds the diagnostics behind this section. 

The stall. With evaluations every 100 steps and per-block diagnostics, every stalled launch shows the same event. Inside a single 100-step window the flip rate doubles (38k to 79k flips per step on one captured event), the mean pre-activation magnitude of the first block rises 2.6-fold (1.28 to 3.39), the gradient norm reaching the binary weights falls five-fold (0.0097 to 0.0018), and the validation loss rises by 0.6–1.4 nats; LayerNorm gains, the head norm, and the FP remnant’s gradient stay on their trend. The core then runs at a tenth of its flip rate and recovers slowly. The “failure to ramp up” of §5.3 is the aftermath of one flip avalanche in the first block; it is a property of the realization, not the seed, and neither a non-zero buffer initialization (5 of 20 launches failed, against 3 of 20, over two realizations of seeds 0–9) nor a warm-up prevents it. On a step-2000 checkpoint the magnitude of the per-weight update u = −η g/s never exceeds 0.19 flip units on an ordinary step (median 0.0066), so a cap at 0.25 flip units, u ← clamp( u, −0.25 , 0.25) before the buffer add, leaves ordinary steps untouched, removes the one-step route to an avalanche, and replaces the stall check of §4. 

Results. Table 3, capped column: where no avalanche occurred (the two smaller sizes on both corpora) the cap moves the loss by at most 0.007 nats in either direction (same seed). (+0 .3% at 30k) against the latent reference. The 19M tokenized gap was an avalanche-rate problem, not a capacity or learning-rate one: with embeddings and head frozen, ED and the latent reference tie (7.279 against 7.243), and at a matched remnant learning rate of 10 −4 they tie again (4.610 against 4.625). A fast remnant on a 50k-token vocabulary triggers the avalanche more often than byte-level data does; the remnant’s size (2.7 × the core at 19M) is unchanged and remains a limitation. 

The 4-bit buffer. Histograms of the buffer over its grid, logged every 1k steps in replicates of the 50k-step cells of Table 2, decide the third question: the 4-bit buffer holds 6.2–7.5% of its weights at every interior level from step 2k to 50k (uniform: 6.7%) with at most 0.6% on the rails, while the 8-bit buffer’s mass gathers near the flip threshold (18.5% in each outermost sixteenth of the range at 50k, 0.2% on each rail). The 4-bit quantum ( 2/15 flip units) is about twenty times the median per-step drift, so rounding noise erases the accumulated signal: the gap is variance, not saturation, and it grows with horizon and scale because both shrink the drift relative to a fixed quantum. The 6wikitext-103 4-bit cells of Table 3 were run under the same protocol: uncapped, 5 of 6 launches at the two smaller sizes and all three 30k launches diverged with a steady flip rate, a failure we have not diagnosed and that the cap does not remove (one of two capped 30k launches diverged as well); the completed capped runs trail the capped 8-bit arm by 3.2%, 4.2%, 5.1%, and 7.1% at 30k, against 5.7%, 12.6%, and 17.2% on enwik8, where the cap changes the 4-bit cells by at most 0.005 nats. 

5.5 Deploy-then-adapt Can a deployed binary model keep learning? No latent copy exists, so the object being trained is the deployed binary network at every step, and adapting it in place adds only the b-bit buffer per weight. Loss falls from 2.32 to 1.520 ± 0.003 in 5,000 steps at 9 b/wt (3 seeds), against 1.95 for ED from scratch at the same budget and 1.533 ± 0.007 (3 seeds, at the best of three Adam learning rates) for continued latent-weight training with its full 97-bit state re-instantiated, so the buffer matches the re-instantiated latent weight. With a 4-bit buffer (5 b/wt) adaptation reaches 1.610 ± 0.005 , a 6% cost. Does it fit on inference-class hardware? We ported the adaptation step to a fused CPU kernel and ran it on the 19M-parameter enwik8 model, adapting to Shakespeare bytes for 2,000 steps (batch 8, block 128, one seed). The deployed artifact packs eight signs per byte into 4.0 MB, against 77 MB for the float32 latents and FP remnant. The kernel applies the integer update during backpropagation, stores no weight gradients, and draws SR bits from a stateless counter-based hash [Salmon et al., 2011]. We poll resident memory every step and abort a run when its peak above the post-setup baseline (about 750 MB of Python and PyTorch) exceeds a cap. Under a 275 MB cap the fused kernel peaks at 254 MB and reaches 1.513, within 0.017 of unconstrained latent-weight continuation (1.496), which peaks at 325 MB and aborts under 150 and 200 MB caps. The FP remnant still needs Adam state and the activation memory is unchanged. 

5.6 The constant-drive transfer rule Does one number set the flip-lr at every scale? Across three corpora, widths 128–512, two activation regimes, 8-bit and 4-bit buffers, and warm-started adaptation, the selected flip-lr varies from 12 to 225, but the drive ρ at each selected flip-lr lies within 0.85 –1.73 × 10 −3 flip units per step, and off-band candidates lose (Appendix E, Figure 3). A pre-registered prediction at d=512 (optimal flip-lr 80–90, Appendix D) held, with 80 winning at loss 1.782 (binary activations, 1 seed), 160 tying, and 40 losing. The MLP harness does not log the step-250 occupancy, so the MLP cells are absent from the figure, and the rule does not extend through heavy-ball momentum. Unlike μP-style transfer [Noci et al., 2024, Yang et al., 2021], the rule is measured, not derived. 

## 6 Limitations 

The tasks are a synthetic MLP benchmark and language models with at most 19M parameters (70M with the wikitext-103 embeddings) and six layers on one GPU, evaluated by validation loss and synthetic accuracy, not downstream tasks. The 50,000-step and tokenized-ladder cells are single runs, so the small margins among the converged methods are not statistically separated. We do not claim wall-clock efficiency, the cost of generating SR bits is not measured, and every ladder size trains on fixed data, so the data dimension is untested [Kumar et al., 2025]. The FP remnant (embeddings, norms, head, and their Adam state) is now the dominant residual training memory. The 1-bit-gradient ablation (Appendix E) is scoped to the weight-gradient operand and shows that gradient bits and buffer bits should not both be cut aggressively. We claim no accuracy advantage over a well-built saturating integer latent weight (§5.1). 

## 7 Conclusion 

ED trains binary-weight MLPs and transformers on 3–9 bits of training state per weight, up to 

19 × less than latent-weight training, by carrying each weight’s unrealized update in a stochastically rounded buffer whose grid has a level at the flip threshold. With a per-step cap on the buffer update, the loss stays within −2.3% to +2 .9% of the latent reference at all six ladder sizes (§5.4), and a deployed binary model continues training on a CPU within a 275 MB training-memory budget. ## A Error diffusion in halftoning and in the weight update 

Figure 2: Error diffusion in halftoning and in the weight update. Panels (a) and (b) show Floyd– Steinberg halftoning, which renders a grayscale image with binary pixels by carrying each pixel’s rounding residual forward in scan order. Panel (c) shows the ED optimizer applying the same recurrence in time, on a simulated weight with an illustrative drive. A binary weight’s unrealized updates accumulate in a small quantized buffer (2-bit here), and a flip fires when stochastic rounding lands the buffer on the threshold level (§5.1). Panel (d) compares the cumulative demanded movement with the movement realized by flips. The flips follow the demand with a lag. The gap can exceed 

C, because the clamp at ±C discards updates that push a weight further toward its current sign, and stochastic rounding adds zero-mean noise that the buffer does not carry forward. 

## B The 250-step drive-probe protocol 

1. Configure the target run exactly (model, data, batch, block, binarization). Pick two or three candidate flip-lrs that bracket a linear-scaling guess from the nearest known scale. 10 2. Train 250 steps per candidate. Record the mean absolute buffer occupancy ¯|e| at step 250 (flip units). 3. Compute the drive ρ = ¯|e|/250 in flip units per step. Select the candidate with ρ ∈

[1 .0, 1.3] × 10 −3. If none lands in the band, interpolate and re-probe. 4. The rule has known boundaries. It does not extend through heavy-ball momentum. At the largest widths prefer the band’s lower edge, because at 4 bits an in-band probe reading can precede buffer saturation. Re-probe after any change of dataset, tokenizer, block size, or warm-start status. 5. The cost is the number of candidates × 250 steps (up to about 11 GPU-minutes per candidate at 19M parameters). For long runs add the stall check, which restarts with a new seed if validation loss at step 2k exceeds its value at step 1k.

## G Reproducibility 

All experiments are seeded, with a single CPU generator per run and a documented consumption order; CUDA kernel non-associativity still separates reruns of one configuration by up to about 0.02 nats in stable runs, and can decide whether an uncapped launch stalls (Appendix F). Ev-ery result row is one JSON Lines (JSONL) record that carries its configuration (the latent-arm rows of the adaptation log omit the Adam learning rate, which the run script sets). Code, run scripts, logs, and the dated records are public at https://github.com/pierreolivierbonin/ error-diffusion-binary-weight-lms under the MIT License. The main branch holds the experiments of Sections 3–5, and each experiment behind §5.4 has its own branch with the exact code that produced its logs; Table 10 maps each reported artifact to its script and log. A large language model (LLM) assisted with drafting, experiment orchestration, and literature search under the author’s direction. Seeded code produced all results.
