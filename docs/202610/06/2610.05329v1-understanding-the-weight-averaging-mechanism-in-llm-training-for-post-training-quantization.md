## 摘要
大语言模型（LLM）通常以高精度进行预训练，但越来越多地以低精度训练后量化（PTQ）进行部署。近期研究表明，与学习率衰减相比，在预训练期间使用权重平均可以提升 PTQ 性能，这表明它可能提供一种简单方法来改善从预训练到量化的过渡。但权重平均背后的机制仍未得到充分解释。这导致性能提升不稳定且脆弱，从而使从业者无法放心地应用此类技术。为此，我们将权重平均形式化为在保留训练进展与提升扰动下鲁棒性之间的一种权衡。我们进一步推导出一族连续的平均核，它统一了传统策略，并在两个相互竞争的目标之间达到帕累托前沿。关键的是，我们提出了一个在 PTQ 下执行权重平均的理论框架。可以证明，较粗的量化更容易受到扰动影响，而较细的量化受到的影响可能更小。因此，我们的结果可为在不同 PTQ 条件下执行权重平均提供统一的理论指导。实验验证了所预测的行为以及所提出的平均策略。代码见 https://github.com/MOFA-LAB/weight-averaging-for-ptq。

## Abstract
Large language models (LLMs) are typically pretrained in high precision but increasingly deployed with low-precision post-training quantization (PTQ). Recent studies have shown that using weight averaging during pretraining can improve PTQ performance compared with learning-rate decay, suggesting that it might provide a simple way to improve the pretraining-to-quantization transition. But the mechanism behind weight averaging remains insufficiently explained. This leads to inconsistent and fragile performance gains, thereby preventing practitioners from applying such a technique confidently. As a response, we formulate weight averaging as a trade-off between retaining training progress and improving robustness under perturbation. We further derive a continuous family of averaging kernels that unifies conventional strategies and achieves the Pareto frontier between the two competing goals. Critically, a theoretical framework for performing weight averaging under PTQ is developed. It can be shown that coarser quantization is more susceptible to perturbations, whereas finer quantization could be less affected. Thus, our results could provide unified theoretical guidance for performing weight averaging under different PTQ conditions. Experiments validate both the predicted behavior and the proposed averaging strategy. Code is available at https://github.com/MOFA-LAB/weight-averaging-for-ptq.

## 2. 方法论：核心思想、关键技术细节与公式流程

### 2.1 核心思想：时间滞后 vs. 空间噪声的分解

- 将每个保留的权重分解为：\(\theta_t = \mu_t + \epsilon_t\)
  - \(\mu_t\)：潜在均值（latent mean），表示跨重复训练运行的期望，即理想的无噪声最终模型。
  - \(\epsilon_t\)：零均值空间噪声，来自小批量采样、数据顺序等训练随机性。
- 对权重平均后，偏差分解为：
  \[
  \theta^w_T - \mu_T = \underbrace{-(\mu_T - \sum_d w_d \mu_{T-d})}_{\text{时间滞后 (temporal lag)}} + \underbrace{\sum_d w_d \epsilon_{T-d}}_{\text{空间噪声 (spatial noise)}}
  \]
- **时间滞后**：权重平均牺牲的近期训练进展，可能损害 PTQ 转换时的性能。
- **空间噪声**：权重平均通过降低随机波动的方差来提升对 PTQ 的鲁棒性。
- 平均核 \(w\) 决定两者的平衡。

### 2.2 关键坐标与 LNWA 核族

- 定义两个关键量：
  - 平均年龄 \(m(w) = \sum_{d=0}^{M-1} d w_d\)：衡量时间滞后。
  - 核的平方 \(\ell_2\) 范数 \(R(w) = \sum_{d=0}^{M-1} w_d^2\)：衡量保留的空间噪声方差。
- **LNWA（Lag–Noise Trade-off Weight Averaging）核族**：
  \[
  w_\lambda = \arg\min_{w \in \mathcal{W}_M} \{R(w) + \lambda m(w)^2\}, \quad 0 \le \lambda < \infty
  \]
- 闭式解：对每个有限 \(\lambda\)，唯一最优解具有活跃前缀 \(S_q = \{0,\dots,q-1\}\)，系数为：
  \[
  (w_\lambda)_d = q^{-1} + \lambda m_q(\lambda)(\bar{d}_q - d), \quad 0 \le d < q
  \]
  其中 \(m_q(\lambda) = \bar{d}_q / (1 + \lambda D_q)\)，\(\bar{d}_q = (q-1)/2\)，\(D_q = q(q^2-1)/12\)。
- **Pareto 前沿**：\(\{w_\lambda\}_{0 \le \lambda \le \infty}\) 参数化了时间滞后与空间噪声之间的完整 Pareto 前沿。增大 \(\lambda\) 减少时间滞后但增加空间噪声；减小 \(\lambda\) 则相反。
- **经典方法作为特例**：
  - LAWA（均匀平均）= \(\lambda = 0\) 端点。
  - Stable（仅最新权重）= \(\lambda = \infty\) 端点。
  - WMA（线性加权）= 精确内部点，\(\lambda_{\text{WMA}} = 6/[M(M^2-1)]\)。
  - EMA（指数加权）= \(M=2\) 时精确，\(M>2\) 时为 \(O(\eta^2 M)\) 局部近似。

### 2.3 PTQ 理论框架

- 采用简化 GPTQ 模型：将参数分为两组，先量化第一组，用第二组补偿重构误差，再量化第二组。
- 定义期望输出重构误差：
  \[
  E_b(w) = \frac{1}{2}\mathbb{E}\left[\|Q_b(\theta^w_T) - \mu_T\|_G^2\right] = P_0(w) + \gamma_b Q(w)
  \]
  - \(P_0(w)\)：量化前误差，含时间滞后项与空间噪声项。
  - \(\gamma_b Q(w)\)：量化引入的重构误差，\(\gamma_b = c_G/(2^b-1)^2\) 随精度降低而增大。
- **Theorem 4.2（有限噪声容忍与退化）**：固定精度下，存在唯一阈值 \(\tau_b \in [0,1)\)：
  - 容忍区间 \(0 < x \le \tau_b\)：减少时间滞后可补偿增加的噪声，误差低于 LAWA。
  - 退化区间 \(x > \tau_b\)：误差严格超过 LAWA 并持续增加。
  - 若 \(\tau_b = 0\)，任何向新权重的移动都会导致退化。
- **Theorem 4.3（精度阈值决定偏好）**：定义精度阈值
  \[
  b_{\text{crit}} = \log_2\left(1 + \sqrt{\frac{2c_G \bar{\mu}^\top u}{u^\top G(\mu_T - \bar{\mu})}}\right)
  \]
  - \(b \le b_{\text{crit}}\)：最优核为 LAWA（\(x_b=0\)），偏好更少空间噪声。
  - \(b > b_{\text{crit}}\)：最优核向新权重移动（\(x_b>0\)），偏好更少时间滞后。
  - \(x_b\) 随 \(b\) 非递减，且在 \(b > b_{\text{crit}}\) 时严格递增。

## 6. 主要结论与发现

1. **权重平均的本质是时间滞后与空间噪声的权衡**：减少空间噪声提升鲁棒性，但引入时间滞后牺牲近期训练进展。
2. **LNWA 统一并推广了经典平均策略**：LAWA 和 Stable 是两端点，WMA 是精确内部点，EMA 在 \(M=2\) 时精确、\(M>2\) 时近似。
3. **有限噪声容忍区间**：固定精度下，减少时间滞后可在一定范围内补偿增加的噪声，超过阈值后性能退化。
4. **精度决定偏好反转**：
   - 低精度（如 2-bit）：量化噪声主导，偏好更少空间噪声（倾向于 LAWA）。
   - 高精度（如 4-bit）：时间滞后主导，偏好更少时间滞后（倾向于更新权重）。
   - 存在明确的精度阈值 \(b_{\text{crit}}\) 标记偏好反转。
5. **LNWA 优于 LR decay**：在 OPT-1.3B 上，LNWA 在 GPTQ 和 AWQ 下的平均 PPL 均低于两种 LR decay 策略，且在 2-bit 下改进最大。
6. **Hessian 迹更低**：权重平均（LNWA）达到与 LR decay 接近的验证性能，同时保持更低的局部曲率（Hessian 迹 1,385 vs. 1,605–1,859）。

## 7. 优点

- **理论贡献扎实**：首次将权重平均在 PTQ 中的作用形式化为时间滞后与空间噪声的权衡，并推导出闭式 Pareto 前沿核族。
- **统一性强**：LNWA 将 LAWA、WMA、EMA、Stable 等经典方法统一为特例，提供了一致的分析框架。
- **理论指导实践**：Theorem 4.2 和 4.3 明确给出了噪声容忍阈值和精度阈值，为不同 PTQ 条件下的平均策略选择提供可操作指导。
- **实验验证充分**：跨模型规模（125M–1.3B）、跨 PTQ 方法（GPTQ/AWQ）、跨精度（2/3/4-bit）验证了理论预测的反转现象。
- **假设的经验评估**：通过 MNIST MLP 多分支训练，实证检验了空间噪声去相关、各向同性、增量对齐等关键假设。
- **代码开源**：提供 GitHub 仓库，便于复现和后续研究。

## 8. 不足与局限

- **理论基于简化模型**：
  - 使用随机抖动舍入（triangular dither）而非确定性最近舍入。
  - 使用全局 scale 而非分组 scale。
  - 仅考虑两阶段量化与补偿，未覆盖更复杂的 PTQ 流程（如多阶段、逐通道量化）。
- **假设较强**：
  - 各向同性空间噪声、不同位置噪声不相关。
  - 潜在均值增量的两两对齐、与窗口起始均值对齐。
  - 固定保留权重数量、固定模型维度等。
- **实验覆盖有限**：
  - 最大模型仅 1.3B，未验证更大规模 LLM（如 7B+）。
  - 未报告多次运行的方差或统计显著性。
  - 主要使用 OPT 架构，未验证其他架构（如 LLaMA、Mistral）。
- **潜在均值估计的局限**：理论假设的验证使用小规模 MLP 而非真实 LLM 多运行训练，因为 LLM 预训练重复运行成本极高。
- **应用限制**：理论结论在理想化条件下成立，直接迁移到实际 PTQ 流水线可能需要进一步调整。
