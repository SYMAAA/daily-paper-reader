ABSTRACT
Post-training compression of LLM attention is often formulated as independent
matrix approximation, ignoring both the shared structure among attention projec-
tions and the representation shift introduced by earlier compression. We propose
FTC, a sequential structured compression framework that adapts the approxima-
tion to the current compressed model while jointly exploiting the native Q/K/V
head structure under a fixed storage budget. The output projection is handled
separately to account for the changed post-attention representation. FTC requires
neither fine-tuning nor gradient-based recovery. Across seven decoder-only LLMs
from 6B to 32B parameters, FTC achieves the lowest WikiText-2 perplexity among
the compared methods at every tested keep ratio on five modern GQA models,
with the largest gains under aggressive compression. The improvements transfer
to downstream tasks and remain substantial at the 32B scale.

INTRODUCTION
Large language models (LLMs) remain costly at inference time because Transformer blocks repeat-
edly apply large dense projection matrices, creating substantial memory and computational overhead
on resource-constrained hardware. A common approach is to approximate each projection indepen-
dently with low-rank factors (Yuan et al., 2023; Wang et al., 2025c). This can miss redundancy
between projections: the query, key, and value projections read the same hidden input and may
use overlapping feature directions. Although independent low-rank factorizations reduce the cost of
each projection, they may still spend a fixed budget repeatedly representing feature directions shared
across Q/K/V. A joint tensor representation can instead represent these common directions through
shared factors, leaving more of the budget to capture the differences across projections and heads.
Previous methods like TensorLLM and LeSTD exploit shared structure through Tucker representa-
tions (Gu et al., 2025; Li et al., 2026). The remaining challenge is to share useful feature structure
without overly restricting the representation available to individual heads.
Sharing structure across Q/K/V is not sufficient by itself, since the features worth preserving depend
on how approximation error is evaluated.Activation-aware low-rank methods use calibration activa-
tions for this purpose (Yuan et al., 2023; Wang et al., 2025c), yet the representations seen by later
layers change as compression proceeds. A shared subspace fitted to the original activations may
therefore become misaligned with the current compressed model. Moreover, the output projection
operates on the post-attention representation, so it requires a separate approximation metric. These
observations motivate a sequential framework that adapts the Q/K/V representation to the current
compressed model while treating the output projection separately.
We propose FTC, a sequential Functional structured Tucker Compression framework for attention
projections. At each layer, FTC constructs an activation-induced metric from the current compressed
model and uses it to fit the query, key, and value projections jointly. The factors along the model
and within-head feature dimensions are shared across projections, while each head slice retains its
own core coefficients. Leaving the head-slice mode uncompressed preserves head-specific coeffi-

cients and naturally supports both multi-head attention (MHA) and grouped-query attention (GQA)
(Ainslie et al., 2023). We also balance the head slices during factor estimation to keep differences
in projection magnitude from dominating the shared fit.
Sharing feature directions does not require each head to use every possible combination of them. A
dense Tucker core nevertheless stores a coefficient for every pair of retained input and within-head
directions. We instead allow each head slice to retain a subset of these interactions. The Tucker ranks
and the total number of retained coefficients are chosen together, counting the factors, core values,
and support metadata in the budget. This provides a choice between fewer shared directions with a
denser core and more directions with a sparser core. We then prune the core gradually, refitting the
factors and surviving coefficients between stages.
The output projection requires a different treatment because it acts on the attention representation
rather than on the common input to the query, key, and value projections. After compressing these
projections, we recompute the attention features. Using these updated features, we construct a cal-
ibrated target for the output projection by matching the original model’s attention-branch outputs
with regularization toward the pretrained weights, yielding a closed-form linear solution.. The cali-
brated target is then compressed under a separate activation-induced metric, and the updated block
provides the inputs for compressing the next layer.
We evaluate FTC across seven decoder-only LLMs spanning MHA and GQA architectures, with
the largest gains appearing under aggressive compression. A matched per-matrix baseline helps
separate the effect of the joint structured representation from that of the activation-induced metric
and sequential calibration.
Our contributions are as follows:
• We develop FTC, which jointly fits shared Q/K/V Tucker factors under an activation-
induced metric from the current compressed model, while preserving the native MHA/GQA
head structure. The output projection is calibrated separately in closed form using updated
attention features and teacher branch outputs.
• We jointly allocate Tucker ranks and sparse-core capacity under a storage budget account-
ing for factors, retained coefficients, and support metadata. The resulting allocation bal-
ances subspace and sparsification errors, followed by gradual core pruning with intermedi-
ate refitting.
• Across seven decoder-only LLMs from 6B to 32B, FTC achieves lower WikiText-2 per-
plexity and higher aggregate downstream accuracy under aggressive compression on all
five GQA models, without fine-tuning or gradient-based recovery. A matched per-matrix
control further supports the benefit of the structured representation.

RELATED WORK
Activation-aware low-rank compression.
Recent low-rank compression methods extend beyond
weight-space reconstruction by incorporating model inputs or parameter importance into the approx-
imation objective. Fisher-weighted SVD uses parameter sensitivity (Hsu et al., 2022), while ASVD
and SVD-LLM exploit activation information to improve low-rank approximation (Yuan et al., 2023;
Wang et al., 2025c). Later work further considers rank allocation, truncation-error compensation,
and numerical stability (Wang et al., 2025b; Li et al., 2025; Parkina & Rakhuba, 2025). FTC differs
by constructing its activation-induced metric from the current compressed model and using it to fit
a joint head-wise Q/K/V representation rather than independent projection matrices.
Shared and tensorized representations.
Shared and tensorized compression methods seek to ex-
ploit redundancy across projections or layers through common low-dimensional structure. Basis
Sharing uses shared low-rank bases with layer-specific coefficients (Wang et al., 2025a), while Ten-
sorLLM and LeSTD model attention projections with Tucker-based shared factors (Gu et al., 2025;
Li et al., 2026). Other work explores tensor-train and sparse tensor representations for model com-
pression (Xu et al., 2023; Solgi et al., 2025), as well as joint Q/K/V factorization (Wang et al.,
2025d). Recent studies also indicate that overly restrictive shared subspaces may not capture the
heterogeneous structure of modern LLM representations (Zagitov et al., 2026). FTC addresses this
2


Preprint
issue by sharing Tucker factors across Q/K/V and retaining head-specific core coefficients, balancing
common structure with head-specific flexibility.
Sequential correction and sparse allocation.
Sequential compression and error correction have
been explored in prior work. SparseGPT performs layerwise activation-aware pruning (Frantar &
Alistarh, 2023), while MPIFA and AA-SVD introduce reconstruction or refinement steps to reduce
accumulated compression error (Zhao et al., 2025; Sinha & Fleuret, 2026). FTC instead uses the
current student activations to define the activation-induced metric for the joint Q/K/V tensor approx-
imation, and compresses the output projection separately using the updated attention representation.
Pruning methods such as Wanda and SliceGPT remove individual weights or structured hidden
dimensions (Sun et al., 2024; Ashkboos et al., 2024), while LoRAP assigns low-rank approximation
and structured pruning to different Transformer sublayers (Li et al., 2024). Global low-rank-plus-
sparse allocation has also been studied across layers (Zhou et al., 2026). In contrast, FTC couples the
Tucker factor ranks and the number of retained latent-core coefficients within each attention layer.
Core sparsity selects rank-one interactions between shared directions rather than producing zeros
in the reconstructed weight matrices; practical acceleration therefore requires a kernel that exploits
the latent representation. Hardware-supported patterns such as 2:4 provide one possible deployment
route (Mishra et al., 2021).

FUNCTION-DRIVEN STRUCTURED COMPRESSION
We compress the attention blocks sequentially using representations generated by the current com-
pressed model. Figure 1 summarizes the overall framework, and the following subsections develop
its activation-induced metric, structured Q/K/V approximation, and output-projection calibration.
Figure 1: Overview of FTC. At each layer, FTC builds an activation-induced metric from the current student
representations, jointly compresses the Q/K/V projections with a shared Tucker representation, and allocates
the layer budget between Tucker ranks and sparse-core capacity. The core is then refined progressively, while
WO is calibrated and compressed separately using the updated attention representation. The resulting student
representation is passed to the next layer, forming a sequential compression process.

EXPERIMENTS
We evaluate our FTC across decoder-only LLMs of different scales and attention architectures. We
report perplexity and downstream performance, followed by ablations and analyses of the main
components. Below we first introduce the models, baselines and protocol of our experiments:
Models.
We evaluate on two MHA models (GPT-J-6B, Llama-2-13B) and five modern GQA
models (Mistral-7B-v0.3, Llama-3-8B, Qwen2.5-7B, Qwen3-8B-Base with QK-norm, and Qwen3-
32B). Among them, Qwen3-32B is further used to test scale and architectural generalization.
Baselines. We compare FTC with five published baselines: enh-LeSTD, our GQA-capable port of
LeSTD using the same head-concat tensorization (Li et al., 2026); TLLM-gen, a TensorLLM-style
data-free dense Tucker baseline (Gu et al., 2025); MPIFA (Zhao et al., 2025); SVD-LLM (Wang
et al., 2025c); and Basis Sharing (Wang et al., 2025a). Seq-SVD is our per-matrix control under
the same functional metric and sequential calibration as FTC, rather than a published baseline.
Protocol. FTC uses 256 WikiText-2 calibration sequences of 2,048 tokens (seed 42), while data-
dependent baselines follow their published 128-sequence configurations; Table 16 quantifies this

difference. All methods use the same evaluation windows and parameter-count accounting. Fol-
lowing LeSTD, ρ denotes the retained storage ratio; smaller ρ means stronger compression. The
detailed storage accounting is provided in Appendix A.1.
All main-table FTC results use one fixed recipe across models and ratios: the budget-allocation
parameter β = 0.5, the teacher-Gram anchoring parameter a = 0.5, no QKV teacher map, a closed-
form teacher map for WO with regularization parameter µ = 1, the gradual core-pruning rate α =
0.02, two refits, 256 calibration windows, and slice-wise normalization. No fine-tuning or gradient-
based recovery is used.

The ablation results reveal three main patterns in how the individual components contribute across
compression levels and model architectures.
(1) Metric whitening, sequential calibration, and joint tensorization become increasingly im-
portant as the compression budget tightens. At ρ = 0.6, removing whitening, sequential calibra-
tion, or joint tensorization increases perplexity by at most 11.7%. At ρ = 0.2, the corresponding
penalties rise to 79.8–1662.4%, 70.2–457.7%, and 65.0–1102.8%, respectively. These results show
that activation-induced metric, adaptation to the evolving student stream, and joint Q/K/V modeling
become increasingly important as the compression budget tightens.
(2) The contributions of the remaining components vary more substantially across models.
At ρ = 0.2, removing anchoring changes perplexity by only 1.5–14.5%, whereas removing slice-
wise normalization costs 11.8–492.4%. Replacing the sparse core with its matched-budget dense
counterpart incurs only 4.3–8.7% on three models but 114.3% on Qwen2.5-7B. The WO teacher
target is beneficial on all four models, with its removal increasing perplexity by 2.6–182.6%.
(3) Fixed head-concat is consistently preferred to K/V repeat-expansion. At ρ = 0.2, replacing
head-concat with K/V repeat-expansion increases perplexity by 41.9% on Mistral-7B, 64.6% on
Llama-3-8B, 2.6% on Qwen2.5-7B, and 35.8% on Qwen3-8B. The magnitude varies substantially
across architectures, but the native head-concat construction is preferred on all four GQA models.
Additional teacher-map and hyperparameter studies are reported in Appendix A.4.
5
CONCLUSION
We proposed FTC, a structured attention-compression framework combining an activation-induced
metric, sequential calibration, joint Q/K/V tensorization, and budget-coupled rank–sparsity alloca-
tion. Across MHA and GQA models from 6B to 32B, FTC achieves consistently lower perplexity
and stronger downstream retention than the compared methods, without fine-tuning or gradient-
based recovery. Ablations further show that metric whitening, sequential calibration, and joint ten-
sorization become increasingly important as the compression budget tightens.

LeSTD reproduction.
We reproduce LeSTD from its published description and first verify the
implementation against its reported GPT-J results. Native LeSTD is not directly applicable to GQA
because its per-head factorization assumes one-to-one Q/K/V head structure. We therefore use enh-
LeSTD, a GQA-compatible port that adopts the same native head-concat tensorization as FTC while
retaining LeSTD’s data-free objective. This isolates the compression objective from the tensoriza-
tion required for GQA support.

attention projections. Since all dense weights use the same precision, this equals their parameter
fraction. Leaving the remaining model unchanged, the corresponding whole-model storage reduc-

HYPERPARAMETER ABLATIONS
Ablation protocol and additional design studies.
Table 3 reports one-at-a-time ablations of the
final recipe on all four GQA models at ρ ∈{0.6, 0.2}. The recipe uses fixed head-concat tensoriza-
tion, budget-coupled allocation, a = 0.5, α = 0.02, two refits, 256 calibration samples, slice-wise
normalization, no QKV teacher map, and a separate teacher-calibrated WO target. Each variant
changes one component while keeping the remaining configuration and compression budget fixed.
“K/V repeat-expand” replaces head-concat by naive GQA→MHA replication, while “dense core”
uses a dense core under the same parameter budget. Additional development-stage studies below
examine design choices not isolated by the main grid.
QKV teacher-map regularization.
Table 10 shows that disabling the QKV teacher map consis-
tently gives the lowest perplexity at ρ = 0.2. Among the mapped variants, µ = 3 performs best
on Mistral-7B, Llama-3-8B, and Qwen3-8B, while Qwen2.5-7B favors µ = 10. Even at these best
mapped settings, perplexity remains 2.1–11.3% higher than the no-map configuration. This supports
using the original QKV weights as the compression target in the final recipe, without an additional
teacher-output map.

Anchoring.
The final recipe mixes the teacher
Gram into the WO statistics with a = 0.5, while
leaving the QKV statistics unanchored. As shown in Table 3, anchoring has little effect at ρ = 0.6:
removing it changes perplexity by only −0.6% to +0.8% across the four GQA models. Its con-

Slice-wise normalization.
The effect of slice-wise normalization is strongly budget-dependent.
As shown in Table 3, removing the slice-wise norm has only a limited and model-dependent effect
at ρ = 0.6, changing perplexity by −0.3% to +5.5% across the four GQA models. At ρ = 0.2,
however, the degradation becomes substantially larger: 27.2% on Mistral-7B, 89.4% on Llama-3-
8B, 492.4% on Qwen2.5-7B, and 11.8% on Qwen3-8B. This indicates that slice-wise normalization
becomes increasingly important under aggressive compression, where a tighter core budget makes
the decomposition more sensitive to energy imbalance across head slices.

Whitening stability guard.
The default whitening metric uses ϵ = 10−4. To ensure numerical
stability, we increase ϵ by factors of ten whenever the de-whitened reconstruction is non-finite or its
norm exceeds 10× that of the original weight. The same guard is applied uniformly to all config-
urations. It is never activated at ρ ≥0.4, and no run falls back to the identity metric or leaves any
layer uncompressed.
At ρ = 0.2, the guard is triggered only for a subset of layers (Table 15). The most sensitive case is
Qwen2.5-7B: under the final no-QKV-map recipe, 9 of 28 layers require increased damping, with 3
reaching ϵ = 1. The escalation frequency also changes with the QKV target, indicating that different
compression choices can alter the conditioning of the activation statistics seen by subsequent layers.
Together with the damping sweep in Table 14, where larger ϵ generally degrades performance at this
budget, these results show that the guard serves as a numerical safeguard rather than a mechanism
for improving compression quality.

B.1
OVERALL COMPRESSION ALGORITHM
Figure 1 provides a conceptual overview of the proposed framework, while Algorithm 1 summa-
rizes its complete layerwise implementation. The compression proceeds sequentially through the
attention layers of the model. At each layer, activations from the current student model are used to
construct the activation-induced metric for joint Q/K/V compression. The resulting Q/K/V projec-
tions are inserted into the student model before the attention output projection WO,l is processed,
so that its compression is based on the representations produced by the updated student attention
branch. After replacing the corresponding projection weights with their compressed counterparts,
the updated student model is used to generate the activations required for compressing the next layer.
