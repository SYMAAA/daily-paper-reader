## 摘要
视觉Transformer（ViT）在图像识别和移动视觉应用中取得了强大性能，但其高维线性投影和注意力计算仍然带来巨大的存储和推理成本。极低位量化是一种有前景的解决方案，但ViT常常遭受严重的精度下降，因为传统的实值标量码本与Transformer投影的方向几何结构匹配不佳。我们提出RPFQ-ViT，一种旋转相位帧量化方法，它在二维相位平面中量化成对通道，使低位码能够更好地保留投影方向，同时通过轻量级缩放恢复幅度。RPFQ-ViT可作为nn.Linear的即插即用量化感知训练（QAT）替代方案，且不修改标准的实值注意力、归一化或激活计算图。在ImageNet-1K上，RPFQ-ViT-B/16在W2/A4下达到79.33% Top-1 / 94.48% Top-5，Swin-T在W2/A8下达到79.30% Top-1 / 94.79% Top-5，DeiT-S在W2/A8下达到77.41% Top-1 / 93.11% Top-5。消融实验、相位几何分析和方向保持指标表明，通道配对、可学习旋转、相位锚点学习和残差相位细化均能提升量化质量。我们进一步将RPFQ-ViT图像分类模型部署到原生iOS和Android运行时栈上；使用2位打包权重时，模型大小相对于FP32缩小约5.4–7.1倍，端到端设备端延迟降低1.4–1.6倍。我们在代码库中训练的所有ImageNet结果均采用匹配的300轮训练方案，并报告三次独立运行的平均精度。这些结果表明，RPFQ-ViT为极低位ViT在精度、压缩和实际移动部署之间提供了有利的权衡。

## Abstract
Vision Transformers (ViTs) achieve strong performance on image recognition and mobile vision applications, but their high-dimensional linear projections and attention computations still impose substantial storage and inference costs. Extremely low-bit quantization is a promising solution, yet ViTs often suffer severe accuracy degradation because conventional real-valued scalar codebooks are poorly matched to the directional geometry of Transformer projections. We present RPFQ-ViT, a Rotated Phase-Frame Quantization method that quantizes paired channels in two-dimensional phase planes, enabling low-bit codes to better preserve projection directions while recovering magnitude with lightweight scaling. RPFQ-ViT serves as a drop-in QAT replacement for nn.Linear and does not modify the standard real-valued attention, normalization, or activation computation graph. On ImageNet-1K, RPFQ-ViT-B/16 reaches 79.33% Top-1 / 94.48% Top-5 under W2/A4, Swin-T reaches 79.30% Top-1 / 94.79% Top-5 under W2/A8, and DeiT-S reaches 77.41% Top-1 / 93.11% Top-5 under W2/A8. Ablations, phase-geometry analysis, and direction-preservation metrics show that channel pairing, learnable rotation, phase-anchor learning, and residual phase refinement each improve quantization quality. We further deploy RPFQ-ViT image-classification models on native iOS and Android runtime stacks; with 2-bit packed weights, model size shrinks by roughly $5.4$-$7.1\times$ relative to FP32 and end-to-end on-device latency drops by $1.4$-$1.6\times$. All ImageNet results trained in our codebase use a matched 300-epoch recipe and are reported as mean accuracies over three independent runs. These results show that RPFQ-ViT provides a favorable trade-off among accuracy, compression, and practical mobile deployment for extremely low-bit ViTs.

# RPFQ-ViT 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：ViT、DeiT、Swin 等视觉 Transformer 在图像识别上表现优异，但高维线性投影与注意力计算导致存储与推理成本高，难以部署在资源受限设备上。
- **痛点**：极低位量化（尤其 2-bit 权重）在 ViT 上掉点严重。既有工作多把原因归结为注意力失真与 QAT 训练不稳定（如 Q-ViT 的 IRM/DGD、OFQ 的 StatsQ/CGA/QKR、Variation-aware 量化的振荡分析）。
- **本文视角（核心论点）**：问题不仅是标量近似误差，更是**几何失配**。传统二值/三值量化对每个标量独立处理，而 ViT 投影对**方向**高度敏感（注意力直接依赖 Q-K 内积）。一维码本在极低比特下会压缩掉关键的方向信息。
- **关键观察**：多数 ViT 线性层通道维度为偶数，可做**确定性对半配对**，把一对通道视为一个二维相位平面，从而用 2-bit 码本表示 4 个方向，而非实轴上的几个标量电平。
- **整体含义**：把极低位 ViT 权重量化重新表述为「**方向保持 + 轻量幅度恢复**」，提出面向 ViT 的相位帧量化器 RPFQ-ViT，兼顾精度、压缩率与移动端可部署性。

## 2. 方法论

### 2.1 核心思想
- 将偶数维 `nn.Linear`（din=2m, dout=2n）按**半分割配对**（第 j 与第 j+m 通道）重写为**精确等价的复算子**，在复平面中用可学习旋转相位帧量化，再精确映射回实值权重矩阵，保持原始计算图不变。

### 2.2 关键技术与流程

- **步骤 1：配对复数重参数化（精确、无损）**
  - 权重分块 `R = [[R11, R12],[R21, R22]]`，定义
    - `U = ½[(R11+R22) + i(R21−R12)]`
    - `W = ½[(R11−R22) + i(R12+R21)]`
  - 原实变换等价于 `yc = U·xc + W·x̄c`（x̄c 为共轭）；逆映射为
    - `R11 = Re(U+W)`，`R12 = Im(W−U)`，`R21 = Im(U+W)`，`R22 = Re(U−W)`
  - 对 `qkv` 融合投影使用同一确定性配对规则，避免分支特化启发式。

- **步骤 2：相位帧量化**
  - 固定相位帧基线码本 `Cφ = {±1, ±i}`（每个复权重 2-bit 方向）。
  - 提出**分组可学习旋转角 θg + 可学习相位锚点 Φ={φk}（默认 K=4）**：
    - 旋转坐标 `Z′g = Zg·e^{−iθg}`
    - 码字分配：`c(z) = argmax_{c∈{e^{iφk}}} Re( z·c* / (|z|+ε) )`
    - 固定帧即 θg=0、Φ={0, π/2, π, −π/2} 的特例。
  - **比特预算**：一个 2-bit 相位分配阶段 ≈ 每个原始实权重 1 bit；T 个残差阶段 → 有效 T bit。
  - **元数据开销**：每组共享旋转/锚点，存 (1+K+T) 个标量；默认 K=4、W2 时每组 **7 个标量**（θg、φ1..φ4、αg、βg），按 bmeta 位精度折算为 `(1+K+T)·bmeta / (2G)` bit/实权重。

- **步骤 3：最小二乘幅度拟合 + 残差相位细化**
  - 组内单尺度最小二乘：`αg = Σ Re(z·c*(z)) / (Σ |c(z)|² + ε)`
  - 残差细化（默认相位方向算子 `S_phase(r) = r/(|r|+ε)`；备选象限符号算子 `S_sign`）：
    - `Ẑg = [ αg·Cg + βg·S(Z′g − αg·Cg) ] · e^{iθg}`
  - 更高有效比特时递归应用同一残差量化。
  - QAT 保留全精度 master weight，前向用 Ẑ，梯度用 STE（直通估计器）。

- **步骤 4：落回标准推理**
  - 量化 U、W 后重构 `R̂`，用标准 `F.linear` 执行；注意力、LayerNorm、GELU、Softmax、残差连接、偏置与量化 scale 均保持高精度。

## 6. 主要结论与发现

- **极低位精度**（3 种子均值）：
  - ViT-B/16 W2/A4：**79.33% Top-1 / 94.48% Top-5**（同配方 FP32 参考 77.89%/93.39%；复现 Q-ViT 62.38%；LSQ++KD 75.10%）
  - DeiT-S W2/A8：**77.41% / 93.11%**（FP32 78.36%；Q-ViT 报告 72.10%；OFQ 75.72%）
  - Swin-T W2/A8：**79.30% / 94.79%**（FP32 81.20%；Q-ViT 74.70%；OFQ 78.52%）
  - 作者对 ViT-B/16 超 FP32 的现象采取保守解释，称其为「有利的正则化效应」，而非宣称 2-bit 普遍超越全精度。
- **消融结论**：仅换用固定相位帧即从 74.89% 提升到 76.56%（说明「表示本身」有效）；残差细化贡献最大（→78.74%）；预对齐帧 →78.79%；去锚点学习 →79.06%；完整模型 79.33%。
- **几何解释**：相对实值 LSQ W2/A4，完整模型权重 MSE 降至 0.49、角度误差降至 0.43、注意力分数 MSE 降至 0.46，特征余弦从 0.931 升至 0.983——精度排序与方向保持程度一致。
- **训练效率**：单阶段 QAT、无教师分支/蒸馏损失/多阶段微调，300-epoch 用时约为 Q-ViT 的 1/3.4。
- **移动部署**：2-bit 打包权重下，ViT-B/16 从 338.6 MB 降至 47.7 MB（7.1×），Swin-T 从 110.2 MB 降至 20.4 MB（5.4×）；中位端到端延迟加速 1.41×–1.58×；模型加载时间同步改善。
- **总体结论**：相位方向码本为极低位 ViT 投影提供了有效且部署友好的归纳偏置，是标量误差最小化之外的互补视角。
