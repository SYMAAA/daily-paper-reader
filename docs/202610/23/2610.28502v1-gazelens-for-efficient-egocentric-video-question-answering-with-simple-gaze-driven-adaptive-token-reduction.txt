# GAZE LENS FOR EFFICIENT EGOCENTRIC VIDEO 

# QUESTION ANSWERING WITH SIMPLE GAZE -D RIVEN 

# ADAPTIVE TOKEN REDUCTION 

Trong-Thang Pham, Anh Nguyen, Hien Van Nguyen, Ngan Le 

## ABSTRACT 

Smart glasses can help users understand their activities and surroundings, but small vision-language models must preserve useful evidence within limited computation. This is difficult because redundant frames consume the visual budget, while aggres-sive spatial compression can discard relevant details. Although gaze identifies the wearer’s focus, the question may require evidence from the surrounding scene. To address these constraints, we propose GazeLens, which combines frame selection with gaze- and question-guided token reduction. First, HOG transitions and image sharpness select frames before visual encoding. For each selected frame, Gaus-sian pooling then forms gaze-focused and complementary summaries. Because their relevance depends on the question, a lightweight gate blends them into a primary token. Together with a global scene token, this retains both focused and contextual summaries within two tokens per frame. On StreamGaze, GazeLens achieves higher macro and micro accuracy than the evaluated full-grid and token-reduction baselines, with lower input-forward FLOPs than the shared-backbone token-reduction baselines.

Reducing visual tokens addresses only part of this cost. FastV and PyramidDrop discard tokens inside the language model (Chen et al., 2024b; Xing et al., 2024), after visual encoding and some language-model computation have already occurred. LLaMA-VID compresses each encoded frame to two tokens (Li et al., 2024), but still encodes every sampled frame. LongVU reduces both temporal and spatial redundancy (Shen et al., 2024), using DINOv2 features computed before frame removal. These choices save downstream computation while retaining the cost of extracting the features used for reduction. This motivates selecting frames before learned visual encoding when inexpensive image statistics can identify redundancy. Deciding what to preserve within a frame introduces a second difficulty. Gaze provides a spatial prior for the wearer’s focus (Li et al., 2021; Zhang et al., 2017; Lai et al., 2024). However, a question about a fixated object and a question about the surrounding scene require different evidence. A compact representation must therefore preserve both local and contextual information, with a balance that depends on the question. Table 1 compares how reduction mechanisms address these requirements. LLaMA-VID conditions aggregation on the question without a gaze prior. GazeLLM crops around gaze (Rekimoto, 2025), removing off-gaze evidence. GazeVLM preserves global and local image views, then selects gaze-near and surrounding tokens with a preset allocation (Yoon et al., 2025). However, this allocation does not depend on the question. Voila-A retains gaze-conditioned features through a learned Perceiver (Yan et al., 2024), adding attention operations after encoding without reducing encoder inputs. These distinctions motivate combining frame selection before encoding with question-conditioned spatial compression that preserves scene context. GazeLens implements these choices through three modules (Figure 1). To avoid encoding redundant or blurred candidates, Dynamic Frame Selection uses HOG transitions and Laplacian sharpness to select frames without learned parameters. To keep evidence beyond the fixation available, Focus-Aware Gaze Aggregation forms soft gaze-focused and complementary summaries. Question-Conditioned Semantic Gating then controls their mixture according to the question. This mixture forms the primary token, while a second, global token retains a scene summary regardless of the gate. Together, the modules reduce how many frames are encoded and control which information survives within two tokens per selected frame. We make three contributions. • A parameter-free frame selector reduces encoder inputs using HOG transitions and image sharpness. • Gaze- and question-conditioned pooling preserves focused, complementary, and global summaries within two visual tokens per selected frame. • Our 500M configuration improves StreamGaze Macro and Micro accuracy over the evaluated baselines while reducing model-forward FLOPs. Gaze-guided VLMs. GazeLLM uses gaze-centered cropping (Rekimoto, 2025), while Voila-A learns gaze-conditioned visual representations (Yan et al., 2024). GazeVLM combines global/local image preprocessing with gaze-guided token selection after encoding (Yoon et al., 2025). It preserves surrounding evidence through sampled context tokens, but its image-based reduction does not select video frames or condition token allocation on the question. GazeLens instead selects frames before encoding and blends focused and complementary features according to the question within two tokens per frame. StreamGaze (Lee et al., 2025) evaluates this balance through Past, Present, and Proactive questions. 

Token reduction and frame selection. FastV and PyramidDrop prune visual tokens within the language model (Chen et al., 2024b; Xing et al., 2024), whereas LLaMA-VID produces a compact representation before language-model input (Li et al., 2024). For video, LongVU and FrameFusion also exploit temporal redundancy in visual features (Shen et al., 2024; Fu et al., 2024). Frame-Voyager and M-LLM Frame Selector learn to choose frames using question relevance and model-derived supervision (Yu et al., 2024; Hu et al., 2025). Across these approaches, the stage of reduction determines which computation can be avoided. We therefore place frame selection before learned encoding and use gaze to allocate the retained spatial-token budget. 

Streaming MLLMs. VideoLLM-online, ViSpeak, Dispider, Flash-VStream, and LiveVLM address interaction with arriving video (Chen et al., 2024a; Fu et al., 2025; Qian et al., 2025; Zhang et al., 2024; Ning et al., 2025), with StreamingBench evaluating streaming comprehension (Lin et al., 2024). Our study concerns the visual input budget for each QA example. Here, frame selection controls the amount of encoded video, and gaze-conditioned pooling controls its spatial representation. Selected frames are encoded independently. 

## 3 METHOD 

Each module in Figure 2 is motivated by a distinct failure mode of prior work. Uniform temporal sampling wastes the token budget on redundant or blurry frames before they ever reach the encoder, so Section 3.1 filters the candidate pool first. Hard gaze crops are brittle to sensor noise and silently drop peripheral context, so Section 3.2 instead builds complementary soft focus and unfocus tokens via Gaussian pooling. Because the right balance between gaze focus and peripheral evidence varies with the question, Section 3.3 introduces a scalar gate conditioned on question semantics to blend these tokens per sample. Section 3.4 details the final token assembly and training objective. 3.1 DYNAMIC FRAME SELECTION 

A fixed frame count imposes a single global trade-off. Too few frames miss rare action moments, and too many inflate the LM-side token budget with redundant content. We instead use a variable count tmin ≤T ≤tmax , spending the budget only on frames where visual content actually changes. This flexibility favors frames that are both visually distinct from their neighbors and free of motion blur. We operationalize these two criteria with HOG transition cues and Laplacian sharpness scores, which are parameter-free, fast to compute, and require no training data.

## 4 EXPERIMENTS 

We first compare StreamGaze accuracy and model-forward computation, then assess transfer to EgoGazeVQA. Finally, component interventions examine sensitivity to frame selection and spatial pooling. Appendix D.1 reports gaze-noise controls. 4.1 IMPLEMENTATION 

Datasets & Metrics. We evaluate our method on StreamGaze (Lee et al., 2025), an egocentric video QA benchmark that we evaluate as three tasks, Past, Present, and Proactive, covering ten subtasks drawn from EGTEA Gaze+ (Li et al., 2021), EgoExo (Grauman et al., 2024), and HoloAssist (Wang et al., 2023). Following the official partition, we train on 5,766 QA pairs and report final results on the held-out test split of 1,399 questions, yielding 2,418 evaluation examples after expanding proactive questions into timestamped probes. We adopt macro accuracy and micro accuracy as the primary evaluation metrics. Each task score averages its constituent subtask accuracies, and Macro is the equal-weight mean of the Past, Present, and Proactive scores. Micro is accuracy pooled over all test examples. To quantify model computation, we report TFLOPs per input forward under the controlled protocol in Appendix E.2. 

Baselines & Models. We compare our method against two groups of baselines. The first group con-sists of small VLMs evaluated without token reduction or gaze tuning, including SmolVLM2-256M and SmolVLM2-500M (Marafioti et al., 2025) (our 256M and 500M backbones), FastVLM (Vasu et al., 2025), and Mobile-VideoGPT (Shaker et al., 2025). These represent the accuracy achievable with full token grids and standard inference pipelines, none of which were evaluated in the original StreamGaze report. The second group consists of token-reduction methods re-implemented on the SmolVLM2-500M framework for a controlled comparison of visual token budget and accuracy on identical hardware, namely GazeLLM (Rekimoto, 2025), LLaMA-VID (Li et al., 2024), and Voila-A (Yan et al., 2024). We use SmolVLM2-500M as the shared backbone to control for model capacity. We select these three because they each reduce visual tokens through distinct mechanisms. GazeLLM crops each frame to a fixed patch centered on the raw gaze point, discarding all peripheral context. LLaMA-VID produces two tokens per frame by combining one global mean over the feature grid with one context token formed by text-attended averaging over the full feature grid without any gaze prior. Table 2 compares accuracy, total parameters, and counted input-forward computation. Across three seeds, our 256M configuration achieves 50 .9% Macro and 61 .66 ± 0.50% Micro. With the larger backbone, our 500M configuration achieves 53 .94 ± 1.54% macro and 64 .01 ± 0.49% micro accuracy (mean ± sample standard deviation). At the same time, Ours-500M uses 3.055 TFLOPs per input, compared with 3.791 for GazeLLM, 3.804 for LLaMA-VID, and 4.758 for Voila-A under the shared-backbone protocol. The methods differ in how they allocate the compact visual budget. Soft Gaussian pooling retains peripheral evidence that GazeLLM’s crop discards, while the gate controls its contribution to the primary token. LLaMA-VID also uses two tokens per frame, but obtains its context token through text-conditioned attention over the full grid. GazeLens adds the wearer’s gaze as a spatial prior and preserves a global summary alongside it. However, Voila-A achieves slightly higher Proactive accuracy than Ours-500M (0.650 vs. 0.645), with its advantage concentrated in gaze-triggered alerts, whereas ours performs better on object-appearance alerts. This advantage comes with higher counted input-forward computation of 4.758 versus 3.055 TFLOPs per input, about 56% more under the RTX 3080 profiling protocol (Figure 3). Voila-A processes 16 frames with a gaze-conditioned Perceiver, whereas ours averages 12.72 selected frames and uses two visual tokens per frame. The Perceiver may retain spatial cues useful for alert triggering. Temporal sampling and spatial representation both differ between these methods. ## 5 CONCLUSION 

In this paper, we proposed GazeLens for compact egocentric video question answering. First, adaptive frame selection uses HOG transitions and image sharpness to reduce temporal redundancy before visual encoding. Next, gaze-focused and complementary pooling preserve evidence within and beyond fixation, while a question-conditioned gate adjusts their contribution. A global summary then retains scene context alongside the primary token, yielding two visual tokens per selected frame. Together, these modules address the need to preserve relevant evidence within a limited visual budget. Our method trains 1.75M parameters on the 256M backbone and 3.88M on the 500M backbone, including LoRA. Gaussian pooling and the frozen question embedding introduce no new parameters. We count input-forward computation at batch size one on an NVIDIA RTX 3080, using synthetic frames and a fixed question-and-options prompt. SmolVLM2 and FastVLM use bfloat16, whereas Mobile-VideoGPT uses float16. ## F LIMITATIONS AND FUTURE WORK 

GazeLens targets devices with gaze sensors. When coordinates are missing, pooling becomes approximately uniform and loses the spatial prior that distinguishes attended content. A useful next step is to estimate gaze confidence and adapt the pooling rule when tracking is unreliable, so that uncertain fixation measurements do not determine the spatial representation. Temporal selection uses HOG transitions and image sharpness without conditioning on the question. Consequently, these cues can suppress visually repetitive frames that still contain relevant evidence. Future work could incorporate question relevance into selection while keeping its cost below that of encoding discarded frames. Selected frames are currently encoded independently, so reusing visual tokens across unchanged regions is another route to reducing repeated computation during longer interactions. Such extensions should be evaluated with end-to-end latency and memory measurements, since the reported model-forward FLOPs exclude frame selection, decoding, and preprocessing. Finally, two tokens per frame provide a compact input but can discard spatial detail needed for fine-grained reasoning. The spatial-budget comparisons motivate adapting token capacity to the question and scene complexity. Increasing capacity only when the task needs finer evidence could extend the present accuracy–computation trade-off, while retaining a compact representation for simpler inputs. 17
