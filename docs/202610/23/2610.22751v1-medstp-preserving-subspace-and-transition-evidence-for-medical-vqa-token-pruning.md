## 摘要
用于视觉问答（VQA）的医学视觉语言模型（VLM）通常会将较长的视觉令牌序列传入语言模型，这使得视觉令牌剪枝颇具吸引力，但对医学图像而言存在风险，因为答案可能依赖于局部的边界和纹理证据。我们研究免训练的解码前剪枝，并将剪枝视为一个子空间稳定证据保留问题。保留下来的令牌应当尽可能接近由完整令牌集所诱导的主导视觉证据子空间。为此，我们提出子空间-转移令牌剪枝（Subspace-Transition Token Pruning，MedSTP），它从主成分空间中估计每个令牌的谱支持，并构建紧凑的表示子空间。为了更好地反映医学图像结构，MedSTP还使用有界令牌网格转移先验来促进对边界和纹理敏感的令牌。我们在封闭式SLAKE和OmniMedVQA基准，以及同时提供封闭式和开放式评估的RadImageNet-VQA上，使用Lingshu-7B和Qwen3-VL-8B骨干模型评估MedSTP。MedSTP在RadImageNet-VQA的封闭式和开放式评估中均持续取得强劲性能。这些结果表明，MedSTP是面向医学领域VQA的有效免训练剪枝框架。

## Abstract
Medical vision-language models (VLMs) for visual question answering (VQA) often pass long visual-token sequences to the language model, making visual-token pruning attractive but risky for medical images, where answers may depend on localized boundary and texture evidence. We study training free pre-decoding pruning and treat pruning as a subspace stable evidence preservation problem. The retained tokens should remain close to the dominant visual evidence subspace induced by the full token set. To this end, we propose \emph{Subspace-Transition Token Pruning} (\method{}), which estimates each token's spectral support from principal component space and constructs a compact representation subspace. To better reflect medical image structure, \method{} further uses a bounded token-grid transition prior to promote boundary and texture sensitive tokens. We evaluate \method{} on the closed-ended SLAKE and OmniMedVQA benchmarks and on RadImageNet-VQA, which provides both closed-ended and open-ended evaluations, using Lingshu-7B and Qwen3-VL-8B backbones. \method{} delivers consistently strong performance on both the closed-ended and open-ended RadImageNet-VQA evaluations. These results show that \method{} is an effective training free pruning framework for medical domain VQA.

## 1. 核心问题与研究动机

- **背景压力**：医学视觉问答（VQA）中的视觉语言模型（VLM）会把很长的视觉 token 序列送入语言模型，推理成本主要由视觉 token 预算而非问题文本决定（如 Qwen3-VL 等骨干）。
- **剪枝的两难**：视觉 token 剪枝是自然的压缩手段，但医学图像中答案往往依赖**局部边界、纹理与细微过渡证据**，而非仅仅主导解剖结构；通用显著性/冗余度打分容易保留“大面积解剖”而丢弃低分但关键的病灶边缘 token（Fig. 1 定性示例）。
- **设定约束**：作者聚焦**免训练、解码前（pre-decoding）、固定预算**的 token 选择——不允许稠密掩码监督、任务特定重训练，也不允许对候选子集反复解码试探。
- **核心问题重述**：真正的问题在于“固定预算的选择器应把什么视为证据”，并非“要不要剪枝”。作者将其形式化为**子空间稳定证据保持**问题：保留子集应尽量贴近完整 token 集所诱导的主导视觉证据子空间。

## 2. 方法论

### 2.1 整体框架
MedSTP（Subspace-Transition Token Pruning）由两部分耦合而成：
1. **子空间稳定子集构建**：基于 token 侧 PCA 的谱支持，逐步贪心选择“能带来最多未表示信息”的 token；
2. **有界局部转移先验**：用 Sobel 式 token 网格过渡分数作为**有界乘子**，在 token 已具备谱支持的前提下提升边界/纹理 token 的排序。

### 2.2 问题形式化
- 全 token 解码分布 $p_{\text{full}}(a\mid x,q)=p_\theta(a\mid q,H)$，剪枝后 $p_S(a\mid x,q)=p_\theta(a\mid q,H_S)$，$|S|=K$。
- 理想目标是最小化 KL 散度：$S^\star=\arg\min_{|S|=K} D_{\mathrm{KL}}(p_{\text{full}}\|p_S)$；但该目标需反复解码，不可直接优化，故转为**表示层代理目标**。

### 2.3 子空间保持视角与理论支撑
- 定义全 token 加权二阶矩 $\Sigma$ 与保留子集受限二阶矩 $\Sigma_S$，残差 $R_S=\Sigma_S-\Sigma$；代理目标为 $\min_S \|R_S\|_2$。
- **命题 1（子空间分支扰动界）**：若 $\|R_S\|_2<\delta_r/2$（$\delta_r$ 为特征间隙），则
 $\|\sin\Theta(U_r,U_{S,r})\|_2 \le 2\|R_S\|_2/\delta_r$。
 证明思路为 Weyl 不等式 + Davis–Kahan sin θ 定理。
- 作者明确声明：该界只是**设计动机**，不证明离散选择器最小化该目标，也不保证答案正确性。

### 2.4 谱支持估计（子空间构建）
- 对 token 矩阵 $H\in\mathbb{R}^{N\times d}$ 先做逐元素 sigmoid，得 $X=\sigma(H)^\top\in\mathbb{R}^{d\times N}$；对 $X$ 做 PCA，取前 $C$ 个主方向，得投影矩阵 $V\in\mathbb{R}^{N\times C}$ 与奇异值 $s$。
- token 在子空间中的表示 $z_i=\mathrm{diag}(s)V_{i,:}^\top\in\mathbb{R}^C$，谱证据量 $\alpha_i=\|z_i\|_2^2$（作为抽象证据权重的可实现代理）。
- **分组**：$g_i=\arg\max_c |V_{ic}|$，每个非空组先分 1 个 token，剩余 $K-G$ 个名额按组规模 $n_g$ 分配（累积取整 + 确定性调整，保证 $\sum_g K_g=K$）。
- **逐步贪心**：以当前保留子空间投影 $P_{U_g^{(t)}}$ 计算“子空间外分量”
 $I^{\text{spec},(t)}_i=\|(I_C-P_{U_g^{(t)}})z_i\|_2^2$，
 每步选该值最大的 token 并更新子空间，直至该组满额 $K_g$。

### 2.5 有界转移先验
- 将 token 重排为空间网格 $H\in\mathbb{R}^{H_g\times W_g\times d}$，通道级施加固定 Sobel 核 $S_x,S_y$，得 $G_x=S_x*H$、$G_y=S_y*H$。
- 转移幅值 $T_i=\sqrt{\|G_x(i)\|_2^2+\|G_y(i)\|_2^2+\epsilon}$，归一化为 $E_i\in[0,1]$。
- **有界乘子**：$I_i^{(\beta,t)}=(1+\beta E_i)\,I^{\text{spec},(t)}_i,\ \beta\ge 0$；选择准则变为组内 $\arg\max$ 该加权分数。
- 关键设计：乘子有界（默认 $\beta=0.2$，最优区间 0.1–0.3），防止转移项**压倒**谱信号；转移项不能“无中生有”地救回谱贡献为零的 token。

## 6. 主要结论与发现

- **整体最优**：三个数据集 × 两个骨干上，MedSTP 均为所比较方法中平均性能最强。
 - OmniMedVQA：Lingshu 70.83%（较最强基线 PruneSID 67.26% 提升 3.57）；Qwen 58.82%（较 BTP 55.93% 提升 2.89）。
 - SLAKE：76.78%（较 PruneSID 74.31% 提升 1.55）；78.45%（较 VisPruner 76.78% 提升 1.67）。
 - RadImageNet-VQA：Lingshu 闭集 82.50%（+3.50）、开集评审均值 63.60%（+5.20）；Qwen 闭集 87.90%（+1.60）、开集 72.05%（+1.25）。
- **KL 最低**：各表中介 MedSTP 的 KL 均为最小（如 SLAKE-Lingshu 0.169 vs 全 token 0），说明保留子集在答案分布上更接近全 token 模型。
- **子空间诊断支持动机**：在多数剪枝率下 MedSTP 的保留 token 特征空间漂移更小，且在“漂移–精度”平面上更靠近低漂移高精度角。
- **剪枝率曲线**：温和剪枝下各法接近全 token；激进剪枝下差距拉开，MedSTP 退化更平缓，OmniMedVQA 上优势出现更早（更依赖局部解剖/组织证据）。
- **转移先验有效但有选择性**：SLAKE 主要在 OT 组增益，OmniMedVQA 主要在 RJ、LC 组增益；KL 变化不大，故作者将其解读为**答案层面的重排序收益**而非整体分布匹配收益。
- **$\beta$ 需适度**：$\beta=0.1$–$0.3$ 最佳，过大反而掉点，印证“有界修正”的设计。

## 8. 局限性与潜在问题

- **代理目标与真实目标的鸿沟**：方法优化的是 token 特征子空间保持（表示层代理），而真正关心的是答案分布 KL。文中未给出“子空间漂移 ↓ ⇒ KL ↓ ⇒ 精度 ↑”的定量因果链，二者仅在趋势上相关；命题 1 亦被作者自己限定为动机性结果。
- **PCA 子空间的语义解释性有限**：谱支持 $\alpha_i=\|z_i\|_2^2$ 度量的是“在主方向上的能量参与度”，对医学图像中低对比度、小面积但决定性的病灶边缘是否稳定敏感，缺乏针对性验证（如按病灶大小/对比度分层分析）。
- **分组机制的刚性**：以 $\arg\max_c|V_{ic}|$ 硬分配组、再按组规模分配名额，可能使跨组边界的过渡证据被系统性低估；组数 $G$ 与主成分数 $C$ 的选择依据未充分讨论，缺少对 $C$、$G$ 的敏感性分析。
- **Sobel 先验的空间假设较强**：要求 token 排成规则网格且相邻性有意义，对非均匀 patch、变分辨率输入或多尺度特征融合的骨干可能需要重新设计；仅用一阶梯度，对细线状结构（如血管、骨折线）的方向性证据刻画有限。
- **评测覆盖仍偏窄**：三个数据集均为相对小规模、以 2D CT/MRI 与多选题为主，缺少 3D 体积数据、报告生成式任务、以及真实临床长尾病种的检验；“开集”仅指答案自由文本，仍由 LLM 按 rubric 打分。
- **统计严谨性不足**：未报告随机种子数、多次运行的均值±标准差，也未做显著性检验；bootstrap 标准误只反映评测采样不确定性，不覆盖方法本身的随机性（尽管方法确定性较强）。
- **效率收益的适用面**：端到端仅 1.07×，说明瓶颈可能转移到视觉编码器或解码阶段；论文未分析在更长答案、更大 batch、不同硬件上的收益缩放规律。

## 9. 可延伸的改进方向

- 将子空间目标从“特征二阶矩保持”推进到**轻量的输出敏感代理**（如用最后一层 logits 的少量探针样本估计敏感性），缩小代理与 KL 的差距。
- 用**软分组或重叠子空间**替代硬分组，缓解跨组边界证据丢失；并对 $C$、$G$、$\beta$ 做联合敏感性网格。
- 引入**多尺度/二阶过渡算子**（如 Hessian、方向可分离滤波）以更好刻画细线状与低对比度边界，同时保持乘子的有界约束。
- 在 3D 与生成式医学任务上验证，并补充病灶分层（大小、对比度、边界清晰度）的细粒度分析，直接检验“边界 token 关键”这一核心假设。

## 10. 总体评价

MedSTP 是一篇**动机清晰、机制克制、工程可落地**的医学 VLM token 剪枝工作。其最大贡献不在于刷新精度，而在于把“固定预算下选什么 token”重构为**子空间稳定证据保持**问题，并用“全局谱支持 + 有界局部转移先验”的耦合设计给出一个自洽且可解释的解法；有界乘子这一约束既是设计亮点，也被消融与 $\beta$ 敏感性实验所支持。实验协议规范（统一插入点/预算、双骨干、双盲开集评审、KL 辅助指标、分组细项披露），对不利结果的呈现也较为诚实。

同时，其理论部分属于**动机性而非保证性**，代理目标与最终答案分布之间缺少定量桥梁；评测集中在中小规模 2D 多模态 QA，统计严谨性与超参选择（$\beta$ 在评测集上选定）仍有改进空间。总体而言，作为一篇面向临床部署约束的免训练剪枝方法论文，其问题提炼与设计取舍具有较好的参考价值，结论应被理解为“在该评测范围内稳定有效”，而非普适性保证。
