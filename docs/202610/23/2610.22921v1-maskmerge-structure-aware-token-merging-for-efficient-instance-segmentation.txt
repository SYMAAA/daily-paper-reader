## Abstract 

Token merging improves the efficiency of Vision Transform-ers by combining redundant tokens, but existing methods largely rely on feature similarity to determine which tokens to merge. This criterion is effective for semantic segmenta-tion, yet can fail in instance segmentation, where adjacent objects of the same class often have highly similar features. We identify this failure mode as cross-instance token fu-sion . We introduce MaskMerge , an instance-aware token merging method that uses coarse intermediate mask predic-tions to constrain feature-based merging and preserve in-stance boundaries. We evaluate MaskMerge on two diverse instance segmentation domains characterized by high inter-instance visual similarity: PanNuke and iSAID. Against the SOTA token merging method ALGM, MaskMerge improves mAP from 30.1 to 32.1 on PanNuke while reducing compu-tation from 229 to 153 GFLOPs and running 1.18 × faster, and from 33.1 to 36.2 on iSAID while reducing computation from 198 to 182 GFLOPs and running 1.23 × faster. Addi-tionally, we also test it on Cityscapes and match ALGM’s performance while using fewer FLOPs. The gains also transfer to an MAE-pretrained backbone, demonstrating that instance-aware merging enables more aggressive com-pression when appearance similarity alone cannot reliably preserve object identity.

Token merging instead combines redundant tokens while maintaining a correspon-dence to the original spatial support, making it particularly attractive for segmentation [1, 24, 38, 43, 46]. Methods such as ToMe [1] and ALGM [43] have demonstrated that substantial computation can be removed with little or even no degradation on semantic segmentation. A central assumption underlying most existing token merging methods is that feature similarity is a reliable proxy for merge compatibility [1, 42, 43]. Tokens with high cosine similarity are treated as redundant and are therefore natural candidates for aggregation. For semantic segmentation, this assumption is often well aligned with the task: neighbor-ing regions representing the same semantic category should receive the same prediction, and merging similar features within such regions is generally benign. The same assumption becomes considerably less reli-able for instance segmentation specifically for homoge-neous data. Here, the model must not only recognize what is present, but also preserve which object each spa-tial location belongs to [31]. Adjacent instances of the same category can have extremely similar visual represen-tations despite requiring different output masks. Two neigh-boring nuclei in a histopathology image [17] or vehicles parked side-by-side in an aerial image [62] may therefore be highly similar in feature space while belonging to differ-ent instances. A similarity-only merge criterion may con-sequently aggregate tokens across instance boundaries, as shown in Fig. 2a, a failure mode we term cross-instance to-ken fusion . Fig. 2b quantifies this effect: at the same merge budget, MaskMerge reduces cross-instace merges by 5.7×

and 2.9× on PanNuke and iSAID respectively in compari-son to ALGM [43]. This shows that feature similarity alone is insufficient to determine whether two tokens are safe to merge for an instance-level task, motivating the use of pre-dicted instance structure to enable both safer and more ag-gressive token reduction. Further, cross-instance token fusion affects not only ac-curacy, but also the attainable efficiency. Increasing the merge rate of a similarity-based method eventually intro-duces more erroneous cross-instance merges, forcing it to retain additional tokens to preserve segmentation quality. A safer merge criterion can instead support more aggressive compression without destroying instance boundaries. Thus, instance awareness offers a dual benefit: it preserves object identity while enabling greater inference throughput. These insights motivate MaskMerge , an instance-aware token merging framework that incorporates predicted mask structure directly into the merge decision. Modern query-based segmentation models [8, 9, 21] progressively form object-specific representations throughout the network. MaskMerge exploits this intermediate structure rather than introducing an independent grouping mechanism. At an early stage of the encoder, a lightweight mask prediction op-eration combines the current object queries with the visual tokens to obtain coarse instance masks. These masks pro-vide an inexpensive estimate of the instance assignment of each token. During subsequent token merging, MaskMerge restricts candidate matches to tokens assigned to the same predicted mask before selecting merges according to feature similarity. The resulting operation retains the efficiency and simplicity of similarity-based token merging while substan-tially reducing opportunities for cross-instance fusion. We evaluate this distinction in two complementary domains where visually homogeneous instances make appearance-only merging particularly challenging: Pan-Nuke [17] for nuclei instance segmentation and iSAID 

[62] for aerial instance segmentation. Across these do-mains, the instance constraint enables MaskMerge to op-erate at substantially more aggressive compression levels without incurring the degradation observed with similarity-only merging. On PanNuke, MaskMerge reaches 32.1 mAP , compared with 30.1 mAP for ALGM [43], while re-ducing computation from 229 to 153 GFLOPs and increas-ing throughput from 121.5 to 142.8 images/s. On iSAID, it improves mAP from 33.1 to 36.2 , while reducing compu-tation from 198 to 182 GFLOPs and increasing throughput from 168.8 to 206.9 tiles/s. Additionally, to test MaskMerge on real-world data, we ran ALGM and Maskmerge on Cityscapes, both methods achieve 19.8 AP, but MaskMerge requires only 298 GFLOPs compared with 347 GFLOPs. MaskMerge outperforms ALGM [1] and ToMe [1] across different backbone scales on PanNuke as shown in Fig. 1, demonstrating a better accuracy-throughput tradeoff than cosine methods. Moreover, the benefit is not tied to a sin-gle initialization: replacing the standard backbone with an MAE-pretrained variant on PanNuke preserves the advan-tage, with MaskMerge obtaining 34.0 mAP compared with 32.0 mAP for Compact ALGM. Together, these results suggest a broader principle for efficient instance-level recognition: visual redundancy and task-level redundancy are not equivalent . Two tokens may be nearly indistinguishable in appearance yet encode dif-ferent information for an instance segmentation objective. Efficient token reduction should therefore consider not only 

how similar two representations are, but also whether the task permits them to share a representation . MaskMerge provides a lightweight realization of this principle by us-ing the model’s emerging instance structure to guide token aggregation. ## 2. Related Works 

2.1. ViTs for Instance Segmentation 

Vision Transformers (ViTs) are well suited to instance seg-mentation because self-attention captures global object con-text, while hierarchical or multi-scale features preserve the spatial detail needed for precise mask prediction [15, 27, 53]. Query-based approaches such as DETR represent ob-jects as a set of learned queries, enabling separate predic-tions for multiple instances of the same category without handcrafted proposal generation [4, 34, 36, 65]. Building on this, MaskFormer reframed segmentation as mask classi-fication, providing a unified formulation that supports mul-tiple segmentation tasks [8]. Mask2Former extended this paradigm with masked attention, improving both accuracy and scalability for universal image segmentation [9]. More recently, EoMT showed that generic ViT backbones can act as strong universal segmentation models when equipped with suitable token-to-mask prediction heads, highlighting the potential of model-agnostic ViT architectures for unified segmentation [21]. Our work follows this line by enhanc-ing efficiency within ViT-based segmentation frameworks while preserving instance structure. 

2.1.1. Token reduction in general. 

In image classification and related settings, token reduc-tion is mainly achieved by pruning, merging, or hybrid strategies. Pruning methods remove uninformative to-kens using auxiliary predictors or attention-derived saliency scores, and are often optimized to preserve top-layer se-mantics under reduced token budgets [16, 23, 30, 40, 45, 52, 59–61, 64]. Beyond token dropping, efficiency is also improved through compressed token representations and quantization-aware formulations [28, 35, 41, 44, 56], as well as through alternative attention mechanisms such as linearized kernels and local-window computation [7, 20, 34, 39, 54]. Merging approaches reduce sequence length by com-bining redundant tokens either with learned mappings [5, 46, 47, 66] or with similarity-driven matching rules [1– 3, 6, 18, 19, 24, 30, 37, 48, 51, 55]. In practice, these methods differ in when reduction is applied (early vs. layer-wise), whether token identities remain recoverable, and how much extra routing computation is introduced. Hy-brid methods explicitly combine pruning, merging, and/or token fusing to improve the speed–accuracy frontier [2, 3, 6, 37, 57]. Despite strong gains, many approaches still rely on learned token-selection policies or threshold sched-ulers, which can increase optimization complexity, reduce hardware-friendliness, and limit end-to-end training-time 3acceleration [11, 14, 40, 60]. 

2.1.2. Token reduction for semantic segmentation. 

Applying token reduction to semantic segmentation is more constrained because dense prediction requires reconstruct-ing per-location outputs while preserving object boundaries and fine structures. Classification-oriented methods can be adapted by tracking assignment maps and remapping merged tokens to original positions [1, 5, 18, 30, 37], but direct transfer is often brittle and can degrade mIoU, espe-cially around thin regions and small objects [29]. This cre-ates a stronger requirement for spatially faithful reduction mechanisms than in global classification. Task-specific segmentation approaches therefore empha-size recoverability. Token pausing/halting methods skip up-dates for confident regions and restore them later [13, 33, 50], improving efficiency but reducing cross-region inter-action once tokens are paused. Clustering-based methods such as ELViT and AiluRus merge neighboring redundant tokens while maintaining dense outputs [25, 29]; however, practical gains are constrained by clustering overhead, one-shot grouping, and limited adaptability to scene-level global redundancy. CTS introduces a CNN policy for token shar-ing before the transformer [38], which improves locality-aware reduction but adds model complexity. ALGM [43] improves upon previous token merging methods by adding a local module and a global merging module inspired by ToMe [1]. While these methods have been great for se-mantic segmentation, they have not been evaluated for in-stance segmentation. Additionally, prior work focuses on using feature cosine similarity as the metric to merge to-kens. However, for instance-level tasks, this leads to many erroneous merges which deterioirates their performance in instance segmentation. Hence, we incorporate an addi-tional object-level mask constraint to mitigate these erro-neous merges and improve performance on these tasks. 

## 3. Methodology 

In this section, we introduce MaskMerge, our mask-based adaptive token merging framework for efficient universal image segmentation. Our approach leverages object-level mask proposals as proxies to define our token merging met-ric, enabling the model to perform segmentation and token refinement jointly within a unified transformer architecture. We first revisit the standard patch-based tokenization used in Vision Transformers [15] (Sec. 3.1). We then present our mask-based token merging module in Sec. 3.2. The overall architecture is illustrated in Fig. 3. 

3.1. Vision Transformers with Patch-based Tok-enization 

Vision Transformers (ViTs) represent an image I ∈

R3×H×W as a sequence of tokens obtained from fixed-size patches. Specifically, the image is partitioned into 

N = HW p2 non-overlapping patches of size p×p. Each patch is flattened and projected through a linear embedding layer to produce a token representation of dimension D. This yields the initial token sequence 

X0 = {x1, . . . , xN } ∈ RD×N ,

where xi ∈ RD denotes the embedding of the i-th patch. The tokens are processed through a stack of L Trans-former blocks. Each block consists of a Multi-Head Self-Attention (MHSA) module followed by a two-layer feed-forward network (MLP), both preceded by Layer Normal-ization. The update rule at layer i is given by 

Zi = Xi + MHSA(Norm( Xi)) ,

Xi+1 = Zi + MLP(Norm( Zi)) . (1) After the final layer, the token sequence XL can be re-shaped into a spatial feature map FViT ∈ RD× Hp × Wp .

While patch-based tokenization provides a structured representation, it lacks spatial adaptivity. All image regions contribute an equal number of tokens regardless of their se-mantic complexity. Consequently, simple regions incur re-dundant computation while complex object boundaries re-main under-represented. To address this limitation, we in-troduce an adaptive token merging mechanism that dynami-cally merges tokens while preserving object-level structure. 

3.2. Mask-based Token Merging 

To introduce spatial adaptivity and reduce redundancy, we progressively transform fixed patch tokens into content-aware tokens through a two-stage merging strategy: (i) local token merging to remove redundancy within small spatial neighborhoods, and (ii) object-level adaptive merging that consolidates tokens belonging to the same instance.

## 4. Experiments 

We evaluate MaskMerge on three questions: (1) does instance-aware merging improve the accuracy–efficiency trade-off over similarity-based merging across domains with high inter-instance similarity? (2) does the benefit gen-eralize across backbone pre-training strategies? and (3) can the same principle be applied to a segmentation architecture in which mask prediction is decoupled from the backbone? 

4.1. Experimental Setup 

Datasets. We evaluate on three instance segmentation datasets spanning substantially different visual domains. 

PanNuke [17] contains nuclei from histopathology images across five classes; we train on folds 1–2 and evaluate on fold 3. iSAID [62] contains 15 categories in high-resolution aerial imagery and includes many small, visually similar ob-ject instances; we use 512 × 512 tiles. Additionally, to test it on real-world data, we use Cityscapes [12]. It contains eight instance categories in urban driving scenes, where vi-sually similar vehicles and pedestrians frequently occur in close proximity. We evaluate on the 500-image validation set using 512 × 1024 sliding-window crops. 

Model and training. Our primary experiments use EoMT with a DINOv2 ViT-B backbone. Following ALGM, we apply local merging in the first encoder block and perform instance-aware merging at layer 5. For the PanNuke ViT-S and ViT-L experiment, we applied global merge at layers 5 and 8 respectively. We initialize from the trained model and fine-tune with token merging enabled for 15 epochs to make sure that the mask queries are adapted to the intermediate representations. We compare against ToMe [1] and ALGM [43] as feature-similarity-based token merging baselines. We ad-ditionally evaluate an MAE-pretrained ViT-B backbone to study sensitivity to backbone pre-training, and apply MaskMerge to Mask2Former with a DINOv2 ViT-B back-bone to examine whether instance-aware merging transfers beyond EoMT. 

Metrics. We report instance segmentation mean aver-age precision (mAP), end-to-end throughput, and GFLOPs. Throughput and FLOPs are measured with batch size 4 us-ing FP16 forward inference. Throughput is reported in im-ages/s for PanNuke and tiles/s for Cityscapes and iSAID.

4.3. Generalization Across Backbone Pre-training 

We next test whether the benefit of MaskMerge depends on the DINOv2 representation. We replace it with an MAE-pretrained ViT-B backbone and repeat the PanNuke experi-ment. MaskMerge improves overall mAP from 32.0 to 34.0 and small-instance performance from 31.5 to 33.4 as shown in Tab. 2. The advantage therefore persists under a substan-tially different self-supervised pre-training strategy, sug-gesting that the improvement is not specific to the DINOv2 feature representation. 

4.4. Extension to Mask2Former 

EoMT exposes intermediate query–token interactions di-rectly in the encoder, making coarse instance masks readily available for MaskMerge. We next study whether the same principle can be applied to Mask2Former [9], where mask prediction occurs in a separate decoder. A direct implementation requires two passes: a dense forward pass to obtain decoder masks followed by a sec-ond mask-guided pass. We therefore additionally introduce a lightweight single-pass variant in which a two-layer con-volutional head predicts coarse instance structure directly from backbone features. The head learns from the decoder masks of the frozen model and is used at inference time to constrain token merging. The results in Table 3 show that instance-aware merging remains beneficial when mask prediction is decoupled from the backbone. 4.5. Ablation Study 

In order to understand more about the different components of our technique, we conduct rigorous ablations and high-light the importance of our design choices. All the ablations are conducted on PanNuke using EoMT-B. 

4.5.1. Impact of each module

Using global cosine merging alone gives 29.5 mAP, whereas replacing the similarity-only criterion with OLAM improves perfor-mance to 33.4 mAP, showing that predicted instance struc-ture provides a substantially safer merge signal. The dif-ference is even clearer when combined with local merg-ing: cosine-based global merging reaches 30.1 mAP at 229 GFLOPs, while OLAM attains 32.1 mAP with only 153 GFLOPs and increases throughput from 121.5 to 142.8 im-ages/s. This indicates that OLAM is better suited to ag-gressive early token reduction, as its instance-aware con-straint allows more tokens to be merged without sacrificing instance separation.

## 5. Conclusion 

We introduced MaskMerge , an instance-aware token merg-ing framework that addresses cross-instance token fusion , a key failure mode of similarity-based merging for instance segmentation. By using intermediate coarse masks to con-strain token aggregation, MaskMerge preserves instance structure while enabling more aggressive token reduction. This leads to consistently better accuracy–efficiency trade-offs than cosine-based merging on PanNuke and iSAID, where visually similar instances are common, and the advantage persists across ViT scales and different backbone pre-training strategies. MaskMerge also matches ALGM on the more heterogeneous Cityscapes benchmark at lower computation and transfers to Mask2Former. Overall, our results show that effective token reduction for instance segmentation should account not only for feature similarity, but also for instance identity , making structural guidance a simple and effective principle for efficient dense prediction.
