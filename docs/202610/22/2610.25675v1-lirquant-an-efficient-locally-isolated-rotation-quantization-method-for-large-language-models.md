## 摘要
训练后量化（PTQ）可支持大语言模型（LLMs）的高效部署，但激活离群值仍是低比特量化的关键挑战。现有全局变换方法忽略了不同通道对量化噪声的异构敏感性，导致精度-效率权衡并非最优。为此，我们提出局部隔离旋转量化（LIRQuant），一种选择性应用变换的敏感性感知框架。LIRQuant 使用噪声加权敏感性度量识别敏感通道，仅对这些通道应用具有表达能力的可学习旋转，而对剩余通道应用轻量级固定旋转。这种解耦设计在保持离群值平滑能力的同时降低了优化复杂度。在 LLaMA-2/3、Mistral、Qwen3 和 Mixtral 系列上的大量实验表明，LIRQuant 在具有挑战性的 W4A4KV4 设置下达到了当前最优精度。同时，LIRQuant 仅需 25 分钟和 20.3 GB 峰值 GPU 内存即可校准 LLaMA-3-8B，在近期可学习旋转方法中实现了最快的校准速度和最低的内存占用，其融合推理内核相较 FP16 可实现最高 2.3 倍的预填充加速和 3.5 倍的内存节省。

## Abstract
Post-Training Quantization (PTQ) enables efficient deployment of Large Language Models (LLMs), yet activation outliers remain a key challenge for low-bit quantization. Existing global transformation methods overlook heterogeneous channel sensitivity to quantization noise, leading to suboptimal accuracy-efficiency trade-offs. To address this, we propose \textbf{Locally Isolated Rotation Quantization (LIRQuant)}, a sensitivity-aware framework that selectively applies transformations. LIRQuant identifies sensitive channels using a noise-weighted sensitivity metric, applying expressive learnable rotations only to these channels and lightweight fixed rotations to the remaining ones. This decoupled design reduces optimization complexity without sacrificing outlier smoothing capability. Extensive experiments across the LLaMA-2/3, Mistral, Qwen3, and Mixtral families demonstrate that LIRQuant achieves state-of-the-art accuracy under the challenging W4A4KV4 setting. Meanwhile, LIRQuant calibrates LLaMA-3-8B in only 25 minutes with 20.3 GB peak GPU memory, achieving the fastest calibration and the lowest memory footprint among recent learnable-rotation methods, and its fused inference kernels deliver up to $2.3\times$ prefill speedup and $3.5\times$ memory saving over FP16.

## 1. 核心问题与研究背景

- **核心问题**：大语言模型（LLM）训练后量化（PTQ）在低比特部署时，激活值中的极端离群值会显著拉大量化步长，导致量化误差平方级放大，成为 W4A4KV4 等低比特量化的主要障碍。
- **现有方法局限**：QuaRot、SpinQuant、OSTQuant、FlatQuant 等基于旋转/正交变换的方法通常采用**全局稠密变换**，对所有通道联合优化同一变换空间，默认各通道对量化噪声的敏感性相同。
- **关键观察**：Transformer 激活通道对量化噪声的敏感性高度异质：仅少量通道对低比特量化脆弱，多数通道相对鲁棒。全局旋转会把优化容量浪费在鲁棒通道上，并可能引入跨通道干扰，使敏感通道不稳定。
- **整体含义**：论文提出 **LIRQuant（Locally Isolated Rotation Quantization）**，即一种敏感度感知的局部隔离旋转量化框架：按通道敏感性划分高/低敏感子空间，对高敏感通道使用可学习旋转，对低敏感通道使用轻量固定 Hadamard 变换，以更低的优化复杂度获得更好的精度-效率折中。

## 2. 方法论

### 2.1 核心思想

- 将激活通道按量化敏感性降序排列，构造置换矩阵 \(P\)，把变换矩阵参数化为块对角形式：
  \[
  T=P^\top \begin{bmatrix}M_{hi}&0\\0&H_{lo}\end{bmatrix}P
  \]
  其中 \(M_{hi}\) 作用于高敏感子空间，为可学习矩阵；\(H_{lo}\) 作用于低敏感子空间，为固定 Hadamard 矩阵。
- 该设计仅对关键通道分配可学习参数，其余通道使用免训练固定变换，从而降低参数量、优化复杂度和过拟合风险，同时保留离群值平滑能力。

### 2.2 噪声加权局部功能敏感度

- 对插入点 \(p\)，定义量化扰动引起的局部功能失真：
  \[
  D_p=\mathbb{E}_C[D_p(f_p(z_p+\epsilon_p),f_p(z_p))]
  \]
- 通过二阶 Taylor 展开与 Hessian 对角近似，将失真分解为各通道贡献之和：
  \[
  D_p\approx\sum_j G_{p,jj}\sigma_{p,j}^2
  \]
  并定义第 \(j\) 个通道敏感度：
  \[
  s_{p,j}=G_{p,jj}\sigma_{p,j}^2
  \]
  即“功能敏感度 × 量化噪声强度”的噪声加权指标。
- 若同时考虑权重量化，采用加性近似 \(s_{p,j}=s^{act}_{p,j}+s^w_{p,j}\)。
- 论文分别给出 Attention/FFN 输入、QK 路径、VO 路径、Down Projection 输入的敏感度实例化公式，均以激活/权重量化误差范数与对应权重范数的乘积形式度量局部功能失真。

### 2.3 两阶段流程

1. **敏感度分析与初始化**：在小校准集上收集激活统计，计算各插入点通道敏感度，确定高敏感通道比例、置换矩阵 \(P\) 和高敏感子空间维度 \(k_p\)。
2. **端到端训练**：冻结原 LLM 权重，仅将各插入点高敏感子空间的 \(M_{hi}\) 设为可学习参数，使用交叉熵损失在校准集上端到端优化：
   \[
   \min_{\{M_{hi}\}}\mathbb{E}_{(X,Y)\in C}\mathcal{L}_{CE}(\text{LLM}_Q(X;\{M_{hi}\}),Y)
   \]

### 2.4 与 Transformer 架构的集成

- **全局残差流**：整个残差流保持在全局旋转空间 \(R_G\) 中；\(R_G\) 使用全尺寸可学习矩阵，不施加局部置换；RMSNorm 缩放参数离线吸收到后续投影权重，保证计算等价。
- **自注意力**：输入经 \(R_G^\top W_q,W_k,W_v\) 投影；RoPE 在通道变换前应用；Q/K 上施加 \(P_1,R_1\)，V 上施加 \(P_2,R_2\)；输出投影吸收 \(R_2^\top,P_2^\top,W_o,R_G\) 为融合权重。
- **FFN**：输入经 \(R_G^\top W_u,R_G^\top W_g\)；激活函数后施加 \(P_3,R_3\)；Down 投影吸收 \(R_3^\top,P_3^\top,W_d,R_G\)。
- **推理在线变换**：仅保留 Q/K 后 RoPE 的 \(R_1\) 和 Down 投影前的 \(R_3\)；\(R_G\) 与 \(R_2\) 离线吸收。在线变换保持块对角结构，高敏感维用稠密子块，其余用快速 Hadamard 变换。
- **融合内核**：将块对角变换、逐 token reduction、对称 INT4 量化和打包融合为单个 Triton kernel；采用 CUDA Graph 优化固定形状解码。

## 6. 主要结论与发现

- **精度**：在 W4A4KV4 下，LIRQuant 在 LLaMA-2/3、Mistral、Qwen3、Mixtral 上取得领先或匹配 SOTA 的 PPL 与零样本平均准确率。例如 LLaMA-2 70B WikiText-2 PPL 为 **3.50**，接近 FP16 的 3.32；LLaMA-3 8B 为 **6.81/9.24**（WikiText-2/C4），优于 SpinQuant 和 FlatQuant；Mixtral-8×7B 为 **4.14 PPL / 77.27%** 平均准确率。
- **效率**：LLaMA-

3-8B 等模型在 W4A4KV4 下相对 FP16 取得可观的解码加速与峰值显存下降，且收益随序列长度和 batch size 增大而更明显；预填充阶段由于融合了块对角变换、逐 token 量化与打包的 Triton kernel，额外变换开销被较大程度摊薄。整体上，LIRQuant 在保持低比特精度优势的同时，校准成本明显低于对全通道施加可学习旋转的方法。

- **敏感通道的结构性**：高敏感通道并非均匀分布，而是集中在少数通道上；跨层敏感通道集合具有较高重叠性（Jaccard 相似度分析支持这一点），说明敏感度并非纯随机噪声，而具有一定可迁移结构。这为“只对关键子空间分配可学习容量”的设计提供了经验依据。
- **局部隔离优于全局稠密旋转**：高敏感比例扫描显示，性能随可学习容量增加先升后趋于饱和，甚至在过高比例时因优化难度和过拟合而下降；说明将所有通道纳入同一可学习变换空间并非最优，局部隔离能够在参数量、优化稳定性与量化误差平滑之间取得更好折中。
- **通道选择指标的有效性**：在 7 种通道选择指标对比中，论文提出的噪声加权局部功能敏感度能够更准确识别对最终损失影响最大的通道，优于仅基于激活幅值、方差或权重大小的启发式指标。
- **架构泛化性**：方法在 LLaMA-2/3、Mistral、Qwen3 等稠密模型以及 Mixtral 这类 MoE 模型上均有效，说明按插入点局部构造敏感子空间、并与全局残差旋转协同的设计具有较好的架构可移植性。
- **效率—精度折中**：固定 Hadamard 变换承担低敏感通道的离群值平滑，可学习矩阵仅作用于高敏感子空间，因而在较小参数量下获得接近或超过全可学习旋转方法的精度，同时降低校准显存和时间。

## 7. 局限性与批判性评价

- **敏感度估计依赖校准集**：通道敏感度由小规模校准集上的激活统计与二阶近似得到，若部署数据分布与校准集差异较大，高/低敏感子空间划分可能不再最优；论文虽报告跨层稳定性，但对跨数据集、跨领域的敏感度迁移性讨论仍有限。
- **二阶近似与加性假设**：局部功能敏感度采用 Hessian 对角近似，并在线性化框架下将失真分解为通道贡献之和；当激活与权重扰动存在强耦合或强非线性时，该近似可能低估交互项，从而影响通道排序的精确性。
- **超参数与结构选择**：高敏感通道比例、每个插入点的子空间维度 \(k_p\) 以及块大小仍需依据校准结果或经验设定；论文虽给出扫描分析，但尚未形成完全自动化的选择准则，实际部署仍需额外调参成本。
- **基线覆盖不完整**：Mixtral 上 OSTQuant、SpinQuant 等基线因显存或实现问题缺失，DartQuant 还修改了缓存机制，导致 MoE 场景的横向比较不够完整；部分表格因独立重采样校准集，绝对 PPL 与主表存在小幅差异，影响细粒度对比。
- **推理评测维度有限**：推理效率主要与 FP16 对比，未系统比较 LIRQuant 与其他量化方法在相同低比特内核下的端到端延迟；在线变换虽保持块对角结构，但在极短序列或小 batch 下，变换与内核启动开销可能削弱加速收益。
- **算力与能耗报告不足**：论文报告了单模型校准墙钟时间和峰值内存，但未给出全部实验累计 GPU 小时、总能耗或完整训练/校准算力，难以全面评估方法的总拥有成本。
- **应用边界**：当前验证集中在语言模型的自回归推理，尚未覆盖多模态模型、长上下文 KV cache 压缩、投机解码等场景；这些场景中激活分布与量化瓶颈可能不同，方法的可迁移性仍需验证。

## 8. 启发与展望

- **“敏感度感知的局部化”可成为低比特量化设计范式**：与其在全通道上追求统一最优旋转，不如先识别对量化噪声敏感的功能子空间，再将可学习容量集中投放。该思想可推广到 KV cache 量化、MoE 专家激活量化以及多模态投影层量化。
- **敏感度指标可与硬件反馈结合**：未来可将噪声加权功能敏感度与内核级延迟、带宽模型联合优化，形成“精度—硬件开销”共同约束的通道划分，而不仅依据统计敏感度。
- **动态与分层敏感度值得探索**：当前划分在校准后固定，若能在推理时根据输入分布或层间状态动态调整高敏感子空间，可能进一步提升长尾输入的鲁棒性；同时可研究跨层共享敏感子空间以降低存储与变换开销。
- **理论刻画仍有空间**：可进一步分析块对角局部旋转对量化误差上界的影响，给出敏感通道选择与误差平方和之间的显式关系，为比例选择提供理论指导。
- **系统级评测应更完整**：后续工作可在统一低比特内核下比较不同方法的端到端吞吐、首 token 延迟和显存占用，并报告完整校准算力与能耗，以支撑实际部署决策。
