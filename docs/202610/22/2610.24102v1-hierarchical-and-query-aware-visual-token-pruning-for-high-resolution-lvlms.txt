Abstract —High-resolution Large Vision-Language Models (LVLMs) preserve critical, fine-grained visual details by encoding a global thumbnail alongside multiple local crops. However, the resulting thousands of vision tokens introduce severe com-putational bottlenecks during Large Language Model (LLM) inference. Existing token pruning methods rely primarily on query-agnostic visual saliency, while current query-aware ap-proaches either operate at a coarse crop-level resolution or compute token relevance too late, after vision tokens have already entered the heavy LLM layers. To address this, we propose a training-free, hierarchical token pruning framework that utilizes query guidance prior to executing any LLM blocks. Our top-down hierarchy first operates at the instance-level, dynamically scaling the vision token retention ratio of each sample based on its visual complexity. Next, at the crop-level, we distribute this sample budget across local crops using sentence-level cross-modal similarity. Finally, at the token-level, we exploit projected vision tokens alongside textual query token embeddings in the shared space to measure fine-grained alignment, applying a text-debiasing normalization to produce high-fidelity query scores. These query-guided budgets and scores are fused with local and global visual saliency metrics to select the most critical vision tokens. Extensive experiments on LLaVA-NeXT-7B demonstrate that our plug-and-play framework retains 98.0% and 94.8% of unpruned performance at 25% and 10% vision token retention, respectively. Notably, at 25% retention, our method delivers a 2.0 × inference throughput speedup and even surpasses the unpruned baseline on POPE by 0.7 points. 

I. I NTRODUCTION 

Large Vision-Language Models (LVLMs) [1]–[3] provide a powerful general interface for multimodal reasoning, yet applications like document understanding, chart analysis, and small-object recognition demand high-resolution inputs to pre-serve critical, fine-grained visual details. To accommodate this, modern high-resolution LVLMs [4] encode a global thumbnail alongside multiple local crops, projecting and concatenating their features into the Large Language Model (LLM) input space. However, this multi-crop strategy drastically increases the vision token count, often exceeding several thousand tokens per image. Because the computational complexity of the LLM’s self-attention mechanism scales quadratically with sequence length [5], this token explosion severely bottlenecks inference speed, inflates memory consumption, and hinders deployment on resource-constrained devices.

Existing token-reduction approaches are broadly divided into training-based methods, which learn compact token pro-jectors but require expensive retraining [6], [7], and training-free methods, which prune or merge vision tokens at inference time [8], [9]. While training-free methods offer plug-and-play flexibility, most are designed for single-grid images and fail to handle the global-thumbnail-and-local-crop layout of high-resolution LVLMs. Recent frameworks like HiRED [10] and GlobalCom 2 [11] address this architecture via a two-stage pipeline: a budget allocation stage that determines how many tokens each crop receives, and a token selection stage that decides which vision tokens to preserve within that crop. Despite their success, both budget allocation and token selection in methods like HiRED and GlobalCom 2 rely en-tirely on visual saliency cues (e.g., [CLS] attention) derived solely from the image. Consequently, their pruning masks remain static across different textual queries, meaning visually inconspicuous but query-critical vision tokens can be discarded prematurely (Fig. 1). Once pruned, this vital visual evidence cannot be recovered by subsequent LLM layers, directly undermining the benefit of high-resolution encoding. While HERO [12] introduces query awareness via crop-query CLIP similarity for budget allocation, its query guidance remains restricted to the coarse crop level, leaving fine-grained token selection completely query-blind. To overcome these limitations, we propose a training-free, top-down pruning hierarchy that infuses query guidance prior to any LLM execution. To address this inefficiency, our hi-erarchy begins at the macro instance-level with a complexity-aware allocation: as illustrated in Fig. 2, visually rich scenes require higher token budgets than visually redundant scenes, which we dynamically compute based on thumbnail token diversity, while maintaining a fixed benchmark average budget. Finally, at the micro token-level , we exploit the shared LLM input space by comparing projected vision tokens directly with query-token embeddings; we normalize similarities per query token via a text-debiasing normalization and fuse the resulting scores with local and global visual attention to preserve the most critical vision tokens. Our contributions are summarized as follows:  

> •

We introduce a pre-LLM query-scoring mechanism that computes text-debiased vision-language relevance in the shared space, combining it with local and global visual saliency to preserve the most critical vision tokens.  

> •

We propose an instance-level budget allocation strategy that scales token retention ratios based on thumbnail-token diversity to improve performance.  

> •

We present a plug-and-play, training-free framework that achieves a 2.0× throughput speedup on LLaVA-NeXT-7B at 25% retention, outperforming state-of-the-art baselines and surpassing the unpruned baseline on POPE. II. R ELATED WORK 

A. High-Resolution LVLMs 

High-resolution inputs preserve critical fine-grained details, such as small objects and scene text, that are lost under aggressive downsampling. Existing high-resolution LVLMs support these inputs through three main designs. Crop-based models , including LLaVA-NeXT [4], InternVL [13], Mon-key [14], and LLaVA-UHD [15], partition images into local views alongside a global thumbnail. Native-resolution models ,like Qwen2-VL [3] and Pixtral [16], directly process arbitrary image scales and aspect ratios. Dual-encoder models , such as Mini-Gemini [17] and LLaVA-HR [18], combine low-resolution semantic features with an auxiliary high-resolution visual stream. While effective, all three designs drastically increase vision token sequence lengths. This work focuses on reducing this token overhead for crop-based LVLMs while preserving their hierarchical thumbnail-crop structure. 

B. Training-Free Visual Token Pruning 

We focus on methods that reduce vision tokens at inference time without requiring model retraining. Pruning within the LLM discards tokens after they enter the language model, leveraging cross-layer attention dynamics [8], [19] or pro-gressive layer-by-layer redundancy dropping [20]. Conversely, 

pruning before the LLM eliminates tokens prior to execut-ing any language block, utilizing vision-encoder visual at-tention [9] or feature redundancy metrics [21] to identify salient regions. Although effective, these existing training-free approaches rely primarily on query-agnostic visual cues or compute text relevance too late inside the heavy LLM layers. Crucially, most are formulated for a single-grid image layout and fail to model the specialized global-thumbnail-and-local-crop structure of high-resolution LVLMs. 

C. Visual Token Pruning for High-Resolution LVLMs 

Recent high-resolution token reduction frameworks ex-plicitly model the hierarchical thumbnail-crop structure. HiRED [10] utilizes global thumbnail visual attention to allo-cate crop budgets, ranking tokens within each crop using local visual attention. GlobalCom 2 [11] improves on this by fusing interpolated global attention with local crop attention for fine-grained selection. HERO [12] introduces query awareness to the budget allocation stage using sentence-level cross-modal similarity, but its token-level selection remains entirely query-blind, relying on multi-layer visual attention. In contrast, while our method adopts sentence-level crop allocation, we drastically bridge the query-blind gap by introducing a pre-LLM, token-level query score and dynamically adapting the total token budget to each sample’s visual complexity. D. Query-Aware Token Scoring 

While the crop-level relevance score ci determines the token budget of each crop, it cannot identify fine-grained, query-relevant details within a crop. Existing methods select tokens within a crop by vision-only metrics such as [CLS] attention. This visual saliency is query-agnostic, causing the model to discard visually inconspicuous yet query-critical regions (e.g., small objects, scene text, or subtle visual cues). To address this, we introduce a token-level query scoring mechanism that scores each visual token against the textual query. and 94 .8, respectively, with the unpruned baseline normalized to 100 .0. Notably, our method surpasses the unpruned model on POPE at both retention ratios (88 .3 and 87 .8 vs. 87 .6). Since POPE evaluates object hallu-cination, these gains demonstrate that pruning query-irrelevant vision tokens effectively mitigates model hallucination.

However, our method achieves a higher throughput than HERO, while simultaneously securing the highest average performance. V. C ONCLUSION 

In this paper, we propose a training-free, hierarchical vision token pruning framework for high-resolution LVLMs. Our top-down pipeline dynamically scales visual budgets per sample based on visual complexity (instance-level), distributes this budget across crops using cross-modal similarity (crop-level), and selects tokens within each crop by combining visual saliency with a text-debiased query score computed in the shared input space (token-level). Extensive evaluations on LLaVA-NeXT-7B demonstrate that our plug-and-play method achieves state-of-the-art performance across diverse bench-marks at both 25% and 10% token retention. Notably, at 25% retention, our framework delivers a 2.0 × inference throughput speedup while even surpassing the unpruned baseline on POPE, highlighting the immense potential of query-aware pruning for efficient multimodal inference.
