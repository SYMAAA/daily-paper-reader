## 摘要
视觉-语言-动作（VLA）模型为通用机器人操作提供了一种有前景的范式，但闭环部署常受限于推理效率：在每个时间步，高分辨率、通常为多视角的图像被编码为数百个视觉token，这些token主导了Transformer的计算和延迟。基于注意力的token压缩是一种自然的解决方案，但用于VLA控制时具有挑战性，因为（1）决策关键token由任务决定，而非通用视觉显著性；（2）token预算在不同步骤间变化显著，因此静态指标和预算会浪费计算或丢弃控制关键token。我们提出FastVLA，一种免训练、任务感知且时间自适应的视觉token压缩框架。在每个步骤中，FastVLA通过任务到视觉的注意力对token重要性进行评分，并基于重要性分布的均匀性自适应设置压缩率，该均匀性由带有在线滑动窗口校准的逆Simpson指标度量。我们在LIBERO和SIMPLER上基于OpenVLA、OpenVLA-OFT和CogACT评估FastVLA，并在实体Franka Research 3机器人上进行评估。在仿真中，它将LLM主干的FLOPs减少35-59%，动作延迟降低9-32%（1.09×-1.46×加速），同时保持任务成功率，与现有即插即用的token压缩/剪枝/复用基线相比，实现了相当或更优的效率-性能权衡。在真实机器人上，它在成功率相当的情况下将动作预测延迟降低20%（1.25×加速）。代码见https://github.com/jiuyixu25/FastVLA。

## Abstract
Vision-Language-Action (VLA) models present a promising paradigm for general-purpose robot manipulation, but closed-loop deployment is often limited by inference efficiency: at each timestep, high-resolution, often multi-view images are encoded into hundreds of visual tokens that dominate transformer computation and latency. Token compression via attention is a natural solution but is challenging for VLA control because (1) decision-critical tokens are determined by the task, not generic visual saliency, and (2) the token budget varies substantially across steps, so static metrics and budgets waste computation or discard control-critical tokens. We introduce FastVLA, a training-free, task-aware, and temporally adaptive visual token compression framework. At each step, FastVLA scores token importance via task-to-vision attention and adaptively sets the compression rate from the importance-distribution uniformity, measured by an inverse-Simpson metric with online sliding-window calibration. We evaluate FastVLA on OpenVLA, OpenVLA-OFT, and CogACT across LIBERO and SIMPLER, and on a physical Franka Research 3 robot. In simulation, it reduces LLM-backbone FLOPs by 35-59\% and action latency by 9-32\% (a 1.09$\times$-1.46$\times$ speedup) while maintaining task success, achieving a comparable or better efficiency-performance trade-off than existing plug-and-play token compression/pruning/reuse baselines. On the real robot, it cuts action-prediction latency by 20\% (1.25$\times$ speedup) at comparable success. Code is available at https://github.com/jiuyixu25/FastVLA.
