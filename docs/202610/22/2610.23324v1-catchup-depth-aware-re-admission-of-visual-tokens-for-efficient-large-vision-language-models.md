## 摘要
大型视觉语言模型（LVLMs）在解码器各层中反复处理数百个视觉Token，带来显著的计算和内存开销。现有的推理时视觉Token剪枝方法通常不可逆地移除低排名Token，尽管获得高查询条件注意力的视觉Token集合会随解码器深度而变化。可恢复路由会保留被跳过的Token以供后续重新考虑，但在绕过中间变换后以陈旧表示重新接纳它们。我们进一步发现，用来自全Token参考轨迹的当前深度oracle状态替换陈旧的重新接纳状态，可以显著提升定位性能。因此，我们提出CatchUp，一个无需训练的深度感知视觉Token再准入框架。CatchUp反复重新评估查询条件视觉相关性，在每个解码器区间仅处理选定的视觉Token，并保留延迟Token以供后续再准入。在再准入时，CatchUp利用来自语义和空间相关视觉Token的参考到当前转移信号，近似缺失的表示演化。在三个指称表达式定位数据集和六个多模态基准上，CatchUp在64、128和192 Token预算下在两个基准组中均取得最高的平均相对保留率。在64 Token预算且活跃视觉Token减少88.9%的情况下，CatchUp在六个多模态基准上平均保留完整模型性能的92.17%，同时将端到端延迟降低8.0%。代码见 https://github.com/pej0918/CatchUp

## Abstract
Large Vision-Language Models (LVLMs) repeatedly process hundreds of visual tokens across decoder layers, incurring substantial computation and memory costs. Existing inference-time visual token pruning methods often irreversibly remove low-ranked tokens, although the set of visual tokens receiving high query-conditioned attention can change across decoder depth. Recoverable routing preserves skipped tokens for later reconsideration, but re-admits them with stale representations after bypassing intermediate transformations. We further find that replacing stale re-admitted states with their current-depth oracle states from a full-token reference trajectory substantially improves grounding performance. We therefore propose CatchUp, a training-free framework for depth-aware visual-token re-admission. CatchUp repeatedly re-evaluates query-conditioned visual relevance, processes only selected visual tokens through each decoder interval, and preserves deferred tokens for later re-admission. Upon re-admission, CatchUp approximates missed representation evolution using reference-to-current transition signals from semantically and spatially related visual tokens. Across three referring-expression grounding datasets and six multimodal benchmarks, CatchUp achieves the highest average relative retention in both benchmark groups at 64-, 128-, and 192-token budgets. At a 64-token budget with 88.9% fewer active visual tokens, CatchUp retains 92.17% of the full model's performance on average across six multimodal benchmarks while reducing end-to-end latency by 8.0%. Code is available at https://github.com/pej0918/CatchUp

## 1. 核心问题与研究背景

- **研究动机**：大型视觉语言模型（LVLM）将图像编码为数百个视觉 token，并在每一层解码器中与文本 token 一起反复计算，带来显著的注意力、前馈与显存开销。推理期视觉 token 剪枝是主流加速手段。
- **现有方法的两个互补缺陷**：
  - **不可逆剪枝**（FastV、SparseVLM、PyramidDrop、Nüwa 等）：一旦 token 被删除或合并，便无法在后续层独立回归。但作者发现，查询条件相关的视觉 token 集合会随解码深度显著变化。
  - **可恢复路由**（ALVTS、ReRoute）：保留未选中 token 以便后续重新纳入，但 token 在跳过若干解码层后，仍以“陈旧”的早期隐藏状态回归，与当前深度表示错位。
- **关键实证观察**：
  - **观察一（相关性随深度漂移）**：在 LLaVA-1.5-7B、500 个 RefCOCO 样本上，相邻层 top-64 集合的平均波动率为 28.85%；相对于第 2 层参考集的“晚出现证据比例”（LER）在第 7 层即超过 50%，第 31 层达 99.42%。说明早期不可逆选择会丢弃后期才变重要的证据。
  - **观察二（表示陈旧有害）**：在固定路由轨迹与 token 预算下，仅把新再准入 token 的陈旧状态替换为全 token 参考轨迹的“当前深度 oracle 状态”，RefCOCO 平均 Acc@0.5 从 18.96 提升至 23.18（+4.22 点）。陈旧状态虽仍保留一定路由信息（Top-K 重叠 59–71%、再准入 Recall 39–46%），但直接用于下游计算会造成明显错配。
- **整体含义**：有效的可恢复路由必须同时满足两点——延迟证据可被重新考虑，且再准入时的表示需补偿其跳过的解码变换。CatchUp 即针对此提出免训练框架。

## 2. 方法论

### 2.1 核心思想

CatchUp 由两部分组成：
1. **可逆视觉证据路由**：在若干路由层对**完整原始视觉 token 集合**重新打分，仅让被选中的 token 参与后续解码区间，其余 token 暂缓但保留身份、空间位置与最新缓存表示。
2. **局部转移校正（Local Transition Correction, LTC）**：当暂缓 token 被重新选中时，利用“语义 + 空间”相关且连续两层被选中的锚点 token 的“参考深度→当前深度”表示位移，近似该 token 缺失的表示演化。

方法**完全免训练**，不更新任何预训练参数，可视为推理期插件。

### 2.2 可逆路由细节

- 路由层集合 \(S=\{\ell_1,\dots,\ell_S\}\)，默认 \(\{2,7,15,23\}\)；路由在层输入处执行，先选择、后计算。
- 相关性分数：用当前层最后一个文本 token 对各视觉 token 的 post-softmax 注意力，在注意力头上平均。
- 对活跃 token 使用其当前表示；对暂缓 token 使用缓存表示，但**用当前路由层的 key 投影重新计算 key**，而非复用旧 key。
- 在完整集合 \(V\) 上取 Top-\(K_s\) 得到 \(V_s\)；未入选 token 被“延迟”而非删除，不进入解码区间、不占解码器 KV cache。
- 新再准入集合 \(R_s=V_s\setminus V_{s-1}\)；首个路由层 \(R_1=\varnothing\)。
- 选中 token 保持原始相对顺序组成紧凑序列，经区间计算后散射回持久化 token 条目，并更新其参考深度。

### 2.3 LTC 关键技术细节

- **锚点候选集** \(F_s=V_s\cap V_{s-1}\)：连续两个路由层均被选中、因而刚经过上一区间更新的 token；新再准入 token 不能在同层充当锚点。
- **锚点打分**：在再准入 token 的参考深度 \(\ell_p\) 的快照上计算语义余弦相似度，并减去空间距离惩罚：
  \[
  a_{pq}=\cos\!\big(h_p[\ell_p],\bar h_q[\ell_p]\big)-\lambda\,d_{sp}(p,q)
  \]
  其中空间距离为归一化 patch 网格坐标的欧氏距离，\(\lambda=0.15\)。
- 取得分最高的至多 \(M=8\) 个锚点，用温度 \(\tau=0.07\) 的 softmax 归一化为权重 \(w_{pq}\)。
- **转移残差**：对每个锚点计算 \(\delta_{pq}=h_q[\ell_s]-\bar h_q[\ell_p]\)，加权聚合得 \(\Delta h_p=\sum_q w_{pq}\delta_{pq}\)。
- **修正**：\(\hat h_p=h_p[\ell_p]+\gamma\Delta h_p\)，\(\gamma=0.8\)。只迁移“变化量”而非替换为锚点绝对状态，保留 token 自身陈旧表示为基底。
- 若锚点集为空或所需参考快照不可用，则跳过 LTC，直接使用缓存表示。
- **快照管理**：采用“按需保留”策略，仅保留仍被某个延迟 token 引用的历史层快照，无引用即释放；避免保存全部层历史。

### 2.4 算法流程（文字版）

1. 初始化所有视觉 token 的持久状态（索引、patch 坐标、最新表示、参考深度），\(V_0=V\)。
2. 对每个路由层 \(s=1,\dots,S\)：
   - 在完整候选集上计算相关性分数并取 Top-\(K_s\)；
   - 求新再准入集合 \(R_s\)；
   - 对每个 \(p\in R_s\) 构造锚点并计算 LTC 修正状态，替换其持久状态；
   - 更新延迟 token 所需的参考快照；
   - 将文本 token 与 \(V_s\) 送入后续解码区间，回写选中 token 状态。
3. 最后一层路由后，选中 token 继续经过剩余所有解码层，输出模型结果。

- **再准入间隔（gap）分析**：跳过的解码层越多（gap 越大），陈旧表示与当前深度的错位越严重，LTC 的相对收益也越明显；这解释了为何在低预算（更多 token 被长期延迟）下 CatchUp 相对 ReRoute 的优势反而扩大。
- **锚点设计消融**：语义+空间的锚点打分优于随机、仅空间、仅语义三种变体，表明“语义相近”保证转移方向合理、“空间邻近”抑制跨区域错误迁移，二者缺一不可；同时说明 LTC 的效果并非来自简单的状态平滑或噪声注入。
- **路由层位置敏感性**：4 种调度下性能存在可观测差异，说明路由时机（尤其是早期是否保留足够证据、后期是否留出恢复窗口）对最终精度有实质影响；默认调度 \(\{2,7,15,23\}\) 表现良好，但作者也提示该选择存在针对定位任务调优的可能。
- **组件消融**：单调紧凑路由（不可逆）性能最低；加入可逆路由但沿用陈旧状态有提升但有限；替换为绝对状态混合会破坏 token 自身信息、弱于残差式迁移；完整 CatchUp（可逆路由 + LTC）取得最佳，验证了两个组件各自的必要性与组合的协同性。
- **跨主干验证**：在 Qwen2.5-VL-7B-Instruct 上，三个预算下的 RefCOCO、POPE、VQAv2 结果同样呈现一致趋势，说明方法不依赖 LLaVA 特有的注意力结构或 token 组织方式，具备一定可移植性。
- **总体结论**：视觉 token 剪枝的核心矛盾不只是“选得准不准”，还包括“被暂缓的证据能否以正确深度状态回归”。CatchUp 用免训练的可逆路由加局部转移校正，把“延迟证据再考虑”与“表示演化补偿”统一到同一推理框架中，在细粒度定位这一对 token 削减最敏感的任务上收益最显著，同时在通用多模态基准上保持较高保留率。

## 7. 局限与可改进方向

- **模型规模与主干覆盖有限**：实验集中在 7B 级模型与两种主干，未验证更大规模（13B/34B/72B）或非 LLaVA 系架构；更大模型中视觉 token 的语义抽象程度与注意力分布可能不同，超参（\(\lambda\)、\(\gamma\)、\(M\)、路由层）是否仍最优尚不清楚。
- **对比范围偏窄**：主要与推理期免训练剪枝方法比较，缺少与训练型压缩（如剪枝后微调、蒸馏）以及 pre-decoder / projector 侧压缩方法的对照，因而“同等训练成本下是否仍占优”无法直接判断。
- **锚点机制的前提假设**：LTC 假设“语义+空间相近且连续两层被选中的 token”能代表再准入 token 的表示演化。当目标 token 处于语义独特区域、或锚点候选集为空/过小时，修正退化为直接使用缓存表示，收益不确定；论文对此类失败情形只做了兜底处理，缺少定量统计。
- **超参与调度敏感性**：\(\lambda=0.15\)、\(\gamma=0.8\)、\(M=8\)、\(\tau=0.07\) 及路由层调度均跨数据集固定，虽体现泛化意图，但未给出敏感性曲线；路由层位置的明显差异也提示默认调度可能对定位基准存在一定适配。
- **评估维度**：以准确率与 KV cache/时延/TFLOPs 为主，缺少生成质量（幻觉、长回答一致性）、多图/视频输入、batch 推理与真实服务吞吐的评估；快照显存的峰值行为在长序列、大 batch 下也需进一步刻画。
- **效率结论的可比性**：未报告 GPU 型号与实验环境，端到端时延数字的外部可比性受限；prefill 匹配虽控制了主要计算量，但不同实现的算子融合、KV cache 布局差异仍可能影响对比公平性。
- **可改进方向**：将锚点选择由启发式打分升级为轻量学习式预测（仍可保持免训练主干）；用更紧凑的“转移算子”替代逐 token 锚点聚合以降低开销；把路由层调度做成输入自适应（依据注意力熵或证据分散度动态决定路由时机）；将 LTC 思想推广到多模态 token 压缩、长视频帧选择等“延迟—再准入”场景。

## 8. 学术与实践意义

- **问题重述的价值**：论文把“可恢复路由”的失效原因从“路由策略不好”重新定位为“表示陈旧”，并用 oracle 替换实验（18.96→23.18）给出清晰因果证据，这类“先诊断、再设计”的范式对推理加速研究具有方法论参考意义。
- **免训练插件的工程价值**：不修改权重、可与现有解码器实现解耦，适合作为部署侧的即插即用加速组件；按需快照管理也体现出对真实显存约束的考虑。
- **对“压缩预算—任务敏感度”的量化**：定位任务在 64-token 预算下仅保留约 37.60% 性能、而通用多模态保留 92.17%，这一落差提示实际部署应按任务类型设定不同压缩策略，而非追求统一的高压缩比。

## 9. 客观评价

CatchUp 的贡献主要在于**识别并命名了一个被忽视的失效模式**（再准入 token 的表示错位），并给出**低成本、免训练、可解释的补偿方案**。其动机观察扎实、消融链条完整、效率报告维度较全，定位基准上的增益在多个预算下一致。相对不足在于：模型规模与基线类型覆盖有限，锚点机制在困难情形下的稳健性缺少统计，超参与路由调度的敏感性分析不足，效率结论的硬件可比性也有待补充。总体而言，这是一篇问题定义清晰、机制解释充分、工程可行性较好的推理期加速工作；其结论在 7B 级 LLaVA 类模型与细粒度定位场景下证据较强，向更大模型、更多任务与训练型压缩方法的推广仍需后续验证。
