## 摘要
随着视觉-语言模型（VLM）的快速发展，Web-GUI 智能体通过基于截图的 grounding 在与真实世界界面交互方面取得了良好性能。然而，高分辨率截图和多轮历史会引入过多视觉令牌，导致显著的推理开销。现有令牌剪枝方法主要面向自然图像设计，通常基于重要性分数独立选择令牌，这可能会割裂识别按钮、图标和超链接等小型 GUI 元素所需的局部视觉结构。在本工作中，我们提出 STP-GUI（Spatially-aware Token Pruning for GUI agents，面向 GUI 智能体的空间感知令牌剪枝），一种查询引导的令牌剪枝框架；该框架在激进令牌缩减下执行空间连贯的窗口级选择，同时保留细粒度的指令条件令牌评分。轻量级选择器通过策略学习进行优化，而 VLM 主干保持冻结。在 Online-Mind2Web 上的实验表明，STP-GUI 在低令牌预算下实现了良好的效率-性能权衡。在 21% 的令牌保留率下，它保留了 77.7% 的全令牌性能，同时将推理延迟降低 31%、FLOPs 降低 57%。在 Android in the Wild 上的结果进一步表明，该方法可迁移到移动 GUI 环境。

## Abstract
With the rapid development of vision-language models (VLMs), Web-GUI agents have achieved promising performance in interacting with real-world interfaces through screenshot-based grounding. However, high-resolution screenshots and multi-turn histories introduce excessive visual tokens, causing substantial inference overhead. Existing token pruning methods, mainly designed for natural images, often select tokens independently based on importance scores, which can fragment the local visual structures required for recognizing small GUI elements such as buttons, icons, and hyperlinks. In this work, we propose STP-GUI (Spatially-aware Token Pruning for GUI agents), a query-guided token pruning framework that preserves fine-grained instruction-conditioned token scoring while performing spatially coherent window-level selection under aggressive token reduction. A lightweight selector is optimized through policy learning while the VLM backbone remains frozen. Experiments on Online-Mind2Web show that \papername achieves a favorable efficiency-performance tradeoff under low token budgets. At 21% token retention, it preserves 77.7% of full-token performance while reducing inference latency by 31% and FLOPs by 57%. Results on Android in the Wild further suggest that the method transfers to mobile GUI environments.

# STP-GUI 论文深度总结

## 1. 核心问题与研究动机

- **背景**：基于 VLM 的 Web-GUI 智能体通过截图 grounding 完成网页操作，效果良好，但代价极高。
  - 单张 1920×1080 截图经 Qwen3-VL 编码后约产生 **2040 个视觉 token**；
  - 智能体通常需要输入多轮交互历史（历史截图、动作、观察），总视觉 token 很容易**超过 10K**；
  - 用户对响应延迟敏感，因此视觉 token 带来的巨大预填充（prefill）开销成为关键瓶颈。
- **现有方法的缺陷**：主流 token 剪枝方法（注意力选择、相似度过滤、可学习摘要）主要为**自然图像**设计，前景物体大而连续；而 GUI 截图的特点是：
  - 有效信息**稀疏、局部、极小**（一个图标或超链接可能只占几个 token），大量区域是空白背景和重复布局；
  - 这些小区域的**空间连续性**至关重要，丢失相邻 patch 会直接破坏可点击元素的视觉证据；
  - 按重要性分数**独立选 token** 会把局部结构打碎成互不相连的碎片。
- **论文识别的核心问题**：现有范式把“重要性估计”和“选择粒度”耦合在一起——token 级选择精度高但碎片化，窗口级选择有结构但依赖打分质量。本文主张**将二者解耦**：用 token 级打分保证精度，用窗口级选择保证空间连贯。
- **整体含义**：提出 STP-GUI，一个查询引导、空间感知的剪枝框架，在冻结 VLM 主干的前提下，于 LLM 处理之前保留空间连续、指令相关的局部证据。

## 2. 方法论

### 2.1 核心思想
- **评分粒度与选择粒度解耦**：token 级打分（细粒度相关性）+ 非重叠空间窗口级选择（空间连贯性）。
- **轻量选择器 + 冻结主干**：只训练约 **2M 参数**的选择器，VLM 完全冻结，可离线训练一次、在线部署复用。

### 2.2 关键技术细节与流程

**（1）问题形式化**
- 视觉 token $V \in \mathbb{R}^{L_v \times d}$ 与文本 token $T \in \mathbb{R}^{L_t \times d}$ 拼接输入；剪枝即按策略 $P$ 选子集：
  - $S = P(V, T)$，$M_i = \mathbb{1}[S_i \in \text{Top-}N(S)]$；
  - 预算 $N = \lfloor \beta L_v \rfloor$，$\beta$ 为保留率（keep ratio）。
- 多轮场景下，对**每一帧独立**执行窗口选择，统一保留率 $\beta$。

**（2）指令引导的 token 打分**
- 轻量评分器 $f_\theta(V,T) \to \mathbb{R}^{L_v}$，对投影后的视觉特征与指令文本做轻量跨模态交互，输出每个视觉 token 的任务相关性分数 $s_i$；
- 文本侧只取**与动作相关的指令片段**，排除思维链推理步骤（沿用 Feng et al., 2025）。

**（3）窗口级聚合与选择**
- 视觉 token 排列为 $H_g \times W_g$ 网格，划分为互不重叠的 $W \times W$ 窗口（默认 $W=4$）；
- 窗口分数 $s_w = \phi(\{s_i\}_{i \in w})$，由窗口内 token 分数聚合得到；
- 以窗口分数参数化 **Plackett–Luce 分布**，训练时按该分布采样窗口子集，使期望 token 预算匹配 $\beta$；
- 推理时无采样，直接按聚合分数**贪心选取** top-ranked 窗口，保留的每个区域都是完整的 $W \times W$ patch。

**（4）策略学习训练选择器**
- 缺少 token 保留掩码的真值，因此用**动作级反馈**训练离散选择策略（PPO）；
- 奖励由两部分组成：
  - $r_{gt}$：与任务级监督（真值动作）一致；
  - $r_{full}$：与全 token 模型的动作偏好保持一致；
  - 单步奖励 $r_{step} = T_{mt}(\lambda_{type} + (1-\lambda_{type}) \cdot sim)$，其中 $T_{mt}$ 为动作类型匹配，$sim$ 为文本参数编辑距离/空间参数容差匹配；
  - 最终 $r = \lambda_{gt} r_{gt} + \lambda_{full} r_{full}$（最优配置 0.7/0.3）。
- 优化目标为 PPO 裁剪目标 + 熵正则：
  - $L_{clip} = -\mathbb{E}[\min(\rho A, \text{clip}(\rho, 1-\epsilon, 1+\epsilon)A)]$，$A = r - b_{ema}$（按动作类型的 EMA 基线降方差）；
  - $L = L_{clip} - \beta_H H(\pi_\theta)$，熵项鼓励探索。

**（5）推理部署**
- 剪枝发生在 **ViT 特征进入 LLM prefill 之前**，因此无需动态注意力掩码，显存开销极低。

## 6. 主要结论与发现

- **性能-效率权衡优异**：Online-Mind2Web 上，21% 保留率下 SR = 0.290（**全 token 性能的 77.7%**），50% 保留率下 SR = 0.350（**93.8%**）；4B 模型上分别为 76.2% 与 95.0%。
- **同预算下全面领先**：21% 时超过 HiPrune、HiPrune\*、FlashVLM、FlashVLM\*、Attention 的同比例结果，并超过在约 41% 原生比例下报告的 PDrop/PDrop\*；50% 时同样领先。
- **效率收益**：3 帧场景下延迟降低 **31%**（494.5ms，全部方法中最低），FLOPs 降低 **57%**；显存仅 982MB，远低于 FlashVLM（9174MB）与 HiPrune（15270MB）——因为后者需要推理时动态注意力掩码。
- **可迁移性**：AitW 上 50% 保留率取得 0.741（General）/ 0.492（Web Shopping），大幅超过 Attention 的 0.338/0.338；21% 时仍有 0.718/0.436。
- **空间连贯性显著更优**：21% 预算下平均仅 **5.71 个连通域**（Attention 为 94.95，FlashVLM/HiPrune 超过 120），78% 保留 token 落在最大连通域内，平均连通域面积大 28–40 倍；8-连通下趋势一致。
- **打分与选择粒度互补**：窗口聚合对 Attention 仅带来 +1.0/+1.7 pp，对 STP-GUI 带来 **+4.3/+3.7 pp**，说明“学习到的打分”与“结构化保留”缺一不可。
- **其他发现**：PPO 比朴素 REINFORCE 高 4.3 pp；W=4 为最优窗口粒度（W=1 退化且方差大）；非重叠窗口优于重叠版本；GT 奖励与 full 奖励单独使用均有效，组合最佳；深层（layer 16）的注意力信号最利于定位。

## 7. 优点

- **问题洞察新颖且准确**：明确指出“重要性估计与选择粒度耦合导致空间碎片化”这一被忽视的失效模式，并用连通域统计给出了量化证据。
- **方法设计解耦清晰**：token 级打分保精度、窗口级选择保结构，两者职责分明，易于理解和复现。
- **工程部署友好**：仅训练 2M 参数选择器、主干完全冻结；剪枝位于 LLM prefill 之前，无需动态注意力掩码，显存与延迟优势明显；选择器可离线训练一次、反复使用。
- **训练信号设计巧妙**：在无 token 级真值的情况下，用“与全 token 模型动作一致”的 $r_{full}$ 作为弱监督，使无 GT 场景也能训练；并验证了两种奖励的互补性。
- **实验体系完整**：覆盖两个 benchmark、三种模型规模、多档保留率、多类基线与丰富消融，并包含 1/2/3 帧的效率测试与逐步骤可视化案例。
- **学术表述诚实**：多处主动声明结论边界（如不主张严格同预算对比、连通域指标不单独证明目标覆盖度提升、重叠消融差异小不足以说明边界不重要），自我批评意识较强。

## 8. 不足与局限

- **固定预算与固定窗口粒度**：使用统一 keep ratio 和预设的非重叠 W×W 窗口，**跨窗口边界的 UI 元素**可能被截断；作者自己也将其列为主要局限，且重叠窗口消融并未带来增益，说明该问题尚未真正解决。
- **对比公平性的残余风险**：多个基线只能在其原生保留率下比较（PDrop 41%、IVC 50%），缺少所有方法在完全相同预算下的完整对照矩阵。
- **空间连贯性证据偏弱**：benchmark 缺少逐步骤 UI 元素标注，无法度量“动作关键目标区域的覆盖度”；连通域指标只能说明保留掩码的形态，案例研究为人工挑选，存在选择性偏差风险。
- **训练成本非零**：选择器训练约 10 小时/8 GPU（GT-only 4.8 小时），相比纯 training-free 方法仍有一次性离线开销；且 PPO 需要在线 rollout，流程相对复杂。
- **模型与场景覆盖有限**：主干最大到 Qwen3.5-9B，未验证更大规模模型；仅覆盖 Web 与 Android 两类 GUI，未涉及桌面 OS、跨应用

- **模型与场景覆盖有限**：主干最大到 Qwen3.5-9B，未验证更大规模模型；仅覆盖 Web 与 Android 两类 GUI，未涉及桌面 OS、跨应用切换、原生桌面软件等场景；也未考察超长交互历史（如 10 帧以上）下剪枝误差的累积效应。
- **对数据分布与动作空间的依赖**：选择器在特定 SFT 数据上离线训练，面对域外网站或布局风格差异较大的界面时，其打分是否稳定缺乏系统验证（跨域实验仅覆盖 AitW 两个划分，且仍是 GUI 域内迁移）；奖励函数中的动作类型匹配与参数容差规则与具体动作空间强绑定，迁移到新的动作集（如拖拽、快捷键、多步组合操作）时需要重新设计。
- **超参数敏感性与统计严谨性**：λ 奖励权重、窗口大小 W、熵系数等关键超参虽有消融，但未报告多种子均值±方差；作者亦承认窗口重叠、优化器等消融“需要更多训练种子来评估稳定性”，因此部分结论（如非重叠优于重叠）的证据强度有限。
- **评测口径的固有偏差**：Online-Mind2Web 为真实在线网站，网站动态变化可能导致不同时间点结果不可完全复现；成功率作为单一主指标，未报告步数效率、无效点击率、任务完成质量等辅助指标，难以判断剪枝是否以“更多试错步数”换取成功率。
- **安全与隐私维度缺失**：GUI 截图常含账号、地址等敏感信息，论文未讨论剪枝对敏感区域的处理，也未涉及部署时的隐私保护与合规问题。

## 9. 可复现性与写作质量

- **可复现性**：论文给出了较完整的关键配置——主干型号与规模、SFT 与选择器训练的超参（epoch、学习率、余弦衰减、冻结策略）、窗口大小默认值、奖励权重最优配置、GPU 型号与训练时长、推理硬件（H20）。这些信息足以支撑方法层面的复现。
- **不足**：选择器网络的具体结构（层数、隐层维度、跨模态交互方式）在总结所依据的正文中描述较简，若附录未补充，会构成复现障碍；PPO 的 rollout 批量、KL/熵系数、EMA 衰减率等细节亦需查附录确认；代码与数据是否开源未在正文中明确承诺。
- **写作与图表**：论文的问题动机—方法—实验链条清晰，用连通域统计把“空间碎片化”这一抽象问题量化，是较强的论证手法；主表同时给出 training-free 与重训练变体，体现了对公平比较的考量；多处主动标注结论边界，学术表达诚实。

## 10. 总体评价与启示

- **定位**：STP-GUI 是一篇“问题定义精准、方法克制、工程友好”的视觉 token 剪枝工作。其最大贡献未必是某个模块的新颖性，而是**把“打分粒度”与“选择粒度”解耦**这一视角，以及用连通域指标把 GUI 场景的特殊性（信息稀疏、局部、空间连续）转化为可测量的实验证据。
- **实践价值**：仅训练 2M 参数、主干冻结、剪枝前置于 LLM prefill，使其具备较强的落地性——显存（982MB）与延迟（3 帧降 31%）收益在真实部署中意义明确，且选择器可离线训练一次、多场景复用。
- **理论/方法启示**：$r_{full}$ 这一“与全 token 模型动作偏好一致”的弱监督信号，为缺乏 token 级真值的剪枝/选择类任务提供了可借鉴的奖励构造思路；窗口级 Plackett–Luce 采样 + 期望预算匹配，也是把离散结构化选择纳入策略优化的一个干净范式。
- **改进方向**：跨窗口边界元素的截断问题、固定预算的自适应化（按指令难度动态分配 keep ratio）、面向更长历史与更多 GUI 形态（桌面、跨应用）的泛化验证，以及引入元素级标注或人工评估来直接度量“关键目标覆盖度”，是后续工作最值得推进的几点。
- **结论**：在“GUI 智能体视觉 token 昂贵”这一现实约束下，STP-GUI 提供了一个精度—结构—效率三者平衡较好的方案；其结论在其设定范围内成立且有较充分证据支撑，但对跨域、跨形态与严格同预算比较的结论应保持审慎，作者本人对此亦有清晰声明。
