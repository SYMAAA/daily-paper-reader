## 摘要
大型视觉-语言模型（VLMs）同时处理视觉输入和文本查询，但由于视觉令牌数量庞大，推理成本很高，因此视觉令牌剪枝成为提升效率的自然方法。近期工作利用查询信息来指导令牌选择，通常基于注意力模式或令牌动态得到的启发式规则。然而，这些方法并未显式利用查询-视觉交互的底层结构。为弥补这一空白，我们观察到：由Transformer注意力中已有的查询和键投影自然诱导出的查询-视觉交互矩阵实际上是低秩的，少量主导潜在交互模式即可捕捉与查询相关的语义。受此观察启发，我们提出查询-视觉分解（QViD），一种新颖的免训练、查询感知的视觉令牌剪枝方法，能够利用该结构。在图像和视频理解基准上的大量实验表明，在相同令牌预算下，QViD 能持续提升性能，且在激进压缩设置下增益最大。

## Abstract
Large vision-language models (VLMs), which process both visual inputs and text queries, incur high inference costs due to the large number of visual tokens, making visual token pruning a natural approach for improving efficiency. Recent work has leveraged query information to guide token selection, often through heuristics derived from attention patterns or token dynamics. However, these approaches do not explicitly exploit the underlying structure of query-vision interactions. We address this gap by observing that the query-vision interaction matrix, naturally induced by the query and key projections already present in transformer attention, is effectively low-rank, with a small number of dominant latent interaction modes capturing query-relevant semantics. Motivated by this observation, we propose Query-Vision Decomposition (QViD), a novel training-free query-aware visual token pruning method that exploits this structure. Extensive experiments on both image and video understanding benchmarks show that QViD consistently improves performance under matched token budgets, with the largest gains appearing under aggressive compression regimes.

# 论文总结：Vision Token Pruning via Query–Vision Interaction Decomposition（QViD）

## 1. 核心问题与研究动机

- **背景**：视觉语言模型（VLM）需将大量视觉令牌与文本查询联合送入 LLM，单张图像可产生数百至数千个视觉令牌，导致推理延迟与显存开销巨大；视觉令牌剪枝是提升效率的自然手段。
- **现有两条技术路线的缺陷**：
  - **注意力引导型**（FastV、SparseVLM、PDrop）：查询感知，但依赖注意力权重，存在**位置偏置**（序列上靠近文本的视觉令牌易获高分），且需访问注意力矩阵，与 FlashAttention 等高效实现不兼容。
  - **无注意力型**（V2Drop）：以跨层隐状态变化量排序，规避位置偏置，但信号**任务无关**，只反映通用令牌动态，未显式建模查询相关性。
- **研究空白**：缺少一种**既显式以查询为条件、又不依赖注意力权重**的剪枝信号。
- **核心问题**：能否用查询–视觉交互矩阵的少数主导潜在模态来刻画与查询相关的视觉证据？
- **关键观察**：由 Transformer 中已有的查询/键投影自然诱导的交互矩阵 `M = Q_txt K_vis^T` 具有**强低秩性**，少量主导奇异方向即可捕捉任务相关语义（在 POPE、GQA、TextVQA、MMBench、ScienceQA、MME 上均观察到奇异值谱快速衰减）。

## 2. 方法论：QViD

- **核心思想**：在第 ℓ 层构造查询–视觉交互矩阵，用其**主导低秩子空间**（而非原始矩阵元素或列范数）为视觉令牌打分，保留参与主导交互模态的令牌。
- **关键步骤**：
  1. **构造交互矩阵**：用冻结的 `W_Q, W_K` 计算 `Q_txt = H_txt W_Q`、`K_vis = H_vis W_K`，得到 `M = Q_txt K_vis^T ∈ R^{Nq×Nv}`，其中 `M_ij` 表示查询令牌 i 与视觉令牌 j 在模型表示空间中的兼容度。
  2. **与注意力分数的两点区别**：在**位置编码之前**计算（消除位置偏置）；**不做 softmax 归一化**（保留原始交互结构，避免令牌间竞争混叠），且无需显式注意力图。
  3. **SVD 分解**：`M = UΣV^T`，右奇异向量 V 描述视觉令牌侧的主导交互模式。
  4. **令牌打分**：`s_j = Σ_{k=1}^{r} V_{jk}^2`，即视觉令牌 j 在前 r 个主导右奇异方向上的参与度（行杠杆分数）。
  5. **多头聚合**：各注意力头独立计算后取平均 `s_j = (1/H) Σ_h Σ_k (V^(h)_{jk})^2`；短查询时用 `r_eff = min(r, Nq, Nv)`。
  6. **剪枝**：保留得分最高的 top-K 视觉令牌，其余丢弃，后续层正常处理。
- **默认超参**：剪枝层 ℓ = 3，SVD 成分数 r = 16，构造 M 时省略 RoPE。
- **高效实现**：因 `Nq ≪ Nv`，先对 `(M^(h))^T ∈ R^{Nv×Nq}` 做薄 QR 分解，再对小的 `Nq×Nq` 矩阵做 SVD，数学上等价但避免对全矩形矩阵做 SVD；总复杂度 `O(H Nv Nq² + H Nq³)`，实测打分步骤（含构造 M）**不到 50 MFLOPs**。
- **性质**：完全免训练、无需修改架构或注意力内核，仅使用模型已有的冻结投影。

## 6. 主要结论与发现

- **一致优于基线**：在所有模型、基准与保留预算下，QViD 的平均归一化性能均优于 V2Drop 等方法；**压缩越激进，增益越大**。
  - LLaVA-1.5-7B @64 令牌：90.4% vs V2Drop 86.9%（+3.5%），TextVQA +3.7%、POPE +5.7%、MME +83 分。
  - Qwen2-VL-7B @11.1%：81.7% vs 62.7%（+19 个百分点）。
  - LLaVA-OV-7B @10%：91.2% vs 69.4%；Video-LLaVA @10%：94.0% vs 80.5%。
- **低秩分解是关键**：同一交互矩阵下，朴素列范数打分仅 70.3%/73.2%/76.5%，远逊于 QViD 的 91.1%/96.5%/98.5%；σ 加权与列范数在数学上等价（`‖M_:,j‖² = Σ_k σ_k² V_jk²`），故排序相同、结果一致。
- **少量主导模态已足够**：n_svd 从 1、2 增至 4、8 时性能陡升，16 时最佳（128 令牌下 96.5%），说明任务相关结构集中于少数交互模式。
- **层选择**：ℓ=3 最优，但 ℓ=1–5 差异较小（LLaVA 较稳定）；Qwen2 对层更敏感，过晚剪枝会削弱激进压缩下的鲁棒性。
- **语义可解释性**：主导奇异分量对 `animal`、`hat`、`country`、`jersey` 等实词赋高分，残差分量偏向 `is`、`the` 等功能词。
- **计算收益**：剪枝节省的算力远大于打分开销（每删一个视觉令牌约省 0.01 TFLOPs，打分总开销 <50 MFLOPs）。
- **聚合方式可改进**：per-head max 聚合在部分预算下略优于默认平均聚合（64 令牌 92.0% vs 91.1%），提示不同注意力头存在查询相关线索的特化。

## 8. 局限与可质疑之处

- **对模型内部结构的依赖**：方法假定存在标准 Q/K 投影且视觉/文本令牌共享同一表示空间；对线性注意力、Mamba 类、早期融合或 Q/K 结构被改造的 VLM，低秩交互矩阵是否仍有意义缺乏验证。

- **端到端加速有限**：FLOPs 降低 51%–71.5%，但吞吐仅提升约 1.19–1.21×，延迟甚至略慢于 V2Drop，说明瓶颈在内存带宽、内核启动与数据搬运，而非纯计算量；论文对此的解释相对简略。
- **模型规模与场景覆盖不足**：仅验证 7B 级模型，未涉及更小（边缘部署）或更大（72B 级）模型；高分辨率多图、长视频、多轮对话中令牌持续累积的场景验证有限。
- **基线可比性存在细节差异**：部分对比数字直接引自 V2Drop 论文而非统一环境复现；各方法的剪枝位置、预算定义未必完全一致，"同预算"不完全等于"同算力/同延迟"。
- **评价口径可能掩盖退化**：以归一化平均性能为主，单基准上的显著下降（如 OCRBench、ChartQA 等细粒度任务）容易被平均掩盖，文中对最差情况的分析不够充分。
- **鲁棒性与安全性未评估**：未考察对抗扰动、分布外输入、幻觉抑制机制在剪枝后的变化，HallusionBench 仅作为单项基准出现。

## 9. 启发与可拓展方向

- **"交互矩阵低秩性"可作为通用查询相关性代理**：该信号不限于视觉令牌剪枝，可迁移到 KV cache 淘汰、长视频关键帧选择、文档检索中的片段筛选、多图场景的图像级裁剪。
- **自适应化是自然延伸**：按奇异值能量占比自动确定 r，按层间交互谱变化自动选择剪枝层，按头特化程度分配头级预算（per-head max 已提示这一可能）。
- **与高效注意力天然解耦**：因不读取注意力矩阵，可与 FlashAttention、PagedAttention、量化推理等正交技术组合，工程组合空间较大。
- **可训练化潜力**：在免训练版本之上，用轻量正则约束交互谱或蒸馏剪枝决策，可能进一步逼近全令牌性能，同时保留低开销特性。
- **理论刻画值得补足**：若能给出低秩近似误差与下游性能之间关系的界，将把当前的经验观察提升为可预测的设计准则。

## 10. 总体评价

QViD 以"查询–视觉交互矩阵的主导低秩子空间"这一简洁信号，填补了注意力引导型与无注意力型剪枝之间的空白：方法免训练、复用冻结投影、与高效注意力兼容，并在 4 个 VLM、10+ 基准上一致优于强基线，压缩越激进增益越明显。其核心贡献在于把"查询相关性"从注意力权重中解耦出来，并用消融证明了收益来自低秩结构本身而非交互矩阵的存在。主要短板在于端到端加速幅度有限、超参需逐模型调整、低秩假设缺少理论支撑，以及大规模与极端场景验证不足。总体而言，这是一项动机清晰、方法优雅、实证扎实的工作，为"结构化信号驱动的令牌压缩"提供了可复用的分析框架。
