Abstract —Vision-language-action (VLA) models enable robots to perform tasks specified through natural-language instruc-tions, but their large weight footprint challenges deployment on memory-constrained onboard platforms. Ultra-low-bit quantiza-tion reduces this footprint, yet preserving task performance and controlling weight recovery costs remain challenging. We propose Action-Guided Quantization, which combines action sensitivity with a measured proxy for weight recovery cost to allocate matrix bitwidths under storage budgets. Per-channel calibration compensates for quantization error, while a uniform bitwidth within each matrix preserves regular layouts. Bit-dependent grouped lossless coding reduces resident weight storage, and block-wise recovery limits temporary buffers. On LIBERO, AGQ achieves 92.7% task success at W3, exceeding AWQ and GPTQ by 1.2 and 3.7 percentage points, respectively, and retains 70.5% success at W2.5. An asymmetric configuration, denoted W1.5 ∗,uses W4 vision weights and a parameter-weighted average of 1.5 bits for language weights. With lossless coding, it achieves 6.10 ×

complete-model compression relative to BF16 while retaining 25.5% task success. Code and experimental results are available at https://github.com/Qiuxu00/AGQ. 

Index Terms —vision-language-action model, mixed-precision quantization, per-channel calibration, lossless coding, hardware-aware inference. 

I. I NTRODUCTION 

Vision-language-action (VLA) models integrate visual per-ception, language understanding, and action prediction, en-abling robots to perform tasks specified through natural-language instructions [1], [2]. Running these models locally is attractive for robots that operate with limited connectivity or require autonomous execution. However, their large weight footprint poses a challenge for resource-constrained onboard computing platforms. Ultra-low-bit weight quantization offers a way to reduce model storage and make VLA inference feasible under tighter memory budgets. These savings come at the risk of degraded action prediction: in closed-loop con-trol, quantization-induced action errors can affect subsequent observations and task outcomes. Therefore, preserving task performance under aggressive compression remains a central challenge. Post-training quantization (PTQ) provides a practical ap-proach to compressing pretrained models using a small cali-bration set [3]. Beyond calibrating quantized weights, mixed precision allows different layers or matrices to use different bitwidths according to their sensitivity [8], [9]. Hardware-aware approaches such as HAQ additionally incorporate latency and energy feedback into precision selec-tion [10]. Recent low-bit schemes also use structured mixed precision [11], lattice codebooks [12], and dense-and-sparse quantization [13]. Ultra-low-bit VLA deployment requires allocating limited precision across matrices with different effects on action pre-diction. Our analysis reveals sensitivity differences even within the same layer, motivating matrix-wise allocation. The de-ployment cost also extends beyond average bitwidth: metadata and padding increase storage, while weight recovery requires computation and temporary buffers. Entropy-based weight compression supports memory-efficient deployment [14], [15], while recovered BF16 weights still require temporary buffers. To address these issues, we propose Action-Guided Quan-tization (AGQ). AGQ selects a bitwidth for each weight matrix based on action sensitivity and a measured estimate of weight recovery cost under storage constraints. A. Overview 

Fig. 2 separates preparation from compressed inference. Starting from a BF16 policy, calibration observations, and backbone storage budgets, stage (b) assigns matrix bitwidths using action sensitivity and execution overhead. Stage (c) fixes this allocation and learns channel quantizers through block reconstruction. Stage (d) encodes the resulting integer weights for deployment. During inference, encoded weights remain GPU-resident; decoding and fused unpacking/dequantization recover the active block’s BF16 weights, which are released on exit. Allocation and parameter learning remain offline. 

B. Action-Guided Bit Allocation 

We assign one bitwidth per matrix to preserve regular decoding. A common W4 perturbation provides a lower-bit allocation prior, assuming some consistency in relative sensitivity across precisions. One probe per matrix replaces separate sensitivity scans at every candidate bitwidth, reducing preparation work without assuming identical rankings. Four adjacent W2 values or two W3/W4 values form a joint Huffman symbol [19], while W1 retains raw packing. These six- or eight-bit symbols capture joint distributions with at most 256 symbols, recovering multiple values per decode operation. To reduce decoding dependencies [20], we partition fixed-size coding blocks into independently decodable segments and use prefix lookup to reduce bit-by-bit traversal. Per-matrix encoding selects the smaller representation, including code-books and block indexes, with raw packing as fallback. Scales and zero points remain unchanged, ensuring no additional quantization error from lossless decoding. Encoded weights and metadata remain GPU-resident. On block entry, decoding restores packed codes for fused un-packing/dequantization. Temporary BF16 weights for seven language or four vision matrices are released on block exit, re-ducing resident storage and bounding temporary dense weights by the largest active block. III. A. Experimental Setup 

Following ActQuant [7], we evaluate OpenVLA-OFT on four LIBERO suites [21]. Some weights are calibrated on A100; all evaluations use RTX3090. Ten configurations each run 600 closed-loop episodes (150 per suite), totaling 6,000. Metrics include overall and per-suite success, complete-model storage, peak GPU memory, and mean latency over ten fixed inputs. Each call predicts eight actions; timing excludes observation preprocessing and action postprocessing.

Table III reports deployment efficiency. Memory. At W1.5 ∗,quantization reduces complete-model storage from 15.457 to 2.656 GB; lossless coding further reduces it to 2.534 GB (6.10 × compression). Peak GPU memory falls from 16.082 to 3.537 GB (78.0%), as block-wise recovery bounds tempo-rary BF16 weights. Ratios include all model parameters and quantization metadata. 

Execution. Uncoded W4–W1.5 ∗ configurations take 243.6– 254.4 ms versus 187.3 ms for BF16. This narrow latency range is consistent with execution dominated by recovery and BF16 matrix multiplication rather than packed weight size. 

Storage–latency trade-off. Coding raises W1.5 ∗ latency from 250.5 to 310.4 ms and W2.5 latency from 245.2 to 473.9 ms, showing configuration-dependent overhead. W1.5 ∗

offers the smallest footprint at 310.4 ms and 25.5% success; greater storage compression therefore does not necessarily accelerate inference. Coding saves 0.122 GB at W1.5 ∗ for 59.9 ms additional latency, compared with 0.204 GB and 228.7 ms at W2.5. Storage gains must therefore be assessed jointly with decoding cost. Published OpenVLA-OFT times on RTX4090 range from 152.6 ms (NF4) to 379.5 ms (LLM.int8()) [22]. These LLM-only rollout measurements provide context rather than amatched speedup comparison. IV. C ONCLUSION 

We presented Action-Guided Quantization (AGQ) for ultra-low-bit VLA deployment. AGQ uses action sensitivity and a measured proxy for weight recovery cost to guide matrix-wise bit allocation, complemented by per-channel calibra-tion, grouped lossless coding, and block-wise recovery. On LIBERO, AGQ outperforms the compared baselines at shared precisions below four bits and achieves 70.5% task success at W2.5.
