## 摘要
NVFP4 是一种颇具吸引力的数据类型，适用于大语言模型（LLM）推理，兼具紧凑存储和原生张量核心加速能力。然而，使用 NVFP4 保持精度需要精细的量化。在本工作中，我们提出了一种新颖的量化方案，称为面向 NVFP4 的优化平滑与缩放（OSFP4）。对于每个线性投影，它使用一个对角平滑矩阵，其元素经过优化，以最小化 NVFP4 下矩阵乘积的平方量化误差，并考虑所采用的舍入过程（最近舍入或 GPTQ 风格的逐次干扰消除）。这需要对平滑元素以及块缩放进行联合优化，而通过分析乘性抖动的 FP4 量化器而非固定的确定性量化器，可以促成这一优化。实验表明，在相应的量化设置下，OSFP4 在所评估的对比方法中取得了最高的平均准确率，同时在所测量的工作负载上保留了厂商 NVFP4 约 94-97% 的预填充吞吐量。我们的代码可在 https://github.com/neriahbd/OSFP4 获取。

## Abstract
NVFP4 is an attractive datatype for large language model (LLM) inference, offering compact storage and native tensor-core acceleration. However, preserving accuracy using NVFP4 requires careful quantization. In this work we develop a novel quantization scheme called Optimized Smoothing and Scaling for NVFP4 (OSFP4). For each linear projection it uses a diagonal smoothing matrix whose entries are optimized to minimize the squared matrix-product quantization error under NVFP4, taking into account the rounding procedure that is used (either round-to-nearest, or GPTQ-style successive interference cancellation). This requires performing joint optimization on the smoothing entries as well as the block scales, which is facilitated by analyzing a multiplicative-dither FP4 quantizer instead of the fixed deterministic one. Experiments show that OSFP4 achieves the highest average accuracy among the evaluated competitors in the corresponding quantization settings, while retaining approximately 94-97\% of vendor NVFP4 prefill throughput on the measured workloads. Our code is available in https://github.com/neriahbd/OSFP4

## 1. 核心问题与研究动机

- **背景**：低比特数据格式（尤其是 FP4）在大语言模型（LLM）推理中日益流行，因为它能减少存储与内存带宽需求，并通过专用硬件加速矩阵乘法。NVFP4（E2M1 格式，每 16 个元素共享一个 E4M3 块缩放因子）是 NVIDIA Blackwell 系列硬件上的重要格式。
- **核心问题**：FP4 只有 2 个指数位（E2M1），动态范围过小，直接量化会造成明显精度损失。业界常用的 absmax-to-6 缩放规则虽然能防止饱和，但会让幅值小于最大幅值 1/24 的元素被量化为 0，且即便在平衡向量中，也存在多个可用的块缩放值，精心优化可显著降低 MSE。
- **整体含义**：作者提出 OSFP4（Optimized Smoothing and Scaling for NVFP4），通过联合优化对角平滑矩阵与块缩放因子，在保持 NVFP4 原生推理效率的同时尽量恢复精度。与 SmoothQuant 主要平衡无穷范数不同，这里对角矩阵的作用是让同一量化组（16 个连续元素）内的分布更均衡，从而让 E4M3 块缩放更好地降低 MSE。

## 2. 方法论

### 2.1 核心思想

- 对每个线性投影，引入对角平滑矩阵 $A$，将权重变为 $WA^{-1}$、激活变为 $AX$（类似 SmoothQuant）。
- 关键难点：FP4 与 INT 不同，其误差主要由有限动态范围而非无穷范数决定，因此需要全新的优化准则。
- 为便于优化，作者分析了一个**乘性抖动（multiplicative-dither）的 FP4 量化器** $\tilde{Q}_{FP4}(x)=2^U Q_{FP4}(2^{-U}x)$，其归一化 MSE 函数 $\phi(x)$ 在区间 $I_{FP4}=[7/4,7]$ 上达到最小值 $\phi_{\min}\approx0.010723$，且是光滑可导的，便于梯度优化。
- 通过 Lemma 1 建立了随机量化器与确定性量化器之间的联系：对任意 $x$，存在 $\beta\in[1,2)$ 使得确定性量化误差不超过随机量化器的期望误差。

### 2.2 关键技术细节

- **矩阵乘积误差分解**：将误差写为 $e\approx e_W AX + WA^{-1}e_X$，忽略二阶项 $e_We_X$。
- **RTN 下的损失函数**：对每个组 $\ell$，损失为
  $$L^{RTN}_{W_\ell}=\sum_{r=1}^{16}\sigma^2_{X_\ell}(r)\sum_{i=1}^{m}W_\ell(i,r)^2\phi\!\left(\frac{W_\ell(i,r)}{\gamma^{(i)}_{W_\ell}\alpha^{(r)}_\ell}\right)$$
  其中 $\sigma^2_{X_\ell}(r)$ 是校准激活的方差。
- **SIC（GPTQ 风格逐次干扰消除）下的损失**：将上式中的 $\sigma^2_{X_\ell}(r)$ 替换为 $U^2_\ell(r)$，其中 $U$ 是 $\Sigma_X=U^\top U$ 的上三角 Cholesky 因子，$U^2_\ell(r)$ 是坐标 $t$ 从后续坐标预测的最优误差方差，满足 $U^2_\ell(r)\le\sigma^2_{X_\ell}(r)$。这使优化能感知实际使用的舍入方式。
- **总损失**：W4A16 用 $L_{W-RTN}$ 或 $L_{W-SIC}$；W4A4 额外加上激活量化项 $L^{RTN}_{X_\ell}$。所有损失按 16 元素组完全解耦为 $L$ 个独立子问题。
- **两阶段优化流程**：
  1. **连续优化**：以 $\log$ 参数化 $\alpha,\gamma_W,\gamma_X$，用 Adam（80 次迭代，学习率 0.12）联合优化 $A$ 与块缩放，$\phi$ 通过查表 + 线性插值实现可微评估。
  2. **离散 E4M3 尺度选择**：固定优化后的 $A$，在每个连续尺度附近区间 $[\gamma/1.2,\gamma/0.3]$ 内搜索最佳 E4M3 权重尺度；SIC 情形使用 Algorithm 1 逐块选择尺度并同步量化。
- **激活缩放**：默认使用 absmax-to-6 在线实时确定，全局缩放因子由校准最大值得出；也可与 ScaleSweep/ScaleSearch 等在线搜索方法结合。

### 2.3 算法流程（文字说明）

- 收集校准激活，估计 $\Sigma_X$；W4A4 时另取 $k$ 个激活向量构成 $X$。
- 初始化 $A=I_n$，$\Gamma_W,\Gamma_X$ 为 absmax-to-6。
- 对每个 16 元素组独立执行 Adam 联合优化。
- 归一化后，对权重做精细 E4M3 尺度搜索（RTN 用逐行 MSE 最小化，SIC 用 Algorithm 1）。
- 激活量化在推理时用固定全局缩放 + 每 16 元素 absmax-to-6。

## 7. 优点

- **理论贡献扎实**：提出乘性抖动 FP4 量化器，推导出光滑且可微的 $\phi$ 函数，并严格证明其在 $[7/4,7]$ 上达到最小值，为联合优化提供数学基础。
- **损失函数设计巧妙**：损失按 16 元素组完全解耦，可将 $n/16$ 个独立子问题并行优化；且损失形式能感知 RTN/SIC 舍入方式，SIC 情形通过 Cholesky 因子 $U$ 捕捉反馈效应。
- **两阶段策略合理**：连续优化指导平滑矩阵与初始尺度，离散 E4M3 搜索补偿随机量化器与实际确定性量化器之间的差距。
- **工程落地性强**：对角平滑比旋转、PCA、密集小矩阵等变换更便宜，可融合进 LayerNorm/RMSNorm；提供 LLM Compressor 插件与 vLLM 插件，支持实际部署。
- **实验覆盖广**：5 个模型、多种精度配置、多 benchmark，且包含预测损失与实测误差的一致性验证。
- **效率损失小**：仅损失 3–6% prefill 吞吐，精度提升明显，性价比高。
