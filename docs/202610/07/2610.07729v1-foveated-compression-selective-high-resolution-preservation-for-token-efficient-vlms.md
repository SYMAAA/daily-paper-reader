## 摘要
视觉令牌是视觉语言模型推理成本的主要来源之一，然而简单的图像下采样仍然是一个出奇强大的压缩基线。这引出一个互补的问题：在固定令牌预算下，应在何处保留视觉保真度？我们提出中央凹压缩，它只对全分辨率图像编码一次，并用原生分辨率与压缩分辨率的视觉令牌混合来表示图像。一个行为自蒸馏的中央凹合并器压缩局部视觉令牌，同时保持与其原生对应令牌的兼容性；一个轻量级中央凹选择器在穷举式预算匹配干预监督下，从九个空间单元中选择一个以原生分辨率保留。在11.11%视觉令牌下，均匀中央凹压缩与等令牌下采样相比没有显著的配对差异。在20.99%时，学习到的选择器显著优于随机和固定分配，但仍低于强全图缩放，表明局部保真度并非普遍更优。一个预算匹配的区域选择预言机达到82.73的宏准确率，而学习到的选择器为69.61，揭示出在同一空间动作空间内仍有相当大的提升空间。匹配探测进一步表明，用于预测压缩何时会破坏答案的信号，在语言模型计算之后比在轻量级免预填充选择器中更容易获得。这些结果揭示了区域选择与压缩区域保真度方面的互补瓶颈。

## Abstract
Visual tokens are a major source of inference cost in vision-language models, yet simple image downsampling remains a surprisingly strong compression baseline. This raises a complementary question: under a fixed token budget, where should visual fidelity be preserved? We introduce Foveated Compression, which encodes a full-resolution image once and represents it with a mixture of native- and compressed-resolution visual tokens. A behaviorally self-distilled Foveated Merger compresses local visual tokens while preserving compatibility with their native counterparts, and a lightweight Foveated Selector chooses one of nine spatial cells to retain at native resolution using exhaustive budget-matched intervention supervision. At 11.11% visual tokens, uniform Foveated Compression shows no significant paired difference from iso-token downsampling. At 20.99%, the learned selector significantly outperforms random and fixed allocation, but remains below strong whole-image resizing, showing that localized fidelity is not universally preferable. A budget-matched region-choice oracle reaches 82.73 macro accuracy versus 69.61 for the learned selector, revealing substantial headroom within the same spatial action space. Matched probing further shows that signals predicting when compression breaks the answer are substantially more accessible after language-model computation than to the lightweight prefill-free selector. These results expose complementary bottlenecks in region selection and compressed-region fidelity.

# 论文总结：Foveated Compression: Selective High-Resolution Preservation for Token-Efficient VLMs

## 一、核心问题与整体含义（研究动机与背景）

- **背景**：视觉语言模型（VLM）处理高分辨率图像时会产生数百至数千个视觉令牌，成为语言模型预填充成本与显存占用的主要来源。为此已有大量视觉令牌剪枝、合并、重采样与学习式压缩工作。
- **关键矛盾**：VTC-Bench 等工作表明，简单的整图下采样竟能匹配甚至超越复杂压缩方法。这说明原生分辨率并非处处必需，全局覆盖与均匀降质已能保留大部分任务所需信息。
- **核心问题**：在固定视觉令牌预算下，**应把有限的保真度预算花在哪里**？作者通过诊断实验发现，高分辨率的价值存在显著空间差异：许多样本在激进降质后仍正确，另一些则只有在恢复局部细节后才能答对，且最佳保留区域因样本而异。
- **整体含义**：论文把问题从“保留多少令牌”推进到“在何处保留原生保真度”，提出在**单次全分辨率编码**内部进行空间保真度分配的 Foveated Compression 框架，并系统评估其能力与当前瓶颈。

## 二、方法论

### 核心思想
- 对全分辨率图像**只编码一次**，用“原生分辨率令牌 + 压缩分辨率令牌”的混合表示图像；在固定预算下选择一个 3×3 空间单元恢复为原生令牌，其余保持压缩，无需重新编码或额外高分辨率视觉前向。

### 关键技术细节

- **Foveated Merger（中央凹合并器）**
  - 在视觉编码器 patch 网格上，将每个 3×3 原生令牌块压缩为 1 个令牌，得到原生序列的 11.11%。
  - 公式：对 3×3 邻域做均值池化，再加一个学习到的残差变换（RMSNorm → 线性层 → GELU → 线性头），残差头零初始化，使模块从纯均值池化出发。
  - 压缩后特征再经过 Qwen 冻结的 2×2 视觉 merger，输出 3584 维压缩令牌；可训练参数 32.77M。
  - **行为自蒸馏**：只训练 merger，视觉编码器、原生视觉 merger、语言模型全部冻结。冻结模型生成贪心教师答案，压缩模型对同一序列做 teacher-forcing，最小化两者逐位置下一 token 分布的 KL 散度，**不使用真实答案监督**。

- **Foveated Selector（中央凹选择器）**
  - 目标：从 9 个粗粒度空间单元中选一个以原生分辨率保留。
  - 每个压缩单元构造 512 维视觉描述符，融合四项信息：原生内容均值、压缩内容、压缩引起的差异、归一化二维坐标；问题令牌取自冻结语言模型嵌入表，截断至 48 个令牌并投影。
  - 视觉描述符经 8 头交叉注意力与问题交互，再经深度可分离 3×3 卷积加入局部空间上下文，最后由打分 MLP 输出每个单元一个 logit；单元得分取所属压缩单元 logit 的均值，选最高分单元。
  - 选择器可训练参数 10.8M，**不需要额外语言模型前向**。
  - **干预式监督**：对每个训练样本穷举评估全部 9 个确定性 K=1 动作，记录达到最高分的获胜单元集合 W；全九者并列的样本丢弃，部分并列保留为集合值目标，用带并列感知的交叉熵损失训练。

- **混合分辨率构建**
  - 被选单元内的每个压缩单元替换为其对应的 3×3 原生令牌块，其余保持压缩；两者共享同一 3584 维接口，无需重编码或额外投影。
  - 令牌预算：若原生序列含 N 个令牌，恢复九分之一单元后 N_mix = N/9 + 8N/81 = 17N/81，即恰好 **20.99%**。
  - 原生与压缩令牌共享原生视觉网格坐标系以支持 M-RoPE：原生令牌用单位步长坐标，压缩令牌用其 3×3 块左上角坐标，保持其他视觉与文本位置不变。

## 六、主要结论与发现

- **均匀压缩与等令牌下采样持平**：11.11% 令牌下，Foveated Compression 宏准确率 64.62，Iso-Token Downsample 64.86，配对差异不显著（95% CI [-0.586, 0.521]），但任务级行为不同（前者在 GQA/POPE/ChartQA 更强，后者在 OCRBench/MME 更强）。
- **学习到的空间选择有效但有限**：20.99% 预算下，选择器 69.61，显著优于随机 67.98（+1.62）和训练集固定单元 68.48（+1.13），说明空间偏好可学。
- **局部高保真并非普遍更优**：强整图缩放仍更好——Matched-Budget Downsample 70.99（+1.38），2× Downsample 72.43（+2.82）；但选择器在 ChartQA 上反超（57.84 vs 53.48），说明当证据集中时局部保真有效。
- **选择空间存在巨大上界**：K=1 oracle 达 82.73，比学习选择器高 13.12 分，说明同一动作空间内存在大量更优区域选择。
- **压缩失败信号的可获得性差异**：prefill-free 选择器信号 AUC 仅 0.5239（OOF 0.5476），而首 token 解码器熵 AUC 0.7651（OOF 0.8072）；压缩敏感信息在语言模型计算后显著更易获得。
- **互补瓶颈**：区域选择（选择器—oracle 差距）与压缩区域保真度（OCRBench 上落后下采样）是两个独立瓶颈。

## 七、优点

- **问题视角新颖**：将视觉令牌压缩从“保留多少”推进到“在何处保留保真度”，并给出固定预算下的可控实验框架。
- **表示设计巧妙**：特征空间压缩保留了同一全分辨率编码内对原生令牌的直接访问，使混合分辨率替换无需重编码或额外投影，且原生/压缩令牌共享同一接口与坐标系统。
- **监督信号扎实**：用穷举预算匹配干预生成选择器监督，而非启发式或注意力代理；并列感知的集合值目标保留部分并列信息。
- **对比公平严谨**：固定 K=1 预算使所有候选区域动作令牌成本完全相同；配对 bootstrap 统计；明确区分可部署方法与 oracle 上界；报告 oracle 差距而非夸大结果。
- **诚实报告负面结果**：明确指出选择器仍不如整图缩放、prefill-free 信号弱、端到端算力不占优。
- **消融与诊断充分**：行为训练带来 +5.57 宏点，并列监督 +1.24 宏点，问题内容无显著增益，这些结论清晰且可复现。

## 八、不足与局限

- **性能未超越强基线**：学习选择器低于匹配预算下采样和 2× 下采样；局部原生保真并非普遍更优。
- **选择信号瓶颈**：压缩敏感信号在语言模型预填充前仅弱可获得（AUC ≈ 0.52），解码器侧信号虽强但只能在生成开始后获得，无法用于单次前向的选择器。
- **单单元恢复能力有限**：保留一个原生单元无法恢复其余八个压缩区域丢失的信息，OCRBench 等任务上压缩区域保真度不足。
- **算力不对等**：令牌比率仅衡量进入语言模型的视觉令牌数；Foveated Compression 仍执行一次全分辨率视觉编码器，而下采样同时降低视觉编码器成本，因此墙钟时间对比有利于基线，论文不主张端到端效率优势。
- **覆盖范围有限**：仅评估一个冻结 VLM 骨干与固定 K=1 预算；自适应预算、更多骨干、训练式端到端方案未探索。
- **oracle 不可部署**：82.73 的 oracle 使用测试时观测结果，仅作为上界参考，不能直接作为方法优势。
- **潜在偏差风险**：K=1 动作空间固定为 3×3 网格，选择粒度较粗；空间信息性样本仅占 21.5%，大量样本对区域选择不敏感，可能稀释学习信号。
