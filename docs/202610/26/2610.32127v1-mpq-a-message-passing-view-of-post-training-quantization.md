## 摘要
训练后量化（PTQ）是一种高效部署大语言模型的关键技术，因为它无需重新训练即可将权重压缩为低比特表示。现有的PTQ求解器，包括GPTQ、LDLQ和块坐标下降，在考虑相邻块之前就将每个权重块确定为单个码字，从而未探索接近最优的替代方案。在这项工作中，我们将逐行PTQ建模为离散码本上的后验推断，其中现有求解器对应于零温度、硬判决极限，即每个块仅保留最优码字。我们提出消息传递量化（MPQ），它在推断过程中保留跨块的软后验信息，并仅在输出阶段确定硬码字。MPQ首先使用向量近似消息传递来计算近似的块级后验，然后通过精确的块坐标下降来细化硬判决初始化。在Llama、Qwen和Mistral系列的稠密语言模型上，针对2比特格点和3比特、4比特标量量化，MPQ在困惑度和零样本准确率上优于强硬判决基线，并且与激活感知缩放和非相干处理等预处理技术良好结合。我们的实现可在 https://github.com/poseidonchan/MPQ 获取。

## Abstract
Post-training quantization (PTQ) is a key technique for efficiently deploying large language models, as it compresses weights into low-bit representations without retraining. Existing PTQ solvers, including GPTQ, LDLQ, and block coordinate descent, commit each weight block to a single codeword before its neighbors are considered, leaving near-optimal alternatives unexplored. In this work, we cast row-wise PTQ as posterior inference over discrete codebooks, in which existing solvers correspond to a zero-temperature, hard-decision limit retaining only the top codeword per block. We propose Message-Passing Quantization (MPQ), which preserves soft posterior information across blocks during inference and commits to hard codewords only at the output stage. MPQ first uses vector approximate message passing to compute approximate blockwise posteriors, then refines a hard-decision initialization by exact block coordinate descent. Across 2-bit lattice and 3- and 4-bit scalar quantization on dense language models from Llama, Qwen, and Mistral families, MPQ improves perplexity and zero-shot accuracy over strong hard-decision baselines, and composes favorably with preprocessing techniques such as activation-aware scaling and incoherence processing. Our implementation is available at https://github.com/poseidonchan/MPQ.

## 1. 核心问题与研究动机

- **背景**：训练后量化（PTQ）无需重训即可把大语言模型权重压到 2–4 比特，是低资源部署的关键技术。近年进展主要集中在**预处理**（AWQ、SmoothQuant 等激活缩放）、**非相干处理**（QuIP/QuaRot/SpinQuant 的旋转）、**码本设计**（E8P12、QTIP）和**跨层误差目标**（YAQA、Qronos）。
- **核心问题**：**离散求解器（solver）环节进展缓慢**。GPTQ、LDLQ、块坐标下降（BCD）等本质上都是“硬判决”求解器：逐块顺序量化，在尚未考虑相邻块时就立即把当前块锁定到单一码字，再贪心补偿误差。
- **危害**：在极低比特下码字稀少、多个码字局部误差接近，且 Hessian 强耦合使某块的最优选择依赖邻居。一旦早期选错，硬判决求解器没有任何机制回溯，只能沿一条离散轨迹走到黑。
- **论文主张**：应让求解器在提交硬判决前，对每个块维护**软分布**并让相邻块的分布相互作用。作者把逐行 PTQ 重新表述为**离散码本上的后验推断**，指出 GPTQ/LDLQ/BCD 只是该后验的**零温度（β→∞）硬判决极限**，从而自然引出有限温度的消息传递求解器。

## 2. 方法论：MPQ

### 2.1 统一概率视角

- 逐行 PTQ 目标：$\min_{\hat w_b\in\mathcal C_b}\ \tfrac12\|Xw-X\hat w\|_2^2$，权重行被划分为 $B=n/d$ 个块，每块取自有限码本 $\mathcal C_b$（标量网格 $d=1$，或 E8P12 等 $d=8$ 的格点码本）。由于 $X^\top X$ 的非对角结构耦合所有块，这是一个组合优化问题。
- 引入**有限温度 Gibbs 测度**：
  $p_\beta(\hat w\mid w,X)\propto \exp\{-\beta E_w(\hat w)\}\prod_b \rho_b(\hat w_b)$，
  其中参考测度 $\rho_b(c)\propto \exp\{-\|c-w_b\|^2/(2\tau^2\sigma_b^2)\}$ 以宽度 $\tau\sigma_b$ 锚定在原始权重附近。
- 该测度等价于高斯似然 $Xw\sim\mathcal N(X\hat w,\beta^{-1}I)$ 下的后验；**β→∞ 时收敛到原问题的最小值集合**。因此 GPTQ/LDLQ/BCD 可视为该 MAP 问题的近似零温度求解，区别仅在块调度与块间耦合的近似方式。有限 β 下后验保留块均值、方差与近优码字的概率质量——这正是 MPQ 要传播的信息。

### 2.2 两阶段算法

**第一阶段：秩空间有限温度 VAMP**

- 令 $A:=X,\ y:=Xw$，问题化为 $\min_{x\in\mathcal C_{\text{prod}}}\|y-Ax\|_2^2$。目标只通过秩 $r$ 坐标 $\Sigma_A V^\top x$ 依赖 $x$，故用紧 SVD $A=U\Sigma_A V^\top$，令 $T=\Sigma_A V^\top,\ \tilde y=U^\top y$，全部计算在 $r\times n$ 的 $T$ 上进行，避免原始大矩阵。
- 每次迭代在**逐块离散去噪器**与**高斯线性模块**间交替：
  - 去噪器：给定高斯腔 $ (r_1^t,\gamma_1^t)$，各块独立计算
    $q_b^t(c)\propto \rho_b(c)\exp\{-\tfrac{\gamma_1^t}{2}\|c-r_{1,b}^t\|^2\}$，
    进而得到后验均值 $\hat x_{1,b}^t$、协方差 $\Sigma_{1,b}^t$ 与平均敏感度 $\alpha_1^t=\frac{\gamma_1^t}{n}\sum_b \mathrm{tr}(\Sigma_{1,b}^t)$。
  - 外信息更新把 $(\hat x_1,\alpha_1)$ 转为线性模块的消息 $(r_2,\gamma_2)$；线性模块求解
    $\hat x_2=(\beta H+\gamma_2 I)^{-1}(\beta g+\gamma_2 r_2)$，在秩空间有闭式解（沿奇异方向逐坐标缩放），敏感度 $\alpha_2=\frac1n\mathrm{tr}[\gamma_2(\beta H+\gamma_2 I)^{-1}]$；再做一次外信息更新回到 $ (r_1,\gamma_1)$。
  - **逆温度 β 不手工设定**，而按高斯似然的 EM M-step 在迭代中在线更新（含残差平方项与后验迹修正项）；均值与精度做几何阻尼，精度裁剪到固定区间，并对退化腔做重试/缩放保护。
- 默认 **16 次 VAMP 迭代**，全程保持所有块软值。

**第二阶段：零温度精确局部精修**

- 在最终腔上取**逐块边际 MAP** 得到硬初始化：$x_b^{(0)}=\arg\max_{c\in\mathcal C_b} q_b^{T_{\text{vamp}}}(c)$。注意边际众数不构成联合 MAP（Hessian 耦合块）。
- 在原始 PTQ 目标上做**精确块坐标下降**：维护残差 $u=\tilde y-Tx$，对块 $b$ 枚举码本使 $F_b(c)=\tfrac12\|u-T_b(c-x_b)\|_2^2$ 最小，并增量更新残差；最多 $S_{\text{CD}}$ 轮、无改动即早停。默认 **3 轮 CD**。
- 附录证明：块更新等价于在当前残差诱导的**马氏度量下做最近码字搜索**，中心随迭代移动，因此仍是局部搜索；VAMP 的价值不在于替代局部搜索，而在于**从更好的吸引域进入精修**。

### 2.3 理论分析（定性指导）

- **定理 5.1（后验集中/热启动精度）**：在 ROI（右正交不变）代理模型与 VAMP 状态演化不动点 $ (\gamma_1^\star,\gamma_2^\star)$ 下，每块等效为 AWGN 信道；对任意竞争码字 $j$，块级 MAP 错误概率满足
  $\mathbb P(\hat j_{\text{MAP}}\neq j^\star)\le \sum_{j\neq j^\star}\exp\{-\gamma_1^\star\|\delta_j\|^2/8\}$。
  即有效精度越高、码字间距越大，热启动越可靠；码本稠密时上界失效，残余错误交给 CD。
- **命题 5.2（预处理对线性模块的影响）**：对对角缩放路径 $H_t=D_tH_0D_t$（$D_t=e^{tL}$），
  $\frac{d}{dt}E_{\text{lin}}(H_t,\gamma)=-\frac{2\beta_0}{n}\mathrm{tr}[LH_t(\beta_0H_t+\gamma I)^{-2}]$。
  推论给出按坐标的非负核 $\kappa_i$ 加权形式：$\ell_i>0$ 的坐标降低 $E_{\text{lin}}$，$\ell_i<0$ 的升高。结合正交不变性引理，AWQ+RHT 流水线可化归为未旋转路径分析。
