## 摘要
将训练后量化（PTQ）到 FP4 已成为降低大语言模型推理成本的关键技术，尤其是在原生支持 FP4 张量核的 Blackwell GPU 上。然而，直接 PTQ 到 FP4 仍会留下明显的精度差距。近期关于 SVDQuant 的工作通过加入由 SVD 获得的高精度低秩校正，缓解了扩散模型因 FP4 量化引入的误差。然而，这种高精度低秩校正每个秩需要较多比特，并且与主 FP4 GEMM 运行在同一批张量核上。我们提出 BiLoCo，一种低秩校正方法，其左右因子以二值 ±1 符号向量而非 BF16 数值存储。这种带符号格式使每个秩一分量的存储占用降低到 1/16，并且由于校正现在由加法/减法组成，因此可以在 CUDA 核上与 FP4 张量核 GEMM 并发执行。在 4B--72B 的大语言模型上，BiLoCo 在 PTQ 中达到或优于内存匹配的 SVDQuant。我们在 B300 上将 BiLoCo 实现为单个融合内核：其中 FP4 GEMM 在张量核上运行，位打包校正在同一次内核启动的 CUDA 核上运行，二者在 GEMM 尾声（epilogue）中合并。在批大小为 1 时，对于不超过 512 的每个秩，融合内核最多比仅 FP4 的 GEMM 慢 11%。在秩为 128 时，在批大小不超过 8 的情况下，它最多慢 20%。

## Abstract
Post-training quantization (PTQ) to FP4 has emerged as a key technique for reducing large language model inference cost, especially on Blackwell GPUs, which offer native FP4 tensor core support. Direct PTQ to FP4, however, still leaves a noticeable accuracy gap. Recent work on SVDQuant mitigates the errors introduced through FP4 quantization for diffusion models by adding high-precision low-rank corrections obtained via SVD. However, this high-precision low-rank correction requires many bits per rank, and it runs on the same tensor cores as the main FP4 GEMM. We introduce BiLoCo, a low-rank correction method whose left and right factors are stored as binary ${\{\pm 1\}}$ sign vectors rather than as BF16 numbers. The signed format uses $16{\times}$ less storage per rank-one component, and since the correction now consists of additions/subtractions, this can be run on CUDA cores concurrently with the FP4 tensor-core GEMM. On 4B--72B LLMs, BiLoCo matches or improves memory-matched SVDQuant for PTQ. We implement BiLoCo on B300 as a fused single kernel, where the FP4 GEMM runs on tensor cores, the bit-packed correction on the CUDA cores of the same launch, and the two are combined in the GEMM epilogue. With batch size $1$, the fused kernel is at most $11\%$ slower than the FP4-only GEMM for every rank up to $512$. At rank $128$, it is at most $20\%$ slower up to batch size $8$.

## 一、核心问题与整体含义

- **背景**：Blackwell GPU 原生支持 FP4 张量核，将 LLM 训练后量化（PTQ）到 NVFP4 可显著降低解码阶段的权重搬运开销，但直接量化仍存在明显精度差距。
- **现有方案及其瓶颈**：SVDQuant 用 BF16 低秩分支吸收 FP4 残差中的离群能量，但存在两个问题：
  - 每个秩一分量需 16 bit 存储，固定字节预算下只能覆盖很少的方向；
  - 校正在张量核上以高精度 GEMM 执行，与主 FP4 GEMM 争用同一硬件。
- **关键观察**：LLM 解码（batch 较小）时 FP4 GEMM 是权重带宽受限，张量核等待 HBM，**CUDA 核大量空闲**；两类单元可独立发射指令（FlashAttention-3/4 已利用此特性）。
- **核心问题**：能否设计一种校正格式，使其算术天然适配 CUDA 核的空闲槽位，并在同等存储预算下获得更强的误差校正？
- **整体含义**：论文提出用“多而低精度”的二值秩一分量替代“少而高精度”的 BF16 分量，把校正从乘法变为加减法，实现存储与硬件的双重解耦。

## 二、方法论

### 核心思想
- 将权重分解为 **二值低秩校正 + NVFP4 残差**：
  \(W \approx \sum_{i=1}^{r}\alpha_i u_i v_i^\top + R\)，其中 \(u_i\in\{\pm1\}^m,\ v_i\in\{\pm1\}^n,\ \alpha_i\in\mathbb{R}\)，\(R\) 量化为 NVFP4。
- 推理形式与 SVDQuant 同构，但校正分支变为：
  \(y=\text{FP4-GEMM}(\text{FP4}(x),\text{FP4}(R))+\sum_i \alpha_i u_i(v_i^\top x)\)。
- 因 \(v_i\) 为符号向量，内积 \(v_i^\top x\) 只需按位选择加/减，**无乘法**；左右因子各占 1 bit/元素，每秩存储降至 BF16 的 1/16。

### 关键技术细节
- **动机验证（§3.1）**：在 189 个投影矩阵（Qwen3-4B/14B、Llama-3-8B，9 层 × 7 类投影）上比较等存储预算下的 Frobenius 捕获率 \(\gamma=\|\hat W\|_F/\|W\|_F\)。LLM 权重顶部谱较平坦（\(\sigma_1/\sigma_{32}\) 中位数 1.93–2.24），二值 rank-512 捕获 47–53%，BF16 rank-32 仅 26–29%；且 \(\gamma\) 比值与谱平坦度负相关，支持“秩数量优先于单秩精度”的假设。
- **求解算法（Algorithm 1）**：不显式做 SVD，采用贪心符号剥离：
  1. 初始化 \(R\leftarrow W\)；
  2. 对每个秩：随机初始化 \(v\)，交替执行 \(u\leftarrow\text{sign}(Rv)\)、\(v\leftarrow\text{sign}(R^\top u)\) 共 \(T=5\) 步；
  3. 闭式最优标量 \(\alpha=(u^\top Rv)/(mn)\)，并 deflate：\(R\leftarrow R-\alpha uv^\top\)；
  4. 全部 \(r\) 项完成后，联合重解所有系数：解 \(A\alpha=b\)，其中 \(A_{ij}=(u_i^\top u_j)(v_i^\top v_j)\)、\(b_i=u_i^\top Wv_i\)，加 \(\epsilon I\) 正则，复杂度 \(O(r^3)\)；
  5. 用最终校正后的残差一次性量化为 NVFP4。
- **理论分析（§3.3，附录 B）**：
  - 定理 3.1：符号交替单调提升单秩双线性目标，deflation 的 Frobenius 下降量恰为 \((u^\top Rv)^2/(mn)\)；
  - 命题 3.2：固定符号后全局系数重拟合不会增大残差；
  - 条件性 cut-norm 衰减界（Frieze–Kannan 风格）：若每步符号满足 \(|\cdot|\ge\rho\|R_t\|_\blacksquare\)，则 \(\min_t\|R_t\|^2_\blacksquare\le mn\|W\|_F^2/(\rho^2 r)\)；作者明确声明这只是条件性陈述，不声称启发式达到固定近似比，也不约束 PPL。
- **融合内核（§3.4）**：
  - 基于 CUTLASS SM100 block-scaled FP4 GEMM，每 SM 至多一个 CTA，输出 tile 128×64，激活零填充至 128 行；
  - \(N/64\) 个 GEMM CTA 跑张量核主循环；剩余 SM 上的 side CTA 用 CUDA 核从位打包符号计算 \(z_i=\alpha_i(v_i^\top x)\)，写入带 **epoch tag** 的全局缓冲区（免去每轮清空）；
  - GEMM CTA 的 epilogue warp 在主循环空闲时等待 \(z\)，经打包的 \(u_i\) 展开并加到 FP32 累加器，再 BF16 写出；使用共享内存 16 项查找表（每 4 个秩一组）把 4 次符号选择加法压缩为一次表读；
  - 大 batch（如 \(M=16,r\ge256\)）时退化为所有 CTA 先算校正再跑 GEMM，仍是单次 launch 但不再重叠。

## 三、实验设计

- **模型**：Qwen3-4B、Llama-3-8B、Qwen3-14B、Qwen3-32B、Qwen2.5-72B。
- **量化设置**：SmoothQuant 预平滑（\(\alpha=0.5\)）、\(T=5\)、权重与激活均用 “four over six” NVFP4 分块 MSE 尺度搜索；校准集为 C4 训练集 128 条 × 2048 token。
- **质量评测**：
  - WikiText-2 与 C4 验证集困惑度（2048 token 窗口）；
  - 对 BF16 参考模型的 KL 散度（200 篇 FineWeb 文档，报告均值与 99 分位）；
  - 下游任务：WinoGrande（5-shot）、HellaSwag（10-shot）主表，附录另报 ARC-easy/ARC-challenge/PIQA/WinoGrande/OBQA 五任务。
- **对比方法**：BF16 参考、NVFP4 直接量化、SVDQuant BF16 rank-32（\(b=512\)，内存匹配）；BiLoCo 报 \(r=128\)（1/4 存储）与 \(r=512\)（同存储）。
- **消融与诊断**：四种校正构造方式对比（随机符号+联合重拟合、贪心、贪心+全局重拟合、pm-altmin 10 轮）；秩扫描 \(r=32\)–2048；与 QuaRot/SpinQuant 旋转骨干组合；同秩 BF16 vs 二值因子对照；PTQ 构建耗时分解；逐投影类型 Frobenius 捕获率；cut-norm 前提的 \(\rho_F\) 经验分布。
