## 摘要
视频大语言模型（Video LLM）会将每一帧编码为数百个视觉词元，导致视频推理成本高昂。现有方法通过基于相似度的合并或基于注意力的选择来降低这一成本，但面临两个挑战：层级盲剪枝（Hierarchy-blind Pruning）忽视了区域可压缩性，可能丢弃关键证据；注意力漂移（Attention Drift）中，位置效应和注意力汇会使文本到视觉的注意力偏离任务相关性。我们提出 FoveaTree，一种两阶段、无需训练的视觉词元剪枝框架。首先，合并增益密度估计（Merge-Gain Density Estimation）衡量区域合并造成的特征失真，并构建由四叉树衍生的密度图来指导词元丢弃、合并与保留。其次，注意力树剪枝（Attention Tree Pruning）利用保留下来的单元和继承的树拓扑，在 LLM 中间层细化文本到视觉的注意力，在保留相关区域证据的同时移除低相关性内容。我们在 InternVL3.5-8B 和 Qwen3-VL-8B 上，于五个视频问答基准和一个描述生成基准中，以 50%、30% 和 10% 的视觉词元保留率评估 FoveaTree。FoveaTree 在所有评估设置下均持续取得整体最先进的性能，提供了出色的精度-效率权衡。

## Abstract
Video large language models (Video LLMs) encode each frame into hundreds of visual tokens, making video inference expensive. Existing methods reduce this cost through similarity-based merging or attention-based selection but face two challenges: Hierarchy-blind Pruning, which overlooks regional compressibility and can discard critical evidence, and Attention Drift, where positional effects and attention sinks shift text-to-vision attention away from task relevance. We propose FoveaTree, a two-stage, training-free visual-token pruning framework. First, Merge-Gain Density Estimation measures the feature distortion caused by regional merging and constructs a quadtree-derived density map to guide token dropping, merging, and retention. Second, Attention Tree Pruning uses the surviving units and inherited tree topology to refine text-to-vision attention in intermediate LLM layers, preserving relevant regional evidence while removing low-relevance content. We evaluate FoveaTree on InternVL3.5-8B and Qwen3-VL-8B across five video question-answering benchmarks and one captioning benchmark at 50%, 30%, and 10% visual-token retention. FoveaTree consistently achieves overall state-of-the-art performance across the evaluated settings, offering a strong accuracy-efficiency trade-off.

## 一、核心问题与研究动机

- **背景**：视频大语言模型（Video LLM）由视觉编码器、模态投影器和 LLM 组成。编码器将每帧切成 patch token，投影到语言嵌入空间。视觉序列长度随视频帧数和分辨率增长（如 InternVL3.5-8B 输入 16,384 个视觉 token），直接推高注意力计算量、prefill 延迟和 KV-cache 显存，因此视觉 token 剪枝成为实用推理的关键。
- **现有路线**：一类是相似度合并/丢弃（ToMe、EViT、VisionZip、FrameFusion、STTM），另一类是文本到视觉注意力选择（FastV、MADTP、LearnPruner）。
- **两大痛点**：
  - **层级盲剪枝（Hierarchy-blind Pruning）**：基于成对相似度或轻量网络预测重要性分数，没有显式建模帧内区域的可压缩性。Fig.1 显示这类方法在 OCR、计数、物体识别、详细描述等细粒度领域出现系统性性能缺口（灰色区域），说明它们丢失了跨空间尺度的连贯证据。
  - **注意力漂移（Attention Drift）**：RoPE 位置效应、对邻近/近期 token 的偏好、attention sink 会把查询到视觉的注意力拉向空间边界或序列前部，导致基于 top-k 的剪枝低估并误删任务相关 token；保留率从 50% 降到 30% 时，相关区域会碎片化甚至丢失。
- **整体含义**：论文试图回答“如何在免训练、低保留率下既压缩视觉冗余、又不破坏查询相关的细粒度证据”，并把“区域层级”作为连接查询无关压缩与查询相关选择的桥梁。

## 二、方法论

### 2.1 整体框架
- **两阶段、免训练**：Stage 1 在 decoder prefill 之前做区域压缩（MGDE）；Stage 2 在 LLM 中间层做查询引导的树剪枝（ATP）。两阶段共享同一棵四叉树拓扑，形成“先粗压缩、再按查询细化”的流水线。

### 2.2 第一阶段：合并增益密度估计（MGDE）
- **动机**：用“区域合并造成的特征失真”作为可压缩性信号，替代相似度或学习型打分，无需训练与标签。
- **特征选择**：使用视觉编码器 **layer-0 浅层特征**（Fig.5 在 SigLIP、InternViT、Qwen-VL-ViT 上均显示 layer-0 最能分辨高/中/低密度区域；深层特征语义化但空间定位变弱）。
- **核心计算**：
  - 对特征做 L2 归一化：`z̄ = z / (‖z‖₂ + ε)`。
  - 区域 R 的失真：`D(R) = |B(R)| − ‖Σ_{p∈B(R)} z̄_p‖₂`（用单 token 表示该区域的代价）。
  - 合并增益：`G(R) = D(R) − Σ_{k=1..4} D(R⁽ᵏ⁾)`，即保留四个象限分别表示所带来的收益。
- **四叉树构建**：帧先 padding，再切成不重叠的 8×8 根，按 8→4→2→1 层级分裂；当 `G(R) > γ`（默认 0.005）且森林叶数不超过 `L_max` 时，优先分裂增益最高的区域。
- **密度图与 token 构造**：按终端区域边长 `s(R)` 标注密度等级——`s≥4` 为 DL1（丢弃）、2×2 为 DL2（区域内特征平均池化为 1 个 token）、单 cell 为 DL3（保留）。每个存活单元保留其空间支撑、祖先关系和最早栅格位置；池化只在帧内进行，保持原始时序顺序。

### 2.3 第二阶段：注意力树剪枝（ATP）
- **动机**：MGDE 之后仍可能残留与查询无关内容；但直接用扁平 top-k 会跟随注意力漂移（Fig.7 显示 LearnPruner 偏向边缘 token，而 ATP 的选择更向中心、更空间连贯）。
- **自底向上传播**：
  - 在 decoder 第 ℓ 层（默认 18 层）对问题 token 集合 Q 和所有 head 求平均：`a_v = (1/(|Q|H_ℓ)) Σ_q Σ_h A_{qhv}`。
  - 在每帧内按经验 2%–98% 分位重缩放并裁剪到 [0,1]，得到叶节点相关性 `ρ_v`。
  - 内部节点取后代最大值：`ρ_u = max_{v∈V(u)} ρ_v`，保证强证据区域不会因同区域弱单元而被稀释（附录给出 max 传播的 1-Lipschitz 稳定性证明）。
- **自顶向下切割与合并**：
  - 节点异质性：`δ_u = 1 − (1/n_u)‖Σ_v h_v/‖h_v‖₂‖²`。
  - 分裂优先级：`κ_u = δ_u + ρ_u`——相关性定位查询相关分支，异质性防止合并内部多样的区域。
  - 按优先级扩展树，若完整扩展会超预算，则用“d 个最高优先级子节点 + 1 个残差簇”精确填满预算。
  - 合并簇时按注意力加权隐藏状态，并把结果锚定在最高注意力成分的原始 RoPE 位置上；后续层为压缩后的前缀重新填充 KV cache，前面层的 cache 不受影响。

### 2.4 预算控制
- 每帧预算 `B_t = min(N_t, ⌈rN_t⌉)`，最终输出 `K_t = min(B_t, M_t)`；预算是**硬上界而非配额**，MGDE 存活不足时不填充、不借用其他帧 token，并用 `assert K_t = min(B_t, M_t)` 强制校验（附录 Algorithm 1、Table 14 审计显示所有 backbone 零超预算）。
