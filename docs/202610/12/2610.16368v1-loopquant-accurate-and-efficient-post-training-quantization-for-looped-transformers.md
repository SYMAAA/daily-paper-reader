## 摘要
循环语言模型（LoopLMs）通过递归复用共享 Transformer 模块来提升参数效率，但其在演化循环状态上的重复计算给低比特部署带来了新挑战。现有训练后量化（PTQ）方法大多面向前馈 Transformer 设计，未能考虑跨循环激活动态、异构循环敏感度和递归误差传播，导致低精度下性能显著下降。为解决这些挑战，我们提出 LoopQuant，一种面向 LoopLMs 的循环感知 PTQ 框架，可实现准确高效的低比特量化。LoopQuant 基于三个核心组件：1）跨循环分布规范化（CLDC）在循环状态间学习共享的、利于量化的表示，同时保持参数共享；2）交互感知的逐循环精度分配（ILPA）在固定比特预算下，通过建模任务级循环敏感度和跨循环交互来分配激活精度；3）循环条件任务校准（LCTC）通过轻量级任务空间校准，进一步使量化推理与低比特递归轨迹对齐。跨 LoopLM 架构的大量实验表明，LoopQuant 持续优于现有低比特 PTQ 方法。在 Ouro-2.6B 上，W4A4 的 LoopQuant 在性能上超过所有 W4A8 基线，同时相比朴素 INT4 仅增加 3.4% 的存储开销，却将模型内存降低 65.3%，并相比 BF16 实现 1.7 倍解码加速。这些结果展示了在准确率、压缩率和推理效率之间的良好平衡，为低比特 LoopLM 推理提供了实用且便于部署的解决方案。代码见 [https://github.com/Kishon-zzx/LoopQuant]。

## Abstract
Looped Language Models (LoopLMs) improve parameter efficiency by recursively reusing shared Transformer modules, yet their repeated computation over evolving recurrent states poses new challenges for low-bit deployment. Existing post-training quantization (PTQ) methods, largely designed for feed-forward Transformers, fail to account for cross-loop activation dynamics, heterogeneous loop sensitivity, and recursive error propagation, leading to substantial performance degradation at low precision. To address these challenges, we propose LoopQuant, a loop-aware PTQ framework for accurate and efficient low-bit quantization of LoopLMs. LoopQuant is built on three core components: 1) Cross-Loop Distribution Canonicalization (CLDC) learns a shared quantization-friendly representation across recurrent states while preserving parameter sharing; 2) Interaction-Aware Loop-wise Precision Allocation (ILPA) allocates activation precision under a fixed bit budget by modeling task-level loop sensitivity and cross-loop interactions; and 3) Loop-Conditioned Task Calibration (LCTC) further aligns quantized inference with the low-bit recursive trajectory through lightweight task-space calibration. Extensive experiments across LoopLM architectures demonstrate that LoopQuant consistently outperforms existing low-bit PTQ methods. On Ouro-2.6B, LoopQuant under W4A4 surpasses all W4A8 baselines in performance, while reducing model memory by 65.3% with only 3.4% additional storage overhead over naive INT4 and achieving a 1.7 times decoding speedup over BF16. These results demonstrate a strong balance among accuracy, compression, and inference efficiency, providing a practical and deployment-friendly solution for low-bit LoopLM inference. The code is available at [https://github.com/Kishon-zzx/LoopQuant].

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：循环语言模型（LoopLMs，如 Ouro、Huginn、Nanbeige4.2-3B）通过递归复用同一组 Transformer 层 T 次，以约 L 层的参数获得约 L×T 的有效计算深度，在参数预算受限时兼顾存储效率与推理能力。
- **部署矛盾**：共享模块被反复执行，权重与中间激活被高频访问，因此权重与激活的低比特量化对降低计算与访存成本至关重要；但现有 PTQ 方法（SmoothQuant、QuaRot、SpinQuant、FlatQuant、DartQuant）几乎都为**前馈 Transformer** 设计，隐含假设“层顺序执行、逐层激活统计稳定、可用局部重构目标校准”。
- **LoopLM 打破该假设**，论文归纳出三个关键挑战：
  - **❶ 跨循环激活动态差异**：同一共享模块在不同循环接收的隐藏状态动态范围、离群值幅度与离群通道均不同；单一静态量化参数难以覆盖所有递归状态，而逐循环独立配置又破坏参数共享、增加存储与部署开销。
  - **❷ 循环重要性/敏感度异质**：各循环处于不同递归阶段，对最终预测贡献不同，且早期循环的量化误差会向后传播；统一精度浪费比特预算，仅按局部量化误差分配也无法反映真实任务影响。
  - **❸ 局部量化目标与递归任务行为错配**：单循环局部误差小，仍可能使隐藏状态偏移，沿递归轨迹累积放大，最终造成显著输出误差。
- **整体含义**：论文主张 LoopLM 量化必须同时建模“跨循环激活动态 + 循环敏感度与交互 + 沿真实低比特递归轨迹的校准”，并给出一个可部署的循环感知 PTQ 框架，声称是首个开源的 LoopLM 量化框架。

## 2. 方法论

### 2.1 核心思想与误差分解框架

- 递归形式：`H^(t) = F_θ(H^(t-1))`，t=1…T，输出 `Y = LMHead(H^(T))`；层间记法 `H_l^(t) = F_l(H_{l-1}^(t); θ_l)`，`H_0^(t) = H_{L}^(t-1)`，参数 θ 跨循环共享。
- 定义量化残差 `r_t(H) = F̂_t(H) − F_θ(H)`，并把第 t 循环的扰动拆为：
  - `u_t = ε_loc_t + ε_traj_t`，其中 `ε_loc_t = r_t(H^(t-1))` 为**循环相关局部误差**，`ε_traj_t = r_t(Ĥ^(t-1)) − r_t(H^(t-1))` 为**继承状态漂移导致的轨迹误差**。
- 对任务损失在满精度处做二阶展开：`ΔL ≈ Σ_t g_t^T u_t + ½ Σ_i Σ_j u_i^T C_ij u_j`，`g_t` 为任务敏感度，`C_ij` 为跨循环交互。
- **该分解直接把三个组件对应到三项误差来源**：`ε_loc → CLDC`，`g_t` 与 `C_ij → ILPA`，`ε_traj → LCTC`。这是全文的方法论骨架。

### 2.2 CLDC：跨循环分布规范化

- **目标**：学习一个**所有循环共享**的量化友好几何变换，既改善量化，又不破坏参数共享、不引入逐循环变换的存储。
- **参数化**：`P_m = D_m R_m`，`D_m = Diag(s_m)` 为通道缩放，`R_m R_m^T = I` 为正交旋转；变换激活 `X̃ = X D R`，同时把逆变换吸收进权重 `W̃ = W D^{-1} R`，由正交性保证 `X̃ W̃^T = X W^T`（**满精度函数严格等价**）。
- **正交参数化**：`R_m = R_m^(0) U_m`，`U_m` 为块对角（块大小 32）可学习正交修正；用反对称矩阵 `A = Z − Z^T` 与 **Cayley 变换** `U = (I − A/2)^{-1}(I + A/2)` 保证优化全程正交，无需投影；初始化 `Z=0` 即从恒等修正出发。
- **优化目标（三项相加）**：
  - 归一化重构误差 `E_m^(t)`（量化激活×量化权重 vs 原始乘积的 Frobenius 相对误差）；
  - **鲁棒最坏循环目标** `L_rob = τ·log( (1/T) Σ_t exp(E_m^(t)/τ) )`，τ→0 时趋近 `max_t E_m^(t)`，避免易量化循环掩盖难循环；
  - **跨循环异常同步** `L_sync = (1/T) Σ_t ||p_m^(t) − p̄_m||²`，其中 `p_m,c^(t)` 为通道高百分位幅度归一化后的异常分布，`p̄` 为其跨循环均值（闭式重心），促使各循环离群通道结构一致，利于分组量化；
  - **尺度正则** `L_reg = (1/d_i)||s_m − 1||²`，防止把量化难度过度转嫁给权重。
- **组感知通道重排**：在连续变换固定后，用通道的跨循环对数动态范围签名 `z_m,c = [z^(1)…z^(T)]`，以组内签名方差的鲁棒 log-sum-exp 版本 `L_grp` 为目标；先按最坏动态范围排序初始化，再做**硬置换的局部两两交换精修**，得到 `Π*`，最终 `P* = D* R* Π*`，仍保持函数等价。

### 2.3 ILPA：交互感知的逐循环精度分配

- **目标**：在固定平均激活比特预算下，为各循环分配低精度 `b_L`（A4）或高精度 `b_H`（A8）。
- **轨迹级评估**：对配置 `S`（低精度循环集合），保持权重量化与参数不变，执行完整递归前向，用校准集 token 级 NLL `v(S)` 作为代价——该量天然包含循环功能、误差传播与联合精度效应，而非局部重构误差。
- **Shapley 式敏感度**：对随机排列 π，边际退化 `Δ_t^(π) = v(S_t^(π) ∪ {t}) − v(S_t^(π))`，`φ_t = (1/T!) Σ_π Δ_t^(π)`，实践中用蒙特卡洛采样（默认 100 次排列）近似。
- **成对递归交互**：`Γ_ij = E_π[Δ_ij^(π) − Δ_i^(π) − Δ_j^(π)]`，正值表示联合降精度有超加性退化；再用边际退化经验方差归一化为 `Γ̃_ij` 以消除尺度偏差。
- **离散代理目标**：`J(q) = Σ_t q_t φ_t + λ Σ_{i<j} q_i q_j Γ̃_ij`，约束 `Σ_t [b_H − (b_H − b_L) q_t] = T·b`；T<5 时**精确枚举**，否则**贪心**逐次选择边际代价最小的循环降精度，复杂度 O(T²)；分配结果推理期固定。

### 2.4 LCTC：循环条件任务校准

- **目标**：在 CLDC 变换与 ILPA 精度固定、量化权重冻结的前提下，只优化**轻量静态**的逐模块逐循环参数 `Γ_{m,t} = {c_{m,t}, g_{m,t}, β_{m,t}}`（分组裁剪、增益、偏置），不依赖 token 历史、无在线优化。
- **校准映射**：`ŷ_{m,t} = g_{m,t} ⊙ [Ŵ_m · Q_{b_t}(x_{m,t}; c_{m,t}) + b_m] + σ_{m,t} ⊙ β_{m,t}`。
- **任务空间缺陷传输**：定义后缀算子 `S_{t+1}(·)`（把第 t 循环输出经其余满精度计算送到 logits），缺陷 `d_t(h) = S_{t+1}(F̂_{t,Γ}(h)) − S_t(h)`；干净状态缺陷 `a_t = d_t(H^(t-1))` 度量直接任务影响。
- **轨迹敏感度**：用继承漂移 `δ_{t-1} = Ĥ^(t-1) − H^(t-1)` 定义**割线** `s_t(α) = [d_t(H^(t-1)+αδ_{t-1}) − d_t(H^(t-1))]/α`，其一阶极限为 `J_{d_t}·δ_{t-1}`，即轨迹误差在任务空间的一阶近似；第一个循环 `δ_0 = 0`，轨迹项自动关闭。
- **Fisher 加权度量**：`F(p) = Diag(p) − pp^T`，`E_F(v) = v^T F v`，是 KL 散度的二阶近似（`D_KL ≈ ½ v^T F v`），使同等欧氏幅度的 logit 扰动按其对预测分布的实际影响加权。
- **总损失**：`L_LCTC = L_KD + λ_NLL L_NLL + λ_a L̃_anchor + λ_t L̃_traj + λ
