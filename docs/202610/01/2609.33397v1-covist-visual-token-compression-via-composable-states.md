## 摘要
视觉Token压缩通过用更少的Token表示图像，降低了视觉-语言模型的推理成本。然而，大多数现有方法将视觉Token压缩为一个缩减后的集合，使得每个Token所表示的视觉证据量及其原始空间上下文变得隐含。因此，压缩表示并未显式编码每个代表Token承载多少视觉信息，也未编码其在原始图像中的位置。这种局限在单次缩减后就会出现，当压缩在解码器各层中重复进行时更为明显。为解决该问题，我们提出CoViST，一个免训练框架，将压缩图像表示为可组合的视觉状态。具体而言，该状态将代表特征与原始位置、有效贡献权重以及可复用的选择元数据相结合。CoViST通过覆盖率引导的选择和基于守恒的贡献组合来构建该状态，并将其贡献与位置信息显式融入解码器注意力。该状态的每个组成部分在连续缩减下仍保持其可解释性，使得同一形式化方法既能支持预填充前的固定压缩，也能支持解码器内的渐进式压缩。在七个LLaVA-1.5-7B基准上的实验结果表明，CoViST-Fixed在192、128和64个Token时分别保留了未压缩性能的99.9%、99.5%和98.1%，而CoViST-Pro在相应的层平均预算下分别保留了99.8%、99.9%和99.1%，在各自预算设置下优于最先进方法。代码将公开发布。

## Abstract
Visual token compression lowers the inference cost of vision--language models by representing images with fewer tokens. However, most existing methods compress visual tokens to a reduced set, leaving the amount of visual evidence represented by each token and its original spatial context implicit. Therefore, the compressed representation does not explicitly encode how much visual information each representative carries or where it lies in the original image. This limitation arises even after a single reduction and becomes more pronounced when compression is repeated across decoder layers. To address this issue, we propose CoViST, a training-free framework that represents a compressed image as a composable visual state. Specifically, the state combines representative features with original positions, effective contribution weights, and reusable selection metadata. CoViST constructs this state through coverage-guided selection and conservation-based contribution composition, and explicitly incorporates its contribution and positional information into decoder attention. Each component of the state retains its interpretation under successive reductions, enabling the same formulation to support both fixed compression before prefill and progressive compression within the decoder. Experimental results on seven LLaVA-1.5-7B benchmarks show that CoViST-Fixed retains 99.9\%, 99.5\%, and 98.1\% of uncompressed performance at 192, 128, and 64 tokens, respectively, and CoViST-Pro retains 99.8\%, 99.9\%, and 99.1\% at the corresponding layer-average budgets, outperforming state-of-the-art methods under their respective budget settings. Code will be released publicly.

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言模型（VLM）将图像编码为大量视觉 Token，每个解码器层都要处理，KV Cache 也需长期保存，导致推理成本高。视觉 Token 压缩旨在用更少 Token 表示图像。
- **核心问题**：现有免训练压缩方法大多只把视觉 Token 缩减为一个代表集合，但**没有显式记录每个代表 Token 承载了多少视觉证据、对应原图哪个空间位置**。这使压缩表示中的“信息归属”是隐含的。
- **问题加剧场景**：单次压缩后该问题已存在；若在解码器多层中反复压缩，后一阶段在前一阶段已聚合多个原始 Token 的特征上继续操作，却不知道此前建立了什么，信息归属更模糊。
- **整体含义**：论文提出把压缩图像表示为一个**可组合视觉状态（composable visual state）**，显式携带代表特征、原始位置、有效贡献权重和可复用选择元数据，并注入解码器注意力。该状态对“缩减”封闭，因此同一套形式化可同时支持预填充前固定压缩与解码器内渐进压缩。

## 2. 方法论

### 2.1 核心思想

- 将压缩视觉分量建模为状态：
  - \(S^\ell=(H^\ell,P^\ell,m^\ell,G^\ell)\)
  - \(H^\ell\)：当前代表特征
  - \(P^\ell\)：原始位置
  - \(m^\ell\)：有效贡献权重
  - \(G^\ell\)：选择元数据（成对相似度、存活锚点）
- 要求满足两个条件：
  - **缩减封闭性**：对已有状态继续缩减，仍得到同形式状态，各分量解释不变；除选择集和证据外只依赖当前状态，不回溯已丢弃 Token。
  - **显式融入注意力**：解码器注意力通过从冻结模型导出的规则，显式使用 \(m^\ell\) 与 \(P^\ell\)。
- 三个模块：CSI（覆盖引导状态初始化）、CSC（耦合状态组合）、SCA（状态条件注意力）。

### 2.2 关键技术细节

- **CSI：覆盖率引导状态初始化**
  - 亲和度：结合 CLIP 编码器 key 与投影嵌入的相似度，\(\kappa_{ij}=s_{ij}^2\) 作为覆盖核。
  - 视觉证据 \(b\)：融合去噪后的编码器注意力、局部对比和全局特征独特性。
  - 指令证据：由冻结 CLIP 文本编码器得到分布 \(\pi\)，仅取相对视觉证据的正残差 \(r=[\pi-b]_+\)，再与 \(b\) 混合：
    - \(e=\mathrm{MassNorm}((1-\lambda_q)b+\lambda_q r)\)
  - 选择权重：将锐化证据与均匀分量混合，并按 \(N_r\) 个区域平衡，得到覆盖权重 \(\omega_j\)。
  - 贪心选择：从受保护注意力峰和非冗余指令锚点出发，贪心最大化覆盖函数
    - \(F(A)=\sum_j \omega_j \max_{i\in A}\kappa_{ij}\)
  - 最后保留预算的 5% 给“剩余覆盖缺口”最大的 Token。

- **CSC：耦合状态组合**
  - 每个被移除 Token 分配给最相似代表：\(a(j)=\arg\max_{i\in A}s_{ij}\)。
  - 贡献组合：代表累积相似度加权贡献，并用尺度 \(\lambda\) 强制**证据加权贡献守恒**：
    - \(b_i=\sum_{j\in D,a(j)=i}m_j s_{ij}^{\gamma}\)
    - \(m'_i=\mathrm{clip}(m_i+\lambda b_i,1,m_{\max})\)
  - 内容组合：按置信度 \(q_j\) 只让足够可信的移除 Token 参与，向加权质心旋转并保持范数：
    - \(h'_i=\|h_i\|\frac{h_i+\alpha\bar h_i}{\|h_i+\alpha\bar h_i\|}\)
  - 组合后保留原位置、相似度与锚点，形成同形式新状态。

- **SCA：状态条件注意力**
  - 代表保持原始 RoPE 索引。
  - 对查询 \(q\) 和视觉代表 \(i\)，注意力 logit 增加偏置：
    - \(B^\ell_h(q,i)=u^\ell g^\ell_h \log[m_i(2-D(|p_q-p_i|))]\)
  - \(D\) 为位置距离因子；权重 \(m_i\) 来自 CSC 的证据守恒贡献。
  - 头增益 \(g^\ell_h\) 由冻结 Q/K 投影的 RoPE 频率能量闭式计算，范围 \([g_{\min},g_{\max}]=[0.6,1.4]\)，无需训练或标注。

- **两种执行策略**
  - **CoViST-Fixed**：预填充前执行一次 CSI+CSC，固定保留 \(K\) 个代表。
  - **CoViST-Pro**：初始保留约 \(1.5K\)，在解码器两个中间层再次选择与组合，最终约 \(0.25K\)，层平均预算为 \(K\)。
  - 两者每层都应用 SCA；Pro 在第一次内部缩减前增益为 0.8，之后为 1。
