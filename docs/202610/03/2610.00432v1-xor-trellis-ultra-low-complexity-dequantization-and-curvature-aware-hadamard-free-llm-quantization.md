## 摘要
网格编码量化能够以超低比特宽度对大型语言模型（LLM）权重进行高维压缩，而无需传统向量量化所需的指数级大型码本。然而，实际部署面临两个挑战：以足够的并行吞吐量重建压缩权重，以避免反量化成为推理瓶颈；以及在不进行昂贵非相干变换的情况下保持量化精度。我们通过两种互补技术应对这些挑战。首先，我们提出一种超低复杂度网格反量化器，它使用结构化、硬件高效的状态到值映射，同时为网格搜索保留多样的重建选择。其次，我们用曲率感知目标重新表述离散网格路径优化，该目标直接在原始坐标空间中反映模型敏感度。这些技术共同实现了高质量的超低比特网格量化，具有低成本、高度并行的运行时重建，并且不依赖基于 Hadamard 的非相干处理。

## Abstract
Trellis-coded quantization enables high-dimensional compression of large language model (LLM) weights at ultra-low bit widths without the exponentially large codebooks required by conventional vector quantization. Practical deployment, however, presents two challenges: reconstructing compressed weights at sufficient parallel throughput to avoid making dequantization an inference bottleneck, and maintaining quantization accuracy without costly incoherence transformations. We address these challenges with two complementary techniques. First, we introduce an ultra-low-complexity trellis dequantizer that uses a structured, hardware-efficient state-to-value mapping while preserving diverse reconstruction choices for trellis search. Second, we reformulate discrete trellis path optimization with a curvature-aware objective that reflects model sensitivity directly in the original coordinate space. Together, these techniques enable high-quality ultra-low-bit trellis quantization with inexpensive, highly parallel runtime reconstruction and without relying on Hadamard-based incoherence processing.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：LLM 推理受存储与内存带宽严重制约，权重-only 后训练量化（PTQ）在自回归解码中尤为关键。极端低位宽下，标量量化精度不足，向量量化（VQ）虽提升表示效率，但码本随维度指数增长。
- **技术基础**：网格编码量化（TCQ）通过有限状态路径耦合量化决策，只存低位转移，可支持远超 VQ 的有效维度（QTIP 已将 TCQ 用于 LLM 超低位宽量化）。
- **两大部署挑战**：
  - **反量化吞吐瓶颈**：压缩表示需在推理时实时还原为数值权重。若每权重重建算术过重（如 QTIP 的 3INST 反量化器需要算术、逻辑、数据搬运操作，约等价 3–5k 门级逻辑），反量化会吃掉压缩带来的带宽收益。
  - **对非相干变换（RHT）的依赖**：主流方法（QTIP、QuaRot、SpinQuant）用随机 Hadamard 变换 / 学习旋转来扩散离群值与敏感方向。但无法被吸收的旋转会引入在线推理开销。
- **核心洞察**：论文认为对 RHT 的敏感性**并非网格表示固有**，而部分源于**二阶量化（模型敏感度感知）与离散网格路径搜索（各向同性欧氏失真）之间的目标错配**。RHT 通过使敏感度更均匀，"掩盖"了这一错配。
- **整体含义**：提出硬件–算法协同设计的 XOR-Trellis，实现**无 Hadamard** 的超低位宽网格量化 + 超低复杂度、可宽并行反量化。

## 2. 方法论

### 2.1 XOR-Trellis FP4 反量化器（超低复杂度状态到数值映射）

- **网格结构**：K=2 的 bitshift trellis，每步 2 bit 分支（4 选 1）；状态 16 bit = 14 bit 保留历史 `h` + 2 bit 当前分支 `b`，共 2^16 = 65,536 个状态。
- **本地调色板（local palette）**：固定历史 `h` 下，4 个分支给出 4 个可选重建值，构成一个"局部菜单"。核心设计目标是不浪费分支（避免出现重复数值）并保留"未来搜索自由度"。
- **四个调色板**（最小间距均为 1.5）：
  - P0 = [−6, −1.5, 0, 2]，P1 = [−4, −1, 0.5, 3]
  - P2 = [−3, −0.5, 1, 4]，P3 = [−2, 0, 1.5, 6]
- **映射算法**：由 4 个掩码奇偶校验函数从 14 bit 历史中算出 p0, p1, q0, q1（掩码 0x1089、0x2112、0x0A24、0x2441），则：
  - 调色板索引 `p = p0 | (p1 << 1)`
  - 分支置换 `b' = b ⊕ (q0 | (q1 << 1))`
  - 重建值 `ŵ = P_p[b']`
- **理论支撑（附录 C）**：
  - **命题 1（逐点单步最优）**：在 16 个标注 FP4 载荷、4 个不相交四元调色板、均匀调色板假设下，按排序秩模 4 交错划分（即上述构造）对任意标量 x 达到最小可能的一步平均失真下界。
  - **最大最小间距 1.5** 由鸽巢原理给出上界，该构造达到上界。
  - **F2 上的线性秩理论**：以二值可观测/驱动矩阵 E_w 的秩（如 rank₂(E₂)=4）作为"结构退化"的精确筛查准则，用于拒绝短窗口秩缺陷的掩码。
- **硬件实现**：约 **14 个 XOR2 门** + 一个固定 **4×4 FP4 调色板查找表**，无需乘法器/旋转/通用算术；综合结果：512 权重/周期的反量化器在 N3P 标准单元下仅占 **1,917 μm²**。
- **扩展性**：文中提到 FP8（E4M3）+ 16 调色板的初步实验重建误差略优，说明不限于 FP4。

### 2.2 曲率感知（Curvature-Aware）网格路径优化

- **问题形式化**：二阶 PTQ 优化模型感知目标 L_Q(e) ∝ eᵀHe，而常规 Viterbi 用各向同性欧氏目标 Σ(z_i − ẑ_i(π))²，二者几何不一致（"二阶/路径搜索目标错配"）。
- **LDL 分解暴露残差曲率**：H = LDLᵀ ⇒ eᵀHe = (Lᵀe)ᵀD(Lᵀe)。L 表示坐标间耦合，D 的对角元 D_ii 表示消除交互后各方向残差的相对代价。
- **曲率感知 Viterbi 目标**：π_D = argmin_π Σ D_ii (z_i − ẑ_i(π))²。即对每个残差乘 √D_ii 后再平方累加，**只改变标量分支代价**，状态空间、分支结构、幸存路径数、压缩比特率与渐近复杂度均不变。
- **理论性质（附录 D）**：各向同性近似误差由对角各向异性 κ_D = D_max/D_min 控制，路径级界 L_D(π_E) ≤ κ_D·L_D(π_D)；若 D = αI，两种目标极小点完全相同。
- **与 RHT 的关系**：RHT 是"改变表示使各向同性度量更合适"，本方法是"保留表示、让路径度量反映曲率"。故式(7)采用条件策略：**无 RHT 时用 D 加权，有 RHT 时用无权欧氏**。
- **能量排序（Energy Ordering）**：按块能量 E_b = tr(H_Bb,Bb) = Σ_{i∈Bb} H_ii 降序处理 LDLQ 特征块，让高敏感方向先量化、后续块可通过 L 的三角反馈补偿误差。同样纯离线、不改变压缩表示与运行时解码器。

### 2.3 离线/在线分离

- 离线量化 → 2-bit 网格序列（存储模型）→ 在线 XOR-Trellis FP4 反量化器。D 与 Hessian 相关信息**不存入部署码流**，运行时解码器完全不变。
