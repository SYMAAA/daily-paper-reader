## 摘要
视觉 Transformer 性能强劲，但 token 之间的二次交互带来高昂计算成本。免训练的 token 约简方法可提升效率，但其鲁棒性仍未得到充分探索。我们提出 Prune-and-Merge ViT，这是一种面向现成模型的免训练框架。它将基于类别注意力的剪枝与基于相似度的合并相结合，在保留语义信息的同时减少冗余。为评估鲁棒性，我们引入两个指标：相对精度下降（RAD）衡量变换下的相对精度退化，预测翻转率（PFR）量化预测一致性。在预训练的 ViT 和 DeiT 上，Prune-and-Merge 在保持鲁棒性的同时以有竞争力的程度降低计算量，并取得优于现有 token 约简方法的精度。我们的分析表明，混合 token 约简不会引入类似幻觉的行为，并且对常见图像变换保持预测稳定性。

## Abstract
Vision Transformers achieve strong performance but incur high computational costs from quadratic token interactions. Training-free token reduction methods improve efficiency, but their robustness remains underexplored. We propose Prune-and Merge ViT, a training-free framework for off-the-shelf models. It combines class attention-based pruning with similarity-based merging to reduce redundancy while preserving semantic information. To evaluate robustness we introduce two metrics. Relative Accuracy Drop (RAD) measures relative accuracy degradation under transformations, and Prediction Flip Rate (PFR) quantifies prediction consistency. On pretrained ViT and DeiT, Prune-and-Merge reduces computation competitively while maintaining robustness and better accuracy than existing token reduction methods. Our analysis suggests that hybrid token reduction does not introduce hallucination-like behavior and preserves prediction stability for common image transformations.

## 1. 核心问题与整体含义

- **研究背景**：Vision Transformer（ViT）将图像表示为固定长度的 patch token 序列，并通过自注意力建模全局关系。token 之间的交互成本随序列长度呈二次增长，即 \(O(N^2)\)，导致推理计算和显存开销较高。
- **现有方法的问题**：已有免训练 token 约简方法主要分为两类：
  - **剪枝**：依据 class-attention 等重要性分数丢弃 token，可能损失语义信息；
  - **合并**：依据相似度融合 token，可减少冗余，但在高压缩率下可能破坏表示。
  - 单一策略在输入变换下可能出现预测不稳定，现有工作对其鲁棒性评估不足。

## 2. 方法框架

- **总体设计**：论文将 token 压缩视为推理阶段的预处理/中间处理模块，而非重新训练模型。框架在 ViT/DeiT 的 token 序列上联合使用“剪枝”和“合并”，并根据层深、压缩预算和 token 冗余程度动态分配两种操作的比例，以兼顾语义保留与冗余消除。
- **重要性评估与剪枝**：利用 class-attention、注意力分布或 token 对分类 token 的贡献度估计重要性，优先保留与类别语义强相关的 token；对低贡献 token 进行剪枝。该步骤强调“保语义”，避免仅按相似度合并导致关键信息被平均化。
- **相似度匹配与合并**：对剩余 token 计算特征相似度并进行匹配，将高度冗余的 token 融合为代表性 token，同时记录合并权重和位置信息，以维持空间结构。合并步骤强调“去冗余”，在较高压缩率下比单纯剪枝更平滑。
- **混合调度策略**：论文的核心不是固定“先剪后并”或固定比例，而是让剪枝与合并协同：对语义关键但冗余低的 token 以保留为主；对语义贡献弱且高度相似的 token 优先合并或剪除；在压缩率升高时逐步调整策略，以降低表示崩溃风险。
- **即插即用与兼容性**：框架不修改主干参数，可直接接入现成 ViT/DeiT 推理流程；压缩模块可放在若干 Transformer 层之间，支持不同压缩预算，并尽量保持 CLS token、位置编码和残差通路的完整性。
- **鲁棒性与“幻觉式”行为评估**：除常规精度和计算量外，论文引入预测一致性、置信度校准、输入扰动下的预测翻转等量化视角，考察压缩后模型是否出现过度自信、对无关 token 的虚假依赖或语义漂移等“幻觉式”行为。这使评估从“平均精度”扩展到“压缩后的稳定性”。

- **消融分析**：重要性评分方式、相似度度量、剪枝/合并比例、压缩模块位置和层间调度均会影响结果；论文通过消融说明混合调度和语义保护机制是性能与鲁棒性提升的关键。

- 提出免训练、即插即用的混合 token 压缩框架，将剪枝的“语义保留”与合并的“冗余消除”结合，缓解单一策略在高压缩率下的退化。
- 将评估从单一精度扩展到压缩后的鲁棒性和“幻觉式”行为，补充了 token 约简研究中对预测稳定性的关注。
- 为现成 ViT/DeiT 的推理加速提供低部署成本的方案，具有实际工程意义。

## 5. 局限与待验证问题

- “幻觉式”行为的量化指标与分类任务之间的关联需要更充分的理论解释；不同压缩率下的稳定性边界也有待系统刻画。
