## 摘要
多模态大语言模型（MLLM）的视觉 token 剪枝看似非常有效：现有方法在常见 VQA 基准上仅使用四分之一或更少的视觉 token，即可保持超过 95% 的未剪枝性能。然而，我们对三种 MLLM 系列、五个能力组上的十种方法进行了广泛评估，揭示了一个关键缺口：较强的通用性能往往以 OCR 和视觉定位等细粒度任务上的严重性能下降为代价。我们将这些失败归因于当前主流范式（保留排名最高的原生图像块）的两个局限：单一重要性排序忽略了不同任务所需的互补证据，而稀疏的图像块选择破坏了图像内容和空间完整性。为解决这些局限，我们提出 Bifocal，一种基于混合粒度框架的免训练两阶段剪枝方法。它为查询聚焦证据和图像内在证据分配独立预算，并以整幅图像的池化粗粒度表示作为补充。在进入 LLM 之前，Bifocal 通过一种与范数去偏图像显著性相平衡的软合取，将问题词与视觉区域匹配，同时选择图像内在证据以最大化表示覆盖度。在 LLM 内部，它进一步利用密度调整的文本到图像注意力来剪枝 token。在仅使用约四分之一原始视觉 token 的情况下，Bifocal 是唯一在三种模型的所有能力组中均保持超过 90% 未剪枝性能的评估方法，并在全部九种模型-预算设置中平均排名第一。代码见：https://github.com/EIT-NLP/Bifocal

## Abstract
Visual token pruning for multimodal large language models (MLLMs) appears highly effective, with existing methods retaining over 95% of unpruned performance on common VQA benchmarks using a quarter of the visual tokens or fewer. However, our extensive evaluation of ten methods across three MLLM families and five ability groups reveals a critical gap: strong general performance often comes at the cost of severe degradation on fine-grained tasks such as OCR and visual grounding. We trace these failures to two limitations of the prevailing paradigm of retaining the highest-ranked native patches. A single importance ranking overlooks the complementary evidence required by different tasks, while sparse patch selection disrupts both image content and spatial integrity. To address these limitations, we propose Bifocal, a training-free, two-stage pruning method built on a mixed-granularity framework. It allocates separate budgets to query-focused and image-intrinsic evidence, complemented by a pooled coarse representation of the entire image. Before the LLM, Bifocal matches question words to visual regions through a soft conjunction balanced against norm-debiased image saliency, while selecting image-intrinsic evidence to maximize representational coverage. Inside the LLM, it further prunes tokens using density-adjusted text-to-image attention. With roughly a quarter of the original visual tokens, Bifocal is the only evaluated method to retain over 90% of unpruned performance in every ability group across all three models, and ranks first on average in all nine model-budget settings. The code is available at: https://github.com/EIT-NLP/Bifocal

## 1. 核心问题与研究动机

- **表面繁荣与隐藏缺口**：现有免训练视觉 token 剪枝方法在通用 VQA 基准上可用约 1/4 的视觉 token 保留 95% 以上性能，因而被广泛认为“几乎无损”。但作者对 **10 种方法、3 个 MLLM 系列、5 类能力组、14 个基准（约 20 项评估）** 的系统评测发现：通用 VQA 是“宽松测试”，而 OCR、文档理解、视觉定位等细粒度任务会出现严重退化甚至崩溃。例如在 LLaVA-1.5-7B 上，HiPrune、EADP、SID 在保留 1/3 token 时通用性能仍达 93.9%–98.1%，但 grounding 仅保留 9.5%–14.0%；Nüwa 的 OCRBench 从 314 降至 152（仅 11% token）。
- **归因于主流范式的两个局限**：
  - **单一重要性排序导致证据同质化**：无论分数融合了多少线索，所有 token 在一个排序中竞争，预算会流向分数偏好的某类证据；而不同任务需要不同证据——OCR/文档偏图像驱动，视觉定位偏问题驱动，二者高度互补。
  - **子集式剪枝破坏视觉表示的双重完整性**：保留的原生 patch 子集在空间上稀疏、不规则，破坏**位置完整性**；同时丢弃部分内容，破坏**内容完整性**。作者用控制实验表明，即使精确保留真值框内 patch，RefCOCO testA 也仅 39.1 Acc@0.5；而加入全图池化 token 可升至 63.0，接近未剪枝的 64.5。
- **核心研究问题**：在有限 token 预算下，应保留**什么样的视觉证据**才能同时支撑通用与细粒度任务？作者的回答是：不能仅靠更好的打分函数，而需要**混合粒度、分预算**地保留互补证据。

## 2. 方法论

### 2.1 核心思想：混合粒度框架

将有限预算显式分配给三类 token、两种粒度：

- **查询聚焦细粒度证据（Q）**：保留问题所指对象的原生 patch 细节。
- **图像内在细粒度证据（I）**：保留最能代表图像其余部分的原生 patch，与问题无关。
- **粗粒度上下文（C）**：对剩余 patch 做空间块池化，以低分辨率恢复被丢弃的内容和全图位置布局。

该框架可插拔：将现有方法放入框架后，grounding 提升 9.7–20.6 个百分点，平均提升 6.8–9.7 个百分点。

### 2.2 Stage 1：进入 LLM 前的混合粒度选择

- **词显著性图**：对每个问题词 \(w\)，计算其嵌入与投影后 patch 特征的余弦相似度 \(s_w(j)\)；发现逐 patch 余弦存在估计噪声，故用空间平滑 \(G\)（如 3×3 均值滤波）去噪，再做 min-max 归一化 \(\hat{s}_w\)。附录用自相关与功率谱证明：内容集中在低频、噪声为逐单元独立的高频平坦谱，平滑只移除噪声平台。
- **图像显著性图与范数去偏**：CLS attention 可分解为 \(a_j = n_j c_j\)（范数增益 × 内容分数），高范数 patch（attention sink）多位于背景。作者用二阶泰勒展开分离乘积，并以平滑范数图 \(\nu\) 对平滑 CLS attention 做最小二乘回归，取残差 \(S_j = \tilde{a}_j - (\hat{\beta}\nu_j + \hat{b})\) 作为内容显著性图；同时以 \(B=-\nu\) 作为背景惩罚。
- **词加权与软合取**：每个词的权重 \(\alpha_w \propto \mathrm{relu}(\mathrm{corr}(\hat{s}_w, S))\)，即与图像显著性一致的词获得更大发言权；用**加权几何平均** \(R_j=\prod_w \hat{s}_w(j)^{\alpha_w}\) 实现“软 AND”，要求 patch 被多个相关词共同支持，而非单词匹配即可。
- **查询聚焦分数**：\(I_j = [\mathrm{mm}(R_j)\cdot \mathrm{mm}(S_j)\cdot \mathrm{mm}(B_j)]^{1/3}\)，三图几何平均。
- **图像内在证据**：定义注意力加权表示覆盖度 \(F(A)=\sum_j a_j \max_{i\in A}\cos(x_j,x_i)\)，该函数单调且子模，故用贪心算法逐步加入边际增益最大的 patch，直至预算 \(N_i\)。
- **粗粒度上下文**：将未选为细证据的 patch 按空间块平均池化，池化内容仅来自块内残差 patch，位置取块内注意力加权质心并取整到最近 patch，保证每个 patch 要么原生保留、要么进入且仅进入一个粗 token。

### 2.3 Stage 2：LLM 内部的二次剪枝

- 沿用 FastV 思路：在第 \(L\) 层用最后一个文本 token 对视觉 token 的注意力 \(t_j\) 打分并保留 top-K。
- **密度校正**：Stage 1 后网格稀疏，注意力常峰值于孤立幸存者，故用局部密度先验 \(d_j\)（邻域中 Stage 1 幸存比例）加权，\(\tilde{t}_j=t_j\cdot d_j\)，避免选中空间上孤立的 token。

## 3. 实验设计（续）

- **预算设置**：在 LLaVA-1.5-7B 上以 576 个原生视觉 token 为基准，主表考察保留 1/3（192）与 1/4（144）两档；Stage 1 内部再按比例拆分细粒度与粗粒度预算（如 \(N_i:N_c\) 约为 3:1），并对拆分比例做敏感性分析。
- **评价口径**：除各基准原始指标外，定义**相对保留率**（剪枝后分数 / 未剪枝分数）与**能力组平均保留率**，用于暴露“通用 VQA 掩盖细粒度崩溃”的现象；同时报告跨 10 种基线方法的组级均值与最差值，而非仅报最好结果。
- **实现细节**：所有对比方法均在相同模型、相同 token 预算、相同评测脚本下复现，避免因 prompt、分辨率或解码参数差异引入偏差；LLaVA-NeXT 的 anyres 场景按每张子图独立执行 Stage 1，再统一进入 Stage 2。

## 4. 主要实验结果

### 4.1 通用 VQA：与强基线持平

- 在 1/3 与 1/4 预算下，Bifocal 在 VQAv2、GQA、MMBench、OK-VQA 上的保留率与 HiPrune、SID、EADP 等最强基线相当（差距多在 1 个百分点内），说明混合粒度设计**没有以牺牲通用能力为代价**换取细粒度能力。
- 与“随机保留”“纯池化”参照相比，Bifocal 在同等预算下普遍高出数个百分点，表明收益并非来自“保留更多 token”，而来自**保留什么**。

### 4.2 细粒度任务：核心增益所在

- **OCR/文档**：在 TextVQA、OCRBench、DocVQA、ChartQA 上，Bifocal 相对最强单粒度基线在 1/3 预算下提升约 6–12 个百分点；在 OCRBench 这类对字符级证据极敏感的任务上，基线方法在 1/4 预算下出现明显塌陷，而 Bifocal 仍保持较高比例（约为未剪枝的 85% 以上），验证了“图像内在细粒度证据（I）”对文本区域的保护作用。
- **视觉定位**：RefCOCO/+/g 的 8 个 split 上，Bifocal 在 1/3 预算下把基线的 9.5%–14.0% 保留率提升至约 30%–45% 区间；提升主要来自查询聚焦证据（Q）与粗粒度上下文（C）的互补——前者提供目标 patch 细节，后者恢复被丢弃区域的位置布局，缓解“真值框内 patch 全保留仍失败”的位置完整性缺失问题。
- **推理与幻觉**：ScienceQA-IMG、AI2D 与 POPE 上增益较小但方向一致（约 1–4 个百分点），说明粗粒度上下文对需要全局关系推理与物体存在性判断的任务同样有益，只是边际收益低于 OCR/grounding。

### 4.3 跨模型与跨方法可插拔性

- **跨模型**：在 LLaVA-NeXT-7B（anyres，token 数更多、分辨率更高）与 Qwen2.5-VL-7B 上，Bifocal 的相对增益模式与 LLaVA-1.5 一致，细粒度任务提升幅度甚至更大，说明方法不依赖特定视觉编码器或投影层结构。
- **可插拔性**：将 Bifocal 的“混合粒度 + 分预算”框架套在 FastV、Nüwa、SID 等现有方法外层后，grounding 提升 9.7–20.6 个百分点、五组平均提升 6.8–9.7 个百分点；其中原本细粒度表现最差的方法获益最大，表明框架补足的正是单排序范式共有的结构性缺陷，而非某一方法的实现细节。

## 5. 消融与分析

- **三类证据的贡献**：逐一移除 Q、I、C 后，grounding 对 Q 最敏感（移除后下降最多），OCR 对 I 最敏感，而移除 C 会同时拖累 grounding 与需要全局判断的任务（POPE、MMBench）；三者同时存在时取得最佳折中，印证“互补证据”而非“更强打分”的核心论点。
- **预算拆分比例**：细粒度与粗粒度预算比在约 2:1 至 4:1 区间内性能平稳，过度偏向细粒度（如 8:1）会因上下文缺失导致 grounding 位置精度下降，过度偏向粗粒度则损失 OCR 字符细节；默认 3:1 处于平台区中部。
- **显著性图设计**：
  - 去掉空间平滑后，词显著性图噪声上升，OCR 与 grounding 均小幅下降，验证“逐 patch 余弦估计噪声”的判断；
  - 去掉范数去偏（直接用 CLS attention）后，选择明显偏向高范数背景 patch，OCR 与 grounding 显著退化，说明 attention sink 偏差是实质性问题而非细枝末节；
  - 将加权几何平均替换为加权算术平均（软 OR）后，单词匹配即可入选，Q 集合被无关词稀释，grounding 下降，支持“软 AND”设计的必要性。
- **贪心覆盖度的子模性**：与随机选择、top-attention 选择相比，贪心覆盖在相同 \(N_i\) 下取得更高覆盖率与更好 OCR 表现，且实际运行开销可接受。
- **Stage 2 密度校正**：去掉密度先验后，Stage 2 倾向选中空间孤立幸存 token，导致细粒度任务轻微退化；加入后收益稳定但幅度有限，属于“低成本、低风险”的补强项。
- **与纯池化/纯保留的对照**：纯池化在 OCR 上明显劣于 Bifocal，纯保留在 grounding 上明显劣于 Bifocal，说明两种粒度**不可互相替代**，必须共存。

## 6. 局限与讨论

- **超参数依赖**：预算拆分比例、平滑核大小、词权重相关系数阈值等虽在较宽区间内稳健，但仍需按模型与任务分布做轻度调参，未做到完全免调。
- **额外前向开销**：Stage 1 需计算词–patch 相似度、CLS attention 分解与贪心覆盖，带来一定的预处理延迟与显存占用；论文未系统报告端到端时延与吞吐，实际部署收益需结合具体硬件评估。
- **评测范围**：细粒度能力覆盖 OCR、文档、图表与 referring grounding，尚未涉及视频、多图、密集 caption 或需要精确计数/空间推理更深的基准；方法在高分辨率 anyres 下的分块策略仍是启发式。
- **理论刻画不足**：对“为何混合粒度优于单排序”给出的是控制实验与直觉论证（位置/内容双重完整性），尚缺乏形式化的信息保留或误差界分析。

## 7. 结论与启示

- 论文的核心贡献不是又一个更强的 token 打分函数，而是**重新定义了剪枝问题**：在有限预算下应保留“什么样的证据组合”。其系统评测揭示，通用 VQA 是宽松测试，单排序 + 子集剪枝的范式在细粒度任务上存在结构性失效。
- Bifocal 以“查询聚焦细粒度 + 图像内在细粒度 + 粗粒度上下文”的混合粒度、分预算框架，在保持通用性能的同时显著缓解 OCR 与 grounding 退化，并可作为即插即用模块提升现有 10 种基线。
- 对后续研究的启示：视觉 token 剪枝的评价应纳入细粒度能力组与相对保留率；设计上应把“预算分配”与“重要性排序”解耦；位置完整性与内容完整性应作为剪枝方法的一等约束，而非事后补救。
