## 摘要
视觉 token 剪枝正越来越多地用于降低视觉语言模型的内存与推理成本。现有工作主要集中于设计特定方法的 token 选择器，并在选定的 token 预算下展示相对于先前方法的渐进式改进。目前尚不清楚，所得性能反映的是视觉 token 剪枝的固有极限，还是当前 token 选择算法的局限。我们采取一个互补视角并提出：当离线搜索成本不是主要约束时，视觉 token 剪枝能表现到多好？我们将面向通用图像理解的剪枝表述为：在固定预算下，选择一个共享的视觉 token 子集，使其能够支持关于一张图像的广泛问题分布。我们用一个由前沿 VLM 生成的有限辅助 QA 集来近似该效用，并在被评估模型冻结的情况下优化教师强制答案概率目标。受加入视觉证据在概念上的单调性与收益递减启发，我们贪心地构造嵌套子集，并引入 QA 小批量贪心（QA-MBG），它在每一步从随机采样的 QA 组件中估计 token 的边际增益。经验上，QA-MBG 比完全贪心更便宜且更有效。凭借一次前沿 VLM 调用和每张图像约 0.5 个 H100 GPU 小时，它产生一条覆盖最高 0.3 保留率的嵌套子集轨迹。在来自九个基准的 900 张图像上，对 Qwen3-VL-4B 和 Gemma~4 E4B 而言，我们发现相对于所评估的剪枝基线，在留出 QA 和基于图像的长文本生成上存在显著提升空间，同时搜索得到的子集大幅缩小了与全 token 推理之间的差距。

## Abstract
Visual token pruning is increasingly used to reduce the memory and inference costs of vision-language models. Existing work has largely focused on designing method-specific selectors and demonstrating incremental improvements over prior methods at selected token budgets. It remains unclear whether the resulting performance reflects an inherent limit of visual token pruning or the limitations of current token-selection algorithms. We take a complementary perspective and ask: \emph{how well can visual token pruning perform when offline search cost is not the primary constraint?} We formulate pruning for general image understanding as selecting, under a fixed budget, one shared visual-token subset that supports a broad distribution of questions about an image. We approximate this utility with a finite auxiliary QA set generated by a frontier VLM and optimize a teacher-forced answer-probability objective with the evaluated model frozen. Motivated by the conceptual monotonicity and diminishing returns of adding visual evidence, we construct nested subsets greedily and introduce \emph{QA mini-batch greedy} (QA-MBG), which estimates token marginal gains from randomly sampled QA components at each step. Empirically, QA-MBG is both cheaper and more effective than full greedy. With one frontier-VLM call and approximately $0.5$ H100 GPU-hours per image, it produces a nested subset trajectory covering keep ratios up to $0.3$. Across Qwen3-VL-4B and Gemma~4 E4B on $900$ images from nine benchmarks, we find significant headroom over evaluated pruning baselines on held-out QA and image-grounded long-form generation, while the searched subsets substantially narrow the gap to full-token inference.

## 1. 核心问题与研究动机

- **背景**：视觉语言模型（VLM）将图像编码为数百至数千个视觉 token，显著增加 prefill 计算、解码注意力、KV-cache 内存与端到端延迟，视觉 token 剪枝因此成为高效 VLM 推理的重要方向。
- **现有研究模式**：多数工作提出新的选择启发式（基于注意力、查询相关性、特征相似度、冗余度、多样性或学习式选择模块），并在选定 token 预算下展示相对前作的增量提升。
- **关键缺口**：这种"方法竞赛"无法回答一个更根本的问题——**在固定预算下，视觉 token 剪枝究竟能保留多少性能？** 与全 token 推理的差距混合了"不可避免的信息损失"与"可恢复的选择器误差"；现有方法之间的小差异也不能证明它们接近最优子集。
- **论文视角**：放松离线搜索时间约束，投入大量离线计算为每张图寻找强子集，从而**暴露出剪枝的可达性能前沿**，把问题从"哪个启发式更好"转变为"还有多少算法提升空间"。

## 2. 方法论

### 2.1 问题形式化

- 设图像 $I$ 的视觉嵌入为 $Z_I=(z_1,\dots,z_n)$，保留比例 $\rho$，预算 $b=\lfloor\rho n\rfloor$。
- 目标：寻找**一个跨问题共享的子集** $S^\star_{U,b}=\arg\max_{|S|=b} U_I(S)$，其中 $U_I(S)$ 表示通用图像理解能力。
- 用目标问题分布 $D_I$ 上的期望答对概率刻画理解能力：
  $F_I(S)=\mathbb{E}_{q\sim D_I}[\Pr_{\hat a\sim p_\theta}(\hat a\in A_I(q))]$。
- 由于真实分布不可得，用前沿 VLM（GPT-5.6-SOL）生成有限辅助 QA 集 $Q_I=\{(q_j,a_j)\}_{j=1}^M$ 近似，优化 $\hat F_I(S)=\frac1M\sum_j f_j(S)$。

### 2.2 评分函数

- 对参考答案 $a_j=(a_{j,1},\dots,a_{j,L_j})$ 做 **teacher forcing**，逐 token 计算概率，取**长度归一化的几何平均**：
  $f_j(S)=\exp\!\big(\frac1{L_j}\sum_\ell \log p_\theta(a_{j,\ell}\mid q_j,Z_I[S],a_{j,<\ell})\big)$。
- 相比二值正确/错误，软概率分数能区分产生相同离散答案的不同子集，且一次因果前向即可并行评分所有答案位置，比自回归解码快得多。

### 2.3 贪心与 QA-MBG 算法

- **概念假设**：加入视觉证据具有近似单调性与收益递减（近似单调子模），因此采用前向贪心构造嵌套子集。
- **完全贪心**代价为 $O(M b_{\max} n)$ 次 QA–候选评分，代价过高。
- **QA mini-batch greedy (QA-MBG)**：每一步均匀无放回采样一个 QA 子集 $B_t$（大小 $m=\max\{1,\lceil\alpha M\rceil\}$），对**所有剩余 token 候选**评估该 mini-batch 上的平均边际增益：
  $\hat\Delta_t(v\mid S_t)=\frac1m\sum_{j\in B_t}\Delta_j(v\mid S_t)$，取最大者加入。
- **与 token-level stochastic greedy 的本质区别**：后者采样 token 候选、评估完整 QA 目标；QA-MBG 采样**目标组件（QA）**、仍评估全部 token 候选，对应可分解目标的小批量子模最大化思想。
- 对固定候选，mini-batch 估计是完整 QA 池边际的无偏估计（式 9），但最大化噪声估计不保证与完全贪心选同一 token。
- **一次搜索多预算**：返回一条嵌套轨迹，各预算取前缀，摊销搜索成本。
- **工程优化**：候选批处理（同一步候选等长、无需 padding）、跨 QA 的 prefix KV 复用、teacher forcing 并行评分、缓存视觉嵌入。

## 3. 实验设计

- **数据集/基准**：9 个基准——AI2D、ChartQA、DocVQA、InfographicVQA、MME、MMStar、RealWorldQA、TextVQA、V*Bench。
  - 主集：每基准 100 图，共 900 图、2,226 个实际 QA。
  - 小集：每基准 20 图，共 180 图、392 个实际 QA。
- **模型**：Qwen3-VL-4B-Instruct 与 Gemma 4 E4B-it，参数冻结；选择发生在视觉编码与投影之后、LLM 处理之前。
- **辅助 QA**：GPT-5.6-SOL 生成 30,273 个 QA，平均 33.64 个/图；主搜索配置 $\alpha=0.2$。
- **评估任务**：
  - 留出实际 QA（native benchmark 指标，相对全 token 归一化）。
  - 长文本生成：两个固定描述提示 P1/P2，由 GPT-5.6-Luna 在匿名、打乱、隐藏方法身份的条件下按 0–5 分评分。
- **对比基线**：Qwen 14 个、Gemma 13 个，涵盖 post-ViT 选择（Uniform、FLoC、DivPrune）、查询感知选择（EADP、AnchorPrune）、特征合并（VisionZip、PruMerge、VisPruner、VScan）、decoder 内部剪枝（FastV、PriorTR、V2Drop、CLSE、DART、MustDrop）以及 ZOO-Prune 等，均为作者针对两个架构的适配实现。
- **分析实验**：
  - QA 采样比例 $\alpha\in\{0.1,0.2,0.5,1.0\}$、每步 1 个 QA、完全贪心对比；$\alpha=0.2$ 用 3 个种子。
  - token-level stochastic greedy 对照。
  - 辅助 QA 池大小（25%/50%/75%/100%）消融。
  - 与真实 QA 语义重叠的生成 QA 移除、随机移除对照。
  - 数据集无关（去 benchmark 条件）生成对照。
  - 替换生成器为 Opus 5。
  - top-k 边际增益选择诊断、固定状态回放分析。
  - 252 个逐预算配对 bootstrap 置信区间（10,000 次重采样）。

## 4. 资源与算力

- **搜索成本**：每张图像约 **0.5 个 H100 GPU 小时**，一次前沿 VLM 调用，产生覆盖保留率至 0.3 的完整嵌套轨迹。
- **单图实测**（Qwen3-VL-4B，1× NVIDIA H100 80GB，PyTorch 2.5.1+cu121，FlashAttention 2）：
  - 完整嵌套轨迹（284 次加入、945 token 图）：batch 64 时 1,853 秒，batch 320 时 1,672 秒（约 27.9 分钟）。
  - 峰值显存：batch 64 为 18.23 GiB，batch 320 为 56.12 GiB。
  - 候选批处理相对串行评分加速 13.84×，叠加 prefix 复用再加速 3.02×（候选评分微基准综合约 41.80×）。
- **说明**：论文未报告总 GPU 数量或全部 900 张图的总机时；仅给出单图测量与"约 0.5 H100 小时/图"的估算。Gemma 未给运行时测量。

## 5. 实验数量与充分性

- **规模**：主实验覆盖 2 个模型族 × 9 个基准 × 900 图 × 6 个预算（0.05–0.30），实际 QA 2,226 个；长文本为 2 模型 × 9 基准 × 100 图 × 2 提示 × 6 预算。
- **消融丰富**：QA 采样比例、采样种子（3 个）、QA 池大小、重叠 QA 移除、随机移除对照、数据集无关生成、生成器替换、top-k 选择、token-level 采样对照、固定状态回放等，共十余组分析。
- **统计严谨性**：252 个逐预算配对 bootstrap 区间下界全部为正；对最强基线给出六预算平均增益及 95% CI（如 Qwen 实际 QA 对 FLoC +10.12 点 [8.35, 11.87]）。
- **公平性努力**：
  - 实际 QA 标注不参与候选评分；重叠 QA 被显式过滤后重跑搜索，headroom 仍存在。
  - 基线针对两个架构做了专门适配，并明确区分 post-ViT 选择、特征合并与 decoder 内部剪枝的计算差异。
  - 长文本评判匿名化、打乱顺序、隐藏全 token 答案身份。
- **局限**：部分对照（完全贪心、top-k、重叠移除、数据集无关生成）为单次运行；仅 $\alpha=0.2$ 做了 3 种子重复；部分消融只在 Qwen 小集上完成，未在 Gemma 上复现；长文本评判为 LLM 而非人类评估。

## 6. 主要结论与发现

- **存在显著 headroom**：在两个模型族上，搜索得到的共享子集在实际 QA 和长文本生成上均显著优于所评估的剪枝基线，并大幅缩小与全 token 推理的差距；这一差距在低/中保留率下尤为明显。
- **当前剪枝损失大部分可恢复**：相当一部分性能损失来自选择器误差，而非 token 预算导致的信息损失必然上限。
- **QA-MBG 优于完全贪心**：尽管每步评估更少 QA 组件，$\alpha=0.2$ 在保留率 0.20 时实际 QA 相对性能 93.44%（三种子范围 91.90–95.95%），完全贪心仅 75.56%；长文本 2.989 vs. 1.869。作者假设 QA 重采样起到正则化作用，避免对有限生成 QA 池的过拟合。
- **任务不均衡**：文档、图表、信息图、示意图类基准增益最大；TextVQA（Qwen）和 MME（Gemma）等存在基线反超的反例，说明聚合增益不等于逐基准支配。
- **迁移性**：用短答案目标搜索的子集也能提升开放式长文本描述质量。
- **稳健性**：headroom 在去除 benchmark 条件、过滤语义重叠 QA、替换生成器为 Opus 5、缩小 QA 池后依然存在（尽管有所削弱）。
- **QA 池越大越好**：保留率 0.20 时，25% QA 池相对性能 86.33%，完整池 96.18%。

## 7. 优点

- **问题视角新颖且有价值**：不设计又一个部署时启发式，而是通过放宽离线搜索成本来刻画"可达性能前沿"，为评估剪枝算法提供了新标尺。
- **形式化清晰**：将通用理解剪枝定义为固定基数约束下最大化期望 QA 效用的共享子集选择，并给出可操作的有限 QA 近似。
- **算法有理论渊源且经验有效**：QA-MBG 对应可分解目标的小批量子模最大化，与 token 候选采样明确区分；经验上比完全贪心更便宜且更好，并给出采样动力学与固定状态回放等机制分析。
- **实验体系完整**：两模型族、九基准、多种基线适配、逐预算配对 bootstrap、长文本迁移、多重控制实验（重叠过滤、去条件化、换生成器），对"是否由数据泄漏或特定生成器导致"做了针对性排除。
- **工程实现扎实**：候选批处理、prefix KV 复用、teacher forcing 等优化使穷举候选的离线搜索可行，并给出可复现的运行时与显存测量。
- **诚实报告反例**：明确指出 TextVQA、MME 等基准上的失败案例与比较范围限制。

## 8. 不足与局限

- **非部署算法**：每图约 0.5 H100 小时的离线搜索成本极高，论文自身定位为"诊断可达上限"而非实际推理方案；如何蒸馏为廉价选择器仍未解决。
- **依赖前沿 VLM 生成辅助 QA**：生成 QA 的分布、质量与语义重叠会影响结果；虽做了重叠过滤、去条件化和换生成器控制，但无法完全排除与真实 QA 的语义关联，过滤本身也会移除有用监督。
- **子模假设仅为近似**：冻结 VLM 的答案概率

- **子模假设仅为近似**：冻结 VLM 的答案概率对 token 子集并不严格满足单调性与子模性——移除关键文字区域 token 可能使概率骤降，加入冗余 token 也可能因上下文扰动而产生负边际；因此前向贪心只具有启发式地位，论文未给出近似比或最坏情况保证，"可达前沿"应理解为该搜索程序实际达到的经验下界，而非理论最优。
- **保留率范围受限**：嵌套轨迹主要覆盖至保留率 0.3，对 0.5 以上的温和压缩区与 0.05 以下的极端区刻画不足；"性能极限"的结论应限定在所考察的预算区间内，不能直接外推为任意预算下的可达上限。
- **任务与模态覆盖有限**：仅涉及静态单图视觉 token，未涵盖视频、多图交错输入、高分辨率文档切片等场景；也未讨论与 KV-cache 驱逐、量化、投机解码等其他效率手段的叠加效应，而实际部署往往是多种压缩技术的组合。
- **模型规模单一**：两个被测模型均属 4B 量级，更大规模模型、MoE 架构或经过强视觉指令微调的模型上 headroom 是否同比例存在尚不清楚；不同模型族的视觉编码器分辨率与 token 数差异也可能改变结论。
- **对辅助监督量敏感**：QA 池大小消融显示池越大前沿越高，说明所得上限本身是监督预算的函数，而非模型固有属性；在标注/生成预算受限时，headroom 会明显收窄，这削弱了"损失大部分可恢复"这一表述的普适性。
- **评估口径的聚合风险**：实际 QA 采用各基准原生指标并相对全 token 归一化，不同指标（准确率、MME 总分、V*Bench 等）尺度与饱和度不同，简单平均可能掩盖基准间的结构性差异；长文本由 LLM 评判，存在风格偏好、长度偏好与评分不稳定性，且未与人类评分做一致性校验。
- **统计覆盖不完整**：bootstrap 仅沿预算维度做配对重采样，未同时刻画图级、种子级与生成器级方差；多组关键对照为单次运行，缺少重复实验的误差棒，个别结论（如完全贪心显著劣于 QA-MBG）虽效应量大，但仍宜有多种子确认。
- **可复现性受专有模型制约**：辅助 QA 生成与长文本评判均依赖闭源前沿模型，外部研究者难以逐位复现；基线为作者自行适配实现，与原论文超参、融合位置可能存在差异，跨论文比较需谨慎。
- **缺少蒸馏验证**：论文明确指出将离线搜索蒸馏为廉价选择器是未来方向，但未提供任何学生选择器逼近该前沿的实验，因而"可恢复"目前只是存在性证明，其转化为部署收益的路径尚未被验证。
- **反例的机制解释偏弱**：TextVQA、MME 上出现基线反超，论文以"聚合增益不等于逐基准支配"作说明，但未深入分析其成因（如细粒度文字定位对局部 token 的强依赖、或某些基准对全局语义布局更敏感），任务不均衡现象缺少可检验的解释。

## 9. 启示与后续方向

- **评价范式的转变**：论文主张以"相对可达前沿的归一化差距"替代"相对上一方法的增量"，这一标尺可用于诊断新启发式究竟在弥补选择器误差，还是已逼近预算导致的信息上限。
- **可探索的技术路线**：将搜索轨迹作为监督信号蒸馏轻量打分器；以搜索得到的最优子集作为奖励做策略学习；把 QA-MBG 的小批量子模思想推广到视频帧选择与多图 token 分配；研究按任务类型自适应分配预算而非全图统一比例。
- **对部署实践的提示**：文档、图表、信息图类任务在低预算区仍有可观提升空间，值得优先投入更强的选择器；而 TextVQA 类细粒度识别任务上启发式的边际收益有限，可能需要与局部高分辨率保留策略结合。

## 10. 总体评价

这是一篇定位清晰、执行扎实的**诊断性研究**：它不追求提出可部署的剪枝器，而是通过大幅放宽离线计算，为视觉 token 剪枝构造了一个经验性能前沿，并用两模型族、九基准、多重控制实验与逐预算区间估计，论证了"当前剪枝损失中相当一部分源于选择器误差而非预算本身"。其方法论贡献在于把问题形式化为固定基数约束下的共享子集效用最大化，并提出 QA-MBG 这一在目标维度采样的实用近似；其经验贡献在于给出可复用的上界参照与诚实的反例报告。主要短板是离线成本极高、子模假设缺乏理论保证、预算与模型覆盖有限、以及尚未验证前沿可被廉价蒸馏——这些也正是该工作自然延伸的方向。总体而言，论文的核心主张（存在显著且稳健的可恢复 headroom）在其考察范围内得到了较充分的证据支持，但其"性能极限"应被理解为**特定搜索程序与特定监督预算下的经验前沿**，而非信息论意义上的绝对上限。
