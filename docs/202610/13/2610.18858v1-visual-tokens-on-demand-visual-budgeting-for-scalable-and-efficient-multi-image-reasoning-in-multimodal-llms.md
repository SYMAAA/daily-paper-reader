## 摘要
多模态大语言模型发展迅速，但大多数仍针对单图像输入进行优化。多图像推理成本高昂，因为每张图像都会增加大量视觉令牌，从而提高编码和注意力需求。现有解决上述问题的技术，包括视觉令牌剪枝、令牌合并、视觉令牌压缩、学习式重采样、层次化压缩、检索增强视觉推理以及基于记忆的架构，大多面向单图像场景设计，其中的冗余主要是空间性和局部性的。多图像推理引入了额外挑战：冗余可能跨图像出现，任务相关证据可能稀疏或分散，并且激进的逐图像压缩可能会删除比较、计数、时序推理、检索或证据定位所需的细节。此外，现有令牌缩减方法通常要么 (i) 免训练但推理效率低，通常依赖访问注意力矩阵来获取令牌重要性，而在 FlashAttention 等内存高效注意力实现中访问这些矩阵可能不切实际；要么 (ii) 依赖训练，需要重新训练基础 MLLM 或使其适应新的压缩令牌范式。在本工作中，我们研究无需重新训练基础模型且无需在推理时访问注意力矩阵的可扩展多图像推理与理解。为此，我们提出 mmVB，一个轻量级即插即用模块，它通过跨图像上下文分配以查询为条件的逐图像令牌预算，仅增加 1.6M 可训练参数，同时将视觉输入令牌减少 9 倍。这一缩减带来 5 倍更快的首令牌时间（time-to-first-token）和 7 倍更少的预填充 FLOPs，同时在八个多图像推理基准上保持全分辨率准确率的 94.4%。

## Abstract
Multimodal large language models have advanced rapidly, but most remain optimized for single-image inputs. Multi-image reasoning is costly because each image adds many visual tokens, increasing encoding and attention demands. Existing techniques that address the above issue, including visual token pruning, token merging, visual token compression, learned resampling, hierarchical compression, retrieval-augmented visual reasoning, and memory-based architectures, have largely been designed for single-image scenarios, where redundancy is primarily spatial and local. Multi-image reasoning introduces additional challenges: redundancy may occur across images, task-relevant evidence may be sparse or distributed, and aggressive per-image compression can remove details needed for comparison, counting, temporal reasoning, retrieval, or evidence grounding. Moreover, existing token-reduction methods are often either (i) training-free but inference-inefficient, typically relying on accessing attention matrices to get token-importance that may be impractical to access with memory-efficient attention implementations such as FlashAttention, or (ii) training-dependent, requiring the base MLLM to be retrained or adapted to a new compressed-token paradigm. In this work, we study scalable multi-image reasoning and understanding without retraining the base model and without accessing attention matrices at inference time. To this end, we propose mmVB, a lightweight plug-and-play module that assigns query-conditioned per-image token budgets via cross-image context, adding only 1.6M trainable parameters while reducing visual input tokens by 9x. This reduction yields 5x faster time-to-first-token and 7x fewer prefill FLOPs, while maintaining 94.4% of full-resolution accuracy across eight multi-image reasoning benchmarks.

## 1. 核心问题与研究动机

- **背景**：多模态大语言模型（MLLM）虽已支持多图输入，但主流设计仍针对单图优化。多图推理时，每张图都会引入大量视觉 token，显著抬升视觉编码、注意力计算、显存占用与首 token 延迟（TTFT），在商品目录理解、跨图比较、检索等真实场景中难以在受限推理预算下扩展。
- **现有方法的局限**（论文归纳为三类挑战）：
  - **系统可扩展性差**：多数免训练方法依赖读取多层注意力矩阵估计 token 重要性，与 FlashAttention 等不物化稠密注意力图的推理内核不兼容，也难以用于纯 API 模型；token 合并还会破坏位置编码（如 M-RoPE）结构。
  - **多图场景研究不足**：现有剪枝/合并方法假设冗余是单图内空间局部的，而多图任务（如"图 1 与图 2 有何区别"）需要跨图保留细粒度证据直到推理后段，早期激进压缩会删除比较、计数、时序推理所需信息；视频压缩方法假设帧间相似性，对多图不成立。
  - **训练依赖与分布偏移**：学习式压缩器/适配器需重训基座或改变输入分布，代价高且可能损害原推理行为。
- **关键洞察**：近期证据表明，在同等 token 预算下简单图像降采样可优于复杂的后编码压缩（Liao et al., 2026），说明"在视觉编码器之前/之中做分辨率选择"更具潜力。
- **研究目标**：在不重训基座模型、不在推理时访问注意力矩阵的前提下，实现可扩展、兼容高效推理、适用于单图与多图、且可用于冻结/黑盒 MLLM 的视觉 token 缩减。

## 2. 方法论：mmVB（多模态视觉预算器）

### 2.1 核心思想
- 将多图推理形式化为**视觉预算分配问题**：在给定查询 Q 与 N 张图时，估计每张图使下游 MLLM 正确回答所需的**最小相对视觉尺度**，即给每图分配离散等级 ℓᵢ ∈ {0,1,2,3,4}（对应约 1/4/16/64/256 个视觉 token，即 4× 递增的分辨率档位）。
- 分配是**查询条件化**且**跨图联合**的：不仅决定"每图多少 token"，还隐式学习"哪张图与查询更相关"。
- 分配发生在**视觉编码之前**，因此同时节省视觉编码器与 LLM 的 prefill 计算（这是相对所有后编码基线的根本差异）。

### 2.2 架构细节
- **图像编码**：冻结的 ImageNet 预训练 EfficientNet-B0 编码每张图，1280 维特征经线性层 + Dropout 投影到共享维度 d=256（仅处理低分辨率缩略图，成本远低于跑 MLLM 视觉编码器）。
- **文本编码**：查询经冻结的 MLLM embedding 层，均值池化后通过 **64 维瓶颈**（Linear→ReLU→Dropout 0.3→Linear→LayerNorm）映射到 256 维；窄瓶颈用于抑制记忆化、保留任务相关信号。
- **上下文融合**：查询 token + N 个图像 token 构成 N+1 序列，送入 **2 层、4 头 Transformer**（FFN 维 512），执行查询条件化的跨图推理。
- **分辨率头**：共享 MLP（256→64→4）输出 4 个序数 logits，P(ℓᵢ≥k)=σ(z_{i,k})，预测等级为四个阈值大于 0.5 的指示之和；四个阈值独立训练、无显式单调约束，但序数损失在实践中保证阈值有序。
- **推理**：按预测等级缩放图像（**从不放大**，以原尺寸为上限）后送入 MLLM。
- **规模**：约 **1.6M 可训练参数**（图像投影 328k、文本编码 181k、Transformer 1,054k、分辨率头 17k），冻结 EfficientNet-B0 另含 5.3M 参数；额外开销约 **2 ms**。

### 2.3 训练目标
- 采用**序数二元交叉熵**：对真值等级 ℓ*ᵢ，构造累积目标 y_{i,k}=1[ℓ*ᵢ≥k]（k=1..4），损失为四个阈值 BCE 之和。
- 该形式保持等级有序性：预测越接近真值，违反的阈值越少、惩罚越小（如真值 3 时预测 2 只违反一个阈值，预测 0 违反三个），对标签噪声更鲁棒。

### 2.4 训练标签生成（Algorithm 1，三轮流程）
1. **预检查**：全分辨率下答错则丢弃样本（保证标签生成的有效性）。
2. **第一轮 独立升序搜索**：对每图从 0 到 4 扫描，取第一个使 MLLM 答对的等级（不假设准确率随分辨率单调）。
3. **第二轮 联合验证**：所有图同时取各自等级，若仍答对则返回。
4. **第三轮 迭代松弛**：最多 K=5 轮，先逐图 +1 尝试，再全体 +1，仍失败则回退 (4,…,4)（预检查保证该回退有效）。
- **标签性质**：返回的是"充分可行分配"而非可证最小分配；贪心松弛可能找不到最便宜的子集组合，因此**偏保守（可能多分配、绝不欠分配）**，训练目标偏向保真而非过度压缩。
- **训练数据**：单图 484k 样本（30k 图，来自 VQAv2/TextVQA/GQA，同图多查询提供对比信号）+ 多图 50k 样本（Mantis-Instruct，17 个子集），采用先单图后多图的课程训练。

### 2.5 预算约束下的部署扩展
- 给定总预算 B（Σbᵢ ≤ B），从所有图的最低等级出发，每次选择**效用/成本比** u_{i,k}/Δb_k = σ(z_{i,k})/(b_k−b_{k−1}) 最大的"升级"动作，贪心直至预算耗尽；这是免训练的、近似多选背包的解法，优先保障查询相关图像。
