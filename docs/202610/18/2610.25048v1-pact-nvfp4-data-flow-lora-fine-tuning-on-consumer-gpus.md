## 摘要
在消费级 GPU 上微调语言模型受限于计算和内存。尽管 LoRA 减少了可训练参数和优化器状态，但冻结投影仍然开销高昂，而为反向传播保留的激活可能主导内存使用。我们提出 PACT，一个 LoRA 微调系统，它使用原生 NVFP4 GEMM 加速冻结投影，同时减少量化和反量化开销并限制量化误差。为降低激活内存，PACT 复用量化后的 RMSNorm 输出，并以 NVFP4 保存 gate/up 激活用于反向传播。为限制数值误差，它为前向非线性运算保留 BF16 输入，并使用适配 NVFP4 缩放因子和量化激活的 GPTQ 离线校准冻结权重。融合非线性内核以及缓存的前向和反向权重布局减少了量化和反量化开销。在 16 GB RTX 5080 上跨多个模型和任务的评估显示，内存占用更低、LoRA 微调更快且精度具有竞争力，使模型适配可在资源受限的消费级硬件上进行。

## Abstract
Fine-tuning language models on consumer GPUs is constrained by computation and memory. Although LoRA reduces trainable parameters and optimizer state, frozen projections remain expensive, and activations retained for backward can dominate memory usage. We present PACT, a LoRA fine-tuning system that accelerates frozen projections with native NVFP4 GEMMs while reducing quantization and dequantization overhead and limiting quantization error. To reduce activation memory, PACT reuses quantized RMSNorm outputs and saves gate/up activations in NVFP4 for backward. To limit numerical error, it preserves BF16 inputs for forward nonlinear operations and calibrates frozen weights offline using GPTQ adapted to NVFP4 scales and quantized activations. Fused nonlinear kernels and cached forward and backward weight layouts reduce quantization and dequantization overhead. Evaluations across multiple models and tasks on a 16\,GB RTX~5080 show lower memory usage and faster LoRA fine-tuning with competitive accuracy, enabling model adaptation on resource-constrained consumer hardware.

# PACT：消费级 GPU 上的 NVFP4 数据流 LoRA 微调 —— 论文结构化总结

## 1. 核心问题与研究动机

- **背景**：大模型微调逐渐走向端侧/私有数据场景（个性化、隐私保护、持续学习），实际目标常是 1B–3B 的小语言模型（SLM）。这类模型虽能在消费级 GPU 上加载，但**训练时的算力与显存压力依然严峻**。
- **LoRA 的局限**：LoRA 冻结预训练权重、只训练低秩适配器，显著减少了梯度与优化器状态；但**冻结投影仍需在前向计算、在反向传播输入梯度**，计算量并未减少。
- **激活内存主导**：图 1 显示，在 batch=4 的 BF16 LoRA 中，随序列长度从 512 增至 2048，激活占峰值显存的比例从 47% 升至 78%，**激活而非权重成为主要显存瓶颈**。
- **现有方法的不足**：
  - QLoRA 只压缩冻结权重为 4-bit，计算与激活仍为高精度；
  - 混合精度训练（如 NVFP4 TE）量化 GEMM 操作数，但**仍以较高精度保留反向激活**，显存收益有限。
- **硬件契机**：NVIDIA Blackwell 提供原生 NVFP4 矩阵乘，实测 6–7× 快于 BF16 GEMM（表 1，如 query 层 0.690ms → 0.113ms）。
- **核心命题**：需要**联合设计计算精度与激活存储的数据流**，在利用 NVFP4 加速的同时控制量化误差与量化/反量化开销。

## 2. 方法论

### 2.1 核心思想
以原生 NVFP4 GEMM 加速全部 7 个冻结投影的前向与输入梯度计算，同时把部分反向激活以 NVFP4 存储；通过“保留 BF16 关键路径 + 离线校准 + 融合内核 + 权重布局缓存”抑制数值误差与转换开销。

### 2.2 关键技术细节

- **NVFP4 GEMM 加速（3.1 节）**
  - 前向：`Y = X̃W̃₀ᵀ`，NVFP4×NVFP4，FP32 累加、BF16 输出；
  - 输入梯度：`∇X ≈ Q(∇Y)·W̃₀,b`，同样使用 NVFP4 GEMM；
  - 量化融合进 RMSNorm 与 SiLU-multiply 内核，直接写 NVFP4 输出，避免额外量化核与高精度中间缓冲；
  - 输入梯度 GEMM 前，用 FP32 张量尺度 + UE4M3 块尺度量化 BF16 梯度。
- **LoRA 分支保持 BF16（公式 5–8）**
  - 前向：`Y = X̃W̃₀ᵀ + (X̄Aᵀ)Bᵀ`，基座项走 NVFP4，适配器项走 BF16；
  - 反向：`∇X ≈ Q(∇Y)W̃₀,b + (∇YB)A`，`∇B = (∇Y)ᵀ(X̄Aᵀ)`，`∇A = (∇YB)ᵀX̄`；
  - 按括号顺序先与秩 r 因子收缩，避免物化稠密的 BA 更新矩阵，适配器计算复杂度与 `bsr(din+dout)` 成正比。
- **激活存储压缩（3.2 节）**
  - **RMSNorm 输出复用**：不再单独保存归一化输入，而是复用为 Q/K/V 投影生成的 NVFP4 输出，并保存 FP32 每 token 统计量 `rₓ`；反向用近似式 `∇x ≈ rₓ[γ⊙∇y − (ȳ/γ)·mean(ȳ⊙∇y)]` 重建，省去一份输入张量；
  - **SiLU-multiply 压缩**：前向用原始 BF16 gate/up 值计算 `z = SiLU(g)⊙u` 以保证前向精度，同时在同一融合核中写出 NVFP4 的 g、u 副本供反向使用，随后释放 BF16 原值；反向在核内重建 `ḡ、ū` 并计算 `∇g ≈ ∇z⊙ū⊙SiLU′(ḡ)`、`∇u ≈ ∇z⊙SiLU(ḡ)`；
  - **存储量估算（公式 12）**：每层约 `0.56U（两个 norm 输出）+ 1.50U（gate/up）+ 4U（attention）= 6.1U`，对比 BF16 LoRA 的 12.3U，**理论激活存储约减半**；NVFP4 含块尺度约为 BF16 的 28%。
- **离线权重量化与校准（3.3 节）**
  - **NVFP4 感知的尺度选择**：对每组 16 个权重，枚举 9 个候选因子（1.5、1.25、1.0、0.95、0.90、0.85、0.80、0.75、0.70），先舍入到 UE4M3 再以 E2M1 衡量重建误差，选 L2 误差最小者并固定；
  - **量化激活下的 GPTQ 校准**：用重建后的 NVFP4 输入 `X̄ = D(Q(X))` 构造 Hessian `H = (2/m)X̄ᵀX̄`，最小化 `‖X̄W₀ᵀ − X̄Ŵ₀ᵀ‖²_F`，逐列量化并用逆 Hessian 补偿误差，使校准目标与训练时激活精度一致；
  - **前向/反向权重布局缓存**：NVFP4 沿 GEMM 归约维分组，前向为 `din`、反向为 `dout`，简单转置无法得到反向布局，故重建-转置-沿新归约维重新量化为 `W̃₀,b`，两种布局均离线缓存，训练循环内无重复量化。
- **精度分配（表 7）**：7 个冻结投影用 NVFP4；RMSNorm、SiLU、注意力、残差、LoRA 分支保持 BF16/FP32；注意力反向状态仍为 BF16。

## 6. 主要结论与发现

- **精度**：分类平均精度较 zero-shot 提升 11+ 个百分点；相对 BF16 LoRA 平均差距为 0.9–1.3 点（Llama-3B、Qwen2.5-1.5B），Llama-1B 为 2.6 点；在三个模型上平均精度均**超过 NVFP4 TE**，并接近 QLoRA（差距 ≤0.3 点）。
- **生成**：在 9 个模型-任务组合中的 8 个超过 TE，整体接近 QLoRA；Llama-3B 在 SQuAD 上略超 BF16（0.842 vs 0.837）、SAMSum 持平；**GSM8K 最敏感**，PACT 一致落后 BF16 约 2 点。
- **多模态**：用图像 prompt 校准（而非 WikiText 文本）后 ScienceQA 精度从 0.876 提升到 0.917，与 BF16 LoRA（0.936）差距缩至 1.9 点，说明**校准数据代表性对量化误差影响显著**。
- **效率**：序列 1024、batch 4 下，较 BF16 LoRA **峰值显存降低 47%–51%、步时间加速 1.7–1.9×**；使 Llama-3B 在 BF16 会 OOM 的配置下可训练；序列 2048 时是唯一能在 batch 4 放下 Llama-3B 的方法（13.11 GB）。
- **容量与吞吐**：最大可容纳 batch 由 BF16 的 10/2/4 提升到 26/10/16；吞吐为 BF16 的 1.85–2.41×、QLoRA 的 1.75–2.32×、TE 的 1.17–1.28×。
- **端到端**：在 BoolQ 与 ARC-Easy 上墙钟训练时间最短。
- **与重计算/压缩方法互补**：PACT + 梯度检查点可进一步把峰值显存压到 2.27 GB，且比“BF16 + 检查点”快 1.95×；相对 HyC-LoRA，PACT 在省内存的同时还降低步时间（HyC-LoRA 2-bit 省 37% 内存但步时间增 13%）。

## 7. 优点

- **计算与存储联合设计**：不止加速 GEMM，还系统性地把反向

激活压缩纳入统一数据流，使显存与时间收益同时成立——这正是多数“仅量化 GEMM”方案（如 NVFP4 TE）做不到的；后者虽把矩阵乘降到 4-bit，却因反向激活仍为高精度而只拿到有限显存收益。

- **量化误差的多层控制而非单点修补**：从 NVFP4 感知的尺度枚举搜索、量化激活下的 GPTQ 校准，到“关键路径保 BF16”（RMSNorm、SiLU、注意力、残差、LoRA 分支）、再到用代表性数据（图像 prompt）做校准，形成了一条从权重到激活、从离线到在线的完整误差控制链；多模态实验中 0.876→0.917 的提升也说明作者对“校准数据分布”这一常被忽视的因素有清醒认识。

- **工程实现细致且可复现**：量化融合进 RMSNorm 与 SiLU-multiply 内核以避免额外 kernel 与高精度中间缓冲；前向/反向两套 NVFP4 权重布局离线缓存，规避训练循环内的重复量化；反向按括号顺序先与秩 r 因子收缩，避免物化 d×d 的 BA 稠密矩阵。这些细节决定了“理论上的 2× 加速”能否真正落到 1.7–1.9× 的实测值。

- **实验设计兼顾多维指标**：不止报告精度，还给出固定形状下的步时间/峰值显存、最大可容纳 batch、吞吐、端到端墙钟时间，并补充与梯度检查点、HyC-LoRA 的正交/对比实验，使“PACT 与重计算、与激活压缩方法互补而非替代”的定位有据可依。

- **硬件针对性强、落地价值明确**：以单张 16 GB RTX 5080 为平台，直接回答“消费级 GPU 能否微调 1B–3B 模型”这一现实问题；Llama-3B 在 BF16 会 OOM 的配置下可训练、序列 2048 时是唯一能在 batch 4 放下的方法，这类结论对端侧/私有化微调场景具有很强的实践指导意义。

## 8. 局限与可改进之处

- **硬件依赖性强**：方法深度绑定 Blackwell 的原生 NVFP4 矩阵乘单元（6–7× 的 GEMM 加速是收益的主要来源），在 Hopper/Ada 或非 NVIDIA 平台上难以直接复现；论文未讨论在缺乏 FP4 原生支持时的降级方案（如以 FP8 替代部分路径）。

- **规模与配置覆盖有限**：仅验证 1B–3B 模型、rank-16、LoRA 仅作用于 Q/V、单卡单机。未考察更大模型、全投影适配、更高 rank、多卡数据并行/张量并行下的表现——而在多卡场景中，激活压缩带来的通信量下降可能反而是新的收益点，这一点未被触及。

- **缺少系统性消融**：未逐组件剥离（RMSNorm 输出复用、SiLU-multiply 压缩、GPTQ 校准、尺度搜索、融合内核、布局缓存）来量化各设计对精度与速度的独立贡献，读者难以判断“哪一项是必需的、哪一项是锦上添花”，也削弱了方法对后续工作的可迁移性。

- **精度差距尚未消除且任务依赖性明显**：相对 BF16 LoRA 仍有 0.9–2.6 点差距，GSM8K 这类多步推理任务一致落后约 2 点，说明 4-bit 激活对需要长链数值一致性的任务更为敏感；论文未分析误差在推理链上的累积机制，也未提出针对性的缓解手段（如对特定层保留更高精度）。

- **校准数据的代表性仍是隐性超参**：多模态实验表明校准集选择可带来 4 个点以上的差异，但论文未给出选择校准数据的一般性原则或敏感性曲线，实际使用中这可能成为一个需要反复试错的环节。

- **部分对比非严格同条件**：端到端时间由“中位数步时间 × 更新数”估算而非真实墙钟测量；HyC-LoRA 的对比作者也承认不可跨实现直接比较；QLoRA 基线未启用梯度检查点，而 PACT 在附录中又与检查点组合，基线的“最强形态”未被完整呈现。

- **未与更广泛的参数高效微调/低精度训练工作对比**：如 LoRA-FA、DoRA、以及 8-bit/4-bit 优化器状态压缩等工作均未纳入，难以判断 PACT 在整个“省显存微调”谱系中的相对位置。

## 9. 总体评价与启示

PACT 的核心贡献不在于发明新的量化格式或新的 LoRA 变体，而在于**指出并解决了“LoRA 微调中激活而非权重才是显存瓶颈”这一被长期低估的结构性问题**，并给出了一套计算精度（NVFP4 GEMM）与存储精度（NVFP4 反向激活）协同设计、同时以多重手段兜住数值误差的完整工程方案。其方法论层面的启示有三点值得后续工作借鉴：

1. **瓶颈识别优先于技术堆叠**：正是先通过 profiling 明确了激活占峰值显存 47%→78% 的走势，才使后续每一项设计都有明确的优化目标；
2. **“关键路径保高精度 + 非关键路径激进量化”的精度分配原则**可推广到其他低精度训练场景，其本质是把有限的数值预算花在对梯度/损失最敏感的算子上；
3. **量化误差的控制必须与训练时的真实数据分布对齐**（量化激活下的 GPTQ、用任务相关数据校准），否则离线校准的收益会在在线训练中大打折扣。

总体而言，这是一篇问题定义清晰、工程完成度高、实验较为扎实的系统性工作，其价值更多体现在“把 4-bit 数据流真正跑通在消费级 GPU 的 LoRA 微调上”这一系统贡献，而非单项技术创新；若能在消融完整性、更大规模验证与精度差距弥合上进一步补强，其影响力与可信度还会显著提升。
