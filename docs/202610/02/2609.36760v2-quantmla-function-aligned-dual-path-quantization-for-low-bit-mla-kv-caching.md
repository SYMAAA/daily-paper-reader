## 摘要
多头潜在注意力（MLA）通过其内容路径与解耦 RoPE 路径的紧凑缓存，实现了富有表现力的多头注意力，但缓存内存仍随上下文长度和批量大小线性增长。在本工作中，我们建立了 MLA 双路径量化误差的系统性模型，刻画了它们对注意力输出失真的不同影响，并解释了 RoPE 路径误差的显著放大现象。在该分析指导下，我们提出 QuantMLA，一个面向低比特双路径量化的功能对齐框架。我们推导出路径特定的变换空间，这些空间在保持全精度计算的同时可完全离线融合进模型参数，从而消除在线变换开销。在这些空间内，QuantMLA 以功能对齐的目标学习路径特定变换：注意力输出重建捕获内容路径中耦合的匹配与聚合误差，而位置 QK 重建保留注意力 logits 中由 RoPE 诱导的分量，并给出输出失真的理论界。在四个 MLA 模型系列上，QuantMLA 据我们所知首次实现了内容缓存与 RoPE 缓存的联合 INT4 缓存，且精度下降极小。进一步将内容缓存压缩至 INT2、同时将 RoPE 键缓存保持为 INT4，在具有挑战性的推理和代码基准上仍保持有竞争力的性能。我们开发了原生低比特 MLA 注意力内核，将解包与反量化直接集成到注意力计算中。物理缓存布局在 128K 上下文下提供 3.59 倍压缩，而缓存压力服务负载相比 BF16 实现了 5.168 倍的全作业输出吞吐量提升。代码将在论文被接收后发布。

## Abstract
Multi-Head Latent Attention (MLA) enables expressive multi-head attention with compact caches for its content and decoupled RoPE paths, yet cache memory still scales linearly with context length and batch size. In this work, we establish a systematic model of MLA's dual-path quantization errors, characterizing their distinct effects on attention-output distortion and explaining the pronounced amplification of RoPE-path errors. Guided by this analysis, we introduce QuantMLA, a function-aligned framework for low-bit dual-path quantization. We derive path-specific transformation spaces that preserve full-precision computation while remaining fully fusible into model parameters offline, eliminating online transformation overhead. Within these spaces, QuantMLA learns path-specific transformations with function-aligned objectives: attention-output reconstruction captures the content path's coupled matching and aggregation errors, while positional QK reconstruction preserves the RoPE-induced component of the attention logits and admits a theoretical bound on output distortion. Across four MLA model families, QuantMLA enables, to our knowledge, the first reported joint INT4 caching of the content and RoPE caches with minimal accuracy degradation. Further compressing the content cache to INT2 while retaining the RoPE key cache at INT4 maintains competitive performance on challenging reasoning and code benchmarks. We develop a native low-bit MLA attention kernel that integrates unpacking and dequantization directly into attention computation. The physical cache layout provides 3.59x compression at 128K context, while a cache-pressure serving workload achieves 5.168x higher whole-job output throughput than BF16. The code will be released upon acceptance.

## 1. 核心问题与整体含义

- **研究背景**：多头潜在注意力（MLA）通过“共享低秩内容潜变量 + 解耦 RoPE 键缓存”两条路径实现紧凑 KV 缓存，被 DeepSeek-V3、Kimi、LongCat、GLM 等模型采用。
- **核心问题**：MLA 缓存仍随上下文长度和批量线性增长。已有方法多将内容缓存量化为 FP8，同时保留高精度 RoPE 键缓存；低比特 RoPE 量化影响不明，内容与 RoPE 缓存的联合低比特压缩基本未被探索。
- **关键观察**：在匹配缓存重建误差（cache NMSE）下，RoPE 路径量化造成的注意力输出失真显著大于内容路径。六个模型中，RoPE/content 响应比从 1.941× 到 6.864× 不等。
- **整体含义**：缓存重建误差本身不足以衡量功能失真；MLA 双路径具有不同误差传播路径，需要路径专属的量化变换与学习目标。

## 2. 方法论：QuantMLA 的核心思想与关键技术

- **核心思想**：将 MLA 双路径的不对称性转化为“路径专属、可离线融合的变换空间”，并在这些空间内用“功能对齐目标”学习变换。
- **误差建模**：
  - 内容路径误差通过注意力匹配、值聚合及二者交互传播：  
    \(\Delta Y_C = \sum_h (\Delta A_{C,h} C B_h + A_h \Delta C B_h + \Delta A_{C,h} \Delta C B_h)\)。
  - RoPE 路径误差仅通过位置 logits 影响注意力匹配：  
    \(\Delta Y_P = \sum_h \Delta A_{P,h} C B_h\)。
  - 局部放大用 Rayleigh 商表示：  
    \(G_b(e_b)=\|J_b e_b\|_2^2/\|e_b\|_2^2=e_b^\top H_b e_b/e_b^\top e_b\)，其中 \(H_b=J_b^\top J_b\)。
  - 进一步分解为 \(G_b=T_b A_b+O_b\)：\(T_b\) 为平均算子敏感度，\(A_b\) 为量化误差能量在敏感坐标上的分配，\(O_b\) 为跨坐标方向耦合。
- **内容路径离线变换**：
  - 设内容潜变量 \(c=u\Gamma\)，其中 \(u=\text{RMSNorm}_1(x)\)。
  - 引入正交旋转 \(R_C\) 和正通道缩放 \(S_C\)，令 \(z_C=u R_C S_C\)，并将补偿吸收到消费投影：\(\tilde W=S_C^{-1}R_C^\top \Gamma W\)。
  - 保持全精度计算等价 \(z_C\tilde W=cW\)，且因 weightless RMSNorm 旋转等变，可完全离线融合。
- **RoPE 路径离线变换**：
  - RoPE 前变换必须与位置旋转交换，因此只允许按频率对的块对角旋转 \(R_P=\text{blockdiag}(R_i)\) 和块对角正缩放 \(S_P=\text{blockdiag}(s_i I_2)\)。
  - 采用互逆查询—键补偿：  
    \(Q'_P=Q_P R_P S_P^{-1}\)，\(K'_P=K_P R_P S_P\)。
  - 保持全精度位置分数 \(Q'_P(K'_P)^\top=Q_P K_P^\top\)，并可融合进 pre-RoPE 投影。
- **功能对齐学习目标**：
  - 内容路径：最小化注意力输出重建误差 \(L_C\)，捕获匹配、聚合及交互误差。
  - RoPE 路径：最小化位置 QK 重建误差 \(L_P\)，并给出输出失真理论界：  
    \(\|\Delta Y_P\|_F^2 \le \frac{\tau^2}{4}(\sum_h\|\bar V_h\|_2^2)(\sum_h\|\Omega\odot\Delta Z_{P,h}\|_F^2)\)。
- **原生低比特执行**：
  - 基于 FlashMLA decode 路径，将解包与反量化直接融入注意力计算。
  - 混合精度缓存策略：前 4 个 sink token 和最近 128 token 保留 BF16，其余低比特历史使用 INT4；所有有效 token 参与同一全局 softmax。
  - 支持内容缓存 INT4 / RoPE 键 INT4（C4R4），以及内容缓存 INT2 / RoPE 键 INT4（C2R4）。
