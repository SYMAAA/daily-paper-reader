## 摘要
使用视觉语言模型（VLM）处理长视频时，视觉令牌的二次方开销成为瓶颈，使长格式推理的成本高昂到难以承受。尽管单轴压缩方法能缓解这一问题，但由于其独立处理空间和时间冗余，因此会遇到难以突破的效率下限。我们提出 VETO（面向视觉语言模型的视频高效令牌优化），一种可选训练的即插即用模块，通过双轴压缩消除该瓶颈：（i）帧内压缩器，通过受最优传输启发的匹配来合并每帧内语义相似的令牌；（ii）帧间压缩器，识别并合并时间上冗余的帧。关键设计洞见在于分层排序：通过先压缩空间维度，VETO 大幅降低后续全局时间匹配的成本，绕过单轴方法的效率壁垒，且其优势随着现代全融合注意力基础设施的发展而增大。实验上，VETO 在保持或提升准确率的同时，推理速度最高提升 45%（例如在 LLaVA-OneVision-7B 上）。在极端令牌匮乏（10% 预算）下，VETO 以 55.7% 的准确率优于 VFlowOpt（54.9%）、VisionZip（52.6%）和 FastV（47.9%）。我们证明了其在 LLaVA-OneVision、InternVL-2.5 和 LongVA 上的普遍适用性，在所有情况下零样本准确率均得到保持或提升。

## Abstract
Processing long videos with Vision-Language Models (VLMs) is bottlenecked by the quadratic cost of visual tokens, making long-form inference prohibitively expensive. While single-axis compression methods mitigate this, they hit a hard efficiency floor because they treat spatial and temporal redundancy independently. We present VETO (Video Efficient Token Optimization for Vision-Language Models), a training-optional plug-in that eliminates this bottleneck through dual-axis compression: (i) an intra-frame compressor that merges semantically similar tokens within each frame via optimal-transport inspired matching, and (ii) an inter-frame compressor that identifies and merges temporally redundant frames. The key design insight is hierarchical ordering: by first compressing spatial dimensions, VETO drastically reduces the cost of subsequent global temporal matching, bypassing the efficiency wall of single-axis approaches, with an advantage that grows with modern fully-fused attention infrastructure. Empirically, VETO achieves up to 45% faster inference (e.g., on LLaVA-OneVision-7B) while preserving or improving accuracy. Under extreme token starvation (10% budget), VETO outperforms VFlowOpt (54.9%), VisionZip (52.6%), and FastV (47.9%) with 55.7% accuracy. We demonstrate universal applicability across LLaVA-OneVision, InternVL-2.5, and LongVA, with zero-shot accuracy preserved or improved in all cases.

## 1. 核心问题与整体含义（研究动机与背景）

- **根本瓶颈**：视觉语言模型（VLM）处理长视频时，视觉 token 数量随帧数与分辨率线性增长，而注意力开销按 token 总数的平方增长，即标准复杂度为 O((T·N)²)（T 帧、每帧 N 个 token）。多分钟视频会产生数万 token，使长格式推理成本高到难以实用。
- **现有方案的局限**：
  - 基于训练的方法需要大量算力；
  - 免训练插件（token 剪枝、合并、帧选择，如 FastV、VisionZip、VFlowOpt、ToMe、HERMES）虽可即插即用，但**几乎都只沿单一轴（空间或时间）压缩**。
  - 单轴方法的硬伤：仅做帧间压缩时，必须先在全尺寸空间 token 上计算全局相似度，引入**硬件级的延迟下限（efficiency floor）**，无法实现最优的速度–精度权衡。
- **整体含义**：VETO 主张空间与时间冗余是互补的，应通过**双轴压缩 + 严格的分层顺序（先帧内、后帧间）**来突破单轴方法的效率墙，且该优势在融合注意力（如 FlashAttention-2）等现代推理栈上**不缩小反而扩大**——因为融合内核能吸收单帧空间缩减，却无法吸收总序列长度的缩减。

## 2. 方法论

### 2.1 核心思想
- VETO 是一个**可选训练（training-optional）的即插即用模块**，置于冻结的视觉编码器与冻结的 LLM 之间，仅做纯张量变换，无需自定义 CUDA 内核或架构改动。
- 关键设计洞见是**分层排序（hierarchical ordering）**：先做空间压缩把每帧维度从 N 降到 N/k，再在已缩小的特征空间上做全局时间相似度匹配，从而大幅降低时间匹配成本。

### 2.2 问题形式化
- 给定视频 V = {I₁,…,I_T}，视觉编码器输出记忆库 M ∈ R^{B×T×N×C}。
- 目标：求压缩函数 f_intra: R^{B×T×N×C} → R^{B×T×N′×C} 与 f_inter: R^{B×T×N′×C} → R^{B×T′×N′×C}（N′<N, T′<T），在语义保真度 D 下最小化下游任务性能损失。

### 2.3 帧内压缩器（Intra-Frame Compressor）
- 对每帧 token 特征 X_t ∈ R^{N×C} 采用**受最优传输启发的 k-way 划分**：
  - 按索引模 k 划分出“目的地锚点” X_dst（N_dst = ⌊N/k⌋）与“源 token” X_src（N_src = N − N_dst）。
  - 计算源–锚点余弦相似度矩阵 S，每个源 token 分配到余弦最近的锚点：idx_i = argmax_j S_{i,j}。
  - 按**尺寸加权平均**合并：合并后 token = (Σ_{i:idx_i=j} X_src,i + X_dst,j) / (|{i:idx_i=j}| + 1)。
  - 空间 token 数由 N 降至约 N/k。
- **为何用均匀（模 k）划分而非内容自适应锚点**：均匀划分保证每个空间区域恰有一个锚点，覆盖完整；内容自适应锚点会把锚点集中到显著区域、导致边缘区域无有效目的地，引发空间塌缩。内容自适应性被保留在“合并步骤”（余弦最近匹配）中；若再加锚点打分需额外 O(N²) 开销，得不偿失。
- **位置信息**：在冻结 ViT 输出上操作，绝对位置信息已烘焙进 token；压缩后作为平坦视觉前缀送入 LLM（LLaVA 式惯例）。对 RoPE 时间嵌入模型（如 LongVA），LLM 在合并后按序分配索引；帧内合并组至多跨越 k 个连续位置，位置漂移有界，消融验证无害。

### 2.4 帧间压缩器（Inter-Frame Compressor）
- 在帧内压缩之后运行，于 N′ 维空间上计算时间相似度：
  - 空间均值池化得到帧表示 F_t = (1/N′)Σ_n M′_{:,t,n,:} ∈ R^{B×C}；
  - 计算 T×T 余弦相似度矩阵 G，配合有效对掩码 W（仅 i<j 且两帧均活跃）；
  - **贪心算法**每步选取 top-m 个最相似且不重叠的帧对，按压缩尺寸加权平均合并（M″_{j_k} = (M′_{i_k}·s_{i_k} + M′_{j_k}·s_{j_k})/(s_{i_k}+s_{j_k})），迭代直到帧数降至 T′。
  - 迭代次数等于帧数减少量（如 64→48 需 16 次），而非视频长度，开销很小。

### 2.5 复杂度分析（附录 7）
- Vanilla：O(T²N²)。
- VETO 总成本：**O(T·N²/k + T²·C + G²T²N²/k²)**，其中 C 为固定隐藏维度、C ≪ N，第二项可忽略。
- 注意力加速比 = (k/G)²；默认 k=2、G=0.75 时约 **7.1×** 的注意力 FLOPs 缩减。
- 压缩开销（帧内+帧间）约占 vanilla 注意力的 **0.7%**，可忽略。
- 单轴对比：Intra-only 约 4× 缩减；Inter-only 约 1.8×；双轴使二者**相乘复合**为 7.1×。且 Inter-only 必须在全 N 空间向量上算 T×T 相似度，引入延迟下限，故实测延迟为 VETO 的 1.16×。

## 6. 主要结论与发现

- **Finding 1（同 backbone 优势）**：LLaVA-OneVision-7B 上，VETO 在 VideoMME 保持 58.9%（与 Vanilla 持平）同时延迟降至 0.85×（15% 降低），而 ToMe 仅 4%、HERMES 仅 7%，**VETO 的领先幅度是 ToMe 的 3.75 倍且零精度损失**。
- **Finding 2（顺序最优）**：所有其他排序都更慢——Intra-only 1.10–1.14×、Inter-only 1.16×、Inter-first 1.07–1.09×；**只有 Intra-first 同时取得最佳精度与最低延迟**。Inter-first 即便最终 token 数相同，也因在 N 维（而非 N/k 维）上算时间相似度而多付 2 倍成本。
- **Finding 3（完全监督下 SOTA）**：MovieChat-1K 上 VETO 达 **80.6%**，比同 backbone（InstructBLIP + vicuna-7B）的 HERMES（78.6%）高 2.0%，说明压缩不仅保持、还能**增强**长程理解。
- **Finding 4（空间宽容、时间敏感）**：帧内 k∈{2,3,4,5}（保留 20–50% 空间 token）精度波动 <0.6%；帧间 G=0.125（保留 12.5% 帧）时精度下降 6.8%。推荐默认 **k=2、G_ratio ≥ 0.75**。
- **Finding 5（极端预算鲁棒）**：10% token 预算下 VETO 达 **55.7%**，是唯一超过 55% 的方法，优于 VFlowOpt（54.9%）、VisionZip（52.6%）、FastV（47.9%）。
- **跨架构通用性**：LongVA-7B 上两个 benchmark 同时取得最佳精度与延迟（53.5%/0.90×、53.0%/0.86×）；InternVL-2.5-1B 上以 19% V100 延迟降低换取竞争性精度（48.1% vs 49.2%）；EgoSchema 上 LLaVA-OV-7B 延迟降 40% 且精度持平（60.2%）；图像任务上 MME 感知分不变（418/1580）且提速 12%，MMMU 48.3%（vs 48.8%）提速 27%。
- **硬件趋势结论**：融合注意力内核能吸收单帧空间缩减，但无法吸收
