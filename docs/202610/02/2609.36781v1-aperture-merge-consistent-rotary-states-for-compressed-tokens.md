## 摘要
token 压缩将来自多个位置的内容合并起来，而旋转位置嵌入通常只给合并后的 token 分配一个坐标。我们追问：哪些位置信息必须在后续合并中保留下来。Aperture 存储 token 加权支撑在模型旋转频率处的傅里叶矩。我们证明，在足以实现所选期望旋转交互的连续状态中，这些矩具有最小的实维数。所表示的质量使更新具有可加性；注意力归一化仍然是独立的读出选择。均匀区间给出中心旋转乘以 sinc 增益。我们刻画了中心何时决定区间宽度，并构造了它们不决定区间宽度的匹配示例。数值检验验证了加权支撑实现。在训练过的时序读取器中，压缩迁移随增益校准和特征放置而变化。在一项预先指定的原生视频问答比较中，存储的支撑达到 65.63% 的准确率，而部署的合并规则为 67.12%。这些结果将压缩下的精确位置保持与下游收益区分开来。

## Abstract
Token compression combines content from several positions, yet rotary position embeddings usually assign the merged token one coordinate. We ask what positional information must survive later merges. Aperture stores Fourier moments of the token's weighted support at the model's rotary frequencies. We prove that these moments have minimal real dimension among continuous states sufficient for the selected expected rotary interactions. Represented mass makes updates additive; attention normalisation remains a separate readout choice. Uniform intervals give a centre rotation times a sinc gain. We characterise when centres determine interval widths and construct matched examples where they do not. Numerical checks verify the weighted-support implementation. In trained temporal readers, compression transfer varies with gain calibration and feature placement. In a prespecified native video question-answering comparison, stored support reaches $65.63\%$ accuracy versus $67.12\%$ for the deployed merging rule. These results separate exact positional preservation under compression from downstream benefit.

## 2. 论文提出的方法论

### 2.1 核心思想：把 token 视为测度，位置状态随内容一起聚合

- 每个 token \(x_i\) 对应一个概率测度 \(\mu_i\)，描述其来源位置与非负权重。
  - 点观测：\(\delta_t\)；均匀池化区间：均匀区间测度。
- 凸池化规则下，\(x=\sum_j \alpha_j x_j\) 携带测度 \(\mu=\sum_j \alpha_j \mu_j\)，\(\alpha_j\ge 0\)，\(\sum_j\alpha_j=1\)。
- 位置状态应与内容使用**相同的聚合权重**，从而支持自底向上的合并，而无需回访源位置。

### 2.2 Aperture 状态定义与合并一致性

- **定义 1**：对选定频率 \(\Theta=\{\theta_1,\dots,\theta_M\}\)，
  \[
  z(\mu)=\big(\phi_{\theta_m}(\mu)\big)_{m=1}^M,\quad
  \phi_\theta(\mu)=\int e^{i\theta t}\,d\mu(t).
  \]
- 满足仿射性（合并一致性）：
  \[
  z\!\left(\sum_j \alpha_j \mu_j\right)=\sum_j \alpha_j z(\mu_j).
  \]
- **存储形式**：携带质量 \(\rho_i\) 与未归一化复矩 \(Z_i\)：
  \[
  (\rho_i,Z_i)=\left(\nu_i(\mathbb R),\int (e^{i\theta_m t})_{m=1}^M d\nu_i(t)\right),\quad
  (\rho,Z)=\sum_i(\rho_i,Z_i),\quad z=Z/\rho.
  \]
  - 更新可加、结合，每次合并 \(O(M)\)，无学习参数。
  - 质量使摘要可复用：相同归一化状态但不同质量的 token，在与同一第三 token 合并后会产生不同结果。

### 2.3 最小性与因子分解定理

- **定理 1**：
  - (i) 任何弱连续仿射状态 \(S:\mathcal P(D)\to\mathbb C^M\)，若在点测度上满足 \(S(\delta_t)=(e^{i\theta_m t})_{m=1}^M\)，则必与 \(z\) 一致；有限混合上仅需仿射与点标定。
  - (ii) 任何仿射或弱连续状态 \(T:\mathcal P(D)\to\mathbb R^d\)，若能确定所选频率下的期望旋转交互（任意固定 query、key 与点探针），则 \(d\ge 2M\)。Aperture 状态 \(z\) 达到该下界。
  - 仿射情形下，充分性等价于因子分解：\(T\) 确定这些交互当且仅当 \(z\) 是 \(T\) 的仿射函数。任何最小仿射充分状态都与 \(z\) 相差一个可逆仿射变换。
- 直观：点探针可恢复每个矩的实部与虚部；\(1,\cos(\theta_m t),\sin(\theta_m t)\) 的线性无关性给出 \(2M\) 维单纯形，从而给出维度下界。

### 2.4 均匀区间特例：中心旋转 × sinc 增益

- 均匀区间（中心 \(c\)、宽度 \(w\)）：
  \[
  z_m=e^{i\theta_m c}\,\mathrm{sinc}(\theta_m w/2),\quad
  \mathrm{sinc}(u)=\sin(u)/u,\ \mathrm{sinc}(0)=1.
  \]
- 实坐标下：
  \[
  \tilde q_i^\top \tilde k_j
  =\sum_m g_m(w_i)g_m(w_j)\,q_i^{(m)\top}R_m(c_j-c_i)k_j^{(m)},\quad
  g_m(w)=\mathrm{sinc}(\theta_m w/2).
  \]
- 期望核恒等式：独立抽取 \(t_i\sim\mu_i\)、\(t_j\sim\mu_j\) 时，
  \[
  \mathbb E[R_m(t_j-t_i)]=g_m(w_i)g_m(w_j)R_m(c_j-c_i).
  \]
- 增益包络：\(|g_m(w)|\le \min(1,2/(|\theta_m|w))\)；点极限为 RoPE；零点在 \(\theta_m w=2k\pi\)。
- 自配对采用独立抽取约定，对角项为 \(g_m(w_i)^2\)，而非相同抽取的 \(R_m(0)=I_2\)。

### 2.5 存储与读出分离：终端归一化

- 终端映射：
  \[
  h_\eta(z)=z/\max(\eta,r(z)),\quad r(z)=\Big(M^{-1}\sum_m|z_m|^2\Big)^{1/2}.
  \]
- 作用：控制注意力 logit 幅度，同时保留精确的 \((\rho,Z)\) 以供后续合并。
- 若在每次中间合并后都做归一化并丢弃范数，通常会破坏可加性；论文的 Aperture RMS 读出只在终端应用该映射，不覆盖原始矩。
- 均匀宽度下的规范不变性：所有 token 同宽且投影不受限时，增益可吸收进 query/key 投影，两类假设类相同；但异质支撑与受限适配使该吸收不成立。

### 2.6 区间宽度可识别性：中心何时决定宽度

- 相邻区间满足：
  \[
  (Dw)_j=\tfrac12(w_j+w_{j+1})=c_{j+1}-c_j.
  \]
- 零空间由交替向量 \(u=(1,-1,1,-1,\dots)\) 张成，因此 \(w'=w+\delta u\) 在满足正性条件下保持所有中心偏移不变。
- **命题 1**：
  - 给定绝对中心与左边界 \(a\)，可递推恢复：
    \[
    w_1=2(c_1-a),\quad w_{j+1}=2(c_{j+1}-c_j)-w_j.
    \]
  - 仅绝对中心：留下交替模式。
  - 已知总跨度：奇数 \(N\) 消除该模式，偶数 \(N\) 仍保留。

  - 仅相对中心偏移时，\(\mathrm{rank}\,D=N-1\)，\(\ker D=\mathrm{span}\{(1,-1,\dots)\}\)。
