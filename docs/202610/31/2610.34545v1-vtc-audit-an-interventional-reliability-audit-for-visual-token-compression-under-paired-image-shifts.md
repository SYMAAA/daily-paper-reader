## 摘要
视觉 token 压缩通常通过干净准确率和效率来评估，但这些平均值无法揭示压缩在图像偏移下引入的失败，而此类偏移下未压缩模型仍保持正确。我们提出 VTC-AUDIT，仅在以下图像对上估计这种增量风险：完整模型在两幅图像上均正确，且压缩模型在干净图像上正确。四种实验分支随后交叉两个二元选择：哪幅图像用于选择保留的 token 位置，以及哪幅图像提供视觉特征。我们在四个任务和八种预先指定的偏移上审计了三个开放的 8-9B 视觉语言模型。我们在匹配的 25% 保留位置预算下评估了两种免训练压缩器——硬剪枝 DivPrune 与剪枝-合并 ApET——产生了 708,000 条推理记录。在偏移图像上重新选择位置，而非复用干净图像的位置，会在全部六种模型-压缩器设置中提高失败率。DivPrune 的增幅为 3.04-9.60 个百分点，ApET 的增幅为 2.05-4.20 个百分点，且所有 95% 区间均高于零。在单独重采样的第二份清单上重复审计，复现了全部六种增幅。在跨四个基准的汇总监控审计中，支持集 Jaccard 不稳定性在全部六种设置中未达到 0.65 的实际 AUROC 标准，而干净压缩模型不确定性则达到该标准。因此，在审计的基准混合下，支持集更替是弱排序信号，而干净压缩模型不确定性信息量明显更高。这些结果表明，未来的视觉 token 压缩评估应在干净准确率和效率之外报告条件可靠性。

## Abstract
Visual-token compression is usually evaluated by clean accuracy and efficiency, but these averages do not reveal failures that compression introduces under an image shift where the uncompressed model stays correct. We introduce VTC-AUDIT, which estimates this incremental risk only on pairs where the full model is correct on both images and the compressed model is correct on the clean image. The four arms then cross two binary choices: which image selects the retained token positions, and which image supplies the visual features. We audit three open 8-9B vision-language models on four tasks and eight pre-specified shifts. We evaluate two training-free compressors---hard-pruning DivPrune and prune-and-merge ApET---at a matched 25% retained-position budget, producing 708,000 inference records. Reselecting positions on the shifted image, rather than reusing the clean-image positions, raises the failure rate in all six model-compressor settings. The increase is 3.04-9.60 percentage points for DivPrune and 2.05-4.20 percentage points for ApET, with every 95% interval above zero. Repeating the audit on a separately resampled second manifest reproduces all six increases. In a pooled monitor audit across the four benchmarks, support Jaccard instability fails the practical AUROC criterion of 0.65 in all six settings, whereas clean compressed-model uncertainty clears it. Thus, support turnover is a weak ranking signal under the audited benchmark mixture, while clean compressed-model uncertainty is substantially more informative. These results suggest that future visual-token compression evaluations should report conditional reliability alongside clean accuracy and efficiency.

# VTC-AUDIT 论文结构化总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：大型视觉语言模型（VLM）把图像编码为数百至上千个视觉 token，免训练视觉 token 压缩（剪枝/合并）被广泛用于降低推理成本，但主流评测只看**干净准确率与效率**这两类平均值。
- **核心问题**：干净准确率和效率无法回答一个关键可靠性问题——**当未压缩模型在干净图和偏移图上都仍然答对时，压缩是否会在图像偏移下引入新的失败？** 这类"增量风险"会被平均值掩盖。
- **整体含义**：论文主张把"条件可靠性"（conditional reliability）作为压缩评测的第三维度，与准确率、效率并列报告；并进一步追问这种失败究竟来自"在哪张图上选 token 位置（support）"还是"用哪张图的特征"，以及支持集变动量能否作为逐样本的失败预警信号。

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想

- 在**配对图像**（干净图 $x$ 与偏移图 $x'=Tx$）上做**干预式审计**：通过交叉"哪张图选 support"与"哪张图供特征"构造四臂，把压缩特定失败归因到 support 重选通路或特征漂移通路。
- 以**条件化人群**定义估计目标：只在"未压缩模型两图都对 + 压缩模型干净图也对"的样本上测量失败率，即严格压缩特定失败率（SCFR）。

### 2.2 形式化与四臂设计

- 记视觉阶段 $V_u=\phi_u(x)$、$V'_u=\phi_u(x')$；压缩器 $m$ 由**选择器** $S_m(V)\subseteq\{1,\dots,N_u\}$（返回 $k<N_u$ 个保留索引，即 support）与**发射器** $C_m^S(V)\in\mathbb{R}^{k\times d_u}$ 组成；答案为 $g_u(C_m^S(V))$。
- 四臂（仅两点不同：support 来自哪张图、特征来自哪张图）：

| 臂 | Support | Features | 含义 |
|---|---|---|---|
| Clean | $S_m(V_u)$ | $V_u$ | 部署实际路径之一 |
| Dynamic | $S_m(V'_u)$ | $V'_u$ | 部署实际路径之二 |
| Frozen | $S_m(V_u)$ | $V'_u$ | 假设：不重选，只换特征 |
| Counterfactual | $S_m(V'_u)$ | $V_u$ | 假设：只换 support，不换特征 |

### 2.3 资格条件与 SCFR

- 资格 $E_{u,m}=1$ 当且仅当 $\sigma(\hat a^{\text{full}}_u)=\sigma(\hat a'^{\text{full}}_u)=\sigma(\hat a^{\text{cln}}_{u,m})=1$（$\sigma$ 为基准评分规则，满分 1）。
- SCFR 在 16 个 task×shift-family 单元内分别计算（严格失败 = 该臂得分为 0），再对 16 个单元等权平均；部分得分样本留在分母但不计为失败。
- 敏感性分析另用条件得分损失 $1-\sigma(\hat a)$。

### 2.4 关键对比量

- **配对重选对比**：$\Delta_{u,m}=\text{SCFR}^{\text{dyn}}-\text{SCFR}^{\text{frz}}$，固定偏移特征、只改 support 来源。
- **持续性（persistence）**：dynamic 失败中同时也在 counterfactual 臂失败的比例，用于检验"恢复干净特征后失败是否仍在"。
- **监控审计**：以 dynamic 失败为二值标签，比较两类打分器的 AUROC——
  - 支持集 Jaccard 不稳定性 $I_{u,m}=1-\frac{|S_m(V_u)\cap S_m(V'_u)|}{|S_m(V_u)\cup S_m(V'_u)|}$（方向未预设，用保守的无方向上界 $U^\pm=\max(H,1-L)$）；
  - 干净压缩模型不确定性（干净压缩答案的平均 token 负对数似然，方向预设为"越高越危险"）。
- 统计：5,000 次按基准分层的**图像簇 bootstrap**（同一图像的所有偏移一起重采样）给出 95% 百分位区间；预指定实用 AUROC 门槛 0.65。

### 2.5 两种被审计压缩器

- **DivPrune（硬剪枝）**：max–min 多样性贪心选点，$S^\star=\arg\max_{|S|=k}\min_{i\neq j\in S}(1-\cos(v_i,v_j))$；选中后丢弃其余 token，按原序还原。
- **ApET（剪枝-合并）**：FPS 选 $M=10$ 个基 token $B$，解 $\min_A\|V-AB\|_F^2$（实现用岭稳定 $\varepsilon=10^{-5}$），保留全部基 token + 近似误差 $\xi_i=\|v_i-\hat v_i\|_2$ 最大的 $k-M$ 个；被删 token 按余弦相似度归组并做组内平均合并。为使 FPS 确定，用记录 UID 哈希选初始点，且干净-偏移对使用同一初始化；frozen 臂固定干净图索引但合并指派按当前臂特征重算。
- 审计只使用 post-projector 阶段，以保证干净/偏移 token 网格对齐、support 可交换。

## 6. 主要结论与发现

- **重选 support 一致地抬高失败率**：dynamic SCFR > frozen SCFR 在全部 6 个设置成立，DivPrune 增 **3.04–9.60 pp**、ApET 增 **2.05–4.20 pp**，所有 95% 区间不含零；seed 2026 复现（DivPrune 3.09–8.71 pp，ApET 2.23–4.76 pp）。最大效应在 InternVL（DivPrune 14.24% → 4.63%）。
- **部分得分下结论不变**：以 $1-\sigma$ 计，6 个设置的 $\Delta_{\text{score}}$ 区间均高于零；TextVQA 单独看 6 个点估计全为正、5/6 区间不含零。
- **失败不只源于特征漂移**：恢复干净特征后，DivPrune 有 **74.8–81.6%**、ApET 有 **55.6–64.1%** 的 dynamic 失败仍然失败——support 本身具有实质敏感性，且该敏感性依赖压缩算子（ApET 更低）。
- **强任务依赖**：ChartQA 最敏感（DivPrune 21.86%/7.20% vs POPE 2.23%/1.33%），POPE 最不敏感；Qwen 的 ApET 例外地在 TextVQA 上最大。跨变换族平均后效应普遍为正（DivPrune 4.71–6.37 pp，ApET 2.35–3.31 pp）；48 单元中 DivPrune 47 正，ApET 41 正 / 3 零 / 4 负（最小 −0.62 pp，最大 +31.75 pp）。
- **更强偏移 ≠ 更大重选效应**：更强偏移抬高 frozen SCFR（6 设置全部），但 $\Delta/\text{SCFR}^{\text{dyn}}$ 比值在 mild→strong 时全部下降（如 InternVL-DivPrune 74.1%→60.6%），说明重选带来的增量在更强扰动下被"固定 support 本身失效"部分稀释。
- **群体效应 ≠ 逐样本可预测**：Jaccard 不稳定性 AUROC 仅 0.423–0.564，无方向上界 $U^\pm\le0.605$（DivPrune）/ 0.535–0.592（ApET），全部未达 0.65；干净压缩不确定性 AUROC 达 **0.705–0.844**，6 个设置下界均 >0.65。即"支持集更替量"是弱排序信号，而干净压缩不确定性显著更有信息量。
- **总体主张**：干净准确率与效率不足以刻画压缩的条件可靠性，应把配对可靠性审计作为常规评测的补充；frozen 臂是诊断工具而非部署策略。

## 7. 优点（方法与实验设计亮点）

- **估计目标定义清晰**：通过三重条件化把"压缩特定失败"从"模型整体错误"中剥离，避免把偏移本身导致的失败误算到压缩头上，概念上比单纯鲁棒性对比更精确。
- **四臂析因设计精巧**：用两次二元交叉把失败分解为 support 通路与 feature 通路，
