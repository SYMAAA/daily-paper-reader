## 摘要
大型视觉-语言模型在VQA任务上取得了强大性能，但处理高分辨率、信息丰富的图像需要大量计算，这促使人们进行视觉Token缩减。然而，现有方法通常对单个Token进行剪枝，或依赖固定尺寸裁剪，限制了其保留空间结构化信息（如水平或垂直延伸的文本）的能力。为了解决这一局限，我们提出ReFIT，一个面向高效LVLM推理的指令引导视觉Token缩减框架。ReFIT由相关性引导窗口重塑（RWR）和指令引导Token精炼（ITR）组成，其中RWR通过适应指令相关区域的空间特征来捕获这些区域，而ITR进一步去除不必要的视觉Token。在四个VQA基准上的实验表明，ReFIT在降低计算成本的同时提高了答案准确率，定性结果也证明了其在定位相关区域和去除不必要视觉信息方面的有效性。

## Abstract
Large Vision-Language Models achieve strong VQA performance, but processing high-resolution, information-rich images requires substantial computation, motivating visual token reduction. However, existing methods often prune individual tokens or rely on fixed-size cropping, limiting their ability to preserve spatially structured information such as horizontally or vertically elongated text. To address this limitation, we propose ReFIT, an instruction-guided visual token reduction framework for efficient LVLM inference. ReFIT consists of Relevance-Guided Window Reshaping (RWR) and Instruction-Guided Token Refinement (ITR), where RWR captures instruction-relevant regions by adapting to their spatial characteristics, while ITR further removes unnecessary visual tokens. Experiments on four VQA benchmarks demonstrate that ReFIT improves answer accuracy while reducing computational cost, and qualitative results demonstrate its effectiveness in localizing relevant regions and removing unnecessary visual information.

# 论文总结：ReFIT —— 用于加速图像理解的自适应视觉 Token 缩减

## 1. 核心问题与整体含义

- **背景**：大型视觉-语言模型（LVLM）在 VQA 等多模态理解任务上表现强劲，但面对高分辨率、信息密集的图像（小字号文本、表格、密集排版元素）时，必须依赖高分辨率输入才能捕获细粒度证据，由此产生冗长的视觉 token 序列，显著推高推理成本。
- **核心矛盾**：回答一个问题往往只需图像中极小一部分区域的信息，却要对全部视觉 token 进行前向计算，效率极低。
- **现有方法的两类局限**：
  - **Token 级剪枝**（如 ToMe、FastV、Pdrop、SparseVLM）：基于重要性逐 token 丢弃，难以保留语义跨多个相邻 token 的空间结构（如横排/竖排延伸的文本），容易造成结构碎片化。
  - **区域级选择**（如 PinPoint）：能保留局部结构，但多依赖**固定尺寸窗口/裁剪**，未显式建模文本的空间延展特征；且即便定位正确，所选区域内仍含大量与指令无关的 token，反而损害答案准确率。
- **论文整体含义**：提出 ReFIT，一个**指令引导（instruction-guided）的视觉 token 缩减框架**，目标是同时提升答案准确率与推理效率，在准确率-效率权衡上超越单纯剪枝与固定区域裁剪方法。

## 2. 方法论

### 2.1 核心思想
- 先"**选对区域**"（RWR：按指令相关性的空间分布自适应重塑窗口，避免固定窗口造成的碎片化），再"**精炼区域内部**"（ITR：在裁剪区域内用指令引导相关性图剔除低相关 token），最终只向 LLM 送入紧凑且高度相关的视觉 token 集合。
- 整体流程：多分辨率编码图像 → 分组为窗口 → 指令编码 → RWR 估计指令-窗口相关性并重塑窗口 → 裁剪相关区域并**重新编码**获得细粒度特征 → ITR 逐 token 精炼 → 剩余 token 与指令一并送入 LLM 生成答案。

### 2.2 特征提取
- 视觉特征经预训练视觉编码器 + 投影层得到 $V \in \mathbb{R}^{T \times d}$（$T$ 为视觉 token 数，$d$ 为特征维度），重塑为二维空间网格并划分为局部窗口，第 $i$ 个窗口表示为 $R_i$。
- 指令经分词与嵌入得到 $T \in \mathbb{R}^{M \times d}$（$M$ 为指令 token 数）；窗口特征与指令 token 被投影到**共享特征空间**用于相关性估计。

### 2.3 相关性引导窗口重塑（RWR）
- **窗口相关性估计**：对第 $i$ 个窗口内的第 $k$ 个视觉 token $r_{i,k}$ 与第 $j$ 个指令 token $t_j$ 计算余弦相似度：
  $$a_{i,k,j} = \frac{r_{i,k}^\top t_j}{\|r_{i,k}\|_2 \|t_j\|_2}$$
- 对每个指令 token 取该窗口内视觉 token 上的**最大相似度**，再对 $M$ 个指令 token 求平均，得到窗口相关性分数：
  $$s_i = \frac{1}{M}\sum_{j=1}^{M}\max_k a_{i,k,j}$$
- **自适应重塑**：按分数对候选窗口排序，依据高分窗口的空间分布，将相邻窗口聚合数量在 **2～4** 之间自适应调整；若相关区域**水平延展**则沿水平方向聚合相邻窗口，**垂直延展**则沿垂直方向聚合。
- 由此形成更贴合内容空间尺度的区域候选，缓解固定窗口边界带来的断裂；被选区域从原图裁剪后**重新编码**，获得更精细的视觉表示。

### 2.4 指令引导 Token 精炼（ITR）
- 对精炼后视觉特征中的第 $i$ 个视觉 token $v_i$ 与第 $j$ 个指令 token $t_j$ 计算余弦相似度：
  $$s_{i,j} = \frac{v_i^\top t_j}{\|v_i\|_2 \|t_j\|_2}$$
- 用**温度缩放 softmax** 在指令 token 维度归一化：
  $$\alpha_{i,j} = \frac{\exp(s_{i,j}/\tau)}{\sum_{m=1}^{M}\exp(s_{i,m}/\tau)}$$
- 视觉 token 的相关性分数为加权和：$r_i = \sum_{j=1}^{M}\alpha_{i,j} s_{i,j}$
- 分数经 min-max 归一化后映射回空间位置，形成**指令引导相关性图**：$\hat{r}_i = \frac{r_i - r_{\min}}{r_{\max} - r_{\min} + \epsilon}$
- **Token 保留图**将每个 token 划为三态：
  - **Protected**：RWR 排名前 2 的区域内的 token，始终保留；
  - **Retained / Removed**：其余区域按归一化相关性分数分类。
- 最终送入 LLM 的视觉 token 集合 = Protected + Retained。

## 7. 优点

- **问题定位精准**：明确指出现有 token 剪枝丢失空间结构、固定窗口裁剪不适配细长文本，这两点动机清晰且有针对性。
- **方法设计有互补性**：RWR 解决"选哪个区域"（粗粒度、结构化），ITR 解决"区域内部留哪些 token"（细粒度、语义化），二者形成由粗到精的两级缩减流水线，逻辑自洽。
- **机制简洁可解释**：以余弦相似度 + max/mean 聚合 + 温度 softmax 构建相关性分数，并在 ITR 中显式构造"指令引导相关性图"与三态保留图（Protected/Retained/Removed），可解释性较强。

- **效率-精度双赢**：在四个基准上同时报告准确率与 FLOPs，结果显示既提升精度又降低计算量（GQA 计算量近乎减半），说服力较强。
