## 摘要
训练后量化（PTQ）能够实现高效部署，但 Transformer 架构仍因非线性层而难以量化。现有方法通常将精度损失归因于数值精度不足，并往往需要回退到浮点计算；然而，我们表明性能退化实际上由特定的结构性误差来源驱动。我们发现，归一化层中可学习的缩放参数以及 GELU 中的复合近似是主要误差来源，而 SoftMax 对激进量化仍具有内在鲁棒性。为解决这些瓶颈，我们提出 TR-PTQ，一种使用共享泰勒区域（TR）指数和对数原语的统一纯整数形式化方法。该方法使包括除法和平方根在内的计算代价高昂的操作能够完全在对数域中通过标准整数算术完成。结合针对 LayerNorm 参数的免校准、异常值感知优化，我们的方法无需用于非线性的浮点硬件单元，在视觉和语言基准上实现了低于 1.5% 的绝对精度下降。

## Abstract
Post-training quantization (PTQ) enables efficient deployment, yet transformer architectures remain challenging to quantize due to nonlinear layers. While existing methods attribute accuracy loss to insufficient numerical precision, often necessitating floating-point fallbacks, we demonstrate that degradation is actually driven by specific structural error sources. We find that learned scale parameters in normalization layers and compounded approximations in GELU are the primary error contributors, whereas SoftMax remains inherently robust to aggressive quantization. To address these bottlenecks, we introduce TR-PTQ, a unified integer-only formulation using shared Taylor Region (TR) exponential and logarithm primitives. This approach allows computationally expensive operations, including division and square roots, to be performed entirely in the log-domain via standard integer arithmetic. Combined with a calibration-free, outlier-aware optimization for LayerNorm parameters, our method eliminates the need for floating-point hardware units for nonlinearities, achieving less than 1.5\% absolute accuracy degradation across vision and language benchmarks.

## 1. 核心问题与研究动机

- **背景**：训练后量化（PTQ）无需重训练即可高效部署模型，但 Transformer 因大量依赖非线性层（SoftMax、GELU、LayerNorm）而难以量化。
- **既有认知的局限**：现有方法普遍将精度损失归因于"数值精度不足"，因而采用复杂校准、专用观察器（observer）或保留浮点回退（FP32 fallback）的混合精度执行方案。
- **本文的核心质疑**：作者挑战"非线性层本质上需要高精度算术"这一假设，主张精度退化实际上由**少量、可识别的结构性误差源**驱动：
  - 归一化层中的**可学习缩放参数 γ**（重尾分布，与 min-max/直方图观察器严重不匹配）是误差主因，而非输入激活或均值/方差估计；
  - **GELU 的"近似叠加近似"（approximation-on-approximation）效应**，即代理实现与量化误差复合放大；
  - **SoftMax 本身对激进量化具有内在鲁棒性**（对数缩放 + 归一化抑制绝对幅值误差，低概率元素不精确影响甚微）。
- **整体含义**：论文证明可以完全消除非线性层的浮点硬件单元，用纯整数运算实现高精度 Transformer PTQ，为资源受限硬件提供简化且高效的部署路径。

## 2. 方法论：核心思想与关键技术

### 2.1 核心思想
以**共享的泰勒区域（Taylor Region, TR）指数/对数原语**（TR-exp、TR-ln）为统一基元，将除法、平方根、指数等昂贵运算全部转入**对数域**并用标准整数算术（移位、加法、乘法、小 LUT）完成，从而实现 SoftMax、GELU、LayerNorm 的纯整数化。

### 2.2 关键技术细节

- **TR-exp（泰勒区域指数近似）**
  - 先做数值稳定化：`x̂ = x − x_max ≤ 0`，使输出落在 `(0, 1]`。
  - 将 b 比特定点数按位域划分为 `1-bit 符号 | l-bit 评价点(evp) | k-bit 小数(frac)`。
  - 用 evp 索引预计算的锚点 LUT（`exp(a_i)`，共 2^l 项），`exp(0)=1` 由符号位特殊编码。
  - 二阶泰勒展开的整数化公式（式 5）：
    `exp(x̂_q) ≈ LUT[evp] · (1≪k + Δ + (Δ²≫(k+1))) ≫ k`，其中 `Δ = x̂_q − (evp≪k)`。
  - **关键优化**：因同一区域 l 个高位相消，`Δ` 仅需 k 比特；二次项 `Δ²/2` 在 Q4.4 下可用 4→2 比特布尔组合逻辑替代乘法器；一阶项 `1 + x − a` 可退化为一个多路选择器（MUX），无需全宽加法器。
  - 采用**就近取整锚点**（`a = round(x)`，由最高小数位决定），将残差限制在 `[−0.5, 0.5]`，误差较 floor 取整减半。

- **TR-ln（移位式泰勒区域对数近似）**
  - 利用对数的次线性特性，采用**分段线性近似**，分段边界由前导 1 比特及次高位决定（对应区间 `2^⌊log₂x⌋`）。
  - 推导得 `ln x_q ≈ ln2·(2^{−a}x + a − 1)`；利用 `ln2 ≈ 0.5 + 0.125 + 0.0625`（均为 2 的幂），乘法退化为移位-加法（式 10）：`(k≫1)+(k≫3)+(k≫4)`。

- **TR-SoftMax**：先做 max 减法稳定；由于 S ≥ 1 保证 `ln S ≥ 0`，用 `S⁻¹ = exp(−ln S)` 在 log 域求倒数，最终 `TR-SoftMax = sf · TR-exp[x̂] ≫ k`，其中 `sf = TR-exp(−TR-ln(Σ TR-exp(x̂_j)))`。

- **TR-GELU**：用 sigmoid 形式 `x·σ(αx)` 近似；但针对以精确 GELU 训练的模型，将全局 `α=1.702` 替换为**区域相关的分段 α_i**（10 个均匀区间覆盖 [−5,5]，离线最小化 MSE 求得），利用 GELU 奇对称性，LUT 缩减至 **4 项**。

- **TR-Norm（LayerNorm 纯整数化）**
  - 对数域重写：`1/√(σ²+ε) = TR-exp(−½·TR-ln(σ²+ε))`，消除除法器与开方单元。
  - 当 `σ²+ε < 1` 时对数为负，故将 exp LUT 扩展至含正项（表大小翻倍但结构不变）。
  - **离群值感知缩放优化**：针对重尾的 γ 参数，采用免校准的方差归一化 RMSE 目标做离线线搜索：`L(s) = RMSE(γ, dequant(quant(γ·s))) / Var(γ)`，搜索范围 `s ∈ [0.5, 2.0]`，避免分布坍缩。

## 6. 主要结论与发现

- **结构性误差源而非精度不足**是 Transformer PTQ 退化的主因：LayerNorm 的 γ 参数与 GELU 的复合近似是主要贡献者，SoftMax 对量化高度鲁棒。
- **SoftMax 鲁棒性机理**：归一化重缩放削弱个体指数误差；注意力主要依赖 logits 的相对排序与量级，`e⁻⁸ ≈ 3×10⁻⁴` 这类强负 logit 贡献可忽略；甚至零阶 Q4.4 近似影响都极小。相反，**max 减法的精度更敏感**（4–6 bit 时误差全局传播，小模型如 DeiT-T 退化明显）。
- **GELU 分段 α_i 能恢复近乎全部残余损失**，证明激活函数的细粒度控制对激进量化是必要的。
- **LayerNorm 的 γ 优化是稳定低比特量化的前提**，而非可选精修：4-bit γ 在朴素 min-max 下严重退化，本文线搜索可恢复至距 FP32 基线 1–2% 以内。
- **最终结果**：无需浮点硬件处理非线性，视觉基准绝对精度损失多数 < 1%，整体 < 1.5%；GLUE 上也取得可比或更优表现。

## 7. 优点

- **观点创新性强**：挑战"非线性层必须高精度"的普遍假设，通过误差源定位将问题从"提升精度"转为"针对性优化"，方法论上具有启发性。
- **统一且硬件友好**：exp/ln 共享同一泰勒区域结构，除法与开方只需两次同宽乘法，可用移位、MUX、组合逻辑实现，无需除法器、开方单元或浮点单元，便于单周期求值。
- **免校准、免浮点回退**：非线性层不需要校准数据与专用观察器，γ 优化仅需轻量线搜索，显著简化 PTQ 流水线。
- **LUT 紧凑**：SoftMax 可用最少 8 项（论文提到，对比常用 256 项），GELU 分段系数经奇对称压缩至 4 项。
