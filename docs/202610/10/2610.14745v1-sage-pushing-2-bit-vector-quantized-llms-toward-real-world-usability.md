## 摘要
极端低比特仅权重量化是降低大语言模型部署成本的一种有效方法。在 3 比特以下，标量量化通常会出现严重的精度损失，而向量量化（VQ）通过更具表现力的联合编码能够更好地保持精度。然而，现有 VQ 方法在真实世界任务上仍会出现显著退化，且两个设计挑战仍未得到充分探索：(1) 在联合编码的向量中保护敏感权重通道；(2) 在表示分量（如方向和半径）之间分配固定比特预算，以适应不同权重矩阵。为应对这些挑战，我们提出 SAGE：面向仅权重量化的拆分自适应与能量分组。首先，能量分层分组（ESG）将通道分组与激活加权拟合相结合，在每个子向量内将来自不同能量层级的通道分组，以优先考虑敏感通道。其次，自适应比特拆分（ABS）为每个矩阵平衡方向码本容量与半径精度，在固定预算下选择激活加权重建误差最低的拆分方案。在涵盖知识、数学、代码生成、指令遵循和工具使用的基准测试中，SAGE 在 2 比特量化设置下取得了最先进的性能。在 Qwen3-30B-A3B 上，它保留了 BF16 模型平均基准分数的 95.3%。借助我们定制设计的 CUDA 内核，SAGE 相比 FP16 可实现最高 2.55 倍的非流式端到端加速。代码见 https://github.com/Zincwolf/sage。

## Abstract
Extreme low-bit weight-only quantization is an effective approach to reducing the deployment costs of large language models. Below 3 bits, scalar quantization often suffers severe accuracy loss, while vector quantization (VQ) better preserves accuracy through more expressive joint encoding. However, existing VQ methods still exhibit substantial degradation on real-world tasks, and two design challenges remain underexplored: (1) protecting sensitive weight channels within jointly encoded vectors; and (2) allocating a fixed bit budget among representation components, such as direction and radius, to suit different weight matrices. To address these challenges, we propose SAGE: Split Adaptation and Grouping by Energy for weight-only vector quantization. First, Energy-Stratified Grouping (ESG) couples channel grouping with activation-weighted fitting, grouping channels from different energy tiers within each subvector to prioritize sensitive channels. Second, Adaptive Bit Split (ABS) balances direction-codebook capacity and radius precision per matrix, selecting the split with the lowest activation-weighted reconstruction error under a fixed budget. Across benchmarks covering knowledge, mathematics, code generation, instruction following, and tool use, SAGE achieves state-of-the-art performance in the 2-bit quantization setting. On Qwen3-30B-A3B, it retains 95.3% of the BF16 model's average benchmark score. With our custom-designed CUDA kernel, SAGE delivers up to a 2.55-fold non-streaming end-to-end speedup over FP16. The code is available at https://github.com/Zincwolf/sage.

## 1. 核心问题与研究背景

- **部署瓶颈**：本地/边缘部署以单 batch、低延迟解码为主，解码阶段权重复用极少，**显存带宽而非算力**成为主要瓶颈；仅权重量化（weight-only PTQ）正是针对这一瓶颈。
- **3 比特以下标量量化失效**：GPTQ、AWQ 等在 3–4 比特已较成熟，但低于 3 比特时每个权重仅剩极少重建值，精度急剧下降。
- **向量量化（VQ）的动机**：将一组权重联合编码到共享码本，相同比特预算下重建点更贴合权重分布，是 sub-3-bit 的主流路线（QuIP#、QTIP、LLVQ、PCDVQ、SPHQuant 等）。
- **两个未充分解决的设计挑战**：
  1. **敏感通道保护**：标量量化中靠激活感知缩放（AWQ）或通道置换（PT2-LLM）保护重要通道，但这两者都依赖"每权重独立标量网格"的性质；VQ 中 8 个通道共享一个码字与一个半径，策略无法直接迁移。
  2. **固定比特预算的切分**：以 8 权重/18 比特为例（8 符号 + 6 方向索引 + 4 半径 = 2.25 bpw），方向码本容量与半径精度之间如何分配，此前工作（SPHQuant）采用**全局固定切分**，未按矩阵自适应。
- **评测观的问题**：困惑度、HellaSwag 类多选题不能刻画后训练 LLM 的生成能力，小幅 PPL 上升未必意味着推理、指令遵循、代码能力仍可用，因此需直接评估生成式任务。

## 2. 方法论

### 2.1 基础：球面向量量化（沿用 SPHQuant 框架）

- 将权重矩阵每行沿输入轴切为 **v = 8** 的子向量 **w**，分解为：
  - 符号 **s** = sign(**w**)（精确存储）
  - 半径 r = ‖**w**‖₂
  - 非负单位方向 **d** = |**w**|/r，用码本 C（K 个非负单位向量）中的 c_z 表示
- 重建：**ŵ = r̂ (s ⊙ c_z)**
- 方向选择：球形 k-means 初始化，按余弦相似度 z = argmax_k dᵀc_k；连续半径闭式解 r̃ = |**w**|ᵀc_z。
- 半径量化：每 G = 128 个权重共享一套均匀网格，**r̂ = μ_g + qδ_g**，q = clip(round((r̃−μ_g)/δ_g), 0, 2^V−1)。
- 比特预算：**B = v + log₂K + V**；基线 (K, V) = (64, 4) → 18 bit/8 权重 = 2.25 bpw（不含共享元数据）。

### 2.2 能量分层分组（ESG）

- **激活加权重建**：用校准激活估计通道能量 e_c = E[x_c²]，定义子向量内权重
  **ω_i = e_{a_i}^γ / (1/v Σ_j e_{a_j}^γ)**，γ = 0.75（归一化为单位均值），目标函数
  **L_ω = Σ_i ω_i (p_i − r̃ c_{k,i})²**，其中 p = |**w**|。
- **关键观察**：加权只有在子向量内通道能量不相等时才起作用（能量相同则退化为欧氏重建）。因此按能量降序排序 σ，切成 v 个 tier（每层 m = d_in/v 个通道），**每个子向量从每个 tier 各取一个通道**：
  **π((j−1)v + t) = σ((t−1)m + j)**, j = 1…m, t = 1…v。
  从而保证子向量跨越能量层级，且位置顺序固定为"高能→低能"。
- **加权码本拟合**：加权球形 k-means，对候选码字有闭式半径
  **r̃*_k = (Σ_i ω_i p_i c_{k,i}) / (Σ_i ω_i c_{k,i}²)**，
  方向选择 **z = argmax_k (Σ_i ω_i p_i c_{k,i})² / (Σ_i ω_i c_{k,i}²)**；再按共享网格量化半径。权重均匀时即退化为余弦规则。
- 推理时对输入激活施加对应置换 π，通道身份保持不变。

### 2.3 自适应比特拆分（ABS）

- 候选集 **F = {(64,4), (128,3), (256,2)}**，约束 log₂K + V = 10，三者编码载荷完全相同（2.25 bpw），因此可**逐矩阵独立选择而不改变总预算**。
- 打分函数（激活加权重建误差，按原始通道顺序计算，使用未加权的原始能量 e_c 以保留跨子向量相对重要性）：
  **E_W(K,V) = Σ_c e_c ‖W_{:,c} − Ŵ(K,V)_{:,c}‖₂² / Σ_c e_c ‖W_{:,c}‖₂²**
- 选择 **(K*, V*) = argmin E_W(K,V)**；该拆分在初始化后固定，贯穿后续分块优化。

### 2.4 校准数据与分块优化

- **校准数据自生成**：从 OpenCodeInstruct、GSM8K、MATH、DeepMath-103K、OpenHermes-2.5、UltraChat、ShareGPT、When2Call 采样六域提示（比例 13:13:13:10:9:6），严格去重（与所有评测集比对），用**目标模型自身**按官方 chat 模板、贪心解码生成响应，thinking 模型保留推理轨迹，打包为 2048 token 定长序列（1920 训练 + 128 验证）。
- **分块顺序优化**：沿用 SPHQuant，逐块最小化 **L_block = E‖F̂_ℓ(x^q_ℓ) − F_ℓ(x^fp_ℓ)‖₂²**，学生端输入来自前面已量化块。**只更新连续半径参数与码本角度**（超球角参数化保证非负单位码字），固定置换、比特拆分、方向索引；半径量化用 STE。Adam，20 epochs，batch 16，lr 1e-3。

### 2.5 定制 CUDA 内核

- **GEMV（解码）**：半径由 8 个权重共享，先做带符号方向的点积再乘一次半径（8 次乘法降为 1 次）；码字 8 个分量连续存放于共享内存，单次 128-bit load；四线程小组处理一个 128 通道组。
- **GEMM（prefill）**：64×64 输出 tile，Tensor Core 复用共享内存中解码后的权重 tile；128 通道组分两半流水，激活双缓冲 + 权重预取 + 屏障同步。
- **比特提取编译期特化**：所有 ABS 拆分共用 16-bit 主字 + 2 个辅助位/子向量。
- 置换与前置归一化/激活算子做图级融合，避免每个输出线程块重复 gather。
