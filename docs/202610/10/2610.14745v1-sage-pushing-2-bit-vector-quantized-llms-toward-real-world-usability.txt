## ABSTRACT 

Extreme low-bit weight-only quantization is an effective approach to reducing the deployment costs of large language models. Below 3 bits, scalar quantiza-tion often suffers severe accuracy loss, while vector quantization (VQ) better pre-serves accuracy through more expressive joint encoding. However, existing VQ methods still exhibit substantial degradation on real-world tasks, and two design challenges remain underexplored: (1) protecting sensitive weight channels within jointly encoded vectors; and (2) allocating a fixed bit budget among representa-tion components, such as direction and radius, to suit different weight matrices. To address these challenges, we propose SAGE : Split Adaptation and Grouping by Energy for weight-only vector quantization. First, Energy-Stratified Group-ing (ESG) couples channel grouping with activation-weighted fitting, grouping channels from different energy tiers within each subvector to prioritize sensitive channels. Second, Adaptive Bit Split (ABS) balances direction-codebook capac-ity and radius precision per matrix, selecting the split with the lowest activation-weighted reconstruction error under a fixed budget. Across benchmarks cover-ing knowledge, mathematics, code generation, instruction following, and tool use, SAGE achieves state-of-the-art performance in the 2-bit quantization set-ting. On Qwen3-30B-A3B, it retains 95.3% of the BF16 model’s average bench-mark score. With our custom-designed CUDA kernel, SAGE delivers up to a 

2.55 × non-streaming end-to-end speedup over FP16. The code is available at 

https://github.com/Zincwolf/sage .

## 1 INTRODUCTION 

Recent large language models (LLMs) (Kimi Team, 2026; GLM-5 Team, 2026; Yang et al., 2025; DeepSeek Team, 2026; Liu et al., 2026) have made remarkable progress in reasoning, coding, and generation. Those gains have come with steadily growing parameter counts. A larger model occu-pies more memory and spends more compute on every token it generates, which makes it hard to run on edge devices and other resource-constrained platforms. Local deployment prioritizes low-latency inference with small batches. In this setting, decoding offers little weight reuse across requests, mak-ing memory bandwidth rather than compute the primary bottleneck (Song et al., 2024). Weight-only post-training quantization (PTQ) (Frantar et al., 2023; Lin et al., 2024; Tseng et al., 2024b; Liang et al., 2026) targets exactly this bottleneck. Lower-bit weights shrink the memory footprint and can accelerate memory-bound decoding by reducing weight traffic (Kim et al., 2024). Scalar methods such as GPTQ (Frantar et al., 2023) and AWQ (Lin et al., 2024) have made 3–4-bit weights practical with little accuracy loss. Below 3 bits the picture changes: each weight has only a handful of reconstruction values left, and accuracy degrades sharply (Egiazarian et al., 2024). Vector quantization (VQ) (Egiazarian et al., 2024; Baalen et al., 2024; van der Ouderaa et al., 2026) instead encodes groups of weights jointly against a shared codebook, so at the same bit budget its reconstruction points follow the weight distribution far more closely. This is what motivates the sub-3-bit line of work built on VQ and related structured coding (Tseng et al., 2024a;b). Existing VQ methods differ in how the codebook is structured and how a weight is recovered from it. QuIP# (Tseng et al., 2024a) and QTIP (Tseng et al., 2024b) use incoherence processing, requir-ing online Hadamard transforms on activations during inference. QuIP# combines table lookups with sign and shift operations, QTIP supports lookup-only, computed, and hybrid trellis codes, and LLVQ (van der Ouderaa et al., 2026) uses structured Leech lattice decoding without an explicit codebook. It stores each group of eight weights, a subvector, in sign-separated form: the signs explicitly, the magnitude through a quantized radius, and the direction as an index into a learned codebook over the non-negative orthant. Folding all 28 orthants into one keeps that codebook at 64 entries, or 1 KiB, so it stays in shared memory and decoding is a lookup, a sign flip, and a multiply. However, two challenges remain insufficiently addressed in vector quantization. (1) How to protect important channels. Protecting the channels that matter most is standard in scalar quantization, by rescaling them (Lin et al., 2024) or by permuting them so that a group’s channels are alike and share a scale well (Yan et al., 2026). Neither strategy transfers directly to vector quantization, where eight channels share one codeword and one radius: both rely on properties of a per-weight scalar grid that a jointly coded subvector does not have. (2) How to divide the fixed budget. A group of eight weights costs 18 bits: eight signs, six for the direction index, four for the radius, a nominal 2.25 bits per weight. How the remaining ten are split between the index and the radius is itself a choice, since moving one bit from the radius to the index doubles the codebook at almost no extra cost. Previous work adopts a fixed split (Zhang et al., 2026). Beyond quantization algorithm design, evaluating the practical capabilities of quantized models is equally important. Common metrics such as perplexity and multiple-choice accuracy on benchmarks like HellaSwag (Zellers et al., 2019) do not fully characterize the generative capabilities of post-trained LLMs. In particular, a small increase in perplexity does not necessarily imply that a model can still reason correctly, follow instructions, or produce functional code. We therefore evaluate quantized models on generative benchmarks covering knowledge, mathematical reasoning, code generation, instruction following, and tool use. Our goal is to preserve the ability of extremely low-bit models to complete real-world tasks, which requires assessing these capabilities directly. In this paper, we propose SAGE : Split Adaptation and Grouping by Energy for weight-only vec-tor quantization. To address Challenge (1), we introduce Energy-Stratified Grouping (ESG), which couples channel grouping with activation-weighted reconstruction. ESG distributes energy-ranked channels across subvectors, placing channels from different energy tiers within each subvector so that weighted fitting can prioritize sensitive channels. To address Challenge (2), we introduce Adap-tive Bit Split (ABS), which evaluates candidate allocations between the direction index and radius using activation-weighted reconstruction error and selects a split for each matrix. Together, ESG and ABS adapt the representation to channel importance and matrix-specific demands while pre-serving the encoding budget. Fig. 1 illustrates both accuracy and inference efficiency on Qwen3-4B-Instruct-2507. SAGE achieves the highest quantized scores across all six generative benchmarks and combines low first-token latency with high output throughput under both input/output length set-tings. Our custom-designed CUDA kernels further enable up to a 2.55 × non-streaming end-to-end speedup over FP16. We hope SAGE advances low-bit models toward real-world deployment. 2Our key contributions can be summarized as follows: • We propose SAGE : Split Adaptation and Grouping by Energy, a novel weight-only VQ framework that advances 2-bit quantization toward real-world usability. • We design Energy-Stratified Grouping (ESG) , which couples channel grouping with activation-weighted fitting. ESG groups channels from different energy tiers within each subvector, enabling weighted fitting to prioritize sensitive channels. • We develop Adaptive Bit Split (ABS) , which derives the division between the direction index and the radius from activation-weighted reconstruction error and adapts it per matrix, rather than applying one fixed split across the whole model, at an unchanged bit budget. • Experiments on five LLMs and six generative benchmarks establish SAGE as a new SOTA for 2-bit VQ, retaining 95.3% of the BF16 average score on Qwen3-30B-A3B. Our CUDA kernel achieves up to a 2.55 × non-streaming end-to-end speedup over FP16. 

## 2 RELATED WORKS 

Quantization can be categorized by optimization and representation. Post-training quantization (PTQ) uses small calibration sets for calibration or lightweight blockwise reconstruction, while quantization-aware training (QAT) typically involves large-scale end-to-end training. Scalar quanti-zation (SQ) encodes weights individually, whereas vector quantization (VQ) encodes them jointly. Our method is weight-only vector PTQ, and we organize this section by representation. 

Scalar Quantization. Among SQ approaches, PTQ is the most widely adopted, for its low cal-ibration cost. At 8 bits, LLM.int8() (Dettmers et al., 2022) and SmoothQuant (Xiao et al., 2023) preserve accuracy via outlier handling and channel-wise scaling, while at 4 bits, GPTQ (Frantar et al., 2023) and AWQ (Lin et al., 2024) reduce quantization error through second-order compensa-tion and activation-aware scaling. Beyond direct quantization, rotation-based methods redistribute outliers with fixed or learned orthogonal transforms (Ashkboos et al., 2024; Liu et al., 2025a; Chee et al., 2023; Sun et al., 2025; Hu et al., 2025; Liang et al., 2026), while permutation-based methods leave channels intact and merely reorder them, gathering channels of similar range so that a shared scale fits every member of a group (Yan et al., 2026). To limit error accumulation, GPTAQ (Li et al., 2025a) and QEP (Arai & Ichikawa, 2025) account for errors from preceding quantized layers when reconstructing layer outputs. Others add auxiliary representations, a sparse full-precision compo-nent (Kim et al., 2024) or shared low-rank corrections (Gu et al., 2026), or optimize the quantizer itself through clipping and equivalent transformations (Shao et al., 2024) and loss-sensitive non-uniform grids (Zhang & Shrivastava, 2025). At even lower precision, ARB-LLM (Li et al., 2025b) and PT 2-LLM (Yan et al., 2026) extend parameter refinement to binary and ternary quantization by alternating updates to grid parameters and discrete assignments. However, scalar PTQ can suffer substantial accuracy loss at 3 bits and below (Liu et al., 2025b). QAT addresses this through distilla-tion (Liu et al., 2024b; Du et al., 2024) or tailored optimization (Chen et al., 2025; Liu et al., 2025b), while limited scalar-grid capacity motivates more expressive VQ representations. 

Vector Quantization. VQ methods differ mainly in how they group weights, how they construct codebooks, and how they optimize the resulting assignments. GPTVQ (Baalen et al., 2024) ex-tends GPTQ’s second-order compensation to weight vectors spanning columns; VPTQ (Liu et al., 2024a) instead groups weights within columns for column-wise compensation. Additive and resid-ual codebooks further refine reconstruction (Egiazarian et al., 2024; Liu et al., 2024a). QuIP# (Tseng et al., 2024a) combines incoherence processing with lattice codebooks. QTIP (Tseng et al., 2024b) retains incoherence processing but replaces these codebooks with trellis coding, enabling higher-dimensional quantization without exponential codebook storage. NestQuant (Savkin et al., 2025) develops the lattice approach using self-similar nested lattices. A further branch applies the clas-sical shape–gain decomposition (Gersho & Gray, 1991), coding magnitude and direction sepa-rately: PCDVQ (Yue et al., 2025) pairs a scalar magnitude code with an E8 direction codebook, LLVQ (van der Ouderaa et al., 2026) uses the Leech lattice, and SPHQuant (Zhang et al., 2026) additionally separates the sign pattern so that one small codebook entry serves every sign pat-tern. Optimization advances include joint refinement of parameters and assignments (Malinovskii et al., 2024) and mixed precision guided by gradients and Hessians for VLMs (Wang et al., 2026d). UniSVQ (Wang et al., 2026b) and LC-QAT (Wang et al., 2026a) use affine lattice codebooks for scalar kernels and lookup-free QAT, respectively. 3➗

Calibration Data Construction. Since ESG and ABS rely on calibration activations, the calibra-tion inputs should reflect the contexts encountered during deployment, including both user prompts and model-generated responses. Following the use of model-generated data in LLM-QAT (Liu et al., 2024b) and target-model reasoning traces in AYOT (Wang et al., 2026c), we construct calibration se-quences from the full-precision model’s own responses. We sample prompts spanning mathematics, code, reasoning, instruction following, tool use, and general conversation, apply the target model’s chat template, and generate responses using greedy decoding. Each prompt is concatenated with its response, and the resulting token streams are packed into fixed-length sequences for activation statistics collection and blockwise optimization. Further details are provided in Appendix A.5.

Channel Permutation and Fusion. ESG stores each weight matrix in permuted input-channel order; each projection applies its corresponding permutation to the input activations. In compiled decoding, we keep permutation visible to the graph compiler for fusion with preceding normaliza-tion or activation operations. This avoids repeating the gather in every output thread block. Eager decoding fuses gather into matrix–vector multiplication for short inputs, avoiding a separate launch. Prefill reorders activations once per projection for reuse across output tiles. 

Quantized Matrix Multiplication with Adaptive Bit Splits. All ABS splits share a 16-bit main word plus two auxiliary bits per subvector, with compile-time specialization of bit extraction. Dur-ing decoding, contiguous shared-memory codewords enable 128-bit loads for register-local packed FP16 dot products, followed by FP32 radius weighting and reduction. Shape-dependent output tiling balances activation reuse against register pressure and thread-block parallelism. During prefill, Ten-sor Cores reuse weight tiles decoded into shared memory across 32 or 64 activation rows. The larger tile amortizes decoding, while staging only 64 activation channels at a time limits shared-memory usage. For small grids, we expose more parallelism by splitting the reduction dimension across thread blocks, then combine partial sums in FP32. Comparisons with State-of-the-Art Methods. As shown in Table 1, SAGE achieves the high-est average score on all five models, retaining 78.9–95.3% of their BF16 average scores. At the same 2.25-bit encoding budget, it improves over SPHQuant by 4.05–16.24 percentage points. The largest gain occurs on Qwen3.5-4B-Thinking, where SAGE raises the average score from 51.44 to 67.68 and leads all quantized baselines on every benchmark. On the three dense instruct models, SAGE surpasses the strongest baseline for each model by 6.39–7.48 points. On Qwen3-30B-A3B, it achieves an average score of 82.48, retaining 95.3% of BF16 performance. These results demon-strate gains across dense, MoE, and hybrid attention models in instruct and thinking modes. 

Task Sensitivity to Quantization. Quantization affects tasks unevenly, with code generation and challenging mathematical reasoning showing substantial losses. For example, SAGE trails BF16 by 22.56 points on HumanEval+ but only 1.85 points on IFEval for Qwen3-4B, indicating that strong instruction following can coexist with substantial degradation in code generation. Sensitivity also varies within mathematical reasoning. On Qwen3.5-4B-Thinking, the gap to BF16 reaches 39.60 points on MATH-500, compared with 7.96 points on GSM8K. This contrast highlights the diffi-culty of preserving demanding reasoning in a thinking model, even when performance on simpler mathematical tasks remains relatively strong. Across five models, SAGE gains 2.44–26.83 points on HumanEval+ and 5.20–21.20 on MATH-500 over SPHQuant. Remaining gaps to BF16 motivate task-level evaluation beyond average scores. 4.3 ABLATION STUDIES

## 5 CONCLUSION 

In this work, we presented SAGE, a weight-only vector quantization method that uses activation in-formation to guide channel grouping and bit allocation. These two decisions are closely connected: grouping determines which weights share a representation, while bit allocation determines its capac-ity to encode direction and magnitude. By addressing them together, SAGE makes more effective use of a limited encoding budget. Experiments across diverse generative benchmarks demonstrate improved capability preservation, while our custom CUDA kernel translates the compact represen-tation into practical inference acceleration. We hope this work helps move extreme low-bit quanti-zation beyond evaluations centered on perplexity toward models that reliably solve real-world tasks. 9REFERENCES

A.1 CUDA K ERNEL IMPLEMENTATION DETAILS 

GEMV. During decoding, each eight-weight subvector contributes a scalar to one output. Its ra-dius is shared by all eight weights, so we apply that radius after taking the dot product with the signed direction (Fig. 6a). This replaces eight radius multiplications with one. In the shape-specialized ker-nels, we place each codeword’s eight components consecutively in shared memory, allowing a thread to fetch the whole direction in one 128-bit load. We divide each 128-channel group among four neighboring threads. Each thread processes four subvectors, while other four-thread teams cover the remaining groups. Assigning multiple outputs to a thread lets it reuse the same activations; using fewer outputs per block instead increases the number of independent blocks. 

GEMM. During prefill, many token rows use the same weights, so we reconstruct each weight once per output tile and reuse it across those rows. The schedule in Fig. 6b processes each 128-channel group in two halves. We decode both weight halves together from the same packed group and retain them until every warp finishes the group. Only the activation half currently being mul-tiplied occupies shared memory, leaving room for other resident thread blocks. We fetch the next half’s activations into registers before the current matrix multiply. A barrier prevents us from over-writing the shared activation buffer until every warp has finished reading it; another makes the replacement visible before the next multiply. Likewise, we prefetch the next group’s packed weights while the current group is still in use, but wait to decode them into shared memory until both current weight halves have been consumed.
