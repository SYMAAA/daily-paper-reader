## ABSTRACT 

Long videos often exceed the context capacity of multimodal large language mod-els (MLLMs), while agentic search repeats costly video processing and grounding for each query. Reusable memory can amortize this cost, but must preserve infor-mation for questions unknown during construction. We propose Video-EMem, an evolvable video memory harness built on time-anchored perceptual observations. This representation combines compact free-form text with sparse images to pre-serve semantic content and complementary visual details across temporal scales, supporting temporal navigation without a fixed semantic schema. A Writer en-codes each video once by consolidating overlapping multiscale observations, and a Reader retrieves and organizes evidence solely from the resulting memory. With the underlying models frozen, we evolve the operators within their writing and reading workflows using distinct feedback: query-independent source fidelity and coverage for the Writer, and QA failures in evidence localization and utilization for the Reader. Experiments support this separation for generalization beyond development queries, with our evolution strategy improving average accuracy by 

7.2% over the unevolved harness. While reducing storage by about 99.86% on average relative to raw videos, Video-EMem improves Qwen3-VL-30B by an av-erage of 2.6% across three long-video QA benchmarks over direct input of 2,048 frames. Using the same o3 answer model as the state-of-the-art agentic method, it improves average accuracy by 2.5% with 19 × lower per-query latency. 

## 1 INTRODUCTION 

Long videos often exceed the practical context capacity of multimodal large language models (MLLMs). Search-based and agentic methods address this limitation by iteratively locating rele-vant segments (Ye et al., 2025; Fan et al., 2024; Zhang et al., 2026b; Chen et al., 2026b), but may repeat costly video processing and grounding, as shown in Figure 1 (a). Inspired by external memory in text-based agents (Park et al., 2023; Packer et al., 2023; Wang et al., 2023), an appealing alterna-tive is to encode the video once into a compact representation reusable across queries. This raises a key question: how can we construct memory under a limited storage budget that preserves video information for unknown future questions and enables efficient evidence retrieval and organization? 

Existing video representations offer different trade-offs. Retaining all visual tokens is costly, while subsampling can discard details and disrupt temporal continuity (Song et al., 2024; He et al., 2024; Zhang et al., 2024b; Yang et al., 2025; Wang et al., 2025b; Qian et al., 2024; Chen et al., 2026a). Tex-tual memories are compact, but verbalization can omit fine-grained visual evidence (Kahatapitiya et al., 2025; Ma et al., 2025). Predefined schemas or relations for multimodal memory (Fan et al., 2024; Yin et al., 2026; Yeo et al., 2026) may constrain what is retained, and independently process-ing temporal segments (Zhang et al., 2024a; Pang & Wang, 2025) can overlook broader context. We therefore represent a video using a lightweight memory composed of time-anchored perceptual observations . Rather than exhaustively storing all frames or intermediate observations, it selectively retains semantic and perceptual evidence across multiple temporal scales through free-form text and sparse images, without imposing a predefined semantic schema.

To construct and access such memory, we introduce Video-EMem, an evolvable harness with frozen underlying MLLMs. Development queries may cover only a subset of video content, so query-guided optimization (Xu et al., 2026b; Wang et al., 2025c; Diko et al., 2025) risks overlooking evidence needed for unseen questions. Our harness therefore separates query-independent writing from query-specific reading. Although prior work adopts this separation (Qian et al., 2024; Kahat-apitiya et al., 2025), improving the two procedures under distinct objectives remains less explored. Our Writer processes each video once, consolidating observations from overlapping, multiscale win-dows bottom-up. Optimizing both agents solely for Question-Answering (QA) accuracy risks biasing memory toward development questions. The Writer there-fore evolves using only source-video evidence, with feedback that rewards coverage and penalizes redundancy in textual and visual observations. With the resulting memory fixed, the Reader evolves from QA failures attributed to evidence localization or utilization. In both stages, an LLM makes targeted updates to the responsible operator. We evaluate Video-EMem on hour-long video QA benchmarks with a memory budget of at most 20K text tokens and 160 images per video, reducing storage by about 99 .86% on average relative to raw videos. For a one-hour video, this corresponds to ∼ 5.6 tokens and ∼ 0.04 images per second. Compared with direct video input, Video-EMem improves Qwen3-VL-30B by 1.2%, 4.8%, and 1.9% on LVBench (Wang et al., 2025a), Video-MME Long (Fu et al., 2025), and LongVideoBench Long (Wu et al., 2024), while the baseline using much more context (2048 images). The Writer evolves without QA supervision, while the Reader uses QA feedback only from a small subset of LVBench; both transfer to the other benchmarks without further adaptation. Our evolution strategy improves average accuracy by 7.2% over the unevolved harness. In addition, compared with the state-of-the-art agentic method DVD (Zhang et al., 2026b), Video-EMem improves average accuracy by 2.5 percentage points (72.3% vs. 69.8%) with ∼ 19 × lower per-query latency (9.69 s vs. 180 s), using the same OpenAI o3 answer model. ## 2 RELATED WORK 

Structured Video and Multimodal Memory. Memory has become a central mechanism for long-video understanding, enabling models to retain long-range evidence beyond their limited context windows and substantially improving performance. Early methods preserve video history through feature banks, recurrent states, or compressed visual tokens (Wu et al., 2022; Song et al., 2024; He et al., 2024; Zhang et al., 2024b; Yang et al., 2025). Subsequent work externalizes video content into language repositories or searchable documents, making long-range evidence easier to retrieve and reason over (Qian et al., 2024; Kahatapitiya et al., 2025; Ma et al., 2025). More recent systems further organize text, images, objects, and events into structured multimodal memories that agents can query or update across temporal scales (Fan et al., 2024; Diko et al., 2025; Yin et al., 2026; Yeo et al., 2026). Despite this progress, memory construction typically follows a fixed architecture with predefined writing, compression, or update rules. Moreover, many repository- and agent-based memories accumulate observations with video duration or reasoning trajectories, while bounded approaches often focus on compressing latent or KV states rather than preserving broadly useful semantic and perceptual information. In contrast, Video-EMem evolves its Writer from source-preservation feedback instead of manually specifying a fixed construction procedure. Under explicit text-token and image-count budgets, the Writer learns to preserve as much source information as possible, producing a lightweight, bounded, and reusable multimodal memory for future queries. 

Agentic Long-Video Understanding. Recent long-video understanding systems increasingly em-ploy agentic workflows to locate and organize evidence beyond the context capacity of multi-modal language models. Search-based methods progressively narrow the relevant temporal or spa-tial region: T* (Ye et al., 2025) performs temporal-spatial zooming, while DrVideo (Ma et al., 2025) iteratively retrieves and augments a textual video document. VideoAgent (Fan et al., 2024) equips a language-model agent with localization, memory-querying, and visual-perception tools, and DVD (Zhang et al., 2026b) uses agentic reasoning to repeatedly search long videos for question-relevant evidence. Related methods construct query-adaptive representations or retrieve relevant video segments, including R-VLM, VideoTree, and ReWind (Xu et al., 2026b; Wang et al., 2025c; Diko et al., 2025). Although these methods achieve superior performance, they largely overlook the substantial redundant computation involved. Instead of invoking the agent over the raw video for every question, Video-EMem processes the video once into a lightweight, reusable memory, after which a Reader performs query-conditioned evidence access solely over the frozen memory. This write-once, query-many design substantially improves efficiency. 

LM-Based Memory and Workflow Evolution. Fixed memory operations and hand-designed LM workflows limit how agents improve from experience. Memory systems such as A-MEM (Xu et al., 2026c) reorganize stored content and links, while MemSkill (Zhang et al., 2026a) learns and refines reusable memory operations. CoEvo-Mem (Ye et al., 2026) further alternates updates to a retrieval policy and memory bank using task outcomes. A related line optimizes prompts, modular LM pro-grams, or code-represented workflows from execution feedback, including DSPy, MIPRO, AFlow, and GEPA (Khattab et al., 2024; Opsahl-Ong et al., 2024; Zhang et al., 2025; Agrawal et al., 2026). In this paper, to address the dual challenges of constructing a broadly informative video memory before future questions are known and efficiently accessing relevant evidence from it for each query, we adopt a two-stage evolution process. First, we evolve a query-independent Writer using source-preservation feedback and materialize the resulting video memories. We then freeze these memories and evolve a query-conditioned Reader from attributed downstream QA failures.

Reusable video memory must balance information fidelity, storage cost, and evidence accessibility. Dense visual tokens are costly to retain for long videos, while compact textual descriptions may omit visual details that are difficult to verbalize. We therefore adopt a hybrid multimodal memory representation : a temporally ordered sequence of time-anchored observations, each comprising a compact textual record and, where needed, sparse 4images that preserve complementary visual observations within a temporal interval. This represen-tation provides a shared interface for the Writer to encode video content and the Reader to retrieve relevant evidence.

We evolve the Writer using source-preservation feedback without downstream QA supervision. Fol-lowing the memory construction order, we first optimize and freeze text construction, then optimize visual selection to complement the fixed text. Both stages use the mutation strategy summarized below and detailed in Section A.4. We guide text construction with two diagnostics: coverage and redundancy. (1) The coverage diag-nostic identifies information lost during construction by comparing the final textual records with the source captions and decomposing omissions into atomic facts. For each video, we retain the con-struction trajectory with the highest proportion of missing facts, together with those facts, to guide updates to the responsible operators. (2) The redundancy diagnostic identifies equivalent, subsumed, or partially overlapping content across the final records. We check temporal locations and source-caption provenance to distinguish redundant descriptions from distinct recurring events. We then retain the groups whose consolidation would save the most tokens, together with their construction trajectories, to guide updates that reduce repetition while preserving distinct evidence. With the text-writing procedure fixed, we optimize the Writer’s image selection to complement the text with visual observations while reducing redundancy. An MLLM classifies each retained im-age as complementary , text-overlapping , or uninformative relative to its textual observation, while DINO-feature similarity measures redundancy among images. We aggregate these diagnostics to identify the dominant selection failure and guide targeted updates to residual-value scoring, redun-dancy penalization, or the retention rule. Each update is evaluated using a complementarity score. 3.4 READER : A CCESSING CONSTRUCTED MEMORY

## 4 EXPERIMENT 

4.1 EXPERIMENTAL SETUP 

Benchmarks and metric. We report accuracy (%) on three long-video QA benchmarks. LVBench (Wang et al., 2025a) contains 103 videos averaging 68 minutes. Video-MME (Fu et al., 2025) contains 900 videos and 2,700 questions across diverse domains and durations; we evaluate its 30-60 minutes subset without subtitles, denoted Video-MME-L. LongVideoBench (Wu et al., 2024) contains 3,763 videos and 6,678 human-annotated questions; we evaluate the long-video subset of its validation set, denoted LongVideoBench-L. 

Evolution and evaluation splits. We reserve 30 LVBench videos for development, maintaining video-level separation from evaluation. Of these, 20 provide query-independent source feedback for Writer evolution and QA feedback for Reader evolution. We use all the 30 development videos to select the final programs. The other 73 LVBench videos are held out for evaluation. All LVBench results in this paper are evaluated on the same 73 held-out videos. We additionally evaluate on Video-MME-L and LongVideoBench-L without further adaptation to assess cross-benchmark gen-eralization. 

Baselines. We compare V IDEO -EM EM with two complementary groups of strong baselines. The first group comprises three state-of-the-art VLMs, Gemini-2.0-Flash, OpenAI o3, and Qwen3-VL-30B, representing direct long-context video understanding. The second comprises three state-of-the-art agentic methods, PACE (Xu et al., 2026a), MR. Video (Pang & Wang, 2025), and DVD (Zhang et al., 2026b), which iteratively access the source video to gather question-relevant evidence. Com-paring with the agentic methods, we use the same answer model as each corresponding baseline, thereby isolating differences in memory construction and video access.

4.2 MAIN RESULTS 

Table 1 compares Video-EMem with frontier VLMs and agentic methods for long-video understand-ing. Following the conventional evaluation setting, VLM baselines receive 256 and 2048 sampled frames. Agentic baselines access the original video through multiple rounds of retrieval and infer-ence, rather than relying on a compressed reusable memory. 

Superior performance. With at most 20K text tokens and 160 images per video, Video-EMem achieves the highest accuracy among the compared methods on all three benchmarks: 74.4% on LVBench, 72.8% on Video-MME, and 69.7% on LongVideoBench using OpenAI o3 as the answer model. These results demonstrate the effectiveness of our memory representation across diverse long-video QA benchmarks. Moreover, Video-EMem consistently outperforms prior agentic meth-ods with the same answer model, supporting the contribution of memory construction and reuse beyond improvements in model capability. 

Query efficiency. Video-EMem combines strong accuracy with low per-query latency by accessing preconstructed memory and invoking the answer model only once. The Qwen3-VL-30B variant takes 5.51 s per query, compared with approximately 3,000 s for PACE. With OpenAI o3, Video-EMem takes 9.69 s, compared with approximately 180 s for DVD. These results demonstrate that memory reuse supports efficient querying while preserving information needed for accurate answers. 4.3 ABLATION STUDY

## 5 CONCLUSION 

In this paper, we introduced Video-EMem, an evolvable write-once, query-many memory harness for efficient long-video understanding. It encodes each video into compact, time-anchored percep-tual observations that combine free-form text with sparse complementary images. With the under-9lying MLLMs frozen, Video-EMem separately evolves a query-independent Writer using source-preservation feedback and a query-specific Reader using attributed QA failures. Experiments on three long-video QA benchmarks demonstrate improved accuracy, strong cross-benchmark general-ization, and substantially lower per-query latency than direct-input and agentic baselines. ## C STORAGE REDUCTION 

A key advantage of our compact video memory is that it avoids repeatedly storing and processing the complete video stream. Each video is converted into a bounded persistent memory containing: (1) a textual memory with a 20K-token budget, and (2) 160 sparsely selected visual observations. The visual observations are stored as JPEG images with the resized to 448 × 448 pixels. This representation retains temporally distributed textual and visual evidence while substantially reducing the persistent storage footprint.
