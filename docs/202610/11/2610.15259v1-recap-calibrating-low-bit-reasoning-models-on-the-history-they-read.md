## 摘要
低比特量化降低了推理模型的部署成本，但可能显著损害长思维链。每一步都会读取跨越数千个 token 的缓存键和值，使得量化误差沿轨迹累积。标准校准在短片段上运行，忽略了后续推理步骤所需的更早上下文。即使保留该上下文，仅靠缓存重建误差也无法刻画量化误差如何影响后续注意力。我们提出 RECAP，一种在模型所读取的历史上进行校准的训练后量化方法。动态前缀校准将长历史上下文与短块重建分离。它使用当前量化器重新生成前缀键和值，并轮换活动块以监督轨迹上的每个位置。前缀读取几何进一步根据历史缓存误差对注意力输出的影响来监督这些误差，并对键误差和值误差进行非对称加权。由于两个组件仅在校准期间应用，RECAP 在多种推理模型和量化设置下均优于基线。在 W4A4KV4 下，RECAP 在 DeepSeek-R1-Distill-Qwen-1.5B 的 MATH500 上比基线提升 13.3 个百分点，在 Qwen3-4B 的 AIME-120 上提升 15.8 个百分点。这些结果凸显了在校准低比特推理时保留历史依赖关系的重要性。

## Abstract
Low-bit quantization reduces the cost of serving reasoning models but can substantially degrade long chains of thought. Each step reads cached keys and values spanning thousands of tokens, allowing quantization errors to accumulate along the trajectory. Standard calibration operates on short segments that omit the earlier context needed by later reasoning steps. Even when this context is retained, cache reconstruction error alone does not capture how quantization errors affect subsequent attention. We present RECAP, a post-training quantization method that calibrates reasoning models on the history they read. Dynamic-prefix calibration separates long historical context from short-block reconstruction. It regenerates prefix keys and values with the current quantizer and rotates the active block to supervise every position along the trajectory. Prefix read geometry further supervises historical cache errors according to their effects on attention outputs, weighting key and value errors asymmetrically. With both components applied only during calibration, RECAP outperforms the baseline across multiple reasoning models and quantization settings. Under W4A4KV4, RECAP improves accuracy over the baseline by 13.3 percentage points on MATH500 with DeepSeek-R1-Distill-Qwen-1.5B and 15.8 points on AIME-120 with Qwen3-4B. These results highlight the importance of preserving historical dependencies during calibration for low-bit reasoning.

## 1. 核心问题与研究动机

- **背景**：低比特量化（W4A4KV4 / W4A8KV4）可显著降低推理模型（如 DeepSeek-R1-Distill、Qwen3）的部署成本，但会严重损害长思维链推理能力。
- **现象**：推理每一步都要读取跨度数千 token 的历史 KV 缓存，量化误差沿轨迹累积，导致答案准确率下降、生成长度异常增长（图 1b,c）。
- **现有方法的不足**：
  - 标准 PTQ 校准（QuaRot、FlatQuant）使用短片段或固定尾段，遗漏后续步骤依赖的早期上下文；
  - 即使保留上下文，仅最小化缓存重建误差（MSE）也不能反映误差对后续注意力的实际影响。
- **论文指出的三大挑战**（第 2 节、图 2）：
  1. **重要性分数迁移性差**：跨推理轨迹的缓存重要性评分接近随机（AUC 0.43–0.50），难以可靠选择应保留的缓存状态；
  2. **历史上下文、位置覆盖与成本三者难平衡**：短窗口缺历史，全序列重建成本高，仅重建末段则早期位置无监督（诊断显示 KL 在前/后 1K 位置分别高达 6.58/7.33 nats/token）；
  3. **同等大小缓存误差影响不等**：当前 query 对历史 token 的注意力权重不同，误差对注意力输出的扭曲程度不同。
- **整体含义**：低比特推理模型的校准必须“在模型所读取的历史上”进行，既要保留长历史依赖，又要按注意力影响监督历史缓存误差。

## 2. 方法论（RECAP）

**核心思想**：将“长历史上下文”与“短块重建”解耦——动态前缀提供历史，短块轮换提供位置覆盖，前缀读取几何提供面向注意力影响的缓存监督。所有组件仅在校准阶段使用，**推理阶段零额外开销**。

**（1）校准基础设定（3.1 节）**
- 用全精度目标模型自生成推理轨迹构建自校准集 $\mathcal{D}_{self}=\{(x_i, r_i)\}$（NuminaMath-1.5 轨迹），保留原始因果顺序与位置 ID，缓存各层 FP 输入/输出。
- 沿用 FlatQuant 的可学习仿射变换、对角缩放与裁剪参数，权重冻结；以全序列重建损失 $L^{full}_\ell$ 为优化目标。

**（2）动态前缀校准（3.2 节）**
- 将长度 $T$ 的轨迹切分为长度 $B$ 的块；对起点 $P=jB$ 的活动块，用**当前量化器**从固定 FP 层输入重新生成前缀 KV：$C_{<P}(\theta_\ell)=\mathrm{KV}_{\theta_\ell}(H^\ell_{<P})$，每个 microstep 重建以保持与变化参数一致。
- 只重建活动块输出（式 6），梯度**流经活动块及其前缀 KV**，从而间接更新产生历史表示的参数，而无需计算前缀的 query/attention/FFN。
- **块轮换**：第 $e$ 个 epoch 中样本 $i$ 使用块 $j=(e+i)\bmod J$，使每个样本在 $J$ 个 epoch 内遍历所有位置。
- **理论保证**（式 7）：固定参数下各块损失之和等于全序列损失，因此均匀采样块是 $L^{full}$ 及其梯度的**无偏估计**（需逐 token 量化统计与相同因果支撑）。
- **成本**：每次更新约 $BP+B(B+1)/2$ 个 QK 对，$T=4B$ 时约为全序列的 1/4；FFN 仅对 $B$ 个活动位置计算。

**（3）前缀读取几何（3.3 节）**
- 对前缀位置 $t<P$ 的扰动，注意力输出一阶变化（式 8）：
  $\delta y_s=\sum_{t<P}a_{st}\delta v_t+\sum_{t<P}\frac{a_{st}}{\sqrt{d_h}}(v_t-y_s)q_s^\top\delta k_t$
  ——键误差通过“查询方向对齐 × 值对比”起作用，值误差按注意力权重直接进入。
- 取注意力 Jacobian Gram 矩阵的 K/V 对角块（式 9）：
  $G^K_{t,P}=\mathbb{E}_{s\in Q_P}\left[\frac{a_{st}^2\|v_t-y_s\|_2^2}{d_h}q_sq_s^\top\right]$，$g^V_{t,P}=\mathbb{E}_{s\in Q_P}[a_{st}^2]$；GQA 下对共享 KV 头的 query 头求和。
- **校准目标**（式 10）：$L_\ell=L^{block}_\ell(\theta_\ell;j)+\alpha_\ell R_\ell$，其中
  $R_\ell=\frac{1}{H_{KV}P}\sum_h\sum_{t<P}\left[s^K_{t,P,h}\delta k_{t,h}^\top\tilde{G}^K_{\beta(t),h}\delta k_{t,h}+g^V_{t,P,h}\|\delta v_{t,h}\|_2^2\right]$
  ——**键误差按投影方向加权，值误差按读取强度加权，形成非对称监督**。
- 关键实现细节：
  - 统计量从原始 FP 模型一次性收集并冻结；键方向按 4K 位置桶与 KV 头池化，取秩 $r=8$ 的主特征向量 + 各向同性残差 $\rho$ 构造 PSD 近似 $\tilde{G}^K$；
  - 比较量化与 FP 缓存时使用**真实逆变换**（保留梯度），避免把缓存基变换误判为量化误差；
  - $\alpha_\ell$ 固定为初始化时“块/辅助梯度范数比”下中位数的 0.1 倍；辅助项权重在前 10% 更新为 0，随后 10% 线性升至 1。
