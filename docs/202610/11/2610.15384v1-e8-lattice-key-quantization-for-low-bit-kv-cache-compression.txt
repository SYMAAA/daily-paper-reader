## Abstract 

Compressing the key-value (KV) cache is essential for serving long-context large language models (LLMs) under memory constraints. While current scalar quantiza-tion methods achieve significant compression, they typically face a quality-fidelity trade-off, either suffering from performance instability at 2-bit precision or ne-cessitating 3-bit keys to maintain model quality. In this work, we demonstrate that a uniform low-bit k2v2 configuration (2-bit keys and 2-bit values) can pre-serve near-baseline quality by using vector quantization (VQ) based on the E8

lattice for KV keys. We show that structured VQ exploits correlations across adjacent dimensions to achieve signal-to-quantization-noise ratios (SQNR) higher than those of independent scalar quantization at the same key payload rate. To ensure practical utility, we adapt a table-based asymmetric scoring algorithm that avoids explicit codebook dequantization during attention computation and pre-serves decode-throughput parity with scalar baselines. Across five LLM families, our E8 k2v2 approach yields ~ 6× KV compression, roughly 20% smaller than scalar k3v2 (3-bit keys and 2-bit values), while retaining near-baseline long-context perplexity. In our full-suite perplexity evaluation, E8 improves over scalar k3v2 in 80% of model–dataset–context settings. These results indicate that E8 lattice VQ improves quality per byte while keeping throughput at parity, suggesting that structured key quantization is a useful primitive for KV-compression stacks. Over-all, our work provides a low-overhead primitive for expanding the quality-memory frontier in long-context LLM inference. 

## 1 Introduction 

Supporting long context windows in large language models (LLMs) is essential for in-context learning, long-horizon reasoning, holistic codebase analysis, and retrieval-augmented generation [Wang et al., 2024]. LLM inference requires storing key-value (KV) pairs for every token in the context window

across all attention layers and heads, placing high pressure on available device memory [Li et al., 2025a]. For a model with L layers, Hkv KV heads, and head dimension d, the KV cache consumes 

2 · L · Hkv · d · 2 bytes per token in fp16. At 128K tokens of context, even an 8B grouped-query model requires tens of gigabytes of KV cache, and models with more KV heads can exceed the memory footprint of the model weights themselves. This bottleneck limits batch size and context length, leading to prohibitive deployment cost. Consequently, KV-cache efficiency directly affects whether long-context serving fits on a single accelerator or requires multi-GPU execution. To mitigate these memory constraints, KV cache quantization has emerged as a prominent solu-tion [Li et al., 2025a]. Recent KV-cache quantization approaches, including KIVI [Liu et al., 2024], KVQuant [Hooper et al., 2024], and TurboQuant [Zandieh et al., 2025], rely primarily on per-channel scalar quantization. Treating each of the key dimensions d as an independent signal, a quantization of b bits assigns each dimension to one of the 2b levels, achieving a rate of b bits/dim. However, scalar quantization often incurs quality degradation at very low bitrates. Recent hardware-optimized configurations typically necessitate 3 bits for keys (e.g., TurboQuant’s k3v2 setting: 3-bit keys and 2-bit values) to preserve model quality. We hypothesize that the degradation of low-bit scalar key quantization is partly due to limited use of geometric structure in key vectors. While scalar methods are computationally efficient, they treat each dimension in isolation, ignoring the inter-dimensional correlations prevalent in LLM hidden states [Engels et al., 2025]. To capture this structure, we use lattice VQ over blocks of dimensions to exploit space-filling and shaping gains, which can provide higher SQNR than scalar quantization at matched bit rates [Zamir and Feder, 1996]. Specifically, we employ the E8 lattice in R8, which offers a useful combination of strong lattice geometry and practical efficiency. It achieves the densest possible sphere packing in eight dimen-sions [Viazovska, 2017], with near-spherical Voronoi cells that provide a shaping advantage over cubic scalar quantizers. Our implementation uses a structured E8-derived (E8P12-style) index-ing scheme with parity/sign constraints and a two-branch ±0.25 selection rule, enabling efficient nearest-codeword assignment without brute-force search over all codewords. 

Contributions. This paper makes the following contributions: 1. We apply E8 lattice VQ to key compression in the KV cache, partitioning each d-dimensional key vector into independent 8-dimensional blocks. At 2 bits/dim payload (65,536 codewords per block; 2.25 bits/dim effective key rate including norm metadata), the resulting k2v2 con-figuration achieves ~ 6× total KV compression relative to fp16. Reported memory numbers are end-to-end KV-cache bytes/token, counting keys, values, quantized indices/signs, norms, and value scale/zero metadata. 2. We show that E8 at low key rate achieves rate-distortion performance between scalar 3-bit and 4-bit quantization. On 128-dimensional Gaussian vectors, E8 obtains 10.47 dB SQNR, compared with 7.37 dB for scalar 3-bit, while using a lower effective key rate. In a controlled attention-fidelity probe, the 2-bit E8 configuration also yields lower average attention KL divergence than scalar k3v2 (0.045 vs. 0.091) and KIVI k2v2 (0.224), indicating better preservation of fp16 attention distributions under compression. 3. To avoid dequantizing vector-quantized keys during decoding, we adapt table-based asym-metric scoring to the fixed E8 key codebook. For each query-head block, we precompute the dot product between the query block and all 65 ,536 E8 codewords. Each compressed key block can then be scored by indexing this table with its stored codeword id, replacing an 8-dimensional dot product with a lookup. This removes explicit key dequantization from the decode-time scoring path in our serving path and matches the throughput of optimized scalar decoders in the measured setting. 4. We provide full-suite evaluations across five LLMs (Qwen2.5, Llama-3.1, Mistral, Falcon3, and Granite). The results show that E8 k2v2 improves the quality–memory trade-off over scalar k3v2 in most long-context perplexity settings and has lower perplexity than KIVI k2v2 across the evaluated perplexity suite, without a measurable decode-throughput penalty. 22 Related work 

KV-cache quantization. Current KV-cache compression methods primarily use scalar quantization. KIVI [Liu et al., 2024] uses per-channel asymmetric key quantization and per-token value quantiza-tion; KVQuant [Hooper et al., 2024] adds pre-RoPE keys, non-uniform calibrated grids, and sparse outlier handling; GEAR [Kang et al., 2024] combines low-rank approximation with quantized residu-als; TurboQuant [Zandieh et al., 2025] uses QJL random projections for calibration-free robustness, and its k3v2 setting is our primary scalar baseline. ZipCache [He et al., 2024], LeanKV [Zhang et al., 2025b], and AQUA-KV [Shutova et al., 2025] further adapt bit-widths across tokens, keys/values, or predictable residual components. These methods are effective, but the dominant coding operation remains scalar or projection-based; our work instead encodes each key block with a structured geometry-aware codebook. 

Joint coding and vector quantization. Coupled Quantization (CQ) [Zhang et al., 2024] observes that joint KV-channel entropy can be far below the sum of marginal entropies, motivating cross-channel coding; PM-KVQ [Liu et al., 2025] highlights the need for long-context-aware calibration under RoPE. Recent VQ-based KV-cache systems, including NestQuant [Savkin et al., 2025] and CommVQ [Li et al., 2025b], further show that lattice or learned vector codebooks can improve low-bit cache compression. Our method shares the premise that key channels should not be treated independently, but differs by using a fixed, non-learned E8 key codebook with online encoding and by adding decode-time table scoring so attention can operate directly on compressed keys. Related VQ work for weights, including PQ [Jegou et al., 2011, Guo et al., 2020], QuIP [Chee et al., 2023], QuIP# [Tseng et al., 2024], and AQLM [Egiazarian et al., 2024], shows that structured codebooks can achieve strong low-bit rate-distortion. KV caches impose different constraints: activations are produced online during decoding and attention scores must be computed against a growing cache, so avoiding dense key reconstruction is central. 

Token reduction and attention approximation. Token-eviction systems reduce cache length rather than bits per token. StreamingLLM [Xiao et al., 2024] retains recent tokens and attention sinks; H2O [Zhang et al., 2023] and SnapKV [Li et al., 2024] retain tokens selected by accumulated or pooled attention; MagicPIG [Chen et al., 2024] uses LSH and CPU-resident hash tables for sparse long-context attention. Projection methods such as Loki [Singhania et al., 2024] reduce effective key dimensionality before attention. These approaches are orthogonal to our quantizer: one could apply 

E8 key coding to the retained token set or to a projected subspace. 

Lattice codes. Lattice quantization theory [Zamir and Feder, 1996, Conway and Sloane, 1999] shows that structured lattices achieve space-filling gain that scalar quantizers cannot. The E8 lattice is the densest known sphere packing in eight dimensions [Viazovska, 2017]; its 240 kissing neighbors and near-spherical Voronoi cells give a shaping advantage over cubic lattices and motivate its use in low-bit neural compression. To our knowledge, this is the first application of E8 coding to runtime KV caches with online encoding and throughput-neutral compressed-domain attention scoring.

3.3 Table-based asymmetric scoring 

A naive implementation of attention with lattice VQ keys would dequantize each key by looking up its M codewords from the E8 grid, reconstructing a dense d-dimensional vector, then computing the dot product with the query. For N cached keys, this requires N M random accesses to a 

65 ,536 × 8 float32 table—a memory bandwidth bottleneck that typically renders lattice VQ slower 4than scalar quantization. We instead use table-based asymmetric scoring , following asymmetric-distance computation in product quantization [Jegou et al., 2011] and recent lookup-based KV-attention systems [Zhang et al., 2025a, Wu et al., 2025, Karmore, 2026]. Computational efficiency. Step 2 costs M × 65 ,536 8-dimensional dot products, implemented as a batched matrix multiplication over query blocks and codewords. Step 3 costs N M table gathers plus N M additions. The M lookup tables require M × 65 , 536 × 4 bytes of memory. For M = 16 ,this totals 4 MB per query head. Because each gather is a single indexed read from a contiguous query-local table, per-key scoring is memory-efficient in our decode setting; only the once-per-query table build scales with codebook size. For batched teacher-forcing quality evaluations (perplexity and downstream tasks), we use the same compressed representation and asymmetric inner-product estimator. These batched evaluations use a mathematically equivalent dense reconstruction when processing many query positions at once; the decode throughput results in Table 3 exercise the table-based serving path directly. 

3.4 Implementation details 

We integrate E8 key quantization into the TurboQuant [Zandieh et al., 2025] framework, retaining its value quantization and residual window for recently inserted tokens. The reported E8 k2 key path does not use QJL residual signs; QJL is retained only in scalar TurboQuant baselines. The random orthogonal rotation matrix R ∈ Rd×d is initialized once per layer from a seeded PRNG. For d = 128 ,storing this dense matrix in fp32 requires 64 KB per layer (or 32 KB in fp16), which is a negligible model-level overhead in our accounting. Encoding a single key requires one matrix-vector multiply followed by M fast structured nearest-codeword searches over 8D blocks. Rather than brute-force 

O(|C| ) VQ lookup, the implementation first rounds in a reduced absolute-value candidate set, then applies sign/parity-consistent index reconstruction with the ±0.25 branch selection. As shown in the rate-distortion analysis in Figure 1, this integration yields an E8 configuration whose SQNR lies between scalar 3-bit and 4-bit baselines while remaining in the low-bit key-rate regime.

Metrics. To provide aholistic assessment, we categorize our evaluation into three axes: (1) End-to-end quality: long-context perplexity on WikiText-2 [Merity et al., 2016] and C4 [Dodge et al., 2021] (contexts 512, 2048, 4096), downstream few-shot accuracy on HellaSwag (10-shot) [Zellers et al., 2019], ARC-Challenge (25-shot) [Clark et al., 2018], and WinoGrande (5-shot) [Sakaguchi et al., 2019], alongside a needle-in-a-haystack (NIAH) retrieval sanity check. (2) Internal fidelity: per-layer cosine similarity between compressed and fp16 key representations, and KL divergence for attention distributions. (3) System performance: single-sequence decode throughput (tokens/s) on a single 80 GB NVIDIA A100 GPU and total memory consumption. We report single-system, single-sequence serving measurements; larger-batch scheduling behavior, cross-hardware variance, and cross-backend variance are left to future work. 

4.2 Rate-distortion analysis 

Figure 1 shows rate-distortion curves for our implemented TurboQuant-style scalar/product key baseline and the E8 lattice key quantizer on 128-dimensional Gaussian vectors. At the low-rate operating point, E8 achieves SQNR of 10.47 dB versus 2.43 dB for the 2-bit scalar/product baseline. More practically, E8 at 2 bits/dim (SQNR 10.47 dB, cosine similarity 0.954) falls between the implemented scalar 3-bit (7.37 dB, 0.920) and 4-bit (12.69 dB, 0.974) configurations. This comparison supports the empirical quality-per-bit advantage of the fixed E8 key codec in our compression stack; it should not be read as an optimal scalar-quantizer lower bound.

4.4 Memory compression 

Table 2 quantifies per-token KV cache memory. E8 k2v2 achieves ∼6× effective compression for the four Hkv = 8 models, compared with ∼4.8× for scalar k3v2. This corresponds to roughly a 20% smaller compressed cache than scalar k3v2 after accounting for packed key/value payloads and per-token metadata. For a representative 8B architecture such as Llama-3.1-8B, scalar k3v2 requires 27.3 KB/token, whereas E8 k2v2 requires 21.7 KB/token, saving 5.6 KB per token in the quantized cache region. At 128K context length, this accounting projects roughly 700 MB of additional memory saved per sequence. 

4.5 Decode throughput 

Table 3 demonstrates that table-based asymmetric scoring (detailed in Section 3.3) successfully eliminates the computational bottleneck traditionally associated with lattice VQ. Across all five evaluated architectures and context lengths, E8 k2v2 achieves decode-throughput parity with both the uncompressed fp16 baseline and the optimized scalar (k3v2) and KIVI kernels in our single-sequence decode benchmark. The variance across all methods falls within the margin of standard measurement noise (±0.2 tok/s), indicating no measurable latency degradation in this setting. This empirical parity supports our system design in the measured setting: precomputing the lookup table avoids dense key reconstruction during attention, and the remaining table-build/gather overhead is below measurement noise for our single-sequence A100 decode path. These throughput results are measured on our A100 serving path; additional validation on other accelerators and paged-attention runtimes is left for future work.

4.7 Attention fidelity 

Figure 3 shows per-layer cosine similarity between compressed and fp16 key representations. E8

at 2 bits/dim remains substantially higher than scalar at 3 bits (roughly 0.954 vs. 0.921 average), consistent with the rate-distortion analysis. The shaded range is narrow and smooth across depth, suggesting lattice quantization error is not concentrated in a small subset of layers. This reconstruction fidelity directly translates to superior preservation of the attention mechanism itself. Figure 3b illustrates the per-layer KL divergence between attention distributions computed with compressed versus fp16 keys. Here, E8 achieves a remarkably stable and low KL divergence (0.045), effectively halving the error of the 3-bit scalar baseline (0.091). Furthermore, E8 outperforms KIVI k2v2, which suffers from attention distribution shifts (KL > 0.200). This confirms that our lattice geometry preserves the true pre-softmax attention logits more faithfully than existing 2-bit methods, ensuring that improved geometric reconstruction meaningfully carries through to downstream attention behavior.

## 5 Conclusion 

We demonstrate that E8 lattice vector quantization is a practical primitive for low-bit KV-cache key compression. Its fixed geometry-aware codebook enables table-based asymmetric scoring: for each query, dot products with the shared codebook are precomputed once and cached keys are scored directly from indices, avoiding explicit key dequantization in the decode path. Across diverse LLM families and long-context evaluations, this design improves key fidelity and quality per byte while preserving downstream quality and single-sequence decode-throughput parity. At the same time, making compressed-domain scoring efficient beyond this setting, especially for larger batches and prefill-heavy workloads remains an important systems challenge. These results suggest that structured vector codes are a useful building block for KV-compression systems.
