## 摘要
大型视觉-语言模型（LVLM）将图像和视频表示为长视觉 token 序列，从而显著增加推理成本。这些成本推动了视觉 token 剪枝，而其有效性取决于两个因素：用于选择的信号是什么，以及该信号何时可用。我们的分析揭示了互补的局限性：在激进压缩下，视觉侧 [CLS] 注意力会产生分散且偏向背景的选择，而更强的查询条件化信号要在大型语言模型（LLM）内部经过大量计算后才可用。这自然引出一个问题：能否在询问 LLM 之前执行结构连贯且查询感知的 token 选择？因此，我们提出 ST-Pruner（Spectral-Textual Pruner），一种用于 LLM 之前视觉 token 选择的免训练框架。它通过无参数乘法融合，将与注意力无关的谱显著性与倒置的 patch-文本相似度结合起来。在多种 LVLM 上，ST-Pruner 最多使用 11.1% 的视觉 token 即可保持全 token 性能的 95% 以上，并在 LLaVA-NeXT 上实现 3.2 倍端到端加速。代码见 https://github.com/sejong-rcv/ST-Pruner。

## Abstract
Large vision-language models (LVLMs) represent images and videos as long visual-token sequences, substantially increasing inference costs. These costs motivate visual-token pruning, whose effectiveness depends on both what signal is used for selection and when that signal becomes available. Our analysis reveals complementary limitations: visual-side [CLS] attention produces scattered, background-biased selections under aggressive compression, while stronger query-conditioned signals become available after substantial computation within the large language model (LLM). This raises a natural question: can structurally coherent, query-aware token selection be performed before consulting the LLM? We therefore propose ST-Pruner (Spectral-Textual Pruner), a training-free framework for pre-LLM visual-token selection. It combines attention-independent spectral saliency with inverted patch-text similarity through parameter-free multiplicative fusion. Across diverse LVLMs, ST-Pruner retains over 95% of full-token performance using at most 11.1% of visual tokens and achieves a 3.2x end-to-end speedup on LLaVA-NeXT. Code is available at https://github.com/sejong-rcv/ST-Pruner.

## 1. 核心问题与研究动机

- **背景**：大型视觉语言模型（LVLM）将图像、多视图图像和视频编码为长视觉 token 序列，显著增加 LLM 的 prefill、自注意力与 KV cache 成本，因此视觉 token 剪枝成为重要加速手段。
- **核心矛盾**：剪枝效果不仅取决于“用什么信号选 token”，还取决于“该信号何时可用”。
  - 视觉侧常用 **[CLS]-to-patch 注意力**：在低 token 预算下选择分散、偏向背景，难以保持前景结构。
  - LLM 内部 **query-to-patch 注意力**：查询相关性更强，但最佳选择出现在中后层，此时 LLM 已产生大量计算，剪枝收益受限；早层还受 RoPE 位置偏移影响。
- **论文问题**：能否在**进入 LLM 之前**，同时获得结构连贯性和查询感知的视觉 token 选择？
- **总体含义**：作者主张不要依赖 LLM 内部注意力来决定剪枝，而应从视觉特征的低秩谱结构和预训练视觉-语言空间中的 patch–text 关系构造前置选择信号。

## 2. 方法论：ST-Pruner

### 2.1 核心思想

ST-Pruner（Spectral-Textual Pruner）是一个**免训练、无参数融合、LLM 前执行**的视觉 token 剪枝框架。它对每个视觉组（图像、视图或视频帧）独立打分，融合两类互补信号：

1. **谱显著性**：与注意力无关，衡量每个 patch 在视觉特征矩阵主导低秩结构中的参与程度。
2. **语义相关性**：利用配对视觉-语言编码器计算 patch–text 相似度，并采用**倒置相似度**作为查询相关性的前置代理信号。

最终通过逐元素乘法融合，选取 top-K token，并按原始顺序保留。

### 2.2 关键技术细节

- 给定视觉特征矩阵 \(Z=[z_1,\dots,z_N]^\top\in\mathbb{R}^{N\times d}\)，计算随机化 rank-R SVD：
  \[
  Z\approx U_R\Sigma_R V_R^\top
  \]
- 谱显著性原始分数：
  \[
  \bar{s}_i=\sum_{k=1}^{R}\sqrt{\sigma_k}U_{ik}^2
  \]
  其中 \(U_{ik}^2\) 表示 patch \(i\) 在第 \(k\) 个主导奇异方向的参与度，\(\sqrt{\sigma_k}\) 用于保留奇异值排序但抑制最强分量的过度主导。
- 对分数做 min–max 归一化得到 \(s_i\in[0,1]\)。
- 语义分支：
  - 使用与视觉编码器配对的冻结视觉投影 \(\phi\) 和文本编码器/投影 \(\psi\)；
  - \(v_i=\phi(z_i)\)，\(q=\psi(T)\)，二者 L2 归一化；
  - 计算余弦相似度 \(\rho_i=v_i^\top q\)；
  - 使用倒置相似度并归一化：\(r_i=\mathcal{N}(-\rho)_i\)，越大表示越重要。
- 融合与选择：
  \[
  g_i=s_i\cdot r_i,\qquad S=\operatorname{TopK}(g,K)
  \]
  乘法融合要求两个 cue 同时支持该 patch，且不引入额外平衡系数。
- 多视图/视频按每个视觉组独立打分、归一化和选择，随后拼接；保留 token 按原序列位置排序。
- 默认谱秩为 \(R=N/8\)，例如 576 token 用 \(R=72\)，256 token 用 \(R=32\)，1296 token 用 \(R=162\)。随机化 SVD 使用少量幂迭代。
- 复杂度：谱分支约 \(O(NdR+NR)\)；语义分支仅一次冻结文本编码前向和相似度计算。

## 6. 主要结论与发现

- ST-Pruner 在 LLaVA-1.5 上以 192/128/64 token 分别保留 **99.2%/98.6%/96.3%** 平均性能；64 token 仅为原 576 token 的 **11.1%**。
- LLaVA-NeXT 上以 640/320/160 token 保留 **99.6%/97.5%/94.4%**；320 token 时 POPE F1 为 86.1，接近 full-token 86.5。
- Video-LLaVA 上以 136/2048 token（约 93.4% 削减）保留 **95.4%** 平均性能，高于 VisionZip 的 91.0%。
- Qwen2.5-VL 仅谱分支时，512/256/128 token 分别保留 **99.6%/98.2%/95.4%**。
- 效率：LLaVA-NeXT 320 token 下，prefill FLOPs 从 34.9T 降至 4.5T，KV cache 从 1542 MB 降至 200 MB；实现 **3.6× prefill 加速、3.2× 端到端加速**，POPE F1 保留约 99.5%。
- 倒置 patch–text 相似度显著优于常规正相似度；例如 K=128 时 POPE 从 1.5 提升到 86.9。
- 谱显著性与语义相关性互补：语义分支在 GQA 上更强，谱分支在 TextVQA 上更好，融合后在 POPE、MME P、TextVQA 上表现最佳。
